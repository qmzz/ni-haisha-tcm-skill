# 柴胡

## 🌿 神农本草原意与性味气味

《神农本草经》原文收载柴胡，列于上品，经文曰：

> **“柴胡，味苦平。主心腹肠胃中结气，饮食积聚，寒热邪气，推陈致新。久服轻身，明目，益精。”**

此原文乃柴胡之灵魂所在——**“推陈致新”** 四字，是整部《本经》中极少出现的至高评价，与大黄同得此四字，而柴胡性味苦平，不似大黄之峻猛攻下，其推陈致新是在**半表半里**之间，以**和解**之法，令陈旧的郁结之气自然消散，新的正气自然流通。

**气味与阴阳升降属性：**

- 味**苦**，苦能泄、能降、能坚。苦味入心，兼走肝胆。
- 气**平**（微寒），平者不偏不倚，不似寒药之沉，不似热药之浮，恰合少阳**枢纽**之位。
- **气薄而味薄**，气薄则能升能降，味薄则能通能散，合之则**升降同调、表里双解**。
- 法象天地之生：柴胡生于春末夏初，得**少阳生发之气**最全。其根深而直，茎细而挺，叶如竹叶，花小而黄，整株植物呈现的是一种**条达舒展、向上向外**的生气。以法象言之，天地间**少阳之气**从地下水中升起，化为春风，吹散阴霾，柴胡正是禀此**春风生发之气**而生，故能入少阳，疏达三焦，和解表里。

倪师常言：“柴胡这味药，你看它长得细细直直的，叶子一片一片很清爽，它就是把堵住的气给你**一条一条解开**的。”

## 🫀 倪师药性推演与破局心法

**柴胡这味药的灵魂，倪师一句话讲透：**

> **“柴胡是和解少阳的第一要药。少阳是什么？就是半表半里，就是那个枢纽。柴胡不是发汗药，不是攻下药，它是在中间给你**和解**的。”**

倪师用大白话与物理比喻讲柴胡的机理，核心有三层：

**第一层：三焦水道与“推陈致新”**

倪师讲，人体有三焦，三焦者，**决渎之官，水道出焉**。三焦不通，水液就停聚，气机就堵塞。柴胡之功，在于**疏通三焦**，让该走的水走，该散的气散。

> **“三焦像什么？就像城市的下水道系统。柴胡就是通下水道的。你下水道堵了，水漫上来，你不是去把水舀掉，你是要把堵的地方通开。柴胡就是把三焦那个堵住的地方给你通开，陈旧的积水、郁气一散，新的气血就来了，这就叫推陈致新。”**

**第二层：少阳枢纽与寒热往来**

倪师讲少阳病的主证是**往来寒热**，为什么？因为少阳在半表半里，正气与邪气相争，正胜则热，邪胜则寒，就像两军对峙在边界上，一会儿你推过去，一会儿我推过来。

> **“柴胡就是把少阳这个‘边界’给理顺了。它不是帮你打仗，它是让两边的军队各回各家，不打了。所以柴胡能治往来寒热，一剂下去，寒热就退了，不是它杀了邪气，是它把邪气**请**出去了。”**

**第三层：疏肝解郁与气机条达**

倪师在讲柴胡疏肝时说：

> **“肝主疏泄，肝气郁结，人就郁闷、烦躁、胸胁苦满。柴胡是干什么的？柴胡就是给肝气**松绑**的。肝像个将军，将军不高兴了，整个军队都乱了。柴胡就是把将军的绳子解开，让肝气重新条达。所以你看小柴胡汤治什么？胸胁苦满、默默不欲饮食、心烦喜呕，全是气机郁结在少阳的症状。”**

**与相似药物的对比，倪师心法：**

- **柴胡 vs 桂枝**：桂枝走太阳，解肌发表，是**从外面**把邪气赶出去；柴胡走少阳，和解枢机，是**从中间**把邪气化解掉。
- **柴胡 vs 大黄**：大黄推陈致新，是从**肠胃**攻下，峻猛直折；柴胡推陈致新，是从**三焦**疏达，温和和解。
- **柴胡 vs 白芍**：白芍酸收，敛肝柔肝，是**往回收**；柴胡苦泄，疏肝达肝，是**往外散**。一收一散，恰恰构成了小柴胡汤与四逆散的核心药对。

## 🎯 临床用量法度与配伍抓手

### 一、倪师常用剂量法度

- **常规剂量**：**一钱至三钱**（约3–9克），用于疏肝解郁、和解少阳，小柴胡汤中柴胡用量一般为**半斤**（汉制），折合现代约**24–30克**，但倪师临床常视体质与病情调整，普通外感少阳证多用**三钱**。
- **急危重症重剂法**：倪师在治疗**少阳阳明合病**、**高热不退**、**疟疾样往来寒热**时，柴胡可用至**五钱至一两**（15–30克），甚至更高，但必须配伍黄芩、半夏、生姜、大枣、人参（或党参）等，**不可单味独用**。
- **倪师特别强调**：“柴胡剂量小，是升提疏达；剂量大，是和解退热。你要看病人是郁证还是热证，郁证轻则一钱两钱，热证重则五钱八钱，不要死死的。”

### 二、经方经典药对配伍要诀

| 药对 | 配伍机理 | 倪师心法 |
|------|----------|----------|
| **柴胡 + 黄芩** | 一升一降，一散一清，和解少阳 | “柴胡把邪气从半表半里往外推，黄芩从里面把热清掉，两个一合作，少阳就干净了。” |
| **柴胡 + 半夏** | 疏达气机 + 降逆止呕 | “少阳证心烦喜呕，柴胡升，半夏降，一升一降，呕就止了。” |
| **柴胡 + 白芍** | 疏肝 + 柔肝，一散一收 | “肝气郁结，你光散不行，还要收。柴胡散，白芍收，散收结合，肝气就顺了。” |
| **柴胡 + 枳实** | 疏肝 + 破气，升降同调 | “四逆散就是柴胡、枳实、白芍、甘草。柴胡升，枳实降，气机一通，四肢就温了。” |
| **柴胡 + 桂枝** | 太阳少阳双解 | “柴胡桂枝汤，就是太阳少阳合病的主方。桂枝走表，柴胡走半表半里，两个一合作，表里都通了。” |
| **柴胡 + 龙骨 + 牡蛎** | 疏肝 + 潜阳 + 安神 | “柴胡加龙骨牡蛎汤，治的是少阳证兼有烦惊、谵语。柴胡疏达，龙牡潜镇，一疏一镇，神就安了。” |

### 三、临证眼目与辨证使用禁忌

**临证眼目（倪师辨证抓手）：**

1. **往来寒热**——一阵冷一阵热，是少阳证第一眼目。
2. **胸胁苦满**——病人说胸口、肋骨下面胀闷不舒服。
3. **默默不欲饮食**——不想讲话，不想吃饭，情绪低落。
4. **心烦喜呕**——心里烦，容易恶心呕吐。
5. **脉弦**——脉象如按琴弦，端直以长，是少阳主脉。

以上但见一证便是，不必悉具，即可考虑柴胡剂。

**使用禁忌（倪师特别警示）：**

- **真阴亏损、阴虚火旺者慎用**：柴胡升散，阴虚之人用之，如**火上浇油**，劫灼真阴。
- **太阳病初起，邪在表者，不可单用柴胡**：邪在表当汗解，柴胡是和解半表半里，用之过早，引邪入里。
- **肝阳上亢、气血上冲者慎用**：柴胡升提，上亢者用之，易致头晕、目眩加重。
- **孕妇慎用**：柴胡疏达之力强，恐动胎气，非有少阳证不可轻用。
- **倪师原话**：“柴胡是好药，但你要知道它走的是少阳，不是太阳，也不是阳明。你搞错了经，用错了地方，它就不灵了。”

## 🗣️ 倪师讲义实录与发挥

倪师在《伤寒论》讲义中，讲到少阳篇与小柴胡汤时，反复强调柴胡的地位，以下为原汁原味的金句与发挥：

**金句一：论柴胡与少阳**

> “少阳证是什么？就是**半表半里**。你说它是表，它又不在表；你说它是里，它又不在里。它在中间。柴胡就是走中间的。所以小柴胡汤是和解剂，不是汗剂，不是下剂。你吃了小柴胡汤，没有发汗，也没有拉肚子，但病好了，为什么？因为**和解**了。”

**金句二：论柴胡“推陈致新”**

> “《神农本草经》说柴胡**推陈致新**，这四个字很厉害。你看柴胡这味药，它不攻下，不发表，但它能把三焦的水道给你打通。三焦一通，旧的积水、郁气排掉，新的气血就生出来。这就像你家里的水管堵了，你不是把水管拆掉，你是把堵的地方通开，水就流了。柴胡就是通三焦的。”

**金句三：论小柴胡汤的实战**

> “小柴胡汤，你只要看到病人**往来寒热、胸胁苦满、默默不欲饮食、心烦喜呕**，四个里面有一个，你就可以用。用了以后，病人常常会**一身微汗而解**，或者**小便通利而解**，或者**大便通而解**，不一定从哪个路走，但病就是好了。这就是和解的力量。”

**金句四：论柴胡与肝病**

> “肝病的人，不管是肝炎、肝硬化，还是肝癌，你只要看到他有少阳证，有胸胁苦满、有往来寒热、有脉弦，你就要考虑用柴胡。柴胡疏肝，黄芩清肝，半夏降逆，人参固本，生姜大枣调和营卫。小柴胡汤不是治肝的，但肝病如果有少阳证，你就要用少阳的法子去治。这就是**辨证论治**。”

**金句五：论柴胡剂量**

> “柴胡用多少？我常常用**三钱**。你如果是一般的外感少阳证，三钱就够了。但如果你遇到的是**高热、寒热往来如疟**，那你要用**五钱、八钱**，甚至**一两**。剂量的大小，看病情。你不敢用，病就压不住；你乱用，病就散了。所以你要**心中了了**。”

**金句六：论柴胡加龙骨牡蛎汤**

> “柴胡加龙骨牡蛎汤，这是少阳证兼有**烦惊、谵语、一身尽重不可转侧**的方子。柴胡疏达少阳，龙骨牡蛎潜镇浮阳，茯苓半夏利水降逆，大黄清里热，桂枝通阳，人参大枣固本。这个方子很复杂，但你看它的核心，还是**柴胡**。柴胡把少阳的气机一疏开，其他药各就各位，病就好了。所以柴胡是**主帅**，其他是**副将**。”

**金句七：论柴胡与温病派**

> “温病派不敢用柴胡，说柴胡劫肝阴。我告诉你，那是他们不会用。柴胡是**和解**的，是**推陈致新**的，你只要辨证准确，该用就用，不要怕。你怕，病就不怕你。你真正懂了柴胡，你就知道它是**少阳第一要药**，无可替代。”

以上即为倪海厦人纪体系下对柴胡的完整重构转写。柴胡一药，味苦平，禀少阳生发之气，入半表半里，和解枢机，推陈致新，为少阳病之**不二主帅**。倪师心法，尽在其中。
