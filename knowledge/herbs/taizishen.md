# 太子参

## 🌿 神农本草原意与性味气味

《神农本草经》未列“太子参”之名。本品首载于清代吴仪洛《本草从新》，记其“味甘微苦，性平”，功在“大补元气，生津止渴”，又见于《饮片新参》，谓其“甘润微苦，补脾肺之气，生津液”。故太子参非上古经方药，乃后世从人参一脉中别出之“清补轻补”之品。

**气味拆解**：味甘，得土之正味；微苦，得火之余气；性平偏微凉，不燥不烈。整体气味俱薄，气薄则升浮，味薄则通降，合之而成“清补肺脾、升津而不助火”之性。按倪师法象之说：人参气厚味厚，如厚重黄土，能填元气之根；太子参气薄味薄，如春日细雨，润而不滞，补而不壅。故人参像“给炉膛添大柴”，太子参像“给干土洒一层露水”——补得轻，补得动，补得走得通。

**阴阳升降属性**：甘能升，苦能降，微凉能清。故太子参属“升中有降、补中带清”之品，偏入脾肺二经，走上焦与中焦，生津液而不过于滞腻，补中气而不至于火升。

## 🫀 倪师药性推演与破局心法

倪师论参，向来先分“厚重”与“轻灵”两层。人参、党参、太子参，一脉相通，力道不同：

- **人参**——大补元气，能回阳于将脱，力猛而厚，如大军压境；
- **党参**——补中焦脾胃之气，力较人参缓，专走中土；
- **太子参**——补气之力更轻，生津之力更柔，尤宜“虚不受补”之人。

倪师的灵魂理解，可用一句话破掉：**太子参不是“小号人参”，而是“另一种打法”。** 人参重在“填根、固脱、回阳”，打的是“深处阳气不续”的仗；太子参重在“润中、生津、清补”，打的是“气阴两伤、虚火上浮而不受温补”的仗。

用自然物理比喻：
- 人参如同**烧旺的炭火**，能驱寒回阳，但火大会灼津；
- 太子参如同**温润的春雨**，不灭火，也不加油，只把干裂的土地慢慢润开。

故倪师心法在于：凡遇患者气虚而兼口干、舌红少苔、虚烦、汗多、脉细数，用党参嫌温、用人参嫌烈，此时太子参上场——**补而不燥，清而不寒，轻舟过峡**。

## 🎯 临床用量法度与配伍抓手

**常规用量**：
- 轻补生津：10～15g
- 气阴两虚明显：15～30g
- 小儿、体弱、热病后调理：6～12g

太子参不走急危重症“回阳固脱”之路，故不必以重剂救逆；其重剂多用于**热病后期、津气大伤、虚不受补**的调养阶段。

**经典配伍抓手**：

| 配伍 | 法度 |
|---|---|
| 太子参 + 麦冬 + 五味子 | 仿生脉散之意，轻补气阴，治汗多、口干、心悸 |
| 太子参 + 山药 + 白扁豆 | 小儿脾虚食少，补脾而不滞 |
| 太子参 + 黄芪 | 气虚自汗、表虚不固，补气升提 |
| 太子参 + 石斛 + 玉竹 | 胃阴不足、口干舌燥、热病后津亏 |
| 太子参 + 陈皮 + 砂仁 | 补而不腻，防甘药壅中 |

**临证眼目**：
- 舌红少苔、脉细数无力、口干而不欲多饮——太子参对证；
- 若见舌淡胖、脉沉迟、畏寒肢冷——此为阳虚，非太子参所宜，当求干姜、附子、人参之路；
- 外感未清、湿热内蕴、痰浊壅盛者，不宜早补，补之则闭门留寇。

**使用禁忌**：实热证、外感初起、湿阻中焦、食积腹胀者，均当先清后补，不可一见“虚”字便投太子参。

## 🗣️ 倪师讲义实录与发挥

倪师论参类药时，常有一句极重的话：**“补药不是看它补不补，是看它补进去以后，能不能走得动。”**

这句话放到太子参身上最贴切。人参补得深、补得猛，但若患者中焦不通、津液已伤，猛补反成壅滞；太子参补得轻、补得润，像给干田洒水，水能渗下去，气能转起来。

倪师又有比喻：**“人参像打仗时派大将军，太子参像战后派文官去安抚百姓。”** 热病之后、大汗之后、久咳之后，人不是没有气，而是气阴两伤、虚火微浮——此时用大将军（人参）会太刚，用文官（太子参）刚刚好，把津液养回来，把虚热压下去，把脾胃慢慢托起来。

临床实战体会：小儿夏季热、热病后低热不退、放疗后口干乏力、久咳气短而舌红少苔者，倪师法度往往不取大剂参芪，而取太子参为君，佐麦冬、五味子、山药、石斛之类，**轻补轻清，缓缓收功**。这正是太子参在倪师药法中的位置——不是冲锋陷阵的猛将，而是收拾残局、重建中焦与津液的高明后手。
