# 葶苈子

## 🌿 神农本草原意与性味气味

- 《神农本草经》原文：“葶苈，味辛、苦，寒。主癥瘕、积聚、结气，饮食寒热，破坚逐邪，通利水道，除肺中痰饮，止咳逆上气。久服令人虚。一名大室，一名大适。生平泽及田野。”

- 气味与阴阳升降属性：葶苈子味辛、苦，辛能横行散结，苦能直行下降，气寒。气薄味厚，阳中之阴。法象天地之生——辛主开、苦主降、寒主清，故其性专于**泻肺中水饮与痰浊**，自里达表，自肺走膀胱，属于“破坚逐邪、通利水道”之品。其气薄走而不守，故仲景用大枣护脾胃，防其峻泻伤中。

## 🫀 倪师药性推演与破局心法

- 倪师如何理解这味药的灵魂：葶苈子 **“泻肺中之水，破肺中之积”** 。肺为华盖，主通调水道。今肺中水饮闭阻，气机不降，喘满不得卧，一身面目浮肿——此即“肺实”、“水饮凌心射肺”之危候。葶苈子苦寒直入肺中，把闭阻的水饮像抽水机一样抽出来，从三焦水道下行膀胱排出体外。它与麻黄不同，麻黄开表发汗走的是“从皮毛孔散水”，葶苈子是走“从肺内破水下行膀胱”。

- 大白话与自然物理比喻：想象一个厨房水槽，下面排水管堵了，水槽里全是脏水，水还倒灌到旁边灶台（肺水肿）。葶苈子就是一根高功率疏通棒，直接伸进排水管里，把堵住的痰水、饮邪打碎，然后猛力往下一顶——脏水从下水道（膀胱）哗地排走。水槽空了，灶台（肺）不淹了，喘满就平了。所以葶苈子**只治实证、闭证**，若肺气虚而喘、脾虚而肿者，一用即败。

## 🎯 临床用量法度与配伍抓手

- 倪师常用剂量法度：
  - 葶苈子入汤剂常用 **6–12 克**，重症如“肺水壅盛、喘不得卧、一身面目浮肿”——**15–20 克**，但必须配伍大枣或甘草护中。
  - 葶苈子入丸散（如大陷胸丸、己椒苈黄丸）——**3–6 克**，峻药缓攻。
  - 倪师强调：“葶苈子炒过再入药可缓其寒性，脾胃弱的人不至于一下受不了。”

- 经方经典药对配伍要诀：
  - **葶苈子 + 大枣**（葶苈大枣泻肺汤）——治肺痈、喘不得卧。大枣补脾护中，防止葶苈子峻泻伤正。
  - **葶苈子 + 大黄**（大陷胸丸加减）——治结胸证，水热互结胸中。
  - **葶苈子 + 防己 + 椒目 + 大黄**（己椒苈黄丸）——治肠间有水气，腹满口干舌燥。
  - **葶苈子 + 麻黄 + 石膏**——治肺胀喘咳、痰水壅肺兼有表证，表里双解。

- 临证眼目：**喘满、不得卧、面目浮肿、咳唾痰水、舌苔白滑或黄腻、脉沉实有力**。以此为核心辨证点。

- 使用禁忌：肺气虚喘、脾肾阳虚水肿、孕妇、久病体弱者——**绝对禁用**。若误用，泻下不止、元气暴脱。倪师常言：“实证用葶苈子，一剂知，二剂已；虚证用葶苈子，一剂倒，二剂了。”

## 🗣️ 倪师讲义实录与发挥

倪师讲葶苈子时拿肺积水做比喻：“病人喘得不能躺，坐着一口气上不来，面目都肿了，这就是肺里全是水。葶苈子下去把水一抽，喘就平了。你看西医抽肺水用针管，中医用葶苈子——抽水机一样。”

又说：“葶苈大枣泻肺汤，就两味药——葶苈子、大枣。你不要看它简单，肺积水、肺脓疡、喘不得卧，用对了比什么都快。但千万记得：是实证才用。我常常跟学生讲，葶苈子是大将，能打硬仗——但只打实仗，不打虚仗。虚人用葶苈子，就是赶一个病人去跑马拉松，当场倒地。”

倪师在讲《金匮·肺痿肺痈咳嗽上气病》篇时特别强调：“葶苈子配大枣，一攻一守，一泻一补。张仲景这个配伍，就是怕葶苈子太猛，把脾胃之气泻光了。大枣下去，脾胃守住，葶苈子只管前面打——这就是经方的王道和霸道，同时存在。”
