# 首乌藤

## 🌿 神农本草原意与性味气味

**《神农本草经》未收载首乌藤。** 首乌藤即何首乌之藤茎，又名夜交藤。何首乌一药，《神农本草经》亦未收录，首见于唐代《开宝本草》（一说《何首乌录》），列于草部。夜交藤入药更晚，至明清本草方见明确记载，《本草纲目》述何首乌时附载其藤，谓“茎叶治风疮疥癣作痒，煎汤洗浴甚效”，至《本草从新》始独立收载夜交藤，言其“补中气，行经络，通血脉，治劳伤”。

**性味归经：** 甘、微苦，平。入心、肝二经。

**气味阴阳升降：** 首乌藤气薄味薄，属阴中之阳。藤蔓之属，其性善走窜通达，法象天地间蔓草攀援之生——根藏于地而藤蔓上腾，昼开夜合，故有“夜交”之名。其气薄则升浮外达，善通经络、走表祛风；其味薄则不甚沉降，能入心肝以养之、通之，而非峻补厚腻之品。与何首乌根块之厚味滋腻迥然不同——根主沉降入下焦补肝肾，藤主升通走经络安心神。同一植株，根与藤气味厚薄相反，此即天地造化之妙：根者，收藏之象；藤者，升散之象。

## 🫀 倪师药性推演与破局心法

**倪师核心心法：藤蔓走窜通络，昼开夜合入心——此药是“引阳入阴”的钥匙。**

倪师讲药，最重“取象比类”与“物理之性”。首乌藤这味药，灵魂在于一个“交”字。

**一、藤蔓之性——走经络如蔓草攀墙。**

你看那何首乌的藤，它不是直挺挺往上长的，是缠绕攀爬，遇到墙就贴墙走，遇到树就绕树转，遇到缝隙就钻进去。这种生长形态，决定了它的药性是**走而不守，通而不峻**。它不像桂枝那样走而不守还带着一股辛温发散之力，也不像大黄那样推墙倒壁。首乌藤的通络，像一根柔软的藤条顺着经络的缝隙慢慢地钻、慢慢地通，把堵在小络脉里的风、湿、痰、瘀一点一点地拨开。所以它治血虚身痛、风湿痹痛、皮肤痒疹，靠的就是这股“藤蔓钻缝”的劲。

**二、昼开夜合——天然的“交阴阳”之象。**

夜交藤为什么叫夜交藤？因为它的叶片白天张开、夜间合拢，跟人的寤寐节律一模一样。白天阳气出表，人醒；夜间阳气入阴，人睡。失眠是什么？就是阳气到了晚上不肯回家，还在外面晃荡。夜交藤这味药，禀赋了天地间“昼开夜合”的节律，它入心肝，能把浮散在外的阳气轻轻引回阴分。它不是安眠药那种强行镇压，而是像一位老朋友，到了傍晚就拍拍你的肩膀说：天黑了，该回家了。

**三、与何首乌根的区别——同一株，两重天。**

倪师反复强调：**何首乌根是补的，夜交藤是通的。** 何首乌根块色黑入肾，味厚质重，补肝肾、益精血，但败在滋腻碍胃，久服容易拉肚子、伤肝。藤呢？藤是升发向上的，气味俱薄，不但不腻，还能通络。所以临床上倪师用何首乌根来补虚，碰到虚而兼有经络不通、心神不宁的，就用夜交藤来替代或配合——**补而不滞，通而不伤。**

**自然物理比喻：** 好比一条河流淤塞了，何首乌根是往河里倒营养液，夜交藤是拿一根竹竿把淤泥拨开。两个作用完全不同方向。你如果只倒营养液，河道越堵越死；你如果只拨淤泥，河水还是没养分。所以倪师有时根与藤同用，一补一通，各司其职。

## 🎯 临床用量法度与配伍抓手

**一、倪师常用剂量法度：**

- **常规养血安神通络：** 15–30克。这是最常用的 range，用于失眠多梦、血虚身痛、皮肤瘙痒。
- **重症失眠（顽固性不寐）：** 可加至30–60克。夜交藤这味药非常平和，重用无碍，不像朱砂、磁石那样重镇伤胃。
- **外用煎汤洗浴（风疮疥癣瘙痒）：** 60–120克，煎水外洗，趁热熏洗患处。
- **注意：** 此药不宜久煎过浓，气味俱薄之品，久煎则走窜之力散失。一般煎煮20–30分钟即可。

**二、经方经典药对配伍要诀：**

| 配伍 | 要诀 |
|------|------|
| **夜交藤 + 酸枣仁** | 养血安神之铁三角。酸枣仁养心肝之血、敛浮阳，夜交藤引阳入阴、通心络。一敛一通，一守一走，治虚烦不眠如鼓应桴。 |
| **夜交藤 + 合欢皮** | 解郁安神。合欢皮解肝郁，夜交藤通心络。治情志不遂、肝郁化火、心烦不寐，此为倪师常用的“解郁安神”对药。 |
| **夜交藤 + 鸡血藤** | 通络养血。两藤同用，一通心络安心神，一通血络养筋脉。治血虚风湿痹痛、产后身痛、中风后遗肢体麻木。 |
| **夜交藤 + 当归 + 白芍** | 养血柔肝、通络止痛。治血虚肝郁之失眠、胁痛、月经不调。 |
| **夜交藤 + 丹参** | 活血安神。丹参入心活血、夜交藤入心通络。治心血瘀阻之失眠、心悸、胸痹。 |
| **夜交藤 + 蝉蜕 + 白蒺藜** | 祛风止痒。治血虚生风之皮肤瘙痒、慢性荨麻疹。 |

**三、临证眼目与辨证使用禁忌：**

- **眼目一：** 失眠而舌淡脉细者，血虚也，夜交藤为首选；若舌红苔黄脉数，心火亢盛者，须配黄连、栀子清火，单用夜交藤力不及。
- **眼目二：** 凡藤蔓之药皆能通络，但夜交藤的通络偏于“养血通络”，不同于威灵仙、络石藤的“祛风通络”。辨在血虚还是风寒湿偏盛。
- **禁忌：** ①脾胃虚寒、大便溏泄者慎用，虽不甚滋腻但藤类毕竟偏于走窜，脾虚不运者不宜单用大剂。②实火扰心之失眠，首乌藤非所宜，须先清热。③《本草从新》谓“多服令人吐”，虽临床少见，但超大剂量（100克以上）内服仍需谨慎。④孕妇慎用，藤类走窜之性恐动胎气。

## 🗣️ 倪师讲义实录与发挥

倪师在讲何首乌这味药时，顺带提到了夜交藤。以倪师原汁原味的风格，大概是这么说的——

> “何首乌的藤，叫做夜交藤。你看它的叶子，白天打开，晚上合起来，跟人睡觉一模一样。所以它专门治失眠。这个藤呢，你看它是缠绕着长的，所以它能通经络——它走窜的力量非常柔和，不像别的药那么猛。你如果碰到一个病人，晚上睡不着，身上又痛，皮肤又痒，这不就是血虚加上经络不通嘛——夜交藤一味药，安神、通络、止痒，三个都管了。”

倪师还常说一个比喻：

> “夜交藤引阳入阴，就像你家里有个小孩，白天在外面玩疯了，到了晚上还不肯回家。你不是拿棍子把他打回来——那是朱砂、龙骨、牡蛎干的事，重镇嘛——你是拿一块糖，在门口喊他：回来吧，有好吃的。夜交藤就是那块糖，它把阳气轻轻引回阴分，病人自然就睡着了。”

在临床实战中，倪师用夜交藤有几个独到心得：

1. **治失眠必问大便。** 若大便不通，夜交藤要配火麻仁或决明子，因为“胃不和则卧不安”，肠腑不通，阳气回不了家。
2. **治皮肤痒必问睡眠。** 很多慢性荨麻疹、湿疹的病人，晚上痒得更厉害，为什么？因为晚上阳气入阴，与阴分之邪气相争，发于皮肤。夜交藤既能安神又能祛风通络，一箭双雕。
3. **中风后遗症肢体麻木。** 倪师常在补阳还五汤的基础上加夜交藤30克，取它“藤蔓通络”之性，帮助恢复肢体功能。他说：“藤能通络，这是大自然给人的提示——你看那藤爬墙，再窄的缝它都能钻进去，我们身体的小络脉，就需要这种药来钻。”

倪师最后总结一句，掷地有声：

> **“何首乌补的是根，夜交藤通的是路。根深才能叶茂，路通才能往来。补而不通，越补越堵；通而不补，越通越虚。这两味药，一阴一阳，一守一走，合在一起，才是完整的何首乌。”**
