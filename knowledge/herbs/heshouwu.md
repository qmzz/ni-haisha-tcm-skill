# 何首乌

## 🌿 神农本草原意与性味气味

《神农本草经》三百六十五味，并未收载何首乌。此药首见于唐代《开宝本草》，明代李时珍《本草纲目》将其收入草部蔓草类，后世本草地位渐重。

《开宝本草》原文：**"何首乌，味苦、涩，微温，无毒。主瘰疬，消痈肿，疗头面风疮，五痔，止心痛，益血气，黑髭鬓，悦颜色，久服长筋骨，益精髓，延年不老。亦治妇人产后及带下诸疾。"**

《本草纲目》补述：**"何首乌，足厥阴、少阴药也。白者入气分，赤者入血分。肾主闭藏，肝主疏泄，此物气温味苦涩，苦补肾，温补肝，能收敛精气，所以能养血益肝，固精益肾，健筋骨，乌髭发，为滋补良药。不寒不燥，功在地黄、天门冬诸药之上。"**

**气味与阴阳升降：**

- 味苦、涩，气微温。苦能泄能燥能坚，涩能收能敛，温能通能补。
- **味厚者为阴，味薄者为阴中之阳。** 何首乌苦味极厚，涩味亦厚，故为**阴中之阴**，沉降之性极强，直入下焦肝肾。
- 气微温而不燥，温能助肝木升发，但被厚厚的苦涩味压住，升中有降，走而不守，最终**沉降为主，收敛为用**。
- **生首乌 vs 制首乌，是这味药的分水岭：**
  - **生首乌**：苦、涩，性平（微温），偏寒，气厚味厚，主**泄**——解毒、消痈、润肠通便，走而不守。
  - **制首乌**：经黑豆汁九蒸九晒，苦味转甘，涩味稍减，气转温润，主**补**——补肝肾、益精血、乌须发、强筋骨，守而不走。

法象天地之生：何首乌根块色黑褐，黑色入肾，质重下沉，生于土中多年，得土气最厚，故能填精补髓。其藤（夜交藤）昼开夜合，交通阴阳，故其根亦能交通心肾、安神定志。何首乌得天地**收藏之气**最全，秋末冬初采挖，正是万物归根之际，故其药性善于**归根复命**。

## 🫀 倪师药性推演与破局心法

倪师在《人纪·神农本草经》讲义中，反复强调一个核心原则：**药性即天地之性，用药即借天地之力以调人身之偏。** 何首乌虽非经方主药，但倪师对其推演极为透彻，关键在一个字：**黑**。

倪师说，中医讲"发为血之余，肾之华在发"。头发为什么会白？不是头发本身出了问题，是**下焦肾精亏了，肝血虚了**。肾精是灯油，肝血是灯芯，油枯芯短，火就烧不旺，头发就白、就枯、就掉。何首乌色黑入肾，味厚填精，质重下沉，就是把灯油重新灌满。

**用大白话打个比方：**

人的下焦肝肾，就像一个老灶台底下的"底火"。年轻人底火旺，锅里的水烧得滚开，蒸汽往上升，滋润全身，所以头发乌黑油亮、面色红润、筋骨强健。人老了，底火慢慢熄了，锅里的水烧不开，蒸汽上不去，顶上（头发、头面）就干了、白了、枯了。

何首乌这东西，就是**往灶膛里添上好的硬柴**。它不像附子那样直接给你点一把猛火（那是破阴实、回阳救逆用的），也不像桂枝那样把火往体表引。它是**沉下去、填进去、慢慢烧**。所以倪师特别强调：**何首乌是"补"药，不是"攻"药；是"守"药，不是"走"药。**

**生首乌和制首乌，倪师分得极清：**

- **生首乌**，倪师说是"**润肠通便、解毒消痈**"的。它那个苦味涩味还在，没有被蒸制转化，所以它带着一股"推"的力量往下走，能把肠子里的燥屎、身上的疮毒、脖子上的瘰疬（淋巴结核）往下排。倪师常讲，生首乌用于**老人血虚肠燥便秘**，非常好，比大黄温和，不伤正气。

- **制首乌**，九蒸九晒之后，苦味变甘，涩味变润，那个"推"的力量没了，变成了"**填**"的力量。倪师说，制首乌是**补肝肾、益精血**的，常用于须发早白、腰膝酸软、头晕耳鸣、遗精崩漏。它的灵魂就是**把下焦的油填满，让底火重新烧起来**。

倪师还有一个关键提醒：**何首乌不是直接染黑头发的。** 很多人以为吃何首乌头发就变黑，错了。它是通过补肝肾之精血，让身体自己把营养送到发根，头发才慢慢转黑。如果下焦已经寒湿一片、脾胃运化不动，你吃再多制首乌也补不进去，反而滋腻碍胃，越吃越胀。这就是倪师常说的：**"补药要能补得进去才算补药，补不进去就是毒药。"**

## 🎯 临床用量法度与配伍抓手

**一、倪师常用剂量法度**

| 类型 | 常规克数 | 重症/重剂 | 说明 |
|------|----------|-----------|------|
| **制首乌** | 9～15g | 30g（配熟地、枸杞、当归） | 补肝肾、益精血、乌须发，需久服缓图 |
| **生首乌** | 6～12g | 15g（中病即止） | 解毒消痈、润肠通便，不可久服 |
| **鲜首乌外用** | 适量捣敷 | — | 疮痈肿毒、瘰疬 |

倪师强调：**制首乌补虚，宜小量久服，像文火炖汤；生首乌攻毒，宜中病即止，像快刀切菜。** 急危重症极少用何首乌单味重剂，它从来不是救急药，而是**缓图根本**的药。

**二、经方经典药对配伍要诀**

1. **制首乌 + 熟地 + 当归 + 枸杞 + 菟丝子 + 补骨脂 + 茯苓**（七宝美髯丹思路）
   - 倪师解：这是补肝肾、乌须发的祖方。熟地填精，当归养血，枸杞菟丝补肝，补骨脂温肾，茯苓渗湿防腻。何首乌居中，**把各路补药引到下焦，并把精血收敛住不外泄**。

2. **制首乌 + 白芍 + 桑椹 + 女贞子**
   - 养肝血、柔肝体。用于肝血虚之头晕、目涩、肢体麻木。

3. **生首乌 + 连翘 + 夏枯草 + 玄参 + 牡蛎**
   - 解毒散结。用于瘰疬痰核（淋巴结核、甲状腺结节）。倪师说，生首乌在这里是**把毒往下引，从大肠排出去**。

4. **生首乌 + 火麻仁 + 肉苁蓉 + 当归**
   - 润肠通便。用于老人、产后血虚肠燥便秘。倪师说，这是**"增水行舟"**，不是拿大黄去硬推。

5. **制首乌 + 枸杞 + 菊花 + 决明子**
   - 补肝肾、明目。用于肝肾不足之视物昏花。

6. **制首乌 + 酸枣仁 + 夜交藤（何首乌藤）+ 远志**
   - 交通心肾、安神。夜交藤昼开夜合，引阳入阴，何首乌根填精，共同安神定志。

**三、临证眼目与辨证使用禁忌**

**倪师辨证眼目：**

- **看头发**：须发早白、干枯、脱落，伴腰膝酸软、头晕耳鸣、脉沉细尺弱者，制首乌对证。
- **看大便**：老人血虚肠燥，大便干如羊屎，数日一行，腹不痛，生首乌对证。
- **看疮毒**：瘰疬、疮痈、皮肤瘙痒，生首乌可解毒。
- **看舌脉**：舌淡红少苔，脉细弱，属精血不足者宜；舌苔厚腻、脉滑实者忌。

**禁忌：**

- **生首乌有肝毒性，不可久服大剂。** 倪师特别提醒，生首乌用于通便解毒，**中病即止，不可当保健品天天吃**。现代研究证实生首乌可致肝损伤，倪师虽不引用西医，但其"中病即止"的原则与此完全一致。
- **湿痰壅盛、大便溏泄、脾胃虚弱者慎用。** 制首乌滋腻，脾虚湿重者服之则胀满、纳呆、泄泻。
- **外感发热、实热证忌用。** 补药恋邪，邪未清时不可用。
- **忌铁器。** 传统认为何首乌与铁器接触会变黑、失效，煎煮宜用砂锅、陶瓷锅。
- **肝病患者慎用。** 尤其生首乌。

## 🗣️ 倪师讲义实录与发挥

倪师在讲何首乌时，有一段非常生动的发挥，大意如下：

**"何首乌这个药，你看它名字——何首乌，姓何的，头发白了又变黑。这是唐朝一个叫何田儿的人，吃了这个药，白发变黑，所以叫何首乌。但你不要以为它是染发剂，它是补肝肾的。** 中医讲，肾藏精，其华在发；肝藏血，发为血之余。你肾精足、肝血旺，头发自然黑。你肾精空了、肝血枯了，头发就白。何首乌色黑入肾，味厚填精，就是把那个空掉的肾精重新填满。"
