# 荜茇

## 🌿 神农本草原意与性味气味

**《神农本草经》未收载荜茇。** 荜茇首见于唐代《新修本草》，其后《海药本草》《开宝本草》均有收录。倪海厦人纪讲义中凡遇神农未载之药，必先溯源至最早经典本草以定其性味根基，此为“以经证药”之铁律。

**《新修本草》原文：** “味辛，大温，无毒。主温中下气，补腰脚，杀腥气，消食，除胃冷，阴疝，痃癖。”

**《海药本草》补充：** “主心腹冷气，冷痢，宿食不消。”

**气味与阴阳升降属性：** 荜茇味辛，气大温，纯阳之品。辛能散能行，温能通能化。气厚味薄，属阳中之阳。法象天地：荜茇生于热带湿热之地，果实成穗而气烈，得盛夏火土之气最厚，故其性纯阳，直入中焦，能破阴寒凝结如阳光融冰。其气升中有降——辛以升散郁结，温以下气归元，故《新修本草》言“温中下气”四字最得要领：温其中焦之寒，降其逆上之气。

## 🫀 倪师药性推演与破局心法

**倪师核心心法：荜茇是“中焦的纯阳火种”，专破胃家阴寒。**

倪师常以物喻药：生姜如炭火初燃，散胃中水气；干姜如炉膛暗火，温肺中寒饮；而荜茇则如烈酒入腹，一团火热直坠中焦，所过之处阴寒冰消。其辛烈之气不走表、不达上，专攻胃与大肠之间的寒凝地带。

**与相似药的灵魂对比：**
- **干姜**温肺饮，走手太阴，守而不走；
- **吴茱萸**温肝胃，散厥阴之寒，降逆止呕；
- **荜茇**温胃肠，专走阳明，散寒下气，消食止痛。

倪师比喻：胃是一个锅，底下有火才能腐熟水谷。胃寒之人，锅底下火灭了，食物煮不熟，停在胃里发胀、打嗝、泛清水。干姜是往锅底添柴，荜茇是往锅里倒烈酒直接点火——辛烈之气瞬间把冷锅烧热。所以荜茇治的是“锅冷食不化”的胃寒实证，而非“火源不足”的脾肾阳虚。

**荜茇的灵魂在于“通”而非“补”：** 它不补火，它引火、散寒、通气。寒凝则气滞，气滞则胀痛。荜茇辛温走窜，把凝住的寒气和滞住的气一并打通，故能“下气”“消食”。倪师强调：荜茇治的是寒实证，若纯虚无寒者用之，反耗气伤阴。

## 🎯 临床用量法度与配伍抓手

**倪师常用剂量：**
- 常规煎剂：1.5～3钱（约5～10克）
- 入丸散：0.5～1钱（约1.5～3克）
- 急危重症（如阴寒内盛、胃冷呕逆不止）：可至5钱（约15克），但须中病即止，不可久服
- 外用（牙痛含漱、寒性头痛熏鼻）：适量，研末或煎汤

**经方经典药对配伍要诀：**

| 配伍 | 功效 | 辨证抓手 |
|------|------|----------|
| 荜茇 + 干姜 | 温中散寒，双火源 | 胃寒呕吐、腹冷痛 |
| 荜茇 + 吴茱萸 | 温肝胃，降逆气 | 厥阴头痛、泛酸呕涎 |
| 荜茇 + 高良姜 | 温胃止痛 | 胃脘冷痛、喜温喜按 |
| 荜茇 + 肉桂 | 温下焦，散沉寒 | 寒疝、腰腹冷痛 |
| 荜茇 + 胡椒 | 温中下气，消食 | 宿食不消、寒泻 |
| 荜茇 + 厚朴 | 行气除满 | 寒凝气滞、腹胀 |
| 荜茇 + 附子 | 破阴回阳 | 阴寒重症、脉微肢冷 |

**临证眼目：** 凡见舌淡苔白滑、脉沉迟、口不渴或喜热饮、呕吐清水、腹冷喜按、遇寒加重者，皆是荜茇证。倪师尤其重视“口泛清水”一症——这是胃寒的直接信号，荜茇投之如矢中的。

**辨证使用禁忌：**
- 阴虚火旺者忌：舌红少苔、口干咽燥、五心烦热
- 实热证忌：高热、便秘、口渴饮冷、舌红苔黄
- 孕妇慎用：辛热走窜，恐动胎气
- 不可久服：辛热耗气伤阴，中病即止

## 🗣️ 倪师讲义实录与发挥

倪师在讲解荜茇时，常以生活场景破题：

> “荜茇这个药，厨房里就有——你吃印度菜、泰国菜，那个辛辣味，很多就是荜茇。它跟胡椒是亲戚，但胡椒偏走上焦，荜茇偏走中焦。你胃里冷，吃东西不消化，打嗝出来是生食味，这就是胃寒。荜茇一下去，辛烈之气把胃里那团冷气打散，食物才开始真正被腐熟。”

> “干姜是温肺的，吴茱萸是温肝的，荜茇是温胃的。你不要搞混。胃寒的人，舌头淡淡的，口水多，吃东西没味道，甚至闻到食物就恶心——荜茇配干姜，一剂下去，胃就暖了。”

> “荜茇还有一个妙用——牙痛。寒性的牙痛，遇冷加重，用荜茇煎汤含漱，辛温之气直透牙根，寒散痛止。这不是消炎，这是散寒。你们不要一看到牙痛就想到清胃散，那是胃火牙痛。寒性牙痛用清胃散，越清越痛。”

倪师特别强调荜茇与胡椒的区别：胡椒走表、走肺、发汗；荜茇走里、走胃、下气。同为辛热，一表一里，方向不同。用错了，胡椒发汗伤津，荜茇温胃下气——这是倪师药性推演的精细之处。
