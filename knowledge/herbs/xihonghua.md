# 西红花

## 🌿 神农本草原意与性味气味

《神农本草经》未收载西红花。此药原生西域，《本草纲目》草部第十五卷载其正名“番红花”，又名“洎夫蓝”“撒法郎”，李时珍明言“出西番回回地面及天方国”，即今波斯、地中海一带，元时随西域商路入中土，故神农、仲景方中绝无此物。

李时珍《本草纲目》原文：“番红花，气味甘，平，无毒。主治心忧郁积，气闷不散，活血。又治惊悸。久服令人心喜。”

《本草品汇精要》补其功：“主散郁调血，宽胸膈，开胃进饮食，久服滋下元，悦颜色，及治伤寒发狂。”

《饮膳正要》记：“主心忧郁积，气闷不散，久食令人心喜。”

**气味与阴阳升降属性：**

- 味甘，气平微寒（一作甘平，一作微寒），无毒。
- 质轻如丝，色赤入心，气清不浊。
- 花类药物禀天地升发之气，主升浮，走而不守；但西红花微寒，升中带清，与草红花辛温纯升迥异。
- 味甘属阴中之阳，气薄属阳中之阴，故能入心肝血分，行血而兼清瘀热，不似肉桂、附子之峻温，亦不似大黄、芒硝之沉降。

法象天地：此花生于秋末，得金气之收，花开于霜降前后，红丝三歧如心脉之分支，一枝三蕊，取象心之三瓣——故入心，走血络之细处，善通心脉中微细瘀滞，而非攻逐大块死血。

## 🫀 倪师药性推演与破局心法

倪师论红花类药，核心一句：**“红花是走血分的药，不是补血的药。”**

草红花（红蓝花）辛温，性烈走窜，像热水冲沟渠，把瘀血硬冲开；西红花则不然，它质轻、气清、味甘、性微寒，是“以柔克刚”的路子。倪师常以自然物理比喻：草红花如夏洪冲刷，西红花如春水浸润——水不急，但能渗到最细的缝隙里去，把心脉、脑络、胞宫那些细如发丝的瘀结点一点一点化开。

倪师对它的灵魂定性：**草红花破血，西红花通脉兼解郁。**

关键在“心忧郁积，气闷不散”这八个字。倪师在人纪讲“心主神明、心主血脉”时反复强调：心是君主之官，情志一郁，心气先结，气结则血滞，血滞则瘀生。西红花同时入心之气血两分——气分能散郁开结，血分能活血通络。这就是它与桃仁、赤芍、三棱、莪术的根本分野：那些药只管破血，不管解郁；西红花是**血中气药**，一边活血，一边把郁结的闷气松开。

倪师的破局心法三层：

1. **解心郁**——心中如有物堵，闷闷不乐、惊悸怔忡、夜不能寐，非痰非火，乃心血郁滞。西红花轻清入心，散其郁结，如开窗透风。
2. **通心脉**——胸痹心痛、唇青舌紫、脉涩而结，心脉中的细瘀，非它不能达。倪师常言“心脉最细，大药打不进去，要轻药才能钻进去”。
3. **凉血化瘀**——瘀久化热，或温病热入血分而见发狂、斑疹紫暗，西红花微寒，活血而不助热，是温病凉血化瘀的轻骑兵。

一句话：**草红花是攻城的将军，西红花是刺穴的金针。**

## 🎯 临床用量法度与配伍抓手

**倪师常用剂量法度：**

- 常规入煎剂：**1～3克**。质轻力专，少用即效，多用反耗血。
- 急危重症（胸痹心痛、热入血分发狂、中风脑络瘀阻）：可至**3～5克**，但须配伍扶正药同用，不可单味久攻。
- 焗服或研末冲服：**0.5～1.5克**。此法取其气全，不损其轻清之性，最合心脉细瘀。
- 倪师特别告诫：西红花贵重，但其力在“透”不在“量”。用大剂量反而壅滞，失其轻灵。草红花可10～15克大剂破血，西红花绝不可照搬此量。

**经方经典药对配伍要诀：**

| 配伍 | 功效 | 临证靶点 |
|------|------|----------|
| 西红花 + 桃仁 | 破血逐瘀，通闭经 | 妇人经闭、盆腔瘀块、腹中刺痛 |
| 西红花 + 当归、川芎 | 养血活血并行 | 血虚兼瘀，面色晦暗，经少色黑 |
| 西红花 + 柴胡、香附 | 疏肝解郁活血 | 情志抑郁、胁痛、胸中气闷不散 |
| 西红花 + 丹参、三七 | 清心通脉止痛 | 胸痹心痛、心悸、冠心病 |
| 西红花 + 丹皮、赤芍 | 凉血化瘀 | 瘀热互结、温病发斑、血热妄行 |
| 西红花 + 益母草、泽兰 | 调经利水 | 经行浮肿、产后瘀滞 |
| 西红花 + 石菖蒲、远志 | 开窍通络解郁 | 郁证健忘、脑络瘀阻 |

倪师尤其推崇**西红花配丹参**：丹参一味功同四物，善入心包络；西红花轻透心脉细络。二药相合，一推一透，是治疗心脉瘀阻的最佳轻剂组合，不伤正气，可久服。

**临证眼目与辨证使用禁忌：**

临证眼目：
- 舌：暗红有瘀点、舌下静脉紫暗怒张——正合此药；舌淡紫胖嫩者，须配温阳药。
- 脉：涩、弦、结代，是心脉瘀滞之征。
- 证：凡“闷、痛、悸、郁、紫”五字中见二三，即可考虑。
- 部位：心、脑、胞宫、肝络为四大靶区。

禁忌：
- **孕妇禁用**——活血通络，有坠胎之虞。
- 月经过多、崩漏、有出血倾向者慎用或禁用。
- 无瘀者不用——血虚无瘀而妄投，反耗新血。
- 不宜大剂量、长疗程单味久服——耗气伤血。
- 脑出血急性期禁用。
