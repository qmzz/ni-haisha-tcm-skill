# 萆薢

## 🌿 神农本草原意与性味气味

《神农本草经》中品原文：

> 萆薢，味苦平。主腰背痛，强骨节，风寒湿周痹，恶疮不瘳，热气。生山谷。

吴普曰：萆薢，一名百枝。名医曰：一名赤节，生真定山谷，二月八月采根，暴干。

此药《本经》列于中品，是"主养性以应人"的一路，无毒，可久服，但不是上品那种养命之药，它是祛邪化浊、通利关节的实干家。味苦，气平，气薄味厚，阴中之阳。苦能泄、能燥、能坚，平则不偏寒不偏热，走而不守，专入下焦与关节。生于山谷阴湿之地，禀土气而长，得土之厚重，故能入脾肾以化水湿；根茎横走蔓延，像藤蔓穿行于地脉，故能通经络、利关节、渗湿浊。这就是法象：**生在湿处而能治湿，横穿土层而能通痹，根白而味苦，故上通骨节，下清膀胱。**

## 🫀 倪师药性推演与破局心法

倪师讲萆薢，把它看作是"分清浊、利湿浊"的专将。这味药的灵魂是什么呢？就是**"把身体里那些黏糊糊、滑腻腻、排不干净的浊湿，从小便带出去"**。

打个比方：身体就像一栋房子，湿气重了，地板上全是黏浆，墙角发霉，下水道又堵了半截。萆薢干的事，就是把下水道疏通，把地板上那层黏腻的湿浆冲走。它不像麻黄那样从毛孔往外发，也不像附子那样温阳化气,它是直接走水道——**让浊水从小便排掉，让清阳重新上升。**

倪师反复强调过经方里"辨证论治"的核心：湿邪有两条路，一条从表走（发汗），一条从里走（利尿）。萆薢走的就是里路。它跟茯苓、泽泻、猪苓一样是利尿渗湿，但**茯苓泽泻利的是"清水"（水湿泛滥、水肿、小便不利），萆薢利的是"浊水"（白浊、膏淋、浊带、痛风结晶、关节里的痰湿浊瘀）。**

这就解释了为什么《本经》原文说它主"腰背痛、强骨节、风寒湿周痹"——风寒湿三气杂至合而为痹，痹久必生浊，浊不走则痹不除。萆薢一边利湿浊，一边通关节，所以它是治痹证里"化浊"的那一环。同时它主"恶疮不瘳、热气"，就是湿浊郁而化热、长年不愈的疮疡。为什么恶疮不愈？湿浊不去，新肉不生。萆薢把湿浊从小便引走，疮才有机会收口。倪师说**萆薢治梅毒疮，道理就在这里——不是去杀菌，是去浊、利湿、分利清浊，把病理产物排干净。**

## 🎯 临床用量法度与配伍抓手

**常规剂量**：倪师临床常用 **二钱到三钱（6–9克）**，视体质与湿浊轻重调整，起手常从三钱开始。重症如痛风急性发作、膏淋白浊、关节肿痛严重者，可用到 **五钱（15克）**。

**急危重症重剂法**：湿热痹阻、关节红肿热痛、小便浑浊如米泔，或梅毒性湿疮久溃不敛者，可加至 **五六钱（15–18克）**，但需配伍扶正药，不可单味猛攻，以免伤阴耗气。

**经典药对配伍要诀**：

- **萆薢 + 土茯苓**：这是治湿浊、解毒疮的黄金搭子，一以利湿分清，一以解毒除秽，梅毒、淋浊、湿热疮疡皆可。二药同用，一清一利，浊毒从下焦而出。
- **萆薢 + 茯苓 + 泽泻**：三路合围利湿，茯苓利中焦清水，泽泻利下焦水热，萆薢利下焦浊湿，层层加压，水湿无路可逃。
- **萆薢 + 杜仲 + 牛膝**：治腰背痛、强骨节。杜仲补肝肾强腰，牛膝下行通络，萆薢化浊除痹，一补一通一化，三管齐下。
- **萆薢 + 威灵仙 + 秦艽**：治风湿周痹、关节屈伸不利，化浊通络，风、寒、湿三气分头对付。
- **萆薢 + 黄柏 + 苍术**：治湿热下注、足膝肿痛，即"四妙散"的底子，萆薢在此加重化浊之力。

**临证眼目**：凡是**小便白浊如膏、尿后余沥不清、妇女白带黏稠腥秽、痛风结石、关节肿胀沉重、湿热疮疡久不收口**者，就是萆薢的靶子。舌头一看——舌苔黄腻或白厚腻，脉滑或濡。

**辨证使用禁忌**：肾阴虚、精关不固而致的遗精滑精，**不是湿浊引起的白浊，绝不可用**——因为萆薢是分利之品，利之愈伤阴。无湿者忌用，阴虚火旺者忌用。单味久服大剂可耗气伤阴。

## 🗣️ 倪师讲义实录与发挥

倪师在讲萆薢的时候，反复叮咛的就是那句大实话——"**湿不去，病不除；浊不化，痛不止。**"

他打了个比方：萆薢这味药，就像水沟里的那块过滤网，把脏东西挡住、分出来，让清水往前走，浊水往下去。你身上那个关节为什么肿？为什么痛？为什么尿酸高？为什么小便浑浊？因为浊物堵在那里不走。萆薢就是来"清浊分利"的——**清阳上升，浊阴下降，各归其位。**

讲到临证实战，倪师特别提到：很多人治痛风、治关节痛只知道消炎止痛，不知道化湿浊，治完又发，发了又治，永远断不了根。为什么？**因为浊湿的根没有拔。**萆薢就是拔根的那味药。你看它一利小便，小便一通畅，尿酸浊物跟着走，关节里的浊水一空，痛自然减。这不是止痛，这是给身体开一条排浊的路。

倪师最传神的一句话是："**萆薢这味药，你不一定天天用它，但你碰到浊病的时候，没有它，你就像进屋没有钥匙——进得去门，出不来。**" 意思是：湿浊盘踞在体内，你用别的药发汗不行、温阳也不行，唯有分利清浊一法，萆薢是这法的先锋。

他还说过：**"关节里的湿浊就像厨房地上的油，你光用拖把擦是擦不掉的，你得用热水加去油剂冲走。萆薢就是那个去油剂。"** 所以治痹证时，别只想着祛风散寒，先看看有没有浊湿，有浊先化浊，浊去痹自轻。
