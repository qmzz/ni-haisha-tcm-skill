# 桃仁

## 🌿 神农本草原意与性味气味

《神农本草经》原文：「桃核仁，味苦平。主瘀血，血闭瘕邪气，杀小虫。」

桃仁在《本经》位列木部中品，其核心功用就是四个字——**破血逐瘀**。原文讲「瘀血、血闭、瘕邪气」，统统指向一个「积」字。血闭就是月经不通、闭经；瘕就是腹中结块、癥瘕积聚；邪气就是瘀血留滞化成的那股不正之气。最后一句「杀小虫」，是因为瘀血久积、湿热内蕴则生虫，桃仁把瘀血打开，虫失去生存环境，自然消亡，不是桃仁真的像槟榔、使君子一样去驱虫。

**气味阴阳属性：**

桃仁味苦，气平，微甘。苦能泄能降，甘能润能缓。气薄味厚，属**阴中之阳**。它的药力走向是**沉降下行**——往下走，往血分走。

法象天地：桃树是春天最先开花的树，禀春木生发之气最旺，但桃仁本身在果实核里，核是收藏的、是包裹的，所以它把春天的生发之气**收在核中**，一旦入体，就是专门去冲击那些「被闭住的、被瘀阻的」地方。桃仁是「仁」，仁有油质，能润，所以桃仁走血分的同时兼走大肠，破血往下推，从大便走。

这是桃仁的「法象」：花性升散，仁性降破。桃仁用仁不用花，就是取它**破积下行**的那股力量。

## 🫀 倪师药性推演与破局心法

倪师在讲桃核承气汤的时候，对桃仁的理解讲得非常直白——**桃仁就是专门去破血里面干掉的、黏住的那一块。**

倪师心法：桃仁的灵魂在于一个「破」字，但它的破和红花、三棱、莪术的破不一样。红花是走窜调动，三棱莪术是消磨痞块，**桃仁是「破血 + 润下」双管齐下**。它把瘀血打散之后，还负责把打散的死血从肠道推出去。

**用大白话和自然物理来比喻：**

你把身体的血脉想象成一条河流。瘀血就是河道里淤积的泥沙和烂泥，堵在那不动了。大黄是推土机，专门往下推，推陈致新；桂枝是鼓风机，把河道上游的风先吹起来；丹皮是凉水塔，因为瘀血久了一定生热，丹皮去清那个热。**那桃仁是什么？桃仁是那个拿高压水枪去冲泥沙的人。** 它先把结块的泥沙打碎、冲散，然后让水流带着从下游排走。

所以桃核承气汤为什么叫「桃核」承气？桃仁负责**破血**，大黄、芒硝、甘草负责**承气下行**。没有桃仁，光用承气汤，瘀血冲不开，泄下去的是新血。没有承气汤，光用桃仁，瘀血打散了排不出去，更堵。这是两个拆开的半招，合在一起才是一剑封喉。

倪师特别强调：**桃仁是血分药里的「通便药」，也是通便药里的「血分药」。** 妇人经期便秘、跌打损伤后大便不通、久病入络腹中硬满，这些都是桃仁的靶场。

## 🎯 临床用量法度与配伍抓手

**倪师常用剂量法度：**

- 常规入汤剂：**9g～15g**（两钱到五钱），破血通经、活血化瘀
- 急危重症——如太阳蓄血证、抵当汤法、腹中癥瘕硬满：**15g～30g**，甚至与大黄、水蛭、虻虫同用
- 桃仁安全度很高，但**孕妇绝对禁用**，无瘀血者不可轻投
- 桃仁要**去皮尖**，倪师讲因为尖端有微毒，去皮尖后药性更纯，破血而不伤正

**经方经典药对配伍要诀：**

| 配伍 | 核心要诀 |
|------|----------|
| **桃仁 + 大黄** | 破血逐瘀 + 推陈致新，瘀从大便走。桃核承气汤、抵当汤的核心骨架 |
| **桃仁 + 桂枝** | 桂枝通阳化气、温通经脉，桃仁破血下行。一温一通，瘀血遇到阳气才化得开。桂枝茯苓丸的配伍 |
| **桃仁 + 丹皮** | 瘀久必生热，丹皮凉血散血，桃仁破血下行。大黄牡丹皮汤、桂枝茯苓丸 |
| **桃仁 + 红花** | 桃仁偏破、偏降、偏走大肠；红花偏散、偏升、偏走周身。一升一降，瘀血无处可藏 |
| **桃仁 + 当归** | 当归补血活血，桃仁破血逐瘀。一补一破，破而不伤，适合妇人经闭、产后瘀阻 |
| **桃仁 + 苇茎（芦根）** | 千金苇茎汤法，桃仁破肺中瘀血，苇茎清肺热排脓，专治肺痈胸中甲错 |
| **桃仁 + 冬瓜仁** | 桃仁破瘀，冬瓜仁排脓利湿，大黄牡丹皮汤里治肠痈 |
| **桃仁 + 水蛭、虻虫** | 抵当汤法，飞者走络、潜者走经，桃仁居中破血，三味合用专攻顽固干血 |

**临证眼目与辨证使用禁忌：**

**眼目一：** 病人腹中硬满、按之痛，大便色黑如柏油，或妇人经闭不来、少腹结块，舌有瘀斑瘀点，这是桃仁的正面靶子。倪师讲「舌上有青紫斑点，就是有瘀血，桃仁就上了」。

**眼目二：** 病人「其人如狂」——太阳蓄血证，热入血室，神志昏狂，少腹急结，小便自利，这是桃核承气汤证，桃仁在其中破血，血去则神清。

**眼目三：** 跌打损伤、骨折筋伤，局部青紫肿痛，桃仁是必用之品，破血消肿。

**禁忌：**

- **孕妇禁用**，破血之力足以动胎
- **无瘀血者勿用**，血虚经闭不是瘀，那是血不够，用了桃仁就是竭泽而渔
- **大便溏泄无瘀者慎用**，桃仁润下降气，便溏之人用了更泻
- **血枯经闭、气血两虚者断不可单用桃仁**，必须配伍补血药，否则破血伤正
- **痈脓已成而正气大虚者**，桃仁破血排脓虽好，但要固护正气，不能一味攻伐

## 🗣️ 倪师讲义实录与发挥

倪师在讲《金匮要略·妇人妊娠病脉证并治》桂枝茯苓丸的时候，对桃仁讲了一段非常经典的话，大意是：

> 「桂枝茯苓丸里面，桂枝、茯苓、丹皮、桃仁、白芍，五味药。你看这个方，丹皮和桃仁是破血的，桂枝是行阳的，茯苓是利水的，白芍是敛阴的。它治的是什么？妇人怀孕，胎动不安，或者漏下不止，为什么？因为子宫里面有癥瘕，有瘀血块住在那里，胎儿长不大，因为营养被瘀血抢走了。你不把瘀血打掉，胎儿就保不住。这时候你用桃仁去破这个瘀，瘀去了，血才能归经，胎儿才能得到滋养。所以经方的高明就在这里——看起来用了破血的药，实际上是在保胎。你如果不懂经方，看到孕妇就用当归、阿胶去补，补了半天瘀血越补越结实，胎反而掉了。」

倪师还讲过一个比喻来形容桃仁：

> 「你看桃核，你拿锤子去砸，外面那层壳硬得不得了，砸开以后里面那个仁，油油的。这个仁就是桃树把一整年的精华收在里面，准备来年春天再发。你把这个仁入药，它入到身体里，专门去找那些『硬壳』——就是被包住的、被封住的瘀血。它把那个硬壳给你打开，让里面的东西重新流通。这叫『仁者，核中之生机也』。所以桃仁不是死药，它是活的，它带着一股要破壳而出的力量。」

讲大黄牡丹皮汤治肠痈时，倪师说：

> 「肠痈是什么？就是盲肠炎、阑尾炎那一类。肠子里面发炎、化脓、堵住了。大黄牡丹皮汤：大黄、牡丹皮、桃仁、冬瓜仁、芒硝。桃仁在里面干什么？桃仁是把肠壁周围那些瘀血、那些黏住的东西打破，冬瓜仁排脓，丹皮清热凉血，大黄芒硝往下推。所以这个方子一下去，大便一通，脓血排出来，痛就减轻了。你看张仲景用桃仁，从来不是单用，一定是配伍，一定是给瘀血找一条出路。」

倪师在讲《伤寒论》桃核承气汤时特别点出「血自下，下者愈」这六个字：

> 「桃核承气汤证，少腹急结，其人如狂，这是太阳表邪不解，热邪随经入腑，跟血结在膀胱。这个血在哪里？在少腹，在盆腔。你不把它打下来，热就退不掉，狂就好不了。桃仁在这里就是先锋，先把血块打散，然后大黄芒硝跟着往下推，推到下面，从小便或大便排出去。病人吃完药以后，如果看到大便里面有黑血，恭喜你，对证了，『血自下，下者愈』。」

倪师还反复叮咛：

> 「桃仁这个药，你用对了，它是救命药。用错了，它是杀人刀。怎么讲？妇人怀孕，你如果不懂，看到有瘀血就用桃仁去破，瘀血破了，胎儿也跟着掉了。所以用桃仁之前，你一定要搞清楚——这是有瘀的，还是没瘀的。有瘀，你用桃仁，瘀去正安。没有瘀，你用桃仁，那是刀刀见血。这就是经方的精神——药没有好坏，看你会不会用。」
