# 白芥子

## 🌿 神农本草原意与性味气味

**《神农本草经》未收载白芥子。**《本经》上品有"芥"之属，然白芥子一物，古时以其辛烈走窜、专走皮里膜外之痰，首载于《名医别录》，历代本草递相补充。其经典本草原文如下：

- 《名医别录》：白芥子，味辛，温，无毒。主冷气，止翻胃，消痰癖。
- 《开宝本草》：主冷气，止翻胃，消痰癖，除胸膈痰饮。
- 朱丹溪：痰在胁下及皮里膜外，非白芥子不能达。
- 《本草纲目》：利气豁痰，除寒暖中，散肿止痛。

**气味与阴阳升降属性**

白芥子味辛、性温，气厚而味亦厚，属纯阳之品，性主升浮而外达。辛能散、能行、能窜；温能化、能通、能燥。其气不走中焦之守，不走下焦之藏，专走"皮里膜外"——即皮与肉之间、脏腑与脏腑之间那层不上不下的空隙地带。

法象天地以观之：白芥子生于秋日、成于霜降，得金秋收敛之气而藏辛烈之性于内，故其辛不浮于表而深藏于核，一入口则辛气烈烈上冲鼻孔，此气厚之验。质小而坚实，为走窜之体，故能钻入寻常药力所不能到之处。辛温属阳，升多于降，入肺经气分，外达皮表，横走胸胁，是化痰药中最能"钻夹缝"的一味。

## 🫀 倪师药性推演与破局心法

**倪师看白芥子的灵魂：不是化痰，是"撬夹墙"。**

寻常化痰药，半夏化的是胃中的痰水，南星化的是风痰，贝母化的是燥痰上的痰，瓜蒌化的是胸膈上的痰。这些药都像是"在房间里拖地"——地拖得再干净，墙缝里的、夹层里的、地板下面的湿气，它照样进不去。

白芥子不一样。**白芥子生用，辛烈之气能穿透皮肤；外敷一点在穴位上，皮肤会起水泡——这就是它把皮里膜外的痰往外逼出来的铁证。**

倪师常拿一个自然比喻讲透：

> "你家里墙壁中间那层夹墙里有湿气，墙皮看起来是干的，实际上里面发霉了。你用除湿机放在房间里吹，吹十年墙壁里面还是湿的。怎么办？你得拿一根铁钎，从墙缝里凿进去，把里面的湿气撬出来。白芥子就是那根铁钎。"

所以朱丹溪那句"痰在胁下及皮里膜外，非白芥子不能达"，倪师读起来是拍案叫绝的。**"达"字最有味——不是说它能化痰，是说它能"到达"别药到不了的地方。**

**与甘遂、大戟合为控涎丹，是倪师破痰饮最深的一手：**

- 甘遂——逐水，像抽水机，把三焦水道里的水从下面抽走；
- 大戟——逐水，专攻脏腑间积水；
- 白芥子——**撬夹墙**，把皮里膜外糊着的那层痰壳子撬松、打散。

三层结构配合：白芥子把夹层里的痰撬松、推出去，甘遂大戟再把水从二便逐出去。若是只有甘遂大戟，没有白芥子，那些黏在膜外的痰根本不动——水是水，痰是痰，此理不可不知。

**与桂枝条下"白芥子厚朴杏仁半夏同用，治上气咳逆"对读：**

此组合是"一升一降、一散一收"的格局。厚朴杏仁降肺气、半夏散胸中水，白芥子专门去撬"痰卡在气管、肺膜之间"的那一层。病人咳得厉害，痰白、带泡沫、咳出来胸胁牵痛——这是痰在肺膜外，一望便知。

**另有一层心法：白芥子能"破阴结"。**

寒痰凝在皮下成核，如皮下痰核、瘰疬、阴疽、冷庁，化不开、散不动，加白芥子一味，辛温能以火破冰。这是生姜干姜不能做的活儿——姜走中焦，白芥子走"肌膜之间"。

## 🎯 临床用量法度与配伍抓手

**一、内服剂量法度**

- 常规汤剂：**一钱至三钱（3–9克）**，多用1–2钱（3–6克）。寻常化痰，一钱足矣。
- 重症寒痰、老痰咳嗽：可加至**三钱（9克）**，须配合温肺化痰药同下。
- 控涎丹（丸剂）：白芥子与甘遂、大戟**等分**，共为细末，糊丸如梧桐子大，每服**5–7丸**，甚者**10丸**，临卧姜汤送下。**取效即止，不可久服。**
- 生用辛烈走窜最猛，外用起泡力最强；**炒用**辛味稍减，护胃，适合内服常服。倪师一般内服主用炒，外敷主用生。

**二、经方经典药对配伍要诀**

| 配伍 | 格局与主治 |
|---|---|
| 白芥子 + 紫苏子 + 莱菔子 | 三子养亲汤。化痰降气、消食宽胸，治老人中气不足、痰壅食滞、咳喘胸闷 |
| 白芥子 + 甘遂 + 大戟 | 控涎丹。痰伏胸膈、皮里膜外、走注疼痛、痰饮流注 |
| 白芥子 + 厚朴 + 杏仁 + 半夏 | 治上气咳逆、痰白泡沫、胸胁牵痛（桂枝条下倪师亲用配伍） |
| 白芥子 + 麻黄 + 杏仁 | 寒邪闭肺、痰白清稀、遇冷即喘 |
| 白芥子 + 细辛 + 甘遂 + 延胡索（生姜汁调） | 三伏贴外敷肺俞、膏肓、膻中，治寒喘冷痰伏肺，以起泡为度 |

**三、临证眼目**

- 痰多色白、清稀如泡沫、遇冷加重
- 胸胁走注疼痛、痛无定处（痰在膜外之验）
- 后背冷痛、咳时牵引胁痛
- 皮下有痰核、冷庁、阴疽不红不热
- 脉象多滑、弦、紧，舌苔白滑

**四、辨证使用禁忌**

- **阴虚火旺、干咳无痰、痰黄黏稠者忌。**白芥子辛温助火，此为第一禁忌。
- **喉症、血症（咯血、吐血）忌。**辛烈能上行气分，恐动血。
- **肺虚久咳、肺结核空洞者忌。**只化实痰，不补虚损。
- **胃溃疡、十二指肠溃疡者慎内服生品。**辛烈之性伤胃膜，须炒用或改外用。
- **孕妇慎用。**走窜之力能动胎气。
- **外敷起泡后不可抓破，可待其自收，或敷以金黄散、紫云膏。**

## 🗣️ 倪师讲义实录与发挥

倪师讲白芥子，最重"皮里膜外"四字。下引讲义中讲控涎丹、讲三子养亲汤的几段金句实录：

> "诸位记住朱丹溪这句话：**痰在胁下及皮里膜外，非白芥子不能达。** 你看病人，咳嗽咳得很厉害，X光照起来，肺里干干净净，什么都没看到。可是他胸口就是这里痛、那里痛，走来走去地痛，一咳就牵到胁下。为什么？——他在皮里膜外有一层痰，透视看不到的。这个痰，你用半夏、用贝母、用南星，一个个都吃进去，没有用！因为它没有钻到夹墙里去。这时候用白芥子，再去配合甘遂大戟，把那个痰一撬、一冲，从大小便排出去——这就叫控涎丹。"

> "白芥子这个药，最像一只钻地鼠。你家的墙好好的，它在墙缝里打洞；痰藏在皮肉之间、藏在脏腑的间隙里，别的药不敢进去，它一进去就把痰撬松，让水药把痰带走。辛能散，温能行，散而不守，专走肌膜的空隙。"

> "**白芥子外敷，会起水泡。** 这就是它的力量。三伏贴为什么要用白芥子？因为夏天阳气最旺，借助天地之气，把白芥子的辛烈之性送进皮肤，把藏在肺膜外的冷痰逼出来，用发泡的方式排出体外。这是天时、药力、穴位三合一的法子——一发的时候，病人咳喘就轻了。"

> "三子养亲汤——苏子降气、莱菔子消食、白芥子化痰。三个都是子，都是往下降的。老人痰多食少、咳嗽气逆，这三味药灵得很。但是诸位记着：**这是化寒痰的方子，痰黄、痰燥、干咳的不对证。**你一见痰黄还给他吃白芥子，辛温助火，越吃痰越稠、越吃喉咙越干——那是你在害他。"
