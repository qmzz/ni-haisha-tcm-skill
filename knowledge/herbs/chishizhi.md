# 赤石脂

## 🌿 神农本草原意与性味气味

**《神农本草经》原文：**
“赤石脂，味甘，平。主黄疸，泄痢，肠澼脓血，阴蚀下血赤白，邪气痈肿，疽痔恶疮，头疡疥瘙。久服补髓益气，肥健不饥，轻身延年。”

倪师人纪讲义引据：《本经》列赤石脂于上经石部，与白石英、紫石英、禹余粮同列，皆石类而具收敛固涩之功。石药之中，赤石脂独以色赤入血分，质重坠下，故能收摄下焦气血之滑脱。

**气味与阴阳升降属性：**
- 味甘、酸、涩，性温而平。甘能补中，酸涩能收，温能通利血脉。
- 气薄味厚，阴中之阳，降也。石质沉重，法象“天降石以镇地”，其性下行，直达下焦，故能固大肠之滑脱、止下部之出血。
- 色赤入心与血分，体重入肾与下焦。赤为火色，石为土质，火土相生，故能温敛下焦而无寒凝之弊；质重如锚，故能镇纳浮阳、固摄脱气。
- 与白石英、紫石英之别：白石英入肺，色白主气；紫石英入肝与冲脉，色紫主血而镇逆；赤石脂则色赤入心与肠胃，主血分之下滑，凡泄痢脓血、崩中漏下之属于虚寒滑脱者，非此不除。

## 🫀 倪师药性推演与破局心法

**倪师如何理解赤石脂的灵魂：**

倪师讲赤石脂，一言以蔽之：**“石类之涩剂，专收下焦滑脱。”** 它不是攻击性的药，不是大黄推陈致新，不是芒硝软坚泻下，恰恰相反——它是“关门”的药。当人体下焦门户洞开，精血津液如决堤之水外泄，赤石脂就是那块堵住堤坝缺口的红石板。

倪师用人纪中的核心比喻来解：**“赤石脂像是河底的沉石。”** 河流泛滥，不是水太多，是河道漏了、堤岸垮了。赤石脂质重如石，色赤入血，味涩能收，它不治“水”，它治“漏”。凡下利滑脱、脓血不止、崩中漏下、遗精滑泄，都是下焦门户不固，赤石脂下去，就像在漏水的缸底垫上一块红石，把窟窿堵住。

与禹余粮的区别：禹余粮也是石类涩剂，但禹余粮偏于止“血崩带下”，赤石脂偏于止“泄痢脓血”。二药常相须为用，如赤石脂禹余粮汤，专治下利不止、心下痞硬、服泻心汤已而复发者——这是利在下焦，非中焦之黄芩黄连所宜，必用石类以固下焦之脱。

**用大白话讲透药理：**
人的大肠就像一个袋子，寒湿久利、或者误下伤阳之后，袋口松了，关不住，什么都在往外漏——先漏稀水，再漏黏液，最后连脓血都漏出来。这时候你用干姜温中、用粳米养胃，那是在修补袋子的布料；但袋口的松脱，得用赤石脂这种“涩剂”去把袋口扎紧。桃花汤里赤石脂用一斤，一半煮一半冲服，就是把“扎袋口”的力量集中在下焦。这就是倪师常说的“涩以固脱”——赤石脂是涩剂的代表，和龙骨牡蛎的“潜镇”不同，龙骨牡蛎收的是浮越之神，赤石脂收的是下脱之形。

## 🎯 临床用量法度与配伍抓手

**倪师常用剂量法度：**
- 常规剂量：**15–30克**，入汤剂包煎（石类质重，不包煎则沉底糊锅）。
- 急危重症重剂：**30–60克**。桃花汤中赤石脂一升（约合今之60–90克），其中一半筛末冲服，一半入煎；赤石脂禹余粮汤亦重用。
- 外用：研极细末，撒敷疮面，治溃疡不收口、痔疮出血。
- 倪师强调：**必须包煎**，否则石粉糊锅；冲服粉末必须“筛末”，取极细者为佳，粗粒冲服伤胃。

**经方经典药对配伍要诀：**
- **赤石脂 + 干姜 + 粳米**（桃花汤）：温中涩肠，治少阴病下利脓血、腹痛、小便不利。干姜温下焦之寒，粳米养已伤之胃，赤石脂涩已滑之肠。
- **赤石脂 + 禹余粮**（赤石脂禹余粮汤）：二石相叠，重涩之极，专治下利不止、心下痞硬、利在下焦者。
- **赤石脂 + 乌头 + 附子 + 蜀椒 + 干姜**（乌头赤石脂丸）：赤石脂在此方中不是止利，而是“收敛浮阳、固护心气”——心痛彻背、背痛彻心，阴寒痰浊上逆，辛热之品荡涤阴霾，赤石脂镇纳之，使温通之力不致散越。
- **赤石脂 + 当归 + 川芎 + 阿胶**：治妇人崩中漏下，血虚而滑脱不止者。
- **赤石脂 + 龙骨 + 牡蛎 + 桂枝**：治遗精、白带、汗出不止兼见下焦滑脱者。

**临证眼目与辨证使用禁忌：**
- **辨证眼目**：下利脓血而色暗、腹痛喜温喜按、舌淡苔白滑、脉沉迟或细弱；或崩漏下血色淡质稀、无臭无热象；或疮疡久不收口、色淡不红。核心是“**虚寒滑脱**”四字。
- **禁忌**：实热积滞、湿热痢疾初起、腹痛拒按、里急后重、舌红苔黄腻、脉滑数者，**绝对禁用**。赤石脂是关门之药，实邪未清而先关门，等于闭门留寇，必成胀满危候。倪师明言：“痢疾初起，有表证、有里急后重、有热象者，绝不可用赤石脂，用了就是把人往死路上推。”孕妇慎用，石类重坠，恐动胎气。

## 🗣️ 倪师讲义实录与发挥

倪师在《金匮》与《伤寒》讲解桃花汤时，反复强调赤石脂的独特用法：

> **“桃花汤为什么叫桃花？** 因为下利脓血，大便颜色像桃花一样，红白相间。你看到这种情形，病人脉沉细，舌淡，腹痛绵绵，喜按喜温，这就是少阴寒化、下焦不固。这时候你开黄芩黄连，那是找死；你开大黄芒硝，那更是找死。你要用赤石脂——**赤石脂是涩剂，专门收敛下焦的滑脱。**”

> **“赤石脂一斤，一半煮一半冲服。为什么？** 煮的那一半，取其气味入汤，走中下焦；冲的那一半，取其质重下沉，像撒面粉一样把粉末直接送到大肠壁上去收口。这是张仲景的巧思，后世很多人不懂，把赤石脂全部煮了，效果就差了一半。”

> **“赤石脂禹余粮汤，这是利在下焦，不是中焦。** 你用了理中汤、泻心汤，利还是不止，为什么？因为中焦已经通了，但下焦的门关不住。这时候你要用石类药去镇固下焦。赤石脂、禹余粮，两个都是石头，都涩，都重，一下去，下焦的滑脱就止住了。这就是‘涩以固脱’的道理。”

> **“乌头赤石脂丸治心痛彻背、背痛彻心，那是阴寒攻心。** 乌头、附子、蜀椒、干姜，全是辛热之药，力量太猛，一下子冲上去，心阳承受不住。所以要加赤石脂——**赤石脂在这里是‘刹车’**，是收敛浮阳、镇纳心气，使辛热之药温通而不散越。你看，赤石脂不只是一个止利的药，它还能固护心阳，这就是石类药的妙用。”

倪师最后总结赤石脂的心法：**“凡是下焦不固、虚寒滑脱，无论泄痢、崩漏、遗精、带下，赤石脂都是首选。但它只能用于寒脱，不能用于热闭。寒脱是门关了，热闭是门打不开——一个要关，一个要开，方向相反，用错就是杀人。”**
