# 海桐皮

## 🌿 神农本草原意与性味气味

**《神农本草经》未收载海桐皮。** 这味药是宋代以后才正式进入本草体系的，首见于《开宝本草》，但与倪师人纪讲义串讲时，必须把它放回《本经》的阴阳气味框架去理解，不能因为《本经》没收就把它当“后世杂药”轻看。

经典本草出处原文：

- 《开宝本草》：“海桐皮，味苦，平，无毒。主霍乱中恶，赤白久痢，除疳䘌疥癣，牙齿虫痛。”
- 《日华子本草》：“治血脉麻痹疼痛，及煎洗目赤。”
- 《本草纲目》引：“主诸风，除湿，杀疮虫。”

**气味与阴阳升降属性：**

海桐皮味苦、辛，性平，气薄味厚。苦能泄、能燥、能坚，辛能散、能横行，平则不偏寒不偏热。它的法象是“树之外皮”——皮走皮，皮入络。天以气生，地以味成，海桐皮取的是“树干最外层护卫之皮”，所以它在人体里天然就走向体表、走向经络、走向关节缝隙这些“皮里膜外”的地方，把停滞在那些角落里的风湿之邪往外泄、往下行。

倪师的读法：气薄者走上走表，味厚者能沉能泄。海桐皮一边辛散走上把关节缝里的风邪散开，一边苦泄往下把湿浊从水道排出去——这就是它为什么能“上治牙痛目赤，下治腰膝顽痹”的阴阳两向性。

## 🫀 倪师药性推演与破局心法

### 倪师怎么理解这味药的灵魂

如果把威灵仙比作一条鞭子——抽打经络，把堵住的地方硬抽开；那海桐皮就是**一层会自己行走的树皮**——它不猛攻，它循着经络系统的缝隙，一路渗透进去，把附着在关节囊、肌腱、筋膜上的风湿一层层剥开、渗出去。

打个自然物理的比方：**人体的经络就像一条排水管道，风湿之邪就像管道壁上日积月累的水垢和青苔。** 威灵仙是拿钢丝刷猛刷，海桐皮是倒进去一种能溶解水垢的温和溶剂——它不是靠蛮力，是靠“同样的皮性”去感应、去渗透、去剥离。树皮在外护树，药皮在表护人。以皮治皮，同气相求。

再打个更接地气的比方：**海桐皮治风湿，就像晒被子。** 被子受了潮，你不去拧它、不去砸它，你把它挂出去、让风和阳光把它里面的湿气一层一层带走——海桐皮就是那阵“风”，辛以散之；同时也是那个“太阳”，苦以燥之。

**与相似药的对比：**

- **海桐皮 vs 五加皮**：五加皮偏补，祛风湿的同时补肝肾、强筋骨，是“又通又补”；海桐皮纯通不补，专门走经络、通痹止痛，是“只通不补”。所以虚人风湿要配五加皮、牛膝；实人风湿闭阻，海桐皮放胆用。
- **海桐皮 vs 秦艽**：秦艽是“风药中之润剂”，走而不燥，偏于退虚热、利二便；海桐皮偏燥，专门针对湿邪偏重的顽痹、皮肤疥癣。
- **海桐皮 vs 威灵仙**：威灵仙通络之力更猛，能消骨鲠；海桐皮更偏于走皮、走表、走关节囊，兼能杀虫止痒。

### 破局心法

倪师讲这味药的核心心法就一句话：**“皮能走皮，络能通络，苦能泄湿，辛能散风。”**

临床上碰到关节不红肿、但就是酸重、屈伸不利、阴雨天加重的，这就是风湿附着在关节囊和筋膜之间，海桐皮是首选之一。它不寒不热，所以寒湿能用、湿热也能用，就看你怎么配伍。

## 🎯 临床用量法度与配伍抓手

### 倪师常用剂量法度

- **常规内服**：二钱至三钱（6–9克）。这是倪师在风湿痹痛、腰膝疼痛中的常规起手量。
- **重症顽痹**：可加至五钱（15克），但必须配伍养血药（如当归、白芍）以防其辛散苦燥伤阴。
- **外用煎洗**：一两至二两（30–60克），煎汤外洗或熏洗，治疥癣、皮肤瘙痒、目赤。外用不拘于此量，以覆盖患处为度。
- **急危重症**：海桐皮不是回阳救逆的药，不入急危重症重剂法。它的战场在“慢病顽痹”和“皮肤外症”，不在生死关头。

### 经方经典药对配伍要诀

| 配伍 | 要诀 |
|------|------|
| **海桐皮 + 牛膝** | 治腰膝以下风湿痹痛。海桐皮走表通络，牛膝引药下行、补肝肾，一上一下，一下一守，腰膝顽痹之标配。 |
| **海桐皮 + 五加皮** | 治虚人风湿。五加皮补肝肾强筋骨，海桐皮通络止痛，一补一通，攻补兼施。 |
| **海桐皮 + 羌活 + 独活** | 治上半身风湿用羌活，下半身用独活，海桐皮居中策应，通走全身关节。三药合用，一身之风寒湿皆可搜剔。 |
| **海桐皮 + 薏苡仁 + 苍术** | 治湿痹重着。薏苡仁利湿健脾，苍术燥湿发汗，海桐皮通络，三药把湿邪从汗、从尿、从经络三条路赶出去。 |
| **海桐皮 + 苦参 + 蛇床子（外用）** | 治疥癣、湿疹、皮肤瘙痒。三药煎汤外洗，苦参杀虫燥湿，蛇床子祛风止痒，海桐皮引药达皮。 |
| **海桐皮 + 当归 + 白芍** | 治血虚风湿。当归白芍养血柔肝，海桐皮通络，防止辛散苦燥伤血。 |

### 临证眼目与辨证使用禁忌

**眼目：**

- 关节**酸重不仁、屈伸不利、阴雨天加重**——海桐皮对症。
- 皮肤**疥癣瘙痒、湿疹渗水**——海桐皮内服外用皆可。
- **牙齿虫痛**——古法用海桐皮煎含漱，苦能杀虫。

**禁忌：**

- **血虚生风者忌单用**。血虚引起的筋骨疼痛，单用海桐皮辛散苦燥，越用越伤血，必须配养血药。
- **阴虚火旺、津液不足者慎用**。苦燥伤津，阴虚之人用后口干、便结。
- **无风湿实邪者不用**。它不是补药，没病别吃。
- **孕妇慎用**。辛散通络之品，恐动胎气。

## 🗣️ 倪师讲义实录与发挥

倪师在讲这味药的时候，语气是轻描淡写的，但下手很准。他说：

> “海桐皮哦，这个药哦，你们不要小看它。它是树皮，树皮走皮。所以我们身上的皮病、关节的病，它都能治。它味苦性平，苦能泄，平就是不偏，所以寒热都可以用。你遇到风湿关节痛，项强、腰酸、膝盖不能弯，海桐皮加进去，配合牛膝、五加皮，效果很好。”

> “它还能杀虫。身上长疥癣、痒得不得了，你拿海桐皮煮水，洗一洗，比什么西药膏都管用。为什么？苦味杀虫，辛味散风，风痒就没了。”

> “有的病人牙齿痛，是蛀牙那种痛，你用海桐皮煮水含在嘴里，不要吞下去，含漱，苦味把虫杀掉，痛就止了。这是古法。”

> “海桐皮这味药哦，记住，它是通剂，不是补剂。人虚了，你要加当归、白芍、五加皮下去，不能单用。单用哦，越通越虚，病人会更累。”

倪师的总结就是一句话：**“皮通皮，络通络，苦杀虫，辛散风，性平不偏，寒热皆宜，但只通不补，虚人必配补药。”**

这就是海桐皮在人纪体系里的灵魂——它不是主角，但它是风湿痹痛方阵里那个“走皮通络、无处不到”的副将，缺了它，很多顽痹就是通不透。
