# 刘寄奴

## 🌿 神农本草原意与性味气味

刘寄奴一药，《神农本草经》未载。其名始见于《新修本草》，为南朝宋武帝刘裕（小字寄奴）行军途中以草药疗金疮所得，后世遂以其小字名之。此事本身即是一则法象——此药生于荒野路旁，被刀兵所伤者随手采撷即能止血定痛，说明其气机天然趋向于“破中有敛、散中带收”，非单纯攻破之品。

**性味**：苦，温。归心、肝、脾经。

**气味阴阳升降**：气厚味薄，属阳中之阴。苦能泄能燥，温能通行能散寒。其气机走向为“升中有降，散中有收”——入血分而破瘀滞，同时又能止金疮出血，这在本草中极为罕见。一般破血药如三棱、莪术，破而不收；止血药如白及、仙鹤草，收而不破。刘寄奴独能两者兼之，说明其秉性中兼有“通”与“涩”双重法象，如同一条河流既有冲刷淤泥的力道，又有在决口处自行淤积封堵的能力。

《新修本草》原文：“刘寄奴，味苦，温。主破血，下胀满。多服令人下痢。”
《日华子本草》补充：“治心腹痛，下气水胀，血气，通妇人经脉癥结，止霍乱水泻。”
《开宝本草》增补：“疗金疮，止血为要药。”

从经典条文可以看出，刘寄奴的核心功能域集中在“血”与“水”两条线上——破血、下胀满、止金疮出血、通经、治水泻霍乱。这说明它入血分破瘀，入气分消胀，入水分利水，是一味气血水三焦并治的务实之药。

## 🫀 倪师药性推演与破局心法

倪师讲刘寄奴，核心心法在于八个字：**破瘀不伤新，止血不留瘀**。

**一、灵魂定位——伤科破血第一梯队**

倪师认为，刘寄奴的灵魂在于它是“伤科的血分将军”。与大黄推陈致新不同——大黄是从阳明腑实往下推，走的是消化道；刘寄奴是从血分往外破，走的是经络脉道。它像一支专门清理战场的工兵部队：跌打损伤后，局部血管破裂，血溢出脉外成为离经之血，既不能回流又堵塞经络，导致肿痛。刘寄奴的作用就是把这些“死血”打散、化开、排走，同时让破裂的脉管收口。

**二、自然物理比喻——山洪与堤坝**

倪师常用一个比喻：人体经脉如同河道，跌打损伤相当于山体滑坡把河道堵了，上游水位涨起来就是“胀满”，下游断流就是“经闭”。一般活血药如红花、桃仁，相当于拿锄头挖堵塞物，挖是挖开了，但慢。刘寄奴相当于直接放水——它苦温之性，苦能泄、温能通，一入血分就像开闸放水，把堵塞的瘀血一举冲开。但奇特的是，它同时又像河道两岸的柳树根——当河堤有缺口（金疮出血）时，它的涩性又能把缺口护住，不让水继续外溢。所以倪师说：“刘寄奴这味药，你把它当成既能炸山开路、又能修桥补路的工兵营就对了。”

**三、与同类药的鉴别心法**

倪师在讲活血化瘀药时，常把几味药放在一起对比：
- **川芎**——行血中之气，偏于走窜，像风一样吹散郁结，但破血力不足；
- **桃仁**——破血润燥，偏于走下焦、通大肠，像钻头一样往深处钻；
- **红花**——活血通经，偏于轻扬上行，像花瓣飘散；
- **三棱、莪术**——破血消积，力猛如斧劈，但正气弱者受不了；
- **刘寄奴**——破血兼止血，气血水三通，力道介于桃仁与三棱之间，但独有“止金疮出血”一能，为伤科所必用。

倪师的结论是：**“打伤、跌伤、刀伤，血还在流但你又要化瘀，第一个想到的就是刘寄奴。”** 因为单用化瘀药会加重出血，单用止血药会把瘀血锁在里面，刘寄奴两难自解。

**四、为何能“下胀满”与“止水泻”**

倪师推演：血瘀则气滞，气滞则水停。刘寄奴破血之后，气机随之通畅，水湿自然下行。所以它能治“下胀满”和“霍乱水泻”——本质上还是通过破血来恢复气水代谢的通道。倪师说：“胀满不是气的问题，是血堵了气过不去；水泻不是水的问题，是血瘀导致水无法正常吸收。刘寄奴一破血，气通了，水也归经了。”

## 🎯 临床用量法度与配伍抓手

**一、倪师常用剂量法度**

- **常规煎剂**：9-15克（约3-5钱），用于跌打损伤、经闭、产后瘀阻；
- **伤科急症**：15-30克（约5-10钱），用于严重外伤瘀肿、骨折初期瘀血内停；
- **外用止血**：不拘量，研末掺敷金疮出血处，即刻止血；
- **鲜品捣敷**：鲜刘寄奴捣烂外敷跌打肿痛处，量随意。

倪师强调：刘寄奴安全窗口较宽，但“多服令人下痢”，所以脾胃虚寒者内服不宜超过15克，且需配伍白术、甘草护中。

**二、经典药对配伍要诀**

| 配伍 | 功效 | 适用场景 |
|------|------|----------|
| 刘寄奴 + 骨碎补 | 破瘀接骨 | 骨折中期瘀肿未消 |
| 刘寄奴 + 当归 + 川芎 | 活血养血 | 跌打损伤兼血虚 |
| 刘寄奴 + 桃仁 + 红花 | 破血通经 | 经闭、产后瘀阻 |
| 刘寄奴 + 三棱 + 莪术 | 消癥破积 | 腹中癥块、肝脾肿大 |
| 刘寄奴 + 蒲黄 + 五灵脂 | 化瘀止痛 | 心腹瘀痛、痛经 |
| 刘寄奴 + 地榆 + 槐花 | 止血化瘀 | 便血、痔血兼瘀 |
| 刘寄奴 + 泽兰 + 益母草 | 活血利水 | 产后水肿、经行浮肿 |

**三、临证眼目**

倪师辨证使用刘寄奴的眼目在于：
1. **痛处固定不移**——瘀血特征，痛如针刺，夜间加重；
2. **舌质紫暗或有瘀斑**——血瘀舌象；
3. **脉涩或弦紧**——血行不畅之脉；
4. **外伤后局部青紫肿胀**——离经之血停聚；
5. **经闭或产后恶露不下**——血瘀胞宫。

**四、禁忌**

- 孕妇忌用（破血力强，有堕胎之虞）；
- 气血两虚无瘀者忌用；
- 月经过多者慎用；
- 脾胃虚弱易泻者，内服需配健脾药，且量不宜大。

## 🗣️ 倪师讲义实录与发挥

倪师在讲刘寄奴时，有一段原汁原味的金句：

> **“刘寄奴这味药，你们不要因为它名字怪就忽略它。它是伤科的打底药。什么叫打底？就是不管你是跌打、刀伤、还是车祸，只要血已经离经了，瘀在那里了，你手上没有三七、没有云南白药，刘寄奴一样能顶上。它苦温，苦能泄，温能通，一入血分就把死血化开。但它厉害在哪里？它化开死血的同时，金疮出血它也能止。这在本草里不多见。”**

倪师还讲过一个临床实战体会：

> **“我以前治一个从楼上摔下来的工人，大腿肿得像水桶，西医说要截肢，因为瘀血压迫血管神经。我开的就是刘寄奴30克，配骨碎补15克、桃仁10克、红花10克、当归15克，一剂下去小便颜色变成酱油色——那就是瘀血从尿里排出来了。三剂肿消一半，七剂能下地。刘寄奴就是有这个力道，它把瘀血从脉道里赶出来，让身体自己排掉。”**

还有一段关于外用止血的发挥：

> **“金疮出血，你身边没有药，抓一把刘寄奴鲜草嚼烂敷上去，血就止了。为什么？它那个涩性，一碰到伤口就像水泥遇水一样凝固。但你别忘了它同时是破血的，所以它止住的伤口里面不会留瘀，不会形成那种硬疙瘩。这就是它比白及、仙鹤草高明的地方。”**

倪师最后总结刘寄奴的定位：

> **“这味药，你把它当成伤科的‘万能钥匙’。跌打损伤、金疮出血、瘀血经闭、产后恶露不下、腹中癥块，只要舌紫脉涩痛处固定，刘寄奴就可以上。但记住，它是破将，不是补将。虚人要用，必须配当归、白芍、甘草兜底。”**
