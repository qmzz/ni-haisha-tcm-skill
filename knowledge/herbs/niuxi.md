# 牛膝

## 🌿 神农本草原意与性味气味

- 《神农本草经》原文字句：

牛膝，味苦，酸。主寒湿痿痹，四肢拘挛，膝痛不可屈伸，逐血气，伤热火烂，堕胎。久服轻身耐老。一名百倍。生川谷。

- 气味与阴阳升降属性：

牛膝味苦酸，苦能泄能降，酸能收能敛。气薄味厚，阴中之阴，沉降下行。其法象天地之生，根直下穿透，节如牛膝，故名牛膝，又名百倍，言其力大如牛也。其性专走下焦，入肝肾二经，善引诸药下行，为足厥阴、少阴之要药。苦降之性使其能逐瘀血、通经脉，酸收之性使其能强筋骨、补肝肾。降中有补，走中有守，此为牛膝气味之妙。

## 🫀 倪师药性推演与破局心法

- 倪师如何理解这味药的灵魂：

牛膝这味药，你只要记住一个字——“下”。它是把所有东西往下引的。好比大黄是推陈致新，把肠子里的东西推出去；牛膝呢，它不推，它是引，是拉，把上头的火、上头的血、上头的湿，统统往下拉。

你看它的根，一茎直下，穿透力极强，像牛的膝盖骨一样坚硬有力，节节贯穿。所以它走的是下焦的路，肝、肾、膝盖、腿脚，这是它的地盘。

倪师讲，牛膝分两种用法：**怀牛膝补，川牛膝破**。怀牛膝色黄白，质润，偏于补肝肾、强筋骨；川牛膝色黑褐，质硬，偏于破瘀血、通经闭。这是天地的差别，一个偏补，一个偏泻，你不能搞混。

- 用通俗大白话与自然物理比喻讲透药理机理：

你想想，一棵树，根往下扎，越扎越深。牛膝的根就是这样的，它天生就是往下走的。人体上焦有病，火气往上冲，血往上溢，膝盖却空了、软了，为什么？因为气血都往上跑了，下面没有东西了。

牛膝就像一根绳子，一头绑在上面的火，一头往下拉，把火拉回下焦，把血引回腿脚。所以吐血、流鼻血、牙龈出血，你要用牛膝引血下行；膝盖痛、脚软无力、下肢水肿，你更要用牛膝，把气血引下去。

它又像一根管道疏通器，苦味能泄，酸味能收，一边把瘀堵的地方通开，一边把该收的收住。所以它逐血气，又强筋骨，既通又补，这在中药里是不多见的。

## 🎯 临床用量法度与配伍抓手

- 倪师常用剂量法度：

倪师常规用量：**三钱至五钱**（约9-15克）。用于补肝肾、强筋骨，多用怀牛膝，三钱起；用于破瘀通经、引血下行，多用川牛膝，五钱至一两（15-30克）。急危重症，如脑溢血、吐血不止，可用至一两以上，但必须辨证准确，不可妄投。

- 经方经典药对配伍要诀：

| 配伍 | 要诀 |
|------|------|
| 牛膝 + 桂枝 | 桂枝走表通阳，牛膝走下引血，一上一下，治四肢拘挛、膝痛 |
| 牛膝 + 杜仲 | 杜仲补肝肾，牛膝强筋骨，相须为用，治腰膝酸软 |
| 牛膝 + 当归 | 当归补血活血，牛膝引血下行，治经闭、痛经 |
| 牛膝 + 代赭石 | 代赭石降逆，牛膝引血，治吐血、衄血、脑充血 |
| 牛膝 + 黄柏 | 黄柏清下焦湿热，牛膝引药下行，治脚气、下肢湿热 |

- 临证眼目与辨证使用禁忌：

**眼目**：凡见上实下虚、气血上逆、膝痛脚软、经闭不通，皆是牛膝的用武之地。尤其是膝盖痛不可屈伸，牛膝是首选。

**禁忌**：梦遗滑精者忌用，因其下行太过，恐致精关不固；孕妇忌用，因其破血堕胎；气虚下陷者慎用，恐引气更下。倪师特别强调，牛膝引血下行，若病人本已下血不止，再用牛膝，是落井下石。

## 🗣️ 倪师讲义实录与发挥

倪师在讲《神农本草经》牛膝时，原汁原味的金句如下：

> “牛膝这个药，你只要记得它是往下走的。所有的东西，它都往下拉。所以膝盖痛，它下去；脑溢血，它把血拉下来；鼻血流不止，它把血引下来。它是引药下行的代表。”

> “怀牛膝和川牛膝，一个补一个破。怀牛膝像温顺的老牛，慢慢补你；川牛膝像愤怒的公牛，狠狠破你。你要搞清楚，什么时候用哪一头牛。”

> “膝盖痛不可屈伸，你开牛膝，再配上桂枝、白芍，那效果，一剂知，二剂已。为什么？因为牛膝把气血引到膝盖，桂枝白芍通阳和阴，膝盖就活了。”

> “吐血、流鼻血，你不要只想着止血，你要想血为什么往上跑。牛膝一下去，血就下来了，比你去止血快得多。”

倪师还特别提到，牛膝在治疗脑溢血时有奇效，但必须配合其他药物，如代赭石、龙骨、牡蛎，才能把上冲的血彻底引下来，单用牛膝力有未逮。
