# 千年健

## 🌿 神农本草原意与性味气味

**经典本草出处**

千年健不见于《神农本草经》。《神农本草经》收药三百六十五味，以西北、中原所产为主，千年健主产岭南、广西、云南边地，汉时未入中土本草视野。千年健入本草文献，最早见于清代赵学敏《本草纲目拾遗》，其言：“千年健，出广西，气极香烈，能祛风湿，壮筋骨，止疼痛。”其后《药材资料汇编》《中药大辞典》承之。

故千年健非神农旧物，属后世南方药材补入本草体系者。

**性味**

- 味：辛、苦
- 气：温
- 质地：根茎坚实，断面红棕色，香气浓烈

**气味厚薄与阴阳升降**

辛者，天之阳也，能散能行；苦者，地之阴也，能泄能燥；温者，春升之气也，能通能助。三气合一身：辛温走窜以祛风，苦温燥湿以除痹，温通经络以止痛。

千年健气厚味薄——气厚则发热，味薄则通泄。它的气味法象，取的是南方瘴湿之地，风湿相搏、筋骨拘挛之象。天地生此物于岭南湿热深山，其根茎伏地坚硬如骨、经年不朽，得土气之厚以壮筋骨，得辛温之气以破风湿。这就是法象：生于湿而能治湿，质坚而能壮骨。

倪师人纪讲义未单列千年健为专章药。但以人纪本草之法眼观之，此药走的是**厥阴肝经与少阴肾经**——肝主筋，肾主骨。风湿久痹，筋缩骨痛，正是肝肾两经为风寒湿三气所困。千年健辛温入络，苦温化湿，把筋骨间陈寒痼湿一层层搜剔出去，筋骨自然舒展。

## 🫀 倪师药性推演与破局心法

**这味药的灵魂在哪里**

倪师人纪讲药，从不按《中药学》教材那种“祛风湿、壮筋骨”一句话了事。他讲每一味药都要问三件事：**它从哪里来？它往哪里走？它把什么东西赶出去？**

千年健的灵魂，用倪师的话法来推：**它是一味“搜骨缝之湿、续断折之筋”的药。**

打个自然物理的比方——你见过南方梅雨季节的老木门没有？湿气渗进木头缝里，门板膨胀、关不拢、嘎吱响，你光在门面上擦干没用，湿在里面。千年健干的事，就是拿一根烧热的铁钎，顺着门缝插进去，把里面那层陈年湿气烘出来、逼出来。它不是发汗药，不走表；它不是利水药，不走膀胱。它走的是**筋骨之间的缝隙**，把伏在那里的风寒湿一点点温化掉。

**与同类药的分野**

- 威灵仙：走窜力猛，像一根钢丝刷，能通十二经络，但偏于“通”而不偏于“补”。
- 千年健：走窜力较威灵仙温和，但兼有“健”字——健者，强壮也。它一边搜湿，一边把筋骨垫实。所以老人家风湿日久、筋骨萎弱、腰膝无力，用威灵仙嫌它太耗，用千年健则通中有补。
- 五加皮：偏于补肝肾、强腰膝，祛湿力不如千年健。
- 千年健：介于威灵仙与五加皮之间——**祛湿不伤正，强骨不滞邪。**

倪师心法一句话：**千年健是把“通”和“健”合在一味药里的东西。**

## 🎯 临床用量法度与配伍抓手

**常规剂量**

- 煎剂：9～15克
- 风湿顽痹、筋骨拘挛重症：可用至15～20克
- 入酒剂（药酒）：15～30克，借酒力助其走窜

千年健气香味烈，不宜久煎过久，一般后下或中段入煎即可。量太大则辛温过燥，反伤阴血。

**经典配伍药对**

| 配伍 | 要诀 |
|------|------|
| 千年健 + 威灵仙 | 一通一健，搜风除湿、通络止痛，治风湿痹痛游走不定 |
| 千年健 + 五加皮 | 一健一补，强筋骨、祛风湿，治老人腰膝酸软兼痹痛 |
| 千年健 + 杜仲 | 一走一守，杜仲补肾固本，千年健搜邪外达，治肾虚夹风湿 |
| 千年健 + 牛膝 | 千年健走上肢筋骨，牛膝引药下行，治下肢痹痛、膝软无力 |
| 千年健 + 当归、川芎 | 辛温走窜易耗血，配归芎养血活血，通而不伤 |
| 千年健 + 苍术、薏苡仁 | 治湿重于风者，苍术燥湿、薏苡仁渗湿、千年健搜筋骨间湿 |

**临证眼目**

1. **辨湿之深浅**：湿在皮肉，用羌活、独活；湿在经络，用威灵仙、海风藤；湿在筋骨，用千年健。
2. **辨正之虚实**：千年健虽通中有健，但毕竟辛温，阴虚火旺、血虚生风者慎用。舌红少苔、脉细数者，不可单用重用。
3. **辨部位**：上肢配桂枝、桑枝；下肢配牛膝、木瓜；腰脊配杜仲、狗脊。

**使用禁忌**

- 阴虚内热者忌：辛温助火，灼伤阴液。
- 孕妇慎用：辛温走窜，恐动胎气。
- 湿热痹证（关节红肿热痛、舌苔黄腻）不宜单用：须配黄柏、苍术、忍冬藤等清热化湿之品，否则温药助热。

## 🗣️ 倪师讲义实录与发挥

倪海厦人纪《神农本草经》讲义共讲解药物数百味，以《本经》所载上中下三品为纲。千年健非《本经》旧药，故倪师讲义中未单独列章讲解，此须如实说明。但倪师在讲**威灵仙、五加皮、杜仲、牛膝**等风湿筋骨类药时，反复串讲了一个核心心法，可以移用于千年健：

倪师讲威灵仙时说（大意）：

> “风湿关节炎，痛在关节上，用威灵仙。但你要知道，威灵仙只是通，通完以后筋骨还是弱的。所以真正的老风湿，要一边通一边补，通和补要同时来。”

倪师讲五加皮时说（大意）：

> “五加皮能补肝肾、强筋骨，但它祛风湿的力量不够。所以你开处方的时候，五加皮要跟祛风湿的药配在一起用。”

倪师讲杜仲时说（大意）：

> “杜仲是补肾的药，肾主骨，骨头的病要从肾上治。但如果你只补肾不祛邪，风湿还在里面，补进去的东西被邪气挡住了。”

把这三段话串起来，千年健的位置就出来了：**它是通与补之间的一座桥。** 倪师没有单独讲千年健，但倪师讲了一整套“风湿久痹、筋骨并治”的用药框架，千年健在这个框架里，就是那个既能搜剔筋骨间风湿、又能强壮筋骨本体的药。

倪师用药风格，从来是“病在筋骨，根在肝肾，邪在经络”。千年健这味药，恰好把这三个层面串在一起——辛温入经络以祛邪，苦温入筋骨以除湿，温通入肝肾以强健。这就是倪师心法在千年健上的推演发挥。
