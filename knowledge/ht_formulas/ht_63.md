# HT-63 中医学之骨损症

## 💊 汉唐方剂出处与原方配伍

**汉唐方剂 HT-63 中医学之骨损症**

**主要成份：** 炮附子、肉苁蓉、续断、熟地、白芍、补骨脂……等。

**方解配伍抓手：**

- **炮附子**——暖小肠之火，壮命门真阳。附子非入肾而热肾，乃改变腹部温度环境，使小肠蒸化有力，钙盐得以气化入髓。
- **肉苁蓉**——温肾阳、润大肠，既助附子壮火，又通大便之燥结。火足则肠道推动有力，糟粕不留。
- **续断**——续筋骨、通血脉，专入骨节修复损伤，为接骨续筋之要药。
- **熟地**——填骨髓、补精血，直入肾中藏精之所，使骨髓有物可充。
- **白芍**——柔肝敛阴，助肝气疏泄有度，大便通畅之关键在肝之升发条达。
- **补骨脂**——温肾助阳、固精缩尿，专治骨痿无力，助钙质归髓。

此方核心思路：**温小肠之火 → 通大肠之滞 → 升肝气之疏 → 补肾中精髓**。药味不多，但每一步都踩在骨损形成的链条节点上。

## 🫀 倪师水火病机与立方心法

倪师立此方，直指骨损之根本病机：**酸性体质逼钙外流，小肠火衰钙不入髓。**

**第一层：为何骨中钙会流失？**

人体要偏弱碱性才是生命活力强的状态。一旦饮食偏酸——过食甜味、碳酸饮料——身体自动动用骨头里的钙质去水解中和酸性，这就是**阴阳相战，呈现钙流**。血液中查出的钙过多，不是钙补多了，而是骨头里的钙被逼出来了。

**第二层：钙为何进不了骨？**

中医认为**肾主骨**，骨头是肾所主、藏精之所，骨髓全是精气。肾的营养来源在大肠与肺——小肠完成消化后，残渣入大肠，大肠围绕小肠一圈，利用小肠的热能，从残渣中再次吸取水及钙等盐类。这些精微物质**上入于肺，再由肺的呼吸作用，使钙及盐水入肾，如此才进入骨髓**。

所以关键链条是：**小肠火足 → 大肠蒸化有力 → 钙盐上奉于肺 → 肺肃降入肾 → 肾藏精入骨。**

若小肠蒸化温度不够，或大肠中粪便阻塞，钙质根本进不了骨髓。此时西医给钙片，钙游离在血液中，根本进不去骨头，再吃钙片有何用？某些钙片加了活化剂，相当于类激素性质，强行把钙压入骨骼——**结果更可怕，这就生癌症了。**

**第三层：心火与小肠的关系。**

人体上部肺金包裹心脏，肺大心小；下部大肠金在小肠火外面，小肠大、大肠小。这个内景对应绝非偶然。心火下移小肠，小肠才有蒸化之热。附子、干姜所谓暖肾，不是热药直接热肾，而是**改变腹部温度环境，增强小肠火力**。仲圣治胸痹照样用附子乌头，可不是附子入肾，它是改变温度。

**第四层：肝气疏泄与大便通畅。**

保持大便通畅是谁的功能？**肝气的功能**。一切生发疏泄，全部是肝。升肝气，火也足了，肝气也足了，消化自然好。暖脾阳、暖小肠、升肝气——说到底都是从君火治。

**立方心法总结：** 此方以附子暖小肠为君，从蓉通肠润燥为臣，续断续骨、熟地填髓为佐使，白芍柔肝助疏泄，补骨脂固肾强骨。全方不直接“补钙”，而是恢复**小肠蒸化→大肠吸收→肺中精液→入肾归骨**这条生理通路。一旦骨质健全即可停药，长期不可过食甜味，保持大便通畅，即可预防复发。

## 🎯 临床适应症与主治眼目

**主治：** 骨损症（临床可比西医学之骨质疏松症）。

**核心眼目：**

1. **无原因之髋关节痛**——骨病早期痛必在髋关节处，因此处是骨头最早生长之位。许多医生误诊为坐骨神经痛，延误治疗时机。无原因髋关节痛就要注意。

2. **血液中钙质过多**——不是补钙过多，而是骨头里的钙游离出来中和酸性。此时为时已晚，再服钙片无用且有害。

3. **骨病及脱发并见**——过食甜味伤骨，肾又主发，故骨病常伴脱发。西洋人、上海人喜食甜味，骨病及脱发较东方人多见。

4. **骨质疏松高危人群**——许多妇女因无知又惧怕骨质疏松，拼命吃预防药，不管副作用多大，结果仍有许多人得此病。

5. **亚健康、酸中毒体质**——人天天蔫尔巴基的，身体肯定偏酸性；生龙活虎的肯定偏碱性。酸性体质是骨损的土壤。

**预防与治疗眼目：**

- 减少甜味食物，而非一味补充钙。
- 多作运动，保持大便通畅。
- 暖小肠之气，保持大便通畅，多运动。
- 良好胃口，消化吸收、阳化气、阴成形正常——吃下什么东西，该到什么地方就到什么地方，不要说缺钙锌，什么都不缺。

**禁忌与注意：**

- 长期不可过食甜味食物。
- 勿信推销员或医生所谓“吃女性荷尔蒙可预防骨质疏松”——若问他们此病因何而来，答不出来，即可肯定所推销的药毫无预防功能。
- 所谓健字号保健品，连生病的原因都不知道是什么，就要保健，这是根本不知道根源。

**方剂设计底层逻辑发挥：**
