# HT-26 石淋,砂淋,小便带血

## 💊 汉唐方剂出处与原方配伍

- **汉唐方剂编号**：HT-26
- **方剂名称**：石淋、砂淋、小便带血
- **对应西医病名**：肾结石（含输尿管结石、砂淋、血尿）
- **核心配伍思路**（倪师原义）：把身体的水大量导向肾脏 + 分解石头的药 + 止血的药 + 滑利排石的药。

**主要药物抓手（按倪师立方逻辑归类）：**

| 功能层次 |  representative 药物 | 作用抓手 |
|---|---|---|
| 引水归肾（疏肝升发） | 柴胡、郁金、枳实之类 | 肝主疏泄升发，把水液向外、向下导向肾与膀胱 |
| 化石软坚 | 滑石、硝石、海金沙、金钱草之类 | 把大石化成小石，把砂状细石化开 |
| 滑利排石 | 滑石、冬葵子、车前子之类 | 使砂石顺利从输尿管、尿道滑出 |
| 止血防割伤 | 阿胶、白茅根、三七、蒲黄之类 | 预防石头通过输尿管时割破管壁造成出血 |
| 清相火、收敛浮火 | 知母、黄柏、生地之类 | 相火不收、外泄煎熬水液是成石之因 |
| 通利小便 | 茯苓、泽泻、猪苓之类 | 开决水道，助砂石下行 |

> 倪师立方心法一句话：**肝郁解、相火收、水道通、石头化、管壁护——五者俱备，石可排而无血。**

## 🫀 倪师水火病机与立方心法

### 一、肾结石的底层病机：肝郁 + 相火不收 + 煎熬水液

倪师明确指出，肾结石与胆结石**机理极为相似**，关键都在**肝的疏泄功能不通畅**：

- 水液向外排，本是**肝的疏泄升发功能**。肝气不得升发，出现郁气，小便上就表现为**淋症**。
- 《四圣心源》讲淋症：**欲行疏泄而不得，肝气郁不得升，相火必然外泄**。
- 相火泄在膀胱里，淋症就出现了——如同西医说的尿道炎，想尿只尿出一点点。
- 若**每次相火不收藏，同时肝郁**，肾中向外排的力量不足，**相火外泄而煎熬水液，必然成石头**。
- 煎熬日久，细沙结成团、长成一块，就是**石淋**；能尿出来的是砂石，留积在里面的是结石。

**倪师原话精炼：**
> “肾结石也是肝郁，如同海水煮盐一样。”

### 二、为什么西医震碎取石无法根除？

倪师一针见血：
> “如果用开刀或超音波来震碎，往往都是只顾大的，仍有许多小颗粒砂状的细石在肾中，是故每年都发病，无法根除。”

因为**病因没有去掉**——肝郁还在、相火还在外泄、水液还在被煎熬，几个月或几年又会重新起来。第二次还能再开刀吗？就不能了。

### 三、本方设计的三层心法

1. **第一层——把身体的水大量导向肾脏**：这是谁的功能？**肝的升发疏泄**。把水导向肾，冲刷水道，让砂石有出路。
2. **第二层——分解石头 + 滑利下行**：用滑石、硝石之类把大石化成小石，再用滑利之药使砂石更容易排下来。
3. **第三层——止血护管**：预防石头在通过输尿管时把管壁割破造成出血。如此石头可顺利排出，**而不带血**。

### 四、上工思想：治未病，断根源

倪师强调：
> “如果懂上医治病方法的人，它不会用外科手术。如果感觉不对，还没有形成结石病因，把肝郁解决掉，把相火收藏了，还能得结石症吗？这就是上工思想。”

若已形成大石、镶嵌肾中，中医外科已失传，此时应**中西医结合**：先把大石头取出，再用中药调理，把病因去掉。

## 🎯 临床适应症与主治眼目

### 一、主治范围

- **肾结石**：腰痛、血尿、砂石排出
- **砂淋**：小便有细沙状物排出
- **石淋**：小便排出石块，或结石留积肾中
- **小便带血**：结石通过输尿管割破管壁所致
- **同症同治**：倪师原话——“本方曾用于**眼压过高**的人，同样有效，只要确定有肾结石，同症同治。”

### 二、肾结石的自我检查法（倪师亲传）

**检查位置**：每人**足踝内侧与大筋之间**，有一直径一寸的长圆形区域，即检查肾结石的穴位。

**检查方法**：
- 用拇指一点一点按压。
- **左足对应左肾，右足对应右肾**。
- 有强烈反应就是压痛点，表示有石头；没有反应就没有。
- 按压疼痛，不但可查肾结石，同时可查肾的其它病——每一个点不同的地方疼痛，代表肾这个数里面的疾病。

**倪师原话：**
> “时常检查，一有小反应，即服中药，在二三天之内即可排除。这是上工思想。”

**服药观察**：
- 反应强烈表示石头很大，必须一段时间方可排出，**不可停药**，必须等到肾石点无反应了，方可停药。
- 每次压痛点的反应可以告诉你进步的情形。

### 三、预防与禁忌

- **饮用水质**：重水、矿物质重的水，或经常吃钙片，造成体内环境水重，一旦肝气郁、相火不收，水气不能正常疏泄，**这重水最易沉淀**。
- **倪师比喻**：黄河泥沙多，容易沉淀；长江水清，流速快，不易形成沉积。
- **钙片无用**：经常吃钙片的人要注意了，肝气郁，那就得小心，得肾结石是难免的，并且钙片是没用的东西。
- **饮水习惯**：绝大多数患者都是长期服用地下水造成的；每日保持定量饮水，**喝水少的人最容易得到肾结石**。多喝茶。

## 🗣️ 倪师讲义实录与医案发挥

### 一、倪师原话精粹

> “肾结石主要看排泄是否通畅，与胆结石机理有相似地方，关键**肝的疏泄功能不通畅，造成水液杂质积聚，形成结石**。”

> “肾结石是很烦恼的问题，早期细砂时西医无法发现，必等到结石较大时，引起腰痛，或它在通过输尿管时，造成出血，在小便中发现血，才知道肾结石，但往往都是结石长得很大的时候才知道。”

> “在中医里面淋症专门有石淋的治疗，实际上就是目前所述的肾结石。”

> “此方的设计，是把身体的水大量导向肾脏，并加入一些分解石头的药，及一些止血的药。”

> “把水液排出，再化石，滑石，把石头化开变成小的，再用滑利的药，使石头更容易排下来，再用一些止血的药，这就可以把大的化成小的，然后顺利的排出。”

### 二、肾经漩涡说——倪师本门心法

倪师在讲肾经循行时特别指出：

> “流水急的时候形成一个漩涡，恰恰肾经走在这一部位，有一个一寸的长圆区域。肾为五脏藏精气，在五行中是水，从涌泉穴发出之后，走在这地方时就形成一个漩涡，就是检查肾结石的地方。”

这个漩涡区域在**足踝后方照海穴、太冲穴、水泉穴、太溪穴**等几穴围成的圆圈。

> “肾经单独这地方与其它经络都不一样，因为其它经络都是直来直往的，唯独肾经这部位要这样的走向。”

> “我问师父，师父就跟我讲漩涡的原理，这是本门的东西，外面其它地方是不会有的。”

**自然之理**：看自然界水的河流走向，最容易形成积聚的地方，一旦水泉比较干净，在漩涡里面不会形成杂质；一旦不干净，它就会形成积聚，你一按压就疼痛。

### 三、倪师对西医检查的批评

> “这地方凡是师传的纯中医都知道这样的检查办法，而现在来说很多民间的纯中医经验的检查办法，现在都不知道了，都去做 B 超看 X 光去了。”

### 四、胆结石与肾结石的类比

| 对比项 | 胆结石 | 肾结石 |
|---|---|---|
| 根本病因 | 肝郁不得疏泄 | 肝郁不得疏泄 |
| 煎熬因素 | 相火煎熬胆汁 | 相火煎熬水液 |
| 物质基础 | 胆汁不得向外正常输泄 | 水液向外排的力量不足 |
| 形成比喻 | 如同海水煮盐 | 如同海水煮盐 |
| 治疗关键 | 解肝郁、收相火、通利胆道 | 解肝郁、收相火、通利水道 |

### 五、治疗次第与预后

1. **早期**：肝郁解、相火收，可避免结石形成——上工思想。
2. **已成砂石**：中药排石，2-3天可排出。
3. **结石较大**：需一段时间方可排出，不可停药，直到肾石点无反应。
4. **结石很大、镶嵌肾中**：中西医结合，先取出大石，再中药断根。
5. **反复发作者**：病因未去，必须从肝郁、相火、水质、饮水习惯上彻底处理。
