# HT-22 奔豚汤

## 💊 汉唐方剂出处与原方配伍

**出处：** 《金匮要略·奔豚气病脉证治第八》

**奔豚汤原方：**

| 药物 | 剂量 |
|------|------|
| 甘草 | 二两 |
| 川芎 | 二两 |
| 当归 | 二两 |
| 半夏 | 四两 |
| 黄芩 | 二两 |
| 生葛 | 五两 |
| 芍药 | 二两 |
| 生姜 | 四两 |
| 甘李根白皮 | 一升 |

**煎服法：** 右九味，以水二斗，煮取五升，温服一升，日三夜一服。

**倪师加减法：** 倪海厦先生于汉唐方剂中将此方定名为 HT-22 奔豚汤，核心药物组成不变，但临证尤重白芍与葛根之用法。大枣十二枚常随证加入以护中焦。

**方义结构：**
- **当归、川芎、芍药** — 养血活血，起阴气以配阳，使肾阳有根可守
- **生葛（葛根）** — 起阴气，升提津液，使下陷之气机得以上达
- **黄芩** — 清上冲之郁热，降逆气
- **半夏、生姜** — 降逆化痰，和胃止呕，平冲气之上逆
- **甘李根白皮** — 专入肝经，降奔豚冲气之要药
- **甘草** — 缓急和中，调和诸药

## 🫀 倪师水火病机与立方心法

**奔豚之本质——气机错乱，不循常道。**

倪师明确指出，奔豚并非单纯某一脏之病，而是整体气机升降出入之秩序崩溃。其病机核心在于：**下焦浊阴之气（或水饮、或浊便、或不足之精血）不能安守于下，借惊恐引发之气机紊乱，循经上冲，冲心冲喉，发则欲死。**

**奔豚三方，三种病因，三种治法，切不可混：**

| 方剂 | 病因 | 病机 | 治法 |
|------|------|------|------|
| 桂枝加桂汤 | 冲气不走正路，从别路而冲 | 气机错乱，肝气逆乱 | 升肝气，使气机归位 |
| **奔豚汤（HT-22）** | 精气血不足，不足以守肾阳 | 肾阳无根，逆冲而上 | 养血起阴以配阳，降逆平冲 |
| 茯苓桂枝甘草大枣汤 | 脐下有邪饮，阻碍气机升发 | 水饮积聚，借路而冲 | 去水饮，运脾阳 |

**倪师精解奔豚汤立方心法：**

此方的根本逻辑是——**精气血不足，肾阳无根，则下焦之气不能安守，一遇惊恐，气机逆乱，肾阳之气便脱根上冲。** 所以治法是“**养血起阴以配阳**”。

- 用**当归、川芎、芍药**养血补血，把精血填足，使肾阳有根可守，不再脱根上冲——这是“起阴以配阳”的核心。
- 用**葛根**起阴气，升提津液，使下陷之气机恢复正常升降。
- 用**黄芩**清上冲之郁热，降逆气。
- 用**半夏、生姜**降逆化痰，平冲气之上逆。
- 用**甘李根白皮**专降奔豚冲气。
- 用**甘草**缓急和中。

**倪师特别强调：绝不可用下法！** 仲景治奔豚三方，一个下法都没有。奔豚是气机错乱，不是实邪结聚，用下法则更伤正气，气机更乱。

**白芍之妙用：** 倪师极为推崇白芍。白芍一味，既能去毒气、排大便、去积聚，又能敛相火、攻其坚。奔豚汤中用白芍，桂枝加桂汤中亦用白芍，其功在于使气机正常归位，理肝升肝的同时护心气，守住肾精，使相火归位。

## 🎯 临床适应症与主治眼目

**核心主治：**

1. **奔豚气上冲胸，腹痛，往来寒热** — 气从少腹起，上冲咽喉，经过心，发作欲死，复还止。
2. **右腹动悸不止，同时心跳加速，无法控制** — 倪师明确指出此为奔豚汤的典型表现。
3. **情绪不稳定，去西医检查又不是心脏病** — 左也不是右也不是，完全不知道怎么回事。
4. **长期便秘又受到惊吓** — 大便阻塞大肠，产生浊气，受惊后气机乱行，浊气顺经络上冲于心、上冲于喉。

**辨证眼目：**

- **发病特点：** 从少腹/脐周围而起，上冲咽喉，经过心，发则欲死，复还止。
- **诱因：** 皆从惊恐得之。倪师强调：奔豚之症都有惊恐，这两点是关键。
- **兼证：** 往来寒热，腹痛，右腹动悸，心跳加速，情绪不稳。
- **西医误诊：** 心电图检查常被认为是心脏病、心律不齐、脉跳过速，实则非心脏本病。
- **便秘史：** 倪师指出，此病多长期便秘又受惊吓造成。大便阻塞大肠，浊气产生，受惊则气机乱行，浊气顺经络上冲。

**鉴别诊断：**

- 若浊气到脑部，不一定发于奔豚之症，可能出现神精恍惚——此时需用桃核承气汤直接去浊。
- 若脐下悸，欲作奔豚，为水饮在下——用茯苓桂枝甘草大枣汤。
- 若冲气不走正路，从别路而冲——用桂枝加桂汤。

## 🗣️ 倪师讲义实录与医案发挥

**倪师原文实录：**

> 此方的使用很特殊，症状也特别，病人呈现右腹动悸不止，同时心跳加速，无法控制，情绪也不稳定，去给西医检查又不是心脏病，因此左也不是右也不是，完全不知道怎么回事。

> 实际上此病是长期便秘又受到惊吓造成的，由于大便阻塞在大肠中，产生浊气，受到惊吓，则气机乱行。浊气一升，气机就乱。浊气亦会顺着经络乱行，一乱行，则会上冲于心上冲于喉部，那就是奔豚之气。

> 如果没有便秘，若腹部浊气多，受惊吓也容易出现奔豚之症。也不是说得奔豚症的全是因为便秘，但是说得奔豚之症的都有惊恐。

> 由于大便阻塞在大肠中，此时突然受到惊吓，造成肠子紧缩，以致大便浊气自肠而出，顺延肝脏进入心脏，此时心脏受到不应有的浊气攻击，因而产生自然反抗反应，心脏加速的目的是在排除逆流入心的大便浊气，因而出现右腹动悸不止，同时心跳加速的症状。

**倪师医案发挥：**

> 这两天我刚接诊一病人，四十岁左右，也有奔豚气，气机发生时候，从腹部上冲于咽喉，压迫自己的脖子很难受，需要喝水压压，过一会才平息。这个人是一个矿业主，开矿的，做这幺多年来，脾气容易激动，碰到的事情也比较多，有时候一惊一乍的。他问我是怎么回事，我说都是你的脾气性情造成的，病从惊恐而得。他就回想这几年，说若干年的经历都是在这状况下，所以有得奔豚症。

**倪师用药规律总结：**

> 这就是仲圣的用药规律，里面有很深的道理在这个后面。它不是说随随便便的药物可以用上的，都有道理在里面的。

> 奔豚汤就是因此而来的，此药能消除大便浊气，同时排浊。

> 在这个里面，向大家推荐一味药：白芍。这味药我特别喜欢用，一方面它去毒气，可以排大便，去积聚还可以敛其相火攻其坚，它都可以。一定要注意不能直接用下法，以观仲景的治疗奔豚的三个方剂，一个下法都没有，不能直接用下法，排其浊气或排水饮气，里面主要的要用白芍，奔豚汤里要用它，桂枝加桂汤里也要用它，同时可使气机正常归位，也就是理肝升肝还要护心气，另外一个便是守住其肾精，使相火归位。

**倪师关于苓桂剂与白术、茯苓之辨析：**

> 我们看苓桂术甘汤，它是治疗什幺的药？治水气凌心的。治疗上面的。苓桂姜枣汤是治疗下部的。为什幺会这样？为什幺里面会少一个白术？白术本来是运化脾阳的而去水湿之气，但是下面出现脐下悸，水饮在下。在下者而为阴，在上者为阳，在下者这一个饮气要重，属于是阴比较重。里面关键要用到茯苓去其邪，邪气去后其脾气自运。如果是立即去运化，脾的中气就会相激。所以说一般水饮在少腹的时候，在脐下的时候，就要用白术。其水饮在上位，因为它属于阳之地带，用到白术去运化其脾阳，脾阳运则其水湿之气自然可以化掉。

> 也就是什幺时候该用白术，什幺时间该用茯苓，什幺时间两种同时用，就可以比较的清楚了。

**倪师结语：**

> 这种情况可治奔豚之证，大家在临床上比较少一点，基本上没遇到奔豚这种证。这证发作起来是比较厉害的，很难受。
