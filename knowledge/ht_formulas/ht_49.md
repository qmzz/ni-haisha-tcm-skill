# HT-49 起阳丸(振奋阳气, 生精) VS 威而刚

## 💊 汉唐方剂出处与原方配伍

**出处：** 汉唐方剂系列第四十九号，名“起阳丸”，又名“振奋阳气，生精丸”。倪海厦医师于2006年12月4日讲授，孟磊录校。本方沿用千年，自古为帝王宫廷所秘用，倪师称“古时唯帝王可享用”，本方与汉唐-38（女科方）互为男女阴阳之对。

**方义核心：** 起阳丸的设计，在于加强“阳”的功能（生足量之精）与“阴”的功能（心、肝之活力），同时并进，再配合一些无毒的刺激性欲之药，合制而成。

**主要配伍药物与抓手：**

- **肉苁蓉**：本方兴阳之核心药。倪师原文明确指出：“肉苁蓉长在新疆沙漠中，形状如男之阴器，它为马精之所化生……治疗的阳萎情况效果特别好，就比VIAGRA好。”此药生于沙漠，禀赋极强之生发阳气，其形似阴器，以形入形，直达宗筋。
- **桂枝**：升肝木，启升发之机。倪师言“凡一切升发之象是肝所主”，桂枝为方中引动肝气、升达生发之力的关键。
- **强心之品**：心主血，血不至则阴茎不振奋。方中必具强心阳之药，令心火下达，血脉贲张，宗筋得充。
- **增小肠吸收之品**：生精第一步，必须加强小肠之吸收能力，迅速将营养升提到心脏。小肠为精宫所在之处，小肠热力足则精宫得温。
- **疏肝解郁之品**：肝主筋，前阴为宗筋所聚。肝气郁则精虫减少，肝动则全身血脉贲张，睾丸中充满压力，精虫乃生。
- **无毒刺激性欲之药**：配合少量无毒之品，引动欲念，但绝不如伟哥之一味充血。

**注意：** 倪师原文中未逐一列全方药味剂量，核心药为肉苁蓉，辅以桂枝升肝、强心之品、助小肠之品，合而成方。倪师强调“本门中内景论述深的地方和倪海厦是有差别，但治的办法很相似”，说明此方在传承中内景叙说略有差异，但用药法度一致。

**服用条件（倪师原定三条件）：**
1. 年纪在40岁以上。
2. 特殊而需要之病人，由本院医师针对使用。
3. 符合节欲要求，不可恣情纵欲。

**禁忌：** 心脏病及高血压病患不可服用。倪师原文：“如只是令阳具勃起（阴亢）而无精出，会造成不正常之充血，以致心脏不胜负荷，故有心脏病及高血压病患不可服用，否则极易引发心脏病。”


## 🫀 倪师水火病机与立方心法

**一、阳萎之根本：五脏皆须参与，非一脏之病**

倪师直斥西医完全不懂壮阳。男子阳气能起，进行正常房事，五脏都要在里面起到作用：
- **心主血**：血若不至，则阴茎不会振奋。心火不下达，宗筋无血以充。
- **气不至则不会变热**：气机不到，则局部不热，阳具无法振奋。
- **肝主筋**：前阴为宗筋所聚，肝气郁则筋萎。
- **肾藏精气**：肾为五脏而藏精气，肾精不足则根本动摇。
- **小肠为精宫**：精生成于精宫之中，此组织在小肠及膀胱间。

倪师一语中的：“如果出现阳萎的，这个气机起不来，临房事时出现萎软，这种情况，肯定是气之不至，心神怯弱，而其最根本的原因就在于人身体的精气，就是五脏共同。”阳萎绝非单一“肾虚”，而是五脏协同失灵。

**二、伟哥之谬：只通血脉，不生精，阴阳俱伤**

倪师指出：伟哥本身开发是治疗心脏病的，无意中发现对阳萎有作用，然后就全部变成壮阳药了。但“伟哥根本不懂壮阳如何保护身体精气，只是一个通血脉的药”。它“不能令人产生大量精子，只一味的刺激局部充血，故造成心脏负荷过重，导致心脏病发”。倪师称之为“性促死，如同贾瑞，最后精气一泻如注然后死掉”。

**三、起阳丸之立方心法：阴阳双补，生精为本**

倪师立起阳丸，底层逻辑为：
1. **生精的过程，首须加强小肠之吸收能力**，并迅速将营养升提到心脏。
2. **再藉由肺脏的吸气，使命门火加大**；肺脏的吐气，令精血下行，进入精宫。
3. **先天元阳与精血（阴）互相结合，进入睾丸**。全身上下只有肝经入睾丸，肝主司动，令全身血脉贲张，睾丸中充满压力。
4. **此时压力与动能的结合，精虫乃生**。
5. **性行为达到高潮时，即会喷出热且浓的精液**。

**四、精之浓淡与热度，关乎五脏**

- 有人精中带血，即小肠热与命门火不足。
- 有人精液极稀，精虫很少，即是肝脏动能不强造成。
- 有肝炎的病人，容易气郁的小性子男人，这种情况都很容易使精子减少。

倪师强调：“如果不把肝炎当成病，保持心脏愉快，精虫自然生出来。”此即“精为阳，血为阴，二者必须要相辅相成，方可奏效”。

**五、精之管道与大脑：记忆与生精同源**

人体只有两个管道直通大脑：
- **其一，由肝入心，再入脑**（参汉唐-68）。
- **其二，即为精之管道**。精生成于精宫之中，其源为血，食物营养被小肠吸收之后即为血之源头，由脾脏导引进入心脏，由于心脏极热，蒸化的营养为血之本色，残渣排出，即为男人的胡须。

此精华会顺脊髓（中医的督脉）而上达脑部，此一管道主司记忆。年轻人记忆好，就因为此管道很强；老年人记忆减弱，即因此管道退化。故起阳丸“不但能加强性欲，更且能加强记忆，预防老人痴呆症”。

**六、男人亦有“日经”**

倪师原文：“也就是说男人也有月经的，但是是每天在排，故可以说成为日经。如果此残渣反逆进入骨髓，就造成男人得到血癌。”真正的精华则由冲脉下达少腹，此际在两肾之间，名为命门所在，因受人的呼吸作用，大量的氧在此燃烧（中医称为命门火），其产生的热能与真水进入精宫，血液之精华到此与之会合，于是生成精子。

**七、起阳丸与伟哥之根本区别**

| | 起阳丸 | 伟哥 |
|---|---|---|
| 作用机理 | 阴阳双补，生精为本，令阴阳平衡 | 只通血脉，刺激海棉组织充血 |
| 生精 | 生足量之精 | 不能令人产生大量精子 |
| 记忆 | 加强记忆，预防老人痴呆 | 无 |
| 安全性 | 千年沿用，无人服之丧命 | 已发现数人死亡案例 |
| 心脏负荷 | 无 | 负荷过重，导致心脏病发 |


## 🎯 临床适应症与主治眼目

**主治核心：** 男性阳萎，阳气不振，生精不足。倪师原文：“治疗男性疾病的，包括阳萎，主要治疗阳气生精。”

**适应症：**
1. **阳萎、性功能低下**：临房事时出现萎软，气机起不来，心神怯弱。
2. **长期服西药导致阳萎**：长期服抗生素、止痛剂、降血压、降血糖等控制性药物，伤及肝肾，肝主筋，前阴为宗筋所聚，肾为五脏而藏精气，必然造成性功能丧失。
3. **精液稀薄、精虫减少**：肝脏动能不强，或肝炎病人气郁，精虫自然减少。
4. **精中带血**：小肠热与命门火不足。
5. **记忆力减退、预防老人痴呆**：精之管道顺督脉上达脑部，主司记忆，起阳丸强此管道。
6. **中年以后体力衰退、需振奋阳气者**：40岁以上，身体机能下降，阳气不足。

**眼目抓手：**
- 阳萎 + 长期服西药史 → 伤及肝肾，宗筋失养。
- 阳萎 + 精液稀薄 → 肝动能不强，小肠吸收力弱。
- 阳萎 + 精中带血 → 小肠热与命门火不足。
- 阳萎 + 记忆力减退 → 精之管道（督脉）退化。
- 阳萎 + 肝炎、气郁 → 肝不主筋，精虫减少。

**倪师特别警告：**
- 服用此药可以，但“如果不注意节欲，精液大量流失，记忆力自然减退”。
- “房中事，既可生人亦可杀人，千万要注意。”
- “学院中没结婚的男孩，要特别注意惜精。”
- “治疗伤精的疾病，不是想当然壮阳用姜附药能治好……一旦服药后看身体反应，不是排病反应，而是精气都将烧干了，注意不要随便乱吃药。”


## 🗣️ 倪师讲义实录与医案发挥

**一、倪师痛斥时弊**

倪师开篇即言：“早年中医在提倡壮阳、补肾，中国人不断的在骂，中医只会搞这一套。一个半月前，美国上市了VIAGRA，而人人却趋之若骛，有人已经吃后引发心脏病而死亡。这显现了几个问题：”

1. 西医完全不知如何安全的来壮阳。
2. 以前完全没有药物可协助，只有很多药物会使人阳萎。
3. FDA尚未完全明了其功能及副作用，就核准其上市，表示FDA也在保护西药厂，罔顾百姓生命。
4. 百姓们长期受控于药物，滥用药物，例如抗生素、止痛剂、降血压、降血糖等，举凡控制性药物及杀细菌及病毒之药物，其它副作用先不提，光是对性功能而言，就造成极大伤害，大多数人丧失性功能，故对此药物有强烈需求，甚至于冒生命危险也在所不惜。“这属于好色不惜命。”

倪师言：“百姓是无知的，他们之所以相信西医，是被一些高科技的仪器、验血报告所迷惑，以为西医什么都知道，中医什么都不知，因此而盲从。其实百姓有所不知，到目前为止，西医连人体的精子，及性功能都一概不知！”

**二、倪师亲治医案：糖尿病十五年阳萎案**

> 患者五十三岁，糖尿病十五年，人不错，一直用西药控制血糖。很多年前，就出现阳萎现象，性功能不行了。同时，身上稍碰就立即出现紫癜，长久不愈。然后到我这，降糖药基本上是没法控制了，吃了降糖药也是高。
>
> 这人服药服了将近一年，我停药时血糖在十二点多，我说你的身体正常了，你的身体由于这么长时间服用降糖药，说明你的身体就适合于血糖比较高，绝对什么事也没有，一直到现在经常到我这玩。
>
> 自从治疗后，性功能马上起来了，如同年轻人一样，每天早晨晨勃，身体体力好。他做煤炭生意，找不到人他就自己装卸车，是把煤炭倒到另一地方。曾经有一次他自己搞了二十吨，当天晚上很累，休息一夜，第二天就很正常了。他说他现在的体质已经回到三十多岁的体质，全身没不舒服的地方，除了检查说血糖十二点多，不再信他们了，血糖就这么高。
>
> 有几个小伙子三十多，跟他一起干活干不过他，身体要是碰出伤口，几天就可结痂长成。按西医说高血糖是不会这么快长成的，而他止血后几天就结疤正常，这说明什么问题？性功能的问题，我说是吃降糖药吃出来的。现在他身体很好了，今年五十四岁了，感觉如同三十多岁的小伙子一样。
>
> 什么叫治病？这就叫治病，不是血糖降到正常，降到正常则人连半条命都不存在了。

**倪师按：** 此案关键在“性功能的问题，我说是吃降糖药吃出来的”。降糖药伤肝肾，肝主筋，前阴为宗筋所聚，肾为五脏而藏精气，此必然之因果。停药后，身体恢复自我调节，性功能自然恢复。倪师强调“什么叫治病？这就叫治病”，直指西医指标迷思之荒谬。

**三、倪师论“精满自溢”与房中术**

倪师言：“男子青春期刚发育时，或要去断除欲望出家的人，平时也无性的刺激，也会出现精满自溢的现象，说明，精是时刻向外升发的。只要掌握住练精化气，这时候才可以不射精，这个包括中医里面，有这一个房中术，它属于养生范围，与我们学治病是两条道，不要去精研它。”

**四、倪师论内景之传承**

倪师言：“看人的内景是比较有意思的。首先来说，我给大家提示，肾是两枚不是一个？肺是两个不是一个？为什么两肾间有小心，而两肺间要夹一个心脏，这都是内景，不是随便出来的……这要经过师传的，不是你随便瞎想出来的。既然人在天地中，天地生人，必然要符合大道的规律，不是随便出来的。没事的时候不要进行瞎想，内景的东西多，我很害怕你们想内景的东西，一走偏就是外道了。一定要注意。”

**五、倪师论伤精之治**

倪师于2006年12月4日B段讲授中特别强调：“现在社会伤精疾病太多太多，治疗伤精的疾病，不是想当然壮阳用姜附药能治好。这么多伤精病人，一旦服药后看身体反应，不是排病反应，而是精气都将烧干了，注意不要随便乱吃药。如果能通过心里对这方面正确认识，因为毕竟是年轻人，精气补充的比较快，根本不用药，就可以治疗伤精疾病。”

**六、倪师自服六十四味肾气丸**

倪师原文末尾提及：“今天的时候，没事我配药丸，我配的是六十四味肾气丸，我服用了一丸，效果很不错。”此虽非起阳丸本体，但可见倪师对丸剂缓图、阴阳双补之思路一贯。

**七、总结：起阳丸之历史地位**

倪师言：“起阳丸，其使用在中国历代王朝之君主，千年而不衰，主因是中医完全了解男人的生殖过程，欲望之源。……本品沿用千年，尚无人服之丧命，古时唯帝王可享用，本院本不愿出售在市场上，免得造成一些社会问题，只由本院医师，针对一些特殊而需要之病人使用。由于效果良佳，且无副作用，许多病人争相购买。”

**倪师最终叮嘱：** “服用这样的药可以，如果不注意节欲，精液大量流失，记忆力自然减退。”房中事，既可生人亦可杀人，千万要注意。
