# HT-45 己椒苈黄丸

## 💊 汉唐方剂出处与原方配伍

**出处：** 《金匮要略·痰饮咳嗽病脉证并治》——"腹满，口舌干燥，肠间有水气，己椒苈黄丸主之。"

**原方配伍：**

| 药物 | 角色 |
|------|------|
| 防己 | 通利水道，走而不守，专泻肠间积水 |
| 椒目 | 降气行水，辛烈走窜，专攻水饮停聚 |
| 葶苈子 | 破坚逐水，泻肺利肠，攻坚消胀 |
| 大黄 | 荡涤肠腑，推陈致新，引燥粪下行 |

**倪师特殊用法——必须配合芒硝汤合服：** 芒硝润肠调津，软坚散结，单用此丸不配芒硝汤，效果不显。服后排出如**片状大便**，同时大量水液随之而出。

**禁忌：** 须经医师处方。不对症使用，仅下利较多，停药即止。

## 🫀 倪师水火病机与立方心法

**核心病机：水燥两极，肠间割据。**

此方的底层逻辑，倪师讲得极透彻——**肠间有水气，大便不出**，这不是单纯的水饮，也不是单纯的便秘，而是**水与燥在肠道中分成两极**：

- **一极：** 水饮之气全聚积于升结肠至平结肠（肝下）部位，形成局部积水，按之碌碌有声，甚至有气块痞块，推之可走，按之可移。
- **一极：** 肠道下半部分因水气偏聚而**干燥**，大便硬结不出。

这就是**燥湿并存、水热互结**的格局。水不在它该在的地方，燥不在它该燥的程度。水饮聚而成实，阻塞气机，肠道传导失司。

**为什么属实证？** 倪师用阴阳法眼看：**拒按为实**。至者为阳，去者为阴，病人拒按，里面必有实邪。实邪盘踞，气机不通，故痛而拒按。

**立方心法：**

- **防己、椒目**——一升一降，把停聚的水饮从肠道分消走泄。
- **葶苈子**——泻肺气以通调水道，肺与大肠相表里，肺气降则肠气通。
- **大黄**——直捣燥结，推陈致新。
- **芒硝汤送服**——润肠软坚，调津液，使燥粪得下、水饮得排。

此方的本质，就是**给肠间的水燥两极同时开一条出路**：水从水道走，燥从谷道出。浊粪一出，胀气退，水肿消，黄疸退，小便通，体力自复。

## 🎯 临床适应症与主治眼目

**主治眼目（抓主证）：**

1. **右腹胀满**——固定于升结肠至肝下区域
2. **肠间有水气**——肠鸣水声，碌碌作响，有时气鸣声，会跑动
3. **大便不出**——肠道下半部干燥，燥粪内结
4. **右腹可触及痞块**——用力按之可推可走，按时有水鸣或气鸣
5. **口舌干燥**——水聚于肠，津不上承
6. **腹满**——气机壅塞

**兼见症：** 肝气虚者常成夜睡不着觉，但西医检查一切正常，B超看不到气块痞块（因为那是气与水饮，非实体肿瘤）。

**倪师加减法：** 若兼有肝炎、肝病、伤精，右腹出现痞块（升结肠部位），按之可推可走，用力按有水鸣气鸣——**大柴胡汤合己椒苈黄丸**。

**关键鉴别：** 此症西医查不出病，病人却极其不舒服。倪师直言——不要管病名，名相全是假的。要从病因病机病症去分析。西医每年造出新病名，多是乱用药治出的坏症，再重新命名，不承认自己的过失。

## 🗣️ 倪师讲义实录与医案发挥

**倪师原话实录：**

> "光是此45号，如此简单的处方就有超过95%以上的中医不知道如何使用它，中医处境如此，实在堪虞。很多中医不识此症，又不敢用芒硝，试问又如何能治好此病呢？此症又是很常见的，中医之所以让人诟病，就是庸医太多。如果你能找到很优秀的中医，其治病效果是立竿见影的。"

> "病人服后会排出如片状的大便，而且有大量水一起排出。当浊粪一出，胀气退，水肿消，黄疸退，小便出，病人体力就会恢复过来。"

**临床医案发挥：**

倪师曾治此类患者，右腹出现痞块，在升结肠部位，按之可推可走，用力按有水鸣气鸣声。病人肝气虚，常年成夜睡不着觉，但西医检查任何病都没有。B超看不到气疙瘩，因为那是气与水饮，非实体。

**处方思路：** 大柴胡汤合己椒苈黄丸。倪师强调——只要能认识此病，会分析就能治。不要被病名困住，名相全是假的东西，要认识到里面的真实。

**倪师对中医现状的感慨：**

> "现在的很多病能够到达你中医手里面，这病人死的差不多了，也就是说死了七八分。一方面要补精气，一方面要去邪气，忙得焦头烂额，甚至有的病你还救不过来。"

> "有的病人到我这儿看病，说中药还要熬，回家熬药好麻烦。麻烦就不要来吃我的中药！不熬药来我这儿治什么病？这不是捣乱吗？这是病人自己造的因，然后必定食其果。"

> "我们看仲圣，该是汤药就是汤药，该是丸药就是丸药。有的时候把汤变成丸，有的时候把丸变成汤。比如理中丸，仲圣可以把它改成理中汤。丸不及汤，该用什么的时候就要用到什么。想懒省事，实际上是自己在造自己的因。"

**精微要义：** 此方之妙，在于**水燥分治**——不单纯利水，不单纯通便，而是同时解决水饮停聚与肠燥便结的两极格局。配合芒硝汤，才能达到排出片状大便与大量水液的效果。浊粪一出，诸症悉退。此乃经方之精微，非明阴阳法眼者不能识。
