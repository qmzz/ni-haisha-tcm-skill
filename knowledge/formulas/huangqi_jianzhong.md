# 黄芪建中汤

## 📜 经方出处与原方配比

**《金匮要略·血痹虚劳病脉证并治第六》原文：**

> 虚劳里急，诸不足，黄芪建中汤主之。

**原方组成（即小建中汤内加黄芪一两半，余依上法）：**

| 药物 | 汉制剂量 | 现代换算参考 |
|------|----------|--------------|
| 黄芪 | 一两半 | 4.5g～5g |
| 桂枝 | 三两 | 9g |
| 芍药 | 六两 | 18g |
| 炙甘草 | 二两 | 6g |
| 生姜 | 三两 | 9g |
| 大枣 | 十二枚 | 十二枚（掰开） |
| 胶饴（麦芽糖） | 一升 | 约200ml |

**倪师特殊加减法（原文紧随方后）：**
- 若气短胸满者——加生姜
- 腹满者——去枣加茯苓一两半
- 及疗肺虚损不足，补气——加半夏三两

**煎服法：** 上六味，以水七升，煮取三升，去滓，内胶饴，更上微火消解，温服一升，日三服。**呕家不可用建中汤，以甜故也。**


## 🫀 倪师核心病机与水火气化

倪师讲得很干脆：**“虚劳里急，诸不足”——这六个字就是黄芪建中汤的全部眼目。** 小建中汤证也有“虚劳里急”，那为什么还要搞个黄芪建中汤出来？关键就在“诸不足”这三个字，以及那一味黄芪。

**一、黄芪补气，人参养阴——这是天大的分别**

倪师原话讲得极清楚：

> “那黄芪跟人参不一样，人参呢我一再跟诸位讲，人参张仲景的观念里面是要养胃阴，因为肠胃的津液不够了，所以我们过去用独参汤……那黄芪呢，真正补气不是人参啊，是黄芪在补气啊，所以我们有气虚和血虚两种虚劳。”

所以诸位要搞清楚：**人参是救胃阴的，是肠胃津液干枯、吃啥吐啥的时候，单独一味人参下去救胃气的；而黄芪才是真正走表、走肌肉、走四肢、补“气”这味药。** 人虚劳了，如果偏于气虚——走两步就喘、四肢没劲、肌肉消削、也就是所谓“诸不足”——那黄芪就要上去。

**二、中焦虚寒，木气横逆——里急的根子**

小建中汤的底子是什么？桂枝汤加芍药加倍再加胶饴。倪师讲芍药的时候点得很透：

> “当你发现到病人的静脉血液循环不好的时候，你都可以用芍药，重用芍药……像腹部的阴，少腹是阴，还有女人的静脉瘤……”

建中汤里面芍药用到六两，是桂枝的两倍。为什么？**中焦虚寒之后，肝木之气失去土气的镇守，横逆克脾，于是就“里急”——肚子抽紧、隐隐作痛、甚至腹皮拘挛。** 芍药重用，就是要把静脉的血往回拉、把拘急的筋脉松开。桂枝走动脉、芍药走静脉，一阴一阳，一出表一入里，配合起来让中焦的气血循环恢复。

**三、黄芪建中汤的“水火气化”到底在哪**

倪师讲经方从来不讲空泛的“君臣佐使”填表，他讲的是实实在在的生理：

- **心阳不足，小肠火衰** → 中焦得不到下焦命门火和心阳的温煦，消化无力，停水内生。
- **脾阳不运，水停中膈** → 所以原文讲“气短胸满者加生姜”，倪师解释得生动：“这个生姜本身的功能是去肠胃里面的水……胃里面有停水，这个时候胸腔里呼吸的时候，气没有办法下去，因为水停在中隔，它会反逆，这个时候用生姜，加重，重用生姜。”
- **下焦虚寒，少腹拘急** → 芍药加倍，就是要把下焦阴分（少腹属阴）的拘急解开。
- **“诸不足”不是单一脏虚，是气血阴阳全部不够用** → 黄芪补气走表，桂枝汤调和阴阳，胶饴建中补脾精，芍药通静脉，生姜散胃中停水，大枣补脾胃津液。合在一起，**中焦这个“土”一转起来，水火才能交济，心火才能下降、肾水才能上升。** 这就是建中汤系列的灵魂。

倪师讲得很直白：仲景的书“言简刚重”，几句话就讲完了，但里面藏的是整个气化循环的机关。黄芪建中汤比小建中汤多一味黄芪，等于在“重建中焦”的同时，再加一把力把“气”推到肌表四肢去——**所以虚劳的人如果兼有肌肉消瘦、四肢无力、自汗、容易感冒，这就是黄芪建中汤证，小建中汤力量就不够了。**


## 🎯 临证眼目与方证相应

**一、抓主证（问诊时怎么抓）**

| 问诊抓手 | 黄芪建中汤证的表现 |
|----------|-------------------|
| 精神体力 | 虚劳久倦，四肢无力，动则气短 |
| 腹痛特征 | 腹中拘急、隐隐作痛，喜温喜按，按之舒适 |
| 寒热感觉 | 畏寒怕冷，手足不温，但不至于四逆（四逆是附子证） |
| 出汗 | 容易自汗、动辄汗出，汗后畏寒加重 |
| 面色 | 面色苍白或萎黄，肌肉消削 |
| 二便 | 小便清长，大便或溏或正常，无热利 |
| 口渴 | 不渴，或喜热饮，口中和 |
| 脚温 | 脚是温的或稍凉——若脚冰冷到膝盖，那是附子证，不是单靠黄芪建中能解决 |

**二、核心鉴别点**

倪师一再强调：“虚劳里急，诸不足”——这六个字里面，“**里急**”是白芍重用的依据，“**诸不足**”是黄芪加入的依据。

- 如果只是腹痛拘急、心悸、虚烦，偏中焦阴阳两虚——**小建中汤**足矣。
- 如果在此基础上，**兼有气虚明显——短气、自汗、四肢倦怠、肌肉消瘦、易感外邪**——才用**黄芪建中汤**。

**三、关键加减法（依原文和倪师讲解）**

1. **气短胸满者加生姜**——胃中有停水，水停中膈，气下不去，重用生姜散水。倪师说得很明白：“重用生姜。”
2. **腹满者去枣加茯苓一两半**——肚子胀满，脾主少腹，大枣甜腻碍脾，去了；加茯苓把中焦的水利掉，腹满自消。
3. **疗肺虚损不足，补气加半夏三两**——肺虚损、气不足，加半夏。这里倪师虽然没有展开讲，但半夏降逆、化痰、通阴阳，肺气虚损往往伴随痰饮内停，半夏能把肺胃的逆气降下来。
4. **呕家不可用建中汤**——倪师特别提醒：呕家不可用，因为“以甜故也”，胶饴太甜，呕家胃中已有热或停饮，甜的东西下去助湿生呕。

**四、相似经方鉴别要诀**

| 经方 | 核心鉴别点 |
|------|-----------|
| **小建中汤** | 虚劳里急，腹中痛，悸、衄、梦遗、四肢酸疼，偏中焦阴阳两虚，无显著气虚 |
| **黄芪建中汤** | 小建中汤证 + 气虚明显（短气、自汗、肌肉消削、四肢无力、易感风邪） |
| **桂枝加芍药汤** | 太阳病误下后腹满时痛，无“虚劳”的底子，纯是表证误下、邪陷太阴 |
| **桂枝加大黄汤** | 桂枝加芍药汤证 + 大实痛（拒按、便秘），有实邪 |
| **理中汤/附子理中汤** | 太阴脾虚寒，以吐利、腹满、不渴为主，无“里急”的拘挛感，无人参养阴的层次 |
| **四逆汤** | 下利清谷、四肢厥逆、脉微欲绝，少阴真阳虚衰，要救逆回阳，非建中可比 |
| **薯蓣丸** | 虚劳诸不足，风气百疾，方证更杂更虚，以薯蓣（山药）为君，气血阴阳并补 |


## 🗣️ 倪师讲义实录与医案精粹

**一、倪师讲“黄芪补气，人参养阴”的原话实录**

> “那黄芪跟人参不一样，人参呢我一再跟诸位讲，人参张仲景的观念里面是要养胃阴，因为肠胃的津液不够了，所以我们过去用独参汤。你说用独参汤来救逆，救什么逆啊？救胃气没有的逆。这个人已经吃不下东西了，吃东西都吐，吐就是独参，单独的人参下去，独参汤！那黄芪呢，真正补气不是人参啊，是黄芪在补气啊，所以我们有气虚和血虚两种虚劳。”

这段话诸位要反复琢磨。**临床上看到虚劳的病人，先把“气虚”和“血虚”分开。** 气虚的，短气、自汗、四肢无力、肌肉消削——黄芪建中汤；血虚的，面色苍白、唇爪色淡、心悸失眠——那是另外的路子（比如酸枣仁汤、薯蓣丸之类）。搞错了方向，人参下去反而碍事。

**二、倪师讲“气短胸满加生姜”的生理机制**

> “若气短胸满者加生姜，为什么会气短胸满？这个生姜呢本身的功能是去肠胃里面的水，胃里面的水。如果这个人虚劳的时候，胃的消化不好吗，胃里面有停水。这个时候呢，这个人胸腔里呼吸的时候，气没有办法下去，因为水停在中隔，它会反逆，这个时候用生姜，加重，重用生姜。”

倪师讲生理病理从来不用“气机升降失调”这种空话，他直接告诉你：**胃里有停水，水停在中膈，呼吸的时候气下不去，反逆上来，所以气短胸满。** 生姜就是去这个停水的。所以看到虚劳的病人又有气短胸满，生姜要重用，把中膈的水散开，气自然就下去了。

**三、倪师讲“腹满者去枣加茯苓”**

> “如果腹满者去枣加茯苓，肚子胀满，腹部是什么，是脾脏，脾主少腹。”

很简单，大枣甜而壅滞，腹已经满了，再吃大枣更胀，去了。加茯苓，把脾脏周围的水湿从小便利掉，腹满就消了。**这就是经方的精妙——一味药的出入，整个方子的方向就变了。**

**四、倪师讲芍药与静脉循环（黄芪建中汤中白芍六两的深意）**

> “当你发现到病人的静脉血液循环不好的时候，你都可以用芍药，重用芍药……所以比如你看到一个人，两个人在一起，这个病人呢这个疮是凸出来的，凸到外面来的疮很简单，那个疮是陷下去的很危险，陷下去的你第一个要想到什么？想到芍药，这就是阴和阳的观念。”

倪师用“疮凸出来”和“疮陷下去”来比喻阴阳——**凸出来是阳，陷下去是阴。** 黄芪建中汤里面芍药用到六两，就是在处理“阴”的层面——静脉血回流不畅、少腹拘急、腹部静脉曲张、甚至女人静脉瘤，这些都是“阴”的问题，都要重用芍药。黄芪建中汤用芍药六两，比桂枝多一倍，就是在**建中焦的同时，把阴分的拘急和瘀滞打开。**

**五、煎服法与瞑眩反应**

**特殊煎服法：**
- 大枣要**掰开**，不然药力出不来。
- 胶饴（麦芽糖）要**在药煮好去滓之后，纳入药液中，微火消解**——不能跟其他药一起煮，否则黏锅、药性也变了。
- 温服一升，**日三服**。

**服药后的排病反应（倪师常提到的建中汤类方反应）：**
- **腹中雷鸣**——中焦阳气恢复，水气开始运化，肚子里咕噜咕噜响。
- **矢气增多**——气机开始通畅，浊气下行。
- **微汗出**——营卫开始调和，但不应该是大汗。如果大汗淋漓，那说明桂枝量过了或者病人阳虚不固，要调整。
- **小便清长**——中焦运化恢复，水湿从小便排走（尤其是加了茯苓之后）。
- **腹痛渐渐缓解，腹皮拘急感松开**——这是白芍和胶饴共同作用的结果。

**六、倪师临证心法——“浑然天成”的处方境界**

> “当你心领神会的时候，像这种处方，像脸上生个血管瘤出来，处方马上就开出来，根本就不用想就出来了。所以我希望诸位能做到一点就是：将来你们不但能够设计处方，不但经方能够很熟练以外，而且可以设计处方，然后你的处方是浑然天成的，很简单，一下就把他病去掉了，这是最高的境界。”

倪师这段话虽然是讲芍药的运用，但用在黄芪建中汤上完全契合。**当你真正理解了“中焦一虚，木气横逆，气虚于表，里急于腹”这个病机，看到虚劳里急、诸不足的病人，黄芪建中汤自然就出来了，根本不用背。** 这就是倪师要我们达到的境界——不是死记方剂，而是看到病机，方子自己就跳出来了。
