# 桃花汤

## 📜 经方出处与原方配比

《伤寒论·辨少阴病脉证并治》：

> **「少阴病，下利便脓血者，桃花汤主之。」**
>
> **「少阴病，二三日至四五日，腹痛，小便不利，下利不止，便脓血者，桃花汤主之。」**

**原方：**

- 赤石脂 一斤（一半全用，一半筛末）
- 干姜 一两
- 粳米 一升

**煮服法：**

上三味，以水七升，煮米令熟，去滓，温服七合，内赤石脂末方寸匕，日三服。若一服愈，余勿服。

**汉制换算：**

- 赤石脂一斤 ≈ 250g（一半入煎，一半研末冲服）
- 干姜一两 ≈ 15g
- 粳米一升 ≈ 200ml
- 水七升 ≈ 1400ml

倪师常说：桃花汤的方名由来，赤石脂色赤如桃花，粳米煮出来汤色微红，故名。但诸位不要被这个温柔的名字骗了——这是少阴病下焦虚寒、滑脱不禁的救急方，是关门之方，是固脱之方。

## 🫀 倪师核心病机与水火气化

少阴是什么？少阴是心肾，是水火之脏。心火在上，肾水在下，水火既济，人身上才温暖、才固密。一旦少阴病，水火分离了，下面肾水寒掉了，命门火衰了，火不能暖土，土不能制水，整个下焦就是一片冰天雪地。

**下利便脓血，诸位不要一看到「脓血」二字就以为是热。** 大肠炎、痢疾，西医讲发炎，中医一看便脓血，温病派马上想到白头翁汤、黄连、黄芩、黄柏，一派苦寒清热。**大错特错！**

桃花汤证便脓血，是**寒利**。为什么寒还会便脓血？因为下焦虚寒到了极点，肠壁的血管因为寒而收缩、而凝滞，血不归经，渗出脉外，与寒湿之利混在一起排出来。这种脓血，颜色是暗的、淡的，不是鲜红的；气味是腥的，不是臭秽的；病人肚子是痛的，但是喜温喜按，按下去反而舒服。

**关键在水火气化。** 命门火衰，下焦没有火去蒸腾气化，水就冷了，冷了以后水不能化气上升，全部往下走，所以「小便不利」——不是没有尿，是气化不行，水不从膀胱走，全部从大肠走了。下利不止，关门不固，滑脱了。这个时候病人是虚的、是寒的、是滑的、是脱的，你再用苦寒药去「消炎」，一剂下去，命门那一点残火都被你打灭了，病人就危险了。

**赤石脂**，色赤入血分，质重性涩，涩可固脱，重可镇下。它专门收敛下焦滑脱，止血止利，把那个关不上的门给关起来。**干姜**，温中散寒，把中焦脾胃的炉子重新点起来，火一生，土就暖了，水就不寒了。**粳米**，养胃气，保胃气，防止赤石脂、干姜过于猛烈伤到胃。

三味药，一味固涩，一味温阳，一味保胃。**固、温、保**三个字，就是桃花汤的灵魂。

## 🎯 临证眼目与方证相应

**必看眼目：**

- **脉**：沉、迟、细、微，或者沉弦而涩。绝不见浮数、洪大。
- **舌**：舌质淡白，或淡胖有齿痕，苔白滑、白腻，甚至水滑。绝不见舌红苔黄。
- **腹诊**：腹痛绵绵，喜温喜按，按之柔软，或有肠鸣。绝不见拒按、腹皮急。
- **大便**：下利不止，或脓血夹杂，色暗、色淡，或如鱼脑、如冻胶，气味腥冷。绝不见里急后重、肛门灼热。
- **小便**：不利，量少，或清白。
- **全身**：畏寒肢冷，精神萎靡，但欲寐，口不渴，或渴喜热饮。

**与白头翁汤的鉴别，这是生死关头：**

| | 桃花汤 | 白头翁汤 |
|---|---|---|
| 病性 | 虚寒滑脱 | 实热下重 |
| 下利 | 不止，滑脱 | 里急后重 |
| 脓血 | 色暗、腥 | 色鲜、臭秽 |
| 口渴 | 不渴或喜热饮 | 渴欲饮水 |
| 舌脉 | 舌淡苔白，脉沉迟 | 舌红苔黄，脉数 |
| 腹痛 | 喜温喜按 | 拒按 |

倪师在课堂上反复讲：**「看到便脓血，先问渴不渴。渴而能饮，热利，白头翁汤；不渴，寒利，桃花汤。这是第一关。再看脉，脉数按之有力，热；脉沉迟按之无力，寒。这是第二关。两关一过，虚实寒热分明，就不会错。」**

还有一个要点：桃花汤的「一服愈，余勿服」。为什么？因为赤石脂涩性极强，中病即止，过服则留邪、则便秘、则壅滞。这是仲景的慈悲，也是经方的分寸。

## 🗣️ 倪师讲义实录与医案精粹

**讲义实录：**

「诸位，少阴病下利便脓血，桃花汤。这个条辨写在少阴篇，你就知道它是寒证。少阴是什么？少阴是寒水之脏。病到少阴，已经是很里面了，是心脏和肾脏的层面了。这个时候下利便脓血，你以为是发炎？不是。是下焦寒掉了，火衰了，血管破裂了，血跟寒湿一起从大肠滑出来。

我讲过，经方用药是『一剂知，二剂已』。桃花汤这种方，一剂下去，利就止了，脓血就少了，为什么？因为赤石脂把门关起来，干姜把火点起来，粳米把胃护起来。三味药，各司其职。

但是你要记住，赤石脂一半煮、一半冲服。煮的那一半，取其味；冲服的那一半，取其涩。这是仲景的巧思，你不要随便改。改了就变成四不像，效果打折。

还有，这个方子使用的前提是——**脉沉迟，舌淡白，不渴，腹痛喜按**。如果病人便脓血，口渴，舌红，脉数，肚子痛得拒按，那是白头翁汤证，你开桃花汤就是关门留寇，病人会发高烧，会鼓肠，会出大问题。所以辨证眼目要抓准。」

**医案精粹：**

倪师曾讲过一个案例：一位七十多岁的老太太，下利脓血三个月，西医诊断为「溃疡性结肠炎」，用过多种抗生素、类固醇，时好时坏。来诊时，人瘦了一圈，面色苍白，精神极差，但欲寐，手脚冰凉。问其口渴？不渴，喝也只喝热水。看其舌，舌淡白，苔白滑。按其腹，脐下腹痛，喜按。诊其脉，沉迟而细。

倪师说：「这就是标准的桃花汤证。少阴寒化，下焦不固，滑脱不禁。你用白头翁汤？那是雪上加霜。」

处方：赤石脂 30g（15g 入煎，15g 研末冲服），干姜 10g，粳米 30g。三剂。

一剂后，下利从一天十余次减到三四次，脓血明显减少。三剂后，下利止，精神好转，手脚回温。后续以理中汤加减调理月余而安。

倪师总结：「这个案例告诉你，不要被『脓血』两个字骗了。中医看的是**证**，不是**病**。病名是溃疡性结肠炎，证是少阴寒利滑脱，那就用桃花汤。这就是经方的力量，这就是六经辨证的眼目。」
