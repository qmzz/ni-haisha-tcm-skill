# baitouweng_jiaoai

## 📜 经方原典与方剂组成

**白头翁加甘草阿胶汤**，出自《金匮要略·妇人产后病脉证并治》：

> 产后下利虚极，白头翁加甘草阿胶汤主之。

**原方组成与剂量（汉代衡制折算）：**

| 药物 | 原方剂量 | 现代折算 | 炮制要求 |
|------|----------|----------|----------|
| 白头翁 | 二两 | 约30g | 去杂质，切段 |
| 黄连 | 三两 | 约45g | 去须 |
| 黄柏 | 三两 | 约45g | 去皮 |
| 秦皮 | 三两 | 约45g | 切段 |
| 甘草 | 二两 | 约30g | 炙 |
| 阿胶 | 二两 | 约30g | 烊化 |

**煎服法：**

上六味，以水七升，煮取二升半，去滓，内胶令消尽，分温三服。

**核心加减法：**

- 无阿胶者，但用白头翁汤，治热利下重。
- 虚甚者，倍甘草、阿胶。
- 腹痛甚者，加白芍。

**禁忌：**

- 虚寒下利者，绝对禁用。此方纯治热利，若脉微欲绝、下利清谷、四肢厥冷者，用之必败。
- 无阿胶者，不可用阿胶替代品，否则滋腻碍邪，反而闭门留寇。


## 🫀 倪师方义推演与核心机理

**倪师原话精神：**

白头翁汤是治“热利下重”的专方。什么叫下重？就是肛门坠胀，想拉又拉不干净，里急后重。这是湿热胶结在大肠，气机被堵住了。白头翁、黄连、黄柏、秦皮，这四味药全是苦寒清热、燥湿止利的东西。苦能泄，寒能清，湿去热清，下重自除。

但产后不一样。妇人生产以后，血室大虚，阴血亏耗。这时候再有热利，那就是虚上加虚。你光用白头翁汤去清，热是清了，但虚极之人受不了那个苦寒攻伐。所以张仲景加甘草、阿胶。甘草炙过，甘温补中，缓急止痛，还能调和苦寒药不伤胃气。阿胶是驴皮熬的，味厚质黏，直入血分，补血滋阴，还能止血。产后下利，往往带血，阿胶既能补血，又能止血，一举两得。

**气化机理层层拆解：**

1. **热利下重之本质**——湿热壅滞大肠，腑气不通，肝气疏泄失常。白头翁苦寒入大肠经，直折热毒；黄连清心火兼厚肠；黄柏清下焦湿热；秦皮涩肠止利。四药合用，苦寒直折，湿热并除。

2. **产后虚极之本质**——生产失血，阴血骤虚，阳气浮越。此时若纯用苦寒，必伤中阳，导致虚寒内生。甘草炙用，甘温入脾，补中益气，缓急迫之势；阿胶甘平，入肝、肺、肾经，滋阴补血，润燥止血。

3. **水火既济之妙**——苦寒药清火，阿胶补阴，甘草补气。火清则不致灼阴，阴补则能制火，气足则能运化。三管齐下，热去而正不伤，利止而血不亏。

4. **与白头翁汤之区别**——白头翁汤纯攻，治实证热利；白头翁加甘草阿胶汤攻补兼施，治虚人热利。倪师常言：**“产后下利，若只见利治利，见热清热，必死无疑。要看到背后的血虚、气虚。”**


## 🎯 临床抓手与六经辨证要领

**六经归属：**

- 主证属**阳明病**——热利下重，肛门灼热，大便黏臭，舌红苔黄腻，脉数。
- 兼证属**太阴病**——产后虚极，面色苍白，神疲乏力，脉细弱。
- 本质为**阳明热利+太阴血虚**，即虚实夹杂之证。

**核心辨证抓手：**

1. **主症**：产后下利，里急后重，大便脓血，肛门灼热。
2. **兼症**：面色萎黄或苍白，头晕心悸，疲乏无力，口干不欲多饮。
3. **舌脉**：舌红少苔或苔黄腻，脉细数或虚数。
4. **腹诊**：小腹按之柔软，无硬满拒按（排除实积）。

**与相似方证鉴别：**

| 方证 | 鉴别要点 |
|------|----------|
| 白头翁汤 | 纯实热利，无虚象，脉实有力 |
| 桃花汤 | 虚寒下利，便脓血，色暗，脉微细 |
| 葛根黄芩黄连汤 | 太阳阳明合病，下利兼表证 |
| 白头翁加甘草阿胶汤 | 产后或虚人，热利兼血虚 |

**倪师临床心法：**

- 产后下利，先辨虚实。脉实者，白头翁汤；脉虚者，此方。
- 若下利纯血，加地榆、槐花。
- 若腹痛甚，加白芍、木香。
- 若气虚甚，加党参、白术。
- **切记：** 此方中病即止，不可久服。热清利止后，转用补中益气汤或归脾汤调理善后。


## 🗣️ 倪师讲义实录与发挥

**倪师原话（据讲课精神整理）：**

“产后下利虚极，这五个字你要把它读透。产后，是前提；下利，是病症；虚极，是本质。你不要看到下利就用白头翁汤，那是治壮实人的。产后妇人，血都跑光了，你再给她苦寒攻下，那不是要她的命吗？

张仲景高明在哪里？他加甘草、阿胶。甘草炙过，补中焦，让苦寒药不伤胃。阿胶呢，补血止血，滋阴润燥。这样一配，清热而不伤正，补血而不留邪。这叫攻补兼施，这叫有制之师。

你们看这个方，白头翁、黄连、黄柏、秦皮，四味苦寒，剂量都不小。黄连三两，黄柏三两，秦皮三两，白头翁二两。加起来是多少？苦寒之力极强。但加了甘草二两、阿胶二两，甘温滋阴，就把苦寒之性驾驭住了。

这就是经方的配伍法度。不是随便加两味药就叫加减，要看到背后的气化机理。苦寒直折其热，甘温补其虚，阿胶补其血。热去则利止，虚补则正复，血充则脉安。

临床我看到产后下利，脉细数，舌红少苔，大便有黏液脓血，里急后重，就用这个方。一剂知，二剂已。但若脉沉微，下利清谷，那就不是这个方了，那是四逆汤证，搞错了要出人命。

还有一点，阿胶一定要烊化。什么叫烊化？就是药煮好了，去滓，趁热把阿胶放进去，搅拌让它融化。你不要把阿胶跟其他药一起煮，那会糊锅，而且阿胶的黏性会把其他药的有效成分包裹住，出不来。

最后强调：这个方是治热利的，不是治寒利的。寒利者，绝对禁用。什么叫寒利？下利清谷，完谷不化，脉微欲绝。那是少阴病，要用通脉四逆汤，不是白头翁汤。差之毫厘，谬以千里。”

**倪师发挥要点：**

1. **阿胶用法**：必须烊化，不可同煮。烊化时用热药汤冲化，搅拌均匀。
2. **甘草用法**：必须炙用，生甘草偏凉，炙甘草偏温，此方需炙甘草补中。
3. **剂量权衡**：苦寒药与甘温药比例约2:1，若虚甚，可加重甘草、阿胶。
4. **煎药时间**：先煮五味药，煮取二升半，再去滓，内阿胶。不可久煮阿胶。
5. **服药反应**：服后若大便次数减少，脓血减少，是佳兆。若腹痛加剧，下利更甚，是药不对证，立即停服。
6. **善后调理**：利止后，用八珍汤或归脾汤补气血，巩固疗效。
