# maimendong_tang

## 📜 经方出处与原方配比

**出处**：《金匮要略·肺痿肺痈咳嗽上气病脉证治第七》

**经典条文**：
> 「大逆上气，咽喉不利，止逆下气者，麦门冬汤主之。」

**原方六味**：

| 药物 | 原量 | 倪师临证参考量 |
|---|---|---|
| 麦门冬 | 七升 | 五钱～一两（君药，量独重） |
| 半夏 | 一升 | 一钱半～二钱（不可多） |
| 人参 | 三两 | 二钱～三钱 |
| 甘草 | 二两 | 二钱 |
| 粳米 | 三合 | 一撮 |
| 大枣 | 十二枚 | 十二枚（擘） |

**煎服法**：上六味，以水一斗二升，煮取六升，温服一升，日三夜一服。

**配伍眼目**：麦冬与半夏，七比一。这不是随便定的比例。七升对一升，是「润」与「降」的配比，也是「补」与「行」的配比。半夏若多，则燥肺；麦冬若少，则滋腻不行。倪师反复强调：**这一味半夏是整方的灵魂**——去性存用，降逆而不伤津。

## 🫀 倪师核心病机与水火气化

倪师讲麦门冬汤，不讲「肺阴虚」四个字了事。他从水火气化切入。

**第一层：大逆上气。**
什么叫「大逆」？正常人气机以下行为顺——胃气降、肺气肃、津液下布。现在津液干枯到极点，胃中无水，火无所附，火就往上冲。冲到哪里？冲到咽喉，冲到肺。这是虚火，不是实火。实火要清要泻，虚火要润要降。麦门冬汤走的是润降一路，不是苦寒直折。

**第二层：肺痿从何而来。**
《金匮》原文明说肺痿的来路：或从汗出，或从呕吐，或从消渴小便利数，或从便难又被快药下利——**重亡津液**。汗、吐、下、利，四个字把津液从不同路口抽干。上焦的热是津液亡失之后产生的，不是先有热才伤津。所以治法不能去清热，要**把津液补回来，把火降下去**。火一降，肺就不焦了。

**第三层：咽喉不利。**
咽喉是肺胃的门户。津液不能上承，咽喉失养，干、痒、痛、堵、声音嘶哑——这些都在「不利」二字里头。倪师说，这个「咽喉不利」跟半夏厚朴汤的梅核气不同：梅核气是痰气交阻，苔白腻、脉弦；麦门冬汤是津枯火逆，舌红少苔、脉细数。一个要行气化痰，一个要生津降火，看舌就知道。

**第四层：方中四味——人参、甘草、粳米、大枣。**
这四味不是配角。倪师讲得很直白：**「补土生金」**。脾胃是津液的源头，源头不恢复，光靠麦冬润肺，润完就干了。人参补气，甘草、粳米、大枣养胃，胃气一复，津液自生，上输于肺。这就是为什么麦门冬汤能治本，不是只管一时之咳。

**水火气化的总枢**：
- 火在上 → 半夏降之
- 水不足 → 麦冬润之
- 中焦虚 → 参、草、米、枣补之
- 全方合力：**止逆下气，生津润燥，培土生金**

## 🎯 临证眼目与方证相应

倪师用麦门冬汤，抓的是「干」与「逆」两个字。

**必见之证**：
- **咳**：干咳无痰，或痰少而黏、拉丝难出，咳声不扬
- **喉**：咽喉干燥、痒痛、如有物堵但无痰可吐，甚则声音嘶哑
- **口**：口干，饮水不解，或口中燥而唾沫黏
- **舌**：舌红少苔，或舌面光剥如镜，或有裂纹
- **脉**：细数，或虚数无力，右寸关尤显不足

**或见之证**：
- 气逆上冲，咳则面赤、胁痛
- 潮热、五心烦热
- 肌肉消瘦，皮毛干枯
- 妇人经后、产后、大病后、化疗后出现上述证候

**核心辨证眼目**：
> **「舌红少苔 + 干咳气逆 + 咽喉干堵」** —— 三者并见，放胆用之。

**禁用与鉴别**：
- 痰多清稀、苔白滑者，**断不可用**（此寒饮，小青龙汤证）
- 痰黄稠、苔黄腻、脉滑数者，是实热痰火，当先清化，非本方所宜
- 梅核气（半夏厚朴汤证）：苔白腻、脉弦、痰气交阻，与麦门冬汤之津枯火逆截然不同
- 炙甘草汤证：心动悸、脉结代，是心阴心阳两虚，与本方之肺胃津枯有别

**倪师加减法**：
- 咳甚气逆：加紫菀、款冬花，降肺气
- 咽痛甚：加玄参、桔梗，开提利咽
- 潮热盗汗：加地骨皮、白薇，清虚热
- 痰黏难出：半夏可稍增，但不可过二钱
- 兼气虚甚：人参加重，或加黄芪

## 🗣️ 倪师讲义实录与医案精粹

**倪师讲麦门冬汤，开篇就说：**

「诸位看这个方，麦门冬七升，半夏一升。七比一。张仲景为什么用这么重的麦冬？因为肺已经干掉了，肺像什么？像秋天的树叶，干枯了、卷起来了，你不多给水，它怎么舒展？七升麦冬下去，润肺、润胃、润喉，把津液全部补足。」

「但是——你光用麦冬不行。麦冬是润的、是黏的，你灌下去，胃不运化，它就停在中间，变成湿、变成痰。所以张仲景放了一味半夏。半夏是燥的、是降的，它把麦冬的滋腻化开，把上逆的气拉下来。**这就是经方的精妙——润而不腻，降而不燥。**」

「人参、甘草、粳米、大枣，这四味你们不要小看。这是补脾胃的。脾胃是什么？是津液的工厂。你光润肺，工厂不生产，润完就没了。所以要先修工厂——胃气一恢复，津液自己就上来了。**这叫培土生金，也叫母生子。**」

「什么时候用？你一看这个人，干咳，没有痰，或者痰少得可怜，黏黏的拉丝，喉咙干得像砂纸，舌头红红的，一点苔都没有，甚至舌头裂开了。脉呢？细细的、数数的。这就是麦门冬汤证。放胆用，一剂知，二剂已。」

**倪师医案举隅（据人纪讲义整理）：**

一妇人，年五十余，干咳半年不止。西医查无异常，予镇咳药无效。来诊时声音嘶哑，咽喉干痛，入夜咳甚，痰少如丝，舌红无苔，脉细数。倪师曰：「此肺痿也，津液枯矣。」予麦门冬汤原方：麦门冬一两，半夏二钱，人参三钱，甘草二钱，粳米一撮，大枣十二枚。三剂咳减大半，七剂声开，十四剂舌上生苔而愈。

又一男子，鼻咽癌放疗后，口干咽燥，饮水不解，干咳无痰，语音难出。倪师以麦门冬汤加玄参、桔梗、紫菀，连服月余，口干大减，咳嗽止，精神恢复。倪师曰：「放疗伤津，与汗吐下伤津同理。津伤则火逆，火逆则肺焦。麦门冬汤正是对证之方。」

**倪师总结语：**

「麦门冬汤不只是治咳嗽的方。你们要看到它的本质——**它是治『津液亡失、虚火上逆』的方**。所以不管病名是慢性支气管炎、咽喉炎、声带息肉、肺结核、肺癌、放疗后遗症
