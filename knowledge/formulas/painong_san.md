# 排脓散

## 📜 经方出处与原方配比

**《金匮要略·疮痈肠痈浸淫病脉证并治第十八》**

> 排脓散方：枳实十六枚，芍药六分，桔梗二分。
> 上三味，杵为散，取鸡子黄一枚，以药散与鸡黄相等，揉和令相得，饮和服之，日一服。

**原方汉制配比：**
- 枳实 十六枚（约合今制 30–40 克，打碎）
- 芍药 六分（约合今制 18 克）
- 桔梗 二分（约合今制 6 克）

**关键比例：枳实 : 芍药 : 桔梗 ≈ 8 : 4 : 1（按枚数折合后之瑞比）**

倪师特别强调：**“枳实要重用，芍药次之，桔梗最轻——这是排脓的黄金比例，你把它倒过来用，脓排不掉，反而把肺气提上去了。”**

**特殊服法：** 三味杵为散，取生鸡蛋黄一枚，以药散与蛋黄等量，揉和令相得，以米饮或温水送服，日一服。倪师说：**“鸡子黄是补中的，排脓的药都很峻，没有鸡子黄护住中焦，脓还没排完，人先虚掉了。”**


## 🫀 倪师核心病机与水火气化

倪师讲排脓散，一上来不讲方，先讲**“脓是什么东西”**。

> “诸位，脓不是病，脓是身体在帮你收拾残局。你身上有一块地方，阳气过不去了，或者热毒壅在那里，气血堵住，肉就烂掉，烂掉以后身体用脓把它包起来，这叫‘腐化为脓’。所以有脓，说明你的阳气还在抵抗，还在想办法把死掉的东西推出去。”

**核心病机：热毒壅肺，气血瘀滞，肉腐成脓——病位在肺与大肠，波及三焦气化。**

倪师用**“水管理论”**讲透：

> “你家的水管，如果水压不够，水流得慢，管壁上的脏东西就冲不走，越积越厚。人体一样——肺主气，肺气一虚，或者热毒一烧，津液变成痰，痰堵住气，气推不动血，血就瘀在那里，瘀久了就化脓。所以排脓散的第一要义，不是‘排’，是‘通’——把气通开，把血活开，脓自己就排出来了。”

**水火气化层面：**
- **心阳不足** → 肺气不降，上焦郁热，热毒郁结成痈
- **小肠火衰** → 下焦不温，大肠传导失职，肠痈内生
- **水气不化** → 津液停滞为痰，痰热互结，腐化为脓

倪师说：**“排脓散为什么用枳实？枳实是通小肠、降大肠的。小肠不通，火就上逆，上逆到肺，肺就化脓。你把小肠一降，火下来了，肺的压力就解了。”**

**配伍直击病根：**
- **枳实**：破气消积，通降小肠与大肠，把壅塞的气机一把推开——倪师喻为“开山斧”
- **芍药**：活血化瘀，通络止痛，把瘀住的血活开——倪师喻为“清道夫”
- **桔梗**：宣肺排脓，载药上行，专入肺经把脓往外推——倪师喻为“排污管”
- **鸡子黄**：补中益气，滋阴养血，护住中焦不让峻药伤正——倪师喻为“安全网”

> “枳实把下面的气一降，桔梗把上面的脓一排，芍药在中间把血一活，鸡子黄在后面把正气一补——这个方子有开有排有活有补，张仲景真是神了。”


## 🎯 临证眼目与方证相应

### 抓主证（问诊抓手）

倪师说：**“排脓散的主证，你眼睛一看，手一按，就知道了。”**

1. **局部症状**：
   - 痈肿处**热**（手按上去发烫）→ 有脓
   - 痈肿处**不热**（按上去凉）→ 无脓，不可用排脓散
   - 痛处固定，拒按，按之加剧

2. **全身症状**：
   - **脉浮数**，应当发热，却**反洒淅恶寒**——这是《金匮》原文，倪师解释：“脉浮数是热，但身体却怕冷，说明热毒壅在里面出不来，阳气被堵住了，这是发痈的征兆。”
   - **咳吐脓血**，或**大便下脓血**——肺痈、肠痈已成
   - **胸中隐隐作痛**，咳则痛甚
   - **口干但不欲饮**，或饮后不舒——热在血分，不在气分

3. **二便**：
   - 小便黄赤短少——热毒壅盛
   - 大便或秘或溏，但多有**里急后重**感——肠痈特征

4. **脚温**：
   - 脚冷 → 下焦阳虚，脓成难排，需加温阳之品
   - 脚热 → 热毒下注，可重用枳实

### 关键鉴别点

倪师说：**“有脓无脓，一按便知。热者为有脓，不热者为无脓。这是仲景的不传之秘。”**

- **有脓**：局部灼热，按之痛甚，脉数有力 → 排脓散主之
- **无脓**：局部不热，按之空虚，脉虚无力 → 不可用排脓散，当用托里消毒散或补中益气汤

### 随证加减法

倪师临床化裁：

| 见证 | 加减 | 倪师原话 |
|---|---|---|
| 肺痈，咳吐脓血，胸痛 | 加**葶苈子、大枣** | “葶苈大枣泻肺汤，把肺里的脓水先泻掉，再用排脓散收尾。” |
| 肠痈，右下腹剧痛，拒按 | 加**牡丹皮、桃仁、冬瓜仁** | “这就是大黄牡丹皮汤的影子，排脓散打底，加这几味专攻肠痈。” |
| 脓已成但排不畅，气虚无力 | 加**黄芪、皂角刺** | “黄芪托里，皂角刺穿脓，一个补一个穿，脓就出来了。” |
| 热毒炽盛，高热不退 | 加**金银花、连翘、蒲公英** | “热毒太盛，先清热解毒，再排脓，不然脓排了又长。” |
| 阳虚脚冷，脓成难溃 | 加**附子、干姜** | “脚一冷，阳气就不够，脓就溃不出来，加附子把火点起来。” |
| 无脓，仅红肿 | **去桔梗**，加**连翘、赤小豆** | “没有脓就不要用桔梗，桔梗是排脓的，没脓排什么？” |

### 相似经方鉴别

| 方剂 | 核心区别 | 倪师要诀 |
|---|---|---|
| **排脓散** | 有脓，热毒壅肺/肠，脉数有力 | “有脓排脓，枳实芍药桔梗，专攻已成之脓。” |
| **排脓汤** | 有脓，但偏于表，疮痈初起 | “排脓汤走表，甘草桔梗生姜大枣，是排脓的轻剂。” |
| **桔梗汤** | 肺痈，咳吐脓血，但无气滞 | “桔梗汤就两味药，桔梗甘草，专治肺痈咳脓。” |
| **大黄牡丹皮汤** | 肠痈初起，右下腹剧痛，未成脓 | “大黄牡丹皮汤是攻下的，脓没成的时候用，脓成了要用排脓散。” |
| **苇茎汤** | 肺痈，咳吐腥臭脓痰，偏于痰热 | “苇茎汤是清肺化痰的，排脓散是排脓的，一个清一个排。” |


## 🗣️ 倪师讲义实录与医案精粹

### 倪师原话精粹

> “诸位，排脓散这个方，你看起来很简单，三味药加个鸡蛋黄。但是张仲景为什么用枳实十六枚？十六枚枳实，你拿在手上看，一大堆啊！枳实是干什么的？破气。气不通，脓就排不出来。所以枳实要重用，用到你觉得‘哇，这么多’，那就对了。”

> “芍药六分，桔梗二分。桔梗为什么最轻？因为桔梗是往上走的，是舟楫之药。你把它用重了，气全往上冲，脓反而下不来。所以桔梗要轻用，轻轻一推，脓就出来了。”

> “鸡子黄，就是生鸡蛋黄。你不要小看这个蛋黄，它是补中的。排脓的药都很峻，枳实破气，芍药活血，都是耗气的。没有鸡子黄护住中焦，你脓排完了，人也虚了。张仲景用鸡子黄，就是告诉你——排脓不能伤正。”

> “
