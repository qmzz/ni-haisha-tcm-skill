# 厚朴麻黄汤

## 📜 经方原典与方剂组成

**《金匮要略·肺痿肺痈咳嗽上气病脉证并治第七》**

> 咳而脉浮者，厚朴麻黄汤主之。

**原方组成与剂量：**

- 厚朴五两
- 麻黄四两
- 石膏如鸡子大
- 杏仁半升
- 半夏半升
- 干姜二两
- 细辛二两
- 五味子半升
- 小麦一升

**煎服法：**

上九味，以水一斗二升，先煮小麦熟，去滓，内诸药，煮取三升，温服一升，日三服。

**剂量折算（汉制）：**

- 厚朴五两 ≈ 75g（汉一两 ≈ 15g）
- 麻黄四两 ≈ 60g
- 石膏如鸡子大 ≈ 40–50g
- 杏仁半升 ≈ 40–50枚
- 半夏半升 ≈ 60g
- 干姜二两 ≈ 30g
- 细辛二两 ≈ 30g
- 五味子半升 ≈ 40g
- 小麦一升 ≈ 150g

**倪师临床常用参考量：** 厚朴15g、麻黄10–15g、石膏15–30g（打碎）、杏仁10–15g、半夏10–15g、干姜6–10g、细辛6–10g、五味子10–15g、小麦15–30g。小儿酌减。

## 🫀 倪师方义推演与核心机理

厚朴麻黄汤，此方出自《金匮》肺痿肺痈咳嗽上气篇，一条主证点破天机—— **“咳而脉浮者”** 。这五个字就是全部的方眼。咳是病，脉浮是机。脉浮代表什么？代表病邪在表，在肺，在上焦，正气尚能与邪气交争于外。如果脉沉了，那就入里了，那就不是这个方子了。

**方义拆解——**

第一组：麻黄、石膏、杏仁——这是麻杏石甘汤的底子。麻黄宣肺开表，把肺里面的郁闭打开；石膏辛寒，清肺中的郁热；杏仁降肺气。肺为华盖，主皮毛，主宣发肃降。当表邪束肺，肺气不宣，郁而化热，就会出现咳嗽、气喘、烦躁。麻黄配石膏，一宣一清，一温一寒，相互制约，打开肺的闭郁，清掉肺中的热。

第二组：厚朴、半夏、干姜、细辛、五味子——这是小青龙汤的变局。厚朴降气除满，宽胸利膈，把上逆的气机往下导。半夏降逆化痰，干姜温中散寒，细辛温散水寒，五味子收敛肺气。这一组药的核心在于—— **“散收并用，开合有度”** 。细辛、干姜、半夏辛温以散水寒，五味子酸收以敛肺气，一散一收，肺气的宣发肃降功能就恢复了。

第三组：小麦——小麦甘凉，养心气，除烦热，更重要的是，它能 **“厚肠胃、养正气”** ，在攻邪的同时固护中焦。

**核心机理——**

这个方的本质是 **“寒热并用、表里双解、散收兼施”** 。肺为娇脏，不耐寒也不耐热。当外邪束表，内有水饮，郁而化热，形成寒热错杂的局面时，单用温药则助热，单用寒药则伤阳。仲景立此方，用麻黄、干姜、细辛温散表寒水饮，用石膏清泄肺中郁热，用厚朴、杏仁、半夏降气化痰，用五味子收敛耗散之肺气，用小麦安中。**一方之中，温、清、散、收、降、养，六法俱全，这就是经方的精密之处。**

倪师常言：**肺是“水之上源”，也是“气之主”** 。肺气一闭，水津不布，停而为饮；肺气一逆，咳喘并作。厚朴麻黄汤打开肺闭、清泄郁热、降逆化饮、收敛肺气，四管齐下，让肺恢复“宣发肃降”的本能。这就是治咳喘的大法。

## 🎯 临床抓手与六经辨证要领

**六经归属：太阳阳明合病，兼太阴水饮。**

**核心辨证抓手：**

1. **主证：** 咳嗽，气喘，胸闷，痰声漉漉，烦躁，脉浮。
2. **关键脉象：** **脉浮**——这是第一抓手。浮脉主表，主上焦，说明病位在肺、在表，正气尚能抗邪于外。
3. **兼证：** 可能伴有恶寒发热、无汗或有汗、口渴或不渴、痰多而稀或稠、喉中痰鸣、胸满胀闷。
4. **舌象：** 舌苔白滑或白腻，或舌尖红，代表外有寒饮、内有郁热。

**与相似方的鉴别：**

- **小青龙汤：** 外寒内饮，表寒重，咳嗽喘息，痰稀白，苔白滑，**无烦躁、无口渴**。厚朴麻黄汤则多了石膏，说明 **“内有郁热”** ，常见烦躁、口渴。
- **麻杏石甘汤：** 肺热壅盛，汗出而喘，**无痰饮、无胸满**。厚朴麻黄汤则多了厚朴、半夏、干姜、细辛、五味子，说明 **“兼有寒饮内停”** ，痰多胸闷。
- **射干麻黄汤：** 咳而上气，喉中水鸡声，**表寒轻、痰饮重**。厚朴麻黄汤则 **表闭更重、郁热更显**。
- **泽漆汤：** 咳而脉沉者，**病已入里，水饮内结**。厚朴麻黄汤是脉浮，病仍在表。

**临床运用范围：**

- 急性支气管炎、慢性支气管炎急性发作
- 支气管哮喘
- 过敏性咳嗽
- 肺炎早期
- 肺气肿合并感染
- 小儿百日咳
- 感冒后咳嗽久不愈，见脉浮、胸闷、痰多、烦躁者

**倪师心法：** **“咳而脉浮，就用厚朴麻黄汤；咳而脉沉，就用泽漆汤。”** 这是仲景给出的最明确的辨证眼目。脉浮在表，脉沉在里。一浮一沉，方向截然不同。临床上摸到咳嗽病人的脉，第一件事就是分浮沉。浮者，邪在肺卫，可汗可散可宣；沉者，邪已入里，当攻当逐当利。厚朴麻黄汤就是治“脉浮之咳”的正治之方。

## 🗣️ 倪师讲义实录与发挥

**倪师讲厚朴麻黄汤，直指核心——**

“诸位看这个厚朴麻黄汤，咳而脉浮者，厚朴麻黄汤主之。这个处方，你一看就知道，麻黄、石膏、杏仁，这是麻杏石甘汤；厚朴、半夏、干姜、细辛、五味子，这是小青龙汤的架子。然后加一味小麦。”

“张仲景在告诉我们什么？他在告诉我们——**肺里面有寒有热，寒热并结的时候，你要寒药热药一起用。** 单用热药，热更盛；单用寒药，寒更盛。怎么办？寒热并用。麻黄配石膏，干姜配石膏，细辛配石膏，这就是经方的配伍艺术。”

“为什么加小麦？小麦是心之谷，能养心气、除烦热。咳而上气，病人往往心烦气躁，晚上睡不好。小麦下去，心安了，神定了，咳喘也容易平下来。这就是经方的细腻之处，不是只治肺，还要治心。”

“脉浮，代表病在表。咳嗽而脉浮，说明肺气还能够在表层抗邪。这时候你要因势利导，从表解。麻黄打开毛孔，把表邪赶出去；石膏清里面的热；厚朴、杏仁、半夏把逆气降下来；干姜、细辛把水寒温散掉；五味子把肺气收住。一开一合，一散一收，一温一清，肺的功能就恢复了。”

“临床上，小孩子感冒咳嗽，咳了很久不好，晚上咳得不能睡，烦躁，痰很多，脉一摸是浮的，舌头一看是白滑的，这就是厚朴麻黄汤证。你开下去，一剂知，二剂已。为什么？因为方证对应。”

“记住，**咳而脉浮，这是用方的铁律。** 脉浮就用厚朴麻黄汤，脉沉就用泽漆汤。你不要搞反了。搞反了不但治不好，还会坏事。这就是经方的严谨之处——**方证相应，丝毫不差。** ”

“还有一点，厚朴麻黄汤里面麻黄用了四两，石膏如鸡子大，这个比例很重要。麻黄重于石膏，说明表寒重于里热。如果里热很盛，石膏就要加重。如果表寒很盛，麻黄就要加重。这就是经方的灵活性。你把握住寒热的比例，就把握住了这个方的灵魂。”

“最后告诉你一个秘诀——**厚朴麻黄汤治的是“肺胀”** 。什么叫肺胀？就是肺里面被寒饮和郁热堵住了，胀满不通。病人感觉胸闷、气短、咳喘、烦躁。你把这个方子用下去，肺里面的东西被清掉了、被散掉了、被降掉了，肺就轻松了。这就是“肺胀”的正治之法。”
