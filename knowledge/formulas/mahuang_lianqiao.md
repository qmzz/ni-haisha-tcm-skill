# mahuang_lianqiao

## 📜 经方出处与原方配比

**《伤寒论》第262条：**

> 伤寒瘀热在里，身必黄，麻黄连轺赤小豆汤主之。

**原方八味：**

| 药 | 汉制 | 现代参考 |
|---|---|---|
| 麻黄（去节） | 二两 | 6–9g |
| 连轺（连翘根） | 二两 | 6–9g（今以连翘代） |
| 杏仁（去皮尖） | 四十个 | 12–15g |
| 赤小豆 | 一升 | 30–45g |
| 大枣（擘） | 十二枚 | 12枚 |
| 生梓白皮（切） | 一升 | 15–30g（今以桑白皮代） |
| 生姜（切） | 二两 | 9g |
| 甘草（炙） | 二两 | 6–9g |

**煎服法：**

> 上八味，以潦水一斗，先煮麻黄再沸，去上沫，内诸药，煮取三升，去滓，分温三服，半日服尽。

倪师特别点出几处关键：

- **连轺**是连翘的根，今药房不备，一律以连翘代，作用不走样。
- **生梓白皮**今已难寻，倪师直说：拿桑白皮替代。梓白皮与桑白皮同走肺家，清肺中郁热，一脉相承。
- **潦水**是天上落下的雨水积在地上所取，味薄而不助湿。倪师讲，用潦水就是不让水湿之气再添进来，湿病最忌以水助水。
- 先煮麻黄、去上沫，是仲景定法，沫不去则令人心烦。
- **半日服尽**，说明此方取效要快、要在表在上的湿热速去，不可拖成一日三服慢慢来。

方中无桂枝，是此方眼目之一。麻黄、杏仁、炙甘草三味，俨然麻黄汤去桂枝。去桂枝者，正因里有瘀热，不可再以辛温助热。麻黄一味开表闭，把郁在皮腠的阳气放出去，热才有出路。

## 🫀 倪师核心病机与水火气化

倪师讲这条，一句一句拆：

**"伤寒"**——表还有邪，太阳的开关没打开，毛孔是闭的。这是前提，没有表闭，就没有麻黄出手的余地。

**"瘀热在里"**——这个"瘀"不是血瘀，是热被郁住、憋住、出不来。热本来该随汗走、随小便走，现在汗路被表闭堵死，小便又不利，热就闷在三焦水道与肌腠之间。

**"身必黄"**——热闷久了，与湿相合，湿热郁蒸，熏到皮肤上就是黄。黄是湿热的颜色外露。

倪师的水火气化讲法是这样的：

人体是一团水火在循环。**肺为水之上源**，主皮毛，主宣发肃降。表一闭，肺气不宣，上源的水就下不去；水不下去，三焦水道不利，湿就停在中焦、停在肌表。湿停则热无所附而又无处散，湿与热搅在一起，如油入面。

于是出现两条路都被堵死的局面：

1. **汗路堵**——太阳表闭，麻黄证。
2. **尿路堵**——三焦水道不通，赤小豆证。

治法就是把两条路同时打开：

- **麻黄、杏仁、生姜**开表，从汗走。麻黄开毛孔，杏仁宣肺降气（肺气一宣，皮毛自开），生姜助其辛散。
- **赤小豆**从下走，利小便，把湿从小便渗出去。倪师说赤小豆不只是利水，还能祛湿、排脓、解血分之湿热。
- **连翘**清上焦郁热，兼散结气，把闷住的热松开。
- **桑白皮（代梓白皮）**直入肺家，泻肺中水气与郁热。肺主皮毛，皮肤上的湿热要从肺上治，这是倪师反复强调的。
- **炙甘草、大枣**守中，防止苦寒渗利伤了脾胃。中焦一败，湿更去不掉。

**水火既济的关键**：汗出则表解，小便利则湿去。一上一下两条出路同时通，瘀热自然消，黄自然退。倪师讲，这个方子治的不是"黄"这个症，治的是"湿热无出路"这个机。

## 🎯 临证眼目与方证相应

倪师抓这个方子，看的是四件事凑齐：

**一、表闭的证据**
无汗，或汗出极不畅；恶风、恶寒；身痒而抓之不解。倪师特别强调"身痒"二字——《伤寒论》讲"以其不能得小汗出，身必痒"，痒就是表闭、热欲出而无路。

**二、湿热的证据**
身黄如橘子色（鲜明者属阳黄），或皮肤起疹、色红、抓破渗水、结痂；小便黄短、不利；口不甚渴或渴不多饮。

**三、肺皮毛的证据**
病变在皮肤——湿疹、荨麻疹、风疹块、疥癣、痤疮、颜面发红发肿、小儿奶癣、异位性皮炎。倪师一句话点透：**肺主皮毛，皮上的病不从肺治，从哪儿治？**

**四、舌脉**
舌苔白腻或黄腻，脉浮、浮紧、浮数。脉沉实、舌红少津者，不是此方。

**倪师常提的鉴别：**

- **与桂枝麻黄各半汤**：那条也是"身必痒"，但那是太阳表郁轻证，热不重、湿不重，面无黄、小便不黄。麻黄连翘赤小豆汤是表闭＋湿热，多了湿与热两个字。
- **与茵陈蒿汤**：茵陈蒿汤治阳明瘀热在里的谷疸，腹满、小便不利、大便难，纯在里，无表证，故不用麻黄。麻黄连翘赤小豆汤是**表里同病**，表不解则里不通，所以麻黄不可少。
- **与麻杏苡甘汤**：那是风湿在表、一身尽疼，偏于湿，不偏于热，也不见黄。
- **与麻黄汤**：麻黄汤纯表寒，无里热，故用桂枝。此方有里热，故去桂枝。

**加减思路**（依倪师人纪讲法）：痒甚者，可加荆芥、防风助其疏风；湿热偏重、疹色红赤者，连翘、赤小豆可稍加重；小儿湿疹，量宜轻，取"半日服尽"之意，中病即止。

## 🗣️ 倪师讲义实录与医案精粹

倪师讲这一条，通常先落在"黄"字上，再一转，落到皮肤上：

> "伤寒，瘀热在里，身必黄。诸位看，麻黄、连翘、赤小豆、杏仁、大枣、生梓白皮、生姜、甘草。生梓白皮现在没有了，我们用桑白皮代替。连轺是连翘的根，现在用连翘，一样的意思。
>
> 这个方子，你如果只拿来治黄疸，那是把仲景看小了。**这是治皮肤病的方子。**"

他讲病机，讲得很直：

> "伤寒，就是表还没解。瘀热在里，热被闷在里边出不来。热出不来，跟湿混在一起，湿热一蒸，皮肤就发黄。可你不要忘了，**肺主皮毛**。肺在上焦，主宣发。表一闭，肺气不宣，皮毛上的湿热就散不掉。所以皮肤痒、起疹子、流黄水
