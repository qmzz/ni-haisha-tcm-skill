# 桂枝去芍药加附子汤

## 📜 经方出处与原方配比

**《伤寒论》原文：**
“太阳病，下之后，脉促胸满者，桂枝去芍药汤主之。若微恶寒者，桂枝去芍药加附子汤主之。”

这一条，讲的是太阳病误下之后，表邪没解掉，反而把胸阳给打伤了。张仲景先给出一个“去芍药”的法子，若再出现“微恶寒”，那就是阳气更虚了一层，非得把附子请出来不可。

**原方组成（汉制）：**

- 桂枝三两（去皮）
- 炙甘草二两
- 生姜三两（切）
- 大枣十二枚（擘）
- 附子一枚（炮，去皮，破八片）

**原方比例要诀：**

桂枝:甘草:生姜 = 3:2:3，大枣十二枚，附子一枚。你把这个比例记住，这是经方的灵魂。倪师常讲，经方的比例一乱，方义就变了，桂枝三两配甘草二两，才是辛甘发散、温通心阳的力道。你搞个桂枝三钱、甘草三钱，那就不叫桂枝甘草汤的底子了。

**现代常用换算（依倪师习惯）：**

- 桂枝三钱
- 炙甘草二钱
- 生姜三钱
- 大枣十二枚
- 炮附子一枚（约三钱至五钱，视附子大小）

倪师在讲《伤寒论》时反复强调：汉朝的一两，我们临床取用，可以按一钱到三钱来灵活斟酌。但原方比例不能动——**桂枝比甘草多，生姜跟桂枝等量，大枣十二枚，附子一枚**。这是规矩。

## 🫀 倪师核心病机与水火气化

这一条的核心，就在一个“下”字，和一个“胸满”上。

太阳病，本该从表解，结果医生一看病人有便秘，或者一看病人发烧，糊里糊涂开了攻下的药。这一下，坏事了。表邪没出去，肠胃里的阳气又被扯了下来。倪师讲得最直白：**“你太阳病在表，应该发汗，结果你用攻下的药，等于把身体的门窗全部打开，让寒水之气往里冲。冲到哪里？冲到胸中。胸阳一被伤到，浊阴之气就堵在胸口，病人就胸满。”**

胸满是什么感觉？就是胸口闷、胀、堵，好像有一块石头压着，吸一口气都吸不深。倪师形容：**“胸口是阳气往来的大马路，现在被阴霾堵住了，车子过不去，你就觉得满。”**

那为什么脉促？促脉，就是跳得很快，跳跳停停。倪师说：**“促脉代表心脏的力量不够，心血不足，心阳不振。心脏想跳，但跳几下就没力了，停顿一下，再跳。这就是胸阳被困住了，心阳没办法舒展。”**

这种时候，张仲景第一刀就去掉芍药。

为什么要去芍药？倪师讲得极生动：**“芍药是酸苦涌泄的药，主收敛，主下降。你胸满的时候，胸阳已经不够了，你还用芍药把它往下收，那不是更闷吗？就好像房间里已经空气不流通了，你还把窗户关起来，把门锁死，那不是找死吗？所以要把芍药拿掉。”**

桂枝汤里有芍药，是拿来收敛营血、调和营卫的。但胸满的人，阳气被困在胸中，需要的是宣通、是发散，不是收敛。所以去芍药，留下桂枝、甘草、生姜、大枣，这就是桂枝去芍药汤，专门通胸阳。

那什么时候加附子？原文说了——“若微恶寒者”。倪师讲：**“微恶寒，就是病人怕冷，手脚冰凉，表阳也不够了，下焦的命门火也衰了。光是通胸阳还不够，你得把下面的火点起来。附子，辛热，入肾，走命门，能壮心阳，能温下焦。你把附子加进去，等于给心脏装了一个马达，给命门加了一把柴火。”**

倪师常讲，心阳跟小肠火是一体的。**“心脏的火往下走，进入小肠，小肠再蒸化水气，水气再往上走，回到胸中。这是一条水火气化的通路。你误下之后，这条通路断了，胸阳没了，下面的火也衰了。所以胸满、脉促、微恶寒，全出来了。桂枝去芍药加附子汤，就是重新把这条通路接起来。”**

桂枝、甘草，辛甘发散，壮心阳；生姜、大枣，补中焦，生津液；附子，温下焦，点命门火。芍药一去，胸阳不再受束，附子一下，心肾之火重新贯通。这就是经方的思路——**一味药的去留，就是整个气机的转折。**

## 🎯 临证眼目与方证相应

**抓主证：**

1. **胸满**——病人说胸口闷、堵、胀，喜欢用手按着胸口，或者觉得吸气吸不到底。这是胸阳不振的第一眼目。
2. **脉促**——跳得快，跳跳停停，或者不规律。你手一搭上去，感觉脉来急促，时有歇止。
3. **微恶寒**——病人怕冷，手脚不温，甚至冰凉。不是那种高烧恶寒，而是微微的、持续的怕冷。
4. **误下史**——问诊时一定要问：之前有没有吃错药？有没有拉肚子？有没有被西医灌肠、用泻药？这是关键诱因。
5. **心阳虚的其他表现**——心悸、心慌、胸闷、短气、精神疲倦、面色苍白或晦暗。

**核心鉴别点：**

- **有汗无汗：** 桂枝汤有汗，桂枝去芍药加附子汤不一定有汗，重点是胸满和恶寒。
- **口渴冷热：** 一般不渴，或者渴而不欲饮。如果大渴引饮，那是阳明热证，不是这个方。
- **脚温与不温：** 脚冷、手冷，这是附子证的关键。倪师讲：**“你摸病人的脚，脚是冰的，就是附子要下去了。”**
- **二便：** 小便清长，大便正常或偏溏。如果小便黄赤、大便燥结，那是热证，要小心。
- **腹诊：** 心下、胸中按之可能微闷，但不像结胸那样硬满拒按。

**随证加减法：**

- 胸满甚，加枳实、厚朴，通降气机。
- 心悸甚，加茯苓、桂枝，甚至加龙骨、牡蛎，镇心安神。
- 恶寒甚，附子加重，或加干姜，温中回阳。
- 气短、乏力甚，加黄芪、党参，补胸中大气。
- 若兼咳嗽、痰多，加半夏、杏仁，化痰降气。
- **绝对不要加芍药！** 胸满未除之前，芍药是禁忌。倪师说：**“胸满用芍药，是闭门留寇。”**

**相似经方鉴别要诀：**

| 经方 | 核心区别 |
|------|----------|
| **桂枝汤** | 有芍药，用于表虚自汗、营卫不和，无胸满。 |
| **桂枝去芍药汤** | 有胸满、脉促，但无微恶寒。 |
| **桂枝去芍药加附子汤** | 胸满、脉促，再加微恶寒、脚冷，阳虚更甚。 |
| **桂枝加附子汤** | 汗漏不止、四肢微急、难以屈伸，有芍药，无胸满。 |
| **桂枝甘草汤** | 发汗过多，叉手自冒心，心下悸，欲得按，纯补心阳，无胸满。 |
| **桂枝甘草龙骨牡蛎汤** | 心阳虚烦躁，惊狂，卧起不安。 |
| **真武汤** | 心下悸、头眩、身瞤动、振振欲擗地，阳虚水泛，有芍药、附子、茯苓、白术。 |

倪师讲得最清楚：**“胸满就去芍药，恶寒就加附子。这是张仲景给你的死规矩，你只要看到胸满，芍药就先拿掉，看到恶寒、脚冷，附子就下去。”**

## 🗣️ 倪师讲义实录与医案精粹

倪师在讲这一条的时候，最喜欢用“门窗”和“马达”来比喻。

**关于误下：**
“太阳病在表，你该发汗，结果你攻下。这一下，就像你家里着火了，你不从门口泼水，你把地板撬开，水全灌到地下室去了。表邪没走，胸阳被打掉了。病人胸口闷，脉跳跳停停，还怕冷。这就是误下伤阳。”

**关于去芍药：**
“芍药这味药，是收敛的，是往下降的。胸满的人，胸阳已经不够了，你还用芍药去收，去降，那不是把阳气往死里压吗？所以张仲景说，胸满者，去芍药。你把这个窗户打开，让阳气能透出来，胸就不闷了。”

**关于附子：**
“附子，你拿起来看，黑的，入肾。它是辛热的，走而不守。心脏力量不够，脉促，胸满，你用附子下去，它一下去，命门火就点起来了。火一点起来，心阳就壮了。所以微恶寒的人，一定要加附子。你光用桂枝去芍药汤，只能通胸阳，不能温下焦。下面没有火，上面的火也撑不久。”
