# 内补当归建中汤

## 📜 经方出处与原方配比

**出处**：《金匮要略·妇人产后病脉证治》附方（《千金》内补当归建中汤）

**原方配比**：
- 当归 四两
- 桂枝 三两
- 芍药 六两
- 生姜 三两
- 甘草 二两
- 大枣 十二枚

**煎服法**：上六味，以水一斗，煮取三升，分温三服，一日令尽。若大虚，纳饴糖六两，汤成内之，于火上暖令饴消。若去血过多，崩伤内衄不止，加地黄六两、阿胶二两，合八味，汤成纳阿胶。若无当归，以芎藭代之。若无生姜，以干姜代之。

**方义拆解**：此方即桂枝汤倍芍药加当归，再入饴糖，实为小建中汤之变局。桂枝汤本为调和营卫、建中气之祖方，倍芍药者，酸收之力厚，能缓腹中急痛；加当归者，直入血分，补血中之虚；纳饴糖者，甘以缓之，建中焦以生津液。全方气血双补，阴阳并调，而重心在“建中”二字——中气立，则气血自生，虚羸自复。

## 🫀 倪师核心病机与水火气化

倪师于人纪讲义中明言：此方所治，核心在**产后中气大虚，水火不交，气血两亏**。

产后妇人，亡血伤津，冲任空虚。中焦者，水火气化之枢轴也——心火欲下降于肾，必赖中焦脾胃之转输；肾水欲上济于心，亦必假中焦之升提。中气虚馁，则火浮于上而为“吸吸少气”，水沉于下而为“少腹中急”。腹中刺痛不止者，非实痛也，乃血虚不荣、经脉拘急之虚痛，所谓“不荣则痛”。

倪师强调：**此方之灵魂在“建中”**。当归四两入血分，补已亡之血；桂枝甘草辛甘化阳，助心火之下照；芍药六两酸甘化阴，敛浮越之阳气；生姜大枣培土和中；饴糖一味，乃稼穑之甘，直补中焦，使水火有交通之阶。中焦一建，则上焦之气得降，下焦之血得升，刺痛自止，少气自平。

**与黄芪建中汤之鉴别**：黄芪建中汤重在气虚自汗、诸不足；内补当归建中汤重在血虚刺痛、产后虚羸。一偏气分，一偏血分，倪师常以此二方对举，示人气血分治之眼目。

**加地黄阿胶法**：若崩伤内衄不止，去血过多，加地黄六两、阿胶二两。倪师指出：地黄生用凉血止血，阿胶烊化直补血海，此乃血脱益气之后，再益其血，层层递进之法。

## 🎯 临证眼目与方证相应

**核心方证**：
- **产后虚羸不足**——面色苍白，神疲乏力，形体消瘦
- **腹中刺痛不止**——痛处固定，喜按喜温，得温则减
- **吸吸少气**——气短不足以息，言语无力
- **少腹中急，摩痛引腰背**——少腹拘急，按揉后痛引腰背
- **不能饮食**——纳呆食少，中焦不运

**辨证眼目**：
1. **刺痛 + 喜按**：此刺痛非瘀血之拒按，乃血虚不荣之喜按，按之痛减，温之则舒。倪师常言：“拒按为实，喜按为虚，此辨证之铁律。”
2. **吸吸少气 + 腹中急**：上见气短，下见拘急，此水火不交、中气不立之象。倪师谓：“上气不足者，下必拘急；下焦紧者，上必少气。此阴阳不能相抱也。”
3. **脉象**：脉细弱，或弦而无力，重按则空。倪师云：“产后之脉，宜缓弱，不宜弦紧。弦紧者，血虚而寒也。”
4. **舌象**：舌淡苔薄白，或舌体瘦小，边有齿痕。

**适用人群**：产后一月内，或流产、崩漏后，或平素血虚而腹中冷痛者。倪师特别指出：**无论男女，凡血虚中寒而腹痛者，皆可酌用**，不必拘于产后。

**禁忌**：若腹痛拒按、恶露臭秽、发热口渴者，此瘀热互结，非本方所宜。

## 🗣️ 倪师讲义实录与医案精粹

**倪师原声（据人纪讲义精神还原）**：

“你们看这个内补当归建中汤，就是桂枝汤倍芍药加当归，再加饴糖。张仲景为什么在产后病里放这个方？因为妇人产后，第一个伤的是血，第二个伤的是中气。血一伤，肝无所藏，经脉就拘急，所以腹中刺痛。中气一伤，水火不能交，上面就吸吸少气，下面少腹就急。”

“当归这味药，不要只把它当补血药看。当归是使血归经，让血回到该去的地方。产后血虚，血不归经，才用当归。芍药六两，你们注意，桂枝汤里芍药是三两，这里倍用六两。为什么？酸能收，能缓，能止腹痛。腹痛用芍药，这是张仲景的心法。”

“饴糖，就是麦芽糖。不要小看这个糖，甘能补中，能缓急，能生津。中焦虚到极点的时候，你光用草木之品补不进去，要用这种稼穑之甘，直接补中。什么叫建中？就是建立中焦的气化。中焦一建，上面心火降下来，下面肾水升上去，水火一交，百病自消。”

“若大虚，纳饴糖六两。这个‘大虚’，就是虚到极处，脉微欲绝，气短不能续。这时候饴糖必须加，而且汤成之后才放，不能跟药一起煮。为什么？饴糖一煮就焦，焦则苦，苦则伤中，反而坏事。”

**医案精粹（据倪师医案精神拟录）**：

一妇人，产后四十日，腹中刺痛，痛则少腹拘急，牵引腰背，不能食，气短不足以息。前医以失笑散、生化汤辈，痛益甚。倪师诊之：脉细如丝，重按则空，舌淡无华，面色㿠白。曰：“此非瘀血，乃血虚而中寒也。不荣则痛，温之补之则愈。”处以内补当归建中汤原方：当归四钱、桂枝三钱、白芍六钱、生姜三钱、甘草二钱、大枣十二枚，加饴糖二两烊化。三剂痛减，六剂能食，十剂诸症若失。

又治一妇人，流产之后，崩漏不止，面色苍白，心悸少气，腹中绵绵作痛。倪师于内补当归建中汤中加地黄六钱、阿胶三钱烊化。二剂血止，五剂痛除，继以八珍汤收功。

倪师总结：**“产后之病，十有九虚。虚则补之，寒则温之。内补当归建中汤，补血之中有温中，温中之中有调和，此仲景为产后虚羸立法之深意也。”**
