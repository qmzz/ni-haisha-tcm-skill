# 大柴胡汤

## 📜 经方出处与原方配比

**《伤寒论》原文：**
- 「太阳病，过经十余日，反二三下之，后四五日，柴胡证仍在者，先与小柴胡。呕不止，心下急，郁郁微烦者，为未解也，与大柴胡汤下之则愈。」
- 「伤寒发热，汗出不解，心中痞硬，呕吐而下利者，大柴胡汤主之。」
- 「伤寒十余日，热结在里，复往来寒热者，与大柴胡汤。」

**《金匮要略·腹满寒疝宿食病脉证治》：**
- 「按之心下满痛者，此为实也，当下之，宜大柴胡汤。」

**原方组成（汉制）：**

| 药物 | 汉制剂量 | 现代换算 |
|------|----------|----------|
| 柴胡 | 半斤 | 八钱（约24g） |
| 黄芩 | 三两 | 三钱 |
| 芍药 | 三两 | 三钱 |
| 半夏 | 半升 | 三钱（洗） |
| 生姜 | 五两 | 五片 |
| 枳实 | 四枚 | 四枚（炙） |
| 大枣 | 十二枚 | 十二枚（擘） |
| 大黄 | 二两 | 二钱 |

**煎服法：** 上八味，以水一斗二升，煮取六升，去滓再煎，温服一升，日三服。

倪师特别强调：**去滓再煎**是柴胡剂的特点，小柴胡汤、大柴胡汤、柴胡桂枝干姜汤都是如此。为什么？因为柴胡这味药，它的药性要「和」——去滓再煎，就是让药气更纯、更融合，和解的力量才出得来。你如果连渣一起煮了就喝，那叫「生柴胡气」，升散太过，反而不好。


## 🫀 倪师核心病机与水火气化

倪师讲大柴胡汤，开宗明义一句话：**「少阳阳明并病，就是小柴胡汤证加上肚子痛、便秘。」**

诸位要抓清楚这个方子的灵魂——它是少阳和阳明之间的「枢纽方」。

少阳是什么？三焦和胆。少阳主枢，是人体水火气机升降出入的转轴。小柴胡汤证是少阳枢机不利，但阳明还没成实。可如果少阳不解，郁而化热，热邪往阳明那边一推，肠子里的大便就被「烧干」了——津液被热邪灼伤，大便硬结在里头出不来。这时候你光用小柴胡不行了，为什么？因为小柴胡没有人参，它和解有余，攻下不足。

**大柴胡汤的关键变化在哪里？**

第一，**去了人参、甘草**。倪师说：「人参是补虚的，甘草是缓中的。现在肚子里有实热堵着，你还在那里补，还在那里缓，这叫关门留寇！实热在里面，你补一分，它旺一分。」所以大柴胡汤把小柴胡汤里的人参、甘草拿掉，换成什么？换成**大黄、枳实、芍药**——这就是半个小承气汤的思路进来了。

第二，**加重生姜**。小柴胡汤生姜三两，大柴胡汤生姜五两。为什么？因为呕不止。倪师说：「生姜是散水气的，胃里有水气往上冲，人才会呕。生姜加重，就是把胃里的水散掉，让水往下走，不走上面。」同时生姜配半夏，这就是小半夏汤的底子，止呕的祖方。

第三，**芍药三两**。芍药干什么？**敛阴、缓急、止痛**。少阳阳明并病，心下急、郁郁微烦，那个「急」字就是拘急、绷紧的感觉。芍药把绷紧的筋脉松开，同时它还能把被热邪伤掉的津液收回来。倪师讲：「芍药是酸味的，酸能收，能把津液收住，不让它继续被烧干。」

所以这个方的水火气化格局是什么？

**少阳火郁→推热入阳明→灼伤津液→大便硬结→浊气上冲（呕）→心下拘急（痛）**

大黄把阳明实热从大便推出去——这是「釜底抽薪」；枳实把痞硬打散；芍药把津液收住、把拘急松开；柴胡黄芩和解少阳，把半表半里的邪热透出去；半夏生姜把胃中水气降下去止呕。**有升有降，有和有攻，有散有收**——这就是大柴胡汤的妙处。


## 🎯 临证眼目与方证相应

**核心抓手（问诊时必须问到的）：**

1. **往来寒热**——一阵冷一阵热，这是少阳的招牌。倪师说：「病人会说『我一下子觉得冷，一下子觉得热』，这就是柴胡证。」
2. **呕不止**——注意，不是偶尔恶心，是持续性的呕，或者说恶心感一直不退。
3. **心下急、心下满痛**——胃脘到胁肋这一带，按下去绷紧、有抵抗感、甚至痛。倪师强调：「你手一按他的胃脘，绷得紧紧的，像一块板一样，这就是心下急。」
4. **便秘**——大便不通，或者大便硬、排不干净。这是阳明腑实的铁证。
5. **郁郁微烦**——情绪烦躁，但还没到大承气汤那种「谵语、烦躁不安」的程度。倪师说：「微烦就是心里有点烦，但人还是清楚的。」
6. **舌苔黄干**——舌苔黄是热，干是津液伤了。

**关键鉴别点：**

| 鉴别 | 大柴胡汤 | 小柴胡汤 | 大承气汤 |
|------|----------|----------|----------|
| 便秘 | 有 | 无 | 有（严重） |
| 呕 | 呕不止 | 喜呕 | 一般无呕 |
| 心下 | 急、满痛、拒按 | 痞硬但不痛 | 脐周硬满痛 |
| 寒热 | 往来寒热 | 往来寒热 | 但热不寒 |
| 烦躁 | 郁郁微烦 | 心烦 | 谵语、烦躁 |

**随证加减法（倪师常用）：**

- **黄疸**：加茵陈、栀子——少阳阳明合病发黄，大柴胡汤加茵陈蒿汤的思路。
- **胆结石痛**：加金钱草、海金沙、鸡内金——倪师治胆结石，大柴胡汤是底方，加这三味专门化石。
- **胰腺炎**：加厚朴、芒硝——加强攻下之力。
- **热重**：加石膏——阳明热盛，大柴胡汤加石膏。
- **呕甚**：加重半夏、生姜——或者加吴茱萸。
- **痛甚**：加重芍药——芍药甘草汤的缓急止痛思路。


## 🗣️ 倪师讲义实录与医案精粹

倪师讲大柴胡汤，最精彩的一段原话：

**「你们看这个方子，小柴胡汤里去掉了人参和甘草，加上大黄、枳实、芍药，這就是大柴胡汤。为什么要去掉人参？因為肚子里有东西堵到了，你再加人参，那堵得更厉害。就像你家水管堵了，你还在那里灌水，那不是越灌越堵吗？大黄就是通水管的，枳实就是把那个堵的东西打散，芍药就是把水管壁收敛一下，不让它再受伤。」**

关于「去滓再煎」，倪师说：

**「柴胡汤为什么要去滓再煎？因为柴胡这个药，它的气很清，它的味很薄。你如果连渣一起煮，那个浊气就上来了。去滓再煎，就是取它的清气，把浊气去掉。你看小柴胡汤、大柴胡汤、柴胡桂枝干姜汤，都是去滓再煎。这是张仲景的秘法，你们要记住。」**

**典型医案——胆结石：**

倪师讲过一个胆结石的案例：病人右胁下痛，痛到背后，往来寒热，恶心呕吐，大便三四天一次，硬得像羊粪。舌苔黄厚，脉弦数。倪师开大柴胡汤加金钱草、海金沙、鸡内金。一剂下去，病人排出很多绿色的大便，痛减大半。三剂后，症状全消。倪师说：「胆结石就是少阳阳明合病，胆汁排不出来，堵在胆管里，热就起来了。大柴胡汤把胆管打通，再加三金化石，石头就排出来了。」

**典型医案——胰腺炎：**

倪师讲：「胰腺炎，西医说是胰脏发炎，中医看就是少阳阳明合病，心下满痛，按之更痛，便秘，呕。大柴胡汤加厚朴、芒硝，一剂下去，大便一通，痛就减轻。为什么？因为胰脏和胆管是通的，胆管一通，胰管就通了。」

**服药后的排病反应：**

倪师说：「吃了大柴胡汤，第一个反应就是大便通，可能一天拉两三次，拉出来的是又臭又硬的大便，甚至带点黏液。拉完之后，肚子就不痛了，也不呕了。有的病人会出一点汗，这是少阳透出来的汗。还有的病人会放屁，腹中雷鸣，这是气机通了。你不要怕，这是排病。」

**特殊煎服法：**

倪师强调：「生姜要切片，大枣要掰开，枳实要炙过。大黄最后放，煮两三沸就行，不要久煮，久煮就失去攻下的力量了。去滓再煎，这是柴胡剂的规矩，不能省。」


**总结一句话：** 大柴胡汤就是小柴胡汤的「升级版」——少阳不解，热入阳明，心下急、呕不止、便秘，这就是大柴胡汤证。和解少阳，通下阳明，一升一降，一和一下，病就去了。
