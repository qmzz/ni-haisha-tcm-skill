# 白头翁汤

## 📜 经方出处与原方配比

**《伤寒论》条文原文：**

> **371条**：“热利下重者，白头翁汤主之。”
>
> **373条**：“下利欲饮水者，以有热故也，白头翁汤主之。”

**《金匮要略·呕吐哕下利病脉证治》**：
> “下利，寸脉反浮数，尺中自涩者，必清脓血，以有热故也，白头翁汤主之。”

**原方组成与汉制配比：**

| 药味 | 汉制剂量 | 现代比例 |
|------|----------|----------|
| 白头翁 | 二两 | 2 |
| 黄柏 | 三两 | 3 |
| 黄连 | 三两 | 3 |
| 秦皮 | 三两 | 3 |

**煎服法**：上四味，以水七升，煮取二升，去滓，温服一升。不愈，更服一升。

> 倪师强调：这方子四味药全是苦寒药，比例上白头翁为君，二两对三两，它是最重要的。你不要去加减，一加减就走样。

## 🫀 倪师核心病机与水火气化

倪师讲白头翁汤，一句话点破：**“这是纯热利，肠子里有热毒，拉都拉不完。”**

什么叫“热利下重”？就是肛门坠胀，蹲在厕所半天起不来，拉完了还想拉，拉出来的是臭秽的、黏黏的、带脓血的——**这就是热邪堵在大肠里，肠子在抽筋，但拉不干净。**

从水火气化上讲，心与小肠相表里，心火要下行到小肠，这是正常的气化。如果**心火过亢，或者肝经郁火下迫**——厥阴肝木生心火，木火太旺，火性急迫，直冲大肠——那大肠就像被火烧过一样，里面的津液被烧干、气血被烧烂，出现脓血。

> 倪师原话大意：“**厥阴篇的热利，就是肝火烧到大肠了。肝木克脾土，木火太旺，土受不了，就下利。但这不是寒利，这是热利，你不能用干姜、附子，一用就坏。**”

为什么用白头翁？白头翁这味药，苦寒入血分，专门清肝经和大肠的热毒。秦皮苦涩，一能清热，二能收涩——**热毒清了，肠子不再抽筋了，再加上涩剂把肠壁收住，利就止了。**

黄连、黄柏，清下焦湿热，一个入心，一个入肾，把中下焦的火一路撤下来。四味药合在一起，**苦寒直折，清热凉血，涩肠止利**，直击热利下重的病根。

## 🎯 临证眼目与方证相应

**核心抓手（问诊时的鉴别点）：**

- **口渴**：必欲饮水，喜冷饮——有热故也。
- **大便**：臭秽黏腻，或纯下脓血，里急后重，肛门灼热。
- **小便**：短赤。
- **脚温**：手脚是温的，甚至发热——没有四逆。
- **脉象**：寸脉浮数，尺中自涩（《金匮》语），或滑数有力。
- **舌象**：舌红苔黄腻，甚至焦黑。

**关键鉴别——与桃花汤的分水岭：**

| | 白头翁汤 | 桃花汤 |
|--|----------|--------|
| 性质 | 纯热利 | 纯寒利 |
| 口渴 | 欲饮冷水 | 不渴，或渴喜热饮 |
| 大便 | 臭秽脓血，里急后重 | 下利清谷，滑脱不禁，无臭 |
| 腹痛 | 灼痛、绞痛 | 隐痛、冷痛 |
| 手脚 | 温或热 | 冰冷（四逆） |
| 脉 | 数、滑 | 微细、迟 |

> 倪师警告：**“这两个方子是天壤之别。热利用了桃花汤，等于火上浇油；寒利用了白头翁汤，等于雪上加霜。搞错了，一条命就没了。”**

**随证加减：**

- 若**下利虚极**（产后或久利伤阴），加**甘草、阿胶**——《金匮》白头翁加甘草阿胶汤。
- 若**腹痛甚**，加**白芍、木香**，但倪师说原方一般不轻动。
- 若**兼表证发热恶寒**，先用葛根汤解表，再攻里。
- 若**热毒极盛，神昏谵语**，可合**黄连解毒汤**意。

**与相似经方要诀：**

- **葛根芩连汤**：表未解，热利兼喘汗，脉促——先表后里。
- **黄芩汤**：热利之轻者，腹中挛痛，无脓血——比白头翁汤轻。
- **大承气汤**：燥屎内结，热结旁流，纯利清水——那是堵，不是热利。
- **乌梅丸**：厥阴寒热错杂，久利——寒热并用，与白头翁汤纯寒截然不同。

## 🗣️ 倪师讲义实录与医案精粹

倪师讲白头翁汤，最精彩的一段是说：

> **“你们看这个‘下重’，什么叫下重？病人跟你讲，医生啊，我蹲在厕所里头，想死的心都有了，拉了半天，就挤出来一点点，站起来又想拉，肛门坠得跟挂了秤砣一样——这就是下重。热毒堵在大肠里，肠子一直在抽筋，它不让你拉干净。白头翁汤下去，一剂知，二剂已。”**

关于热利的形象比喻：

> **“肠子发炎就像马路被火烧了，洒水车救不了，你得用灭火器。白头翁、秦皮、黄连、黄柏，四味药就是四支灭火器，苦寒直折，一泼下去火就灭了。但你要是用成干姜附子——那叫火上浇油，火更旺，肠子直接烧穿了。”**

**典型临证医案（倪师风格）：**

> 一个病人，下利三天，一天跑二十几次厕所，拉的全是红白相间的黏液，肛门灼热，肚子绞痛，渴得要命，喝冷水。西医说是“细菌性痢疾”，抗生素打了三天没用。倪师一摸脉，滑数有力，一看舌苔，黄厚腻。**
>
> 倪师说：这就是白头翁汤证。开原方：白头翁二钱、黄柏三钱、黄连三钱、秦皮三钱。一剂下去，当晚拉出大量臭秽浊物，腹中雷鸣，第二天热退利减，三剂痊愈。**

**服药后的排病反应：**

- **腹中雷鸣**：药力下去，热毒在动，肠子在排邪。
- **先泻后止**：可能有一两次大泻，排出臭秽浊物，这是“排病”，不是坏事。
- **小便转清长**：热从小便走，气化恢复。
- **微汗出**：热从表解，阴阳自和。

> 倪师最后叮嘱：**“白头翁汤，中病即止。热利一止，就不能再吃，再吃伤中阳，反而变成寒利。所以经方不是让你吃到底的，是让你‘知止’的。”**

---

**特殊煎服法**：原方水七升煮二升，分两次温服。不愈，再服一升。倪师说：**“不要加什么生姜大枣，这是纯清热方，加姜枣等于给火场送棉被。”**
