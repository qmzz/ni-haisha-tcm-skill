# 白虎汤

## 📜 经方出处与原方配比

**出处：《伤寒论》阳明病篇、太阳病篇皆有。**

倪师讲白虎汤，先叫你搞懂什么叫“白虎”。不是一只白色的老虎跑出来咬人，而是**西方金神**，主秋令，主肃降，主清凉。天地之间，夏天暑热到了极点，一到秋天，金气一来，热就往下退。白虎汤就是人体里面的“秋令”，负责把阳明经那一股燥热、那一股高烧，像秋风扫落叶一样——**肃降下去**。

**原方组成：**

- 知母 六两
- 石膏 一斤（碎，绵裹）
- 甘草 二两（炙）
- 粳米 六合

**汉制换算（依倪师讲课常用比例）：**

- 知母 六两 ≈ 90g（临床常用 15～30g）
- 石膏 一斤 ≈ 250g（临床常用 30～120g，热盛可重用）
- 炙甘草 二两 ≈ 30g（临床常用 6～10g）
- 粳米 六合 ≈ 90ml（约一小碗，用糯米或一般白米皆可）

倪师特别交代：**石膏一定要打碎，最好绵裹，先煮。** 粳米就是平常吃的米，不要用别的代替。四味药，看起来平平无奇，但配伍的力道——**一剂知，二剂已**。

## 🫀 倪师核心病机与水火气化

倪师讲白虎汤，一句话点破：**“阳明经热，不是阳明腑热。”**

什么叫阳明经热？就是肠胃里面的津液被烧干了，但肠子里面还没有燥屎堵到。热在经上，不在腑里。这个时候你看到病人——

- **大热**：高烧，壮热，不是潮热，是持续性烧，烧到病人自己都觉得烫
- **大汗**：汗出濈濈然，不是微微汗，是汗流浃背，汗出如油
- **大渴**：口渴得要命，想喝冰水，一直喝，喝下去还是渴
- **脉洪大**：脉象来势汹汹，像洪水一样，按下去中空，像葱管

倪师说，这叫什么？这叫**“热在气分”**，也叫**“阳明经热”**。热在阳明，把津液都蒸干了，所以汗出、口渴。汗是心之液，汗出太多，心阳也跟着耗。这个时候，**光用承气汤不行**——肠子里面没有燥屎，你攻下，反而伤正气。要用白虎汤，**清经热，生津液，把火降下来**。

倪师常用一个比喻：**“阳明就像一锅烧开的水，锅盖都快被冲掉了。白虎汤就是往锅底下撤火，同时往锅里加凉水。”** 石膏撤火，知母加水，甘草粳米护住胃气，不让寒凉伤中。

为什么石膏是君药？倪师说，**石膏色白，入肺，肺主皮毛，主肃降。** 阳明经热，其实是阳气不能潜降，全浮在表面。石膏一进去，把热从肺、从皮毛往下压，压到中焦，再从中焦往下走。知母苦寒，专门去热、生津，配石膏，一个撤火，一个加水。甘草、粳米，甘甜入脾，把中焦稳住，让寒凉药不至于直冲下焦。

倪师特别强调：**“白虎汤证，热在经，不在腑。大便不一定不通，有的还下利。你千万不要看到发烧就用承气汤，那是错的。”** 阳明无死证，但误治会死。该用白虎你用承气，该用承气你用白虎，都会出问题。

## 🎯 临证眼目与方证相应

### 抓主证（问诊抓手）

倪师问诊，白虎汤证抓四条：

1. **发热**：壮热，高烧不退，病人自己觉得热，不怕冷，反而怕热
2. **出汗**：汗出不止，皮肤摸上去是烫的、湿的
3. **口渴**：大渴引饮，喜冷饮，喝很多水还是渴
4. **脉**：洪大而数，按之有力，或洪大而中空

**关键鉴别点：**

- **怕冷还是怕热？** 白虎汤证是**但热不寒**。桂枝汤证是恶风恶寒，白虎汤证是恶热。
- **口渴冷热？** 白虎汤证喜冷饮。理中汤证也口渴，但喜热饮，而且下利、腹冷。
- **脚温不温？** 白虎汤证脚是热的，甚至烫的。四逆汤证手脚冰冷。
- **二便？** 白虎汤证小便黄赤、量少，大便或干或正常，不一定秘结。承气汤证大便不通、腹满痛、潮热谵语。

### 随证加减

倪师讲白虎汤的加减，干净利落：

- **渴甚、津液大伤**：加人参，成**白虎加人参汤**。人参补气生津，热盛汗多、脉大而虚者必用。
- **兼气虚、脉浮大而芤**：也是白虎加人参汤。
- **兼身痛、骨节烦疼**：加桂枝，成**白虎加桂枝汤**，治温疟。
- **兼湿、身重**：加苍术，成**白虎加苍术汤**。
- **热盛动风、抽搐**：加羚羊角、钩藤，或合紫雪丹、安宫牛黄丸。

倪师说，**“白虎汤用得好，关键在石膏的剂量。”** 热轻用 30g，热重用 60g、90g，甚至 120g。石膏是石头，你不重用，压不住火。

### 相似经方鉴别

| 方 | 核心区别 |
|---|---|
| **白虎汤** | 阳明经热，大热、大汗、大渴、脉洪大，**无燥屎** |
| **承气汤** | 阳明腑实，潮热、谵语、腹满痛、大便不通，**有燥屎** |
| **桂枝汤** | 太阳表虚，发热、汗出、恶风，**脉浮缓** |
| **白虎加人参汤** | 白虎汤证 + 津气两伤，**渴甚、脉大而虚** |
| **竹叶石膏汤** | 热病后期，余热未清，**气逆欲吐、虚羸少气** |

倪师口诀：**“白虎清经，承气攻腑。一个有屎，一个没屎。一个脉洪大，一个脉沉实。”**

## 🗣️ 倪师讲义实录与医案精粹

### 倪师原话精粹

倪师讲白虎汤，最精彩的一段：

> **“白虎汤，你看它四味药，知母、石膏、甘草、粳米。你以为这是清热的？我告诉你，这是救命的。阳明经热，热到极点，汗一直流，津液一直耗，再不撤火，心阳就脱了。石膏一下去，像秋天一来，暑气就退。知母下去，像给锅里面加凉水。甘草粳米，就是护住你的胃，让你不会因为寒凉而拉肚子。这就是经方的配伍——君臣佐使，不是死的，是活的。”**

他又说：

> **“你们看白虎汤证，病人烧得跟火炉一样，汗出得像淋雨，口渴得想跳井。这个时候，你摸他的脉，洪洪大，像洪水。这就是白虎。白虎是金神，金克木，木是风，风火相煽，金一来，风就息了，火就降了。所以白虎汤叫白虎，不是随便取的。”**

### 典型医案

倪师讲过一个案子：

> **“有一个小孩子，高烧四十度，烧了三天，汗出不止，口渴，一直要喝冰水。西医说是病毒感染，退烧药吃下去，汗更多，烧更高。我一看，脉洪大，舌苔黄燥，这就是白虎汤证。一剂白虎汤，石膏用二两，知母五钱，甘草二钱，粳米一把。煮好，温服。当天晚上，烧就退了，汗也止了，渴也解了。第二天再一剂，痊愈。”**

他还讲过：

> **“白虎加人参汤，治糖尿病口渴，效果很好。病人上消，喝一杯水，小便一杯水，渴不止。石膏清胃热，知母生津，人参补气。热一退，津一回来，渴就止了。”**

### 特殊煎服法

倪师交代白虎汤的煎法：

1. **石膏打碎，绵裹，先煮**。石膏是石头，不先煮，药力出不来。
2. **粳米后下**，煮到米熟，汤成。米不要煮烂，煮烂了汤太稠，反而不好喝。
3. **去滓，温服**。不要冷服，冷服伤胃。
4. **服后观察**：如果热退、汗止、渴解，就停药，不必尽剂。经方讲究“中病即止”。

### 服药后反应

- **热退**：这是最直接的效验，往往一剂下去，几个小时内体温就下降。
- **汗止**：石膏肃降，热退汗自止。
- **口渴减轻**：知母生津，粳米养胃，渴感很快缓解。
- **小便清长**：热从下去，小便从黄赤变清长，这是热退的标志。
- **腹中雷鸣、矢气**：有时候热退过程中，肠子蠕动恢复，会有腹中雷鸣、放屁，这是气机通畅的好现象。

倪师最后叮嘱：**“白虎汤是峻剂，用对了，一剂知，二剂已。用错了，寒凉伤中，病人会拉肚子、胃口变差。所以辨证要准——但热不寒，大渴引饮，脉洪大，这才是白虎。”**
