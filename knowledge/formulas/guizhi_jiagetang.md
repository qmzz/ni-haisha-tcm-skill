# 桂枝加葛根汤

## 📜 经方原典与方剂组成

**出处**：《伤寒论》太阳篇

**原文**：「太阳病，项背强几几，反汗出恶风者，桂枝加葛根汤主之。」

**方剂组成**：

| 药物 | 剂量 | 说明 |
|------|------|------|
| 桂枝 | 三两（去皮） | 解肌发表，温通经脉 |
| 白芍 | 三两 | 敛阴和营，柔肝缓急 |
| 葛根 | 四两 | 升津液，解肌表，通利项背 |
| 生姜 | 三两（切） | 散寒和胃 |
| 大枣 | 十二枚（擘） | 补中益气，调和营卫 |
| 甘草 | 二两（炙） | 调和诸药，益气和中 |

**剂量折算**（汉制→现代）：桂枝15g、白芍15g、葛根20g、生姜15g、大枣12枚、炙甘草10g。

**煎服法**：上六味，以水一斗，先煮葛根，减二升，内诸药，煮取三升，去滓，温服一升，覆取微似汗，不须啜粥，余如桂枝法将息及禁忌。

**核心禁忌**：表实无汗者禁用（当用葛根汤）；脉沉、里虚寒者慎用。

## 🫀 倪师方义推演与核心机理

桂枝加葛根汤，就是桂枝汤这个底子，再加一味葛根。桂枝汤是什么？是调和营卫的第一方，是太阳中风的主方。什么叫中风？就是风伤卫，卫气被伤到了，营卫不调，出现汗出、恶风、脉浮缓——这是桂枝汤证。

在这个基础上，病人出现「项背强几几」。几几是什么？就是脖子后背僵硬绷紧，像小鸟缩着脖子那个样子，转侧不利，拘急不舒。为什么加葛根？关键就在这里。

葛根这味药，你去看它，它是藤蔓之属，能升能散，专门走项背。它的气是往上走的，能把津液升提上来，输布到项背的肌肉筋脉中去。项背为什么会强几几？两个原因：一是风邪客于太阳经输，经气不利；二是津液不能上承，筋脉失养。葛根既解肌发表，又能升津液，一药两用，恰到好处。

**气化机理**：桂枝汤本身是桂枝走卫、白芍走营，一散一收，一阳一阴，把营卫重新调和起来。加葛根之后，葛根把中焦的津液往上提，沿着太阳经的通道，一直送到项背。所以这个方子的气机走向是：中焦（脾胃）→ 上焦 → 项背太阳经输。等于是在桂枝汤调和营卫的基础上，又专门打通了项背这条路径的津液输布。

**与葛根汤的区别**：葛根汤是桂枝汤加葛根再加麻黄。有麻黄就是无汗表实，桂枝加葛根汤是汗出表虚。一字之差，天壤之别。有汗用桂枝加葛根汤，无汗用葛根汤，这是死规矩。

## 🎯 临床抓手与六经辨证要领

**六经归属**：太阳病，太阳中风兼太阳经输不利。

**核心辨证抓手**：

1. **汗出**——这是第一个眼目。有汗，说明表虚，腠理开泄，营卫不固。没有汗？那就不是这个方。
2. **恶风**——怕风，风吹过来不舒服，这是太阳中风的本证。
3. **项背强几几**——后颈到后背这一片，僵硬、紧张、拘急，活动不灵便。这是葛根证的典型表现。
4. **脉浮缓**——浮是病在表，缓是营卫不调、汗出伤津的表现。

**鉴别要点**：

- 有汗 + 项背强 → 桂枝加葛根汤
- 无汗 + 项背强 → 葛根汤
- 有汗 + 无项背强 → 单纯桂枝汤
- 项背强 + 脉沉迟 → 考虑柔痉，栝蒌桂枝汤

**临床扩展应用**：倪师常讲，这个方子不只是治感冒。现代人长期伏案、颈椎病、肩背僵硬酸痛，只要辨证属于津液不升、营卫不和、有汗恶风者，桂枝加葛根汤照样好用。还有一类是面部中风、口眼歪斜初起，如果兼有项背僵硬、汗出恶风，也是这个方子的路子。关键还是抓「汗出、恶风、项背强」这三个主证。

## 🗣️ 倪师讲义实录与发挥

我们介绍伤寒论，太阳篇占了百分之六十以上。太阳篇第一个方就是桂枝汤，第二个就是桂枝加葛根汤。你看张仲景，他就是言简刚中，几个字就把病机讲透了——「项背强几几，反汗出恶风者」。

这个「反」字很有味道。太阳病项背强，一般来说应该是无汗的，是伤寒，是表实。结果这个人反而汗出，说明什么？说明他是表虚，是中风。所以这个「反」字就是在提醒你，不要跟葛根汤搞混了。

葛根这个药，你们要好好体会。它是升提津液的，专门走项背。你看那个葛根，藤蔓绵长，能通达经络，能把脾胃的津液往上输送。所以项背僵硬，就是因为津液上不去，筋脉失养。葛根一上去，津液一升，筋脉一润，脖子就软了，背就不僵了。

我在临床上看到很多颈椎病的病人，脖子硬得像木头一样，你一问，他平时容易出汗，怕风，脉又是浮缓的，这就是桂枝加葛根汤证。你开下去，几剂药下去，脖子就松了。但是你要注意，如果这个人无汗、脉浮紧，那是葛根汤证，你开桂枝加葛根汤就没用，因为力量不够，麻黄不在里面。

还有一点，桂枝加葛根汤的煎法，是先煮葛根，再放其他药。为什么要先煮葛根？就是要先把葛根的药力熬出来，让它先走一步，把津液升提的通路打开，然后其他药再跟上。这就是经方的精妙之处，连煎药的程序都有讲究。

记住：有汗用桂枝加葛根汤，无汗用葛根汤。这是太阳篇项背强几几的两大法门，绝对不能搞错。
