# puhui_san

## 📜 经方出处与原方配比

**经典出处**

《金匮要略·消渴小便不利淋病脉证并治第十三》：

> “小便不利，蒲灰散主之；滑石白鱼散、茯苓戎盐汤并主之。”

此条一出，是三个方并列，都是冲着“小便不利”这四个字来的。仲景老爷子的规矩就是这样——同一条症，摆出三方，让你自己辨证。倪师说这条最容易被读滑过去，因为很多人眼睛只盯着“小便不利”四个字，却不知道底下暗藏着不同的病因：一个是有热有瘀、一个是湿热夹瘀、一个是脾肾虚寒。蒲灰散打的是第一路——**下焦湿热瘀阻、小便短赤、尿时刺痛甚至带血**。

**原方组成与配比**

- 蒲灰 七分
- 滑石 三分

上二味，杵为散，饮服方寸匕，日三服。

汉制一两 ≈ 四分为准，一分 ≈ 6铢。这个方子是**散剂**，不走煎煮，仲景特意强调“杵为散”——打成粉直接吞服，取它直达下焦、清利通窍之性。按原方比例，蒲灰与滑石是 **7 : 3**，换算现代剂量大约：蒲灰 21g、滑石 9g，打成细粉，每次一汤匙（约6–9g），温水送下，一日三服。

记住：**七三比例不能乱动**。蒲灰为主帅，滑石是副将，主次一颠倒，药力方向就偏了。

## 🫀 倪师核心病机与水火气化

倪师讲这个方子的时候，是先问一句——“小便不利，你怎么知道是热还是寒？”

他说，膀胱者，州都之官，津液藏焉，气化则能出矣。这“气化”两个字就是关键。膀胱的水要出来，靠的是下焦有火——小肠的火、命门的热，蒸腾气化，水才能像蒸锅揭盖一样出来。如果下焦的火不够，水就是冷的，冷了就不动，小便滴滴答答出不来，那是寒证，要温阳，像真武汤、肾气丸那种路数。

**但蒲灰散证不是寒，是湿热瘀堵。**

倪师打比方：你看一条水沟，水流通畅的时候，沟底干干净净。可是如果丢了一堆泥沙、烂叶进去——这就是“瘀”——再加上天气又闷又热——这就是“湿热”——水沟就堵住了。膀胱里面也一样。湿热煎熬，水分被蒸得浓稠短赤；瘀血阻络，尿道就涩痛、刺痛，严重的还会刮破血络，尿中带血丝。

**所以这个方的灵魂在于两个字：一个“通”，一个“清”。**

- **蒲灰**——就是蒲黄烧灰存性（也有一说直接用蒲黄），味甘性平，入肝、心包、膀胱，最善**活血化瘀、通淋止痛**。倪师说，蒲黄这味药很特别，它既能止血、又能化瘀——听上去矛盾对不对？可它就是这样，血止住了、瘀也化开了，不走极端。小便里面带血，或者痛得像刀割，就是它上场的时候。
- **滑石**——甘淡寒，利水通淋、清热渗湿。它把下焦那团湿热从小便渗出去，让尿道润滑不涩。倪师形容滑石像“给水管内壁上油”——通路滑了，水自然顺畅。

两味合在一起，蒲灰负责把瘀堵打开、把血络理顺，滑石负责把湿热从小便引走、让水道滑利。**一开一利，一化一渗，膀胱的气化功能就恢复了。**

倪师特别叮嘱：这个方针对的是**实证、热证、有瘀**。如果一个人面色苍白、手脚冰凉、小便清长却尿不出来，那是阳虚，用这个方就是雪上加霜。

## 🎯 临证眼目与方证相应

**抓主证——问诊时的几个抓手：**

1. **小便什么颜色？** 蒲灰散证的小便是短赤、黄赤，甚至带血色。不是清长的。
2. **尿的时候痛不痛？** 一定痛。刺痛、灼痛、涩痛，严重的痛引小腹或尿道如刀割。
3. **口渴不渴？** 这个方证一般不渴，或者渴了也不想多喝水。跟五苓散证那种“渴欲饮水”的水逆刚好相反。
4. **脚温不温？** 脚是温的，下焦还有热，不是四逆汤那种冰脚。
5. **小腹按诊：** 小腹可能有胀满或压痛，提示下焦有瘀阻。

**核心鉴别点：**

| 方证 | 关键鉴别 |
|------|----------|
| **蒲灰散** | 小便短赤、涩痛带血、脚温、不渴、有瘀热 |
| **五苓散** | 口渴欲饮、小便不利、微热、水逆（喝水就吐） |
| **猪苓汤** | 小便不利、口渴、心烦失眠、阴虚水热互结 |
| **茯苓戎盐汤** | 小便不利但无热象，脾肾偏虚，尿色淡 |
| **滑石白鱼散** | 同条并列方，也治小便不利，但重用乱发、白鱼，偏于化瘀利水 |

**随证加减：**

- 尿血明显、血丝多：蒲灰可以加量，或加**蒲黄炭**增强止血化瘀。
- 刺痛剧烈、瘀象重：可加少量**琥珀粉**冲服，化瘀通淋、安神定痛。
- 湿热偏重、尿黄浊：可加**车前子、木通**，增强清热利湿之力。
- 若兼有肾虚腰酸：合**六味地黄丸**或加**怀牛膝**，攻补兼施。
- 若兼结石（石淋）：合**海金沙、金钱草、鸡内金**，化石通淋。

**倪师特别提醒：** 这个方是**散剂**，不要随便改成汤剂。散剂走散、直达下焦，汤剂走全身、力量分散。原方怎么用就怎么用，不要自作聪明。
