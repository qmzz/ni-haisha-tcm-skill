# 葛根汤

## 📜 经方原典与方剂组成

**《伤寒论》原文：**

> 太阳病，项背强几几，无汗恶风，葛根汤主之。
>
> 太阳与阳明合病者，必自下利，葛根汤主之。

**葛根汤方：**

葛根四两 麻黄三两（去节） 桂枝二两（去皮） 芍药二两 甘草二两（炙） 生姜三两（切） 大枣十二枚（擘）

上七味，以水一斗，先煮麻黄、葛根，减二升，去白沫，内诸药，煮取三升，去滓。温服一升，覆取微似汗，余如桂枝法将息及禁忌。诸汤皆仿此。

**剂量折算（汉制）：**

- 葛根四两 ≈ 60g
- 麻黄三两 ≈ 45g
- 桂枝二两 ≈ 30g
- 芍药二两 ≈ 30g
- 炙甘草二两 ≈ 30g
- 生姜三两 ≈ 45g
- 大枣十二枚

**煎服法关键：** 先煮麻黄、葛根，去白沫后再入诸药。白沫是麻黄中的碱类物质，不去则令人心烦。温服一升，覆被取微似汗，不可如水流漓。余如桂枝汤将息法——服后啜热稀粥，温覆，禁生冷、黏滑、肉面、五辛、酒酪、臭恶等物。

**禁忌：** 表虚有汗者禁用（有汗用桂枝加葛根汤）；尺脉迟弱、阳虚者慎用麻黄。


## 🫀 倪师方义推演与核心机理

葛根汤这张方，你不要把它看成单纯的发汗剂。它的核心在“项背强几几”这五个字。几几是什么？就是鸟的翅膀缩起来那个样子，脖子和后背僵硬、绷紧、转侧不利。这个症状说明寒邪已经不在皮肤表面了，它进到了项背的肌腠、筋脉之间，把太阳经的气血津液冻住了。

**为什么用葛根？**

葛根这味药，是这方子的灵魂。它从地里挖出来，藤蔓能长到几十米，一路往上攀，它的本性就是“升提津液”。项背那个地方，是太阳经和阳明经交接之处，寒邪把津液凝住了，筋脉失养，所以强几几。葛根一下去，把肠胃里的津液往上提，提到项背，筋脉得到濡润，僵硬就解开了。你看《神农本草经》讲葛根“主消渴，身大热，呕吐，诸痹”，这个“痹”就是不通，就是项背强几几的根源。

**麻黄与桂枝的配合：**

麻黄三钱去节，桂枝二钱，这是发汗的组合，但葛根汤的麻黄不是拿来单打独斗的。桂枝汤打底——桂枝、芍药、生姜、大枣、甘草——这是调和营卫、固护中焦的。麻黄在这个基础上，借着桂枝的推动，把毛孔打开，把寒邪往外赶。但因为有葛根在前面升提津液，所以这个汗出得来，津液不伤，项背的僵硬随汗而解。

**无汗恶风是关键：**

有汗用什么？桂枝加葛根汤。无汗才用葛根汤。无汗说明表闭得紧，毛孔完全关死了，寒邪一点出路都没有，所以要用麻黄去开。恶风说明卫气还在抵抗，病还在太阳层面，没有深入。

**太阳与阳明合病，必自下利：**

这一条你要特别注意。太阳的表邪没有解，阳明里气又不足，寒邪往下一压，肠胃就受不了，直接下利。这个下利不是热利，是寒利，是表邪内迫造成的。葛根汤一吃，表解了，津液升上去了，下面的压力一松，利自止。这就是“逆流挽舟”的道理——病在下，治在上；病在里，透于表。葛根本身还能升提肠胃的清阳，所以对下利有直接作用。

整个方子的气化机理：**桂枝汤固中焦、和营卫，麻黄开表闭，葛根升津液、解项背，姜枣草补中焦以助汗源。** 汗出而津不伤，表解而里自和。


## 🎯 临床抓手与六经辨证要领

**六经定位：** 太阳病，表实证，兼阳明津液不升。

**核心辨证抓手：**

1. **项背强几几**——这是第一抓手，从后脑勺到肩胛骨内侧那一片，僵硬、酸胀、转侧不利。病人会说“脖子好像不是自己的”“后背像背了一块板”。
2. **无汗**——皮肤干燥，摸上去没有湿润感，毛孔紧闭。
3. **恶风**——怕风吹，怕空调，风吹过来不舒服。
4. **脉浮紧或浮数**——浮是病在表，紧是寒邪束表，数是正气抗邪。
5. **可能伴有下利**——太阳阳明合病时出现，这个下利是水样便，不臭，肚子不痛或微痛。

**临床扩展应用（倪师常用）：**

- **颈椎病、落枕**——只要是无汗、项背僵硬，葛根汤一剂下去，汗出即松。落枕的，加苍术；久痛的，加威灵仙。
- **小儿感冒初起**——小孩感冒发烧，无汗，脖子硬，用葛根汤。剂量按年龄折算，小儿用原方三分之一到二分之一。
- **面瘫初期**——无汗恶风，脸歪，葛根汤加全蝎、蜈蚣。葛根升提津液到面部，麻黄开表，寒邪一去，经气恢复。
- **鼻窦炎**——前额痛，鼻涕浓稠，无汗，葛根汤加辛夷、苍耳子、白芷。葛根提到阳明经，把鼻窦的郁热透出来。
- **急性肠胃炎**——又吐又拉，发烧无汗，葛根汤加半夏。这是太阳阳明合病下利的典型。
- **刚痉**——《金匮》讲“太阳病，无汗而小便反少，气上冲胸，口噤不得语，欲作刚痉，葛根汤主之”。痉病就是筋脉拘急，葛根汤解表升津，筋脉得养，痉自止。

**与桂枝加葛根汤的鉴别：**

| | 葛根汤 | 桂枝加葛根汤 |
|---|---|---|
| 汗 | 无汗 | 有汗 |
| 麻黄 | 有 | 无 |
| 适用 | 表闭紧，津液不升 | 表虚，营卫不和 |

**针灸辅助：** 针风池、大椎、后溪、申脉，针后加艾灸，助阳气驱寒。项背僵硬严重的，在膀胱经刮痧，把表邪透出来。

**关键注意：** 麻黄剂量要因人而异。北方人壮实，可用原量；南方人瘦弱，麻黄减到二钱甚至一钱半。心脏病、高血压、失眠患者，麻黄要慎用或不用，改用荆芥、防风代替。


## 🗣️ 倪师讲义实录与发挥

倪师讲葛根汤，反复强调两个字——“津液”。

他说：“你看那个葛根，藤蔓长得那么长，它能把地下的水一路吸上来，吸到最高的地方。人身上项背是最高的地方，寒邪把那里冻住了，津液上不去，筋就硬了。葛根一下去，把肠胃的津液提上去，项背得到滋润，几几就没了。”

关于麻黄，倪师特别指出：“麻黄是青龙，能行云布雨。但你要有水源给它，没有津液，麻黄一发汗，人就干了。葛根汤高明在哪里？它有葛根在前面升津液，有桂枝汤在后面补津液，麻黄只是打开门让邪出去。所以这个方子，发汗而不伤津，解表而不伤正。”

讲太阳阳明合病下利时，倪师打比方：“就像房子外面着火了（太阳表邪），屋里的人想从后门跑（下利），结果后门也被烟堵住了。葛根汤一吃，先把前门的火灭了（解表），再把烟抽走（升津液），后门自然就通了，利就止了。所以你不要看到下利就去止利，要治它的源头。”

倪师还提到临床上的一个诀窍：“病人项背强几几，你摸他的脉，如果是浮紧的，无汗，葛根汤一剂知，二剂已。如果脉是沉细的，那是少阴证，项背强是阳虚不能温煦，那就不是葛根汤了，要用附子汤。所以脉象是定生死的关键。”

对于煎服法，倪师强调：“先煮麻黄、葛根，去白沫，这个步骤绝对不能省。白沫是麻黄的毒，你不去，病人吃了心烦、心跳加速，以为是药不对，其实是你的煎法不对。经方的每一个细节，都是几千年传下来的经验，你不要自作聪明去改。”

最后倪师总结：“葛根汤是太阳病表实无汗、项背强几几的第一方。它的魂在葛根，它的力在麻黄，它的根在桂枝汤。你把这个方子吃透了，颈椎病、落枕、面瘫、鼻窦炎、急性肠胃炎，都在你的手掌心里。”
