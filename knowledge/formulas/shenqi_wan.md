# 肾气丸

## 📜 经方出处与原方配比

**经典出处：**

《金匮要略·血痹虚劳病脉证并治第六》：

> “虚劳腰痛，少腹拘急，小便不利者，八味肾气丸主之。”

《金匮要略·痰饮咳嗽病脉证并治第十二》：

> “夫短气有微饮，当从小便去之，苓桂术甘汤主之，肾气丸亦主之。”

《金匮要略·消渴小便不利淋病脉证并治第十三》：

> “男子消渴，小便反多，以饮一斗，小便一斗，肾气丸主之。”

《金匮要略·妇人杂病脉证并治第二十二》：

> “问曰：妇人病，饮食如故，烦热不得卧，而反倚息者，何也？师曰：此名转胞，不得溺也。以胞系了戾，故致此病。但利小便则愈，宜肾气丸主之。”

**原方组成与汉制换算：**

| 药物 | 原方剂量 | 现代参考用量 | 倪师常用比例 |
|------|----------|--------------|--------------|
| 干地黄 | 八两 | 24钱（约72g） | 8 |
| 山药（薯蓣） | 四两 | 12钱（约36g） | 4 |
| 山茱萸 | 四两 | 12钱（约36g） | 4 |
| 泽泻 | 三两 | 9钱（约27g） | 3 |
| 茯苓 | 三两 | 9钱（约27g） | 3 |
| 牡丹皮 | 三两 | 9钱（约27g） | 3 |
| 桂枝 | 一两 | 3钱（约9g） | 1 |
| 附子（炮） | 一枚 | 3钱（约9g） | 1 |

上八味，为末，炼蜜为丸，如梧子大，酒下十五丸，日再服。倪师常以汤剂加减使用，取“丸者缓也”之意，但急症时亦作汤剂。

**倪师特别强调的比例关键：** 桂枝与附子的用量极小——一两对八两，这就是经方的秘密。桂枝走心，附子走肾，两味药加进去就是“点火”的，是启动气化之力的钥匙，量少反而能四两拨千斤，引火归元。后世把桂附拿掉变成六味地黄丸，那就是死方，只能滋阴，不能气化。

## 🫀 倪师核心病机与水火气化

倪师讲肾气丸，从来不讲什么“肾阳虚”“肾阴虚”这种后世空话。倪师直接画图给你看：

**人身上有两股力量，一个是火，一个是水。**

火从心脏来——心属火，这是君火。君火要下行，经过肺的肃降，入到小肠。小肠是关元、气海关元所在，小肠的火在下面烧，这就是“相火”的源头。肾水在下面，被小肠的火一烧，水就气化，蒸腾上去。这个气化上来的水，才是真正的“津液”，才能润泽五脏六腑。

**水火要既济，靠的是什么？靠的是中间这个“气化”功能。**

肾气丸证的病人是什么状态？——**下面寒掉了，上面反而燥。** 小肠不热了，肾水不能气化上来，上面就干渴，但喝下去的水又直接从小便排掉，因为下焦没有火去蒸化它。所以病人说“我渴得要死，喝一碗水就尿一碗”，这就是《金匮》说的“饮一斗，小便一斗”。这不是糖尿病是什么？倪师说，西医叫糖尿病，我们叫消渴，处方开出来就是肾气丸。

**肾气丸的结构，倪师拆给你看：**

- **桂枝 + 附子** = 点火。桂枝走心，让心火往下走；附子入肾，把命门火点起来。两味药量最少，但最关键。没有这两味，剩下的六味就是一堆死药，补进去化不开，反而变成湿。
- **干地黄八两** = 补肾水、填髓。水要足，火才有所附。
- **山药、山茱萸** = 一个补脾固精，一个补肝固脱。肝脾肾三脏同补，但是——倪师强调——这三味是“填”的，是加材料的。
- **泽泻、茯苓、牡丹皮** = 三泻。泽泻泻肾中浊水，茯苓利中焦之水，牡丹皮清肝中郁热。有补有泻，补而不滞。

**为什么叫“肾气”丸，不叫“肾阳”丸？**

倪师原话：气就是功能。肾气丸不是去补那个物质，是恢复肾的气化功能。所以你看它的结构——真正的大剂量是地黄、山药、山茱萸，大量地填精补髓；桂枝附子只有一点点，是去启动的。填满水，再点火，水一滚，蒸气就上来了。这才是“气”。

## 🎯 临证眼目与方证相应

**倪师抓主证（问诊时的抓手）：**

1. **口渴，但不想喝冷水，或喝热水才舒服。** 这是下焦寒、上焦燥的核心矛盾。如果病人渴饮冷水、大汗、脉洪大，那是白虎加人参汤，不是肾气丸。
2. **小便不利，或小便反多。** 这两个看似矛盾，其实是一个理——气化不够。气化不够，水排不出去就“不利”；气化不够，水直接漏下去就“反多”。两种情况都可用肾气丸。
3. **少腹拘急。** 肚脐以下这一圈，病人说“绷绷的、紧紧的、不舒服”，按下去不痛，就是拘急。这是下焦虚寒、水气不化。
4. **脚冷，膝盖冷。** 倪师要求病人脱袜子摸脚——脚是热的还是冷的？脚冷到膝盖，这是下焦寒的铁证。
5. **腰痛，劳则加重。** 这种腰痛不是闪腰那种刺痛，是绵绵的酸痛，躺一躺好一点，一累就犯。
6. **转胞——妇人烦热不得卧，但饮食如故。** 倪师特别点出：这妇人能吃能喝，但就是烦热睡不着，要靠着东西才能呼吸。为什么？因为胎压到膀胱，水排不出去，水气往上冲，冲到心肺就烦热喘逆。肾气丸一下去，小便一通，水气一泄，烦躁顿消。倪师说，这个方你拿到手，妇人怀孕七个月小便不通，医院说要导尿，你开肾气丸，一剂就通。

**关键鉴别：**

| 方剂 | 核心区别 |
|------|----------|
| **苓桂术甘汤** | 短气有微饮，但以中焦水饮为主，心下逆满、起则头眩。肾气丸则以下焦虚寒、腰痛脚冷为主。 |
| **五苓散** | 口渴、小便不利、脉浮、微热，是表邪入里、膀胱气化不利。肾气丸是纯虚证，无表证，脉多沉细。 |
| **真武汤** | 腹痛、小便不利、四肢沉重疼痛、自下利，是阳虚水泛。肾气丸则偏于精血不足而气化无力，无下利、无沉重。 |
| **六味地黄丸** | 无桂附，纯补阴，不能气化。倪师批评：现在人拿六味地黄丸当补肾药天天吃，吃得满脸暗、胃口全无，就是因为没有桂附去气化，补进去的全是湿。 |

**随证加减（倪师常用）：**

- 脚冷甚、命门火衰 → 附子加至五钱，桂枝加至三钱。
- 夜尿频多、小便清长 → 加益智仁、乌药，或合缩泉丸。
- 腰痛如折、不能转侧 → 加续断、杜仲、补骨脂。
- 消渴甚、渴饮不止 → 加天花粉、麦冬，但倪师强调：绝不能因渴而撤桂附，桂附才是治渴的根本。
- 转胞、小便不通 → 合五苓散，或加通草、王不留行。
- 痰饮短气 → 合苓桂术甘汤。

## 🗣️ 倪师讲义实录与医案精粹

**倪师讲肾气丸，开口就是大白话：**

“你看这个处方，八两地黄，四两山药，四两山茱萸——全是补药，对不对？然后三两泽泻、三两茯苓、三两丹皮——这是泻药。最后，一两桂枝，一枚附子。你注意看，桂枝和附子的量，加起来不到其他药的五分之一。为什么？因为这是**导火线**，不是**炸药包**。你放一大堆桂枝附子进去，火是旺了，但水不够，干烧，烧到最后水烧干了，人更燥。所以经方是**先填水，再点火，火一滚，气就上来了**。”

“什么叫肾气？你到厨房去看，锅里有水，灶下有火，火一烧，水一滚，锅盖上一滴一滴的水珠——那个就是**气**。我们人身上，肾就是那锅水，心脏和小肠就是那团火。火不够了，水滚不起来，锅盖上就没水珠，上面就干。你看到病人口渴，拼命喝水，喝下去水又从小便跑掉了，为什么？因为下面没有火去蒸它。所以你要治消渴，不是去止渴，是去**把下面的火点起来**，水一蒸上来，上面就不渴了。这就是肾气丸。

所以这个方，你拿到手上，不要看它八味药，要看成**两组**：一组是往锅里加水的——地黄、山药、山茱萸；一组是往灶下添柴的——桂枝、附子；还有一组是清锅底的——泽泻、茯苓、丹皮。三组一配合，火一烧，水一开，气化就恢复了。”

**倪师讲转胞医案：**

“有个太太，怀孕七个月，小便解不出来，肚子胀得跟鼓一样，医院说要导尿，插了管子还是解不出来，人烦躁得不能躺，只能坐着喘。她来找我，我一看，饮食如故——能吃能喝，就是小便不通。这就是《金匮》讲的**转胞**。我开肾气丸加五苓散，一剂下去，当晚小便如注，腹胀全消，当天就能躺下睡了。为什么？因为胎气压迫了膀胱，膀胱的气化功能被堵住了，肾气丸把下焦的火一点，五苓散把水一利，气化一通，小便自然就出来了。”

**倪师讲消渴（糖尿病）医案：**

“有个病人，西医说是糖尿病，血糖三百多，每天喝水一加仑，小便也是一加仑，人瘦得皮包骨。他来找我，我一看，脚是冷的，脉是沉的，舌是淡的，口渴但不想喝冰水。我说你这个简单，就是肾气丸证。我开肾气丸作汤剂，重用生地，桂枝附子按原方比例。吃了一个礼拜，血糖降到一百八，口渴减半。吃了两个月，血糖稳定在一百二。他问我能不能停西药，我说你继续吃，等脚热了、口不渴了、小便正常了，再说。后来他脚热了，我就让他把西药停了，到现在五年了，血糖都正常。”

**煎服法与暝眩反应：**

倪师用肾气丸，丸剂作汤剂皆可。作汤剂时，倪师通常：

- 干地黄用**生地黄**，重剂八钱至一两起步，取其凉血清热、滋阴填髓。
- 附子用**炮附子**，先煎四十分钟，去其毒性，存其温阳之力。
- 桂枝用**肉桂**亦可，但倪师多按原方用桂枝，取其走心、通阳、降冲气。
- 八味同煮，温水泡服，日三服。

**服药后的瞑眩反应：**

1. **小便清长，次数增多**——这是下焦寒水被气化排出的表现，倪师说“这是好事情，水排掉了，人反而轻松”。
2. **腹中雷鸣，矢气频作**——这是中焦气机开始运转，寒湿在动。倪师说“你听到肚子咕噜咕噜叫，就知道药对了”。
3. **脚底发热，从下往上暖**——这是命门火开始布达四末，最直接的验证。
4. **口渴减轻，饮水减少**——这是气化恢复的根本标志。
5. **微汗出**——倪师说，有的病人吃完肾气丸，身上微微出汗，这是“水火既济，营卫调和”的表现，不必止之。

倪师最后总结一句话：**“肾气丸，就是让你身体里的那口锅，重新滚起来。”**
