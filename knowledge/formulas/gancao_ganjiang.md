# 甘草干姜汤

## 📜 经方出处与原方配比

- **经典出处**：
  - 《伤寒论》第29条：“伤寒脉浮，自汗出，小便数，心烦，微恶寒，脚挛急，反与桂枝汤，欲攻其表，此误也。得之便厥，咽中干，烦躁，吐逆者，作甘草干姜汤与之，以复其阳。”
  - 《金匮要略·肺痿肺痈咳嗽上气病脉证治第七》：“肺痿吐涎沫而不咳者，其人不渴，必遗尿，小便数，所以然者，以上虚不能制下故也。此为肺中冷，必眩，多涎唾，甘草干姜汤以温之。”

- **原方组成与配比**：
  - 炙甘草四两（汉制），约合现代**15克**（倪师临床常取**二钱至三钱**，即**6～9克**）
  - 炮干姜二两（汉制），约合现代**7.5克**（倪师临床常取**一钱至二钱**，即**3～6克**）
  - 上二味，以水三升，煮取一升五合，去滓，分温再服。
  - 倪师强调：此为“辛甘化阳”之祖方，炙甘草与炮干姜比例**二比一**，不可颠倒。炙甘草补中益气、复脉之本，炮干姜温中散寒、守而不走，两者相合，专复胸中阳气与肺中冷气。

## 🫀 倪师核心病机与水火气化

倪师讲甘草干姜汤，一开口就点破：**“这是张仲景用来救逆的方，专门复阳气，把上面冷掉的肺、下面漏掉的水，一并收拾干净。”**

- **肺中冷，上虚不能制下**：倪师用大白话说，肺像天上的云，心阳像太阳。太阳一弱，云就变冷，冷云不降雨，反而化成涎沫往外吐。肺冷则不能管束下面的水，膀胱就失去约束，所以**遗尿、小便数**。这不是膀胱发炎，是“上面的开关坏掉了”。
- **心阳与小肠火**：倪师常打比方，心脏是引擎，小肠是锅炉。心火要往下走，点燃小肠火，小肠火再蒸化下焦的水，水气才能上蒸为津液。甘草干姜汤就是直接给胸中补一把火，让心肺之间的阳气重新运转起来。干姜温中，甘草补中，中焦一暖，上焦的冷气就散了。
- **虚热与真寒**：条文中“咽中干、烦躁、吐逆”，表面看是热，倪师一针见血：**“这是寒极生热，里面冷到极点，仅存的一点阳被逼到上面，叫浮阳。你再去清热，人就死了。”** 所以用甘草干姜汤，温中复阳，阳一回，浮热自退。
- **配伍直击病根**：干姜炮过，守而不走，专门温肺胃之寒；甘草炙过，补中焦之气，两者一辛一甘，辛甘合化为阳。倪师说：“这不叫发汗，这叫**温复**。阳气回来了，肺不冷了，水能制了，遗尿、涎沫、咽干、烦躁，统统去掉。”

## 🎯 临证眼目与方证相应

- **核心抓手**：
  - **吐涎沫而不咳**：口水多、白色泡沫痰，但不像咳嗽那样频繁，这是肺中冷的铁证。
  - **不渴**：口不渴，或渴但喜热饮，舌淡白，苔白滑。
  - **遗尿、小便数**：尤其夜间尿多，或小儿遗尿，无尿痛、无黄赤。
  - **脚温与手足冷**：倪师特别强调，**“肺中冷的人，脚是冰的，手也冷，但又不是四逆汤那种冷到肘膝。”** 脚温则病退，脚冷则病进。
  - **出汗**：自汗出，但汗是凉的，皮肤摸上去冰的。
  - **眩晕**：肺中冷，清阳不升，头会眩。

- **随证加减法**：
  - 若**咽干、烦躁**明显，加**茯苓、白术**，导水下行。
  - 若**遗尿甚**，加**益智仁、覆盆子**，温肾缩尿。
  - 若**吐涎沫不止**，加**半夏、陈皮**，降逆化痰。
  - 若**中焦虚寒腹泻**，加**白术、人参**，即为理中汤之意。

- **相似方鉴别**：
  - **理中汤**：甘草干姜汤加人参、白术，偏于中焦虚寒、腹泻、腹痛。甘草干姜汤偏于肺冷、遗尿、涎沫。
  - **四逆汤**：甘草干姜汤加附子，偏于少阴阳衰、四肢厥逆、脉微欲绝。甘草干姜汤则阳未亡，只是阳虚。
  - **桂枝汤**：桂枝汤是解表调营卫，甘草干姜汤是温里复阳。倪师说：“一个是开门赶贼，一个是关灯取暖，完全两回事。”

## 🗣️ 倪师讲义实录与医案精粹

- **倪师生动讲解**：
  - “甘草干姜汤，就两味药，你千万不要小看它。张仲景用它来救逆，什么叫救逆？就是医生治错了，病人手脚冰了，咽干了，烦躁了，快要阳脱了，这时候你再用桂枝汤去攻表，人就死掉了。张仲景说，赶紧用甘草干姜汤，**以复其阳**。”
  - “干姜和生姜不一样。生姜是散的，走表；干姜是守的，走里。炮干姜更守，专门温肺、温胃、温中焦。甘草炙过以后，补中益气，还能复脉。这两味药合在一起，就是给身体**生火**。”
  - “你看那个肺痿的病人，吐出来的涎沫，白白泡泡的，像肥皂水一样。你问他渴不渴？不渴。小便呢？一夜跑七八次。脚呢？冰的。这就是肺中冷，上虚不能制下。甘草干姜汤一下去，涎沫少了，小便少了，脚也温了。这叫**温上制下**。”
  - “有的小孩子，十几岁了还尿床，西医说是膀胱过动，中医一看，口水多，脚冷，舌淡，这就是甘草干姜汤证。你给他吃个两三次，尿床就好了。为什么？上面的肺暖了，下面的水就管住了。”

- **特殊煎服法与排病瞑眩反应**：
  - 倪师强调：**“这两味药，不要煮太久，水三碗煮一碗半，分两次温服。喝完以后，让病人喝点热粥，助药力。”**
  - 排病反应：**“有的人喝完，会吐一口白痰，或者打几个嗝，放几个屁，这是寒湿在动，阳气在复。还有人会突然觉得胸口热热的，脚开始温了，这是好现象。千万不要以为是上火，再去吃清热药，那就前功尽弃。”**
  - 倪师医案：曾治一妇人，五十岁，肺痿，吐涎沫不止，遗尿，脚冷，咽干烦躁。前医给清热滋阴药，越吃越重。倪师用甘草干姜汤，炙甘草五钱，炮干姜二钱，两剂后涎沫大减，五剂后遗尿止，脚温脉回。倪师说：“这就是《金匮》的原文，一字不差，你只要对证，效果就是这么快。”
