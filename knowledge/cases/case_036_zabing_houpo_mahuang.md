# case_036_zabing_houpo_mahuang

## 📋 病案实录与四诊信息

- **患者：** 男，55岁，退休职工。
- **主诉：** 咳嗽气喘反复发作三年，加重一周。
- **望诊：** 面色暗滞，如蒙尘垢；舌淡、苔白滑，津液满布。
- **闻诊：** 咳嗽声重浊，喉间痰鸣辘辘，如水鸡声。
- **问诊：** 咳嗽气喘，胸膈满闷，烦热躁扰，痰涎量多色白，状如泡沫，肩背牵痛。
- **切诊：** 脉浮。
- **八纲辨证：** 表里同病，阳证，实证。
- **六经辨证：** 杂病，饮邪迫肺，上焦气逆，郁而化热。

## 🫀 倪师水火病机深层推演

此案眼目，全在“脉浮”与“烦躁”四字。

倪师常言：**“脉浮者，病在上也。”** 此浮脉非太阳表证之浮紧，乃饮邪停聚上焦，逼迫肺气，气机壅塞于胸膈之间，如云雾笼盖，故脉气浮越于外。肺为华盖，主通调水道，今饮邪上逆，肺失肃降，故咳嗽气喘、胸满。喉中痰鸣如水鸡声，正是饮邪激荡气道，寒水之气与肺中津液交争之象。

然最须着眼者，是“烦躁”一症。饮邪本属阴寒，何来烦躁？倪师一语道破：**“饮邪郁久，必化郁热。”** 此热非阳明实热，乃寒饮包裹郁阳，阳气不得宣通，郁而化热，扰及胸膈，故见烦热躁扰。此即大青龙汤证“不汗出而烦躁”之变局，同是寒饮闭郁、郁热内扰，但大青龙偏于表寒闭郁，此则偏于饮邪迫肺、上焦气逆。

更深一层，饮邪从何而来？《金匮》云：“病痰饮者，当以温药和之。”此患者面色暗滞，舌淡苔白滑，明是脾阳不运，水谷不化精微，反聚为饮。饮邪上泛，射肺则咳喘，凌心则胸满，溢于肌腠则肩背疼痛。**病根在脾，病标在肺，病势在上焦。** 若只宣肺不化饮，饮邪不去，咳喘必复；若只温脾不降逆，上焦壅塞不开，烦躁难除。故倪师断此证为：**饮邪迫肺，上焦气逆，郁而化热，表里同病。**

## 💊 经方法度处方与剂量配伍

**厚朴麻黄汤** —— 此方出自《金匮要略·肺痿肺痈咳嗽上气病脉证治》，专为“咳而脉浮者”而设。

| 药物 | 剂量 | 配伍精义 |
|------|------|----------|
| 厚朴 | 15g | 重用为君，行气除满，降上焦逆气，开胸膈壅塞 |
| 麻黄 | 9g | 宣肺平喘，开鬼门以散饮邪，与厚朴一宣一降，复肺之开阖 |
| 石膏 | 15g | 清郁热，止烦躁，量不宜大，取其清透不伤阳 |
| 杏仁 | 9g | 降肺气，与麻黄相配，一升一降，调畅气机 |
| 半夏 | 9g | 燥湿化痰，降逆止呕，涤饮邪之窠臼 |
| 干姜 | 6g | 温中化饮，治生痰之源 |
| 细辛 | 3g | 温散寒饮，开肺窍，通水道 |
| 小麦 | 30g | 养心气，护胃气，防金石之药伤中 |
| 五味子 | 6g | 收敛肺气，防麻黄、细辛宣散太过，一散一收，相得益彰 |

**煎服法：** 先煮小麦熟，去滓，纳诸药，煮取三升，温服一升，日三服。本方以小麦先煎为引，取谷气养胃，使药力缓行上焦，不伤中州。

倪师特别指出：**“此方与小青龙汤只差一味——去桂枝、芍药，加厚朴、石膏、小麦。”** 小青龙汤偏于外寒引动内饮，故用桂枝、芍药调和营卫；此方偏于饮邪迫肺、郁热内生，故用厚朴降气除满，石膏清透郁热，小麦安中护心。**一味之差，法度天壤。** 若见烦躁而误投小青龙，桂枝助热，必增其烦；若见胸满而妄用大青龙，麻黄倍用，必伤其气。仲景制方，丝丝入扣，此之谓也。

## 📈 瞑眩反应与转归追踪

**一诊（7剂）：** 服3剂后，咳嗽减轻，痰量减少，泡沫状痰转稠，烦躁止。此乃饮邪渐化，郁热得清，肺气渐降之佳兆。服完7剂，气喘平，胸满消，能平卧，肩背疼痛大减。脉由浮转缓，舌苔由白滑转薄白。

**二诊：** 咳喘虽平，但饮邪未净，脾阳未复。倪师改**苓桂术甘汤合二陈汤**调理——苓桂术甘汤温脾化饮，崇土制水，绝其生痰之源；二陈汤理气和中，化痰燥湿，扫其残余之饮。此即“病痰饮者，当以温药和之”之根本大法。

**最终转归：** 调理半月，诸症悉平，面色转润，精神渐复。随访三月，未再复发。

## 💡 倪师按语与画龙点睛

倪师尝言：**“治咳喘不知化饮，如隔靴搔痒；化饮不知降气，如扬汤止沸。”**

此案之妙，全在**“脉浮”** 二字。脉浮者，病在上，上者越之，然不可纯用升散。厚朴麻黄汤之精义，在于**“宣降同施、寒温并用、散收兼行”**——麻黄宣肺以开其壅，厚朴降气以平其逆，石膏清透郁热，姜辛温化寒饮，五味子收敛肺气，小麦安中护心。九味药中，有开有阖，有升有降，有散有收，有寒有温，看似矛盾，实乃天衣无缝。

更须看破一层：**烦躁非热，乃郁也。** 饮邪闭郁，阳气不得宣通，故烦。若见烦即投苦寒，则饮邪愈凝，阳气愈郁，祸不旋踵。仲景用石膏，只取清透，不取沉降，且配伍姜辛之温，正是**“火郁发之”**之意。

最后，倪师常诫弟子：**“饮邪之病，标在肺，本在脾。厚朴麻黄汤治其标，苓桂术甘汤治其本。若只治标不治本，暂愈必复。”** 此案一诊攻邪，二诊扶正，攻邪不伤正，扶正不留邪，章法井然，堪为经方实战之典范。
