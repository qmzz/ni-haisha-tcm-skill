# case_028_funren_wenjing

## 📋 病案实录与四诊信息

- **患者：** 女，32岁，职员
- **主诉：** 月经后期、量少已一年，婚后三年久不受孕。

**四诊合参：**

- **望：** 面色萎黄无华，唇口干燥起皮，舌质淡暗，舌边隐有瘀点，苔薄白而润。
- **闻：** 语声低微，气息怯弱，懒言少动。
- **问：** 月经后期，四十至五十日方一行，量少色暗，夹杂血块，小腹冷痛，喜温喜按，得暖则舒；手足心热，入夜尤甚；久不受孕，白带清稀，腰膝酸冷。
- **切：** 脉沉细而涩，重按无力。

**八纲辨证：** 里证、阴证、虚证、寒证，兼夹瘀血。

**六经辨证：** 妇人病，冲任虚寒，瘀阻胞宫，寒热错杂。

**病机关键：** 冲为血海，任主胞胎。冲任虚寒，则血海不温，经水后期而量少；寒凝血滞，瘀阻胞宫，故色暗有块，小腹冷痛；瘀久化热，虚热上浮，故唇口干燥、手足心热。此乃下寒上热、虚中夹瘀之复杂格局，非单纯温补或单纯化瘀所能奏效。


## 🫀 倪师水火病机深层推演

倪师常言：「妇人以血为本，以气为用。冲任二脉，起于胞中，上通于心，下连于肾。冲任一虚，则水火不济，寒热错杂。」

此案之核心，在于**冲任虚寒为本，瘀血阻滞为标，虚热上浮为变**。

**第一层：下焦如冰，血海失温。**  
患者小腹冷痛，喜温喜按，白带清稀，腰膝酸冷，脉沉细涩——此乃少阴火衰，厥阴寒凝，冲任二脉如处冰窖。血得温则行，得寒则凝。寒邪客于胞宫，经水自然后期、量少、色暗。

**第二层：瘀血内阻，新血不生。**  
寒凝则血滞，血滞则成瘀。瘀血不去，新血难生，故经行有块，舌暗有瘀点，脉涩。此瘀非热灼所致，乃寒凝而成，若一味破血逐瘀，反伤正气，瘀必愈甚。

**第三层：虚热上浮，寒热错杂。**  
唇口干燥、手足心热，看似阴虚火旺，实则是下焦阴寒太盛，逼阳上浮，虚火上炎。此火乃无根之火，非实火，非真阴虚，乃「阳不入阴」之象。若误用苦寒清热，则下焦更寒，瘀滞更甚；若单用温燥，则虚火更炽，唇口焦裂。

倪师一针见血：「此证若只温不润，则火上加油；若只清不温，则雪上加霜。必须温经散寒以治其本，养血活血以通其滞，滋阴润燥以敛其浮火。寒热并用，攻补兼施，方得冲任调和。」

**破局之眼：**  
温经汤中，吴茱萸、桂枝温经散寒，直入厥阴、少阴，破下焦之冰；当归、川芎、芍药养血活血，通冲任之滞；人参、甘草补中益气，培土以生血；阿胶、麦冬滋阴润燥，敛上浮之虚火；牡丹皮凉血散瘀，清瘀久所化之热；半夏降逆和胃，生姜温中散寒。全方寒热并用，气血双调，冲任自安。


## 💊 经方法度处方与剂量配伍

**处方：温经汤（《金匮要略》）**

| 药物 | 剂量 | 炮制与用法 |
|------|------|------------|
| 吴茱萸 | 三钱（9g） | 洗，去腥 |
| 当归 | 三钱（9g） | 酒洗 |
| 芍药 | 二钱（6g） | 白芍 |
| 川芎 | 二钱（6g） | 酒炒 |
| 人参 | 二钱（6g） | 党参代亦可 |
| 桂枝 | 二钱（6g） | 去皮 |
| 阿胶 | 二钱（6g） | 烊化，分冲 |
| 牡丹皮 | 二钱（6g） | 去心 |
| 生姜 | 二钱（6g） | 切 |
| 甘草 | 二钱（6g） | 炙 |
| 半夏 | 二钱（6g） | 姜制 |
| 麦冬 | 三钱（9g） | 去心 |

**用法：** 水煎服，日二服，早晚饭后温服。阿胶分两次烊化冲入药液中。

**配伍精义：**

- **吴茱萸配桂枝：** 吴茱萸入厥阴，桂枝入少阴，二药相合，温通冲任，散下焦之寒，为全方温经之核心。吴茱萸用量宜重，三钱为底，方能破冰。
- **当归配川芎、芍药：** 当归补血活血，川芎行气开郁，芍药养血敛阴。三药一通一补一敛，使血行而不伤，补而不滞。
- **阿胶配麦冬：** 阿胶血肉有情之品，补血滋阴；麦冬润肺清心，滋阴降火。二药相合，敛上浮之虚火，润唇口之干燥。
- **牡丹皮配半夏：** 牡丹皮凉血散瘀，清瘀久所化之热；半夏降逆和胃，生姜温中。寒热并调，胃气自和。
- **人参配甘草：** 补中益气，培补后天，使气血生化有源。

**倪师特别强调：** 「温经汤之妙，不在单味药之功效，而在配伍之寒热并调。吴茱萸、桂枝之温，与牡丹皮、麦冬之凉，看似矛盾，实则相成。温者温其下寒，凉者清其上热，下寒得温则瘀化，上热得清则火敛。此乃经方之精妙，非时方所能及。」

**服用时机：** 月经前一周开始服用，至月经来潮停药。连续三个月经周期为一疗程。若经期腹痛甚，可于经期续服，但阿胶减量至一钱半，以免滋腻碍血行。


## 📈 瞑眩反应与转归追踪

**第一月：**  
服药三剂后，小腹冷痛减轻，手足心热略减。服至七剂，月经来潮，周期缩短至三十五日，量较前增加，色转红，血块减少。经期小腹微痛，但可忍受，无大血块。此乃阳气渐复，瘀血渐化之兆。

**第二月：**  
经前续服，周期三十二日，量中，色红，血块明显减少，小腹冷痛基本消失。唇口干燥缓解，手足心热减半。白带转稠，腰膝酸冷减轻。脉象由沉细涩转为沉细，涩象渐去。此乃冲任渐温，瘀滞渐通。

**第三月：**  
月经如期而至，周期三十日，量中，色红，无血块，小腹无冷痛。手足心热消失，唇口润泽，面色转红润。舌质淡红，瘀点消退。脉沉细有力。此乃冲任调和，气血充盈。

**随访：**  
停药后三月，月经规律，基础体温呈双相，第四月即告妊娠。后足月顺产一子，母子平安。

**倪师点评转归：** 「此案之瞑眩，不在剧烈反应，而在渐进之变。初服三剂，小腹冷痛减轻，此阳气初回；七剂经至，周期缩短，此冲任渐温；三月而孕，此气血调和，种子生根。若见初效而停药，则前功尽弃；若见虚火而改弦更张，则寒凝更甚。守方如守城，不可轻动。」


## 💡 倪师按语与画龙点睛

温经汤，乃张仲景为妇人冲任虚寒、瘀血阻滞而设，为妇科调经之祖方。倪师常言：「此方寒热并用，攻补兼施，看似庞杂，实则丝丝入扣。后世妇科诸方，如四物汤、逍遥散、归脾汤，皆从此方化出，然皆不及此方之周全。」

**第一，辨清寒热真假。**  
此案手足心热、唇口干燥，看似阴虚火旺，实乃下寒逼阳上浮。若误投知柏地黄丸、大补阴丸之属，则下焦更寒，瘀滞更甚，经水必闭。倪师强调：「辨寒热，不在上热之下，而在下寒之根。小腹冷痛、白带清稀、腰膝酸冷，此三症为下寒之铁证。有此三症，虽见上热，亦当温下。」

**第二，瘀血之治，温通为要。**  
寒凝血瘀，非热灼所致，故不可一味破血逐瘀。桃仁、红花、三棱、莪术之属，虽能破血，但性偏寒凉，用于寒瘀，反伤阳气。温经汤用当归、川芎、芍药、牡丹皮，活血而不伤正，温通而不助火，此乃治寒瘀之正法。

**第三，冲任之调，贵在气血双补。**  
冲任虚寒，非一日之寒。若只温经散寒，不补气血，则温散之力虽能暂通，但血海空虚，经水虽来亦少。温经汤用人参、甘草补中益气，当归、阿胶补血滋阴，气血双补，使血海充盈，经水自调。

**第四，种子先调经，调经先温经。**  
妇人久不受孕，非独肾虚一端。冲任虚寒，瘀阻胞宫，则胞宫寒冷如冰，何以受孕？温经汤温经散寒，养血活血，使胞宫温暖，瘀血去而新血生，冲任调和，自然受孕。倪师常言：「种子之法，不在补肾，而在调经。调经之法，不在破血，而在温经。温经汤者，种子之圣方也。」

**画龙点睛之笔：**  
此案之妙，在于寒热错杂之辨。下寒为本，上热为标，瘀血为中间之阻。温经汤以吴茱萸、桂枝温下寒，以阿胶、麦冬敛上热，以当归、川芎、芍药、牡丹皮化瘀血，以人参、甘草补中气，以半夏、生姜和胃气。一方之中，寒热攻补，各得其宜。此乃经方之精妙，非时方所能及。倪师叹曰：「温经汤，妇科之圣方，冲任虚寒夹瘀者，非此方不能治。学者当细究其配伍之妙，方知仲景之用心良苦。」
