# 肩髃

## 📍 经络归属与精准取穴法

- 肩髃穴属**手阳明大肠经**，为手阳明与阳跷脉之**交会穴**。大肠经五输穴为：商阳（井金）、二间（荥水）、三间（输木）、阳溪（经火）、曲池（合土），另有大肠经原穴合谷。肩髃不在井荥输经合之列，其定位属大肠经腧穴中的肩部要穴，兼为阳跷脉交会，故能通调阳明经气与阳跷脉气，主司上肢运动与肩部开阖。
- 倪师动态取穴法：令患者**手臂自然下垂**，此时肩端外侧会出现一个**凹陷**，此凹陷即是肩髃。若手臂平举，则凹陷消失，穴随臂移，故取穴时须令患者垂臂取之。倪师常讲：“肩髃这个穴道，你让病人手垂下来，肩膀这边有个凹洞，那就是肩髃。”又或以手下垂时，肩峰前下方凹陷处即是，以指甲切痕为记，再令患者抬手进针。
- 骨度折量辅助：以肩峰至肘横纹为九寸，肩髃在肩峰端下缘，当肩峰与肱骨大结节之间。倪师强调“摸骨找穴”，先摸到肩峰最高点，再往前下寻凹陷，凹陷处即是穴。
- 下针深度与方向：倪师讲肩髃针法，“针下去，**直针**可以，**透针**也可以，一针透下去，可以透到极泉，但一般不必那么深。”常规直刺或斜刺**一寸至一寸半**，视患者胖瘦而定。针感应向下扩散至肩臂，酸麻胀为得气。
- 禁针禁灸法则：肩髃穴**可灸**，倪师常用于肩痛不得举、风热瘾疹等，灸法以温和灸或隔姜灸为主。禁针之说古籍有载，但倪师认为“只要手法对，肩髃是可以下针的，尤其肩关节痛、抬不起来，针肩髃效果非常好。”注意**不可深刺过深伤及肺尖**，瘦人尤须谨慎，以得气为度。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演肩髃的气血流注：肩髃位居肩端，为手阳明经气从臂走肩、上颈入面的**转枢要冲**。阳明经多气多血，肩髃又为阳跷脉交会，阳跷主**一身左右之阳气的开阖与运动**，故肩髃之开阖机理在于**通阳利节、活血散风**。倪师常言：“肩髃这个穴道，是肩膀活动的开关，肩膀不能动，就是阳气堵在这里，针下去，阳气一通，手就抬起来了。”
- 从气化角度看，肩髃能**引阳明经气上达肩臂**，疏通局部气血瘀滞，同时借阳跷脉之性，令阳气左右贯通，故对半身不遂、肩凝不举有破局之效。倪师又讲，肩髃能**散风热**，因阳明主肌肉，风热之邪客于肌表，针肩髃可引邪外出，故治风疹、瘾疹。
- 子母补泻与五行生克：肩髃不属五输穴，故不直接以井荥输经合论母子。但倪师心法常以**经络五行**论之：大肠经属金，肩髃为金经之穴，若肩部虚寒无力，可补其母——土生金，取大肠经合穴曲池（土穴）以补之；若肩部实热肿痛，可泻其子——金生水，取大肠经荥穴二间（水穴）以泻之。肩髃本身则作为**局部开关**，先针肩髃以开其枢，再配曲池、二间调其虚实，此为倪师活用五行于肩部病症之心法。

## 🎯 临床主治与配穴组合手印

- 核心特效主治：
  - **肩臂痛、肩凝不举（五十肩）** ：倪师称肩髃为治肩痛**第一要穴**，凡肩关节抬举困难、夜间痛甚，针肩髃立见松解。
  - **半身不遂、中风后上肢瘫痪**：肩髃配臂臑、曲池、合谷，通阳起废。
  - **风热瘾疹、皮肤瘙痒**：肩髃能散阳明风热，配曲池、血海、三阴交。
  - **颈椎病、肩颈综合征**：肩髃配肩井、天宗，松解肩颈僵紧。
  - **急性肩扭伤**：倪师常**肩髃透极泉**，一针下去，肩部气机顿开。
- 倪师经典对穴与排针组合：
  - **肩髃 + 肩髎 + 肩贞**：三肩齐刺，治肩关节周围炎，肩部前后中三面皆顾。
  - **肩髃 + 曲池 + 合谷**：大肠经本经配穴，治上肢痿痹、风疹。
  - **肩髃 + 肩井 + 天宗**：治肩背痛、颈椎病。
  - **肩髃 + 极泉 + 少海**：治上肢不遂、腋下肿痛。
  - **肩髃 + 外关 + 后溪**：治肩臂痛牵引颈项。
  - 倪师排针心法：“肩膀痛，先针肩髃，再针曲池，再针合谷，三针下去，手就松了。如果还痛，加针肩髎、肩贞，三肩齐下，没有不效的。”

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》中讲肩髃时原话：“**肩髃这个穴道，你让病人手垂下来，肩膀这边有个凹洞，那就是肩髃。** 针下去，可以直针，也可以透针，一针透到极泉，肩膀就开了。五十肩、肩膀抬不起来，针肩髃效果非常好。”
- 又讲：“**肩髃是手阳明大肠经的穴道，大肠经多气多血，肩髃又是阳跷脉的交会，所以它能让肩膀的阳气动起来。** 很多人肩膀痛，晚上睡不好，针肩髃，再配曲池、合谷，当场就能抬起来。”
- 实战手下针感体会：倪师说：“针肩髃，得气的时候，病人会感觉**酸麻一直往下走，走到手臂**，有的会走到手指。如果针感只停在局部，效果就差。这时你可以**稍微提插一下，或者把针尖偏向下方**，让气往下走。”
- 医案故事：倪师曾讲一案例，“有个太太五十肩，手不能梳头，晚上痛到哭。我针肩髃、肩髎、肩贞，三针下去，再针曲池、合谷，**针完叫她抬手，她当场就抬起来了**，她自己都吓一跳。这就是肩髃的开关作用。”
- 针灸秘要：倪师强调：“**肩髃透极泉**，这是治疗肩部重症的绝招。但透针要小心，针要贴着骨头走，不要刺到肺。瘦的人要浅一点，胖的人可以深一点。透过去之后，肩膀整个气机就通了。”又嘱：“**针肩髃，一定要让病人垂臂取穴**，手抬着取穴，穴道就跑掉了，针下去也没用。”
