# 胃俞穴 (BL21)

## 📍 经络归属与精准取穴法

胃俞穴，隶属**足太阳膀胱经**。它在背部的膀胱经第一条侧线上，是**胃的背俞穴**。

倪师在讲膀胱经背俞穴的时候，反复强调一个核心观念：**背俞穴是阳气出入脏腑的后门**。膀胱经在人体背后贴着脊椎两侧循行，它就像一条高速公路，脏腑的阳气、经气都从这条路上转输进出。而胃俞，就是胃的阳气在后背的转输窗口。

**怎么找？**

倪师取穴从来不让你拿尺子量，他讲的是“摸骨法”。

先找**第七胸椎（T7）下缘**，旁开一寸半，这是膈俞。再找**第九胸椎（T9）下缘**，旁开一寸半，这是肝俞。那**第十胸椎（T10）下缘**，旁开一寸半，就是胃俞。

倪师原话大意是：你让病人趴着，从肩胛骨下角往下摸，摸到第七椎，然后往下数到第十椎。第十椎下旁开一寸半——一寸半就是你食指和中指并拢的宽度——那个位置就是胃俞。

**下针深度：** 倪师说，背部的穴位，尤其是膀胱经上的背俞穴，下针**五分到一寸**，针要斜刺，向脊柱方向斜刺，不要直刺往胸腔方向扎。因为底下就是肺和胸膜，扎深了会气胸。倪师特别叮嘱：**膀胱经背部的穴位，安全第一，宁浅勿深。**

**禁灸法则：** 胃俞可以灸，尤其是虚寒性的胃病，灸胃俞效果极好。但倪师也讲过，背部穴位灸的时候要注意不要烫伤，尤其是体瘦的人，骨头突出来，艾炷不要太大。

## ⚡ 倪师经穴气化与破局心法

倪师在讲背俞穴的时候，有一个贯穿始终的框架：**前募后俞**。

前面是募穴——中脘是胃的募穴；后面是俞穴——胃俞是胃的俞穴。一前一后，一阴一阳，合在一起调胃。

倪师的原话精神是：**募穴是开口，俞穴是出口。** 胃的气机如果堵在前面（中脘附近胀满），你可以在后面（胃俞）打开出口，让气有地方走；如果胃的阳气虚弱、运化无力，你在后面（胃俞）给它加一把火，前面的胃口自然就开了。

**胃俞的气化机理，倪师是这样推演的：**

胃属中焦，主受纳、腐熟水谷。胃气以降为顺。胃俞作为胃的背俞穴，它调的是胃的**阳气**和**通降之力**。如果胃阳不足，寒饮停胃，人会泛酸、打嗝、胃胀、吃不下饭。你在胃俞下针或者艾灸，等于从背后给胃的阳气“点火”，让胃重新蠕动起来，把停积的食物和寒饮往下推。

倪师还讲过一层：**胃俞和脾俞是搭档。** 脾俞在第十一椎下，胃俞在第十椎下，两个挨着。脾主升，胃主降。倪师说，你调脾胃的时候，这两个穴常常一起用，一升一降，中焦的轮子就转起来了。

**子母补泻：**

胃属土。足阳明胃经的五行属性是土。胃经的子穴是厉兑（金），母穴是解溪（火）。但倪师在讲背俞穴的时候，重点不在胃经本身的子母补泻，而在于**俞募配穴**的整体调节。他说，胃俞本身不是子母穴，但它是胃气的“总开关”之一。你通过胃俞来调胃的虚实——虚则灸之，实则泻之——这是从阳气层面入手，比在四肢末端扎子母穴更直接、更浑厚。

## 🎯 临床主治与配穴组合手印

**核心特效主治：**

第一，**一切胃部慢性病**。胃痛、胃胀、胃酸过多、消化不良、食欲不振。倪师说，长期的胃病，你不要只扎中脘和足三里，背后加一个胃俞，效果翻倍。

第二，**胃寒证**。吃冷的东西就胃痛、喝热水就舒服、手脚冰凉的人，灸胃俞，配合灸中脘，这是倪师常用的组合。

第三，**打嗝、嗳气、泛酸**。胃气上逆的时候，胃俞可以降逆。倪师讲，胃俞加内关，一个在背后降胃气，一个在手臂上宽胸利膈，打嗝立止。

第四，**小儿厌食、面黄肌瘦**。小儿脾胃虚弱，不想吃饭，倪师说可以用灸法，轻轻灸胃俞和脾俞，不要烫到孩子。

第五，**胃下垂**。中气下陷引起的胃下垂，倪师说，灸胃俞、脾俞，配合百会升提，这是从背后托住胃的阳气。

**倪师经典对穴与排针组合：**

- **胃俞 + 中脘**：俞募配穴，一前一后，胃病的基本组合。
- **胃俞 + 脾俞 + 足三里**：脾胃同调，加上足三里引气下行，这是调理中焦的黄金三角。
- **胃俞 + 内关 + 公孙**：公孙配内关治胃心胸，再加胃俞从背后加强，专治胃痛、胸闷、恶心。
- **胃俞 + 肝俞 + 胆俞**：胃病如果跟情绪有关（肝气犯胃），倪师说，你要加肝俞、胆俞，把木克土的问题一起解决。

倪师特别强调：**背部的穴位，排针的时候要对称。** 左边扎了胃俞，右边也要扎，或者左右交替。他说，人体的阳气是左右循环的，你只扎一边，气机会偏。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲膀胱经背俞穴那一段，讲到胃俞的时候，原汁原味的精气神是这样的：

“你摸到第十椎下，旁开一寸半，这是胃俞。胃不好的人，你按那个地方，他会叫——‘啊！’——那就是胃俞。你按下去他会痛，说明胃有问题。”

“下针的时候，针尖朝着脊柱方向斜刺，不要直刺。你直刺下去，扎到肺，那就是气胸，要送急诊的。所以背部的针，我一再讲，安全第一。”

“胃寒的人，你灸胃俞，灸到热气透进去，病人会感觉到胃里面暖暖的，那就对了。你不要灸到起水泡，那是烤肉，不是治病。”

倪师还讲过一个个案：有位老太太，胃痛几十年，吃西药吃到胃都烂了。倪师在中脘、胃俞、足三里上下针，再加上灸胃俞。老太太说，灸的时候，感觉有一股热气从背后钻到胃里面，胃就不痛了。倪师说，这就是阳气回来了。胃本身是阳腑，它需要阳气来腐熟水谷。你灸胃俞，就是给它阳气。

还有一段，倪师讲：**“胃俞和脾俞，你没事不要乱扎。”** 他说，这两个穴是调中焦的大穴，你如果没有脾胃的问题，不要随便动它。扎多了，反而会扰动中焦的气机。这是倪师的谨慎之处——大穴要用在刀刃上。

倪师最后的总结是：**“前有中脘，后有胃俞，中有足三里。胃的病，你把这几个穴玩熟了，就够用了。”**
