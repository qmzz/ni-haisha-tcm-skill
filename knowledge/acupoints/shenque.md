# 神阙

## 📍 经络归属与精准取穴法

- **所属经络**：任脉。神阙即肚脐正中，任脉循行“起于中极之下，以上毛际，循腹里，上关元，至咽喉”——神阙正当任脉腹段之核心孔窍，为先天元神出入之门户，故名气舍、脐中、命蒂。
- **特定穴属性**：神阙不在五输穴之列（任脉无井荥输经合），亦非原穴、络穴、郄穴。其特殊定位在于：它是**任脉与冲脉交会之处**，脐下为丹田元气所居，脐中为胎儿与母体气血相通的唯一通道。倪师强调，神阙一穴“上通心神，下交肾气，中是脾胃”，属先天后天交界之关卡，不可当普通穴位看。正因其为“生命之根蒂”，故《针灸大成》列其为**禁针**之穴，与一般募穴不可同日而语。
- **动态取穴与骨度折量法**：神阙取穴至简——仰卧，肚脐正中即是。但倪师讲取穴从不只看“点”，要看“势”。神阙之势在于脐孔深浅、脐轮大小、脐周温度。有人肚脐深凹如碗，有人平浅如盘，有人外凸如覆杯——外凸者多内有积水或疝气，浅平者多中气不足，深凹温热者元气尚足，深凹冰冷者命门火衰。倪师说，摸神阙不用骨度，要用掌心去“听”——掌心覆脐，感受脐周温度、跳动、软硬。脐周冰凉如铁板者，寒凝中焦；脐周跳动应手者，下焦有水气或奔豚。
- **下针深度与禁针禁灸法则**：**神阙绝对禁针**。倪师原话——“神阙不能针，针了发炎，肚脐发炎不得了。”肚脐是腹壁最薄弱处，下方无肌肉覆盖，直接与腹膜、肠管相贴，针之极易穿透腹膜导致腹膜炎。那怎么用？**隔盐灸**。用青盐填平脐孔（无青盐用细盐亦可），上置姜片或直接置艾炷灸之。艾炷如枣核大，灸五壮、七壮、九壮，看病情轻重。灸到脐周温热、腹中气动为度。倪师特别叮嘱：隔盐灸用**青盐**最好，青盐入肾，能把艾火的热力导入下焦，不至于浮在表面烤肉。


## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：神阙的气化核心在于一个字——**“通”**。胎儿在母腹中，不吃不喝不呼吸，全靠脐带与母体相通，这通道便是神阙。出生之后脐带剪断，神阙闭合，但它在气化层面**永远是半开状态**。倪师推演：任脉为阴脉之海，神阙恰在任脉中段，上是中脘、巨阙通心胃，下是气海、关元通肾命。神阙一穴，如同**阴阳之间的旋转门**——艾火一照，阳气从外入内，从脐入腹，从腹入脏，从脏入命门。所以神阙灸法的机理不是“补”，是**引**：引火归元，引气归海，引水归经。
- **具体气化路径**：艾火之热从脐孔渗入，先温中焦脾胃（脐上为中脘之域），脾胃得温则运化复；继而下行温肾命（脐下为气海关元之域），肾命得温则水有所主；同时一部分热气从任脉上行入心，心阳得助则神有所归。倪师说，这就是为什么神阙灸能同时治腹泻、治水肿、治宫寒、治阳虚厥逆——**一个脐孔，三条路同时打开**。
- **子母补泻与五行生克心法**：神阙在五行中**属土**（位居中央，脐为中土之象）。土生金，土克水。倪师用神阙从不孤立用，必配合五行生克：
  - **虚则补其母**：土之母为火（心、命门）。灸神阙时，若患者心阳不足、神疲欲寐，加灸**关元**（命火之根），此为“火生土”，补母以实子。
  - **实则泻其子**：土之子为金（肺、大肠）。若中焦实满、腹胀便秘，灸神阙后加针**足三里**（胃经合穴，土经土穴）泻之，此为“泻子以清母”。
  - **土克水之变**：若水湿泛滥、水肿尿少，灸神阙温土，土旺则能制水，同时加灸**水分穴**（脐上一寸），分利水湿——这就是“培土制水”在针灸上的落实。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **急症救逆**：中风脱证、阳气暴脱、四肢厥冷、脉微欲绝。倪师急救法第一步是**隔盐灸神阙**，大艾炷连续灸，不计壮数，灸到患者手脚回温、脉起为度。这是“回阳九针”之外的重要补充，针法用涌泉、足三里、人中，灸法必用神阙、关元。
  - **慢性病调理**：脾胃虚寒之久泻、五更泻、完谷不化。隔盐灸神阙，配合针**天枢**（大肠募穴）、**足三里**。倪师说五更泻是肾阳不能温脾土，灸神阙后加灸**命门**，前后夹击。
  - **妇科特效**：宫寒不孕、痛经、月经后期、白带清稀。灸神阙加灸**关元**、**中极**，此为“暖宫三穴”。倪师强调，妇人宫寒不是一天造成的，灸神阙要持之以恒，最好在月经干净后连续灸五天，每天七壮。
  - **儿科特效**：小儿脱肛、小儿泄泻、小儿夜啼。小儿灸神阙用**米粒灸**，艾炷如米粒大，灸三壮即可，不可多灸。倪师说小儿是纯阳之体，艾火宜轻宜短，引气归元即可。
  - **痛症**：寒性腹痛、绕脐痛、奔豚气上冲。灸神阙配合针**公孙**（冲脉交会穴）、**内关**，此为“公孙内关治胃心胸”的延伸，专治冲脉气逆。
- **经典对穴与排针组合**：
  - **神阙（灸）+ 关元（灸）+ 足三里（针）**：此为“温中培元三诀”。神阙温中焦，关元固下焦，足三里引气下行。倪师治一切虚寒证皆以此为基础方。
  - **神阙（灸）+ 天枢（针）+ 上巨虚（针）**：治腹泻、痢疾。天枢为大肠募穴，上巨虚为大肠下合穴，神阙灸之温中，此为“募合配穴”加灸脐。
  - **神阙（灸）+ 水分（灸）+ 阴陵泉（针）**：治水肿、腹胀。水分分水，阴陵泉健脾利水，神阙温阳化气，三穴合力，水湿自去。
  - **神阙（灸）+ 气海（灸）+ 三阴交（针）**：治妇科虚寒诸证。气海补气，三阴交调肝脾肾三经，神阙引火归元。


## 🗣️ 倪师讲义实录与针灸秘要

- **原文金句**：“神阙这个穴道，我们**禁针**。肚脐眼不能针，你针下去，病人发炎，肚脐发炎不得了。那神阙怎么用？**灸**。隔盐灸。盐用青盐最好，没有青盐用细盐。盐填满肚脐，上面放艾炷灸。灸神阙，治什么？**中风脱证、阳气虚脱、拉肚子、水肿、妇人宫寒**。肚脐是命蒂，是先天和后天连接的地方。你艾火一灸，热力从脐孔透进去，先温脾胃，再温肾命，一路温下去。所以神阙灸是**温阳固脱**的第一大穴。”
- **手下针感与灸感体会**：倪师描述，隔盐灸神阙时，患者会有一种特殊的感觉——不是皮肤烫，是**肚子里热**。热感从脐中心向四周扩散，有的患者会觉得热气往下走，走到小腹、走到腿；有的患者会觉得热气往上走，走到胃、走到心。这就是“得气”在灸法上的表现。倪师说，如果灸了半天患者只觉得皮肤烫、里面没感觉，那是**盐填得太厚**或者**艾炷太小**，热力没透进去。正确的灸感是：皮肤微温，腹内温热如春日暖阳。
- **医案故事**：倪师讲过一个案例——一位中年妇人，常年腹泻，每天天亮前必泻一次，完谷不化，手脚冰冷，夏天也要穿厚袜子。倪师看她肚脐，平浅无神，脐周冰凉。处方：隔盐灸神阙，每天七壮，连续灸两周；同时针足三里、天枢、关元。灸到第三天，患者说肚子里有热气在转；灸到第七天，五更泻止；灸到第十四天，手脚回温。倪师说，这就是“**火生土、土制水**”的实效。神阙一穴，看似简单，但用好了，**胜似一剂四逆汤**。
- **针灸秘要**：倪师最后叮嘱——神阙灸法，**急症用大炷，缓症用小炷；成人用大炷，小儿用米粒炷**。灸后不可立即洗澡，不可吹风，不可吃生冷。灸神阙期间，忌房事、忌大怒、忌思虑过度。因为神阙是命蒂，你在这里点火，就要给它一个安静的环境去“引火归元”。如果灸完神阙就去吹冷风、喝冰水，等于火刚点着你就一盆水泼上去，前功尽弃。
