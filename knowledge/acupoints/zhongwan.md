# 中脘穴 (CV12)

## 📍 经络归属与精准取穴法

中脘穴，任脉上的大穴，是胃的募穴。什么叫募穴？募就是开口、聚集的意思，五脏六腑之气直接汇聚在胸腹部的位置就叫募穴。中脘是胃气汇聚之所，所以一切胃家的问题，第一个考虑的就是中脘。

同时它还是八会穴中的“腑会”——所有六腑的病，大肠、小肠、胆、胃、膀胱、三焦，通通可以在中脘上治。你只要记得：腑有问题，中脘一针下去，六腑都受管辖。

在五行属性上，中脘归任脉，任脉总任一身之阴。胃本身属土，中脘作为胃募，是土气最厚的点，调和脾胃、补益中土，都从这里入手。

**倪师动态取穴法：**

怎么找中脘？先找心蔽骨，就是胸口正中那个剑突尖，再找肚脐。心蔽骨和肚脐正中间这个点，就是中脘。这是骨度折量法，用身体自己的骨头做尺子，不需要什么寸啊分的。

你摸到心蔽骨下端，再摸到肚脐，两个点连线取中点，按下去通常会有酸胀感，那就是穴道所在。胖的人肚子大，按深一点；瘦的人一摸就摸到了。

**下针深度：** 中脘下针，一般一寸到一寸半。看体型，肚子厚的可以针到一寸半，肚子薄的针一寸。针下去是直刺，不要斜刺，直进直出。

**禁忌：** 中脘这个位置，里面是胃，再深就是腹主动脉。你不能针太深，针到胃壁上没关系，但你不能穿透。一般来说一寸半为限，不要超过两寸。灸中脘可以，效果很好，尤其是隔姜灸，温胃散寒的效果比针还好。但如果有胃出血、胃穿孔这种急腹症，你不要乱动，先辨清楚再说。

## ⚡ 倪师经穴气化与破局心法

中脘的气化机理，你从它的位置去想就明白了。它在身体正中间，上面是心，下面是脐，刚好卡在中焦的核心位置。中焦是什么？脾胃。脾胃是什么？后天之本，气血生化之源。

倪师讲，中脘这一针下去，最核心的作用是“旋转中焦”。什么叫旋转中焦？脾胃一升一降，脾升清、胃降浊，像一个轴心一样在转。中脘就是给这个轴心加力。中焦不转，上面就堵，下面也堵——上面呕吐、胸闷，下面便秘、腹胀。中脘一针，轴心一转，上下就通了。

**五行生克心法：**

胃属土，中脘是胃募，补中脘就是补土。土生金，金对应肺，所以脾胃虚弱导致的肺气虚、容易感冒、气短，你可以从中脘上补土生金。

土克水，脾胃太实、水湿泛滥的时候，你泻中脘，土不克水了，水湿反而能排出去。这就是为什么中脘能治水肿、痰饮——不是直接去利水，是把土的功能调回来，水自然归位。

虚则补其母：胃土之母是心火。所以心火不足、脾胃虚寒的人，中脘配巨阙（心之募穴），补火生土，效果翻倍。

实则泻其子：胃土之子是大肠金。胃家实热、便秘腹胀，中脘配天枢、大肠俞，泻土之子，腑气就通了。

倪师特别强调：中脘是腑会，六腑的募穴各管各的，但中脘总管全局。你遇到复杂的肠胃问题，不知道从哪入手，先针中脘，让中焦转起来，再根据具体症状加配穴，这是破局的心法。

## 🎯 临床主治与配穴组合手印

**核心特效主治：**

一切胃病——胃痛、胃胀、反酸、打嗝、呕吐、消化不良、食欲不振，中脘是首选。不管是寒证热证虚证实证，中脘都能用，关键看补泻手法和配穴。

急症方面：霍乱吐泻、急性胃痉挛、食物中毒引起的胃部剧痛，中脘配内关、足三里，针下去就能缓解。倪师讲过，急性胃痛的时候，中脘一针，内关一针，足三里一针，三针下去，痛当场就减。

慢性病调理：脾胃虚弱导致的贫血、疲劳、四肢无力、面色萎黄，中脘配足三里、关元，长期灸，比吃什么补药都管用。

妇科方面：任脉主胞胎，中脘虽然不直接管子宫，但脾胃为气血生化之源，气血足了，月经自然正常。中脘配气海、三阴交，治月经量少、色淡、延期。

儿科方面：小儿厌食、疳积、腹胀，中脘轻轻针或灸，配合捏脊，效果很好。倪师说小儿中脘不要针太深，一点点就行，或者用灸法。

**倪师经典对穴与排针组合：**

1. **中脘 + 足三里 + 内关**：这是治胃的黄金组合。中脘是胃募，足三里是胃经合穴，“合治内腑”；内关是心包络穴，别走三焦，管胃心胸。三针齐下，从募到合到络，立体覆盖，胃的问题无所遁形。

2. **中脘 + 公孙 + 内关**：公孙配内关是八脉交会穴的经典组合，公孙通冲脉，内关通阴维脉，合治胃、心、胸。再加中脘，等于在病灶上直接加了一个总开关。胃痛、胸闷、心悸、呕吐，这个组合一网打尽。

3. **中脘 + 天枢 + 关元**：这是调理中下焦的排针。中脘管中焦，天枢是大肠募穴管下焦传导，关元是小肠募穴管下焦气化。三针一排，从胃到肠到丹田，整个腹部的气机都转动起来。腹胀、便秘、腹泻、小便不利，都管。

4. **中脘 + 巨阙 + 膻中**：这是上中焦同调的组合。巨阙是心募，膻中是气会，中脘是腑会。三会齐用，治胸闷、心痛、气短、胃心综合征。倪师讲，心胃同治的时候，这个组合非常好用。

5. **中脘 + 章门 + 脾俞**：这是补脾胃的排针。章门是脾募也是脏会，脾俞是脾的背俞穴，中脘是腑会。前面募穴后面俞穴，再加上腑会，把脾胃前后左右都围住了。虚寒性胃痛、慢性腹泻、脾虚水肿，用这个组合。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲中脘的时候，原话是这么说的：

“中脘是胃的募穴，也是腑会。腑会中脘，所有腑的病都可以在中脘上治。你记住，中脘这个穴道，你下针的时候，针下去要直刺。肚子大的人，你针到一寸半；肚子小的人，针一寸。针下去以后，你用手去感受，针尖碰到胃壁的时候，病人会有一种温热的感觉，或者有一种胃在蠕动的感觉，那是气到了。”

“过去我们讲中脘治一切胃病，可是你要知道，中脘不单单治胃。六腑的病它都管。胆结石、便秘、腹泻、膀胱的问题，你都可以在中脘上做文章。为什么？因为它是腑会啊。”

倪师还讲过一个医案：

“有个病人胃痛了十几年，什么药都吃过了，就是不好。我一看，中脘这个地方按下去，硬邦邦的，像一块石头。我就针中脘，针下去的时候，针被顶住了，进不去。我就用呼吸补泻，让他吸气的时候进针，呼气的时候出针，慢慢磨进去。针到一寸的时候，突然‘噗’一下，针就滑下去了，病人当场就打了一个嗝，说胃里面松了。这就是中脘的气结打开了。后来我配了足三里、内关，针了三次，十几年的胃痛就好了。”

“还有一点，中脘灸比针还好。尤其是隔姜灸，你切一片生姜，扎几个洞，放在中脘上，艾绒放上去烧。生姜的辛温加上艾火的阳热，直接透到胃里面去。胃寒的人，灸完中脘，整个肚子都是暖的，比吃什么附子理中丸还快。”

倪师最后强调：

“中脘这个穴，你看起来简单，就是在肚子上扎一针。可是它的道理很深。它是中焦的枢纽，是六腑的总管。你把这个穴用好了，一半的肠胃病你都能治。记住，针中脘的时候，心要静，手要稳，要让病人放松肚子。肚子一紧，气就堵住了，针就进不去。你让病人吐气，肚子瘪下去的时候进针，顺着气机走，针就顺了。”
