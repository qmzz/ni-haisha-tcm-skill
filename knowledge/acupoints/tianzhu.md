# 天柱

## 📍 经络归属与精准取穴法

- 天柱穴属**足太阳膀胱经**。膀胱经本身无五输穴属性（五输穴只在肘膝关节以下），天柱位于颈项部，是膀胱经从头顶下行的**重要关口穴**。它的位置紧贴后项大筋（斜方肌）外侧缘，是**足太阳经气从脑户下行入项、联络脑与督脉的枢纽**。倪师强调：天柱不是五输穴，但它在**子午流注**上归属于膀胱经，膀胱与肾相表里，故而此穴能**通脑气、调肾气、利项背**。

- 倪师在《人纪·针灸篇》讲膀胱经时反复提示：**“天柱在玉枕骨下，后项大筋外取之。”** 具体摸法：先找**后发际正中线上1寸为大椎**（第1胸椎棘突下），再上推到**后发际正中直上0.5寸为哑门**（督脉），从哑门旁开**1.3寸**，按到后项大筋（斜方肌起始部）**外缘凹陷处**，就是天柱。倪师说：**“你摸到那条大筋，筋内是哑门，筋外就是天柱，一按一个酸胀，那就是穴。”**

- **骨度折量法**：后发际正中至大椎为**3寸**，所以天柱约在后发际正中直上**0.5寸**、旁开**1.3寸**。倪师常用**“一夫法”**辅助：患者正坐，医者以食指、中指、无名指、小指四指并拢为**3寸**，从后发际正中量到旁开约**1.3寸**（约一横指半），再按到筋外凹陷。

- **下针深度**：倪师直言：**“天柱不可深针。”** 一般**直刺0.5～0.8寸**，针尖方向**略向下或向内**，**严禁向内上方深刺**，否则伤及延髓。倪师原话：**“天柱你扎五分、八分就好，不要往里面戳，戳进去就完蛋，这是禁针深刺的穴。”** 禁灸法则：**可灸但不宜多灸**，倪师说天柱“灸多了脑血不足、头昏”，一般**艾炷灸3～5壮**或**温灸5～10分钟**即可。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演天柱的气化机理：**膀胱经气从头顶（通天、络却、玉枕）下行，经过天柱这个“柱子”把脑气承接下来，再沿着背脊两旁往下走。** 所以天柱是**“脑气下行的第一道闸门”**。它能**引脑中之火上归水脏（肾）**，因为膀胱属水，与肾相通。倪师说：**“天柱就是天塌下来帮你撑住的那根柱子，它把上面的天（脑）和下面的水（膀胱肾）连起来。”**

- **开阖机理**：天柱主治**头项强痛、眩晕、目视不明、鼻塞、咽喉肿痛、中风后遗症**。倪师认为：天柱能**开脑窍、利项背、降逆气**。对于**高血压引起的后头痛、脖子僵硬**，天柱配**大椎、风池**，可**引气血下行**。对于**脑瘤、脑积水**等重症，倪师在讲膀胱经时提到：**“天柱、通天、络却，这几个穴轮流用，能把脑部的压力往下导。”**

- **子母补泻与五行生克**：天柱本身不是五输穴，但倪师在临床上常把天柱与**膀胱经的母穴（委中，属土）**和**子穴（束骨，属木）**配合使用。**虚证**（肾气不足、脑髓空虚、眩晕耳鸣）：补**委中**（母穴，土生金，膀胱经属金？倪师在五行配属上把膀胱经归为**水经**，其母穴为**金穴（委中，土？）**——此处需注意倪师原意：膀胱经五输穴的五行属性是：井（至阴，金）、荥（通谷，水）、输（束骨，木）、经（昆仑，火）、合（委中，土）。按“虚则补其母”，膀胱经属水，金生水，故**母穴是井穴至阴（金）**；实则泻其子，水生木，故**子穴是输穴束骨（木）**。倪师在《人纪》中明确讲过：**“膀胱经虚，补至阴；膀胱经实，泻束骨。”** 天柱虽非五输，但在调理膀胱经虚实时要“上病下取”，**天柱搭配至阴或束骨**，形成上下呼应。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **急症救逆**：中风昏迷、脑溢血后遗症——天柱配**百会、人中、涌泉**，倪师用于**醒脑开窍**。
  - **慢性病调理**：高血压、颈椎病、眩晕、偏头痛——天柱配**风池、大椎、肩井**。
  - **痛症特效**：后头痛、项背痛、落枕——天柱配**后溪、申脉**（通督脉与阳跷）。
  - **五官科**：鼻塞、鼻炎、目视不明、咽喉肿痛——天柱配**迎香、合谷、少商**。

- **倪师经典对穴与排针组合**：
  - **天柱 + 大椎 + 风池**：倪师称“颈三针”，治一切**项背强硬、头晕目眩**。
  - **天柱 + 后溪 + 申脉**：后溪通督脉，申脉通阳跷，天柱居中调度，治**颈项强痛、落枕**，倪师说“针下去脖子就能转”。
  - **天柱 + 合谷 + 太冲（开四关）**：治**肝阳上亢型高血压、头痛**，倪师说“四关一开，气血就平了”。
  - **天柱 + 足三里 + 三阴交**：治**气血两虚型眩晕、脑供血不足**，倪师说“下面补够了，上面天柱一撑，脑就不缺血了”。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲膀胱经时，原汁原味逐字稿金句：**“天柱这个穴，你摸到后项大筋，筋的外侧，一按就酸，那就是天柱。天柱顾名思义，就是撑天的柱子。人的头是天，天柱就是撑住头的柱子。你脖子不能转，头重脚轻，天柱一针下去，马上松掉。”**

- **实战手下针感**：倪师说：**“针天柱，针尖要稍微往下，不要往上。你针一下去，病人会有酸胀感往头顶或往肩背走，那是气到了。如果病人说像触电一样往脚上走，那是扎太深了，要马上提针。”**

- **医案故事**：倪师讲过一个案例：**“有个病人高血压，后脑痛得像要炸开，脖子硬得像木头。我针天柱、大椎、风池，针一下去，病人说‘哎，头松了’。留针二十分钟，血压从180降到150。天柱就是能把上面的压力往下导。”** 另一个案例：**“一个老太太眩晕十几年，西医说是内耳不平衡。我针天柱、足三里、三阴交，三次就好了。为什么？天柱把脑气往下引，足三里、三阴交把气血补上来，上下交通，眩晕就停了。”**

- **针灸秘要**：倪师特别警告：**“天柱靠近延髓，绝对不能深针，也不能乱捻针。你扎五分，病人有酸胀就够了。你扎一寸，病人一咳，针就进去了，那会出人命的。所以天柱这个穴，宁浅勿深，宁轻勿重。”** 他又说：**“灸天柱，用米粒灸，三壮五壮就好，灸多了脑水不足，病人会头昏。这是禁灸多壮的穴。”**

- **倪师心法总结**：**“天柱是膀胱经的关口，膀胱经主水，水能克火。所以天柱能降火、能醒脑、能利项背。你只要记得‘天柱撑天，水降火’这六个字，就懂了这个穴。”**
