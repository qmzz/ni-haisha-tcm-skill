# 巨髎

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经，阳跷脉之会穴。巨髎是胃经与阳跷脉的交会穴，《针灸大成》归入足阳明胃经面部腧穴。
- **穴性定位**：巨髎非井荥输经合，非原络郄募俞，属阳跷脉与胃经之会。阳跷主一身左右之阳，司眼睑开合、下肢运动。巨髎位于面部，承接胃经多气多血之脉气，与阳跷脉相交，故能调面部气血、通阳跷之经气。
- **倪师动态取穴法**：倪师讲，巨髎怎么找？你摸到颧骨，颧骨再往下摸，有个凹陷，瞳孔直下，平鼻翼下缘。你对着镜子看，瞳孔正中对下来，差不多跟鼻翼下沿齐平的位置，按下去有个坑，那就是巨髎。不要死记“目正视，瞳孔直下，平鼻翼下缘”，你要用手去摸，颧骨下方那个骨缝凹陷就是它。
- **骨度折量**：从睛明到巨髎，瞳孔垂直线为纵轴，鼻翼下缘水平线为横轴，交叉点即是。简易法：四白穴直下，摸到颧骨下缘凹陷，张口时凹陷更明显。
- **下针深度**：倪师说，面部穴位，针要浅，直刺三分到五分，不要深刺。巨髎这个地方，你用手按下去是凹的，针进去要贴着骨面，不要往深处扎。
- **禁针禁灸法则**：巨髎可灸，但面部一般不灸，灸了留疤不好看。针宜浅，不可深刺，深刺伤及面部血管神经。面部穴位手法宜轻，得气即止。


## ⚡ 倪师经穴气化与破局心法

- **倪师推演此穴的气血流注与开阖机理**：巨髎在面部，承接胃经气血上行之势。胃经多气多血，气血到面部靠巨髎这个“髎”来渗灌——髎就是骨隙孔窍，气血在此渗入面部络脉。阳跷脉在此与胃经相会，阳跷主“动”，主一身左右之阳气的协调，所以巨髎能开关利窍，把胃经的气血通过阳跷脉这个“开关”泵到面部、眼睑、口唇周围。
- **自然机理**：倪师讲，面部的问题，不管是口眼歪斜还是牙痛，都是面部气血不通、经气不达。巨髎就是把胃经的气血引到面部来的一个“闸口”。胃气一开，气血涌上来，面部就活了。阳跷脉主眼睑开合，所以眼睛闭不上、眼皮跳，巨髎能调。
- **子母补泻与五行生克**：足阳明胃经五行属土。虚实补泻看胃经整体。倪师强调，面部穴不讲本穴子母补泻，要看远端配穴。胃经实证，下内庭（荥穴，属水，土克水，实则泻其子，泻内庭以泻胃实）；胃经虚证，下解溪（经穴，属火，火生土，虚则补其母，补解溪以生胃土）。巨髎作为面部局部穴，配子母穴一补一泻，形成远近呼应。
- **开窍醒神机理**：倪师说，阳跷脉从足跟上来，过面部，主眼睛开合。巨髎是阳跷与胃经交会，中风后眼斜口歪的人，巨髎能引阳跷之气来调整面部经筋的松紧。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **面部局部病**——面瘫、口眼歪斜、眼皮跳、眼睑下垂不能闭、流口水、面部肌肉痉挛、三叉神经痛（第二支区域）。
  - **齿病**——上牙痛（胃经入上齿），配下关、合谷。
  - **鼻病**——鼻塞、鼻窦炎，巨髎近鼻旁，配迎香、印堂。

- **倪师经典对穴与排针组合**：
  - **面瘫组合**：地仓透颊车，配巨髎、四白、阳白、合谷（对侧）。倪师说，地仓透颊车是主力，巨髎是帮衬，从面部侧面把经气兜住，不让它散掉。针巨髎要顺着肌肉走向，不可直刺太深。
  - **上牙痛组合**：巨髎 + 下关 + 合谷。倪师说，胃经入上齿，上牙痛是胃火。下关管下颌关节，巨髎管上颌，合谷引到面部，三针一下去，牙痛当场减。
  - **眼睑开合不利**：巨髎 + 攒竹 + 阳白 + 申脉（阳跷脉起点）。倪师讲，阳跷脉主眼睑开合，申脉通阳跷，巨髎是阳跷与胃经会穴，两个都取，一个在脚上一个在脸上，上下呼应，眼睑就听话了。
  - **鼻塞不通**：巨髎 + 迎香 + 鼻通（上迎香） + 印堂。倪师说，鼻子的问题，迎香是主穴，巨髎在旁边帮它把胃经的气往鼻子上引。


## 🗣️ 倪师讲义实录与针灸秘要

（说明：原视频为倪海厦先生人纪系列授课实录之针灸篇，本处所录为贴合倪师讲课风格的还原性整理，未逐字核对原始音视频，仅供学习参考。）

- **气机推演与取穴心法**：倪师讲，面部穴位，你要配合脏腑辨证。巨髎在面上，但你不要只看脸。胃经从脚走到脸，你脸上有问题，要先看胃经通不通。胃经堵了，你扎一百个面部穴也没用。先看胃经的虚实，虚的补解溪，实的泻内庭，再来扎巨髎，那才叫治病。

- **实战操作与针感体会**：倪师说，针巨髎，手法要轻。你用手按着穴位旁边，针慢慢进去，得气之后，病人会感觉脸上有一股酸胀感往周围散。有时候针一下去，病人眼皮会跳一下，那就是气到了。你不要捻转太猛，面部经筋薄，猛了容易伤。

- **医案故事**：倪师在讲面部中风的时候讲过，有个病人眼睛闭不上，半边脸歪的。倪师先取地仓透颊车，再取巨髎、四白、阳白，健侧取合谷。针了几次，病人眼睛慢慢能闭上了。倪师说，巨髎是关键，因为它是阳跷与胃经的交会，阳跷主眼睑开合，你不开这个“开关”，光扎地仓效果就差一半。

- **禁忌提醒**：倪师反复强调，面部针要浅，巨髎这个地方血管多，扎深了容易出血，瘀青一片，病人吓都吓死。三分到五分，得气就停，不要贪深。灸就更不要了，脸上灸一个疤，病人恨你一辈子。

- **倪师口诀**：巨髎在颧下，瞳孔鼻翼间。针浅三分许，口眼歪斜安。配谷谷与关，牙痛立时宽。阳跷通眼睑，开合此中参。
