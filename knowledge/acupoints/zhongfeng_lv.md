# 中封二

## 📍 经络归属与精准取穴法

- **所属经络与五输穴属性**：中封穴，足厥阴肝经之**经穴**，五行属**金**。肝经五输依次为：大敦（井木）、行间（荥火）、太冲（输土）、中封（经金）、曲泉（合水）。中封为肝经经金之穴，金能克木，故本穴暗藏“制肝木之刚”之义，肝经实热亢逆者，取此穴泻之，正合“经主喘咳寒热”之调气要义。

- **倪师动态取穴与骨度折量法**：倪师讲，中封在**内踝骨前方，踝关节内侧横纹端凹陷中**。你让病人脚微微翘起来，脚后跟蹬地、脚尖向上勾，内踝前方会出现一条大筋（胫骨前肌腱），这条筋的内侧凹陷、紧贴内踝尖前方一寸不到的位置，就是中封。倪师原话大意是——**“你摸到内踝尖，往前一点点，脚尖一翘，筋一绷，筋内侧那个坑就是中封。”** 下针深度，**直刺三到五分**，针尖略向后下方斜透照海方向亦可。**禁灸**——倪师明确讲，中封是肝经上的穴，肝主筋，**灸了容易伤筋动骨**，此处不宜艾灸，尤其不宜化脓灸。下针时嘱病人轻轻活动踝关节，得气后留针二十分钟，效果最好。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：中封为肝经经穴，属金。肝属木，木性升发；金性收敛肃降。倪师推演，这个穴的气化机理在于**“以金制木、以肃降敛肝阳”** 。肝气太旺、肝火上炎、肝阳上亢时，好比树木疯长不结果，中封之金气如同一把修枝剪，把肝经多余的升发之气敛下来、降下去。同时，肝经环绕阴器、抵小腹、布胁肋，中封能**引肝经郁热下行、从下焦泄出**，所以对疝气、阴缩、小便不利、遗精、踝关节内侧痛，都有“开阖转枢”的作用。倪师说：**“中封像肝经的一个闸门，闸门一开，郁气下行；闸门一关，精血内守。”**

- **子母补泻与五行生克运用心法**：肝经五行属木，中封五行属金。**金克木**，故中封本质上是肝经的**“制约穴”** 。实则泻其子——肝经实证（肝火、肝阳、肝风），可取行间（荥火，木生火，火为木之子）泻之，亦可取中封以金制木。虚则补其母——肝经虚证（肝血不足、肝气虚），应补曲泉（合水，水生木，水为木之母）。**中封的特殊地位在于“平调”** ：既非纯泻，也非纯补，而是通过金木相克的关系，把肝经气血从“太过”拉回“中庸”。倪师常讲：**“太冲是开路的，中封是收路的。太冲把气引上来，中封把气降下去，一开一合，肝经就活了。”**

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **疝气、睾丸肿痛、阴缩**——肝经绕阴器，中封配大敦，一针一灸（大敦可灸，中封只针），立见缓和。
  2. **遗精、白浊、小便不利**——中封配关元、三阴交，降肝火、固精关。
  3. **踝关节内侧痛、足内翻**——局部取穴，中封透照海，当场让病人活动脚踝。
  4. **肝阳上亢之头痛、眩晕**——中封配太冲、风池，引肝阳下行。
  5. **疟疾、寒热往来**——经穴主“喘咳寒热”，中封配间使、后溪，调少阳厥阴之枢。

- **倪师经典对穴与排针组合**：
  - **中封 + 太冲**：太冲开四关，中封收肝气。肝郁化火、烦躁易怒者，先针太冲泻之，再针中封平之。
  - **中封 + 三阴交**：三阴交调肝脾肾三经，中封专理肝经。妇科月经不调、痛经、带下，此组合为倪师常用。
  - **中封 + 关元 + 大敦**：治疝气之经典排针。关元温下焦，大敦灸之提气，中封针之降逆。
  - **中封 + 阳陵泉**：阳陵泉为筋会，中封为肝经经穴，筋病、关节屈伸不利，两穴同用，筋脉自柔。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味金句**：倪师在讲肝经时原话大意是——**“中封这个穴，你看它名字就知道，封就是封藏、收敛。肝经的气到这里，本来该往上升的，它给你封一下、降一下。所以肝火太旺的人，你下中封，火就下来了。但你要注意，中封是金穴，金能克木，它是肝经上唯一一个能‘管住’肝的穴。你如果肝虚，就不要碰它，越碰肝越虚。”**

- **实战手下针感体会**：倪师讲，中封下针后，病人常感觉**一股酸胀感从内踝向脚底或向小腿内侧放散**。如果病人肝气郁结严重，针下去会有“紧针”感，针身被肌肉裹住，这时不要硬捻，轻轻提插几下，让气机松开。倪师特别强调：**“中封针下去，你问病人，脚趾头有没有感觉？有，气就到了。没有，你针尖偏一点，往照海方向斜一点。”**

- **医案故事**：倪师曾讲过一个案例——有个病人疝气痛得直不起腰，睾丸肿得像鸡蛋大。倪师先灸大敦，再针中封、关元、三阴交。针中封时，病人当场说“有一股凉气从睾丸往下走”，痛就减了大半。倪师说：**“这就是中封把肝经的郁热往下泄了。大敦是提气的，中封是降气的，一提一降，疝气就回去了。”** 还有一次，一个年轻女孩痛经，痛得在地上打滚，倪师针三阴交、中封，针下痛止。倪师说：**“中封治痛经，不是补，是通。肝经通了，子宫就不痛了。”**
