# 承扶二

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。承扶在膀胱经上，膀胱经是人体最大的排毒通路，从头走到脚，背部整条太阳经都是它的地盘。
- **特定穴属性**：承扶不是五输穴，不是原络郄募俞，它是膀胱经在臀部下缘的一个重要关口穴。倪师讲，承扶穴的位置正当臀横纹中央，是足太阳经气从腰背下行、经过臀部、进入大腿后侧的枢转之处。它虽然不归五输，但它是膀胱经气机转输的一个大穴，相当于一个“关卡”，气到这里要转个弯往下走。
- **倪师动态取穴与骨度折量法**：
  - 怎么找？很简单。你让病人趴着，脚伸直，臀部和大腿交界的地方有一条横纹，这就是臀横纹。承扶就在臀横纹的正中央。你用大拇指按下去，会感觉到一个大筋的缝隙，酸胀感非常明显，那就是承扶。
  - 倪师说，你不要死板板地拿尺子去量，你要用手去摸。臀横纹中央，按下去有个凹陷，病人会“哎哟”一声，那就是穴道。有的人胖，臀纹深；有的人瘦，臀纹浅，但那个缝一定在。
  - **下针深度**：倪师讲，承扶可以下针，但不要深，一般针下1寸到1.5寸。因为下面有大神经，你不能乱搞。针下去的时候，病人会有酸麻胀的感觉，有时候会往大腿方向放射，那是气到了。
  - **禁针禁灸法则**：承扶这个穴，倪师一般不灸。为什么？因为它在臀部，肉厚，灸了容易上火，而且这个位置灸起来不方便。禁针？没有禁针，但你要小心，不要往深处乱扎，避开坐骨神经干。倪师说，你扎针要“如临深渊，如履薄冰”，不是让你怕，是让你精准。

## ⚡ 倪师经穴气化与破局心法

- **倪师如何推演此穴的气血流注与开阖机理**：
  - 倪师讲，承扶这个穴，顾名思义，“承”是承接，“扶”是扶持。它承接的是从腰背下来的膀胱经气，扶持的是大腿后侧的气血运行。膀胱经气从委中往上走，经过承扶，再上到臀部、腰背。所以承扶是膀胱经气上下交通的一个枢纽。
  - 它的气化机理，倪师归纳为“通调水道、疏利腰腿”。膀胱经主水，承扶在臀部，臀为足太阳之根，针承扶可以引膀胱经的水湿下行，从委中、承山、昆仑一路排出去。所以它有利水消肿、通利腰腿的作用。
  - 倪师特别强调，承扶不是直接补肾的，它是通过疏通膀胱经的气机，让水道通畅，间接达到“引火归元”的效果。比如有的人下焦湿热，小便不利，腰腿沉重，针承扶可以打开臀部的气结，让湿热往下走。
- **子母补泻与五行生克运用心法**：
  - 承扶不是五输穴，所以没有直接的子母补泻。但倪师讲，你可以从膀胱经的五行属性来推。膀胱经属水，水之母为金，水之子为木。膀胱经的井穴至阴属金，荥穴通谷属水，输穴束骨属木，经穴昆仑属火，合穴委中属土。
  - 如果膀胱经虚，你可以补它的母，也就是补金，取至阴穴；如果膀胱经实，你可以泻它的子，也就是泻木，取束骨穴。承扶虽然不直接参与子母补泻，但它是膀胱经气机的一个大关口，你针承扶可以调节整条经的气血，配合子母穴使用，效果更好。
  - 倪师说，比如病人膀胱经虚，腰背酸痛，你针承扶，再补至阴，这就是“虚则补其母”的变通用法。如果病人膀胱经实，小便赤涩，腰腿胀痛，你针承扶，再泻束骨，这就是“实则泻其子”的活用。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **腰腿痛**：这是承扶的第一大主治。倪师讲，不管是急性腰扭伤，还是慢性腰肌劳损，还是坐骨神经痛，承扶都是必取的。特别是痛从腰背往下窜到臀部、大腿后侧的，针承扶立竿见影。
  - **痔疮**：倪师说，承扶在臀横纹中央，靠近肛门，膀胱经别络于肛。所以针承扶可以治痔疮，尤其是内痔出血、脱肛。配长强、会阳，效果更好。
  - **小便不利**：膀胱经主水，承扶可以通利膀胱。倪师讲，有的人小便点滴不出，或者尿频尿急，针承扶可以疏通下焦气机。
  - **妇科**：倪师讲，承扶在臀部，臀为阴部之邻，针承扶可以治痛经、月经不调、带下。特别是寒湿下注引起的带下清稀，针承扶配三阴交、关元，效果很好。
- **倪师经典对穴与排针组合**：
  - **承扶配委中**：这是倪师治腰腿痛的经典组合。承扶在臀，委中在腘，一上一下，一气一血，针下去，膀胱经的气血就活了。倪师说，腰背委中求，但你别忘了承扶，承扶是委中的上游，上游不通，下游怎么通？
  - **承扶配昆仑**：昆仑是膀胱经的经穴，属火。承扶配昆仑，可以引火归元，治下焦虚寒、腰腿冷痛。
  - **承扶配三阴交**：这是治妇科病的组合。承扶通膀胱经气，三阴交调肝脾肾三经，一阳一阴，一上一下，气血双调。
  - **承扶配长强**：这是治痔疮的组合。长强在尾骨端，承扶在臀横纹，两针下去，肛门周围的气机就通了。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：
  - “承扶这个穴，你趴着看，臀横纹正中间，一按一个坑，那就是。你不要小看它，它管的事可多了。”
  - “腰腿痛，你针承扶，针下去，病人说哎哟，一股麻电往大腿走，那就是气到了。气到了，痛就松了。”
  - “痔疮，你不要只想着长强，承扶也要针。承扶在臀横纹，长强在尾骨，两个一配，肛门周围的气就活了。”
  - “承扶可以治小便不利，为什么？因为膀胱经主水，承扶是膀胱经气机转输的大穴。你针下去，水道就通了。”
- **实战手下针感体会**：
  - 倪师讲，他针承扶，一般用2寸针，直刺1.5寸。针下去的时候，病人会有酸胀感，有时候会往大腿后侧放射，那是气到了。如果病人说“哎哟，麻到脚底了”，那更好，说明膀胱经整条都通了。
  - 倪师说，你针承扶，不要捻得太快，要慢，要稳。因为下面有坐骨神经，你捻太快，病人会受不了。你要“如临深渊，如履薄冰”，慢慢捻，慢慢进，让气自己走。
- **医案故事**：
  - 倪师讲过一个案例。有个病人，腰痛了十几年，痛从腰背窜到臀部、大腿后侧，西医说是坐骨神经痛，开了止痛药，吃了没用。倪师一看，说这是膀胱经气机不通。他针了承扶、委中、昆仑，针下去，病人说“哎哟，一股热流从臀部往下走，走到脚底了”。留针20分钟，起针后，病人说腰松了，腿也不痛了。倪师说，这就是“通则不痛”。
  - 还有一个案例。有个妇人，痔疮出血，痛得坐不住。倪师针了承扶、长强、会阳，针下去，病人说“哎哟，肛门周围热热的，好舒服”。留针15分钟，起针后，病人说痛减轻了，第二天出血也少了。倪师说，这就是膀胱经别络于肛的道理。
