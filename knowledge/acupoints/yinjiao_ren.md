# 阴交二

## 📍 经络归属与精准取穴法

- **所属经络**：任脉。阴交为任脉经穴，又为**任脉、冲脉、足少阴肾经**三脉之会穴（《针灸大成》卷七：“阴交，一名横户，脐下一寸，当任脉、冲脉、足少阴之会”），故又名“横户”。非五输穴、非原络郄、非募俞，属“**三经交会穴**”一类的特定穴范畴，五行定位不归井荥输经合之列，而以“交会”统摄三阴经气化。

- **倪师动态取穴与骨度折量法**：
  倪师取阴交，第一步先定**神阙**（肚脐正中心），从神阙正下量**一横指**（同身寸一寸），就是阴交。倪师原话强调过，从肚脐到曲骨这一段是**五段寸法**——脐下一寸阴交、脐下一寸半气海、脐下二寸石门、脐下三寸关元、脐下四寸中极。一横指压下去摸准了再进针，不要马马虎虎“差不多一寸”。

  - **针刺深度**：倪师讲下针**八分到一寸**，腹白线上直刺。针下去后病人会觉得**酸胀感向会阴部或小腹深处扩**，那就是气到了。
  - **禁针禁灸法则**：阴交**禁灸**。因为阴交是任、冲、肾三脉交会，灸之则**热入冲任**，妇人可致**经水不调、血崩**，孕妇更是**禁针禁灸**——下针动胎气，艾灸助火热，皆犯冲任。
  - **手法提示**：孕妇禁；小腹有癥瘕积聚者慎深刺；针前排尿，针后勿受寒。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：
  倪师把阴交看作**任、冲、肾三气交汇的“枢纽”**。任脉总一身之阴，冲脉为血海，肾经主水、主生殖。阴交居脐下，正是**阴气交会**之所。倪师推演：脐下一寸处，上通神阙（先天元气之门），下临气海关元（元气之海），阴交恰是**三阴经气灌注入小腹的入口**。其开阖机理是：**温养冲任、通利下焦、利水调经**。凡小腹冷、经水不来、带下清稀、水肿胀满、小便不利，皆是阴交气化失职——水不化气、血不下行。

- **子母补泻与五行生克心法**：
  阴交非井荥输经合，故不直接套“虚补其母、实泻其子”的井荥补泻。倪师用的是**三阴交会、气血双调**的心法：
  - **虚证**（冲任虚寒、肾气不足）：配**关元、气海**，以艾灸关元（阴交本身禁灸，借关元温养）引火归元，补冲任之虚。
  - **实证**（水湿停聚、经闭不通）：配**三阴交、水道、中极**，用泻法通利下焦。三阴交是足三阴之会，阴交是任冲肾之会，两会相合，**一开一阖**——三阴交引血下行，阴交通阴气之闭，血水同调。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **妇科特效**：月经不调、经闭、痛经、崩漏、带下、不孕、产后恶露不尽。阴交是倪师治妇人小腹虚冷、月经久不来的**近取要穴**。
  - **冲任不固**：小腹冷痛、疝气、奔豚气上冲心。
  - **下焦水病**：水肿、小便不利、腹胀绕脐痛。
  - **急症救逆**：阴证腹痛、寒疝绕脐痛。

- **倪师经典对穴与排针组合**：
  - **阴交 + 关元 + 三阴交** —— 妇科万用组合。阴交通阴气，关元补元气，三阴交调三阴血。三针齐下，温通冲任。
  - **阴交 + 气海 + 石门** —— 脐下四针一线通，治小腹一切胀痛。倪师说这是“**打通任脉下焦段**”。
  - **阴交 + 中极 + 水道** —— 治小便不利、水肿。任脉与水道一穴通，利三焦水道。
  - **阴交 + 公孙 + 内关** —— 公孙通冲脉，内关通阴维，阴交本冲任之会，三穴合治**胃心胸兼小腹冲气**上逆之证。
  - **阴交 + 太冲** —— 太冲为肝经原穴，妇人经闭因于肝郁者，开四关之意，从“调任冲”走向“调气血”。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在人纪针灸篇讲任脉时，讲到脐下这一段，当场拿笔画了那条从神阙到曲骨的线，一寸一寸地数给学员听：**“从肚脐下一寸，这叫阴交。阴交是什么意思？就是三条阴经——任脉、冲脉、肾经——交会在这一寸的地方。”**

他特别强调孕妇的问题，原汁原味的话大意是：**“妇人怀孕的时候，肚子这一带你不要乱下针，阴交、石门、关元，通通不要碰。你一针下去，冲任之气一泄，胎就动了。”** 倪师讲得干脆，不跟你绕理论，直接让学员记住——**肚脐以下，孕妇禁针，阴交禁灸**。

又问学员：**“为什么阴交禁灸？”** 他自答：**“冲脉是血海，任脉是阴海，艾火一入，血热妄行。妇人本来月经不调，你一灸阴交，血崩了怎么办？”** 所以倪师反复叮咛，阴交这个穴“**只针不灸，孕妇不用**”。

临床上倪师用阴交多在妇人小腹冷痛、月经三个月不来、少腹坠胀一类。他的手下体会是：**“针到八分深，病人讲小腹里面有一股酸胀往下走，走到会阴，那就是冲脉的气动了。”** 这时候再配三阴交，效果最快。
