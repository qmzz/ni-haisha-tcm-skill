# 大横二

## 📍 经络归属与精准取穴法

- **所属经络**：足太阴脾经。大横为足太阴脾经与阴维脉之会穴（《针灸大成》列为足太阴、阴维之会）。非五输穴，属经外奇穴并入正经体系后的**腹部要穴**，在五行归土（脾经本属土），为脾土之“横”位枢纽。
- **穴名解**：倪师言“大横者，横贯腹中之大脉也”。腹为坤土，大横居中，横通带脉，是脾经气机在腹部横向布散的关键节点。与带脉穴平齐（脐旁四寸），一在胁下，一在腹侧，共同约束诸经。
- **精准取穴（骨度折量法）**：
  - 先定**神阙**（肚脐正中），从脐中向左右两侧水平旁开**四寸**。注意：是“旁开四寸”，非三寸、非五寸。四寸如何折？倪师讲：以乳头至脐中为八寸，取其中点即四寸；或以患者本人食、中、无名、小指四指并拢为三寸，再加一寸即是四寸。
  - 大横与**天枢**（脐旁二寸）同高，天枢在二寸，大横在四寸，中间隔二寸，可先找天枢再外移二寸定大横。
  - 左右各一穴，共两穴。
- **下针深度与禁针禁灸**：
  - 倪师原话：“腹深如井，背薄如饼。”大横在腹部，可直刺**一寸至一寸五分**，针感可向腹内或两侧扩散，偶有酸胀牵拉至腰侧之感。
  - **禁灸**：腹部穴位多不宜重灸，尤其大横靠近带脉与肠腑，灸之易助火气内攻，引发腹胀或便秘。倪师强调腹部穴“针可通，灸可慎”，大横以针法为主，温灸仅可浅灸三五壮，不可多灸。
  - 孕妇禁针，腹部有癥瘕积聚者慎针。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：
  - 大横位于脐旁四寸，正当**带脉**循行区域。带脉如腰带，约束纵行诸经。大横是脾经气机横向布散的门户，倪师推演其气化机制为：**“脾土横运，约束带脉，通调肠腑”**。
  - 脾气主升，但升中有横。大横的“横”字，正是脾土之气向两侧布散、润泽腹壁、约束带脉的体现。若脾虚气陷，大横处会松软凹陷；若湿热积滞，大横处会胀满压痛。
  - 倪师心法：大横能**“横通腹气，解带脉之拘急”**。凡腹中气机横逆、绕脐痛、腹胀如鼓、带脉拘紧（腰腹一圈如束带感），取大横可开横阖、通腹络。
- **五行生克与子母补泻**：
  - 大横属脾经（土），本经五输穴为：隐白（井木）、大都（荥火）、太白（输土）、商丘（经金）、阴陵泉（合水）。
  - 大横非五输穴，但可借**脾经子母补泻**之大法：脾土虚，补其母——心火（火生土），可取大都（荥火）或心经少府；脾土实，泻其子——肺金（土生金），可取商丘（经金）或肺经经渠。
  - 倪师临床应用大横时，常按**“实则泻其子”**思路：腹胀、便秘、湿热积滞属脾实，针大横用泻法（捻转提插，呼气进针，吸气出针），再配商丘或阴陵泉，导土气下行。
  - 若脾虚气陷、脱肛、子宫下垂，则大横用补法（吸气进针，呼气出针，轻捻转），配百会、气海，升提中气。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **肠腑急症**：绕脐腹痛、腹胀如鼓、肠鸣泄泻、便秘、痢疾。倪师言大横“专治肚脐一圈的毛病”，凡脐周绞痛、气胀攻冲，针大横可立缓。
  - **带脉病**：腰腹一圈拘紧如束带、带下、腰溶溶如坐水中。大横配带脉穴，解带脉之困。
  - **妇科**：月经不调、痛经属脾虚湿滞者；产后腹胀、恶露不尽。
  - **儿科**：小儿腹胀、疳积、消化不良。小儿针大横宜浅刺疾出，不留针。
  - **慢性调理**：脾虚肥胖、腹型肥胖、大便黏滞不爽，大横可助脾运湿、通腑降浊。
- **倪师经典对穴与排针组合**：
  - **大横 + 天枢 + 中脘 + 关元**：腹四针法，通调任脉与脾经，治一切腹病。
  - **大横 + 带脉 + 足临泣**：带脉三针，治带下、腰腹拘急。足临泣通带脉，大横横通腹气，带脉穴直接约束。
  - **大横 + 公孙 + 内关**：公孙通冲脉，内关通阴维，大横通带脉，三脉交会，治胃心胸及腹中气机横逆。
  - **大横 + 足三里 + 三阴交**：脾经本经配穴，健脾行水，治腹胀、泄泻、水肿。
  - **大横 + 合谷 + 太冲**：开四关加腹针，治腹中气滞血瘀之痛证。
  - **大横 + 支沟 + 照海**：通便组合，支沟宣三焦，照海润肠，大横通腹，治便秘。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原味金句**：
  - “大横这个穴，你看名字就知道，它在肚子中间横着走。肚脐旁边四寸，你摸下去，很多人这里硬邦邦的，那就是腹气不通。针一下去，病人会感觉肚子里面‘咕噜’一声，气就散开了。”
  - “大横是脾经和阴维脉的交会。阴维主一身之里，所以大横能通里气。肚脐周围的病，绕脐痛、腹胀，你针大横，再针天枢，效果立竿见影。”
  - “很多人肚子大，不是胖，是脾湿停在那里。大横针下去，用泻法，再配阴陵泉，小便一利，肚子就消一圈。这不是减肥，是去湿。”
  - “带脉一圈像腰带，大横就是腰带上的扣子。扣子松了，带脉就紧；扣子紧了，带脉就松。针大横，就是调这个扣子。”
- **实战针感体会**：
  - 倪师弟子问：“大横针多深？”倪师答：“一寸到一寸半，看你病人肚子多厚。针进去后，不要猛提插，轻轻捻转，等气。气到了，病人会觉得肚子里面在动，有的会放屁，有的会想去厕所，这都是气通了。”
  - “大横针感不是酸麻胀那么简单，它是一种‘横’的感觉，会往两边走，甚至走到腰侧。你要是针下去病人只喊痛，那是你没扎准，扎到腹直肌鞘了，要稍微调整方向。”
- **医案故事**：
  - 倪师曾治一妇人，绕脐痛三年，西医查无异常，只给止痛药。倪师取大横、天枢、公孙、内关，针一次痛减大半，三次痊愈。倪师言：“这就是腹气横逆，大横一开，横气就散了。”
  - 又治一男子，腹大如鼓，小便不利，脾虚湿盛。倪师针大横、阴陵泉、水分、气海，用泻法，留针二十分钟，起针后小便如注，腹围当场减两寸。倪师笑言：“这不是魔术，是脾土通了，水就下去了。”
  - 倪师强调：“大横这个穴，一般人不知道，但它是腹诊的关键。你按病人大横，如果痛或者硬，那就是腹中有积。针大横，再配相应的募穴，积就会慢慢化掉。”
