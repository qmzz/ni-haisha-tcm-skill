# 承光

## 📍 经络归属与精准取穴法

- 承光穴归属足太阳膀胱经。足太阳膀胱经起于目内眦睛明穴，上额交巅入络脑，下项夹脊抵腰入腘腨，终于至阴穴，是人身最长、穴位最多的一条阳经大脉。膀胱经五输穴属性为：井穴至阴（金）、荥穴通谷（水）、输穴束骨（木）、经穴昆仑（火）、合穴委中（土），原穴京骨。承光位于头部五处穴之后、通天穴之前，属膀胱经在头顶区域的重要腧穴，紧邻通天、络却，与五处、曲差一字排开，各相距一寸五分。此穴非五输穴、非原络郄募，是膀胱经在巅顶区域的气机转输要站。

- 倪师动态取穴法：先找曲差。曲差在神庭穴旁开一寸五分，神庭是督脉穴，在前发际正中直上五分。从曲差往上量五分之距是承光？不对，倪师讲得清楚——曲差往上是一寸五分到五处，五处再往后一寸五分就是承光。你手指从曲差开始，沿着膀胱经在头部的循行线往后摸，过了五处，再一寸半，就是承光。承光穴在头顶部，前发际正中直上二寸五分，旁开一寸五分。你叫病人正坐，从眉心直上入发际，手指贴着颅骨往后推，推到顶骨和额骨交界那个棱，旁开两横指，就是承光。倪师原话：承光、通天、络却，这三个穴并排在后脑袋上，你摸骨缝，骨缝之间凹陷处就是穴道，不用太死板。

- 下针深度与禁忌：承光穴平刺，针尖向后沿皮刺入三到五分，不可直刺深刺。头部穴位倪师反复强调——头是诸阳之会，脑为髓海，你拿一寸针斜着刺进去，得气即止，不要往里捅。此穴古籍记载禁灸，《针灸大成》明言“禁灸”，因为头为诸阳之会，艾火一烧，阳气上冲，病人容易头胀目赤、烦躁不宁。倪师说：头顶上的穴，大部分禁灸，你艾灸百会可以，那是诸阳之会能升提，承光是膀胱经气转输的地方，灸了反而把水气蒸上头顶，病人会头晕。

## ⚡ 倪师经穴气化与破局心法

- 承光的气血流注机理：膀胱经是人体最大的排毒通道，从睛明一路上来，把五脏六腑的代谢浊水通过背俞穴汇入膀胱经，走到头顶的时候，气机要有一个转输和沉降的过程。承光这个穴名——承者，承接也；光者，光明也。倪师解：膀胱经的气血到了头顶，就像水蒸气升到天空，承光就是让这个气血中的精华——光——能够承接住，输送到眼睛和脑窍。如果膀胱经的浊水不能正常下降，反而上冲头部，就会出现头痛、目眩、鼻塞。承光能把这些乱窜的水气收住，让它该降的降、该散的散。

- 倪师推演此穴的开阖机理：膀胱经与肾经相表里，肾主水，膀胱为水府。承光靠近通天，通天是膀胱经气与天气相通之处，承光在通天之前，相当于一个关卡——气从通天进来之后，承光负责把清阳之气承接下来，输送到头面和目窍。所以承光主治目疾、鼻疾、头痛，机理就是承接清阳、宣通鼻窍、清利头目。倪师说：你眼睛看不清、鼻子不通、头顶痛，这是膀胱经的水气不能正常气化，堵在头顶上了，承光一针下去，斜刺向后，气就通了。

- 子母补泻与五行生克：承光非五输穴，不直接参与膀胱经井荥输经合的五行补泻。但倪师讲，膀胱经属水，承光位于头顶，在五行方位中头属火（南方），水克火，膀胱经的水气到了头顶，天然有制约亢阳的作用。如果膀胱经气虚，水不制火，就会出现头顶痛、目赤、鼻衄，这时候可以在膀胱经的母穴——委中（合穴土，实则泻其子）——上做补泻，再配承光导引气血下行。如果膀胱经水气太过，上冲头部，出现眩晕、鼻流清涕不止，可以在膀胱经的荥穴通谷（水穴，实则泻其子）上泻之，承光作为局部配穴，把多余的水气疏散开。

## 🎯 临床主治与配穴组合手印

- 核心特效主治：
  1. **头痛、目眩**——特别是头顶痛、后头痛牵连到前额，膀胱经循行部位的疼痛。倪师说：承光配百会，头顶痛一针见效。
  2. **鼻塞、鼻流清涕、鼻炎**——膀胱经气不通，鼻窍闭塞，承光能宣通鼻窍。倪师讲：承光、通天、络却这一排，治鼻病效果好得很。
  3. **目视不明、目翳、青光眼、白内障早期**——膀胱经起于目内眦，承光承接清阳上达目窍，对视力模糊、眼压高有调理作用。
  4. **癫痫、瘛疭**——膀胱经入络脑，承光能安神定志，辅助治疗神志病。
  5. **热病无汗、烦渴**——膀胱经主表，承光能宣发阳气，解表退热。

- 倪师经典对穴与排针组合：
  - **承光 + 百会 + 风池**：治头顶痛、巅顶痛。百会升提阳气，风池祛风，承光承接膀胱经气，三针齐下，痛立止。
  - **承光 + 迎香 + 印堂**：治鼻塞、鼻炎。迎香通鼻窍，印堂安神，承光从膀胱经上引气下行，鼻涕立马收住。
  - **承光 + 睛明 + 光明**：治目视不明。睛明是膀胱经起点，光明是胆经络穴，承光在头顶承接清阳，三穴合用，眼睛就亮了。
  - **承光 + 通天 + 络却**：治鼻塞、鼻渊、脑漏。这一排针下去，从承光到络却，整个头顶的膀胱经气都打通了。
  - **承光 + 后溪 + 申脉**：治督脉和膀胱经的头痛、颈项强痛。后溪通督脉，申脉通阳跷，承光在头顶，上下呼应。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲头部膀胱经穴位时原话：“承光、通天、络却，这三个穴，你从曲差往上，一路寸半寸半地上去。五处、承光、通天、络却，都在一条线上。你摸骨，后脑勺有个棱，棱上就是穴道。针下去，平刺，不要深，三分到五分，得气就停。头顶的穴，一针下去，病人眼睛就亮了，鼻子就通了，为什么？因为膀胱经的水气被调动起来了。”

- 倪师手下针感体会：“承光这个穴，你针尖向后平刺，病人会有一种感觉——好像头顶有一盏灯被点亮了，或者有一股凉气从头顶往下走，走到眼睛、走到鼻子。这就是‘承光’的意思。你针尖向前刺，气就往前走到前额；针尖向后刺，气就往后走到后脑。看病人哪里不舒服，你就调整针尖方向。”

- 倪师医案故事：倪师曾治一五十多岁妇人，头痛二十年，痛在头顶，像戴了个紧箍咒，西医说是紧张性头痛，吃止痛药没用。倪师一看，膀胱经气血堵在头顶了。取承光、百会、风池，平刺承光，针尖向后，百会向前斜刺，风池双侧。针下去不到五分钟，病人说头顶松了，像有人把紧箍咒摘掉了。倪师说：“这个头痛，就是膀胱经的水气上不去、下不来，堵在头顶。承光把气一承接，百会一升提，风池一疏散，路就通了。”后来又针了三次，二十年的头痛再没犯过。倪师总结：头顶的病，你要看膀胱经和督脉，承光就是膀胱经在头顶的开关。
