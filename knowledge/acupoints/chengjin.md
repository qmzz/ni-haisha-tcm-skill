# 承筋

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经，经别络属。承筋穴在《针灸大成》中归足太阳膀胱经，位于小腿后侧，腨肠（腓肠肌）中央。
- **五输穴属性**：承筋不属于井荥输经合五输穴，它是膀胱经在腿部循行中的一个**独立腧穴**，无特定穴属性（非原、络、郄、募、俞、八会）。正因为它不是五输穴，倪师在讲此穴时，强调的是**局部气机与循经远端**的关系，而非子母补泻的直接应用。
- **倪师动态取穴与骨度折量法**：
    - **怎么摸**：从足外踝尖往上量，先找到**委中**（腘横纹中点），再从委中往下量，在腓肠肌两肌腹之间、人字纹顶点处取穴。倪师常说：“你让病人踮脚，小腿肚子鼓起，那两块肉中间的人字缝，就是承筋。”
    - **骨度折量**：委中至承山为**八寸**，承筋在委中下**三寸**（一说五寸，倪师取三寸法，以腓肠肌肌腹最丰隆处为准），承山在委中下八寸。
    - **下针深度**：直刺**0.5～1寸**，针感酸胀麻，可向足底或腘窝放散。
    - **禁针禁灸法则**：《针灸大成》明言“**禁针**”，但倪师在临床上**并不绝对禁针**，而是强调“**不可深刺**”。他说：“承筋穴，古人说禁针，是怕你扎到血管和神经。你手法轻，浅刺五分，得气就停，没问题。”至于灸法，可灸**三壮至五壮**，但**不宜多灸**，因为小腿肌肉丰厚，灸多则伤津。


## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：
    - 承筋穴的气化核心在于“**承**”字。倪师说：“承者，接也。筋者，肝所主，宗筋之所聚。”承筋承接的是**膀胱经的经气**，再往下就是承山，承山再下就是昆仑。所以承筋是膀胱经经气从大腿后侧向小腿后侧**下贯**的关键中转站。
    - 它的气化功能是：**舒筋活络、通利腰腿、升提中气**。倪师推演：“膀胱经主一身之表，承筋在腨肠，腨肠是**足太阳之别**，别入于腘中。所以承筋能治**转筋、霍乱、腰背拘急**——都是筋的病，因为太阳经气在这里承上启下。”
    - 他又说：“你看那些**腿抽筋**的人，不管是半夜抽筋还是游泳抽筋，承筋一针下去，筋就松了。为什么？因为**肝主筋，膀胱经与肝经相通**（厥阴与太阳为表里之经气相通），承筋能**引膀胱经气以柔肝筋**。”

- **子母补泻与五行生克运用心法**：
    - 承筋非五输穴，故**不直接参与子母补泻**。但倪师在五行生克上用它时，是**借邻近五输穴之力**：
        - 膀胱经属**水**，其母穴为**至阴**（金生水），子穴为**束骨**（水生木）。
        - 若膀胱经虚证（腰背冷痛、小便不禁），补**至阴**，再配**承筋**以固经气。
        - 若膀胱经实证（腰背拘急、转筋痉挛），泻**束骨**，再配**承筋**以松筋急。
    - 倪师心法：“承筋是**局部的开关**，不是补泻的穴位。你补泻用五输，开关用承筋。就像电灯，开关在承筋，电源在至阴、束骨。”


## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
    - **转筋（腓肠肌痉挛）** ：特效。不论寒热虚实，承筋一针，筋即松。
    - **霍乱吐泻转筋**：配**委中**、**承山**，点刺放血。
    - **腰背拘急、腰腿痛**：配**肾俞**、**大肠俞**、**委中**。
    - **痔疮**：承筋可治**痔疾**，因膀胱经别入肛，倪师说“承筋能提肛气”。
    - **小腿水肿、脚气**：配**三阴交**、**阴陵泉**，利水消肿。
    - **小儿麻痹后遗症、足内翻**：配**绝骨**、**丘墟**。

- **倪师经典对穴与排针组合**：
    - **承筋 + 承山 + 委中**：治一切小腿转筋、腰腿痛。倪师叫“**三承一排**”，从腘窝到小腿，一气贯通。
    - **承筋 + 三阴交 + 复溜**：治小腿水肿、静脉曲张。
    - **承筋 + 合谷 + 太冲**（开四关）：治全身筋惕肉瞤、抽筋。
    - **承筋 + 公孙 + 内关**：治霍乱转筋、胃心胸急症。


## 🗣️ 倪师讲义实录与针灸秘要

- **逐字稿金句**：
    - “承筋这个穴，你看名字就知道，**专门治筋**。腿抽筋，你扎承筋，不管是半夜抽还是运动抽，针一下去，筋就软了。”
    - “古人说承筋禁针，那是**怕你扎太深**。你扎五分，得气就停，怎么会出事？我扎了几十年，从没见过承筋扎出问题的。但你要**避开血管**，看到青筋鼓起来，你就偏一点。”
    - “承筋和承山，一个在腨肠上头，一个在下头。**承筋管筋，承山管痔**。两个一起用，腰腿的毛病一起收。”
    - “你遇到霍乱吐泻转筋的病人，**委中放血，承筋下针**，再喝点盐水，很快就缓过来。”

- **实战手下针感体会**：
    - 倪师说：“针承筋，针尖要**略向上斜**，迎着膀胱经的经气来路。得气时，病人会觉得**一股酸胀从腨肠窜到脚底**，或者**往腘窝方向回传**。这时候你就停，不要捻针，让它自己动。”
    - 若针下**紧涩**，是筋急，可**轻轻摇针**；若针下**松滑**，是气散，可**慢慢提插**。

- **医案故事**：
    - 倪师讲过一个案例：“有个**五十多岁的太太**，半夜腿抽筋，痛得哭。她儿子背她来，我一看，腨肠硬得像石头。我**承筋一针**，针下去她就说‘松了’，再**承山一针**，她说‘不痛了’。第二天她带了一堆朋友来，都说要扎承筋。”
    - 又有一个**运动选手**，跑马拉松时小腿抽筋，倒在地上。倪师说：“我**承筋下针，强刺激**，针一进去，他腿就直了。起来走了两步，又跑完了全程。”
    - 倪师总结：“承筋是**救急的穴**，也是**日常保养筋的穴**。你平常没事，**灸一灸承筋**，腿脚就有力，不容易抽筋。”
