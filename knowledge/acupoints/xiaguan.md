# 下关

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：下关穴归属**足阳明胃经**，是足阳明胃经与足少阳胆经的**交会穴**。它不属于井荥输经合五输穴体系，也不是原络郄募俞，而是**面部要穴、交会穴**。阳明经多气多血，胃经循行入上齿，胆经循行入耳中，下关一穴同时咬合两条阳经的气血交汇，这就是它既能治牙口、又能治耳病的根本原因。五行上，胃经属土，胆经属木，下关作为土经与木经的交会，暗含木克土的自然制衡关系——胆火上炎克胃土时，下关就是那个"讲和"的关卡。

- **倪师动态取穴与骨度折量法**：倪师讲下关，绝不会让你去背什么"颧弓下缘与下颌切迹之间凹陷中"这种解剖学八股。倪师的手法是：**先摸颧弓**。你顺着耳朵往前摸，耳朵前方横着一条骨头就是颧弓。颧弓下方有一个凹陷，你让病人**把嘴巴张开**，这个凹陷就鼓起来了、合上了。为什么呢？因为下颌骨的髁状突在张嘴时前移，正好顶到这个位置，一闭嘴它又缩回去，凹陷就没了。所以倪师取穴的诀窍就一句话——**"张口取穴，闭口进针"**。你让病人张着嘴找到那个鼓起来的骨尖前面的凹陷，定好位，然后让他闭上嘴，再下针。闭口时针尖才能顺利通过下颌切迹进入穴位深处。

  下针深度：**直刺五分到一寸**。禁灸——面部穴位，艾火一烧就是疤，倪师说脸上灸了等于毁容，绝对不灸。禁针的情况：如果局部有红肿热痛的急性炎症，或者病人有凝血问题，不下针。倪师特别提醒：下关这个位置**里面有血管**，下针时如果病人喊"触电一样"窜到牙齿或耳朵，那是扎到神经干了，要立刻退针换个角度，不要死命往里捅。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：下关的气化机理，倪师是从"关"字入手的。什么叫关？关就是**关卡、门户**。阳明经的气血从面颊上行，胆经的气血从耳周环绕，两条阳经的气血都要经过这个"关隘"。如果这个关卡堵住了，胆火降不下去就往上冲——耳鸣、耳聋、偏头痛；胃气降不下去就往上逆——牙痛、面肿、口眼歪斜。所以下关的核心机理是**"通降阳明、清泄少阳、开关利窍"**——把堵在面部的浊气放下来，让该降的降、该通的通。

  倪师还讲过一个更深的层面：下关靠近下颌关节，这个关节是人体**唯一会"脱臼"的关节**。为什么？因为阳明经的气血在这里如果虚了，筋就松了，下颌骨就掉下来了。所以下关穴还有一个**升提阳明经气、强健下颌筋脉**的作用。临床上有人下巴习惯性脱臼，倪师就会在下关配合颊车做针灸，让阳明气血把筋重新"绑紧"。

- **子母补泻与五行生克**：下关本身不是五输穴，所以子母补泻不直接落在它身上。但倪师的心法是**借经用穴**——下关归胃经，胃属土。如果胆木克胃土太过，出现胆火犯胃的症状（口苦、牙痛、耳鸣、烦躁），你取胆经的**侠溪穴（荥水穴）** 泻胆火，再取胃经的**解溪穴（经火穴）** 或**足三里（合土穴）** 来补胃土，下关作为局部交会穴**引气至病所**，这就是五行生克的实战用法。虚证——比如阳明气虚导致的面部麻木、咀嚼无力——你补胃经母穴**解溪**，再针下关，让气能灌到面部去。

  倪师的破局心法一句话总结：**下关是阳明和少阳的"谈判桌"，胆火太旺你从少阳那边泄，胃气太虚你从阳明这边补，下关负责把谈好的结果送到脸上。**

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **牙痛、牙龈肿痛**（尤其是下牙痛）——阳明经入下齿，下关是近取穴，针下痛止。
  2. **耳鸣、耳聋、聤耳**（中耳炎）——胆经入耳，下关开耳窍，特别是那种"轰隆隆"的低频耳鸣。
  3. **下颌关节痛、咀嚼无力、习惯性下颌脱臼**——下关配颊车，这是倪师治疗颞下颌关节紊乱的**铁三角**（再加合谷）。
  4. **面瘫、口眼歪斜**——下关配地仓、颊车、合谷，通阳明经气，让面部肌肉重新收到指令。
  5. **偏头痛、三叉神经痛**——尤其是痛在颧弓附近、耳朵前方的，下关是局部狙击点。

- **倪师经典对穴与排针组合**：
  - **下关 + 颊车 + 合谷**：治一切牙痛、下颌关节病。合谷是面口合谷收的远取总穴，下关颊车是近取局部，远近呼应，一气贯通。
  - **下关 + 听宫 + 翳风 + 中渚**：治耳鸣耳聋。听宫是手太阳小肠经穴、翳风是手少阳三焦经穴，下关是足阳明足少阳交会，三阳经一起开耳窍，中渚（三焦经输穴）从远处引气上来。
  - **下关 + 地仓 + 颊车 + 合谷 + 太冲**：治面瘫。前面四穴通面部阳明经气，太冲开四关之一，调肝血以养筋，因为面瘫倪师认为很多是**肝血不足、风邪中络**。
  - **下关 + 太阳 + 率谷 + 外关**：治偏头痛。太阳率谷是局部疏通少阳，外关是少阳经络穴，从远端调理三焦气机。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲下关的时候，原话大概是这样的：

> "下关这个穴道，你注意看，在颧弓的下方。你让病人嘴巴张开来，哎，这个地方就凸起来了，像一个小山包一样，你摸到那个骨头的尖尖，前面那个凹洞就是下关。你嘴巴张开的时候它鼓起来，闭起来它就凹下去了。所以你下针的时候，叫病人嘴巴张开找到穴道，然后嘴巴闭起来再下针。你张着嘴下针，下颌骨顶着，你针进不去嘛。"

> "下关针下去，直刺，五分到一寸。你不要灸，脸上哪个穴道都不要灸，一灸就是一个疤，很难看。你针下关，病人会有酸胀的感觉，有时候会像触电一样窜到牙齿那边去，那是正常的针感。但如果窜得太厉害，像刀割一样，你要退出来一点，换个方向。"

> "下关治牙痛，效果非常好。尤其是下牙痛，阳明经嘛，下关是胃经的穴道，胃经入下齿。你下关配颊车，再配个合谷，牙痛当场就减轻。我常常跟学生讲，你牙痛的时候不要急着找牙医拔牙，你先扎一针下关看看，说不定就不用拔了。"

> "耳朵的问题，下关也管。你看胆经的循行，它从耳朵后面绕到耳朵前面，下关正好在耳朵前面。所以耳鸣、耳聋，你下关配听宫、配翳风，针一下去，病人耳朵里面就开了。尤其是那种'嗡嗡嗡'的低频耳鸣，效果最好。高频的像蝉叫那种，那是肾虚，你要从肾去治，下关只能辅助。"

> "还有一个很特殊的用法——下颌脱臼。有的人打哈欠下巴就掉下来了，或者嘴巴张太大合不拢。你下关配颊车，针下去，阳明经的气血一过来，筋就紧了，下颌就收回去了。平常你还可以教病人自己按揉下关和颊车，每天按，让阳明气血充足，就不容易掉下巴。"

倪师还特别强调过一个临床体会：**下关这个穴，针感是"往两个方向走"的**——往下走能到牙齿、下颌，往侧走能到耳朵、太阳穴。所以你在行针的时候，可以用手轻轻按着病人的脸颊，感受针气的走向，然后根据病情调整针尖的方向。牙痛往下引，耳病往侧引，这就是**"气至病所"**的活用法。
