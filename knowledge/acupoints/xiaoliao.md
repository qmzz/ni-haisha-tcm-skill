# 下髎

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经，八髎穴之一（上髎、次髎、中髎、下髎）。
- **八髎穴总义**：八髎即左右各四，合为八穴，对应骶骨八个骶后孔。倪师常言：“八髎是治妇科、腰痛的宝地，尤其是痛经、月经不调、带下，针下去效果立竿见影。”
- **下髎位置**：在骶部，当骶正中嵴旁开约0.8寸至1寸，对应第四骶后孔。也就是从次髎往下数，上髎、次髎、中髎、下髎，一路排下来，第四对孔就是下髎。
- **倪师动态取穴法**：倪师讲，八髎穴不能死记硬背。你让病人趴着，先摸骶骨。骶骨上有四个孔，像麻将牌里的“四筒”一样排列。上髎最靠上，次髎在第二孔，中髎第三孔，下髎第四孔，最靠近尾骨。你用手指从髂后上棘往下推，推到骶骨正中旁开，能摸到一个个凹陷，凹陷处就是骶后孔。下髎的凹陷最不明显，但找到中髎往下再摸一个孔，就是下髎。
- **骨度折量**：从骶正中嵴到髂后上棘的距离，折作1寸左右。下髎旁开约0.8寸，不是1.5寸，别跟膀胱经其他背部穴搞混。倪师强调：“八髎穴是贴着骶骨走的，旁开只有八分到一寸，你开太外就扎到肌肉里去了，扎不到孔里，效果就差了。”
- **下针深度**：倪师说，下髎针下去，一般1寸到1.5寸。瘦的人扎1寸，胖的人扎1.5寸。因为骶后孔是斜的，针尖要稍微朝内下方斜刺，顺着孔道进去。你得有手感，针穿过骶后孔时会有一种“落空感”，像扎穿一层纸，那就到位了。不要硬捅，硬捅扎到骨头，病人会痛。
- **禁针禁灸法则**：下髎可以灸，尤其是虚寒性的妇科病、腰痛，用艾条灸八髎区域，整个骶骨热起来，效果很好。但禁针的情况也有：孕妇禁针八髎，因为会动胎气；局部皮肤感染、破损，不针不灸；骶骨骨折、严重骨质疏松，禁针，灸也要小心。倪师说：“八髎穴孕妇绝对不能碰，你一针下去，胎气一动，可能就流产了，这是大忌。”

## ⚡ 倪师经穴气化与破局心法

- **下髎的气血流注与开阖机理**：倪师认为，八髎穴是膀胱经气血在骶骨区域的汇聚点，而下髎位于最下，对应下焦、胞宫、前后二阴。膀胱经主一身之表，但八髎穴又内应胞宫、精室、大肠、膀胱。下髎的气化特点，是“引气血下行，开下焦之闭”。倪师常说：“下髎能通气机到子宫、到直肠、到膀胱，下面堵住了，你针下髎，就像把下水道的塞子拔开。”
- **引火归元**：下焦虚寒、虚火上炎，比如女性更年期烘热、心烦、失眠，但脚是冷的，倪师会用下髎配合关元、三阴交，引火归元。下髎把上面的浮火拉回下焦，温暖胞宫。
- **健脾行水**：膀胱与肾相表里，下髎能助膀胱气化，利水渗湿。倪师治水肿、小便不利，有时会取八髎，尤其是下髎，配合阴陵泉、水分，把下焦的水湿排出去。
- **升提中气**：下髎虽在下，但能调气机升降。倪师治脱肛、子宫脱垂，会用下髎配百会、气海，升提中气。他说：“下髎能提，不是因为它位置高，而是因为它能开下焦之闭，闭一开，气就上来了。”
- **子母补泻与五行生克**：膀胱经属水，下髎不是五输穴，但倪师在临床中，会根据五行生克来配穴。膀胱经虚证，补其母——金生水，取膀胱经的母穴（委中？不对，膀胱经母穴是至阴？倪师讲五输穴时，膀胱经的井穴至阴属金，荥穴通谷属水，输穴束骨属木，经穴昆仑属火，合穴委中属土。膀胱经属水，虚则补其母，金生水，所以补至阴（井穴，属金）。实则泻其子，水生木，所以泻束骨（输穴，属木）。下髎虽不是五输穴，但倪师会用它来调膀胱经的虚实。比如膀胱经实证，小便不通、腰痛剧烈，针下髎用泻法，配合束骨；膀胱经虚证，遗尿、腰酸，针下髎用补法，配合至阴。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **妇科病**：痛经、月经不调、带下、盆腔炎、子宫内膜炎、不孕症。倪师说：“八髎穴治妇科，尤其是下髎，对痛经效果最好。你针下去，病人会觉得小腹暖暖的，痛就减了。”
  - **男科病**：遗精、阳痿、早泄、前列腺炎。下髎能通下焦气血，配关元、中极、三阴交。
  - **二便病**：便秘、泄泻、小便不利、遗尿。下髎能开下焦之闭，通调二便。
  - **腰骶痛**：腰痛、骶髂关节炎、坐骨神经痛。下髎是局部取穴，能疏通局部气血。
  - **急症**：急性腰扭伤，针下髎配合动气疗法，让病人活动腰部，效果立竿见影。
- **倪师经典对穴与排针组合**：
  - **下髎 + 关元 + 三阴交**：治妇科病、痛经、月经不调。关元温下焦，三阴交调肝脾肾，下髎通胞宫气血。
  - **下髎 + 中极 + 阴陵泉**：治小便不利、水肿、前列腺炎。中极是膀胱募穴，阴陵泉健脾利水，下髎助膀胱气化。
  - **下髎 + 大肠俞 + 天枢**：治便秘、泄泻。大肠俞、天枢调大肠，下髎通下焦。
  - **下髎 + 肾俞 + 命门**：治阳痿、遗精、腰酸。肾俞、命门补肾，下髎通下焦。
  - **下髎 + 环跳 + 委中**：治坐骨神经痛、腰腿痛。环跳、委中通经活络，下髎局部疏通。
  - **下髎 + 百会 + 气海**：治脱肛、子宫脱垂。百会、气海升提中气，下髎开下焦之闭。
- **排针组合**：倪师常讲，八髎穴可以一起用，上髎、次髎、中髎、下髎，左右交替，或者一起针，像排针一样。治妇科病，他会在八髎区域排针，然后加关元、三阴交。他说：“八髎一起针，整个骶骨的气血都活了，效果比单针一个穴好得多。”

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原话**：“八髎穴，你们要好好学。这是治妇科病的法宝。尤其是下髎，在第四骶后孔，你针下去，病人会觉得小腹在动，这就是气到了。痛经的病人，针下髎，配合关元、三阴交，针完就不痛了。”
- **手下针感体会**：倪师说，针下髎，针尖穿过骶后孔时，会有一种“落空感”，像扎穿一层纸。这时候病人会感觉局部酸胀，或者有一股气往下走，走到小腹、会阴。如果病人说“有一股气冲到子宫了”，那就到位了。如果针下去病人喊痛，那是扎到骨头了，要退针，调整角度。
- **医案故事**：倪师讲过一个案例。有个女的，痛经十几年，每次月经来都痛得在床上打滚。倪师给她针八髎，重点针下髎，配合关元、三阴交。针第一次，病人就说痛减了。针了三次，下次月经来，几乎不痛了。倪师说：“八髎穴治痛经，比吃药还快。你针下去，气血一通，痛就没了。”
- **针灸秘要**：倪师强调，八髎穴针灸，一定要让病人趴着，放松。针之前，先用手按压八髎区域，找到最酸胀的点，那就是穴位所在。针下髎，针尖要朝内下方斜刺，顺着骶后孔进去。不要直刺，直刺扎到骨头，进不去。灸八髎，用艾条悬灸，整个骶骨热起来，效果最好。倪师说：“八髎穴，灸比针还舒服。尤其是虚寒性的妇科病，灸八髎，病人会觉得整个下半身都暖了。”
