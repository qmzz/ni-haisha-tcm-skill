# 居髎

## 📍 经络归属与精准取穴法

- 居髎穴归属**足少阳胆经**，为**阳跷脉与足少阳胆经之会穴**。倪师在《人纪·针灸篇》中讲足少阳胆经时指出，居髎位于髂骨之上、髋关节附近，属胆经在髋部区域的重要穴位，与阳跷脉相通，故能治腰腿痿痹、筋脉拘急之证。它不是井荥输经合五输穴，也不是原络郄募俞，其特定穴属性为**阳跷脉交会穴**——这一点在临床上极重要，凡是“阳缓而阴急”或“阴缓而阳急”的腿脚问题，阳跷脉的穴都能治。

- 倪师讲居髎的找法，绝不是让你去背“髂前上棘与股骨大转子最凸点连线的中点”这种死板的话。倪师在课堂上（《人纪·针灸篇》足少阳胆经部分）是这样教的：**你先摸到髋骨最高那个骨头尖（髂前上棘），再摸到屁股侧面那个大骨头转子（股骨大转子），两个骨头中间有一条连线，居髎就在这条线的正中间**——你摸上去会感觉到一个凹陷，那个凹窝就是穴。倪师强调，居髎是“髎穴”，髎就是骨孔、骨缝的意思，所以**一定要贴着骨头边下针，不能扎在肌肉上，扎到骨缝里才有效**。下针时，让病人侧卧，下面那条腿伸直，上面那条腿弯起来，这样髋骨和大转子之间的缝隙才打得开，一摸就摸到了。

- 关于下针深度与禁针禁灸：倪师讲，居髎**直刺或斜刺，针入一寸半到两寸**，针下去后病人会有酸胀感往整个髋关节甚至大腿外侧放散。这个穴**可以灸**，尤其对髋部冷痛、下肢无力的人，灸居髎能温通阳气。但倪师特别提醒：**居髎靠近关节腔，绝对不要用粗针猛扎，也不要深刺到关节囊里面**，扎到骨面即可，否则容易引起关节积液发炎。禁针的情况是局部皮肤有感染、或者髋关节刚受过外伤肿胀的时候，先不要下针。


## ⚡ 倪师经穴气化与破局心法

- 倪师推演居髎的气化机理，是从**阳跷脉**入手的。阳跷脉起于足跟，沿外踝上行，经过髋部，上入肩背，到口角、眼角，主一身**左右阴阳的平衡**。居髎是阳跷脉与胆经的交会点，它的气血流注特点是：**把胆经的阳气从髋部向上下两端输布——往上走能通达胁肋、肩背，往下走能濡养大腿外侧、膝关节**。所以居髎的破局心法就是两个字：**“通”与“转”**。通，是通利髋关节的气血闭塞；转，是转枢下肢的运动功能。凡是髋关节屈伸不利、腿脚转动不灵、走路一瘸一拐的，居髎就是转枢的钥匙。

- 从五行生克看，胆经属木，居髎作为胆经在髋部的穴位，它的母穴是胆经的井穴足窍阴（金生木？不对，胆经属木，水生木，母穴是通谷——水穴），子穴是阳辅（火穴，木生火）。居髎本身不是五输穴，但倪师在临床运用时，**如果髋部虚寒、筋骨无力，就补居髎，同时补胆经的水穴通谷（母穴），这叫“虚则补其母”，补水以生木，让胆经的阳气有源头**；**如果髋部红肿热痛、筋脉拘挛，就泻居髎，同时泻胆经的火穴阳辅（子穴），这叫“实则泻其子”，泻火以清木，让胆经的邪热有出路**。倪师讲，居髎本身是局部取穴，但配上子母补泻的远端穴，效果就完全不一样了——这是“近取局部，远取子母”的排针心法。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：居髎的第一大主治是**髋关节痛、屈伸不利、腿脚转动不灵**，这是它的看家本领。不管是风湿性髋关节炎、股骨头问题、还是单纯的闪腰岔气导致髋部筋缩，居髎都是首选。第二大主治是**腰腿痛**，特别是那种痛从腰部沿着屁股外侧一直窜到腿外侧的（胆经走向的坐骨神经痛），居髎能疏通胆经在髋部的郁堵。第三是**下肢痿痹、脚无力**，尤其是中风后遗症患者，腿能抬但迈不出去，居髎配上阳跷脉的其他穴位，能帮助恢复步态平衡。

- 倪师经典对穴与排针组合：

    - **居髎 + 环跳**：这是治髋部一切问题的“铁三角”核心组合。环跳是胆经与膀胱经的交会，主髋部深层的气血；居髎是阳跷脉交会，主髋部浅层和关节缝隙。两针齐下，一深一浅，一里一表，髋关节的气血就全打开了。倪师讲，针环跳要深，针居髎要贴着骨边，两个穴的气感要能接上，病人才会觉得整个屁股“松了”。

    - **居髎 + 阳陵泉**：阳陵泉是筋之会穴，主一身筋脉。居髎治髋关节的骨缝，阳陵泉治全身的筋，两个配合，专治筋脉拘挛、腿伸不直、蹲不下去的毛病。倪师说这叫“骨筋并治”。

    - **居髎 + 悬钟（绝骨）**：悬钟是髓之会穴，主骨髓。居髎在髋，悬钟在踝，上下呼应，专治下肢痿软无力、骨头里发空发冷的感觉。老年人腿脚没劲、走路发飘的，这个组合最合适。

    - **居髎 + 风市**：风市在大腿外侧，是祛风要穴。居髎配风市，专治风邪客于经络导致的腿外侧麻木、游走性疼痛。倪师讲，风性善行而数变，今天痛这里明天痛那里，就在居髎和风市上做文章。

    - **居髎 + 足三里 + 三阴交**：这是倪师调理中风后遗症下肢问题的经典排针。足三里补中气、健脾胃，让气血有来源；三阴交调肝脾肾三经，让阴血能濡养筋脉；居髎局部通利髋关节。三针下去，上面补、下面调、中间通，腿脚的功能就慢慢回来了。


## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲足少阳胆经居髎穴时，原话大意是这样：**“居髎这个穴，你摸到那个骨缝，针下去，病人会感觉到整个髋关节好像被电到一样，一股酸胀感从屁股窜到膝盖。这就是气到了。你不要扎得太深，扎到骨头边就行了，扎到关节里面去，病人第二天关节会肿。”**

- 倪师在课堂上讲过一个实战案例：**“有个老太太，髋关节痛了十几年，走路只能小碎步，腿张不开。我给她针居髎、环跳、阳陵泉，针完第一次，她起来走路，腿就能抬高一点了。针了五次，她可以自己上下楼梯。居髎这个穴，对老年人髋关节退化，效果非常好。但你要注意，针居髎的时候，病人一定要侧卧，下面的腿伸直，上面的腿弯曲，这样骨缝才开，针才能到位。”**

- 倪师还特别强调过居髎与阳跷脉的关系：**“阳跷脉主一身左右之阳，人走路两条腿要交替，就是阳跷脉在管。居髎是阳跷脉的会穴，所以腿脚不协调、走路一脚高一脚低的，居髎是必扎的。你扎了居髎，病人会觉得两条腿好像重新对齐了一样。”**

- 倪师手下针感体会：针居髎，**针尖触到骨面时，会感觉到针身有轻微的弹动，那是气至的表现**。这时候不要再往里推，稍微提一点，留针二十分钟，病人的髋部会有温热感，甚至整个大腿外侧都暖暖的。倪师说，这就是“阳跷脉的气通了”。如果针下去病人没感觉，那是没扎到骨缝，要退出来重新摸骨再扎。
