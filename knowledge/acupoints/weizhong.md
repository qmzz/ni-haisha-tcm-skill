# 委中穴 (BL40)

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。膀胱经从头走足，行于背脊与下肢后侧，是人体最长、穴位最多的一条阳经，倪师称之为“最大的排毒通道”。
- **五输穴属性**：委中是膀胱经的**合穴**，五行属**土**。膀胱经五行属水，水经之土穴，土能克水，故此穴是膀胱经的“制水之穴”。倪师在《人纪》中反复强调：**“膀胱经的合穴就是委中，合穴主的是‘逆气而泄’，所以腑病、气逆、胀满，统统可以在合穴上治。”**
- **特定穴属性**：委中为**血郄**，是八会穴中“血会”膈俞之下、调理血证的重要穴位。倪师常讲：**“身上有淤血、毒血，在委中放出来，比吃药还快。”** 同时委中也是膀胱经下合穴体系的枢纽，所谓“腰背委中求”，凡腰背部气血淤滞，委中皆可开合通气。
- **倪师动态取穴与骨度折量法**：
  取穴时让病人**俯卧或弯腰**，膝盖微屈。倪师在讲课时喜欢用手去摸腘窝：**“你叫他腿弯起来，膝盖后面腘横纹的正中间，两条大筋——一条是半腱肌肌腱，一条是股二头肌肌腱——中间那个凹陷，就是委中。”** 用食指按压，会感到明显的酸胀，有时病人会告诉你“这里酸到脚底去了”，那便是气至。
  倪师特别提醒：**“委中在腘窝正中央，你摸到两条筋，筋中间才是穴。不要扎到筋上，扎到筋上病人会像触电一样弹起来。”**
- **下针深度与禁针禁灸法则**：
  倪师在《人纪》中明确：**“委中直刺，针下去五分到八分，不要深，一寸最多了。”** 因为委中下方有腘动、静脉，深刺易伤血管。至于**禁灸**，倪师曰：**“委中禁灸，因为这个地方是血管、筋脉集中的地方，灸了容易伤血，而且这个穴本身就是用来放血的，你灸它干嘛？”** 所以委中在倪师手上几乎是**只针不灸、或放血**的穴位。

## ⚡ 倪师经穴气化与破局心法

- **经气流注与开阖机理**：
  膀胱经是太阳经，太阳主表，主一身之藩篱。委中作为膀胱经的合穴，是经气由足小趾外侧一路循行、汇聚于腘窝的**总合之处**。倪师推演：**“膀胱经的经气，从睛明一路下来，像一条大河，到了委中这里，是河水入湖的关口。”** 水性趋下，膀胱经的经气也带着寒水之气下行，委中就像一道闸门，把经气中多余的、淤滞的水湿、毒血在这里汇聚，再决定是往下走到小趾出去，还是从委中放掉。所以委中善治**水湿停聚、气血瘀滞**诸证。
  同时，委中属土，土能制水。膀胱为水腑，若水液泛滥，如水肿、小便不利，取委中土穴可以**培土制水**，让水湿不再泛滥。倪师讲：**“水太多了，用土去挡，这是委中的另一种用法。”**
- **子母补泻与五行生克运用心法**：
  - 膀胱经属**水**。
  - 委中为**土**穴。
  - 五行生克：**土克水**。所以委中对于膀胱经而言，是**“实则泻其子”的反方向运用**——土为水之“所胜”，若膀胱经实热、水湿泛滥，取委中土穴，是以“克”为泻，以土制水。
  - 若膀胱经气虚、下焦不固、遗尿、小便失禁，则不宜在委中上补，而应取膀胱经的**母穴——至阴（金生水）** 来补。倪师强调：**“补要补母，泻要泻子。膀胱经的母穴是至阴，子穴是束骨。委中是合穴，合穴治腑，不是补虚的地方。”**
  - 倪师心法：**“委中不是拿来补的，是拿来通的、泄的、放的。你把它当补穴用，就搞反了。”**

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **腰背痛**：“腰背委中求”——这是委中第一主治。无论急性腰扭伤、慢性腰肌劳损、腰椎间盘突出、坐骨神经痛，委中都是首选。倪师说：**“腰背的问题，你在委中下针，针一下去，病人腰就松了。”**
  - **急性吐泻、中暑、霍乱**：委中放血，是倪师治疗急性胃肠炎、中暑昏迷的急救手法之一。倪师曰：**“夏天中暑，头晕、恶心、想吐，在委中放几滴黑血出来，人马上就清醒了。”**
  - **皮肤病**：如丹毒、疔疮、湿疹、牛皮癣。委中放血可清血分热毒。
  - **下肢痿痹、半身不遂**：委中可疏通下肢气血，配合环跳、阳陵泉、承山治疗下肢不遂。
  - **小便不利、水肿**：委中土穴制水，配三阴交、阴陵泉可利水消肿。
  - **血症**：鼻衄、吐血、便血，委中放血可引血下行。
- **倪师经典对穴与排针组合**：
  - **委中 + 肾俞 + 大肠俞**：治腰痛。倪师说：**“腰的问题，近取肾俞、大肠俞，远取委中，这叫远近配穴。”**
  - **委中 + 承山**：治腿抽筋、坐骨神经痛。承山是膀胱经另一个重要穴位，与委中上下呼应。
  - **委中 + 三阴交 + 阴陵泉**：治水肿、小便不利。三阴交调三阴，阴陵泉健脾利水，委中制水，三穴合用，水湿自去。
  - **委中放血 + 曲池放血**：治皮肤病、血热。曲池清阳明热，委中清太阳血热，上下放血，热毒自解。
  - **委中 + 环跳 + 阳陵泉**：治下肢痿痹、半身不遂。环跳通少阳，阳陵泉主筋，委中主血，三穴通经活络。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味金句**：
  - **“腰背委中求，这句话你们要背一辈子。腰背的问题，你就在委中上做文章。”**
  - **“委中放血，是针灸里最好的排毒法。你看到那个黑血喷出来，病人当场就松了。”**
  - **“委中穴，你摸到两条筋，筋中间才是穴。针下去五分，不要深，深了会扎到血管。”**
  - **“委中禁灸。这个穴是放血的，你灸它，火上浇油。”**
  - **“膀胱经的合穴是委中，合穴治腑病。所以膀胱的问题、水的问题、气逆的问题，统统可以在这里治。”**
  - **“有些人腰痛，你在委中扎针，针一下去，病人说‘哎呦，我的腰松了’，这就是气至病所。”**
- **实战手下针感体会**：
  倪师在视频中示范委中下针时，常用左手拇指按压委中穴，右手持针快速刺入。针入五分左右，病人会有**酸、麻、胀**感，有时会**向下肢放射到脚底**，有时会**向上传到腰部**。倪师说：**“针感往哪里走，就说明气往哪里通。往脚下走，说明下肢气血通了；往腰上走，说明腰部的气机开了。”**
  若用**放血法**，倪师先用拍打或热敷让委中周围血管充盈，再用三棱针快速点刺，然后拔罐，让黑血流出。倪师形容：**“那个血，黑的像墨汁一样，放出来之后，病人马上觉得腰轻了，头也不晕了。”**
- **医案故事**：
  倪师在《人纪》中讲过一则案例：一位患者**急性腰扭伤**，痛得无法转身，被人扶着进来。倪师让患者俯卧，在**委中**下针，针入五分，行**泻法**，同时让患者慢慢活动腰部。**针下去不到两分钟，患者说腰不痛了，可以自己翻身下床。** 倪师说：**“这就是‘腰背委中求’的威力。你只要针对了，效果就是这么快。”**
  又一例：**夏天中暑**的患者，头晕、恶心、脸色苍白。倪师在**委中放血**，黑血一出，患者立刻说“头不晕了，想喝水了”。倪师曰：**“中暑就是热毒闭在血分里，委中放血，把毒血放掉，热就散了。”**
