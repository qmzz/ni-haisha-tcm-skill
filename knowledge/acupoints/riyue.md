# 日月穴 (GB24)

## 📍 经络归属与精准取穴法

日月穴，代号GB24，归属于足少阳胆经。在倪海厦老师的五输穴体系中，日月穴是胆经的**募穴**。募穴者，脏腑之气汇聚于胸腹部的特定穴位，是调理脏腑功能、治疗慢性虚损的核心门户。胆之募穴即日月，与肝之募穴期门相平，一脏一腑，阴阳相配，在临床上意义重大。

**动态取穴与骨度折量法：**

倪师在《人纪·针灸篇》中讲胆经时反复强调，取穴要“以骨为凭，以筋为界，以肉为候”。日月穴的精准定位，离不开乳头与肋骨这两个关键参照物。

1. **先找乳头**：让患者自然平躺，乳头正下方画一条垂直线，此为基准线。
2. **再数肋间**：从锁骨下缘开始数肋骨间隙。第一肋间隙在锁骨下，第二肋间隙在胸骨角外侧……一路数到第七肋间隙。乳头通常平第四肋间隙或第五肋间隙（因人略有差异），但日月穴在**第七肋间隙**。
3. **最后横向定位**：在乳头垂直线与第七肋间隙的交点处，即为日月穴。倪师常说：“你不要死记几寸几分，把肋骨一摸，肋间一数，穴就在那里，跑不掉的。”

**下针深度与禁针禁灸法则：**

- **进针手法**：倪师强调，胸腹部穴位进针必须**斜刺或平刺**，不可直刺深刺。日月穴位于第七肋间隙，内有膈肌、肝脏（右侧）或脾脏（左侧），直刺深刺极易伤及内脏，造成气胸或内出血。正确做法是：沿肋间隙方向，**斜刺0.5～0.8寸**，针尖朝向肋弓方向，得气即止。
- **禁灸原则**：日月穴**禁灸**。倪师在讲义中明确指出，胸腹部靠近脏腑的穴位，尤其是有重要脏器覆盖的区域，艾火之热会直透内膜，轻则灼伤筋膜，重则引动内热，造成吐血、烦躁等变症。日月穴属胆经，胆为清净之腑，喜凉恶热，灸之如火上浇油，故**绝对禁灸**。
- **禁针情形**：肝脾肿大、肺气肿、极度消瘦者，此穴区域解剖结构已发生变化，进针风险倍增，倪师建议以指代针，用**指针点按**替代针刺，同样能激发经气。

## ⚡ 倪师经穴气化与破局心法

**气血流注与开阖机理：**

日月穴的气化机理，要从胆经的整体循行来推演。胆经从头走足，从头维、率谷一路下行，经过风池、肩井，再到渊腋、辄筋，然后到日月、京门，最后下行到环跳、阳陵泉，直达足窍阴。日月穴正好位于胆经在胸胁部的一个**气血汇聚点**，是胆腑之气在体表的“窗口”。

倪师在《人纪》中推演：胆为中正之官，主决断，藏精汁（胆汁），其气以**疏泄**为用。日月穴作为胆之募穴，是胆气在胸胁部的**开阖之枢**。当胆气郁结、疏泄失职时，日月穴处往往会出现压痛、结节或酸胀感。此时针日月，等于直接打开胆腑的“排气阀”，让郁结的胆气得以疏泄，胆火得以清降。

更深一层，倪师将日月穴与肝经的期门穴对看：期门在乳头直下第六肋间隙，日月在第七肋间隙，两穴上下仅隔一肋。肝与胆互为表里，期门调肝之血，日月调胆之气，一血一气，一升一降，构成胸胁部气机流转的**太极双鱼**。临床上，倪师常将两穴搭配使用，左期门右日月，或同期门同日月，以恢复肝胆气机的圆运动。

**五行生克与子母补泻：**

胆经在五行属**木**，胆为甲木，肝为乙木。木能生火，木能克土。

- **虚则补其母**：胆木之母为**水**（水生木），对应胆经的母穴是**侠溪穴**（胆经荥穴，属水）。若胆气不足，表现为胆怯、易惊、决断无力、目眩等，倪师会取侠溪穴补之，再配日月穴募穴以固本。
- **实则泻其子**：胆木之子为**火**（木生火），对应胆经的子穴是**阳辅穴**（胆经经穴，属火）。若胆火过旺，表现为口苦、咽干、目赤、偏头痛、胁痛等，倪师取阳辅穴泻之，同时针日月穴以清胆腑之热。
- **五行生克运用**：木克土，胆气郁结常横逆犯胃，导致胃胀、嗳气、食欲不振。倪师在针日月的同时，会加针**足三里**（胃经合穴，属土）以实土御木，或加**中脘**（胃之募穴）以和胃降逆。这就是“见肝之病，知肝传脾，当先实脾”的针灸版演绎。

## 🎯 临床主治与配穴组合手印

**核心特效主治：**

1. **胆腑急症**：急性胆囊炎、胆结石绞痛、胆道蛔虫症。倪师指出，日月穴是胆腑的“感应器”，急性胆痛时，日月穴处往往拒按，针之可迅速缓解痉挛，为后续治疗争取时间。
2. **胁肋痛症**：无论是闪挫跌仆引起的胁肋岔气，还是带状疱疹后遗神经痛，日月穴配合期门、支沟，往往立竿见影。
3. **消化系统慢性病**：胆汁反流性胃炎、慢性胆囊炎、胆胃综合征。倪师强调，此类病根在胆，胆气不疏则胃气不降，针日月以疏胆，配公孙、内关以调胃心胸。
4. **情志病**：胆主决断，胆气不足则优柔寡断、易惊善恐。日月穴配**丘墟**（胆经原穴）、**神门**（心经原穴），可宁胆安神，治疗焦虑、失眠、心悸。
5. **妇科**：胆经循行经过胸胁，与冲脉、肝经相通。日月穴配**三阴交**、**太冲**，可调理因胆气郁结引起的月经不调、乳房胀痛。

**倪师经典对穴与排针组合：**

- **日月 + 期门**：肝胆同治，气血双调。倪师常讲：“期门管血，日月管气，两个一起下，肝胆的气血就活了。”用于所有肝胆气滞血瘀之证。
- **日月 + 支沟 + 阳陵泉**：支沟为三焦经经穴，善治胁肋痛；阳陵泉为胆经合穴，善治胆腑病。三穴合用，是倪师治疗胆绞痛、胆结石的**实战排针**。
- **日月 + 公孙 + 内关**：公孙配内关是倪师治疗胃心胸疾病的经典组合。加日月穴，专门针对胆胃不和引起的胃胀、反酸、胸胁满闷。
- **日月 + 太冲 + 足三里**：太冲泻肝，足三里补胃，日月调胆，三穴构成“肝胆胃”三角调理阵，用于慢性胆囊炎、胆汁反流性胃炎。
- **日月 + 大包**：大包为脾之大络，总统阴阳诸络。倪师用此组合治疗全身气机不畅、胁肋胀满连及后背者，一穴调胆，一穴通络，上下呼应。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲胆经时，讲到日月穴，原汁原味的金句如下：

> “日月穴，胆的募穴。你摸，乳头正下方，第七肋间隙。你数肋骨嘛，一、二、三、四、五、六、七，第七肋骨缝中间，就是日月。你不要拿尺去量，拿尺量是笨蛋，你摸肋骨最准，每个人高矮胖瘦不一样，肋骨数出来就对了。”

> “针日月，斜刺，顺着肋间隙下去，半寸到八分，不要直刺。你直刺下去，右边是肝，左边是脾，扎穿了要出人命的。得气就好，病人会感觉到酸胀往胁肋两边散开，那就到位了。”

> “日月穴禁灸，你拿艾条一烤，胆火就上来了，病人当场口苦、心烦。胆是清净之腑，你给它加热，它就不清净了。所以胸腹部这些靠近脏腑的穴位，我都不太赞成灸，除非是虚寒到极点，那也要选关元、气海这些地方，不要选日月。”

> “临床上胆结石的病人，你按他日月穴，十个有九个会叫痛。你针下去，再针支沟、阳陵泉，那个痛当场就松了。为什么？因为募穴是腑气汇聚的地方，你针它，等于给胆腑开了一扇门，郁气有出路了。”

倪师在讲课时还分享过一个医案：

> “有个太太，胆囊炎十几年，右边胁肋经常胀痛，吃一点油就发作。我一看，日月穴处鼓起来一块，按之如泥，眼睛也发黄。我针日月、期门、阳陵泉、足三里，针了三次，她跟我说，倪医师，我右边的‘那块石头’好像被搬走了。其实我没有搬走任何东西，我只是把她胆经的气机打通了，它自己把垃圾运走了。”

**手下针感体会：**

倪师描述，针日月穴时，针尖穿过肋间肌的那一刻，手下会有一种**“穿透薄膜”的落空感**，此时患者往往会深吸一口气，感觉胁肋部有热流或酸胀感向四周扩散。若患者感觉刺痛或针感向胸腔内放射，说明针尖方向不对，应立即退针调整角度。倪师强调：“针日月，要像蜻蜓点水，点到即止，不要贪深。气到了，效果就有了。”

**针灸秘要总结：**

日月穴是胆腑在体表的“气口”，针之可疏胆气、清胆火、利胆腑。取穴以肋骨数为准，斜刺半寸至八分，禁灸。临床上与期门、支沟、阳陵泉、公孙、内关等穴灵活配伍，可治疗从急性胆绞痛到慢性胆胃不和、从胁肋痛到情志病的广泛病症。倪师心法，重在**“以骨定穴，以气为用，以通为补”**，日月一穴，正是这一心法的绝佳体现。
