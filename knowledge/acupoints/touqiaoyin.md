# 头窍阴

## 📍 经络归属与精准取穴法

- 头窍阴归属**足少阳胆经**，在足少阳胆经的循行体系中，它紧接足太阳膀胱经的天柱之后，是胆经从脑后进入耳后、再上头角这条上行干线上的**转枢要穴**。胆经的井荥输经合五输穴分别在足窍阴（井金）、侠溪（荥水）、足临泣（输木）、阳辅（经火）、阳陵泉（合土），而头窍阴**不在五输穴之列**，它是胆经在头部的重要腧穴，与**听会、完骨、本神**共同构成胆经在侧头部的穴群。其五行属性，要从胆经“甲木”本气与穴名“窍阴”去推——窍者孔窍也，阴者阴液、阴精也，此穴近耳窍、近脑窍，是**胆经精气灌注耳窍、脑窍的门户**，倪师在讲胆经时反复强调：*“胆经的穴道，只要靠近耳朵、靠近脑后的，统统能治耳朵和偏头痛，因为胆经的线就是从那儿绕过来的。”*

- 倪师取头窍阴，最重**骨度折量加摸骨探穴**。标准定位是：在头部，耳后乳突的后上方，**天冲穴至完骨穴的弧形连线上**，当**浮白穴与完骨穴连线的上1/3与下2/3交点处**。翻译成大白话：你先找到耳后那块最突出的骨头——**乳突骨**，也就是完骨穴所在；再从耳尖往上往后摸，摸到天冲穴附近；这两点之间画一条弧线，弧线的**中下三分之一交界那一点**，按下去有酸胀感、往往病人会喊“对，就那儿”，那就是头窍阴。倪师常说：*“穴道是活的，书上写‘完骨上、浮白下’，但你手一摸，骨缝里那个凹陷才是真穴，死记尺寸没用。”*

- **下针深度**：倪师手法是**沿皮刺，平刺0.5～0.8寸**，绝对**不直刺深刺**。因为此处头皮薄、紧贴颅骨，深刺无益，反而容易伤及骨膜引起剧痛。倪师原话大意：*“这种头上的穴，你针下去贴着皮，半寸、八分就够了，它是引气机到窍的，不是让你扎进脑子里的。”* **禁灸**——头部阳经穴位多禁灸，头窍阴尤其不宜艾灸。倪师在讲头部穴时反复告诫：*“头上少灸，一灸火上头，病人头痛更厉害。”* 所以此穴**只针不灸**，虚证也以针代灸，用补法。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演头窍阴的气化机理，核心在一个字：**“窍”**。胆经之气从头角下行耳后，经过头窍阴时，**精气要向耳窍、脑窍灌注**。所以此穴的气化功能是**“开耳窍、清脑窍、疏胆经之郁热”**。胆经郁热上扰，病人会耳聋、耳鸣、偏头痛、眼睛发花——这就是胆火上冲，堵在窍里出不来。头窍阴正是那把**开窍的钥匙**。倪师原意是：*“胆经的热往上走，走到耳朵后面堵住了，耳朵就聋了、鸣了。你针头窍阴，就是给它开个口，让郁热散掉，耳窍就通了。”*

- 再深一层，倪师讲此穴还有**“引阳入阴”**之机。胆经属阳，头为诸阳之会，但**耳窍、脑窍需要阴液的滋润才能听、才能思**。头窍阴穴名中的“阴”字，倪师点破：此穴能把胆经上亢的阳气**往下引、往阴分引**，让浮阳归位。所以它治**失眠、脑鸣、头晕目眩**，机理是**潜阳入阴、引火归元**——不是补肾那种引火归元，而是**把胆经浮越之火拉回胆腑**，胆火一降，心神就安，人就能睡。

- **子母补泻与五行生克**：头窍阴不直接参与五输穴子母补泻，但倪师在临床上会**借胆经五输穴做母子配穴**来放大头窍阴的效果。胆经属木，**木之母为水**，所以**虚则补其母**——胆气虚、耳窍失聪、脑鸣绵绵不休的，取胆经荥水穴**侠溪**（水穴，水生木）做补法，再配头窍阴开窍，这叫**“母补其子之窍”**。**实则泻其子**——胆经实火、耳聋暴发、偏头痛如裂的，取胆经经火穴**阳辅**（火为木之子）做泻法，再针头窍阴放郁热，这叫**“泻子以清母之窍”**。倪师心法：*“头窍阴是开门的，侠溪、阳辅是调水火的，门开了，水火才能各归其位。”*

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：头窍阴的看家本领是**耳疾**——**耳鸣、耳聋、耳中痛痒、耳流脓**。不管是突发性耳聋、神经性耳鸣，还是中耳炎后的听力减退，此穴都是倪师必取。其次治**偏头痛**，特别是**耳后痛、后脑痛牵引到耳根**的那种，西医叫枕大神经痛、耳大神经痛，倪师一针头窍阴，痛就松一半。第三治**脑鸣、头晕、目眩**，病人说“脑子里像有蝉叫”“头一摇就晕”，这是胆经风火上扰清窍，头窍阴能清。第四治**失眠、多梦、心烦**，尤其是胆经当令（子时）易醒、醒后难睡的，此穴引胆火下行，神就安了。第五，倪师还用它治**颈项强痛连及耳后**，因为胆经循颈，此穴能疏通颈侧经气。

- **倪师经典对穴与排针组合**：
  1. **头窍阴 + 听会 + 翳风**：治一切耳疾。听会开耳前，翳风开耳后，头窍阴开耳上后，三穴合围，把耳朵前后上下的气机全打开。倪师说：*“耳聋耳鸣，这三针下去，像给耳朵开了三扇窗，气一通，声音就进来了。”*
  2. **头窍阴 + 风池 + 率谷**：治偏头痛、后头痛。风池散风，率谷透头角，头窍阴通耳后，三穴把胆经在侧头的线全打通。
  3. **头窍阴 + 足临泣**：这是**远近配穴**的典范。足临泣是胆经输木穴，主“体重节痛、耳聋耳鸣”，是胆经的远道要穴；头窍阴是局部开窍穴。一远一近，一上一下，引胆经之气上下贯通。倪师常用此组合治**少阳头痛、耳胀、胸胁苦满**。
  4. **头窍阴 + 太冲 + 合谷**：开四关的变阵。太冲（肝经原穴）泻肝火，合谷（大肠经原穴）泻头面热，再配头窍阴开耳窍脑窍，治**肝胆火旺导致的暴聋、暴鸣、头胀痛**，效果极快。
  5. **头窍阴 + 三阴交 + 太溪**：治**虚性耳鸣、脑鸣**。三阴交调肝脾肾三阴，太溪补肾水，头窍阴开窍，这是**“补水开窍”**法，针对肾虚不能濡养耳窍、胆经浮阳上扰的慢性耳鸣。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲胆经头部穴位时，原汁原味的金句大意如下：*“从完骨上来，到浮白、到头窍阴，这一排穴道，你只要记得一件事——它们都在耳朵后面。耳朵后面这一圈，是胆经和膀胱经交会的地方。所以耳朵的问题，你针完骨、针头窍阴、针浮白，统统有效。为什么？因为胆经的热堵在耳朵后面了嘛。你针下去，气一到，热就散了，耳朵就开了。”*

- 倪师手下针感体会：头窍阴下针，**针尖沿皮刺入**后，病人常感觉**一股酸胀感从耳后向耳内、向头顶扩散**，有时耳朵里会突然“嗡”一下，然后耳鸣减轻。倪师说：*“你针下去，病人说耳朵里好像有东西通了，那就是气到了。这时候你不要再提插，让它留在那儿，留针二十分钟，气自己会走。”* 如果是实证耳聋，起针后可能耳朵里流出一点水或感觉热乎乎的，那是郁热外散；如果是虚证，起针后病人会觉得耳朵里“空空的、松松的”，那是气通了的反应。

- 倪师实战医案故事：曾有一妇人，**右耳突发耳聋三天**，西医查不出原因，说可能是病毒性神经炎。倪师一看，病人**耳后按压痛、偏头痛、口苦、脉弦数**，断为**胆火上冲、堵住耳窍**。取穴：**头窍阴（右）、听会（右）、翳风（右）、足临泣（双）、太冲（双）**。头窍阴沿皮刺，听会张口进针，翳风直刺，足临泣、太冲泻法。针下不到五分钟，病人说耳朵里“像有风在吹”，留针二十分钟起针，病人**听力恢复大半**，第二天再针一次，痊愈。倪师总结：*“这种暴聋，就是胆经的火堵住了。头窍阴是开窍的，足临泣是泻火的，火一泻、窍一开，耳朵就听见了。你不要去管什么神经炎，中医看的就是胆火。”*

- 倪师还有一个**秘要**：头窍阴配**耳门、听宫、听会**三穴时，**先针头窍阴**，再针耳前三穴。为什么？倪师说：*“你先从头窍阴把耳后的气打开，再去开耳前的穴，气才进得去。你先针耳前，气堵在耳后，进不去，效果就慢。”* 这是倪师手下**顺序心法**，书上不写，视频里才讲。

- 最后，倪师强调：头窍阴**禁灸**，**禁深刺**，**禁提插捻转过度**。头部穴位，**气到即止**，手法要轻、要柔、要留。*“头上针，像蜻蜓点水，不是让你去耕地。”* 这是倪师对头窍阴乃至所有头部穴位的总诀。
