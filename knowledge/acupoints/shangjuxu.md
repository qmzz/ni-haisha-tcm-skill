# 上巨虚

## 📍 经络归属与精准取穴法

- 上巨虚归属于**足阳明胃经**，为**大肠之下合穴**。《灵枢·邪气脏腑病形》云：“合治内腑”，六腑有病取之于下合穴。大肠为六腑之一，其气通于上巨虚，故凡大肠传导失职、腑气不通之症，皆可取此穴调之。
- 倪师在《人纪·针灸篇》中讲得明白：**下巨虚是小肠的下合穴，上巨虚是大肠的下合穴**。两个穴怎么区分？上巨虚在上，下巨虚在下。从**足三里往下走三寸就是上巨虚，再往下三寸就是下巨虚**。所以上巨虚管大肠，下巨虚管小肠，这是它的名分。
- 从五行属性看，足阳明胃经为**土经**，上巨虚为土经中之穴，与胃土同气相求。大肠属金，土生金，故此穴能以胃土之气滋养大肠金腑，本就是**母子相生**的关系，天然具备通调大肠的底气。
- 倪师动态取穴法：先找**足三里**。足三里怎么找？膝盖骨下方有个凹陷叫**犊鼻**，从犊鼻往下量**三寸**（四指并拢为三寸），胫骨外侧一横指处，按下去酸胀感极强，那就是足三里。找到足三里之后，**从足三里直往下再量三寸**，也就是犊鼻下六寸，胫骨前缘外开一横指，这就是上巨虚。再往下三寸是下巨虚，条口在上巨虚和下巨虚中间。
- 倪师特别强调：**骨度折量法要活用**。不要死记“犊鼻下六寸”这个数字，人的高矮胖瘦不同，寸是比例寸。你用手去摸，从膝盖到外踝尖是十六寸，取其中间再偏上一点，骨头边上按到酸麻胀重的地方，那就是穴。**扎针要扎在胫骨骨膜旁边，贴着骨头下针，不要太靠外**，靠外扎到肌肉层，效果就差了。
- 下针深度：倪师说**一寸到一寸半**。成人可以扎到一寸半，小孩子浅一些，半寸到一寸即可。针尖方向**直刺**，微微偏向胫骨方向，让针感贴着骨膜传导。
- 禁针禁灸法则：上巨虚**可以灸**，尤其是虚寒性的腹泻、便秘，灸比针还好。但**红肿热痛的实热证，不灸**，只针。孕妇**慎针**，尤其不宜深刺，因为阳明经气与冲脉相通，过强刺激可能影响胎气。局部皮肤溃烂、感染处禁针。

## ⚡ 倪师经穴气化与破局心法

- 倪师在讲下合穴时反复强调一个核心观念：**六腑的病，要从合穴下手**。为什么？因为**合穴是经气深入脏腑、汇合入内的关口**。就像江河入海的地方，水流最大、力量最猛。大肠的经气在体内汇聚之后，从下合穴上巨虚这里透出来，所以**大肠有问题，你扎上巨虚，就是直接在大肠的经气总开关上做文章**。
- 上巨虚的气化机理，倪师讲得极为透彻：**它能把胃经的土气转化传导到大肠**。土能生金，胃气强壮了，大肠的传导功能自然恢复。所以这个穴的本质是**借胃土之力，行大肠之腑**。凡是大肠传导失常——不管你是腹泻还是便秘——上巨虚都能调。**腹泻是水湿下注，上巨虚能升提中气、分清泌浊；便秘是腑气不通，上巨虚能通降浊气、导滞下行**。同一条经、同一个穴，为什么能双向调节？因为它是合穴，合穴调的是**气化的方向**，而不是死板地“止泻”或“通便”。气化正常了，该升的升，该降的降，大肠自己就知道该干什么。
- 从五行生克看：胃经属土，大肠属金，**土生金为母子关系**。上巨虚作为土经之穴，天然就有**补益大肠金气**的作用。虚证——比如久泻不止、大肠气虚下陷——取上巨虚就是**虚则补其母**，用胃土之气来补大肠之虚。实证——比如热结旁流、大肠实热便秘——取上巨虚就是**实则泻其子**，通过泻大肠金气来间接清胃土之热。
- 倪师还点出一个关键：**上巨虚与足三里是母子配穴**。足三里是胃经的合穴（土经土穴），是胃气的大本营；上巨虚是胃经的下合穴，是大肠之气的汇聚点。**先针足三里，再针上巨虚，就是先固中土、再通大肠**。中土一旺，四旁得养，大肠的传导就有了后劲。这个顺序不能乱，乱了就散了。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **一切大肠腑病**：急慢性腹泻、便秘、痢疾、肠鸣、腹胀、腹痛、肠痈（阑尾炎初期）。倪师说**阑尾炎发作，先扎上巨虚，再配阑尾穴**（足三里下二寸），当场就能缓解疼痛。这是下合穴“合治内腑”的经典运用。
  - **脾胃病**：胃痛、胃胀、消化不良、食欲不振。上巨虚虽是大肠下合穴，但穴位在胃经上，同样能调胃气。
  - **下肢痿痹**：中风后下肢无力、坐骨神经痛、膝关节痛、小腿酸麻。**上巨虚配合足三里、阳陵泉、悬钟**，是倪师治下肢痿软常用的排针组合。
  - **妇科/儿科**：小儿腹泻、小儿疳积，灸上巨虚配灸天枢、中脘，效果极好。妇人经期腹泻（脾虚湿盛型），上巨虚配三阴交、阴陵泉。
  - **急症**：急性肠炎、食物中毒引起的腹痛吐泻，**先针上巨虚、天枢、中脘，再配内关、公孙**，能迅速止呕止泻。

- **倪师经典对穴与排针组合**：
  - **上巨虚 + 天枢**：天枢是大肠募穴，上巨虚是大肠下合穴，**募穴配下合穴，就是“俞募配穴”的简化版**（严格说是“募合配穴”），专治大肠一切病。针天枢要深，针上巨虚要透，上下呼应，腑气自通。
  - **上巨虚 + 足三里 + 三阴交**：这是倪师治**慢性腹泻、消化不良、脾虚湿盛**的黄金三针。足三里补中土，上巨虚通大肠，三阴交调肝脾肾三经，三针下去，中焦运转，下焦通利。
  - **上巨虚 + 曲池**：曲池是大肠经的合穴（手阳明），上巨虚是大肠的下合穴（足阳明）。**上下合穴同用，通调大肠气机**，治便秘、肠风下血效果倍增。
  - **上巨虚 + 公孙 + 内关**：公孙配内关是倪师治胃心胸的要穴，再加一个上巨虚，**把胃、心、肠三条气脉一起打开**，治胃痛牵连腹痛、胸闷伴便秘的复杂症。
  - **上巨虚 + 阑尾穴 + 天枢 + 关元**：急性阑尾炎的标准组合，倪师说**先针阑尾穴，再针上巨虚，最后针天枢、关元**，留针二十分钟，痛减大半。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》中讲到足阳明胃经下合穴时，原话是：**“上巨虚，是大肠的下合穴。合穴呢，就是我们治内腑的病。所以大肠有问题，你通通可以在上巨虚上面下针。便秘、下利、腹泻，通通可以治。你如果说，老师，上巨虚在下巨虚的上面？对，上面那个管大肠，下面那个管小肠。”**
- 倪师讲取穴时特别强调手感：**“你从足三里往下摸，摸到那个骨头边上，按下去病人会‘啊’一声，那就是上巨虚。不要死板板地量六寸，每个人不一样。你按到那个酸点，就是穴。”**
- 倪师在讲阑尾炎医案时说：**“我有个病人，右下腹疼得打滚，西医说是急性阑尾炎要开刀。我一看，足三里下面二寸的阑尾穴，一按就痛得跳起来。先针阑尾穴，再针上巨虚，针下去不到五分钟，病人说不痛了。再针天枢、关元，留针二十分钟，病人自己走回家的。当然，严重的该开刀还是要开刀，但针灸的急救效果，你不能不知道。”**
- 倪师讲针感体会：**“上巨虚针下去，针感会往下走，走到脚背上去。有时候病人会觉得肠子里面在动，咕噜咕噜响，那是气通了。你针上不要动，让他自己动。气到了，效果就来了。”**
- 倪师在讲子母补泻时说：**“大肠虚，久泻不止，你灸上巨虚，灸足三里，这是补母生子。大肠实，便秘不通，你针上巨虚，针曲池，这是泻子清母。但你不要死记，关键看病人虚实。虚的，灸比针好；实的，针比灸好。针用泻法，灸用补法，这是大原则。”**
- 倪师最后叮嘱：**“上巨虚这个穴，看似简单，但它是大肠经气的总开关。你把这个穴用好了，大肠的病就治了一大半。不要贪多，一个穴扎透了，比十个穴扎浅了强。”**
