# 阴包

## 📍 经络归属与精准取穴法

阴包穴，属足厥阴肝经。肝经从足大趾内侧起，沿腿内侧上行，过膝关、曲泉，再往上走，阴包就位于大腿内侧中段。它在曲泉穴上四寸，股骨内上髁之上，缝匠肌后缘。你摸到膝盖内侧那个高骨——股骨内上髁，从曲泉往上量四寸，也就是大概一个手掌并拢的宽度再加一点，在大腿内侧肌肉隆起处，按下去会有酸胀感，那便是阴包。

倪师讲取穴，从不让你死记硬背。他常说：你顺着肝经往上摸，从曲泉推上来，推到肌肉开始丰厚、指下有一处凹陷或敏感点，那就是阴包。骨度折量法在这里用的是“一夫法”，四指并拢为三寸，再加一拇指宽为一寸，合起来四寸。下针时，直刺一寸到一寸五分，针尖略偏向大腿外侧，得气后局部酸胀，有时会往膝盖或腹股沟方向放散。

禁灸？倪师不太主张在这里灸。阴包位置在大腿内侧，肉厚脉深，灸法热力不易透达，反而容易烫伤皮肤，所以临床上以针刺为主，或配合点按、刮痧。孕妇禁针，因肝经与冲任相关，刺激过强恐动胎气。

## ⚡ 倪师经穴气化与破局心法

阴包的气化机理，倪师是从肝经的“木”性来推的。肝属木，主疏泄，主藏血，其性喜条达而恶抑郁。阴包在大腿内侧中段，正是肝经气血从膝关、曲泉一路升发上来，准备入腹、入胸、上达头面的中转站。它像是一个“气血调度站”——肝经的郁气在这里能不能散开、能不能顺利上行，全看这个关卡通不通。

倪师常讲：肝经郁结的人，大腿内侧往往捏起来绷紧、有硬结，阴包附近尤其明显。你在这里下针，等于给肝经开了一个排气口。气一通，上面胸胁的胀闷、下面的少腹坠痛，都会跟着松解。所以阴包的核心作用是“疏肝理气、活血通络”，让郁住的肝气重新流动起来。

子母补泻怎么用？肝经五行属木，阴包是肝经的腧穴之一，但非五输穴。若要补肝，当补其母——肾经的阴谷；若要泻肝，当泻其子——心包经的大陵。阴包本身不参与子母补泻的穴位选择，但它是肝经气血运行通道上的重要节点。你在大陵泻肝火的同时，若在阴包处下针疏通，等于双管齐下：一头泻热，一头开郁。倪师说这叫“泻子开母路”——把肝经的郁滞从阴包打开，热才有出路可泻。

## 🎯 临床主治与配穴组合手印

阴包的主治，倪师归纳为三大块：

**第一，少腹与妇科问题。** 肝经绕阴器、抵少腹。阴包能通肝经气血，所以少腹疼痛、月经不调、痛经、带下、子宫脱垂，都可取阴包。尤其是痛经，倪师常用阴包配三阴交、太冲。三阴交调三阴经气血，太冲平肝，阴包疏通局部，三穴合用，经前一周开始针，痛经能明显缓解。

**第二，泌尿系统问题。** 肝经与膀胱、肾经相邻，阴包能影响下焦气化。小便不利、遗尿、尿频，配中极、膀胱俞，效果很好。倪师曾讲，有些中老年男性前列腺问题，肝经郁滞是重要因素，阴包针后加灸关元，能改善排尿。

**第三，腰腿痛与下肢痿痹。** 阴包在肝经上，肝主筋。大腿内侧痛、膝内侧痛、下肢筋脉拘挛，取阴包配阳陵泉（筋会）、承山，能舒筋活络。倪师有个经典组合：阴包配环跳、委中，治坐骨神经痛偏内侧者，针后患者常觉一股热流从大腿内侧往下窜。

**对穴组合：**
- **阴包 + 三阴交 + 太冲**——治痛经、月经不调
- **阴包 + 中极 + 膀胱俞**——治小便不利、遗尿
- **阴包 + 阳陵泉 + 承山**——治下肢筋脉拘挛、内侧痛
- **阴包 + 期门 + 支沟**——治胸胁胀满、肝郁气滞

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲肝经这一段时，原话是这么说的：

“阴包这个穴道，在曲泉上四寸。你摸到膝盖内侧那个大骨，从曲泉往上推，推到肌肉厚的地方，那就是阴包。它为什么叫阴包？阴，就是内侧；包，就是包起来。肝经的气血到这里，像被包住了一样，容易郁住。所以妇女同志，月经来之前乳房胀、少腹胀，你在这里一按，哎哟，痛得要命！那就是郁住了。你针下去，或者用指头按揉，把这个包打开，气一散，胀就消了。我们治痛经，常取阴包，再加上三阴交、太冲，针一下去，病人当场就觉得少腹松了。这个穴道，是肝经的‘排气孔’，你记住这句话——肝郁找阴包，气顺百病消。”

还有一段医案：倪师在课上提过，有位四十多岁的太太，长期少腹坠痛，西医说是慢性盆腔炎，抗生素吃了半年没好。倪师看她舌暗、脉弦，大腿内侧阴包处一按就皱眉。他针阴包、三阴交、太冲，留针二十分钟。起针后，患者说肚子里面像有东西“咔”一下松开了。连续针了三次，配合中药当归芍药散，一个多月后症状基本消失。倪师总结说：“病在气，你调气；病在血，你活血。阴包是气郁化火、气滞血瘀的起点，从这里下手，事半功倍。”

针感体会：倪师说，阴包下针，得气后不要急着捻转。先让针静静地“坐”在那里，等局部酸胀感慢慢扩散。有时患者会感觉一股热流或凉气往膝盖或腹股沟走，那是气在动。这时你再轻轻提插几下，顺着肝经的方向引气，效果最好。切忌大幅捻转，大腿内侧肉薄脉多，手法过重容易伤血络。

最后倪师叮嘱：阴包虽好，但不能滥用。肝经实证、郁证，用阴包开郁；肝血虚、肝阴虚者，要配太溪、照海滋阴养血，不可一味疏泄，否则越疏越虚。这就是“补其母、泻其子”之外的变通心法——看虚实，调开阖。
