# 梁丘穴 (ST34)

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经。梁丘是胃经的**郄穴**。郄穴者，气血深聚之孔隙也，多用于急症、痛症，阳经郄穴尤善治急性痛证。
- **穴名释义**：梁，屋梁也，横木也；丘，土丘也，高处也。穴在膝盖上方，股骨外侧髁之上，犹如筑梁于丘上，故名梁丘。
- **精准取穴**：屈膝，从膝盖外上缘（髌骨外上缘）直上两寸。找穴时，先让病人屈膝，膝盖骨外上缘有一条肌肉（股外侧肌）隆起，沿着这条肌肉往上推两寸即是。简单说：膝盖骨外上角直上三横指，肌肉隆起处，按之有明显酸胀感，就是梁丘。
- **下针深度**：针一寸，直刺或斜刺均可。针下去后病人会有酸麻胀感向膝盖方向放散。
- **禁针禁灸**：梁丘无特殊禁针禁灸，但膝盖附近血管丰富，下针时避开明显血管即可。灸可温通胃经气血，对胃寒、膝冷有效。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：梁丘为胃经郄穴，郄穴是经气深聚之处，如同江河的深潭。胃经多气多血，梁丘便是气血汇聚的“急所”。倪师讲，郄穴就是专门用来“救急”的——急性胃痛、急性膝痛，针梁丘，气血立通。胃经气血在此处汇聚后，向下濡养膝盖，向上输布胸腹，所以梁丘既能治膝，又能治胃。
- **五行生克运用**：胃经属土，梁丘为郄穴，郄穴本身不按五行子母补泻取穴，但倪师强调，郄穴治急症，不分虚实，凡胃经气血骤然瘀滞不通，梁丘即能开之。实则泻其子——胃经实证（如胃火牙痛、胃痉挛），可取梁丘泻之，因胃经气血在此深聚，泻之则热随血散；虚则补其母——胃经虚证（如胃下垂、久泻），梁丘亦可温灸补之，助胃气升提。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **急性胃痛、胃痉挛**：梁丘是胃经郄穴，治急性胃痛立竿见影，针下痛止。
  - **膝盖痛、膝关节炎、髌骨软化**：梁丘在膝盖上方，近取穴治膝，尤其是膝盖外侧痛、上下楼梯痛。
  - **乳痈、乳腺炎**：胃经循行经过乳房，梁丘郄穴能清胃热、通乳络，治急性乳腺炎红肿热痛。
  - **下肢不遂、股外侧麻木**：胃经气血不通，梁丘能疏通局部气血。

- **倪师经典对穴与排针组合**：
  - **梁丘 + 足三里**：治一切胃痛。足三里为胃经合穴，梁丘为郄穴，郄合配穴，急缓皆宜。急性胃痛先针梁丘，再针足三里，留针二十分钟，痛即缓解。
  - **梁丘 + 犊鼻（外膝眼）+ 阳陵泉**：治膝痛。梁丘在膝上，犊鼻在膝下，阳陵泉在膝侧，三穴合围膝盖，通治膝部诸痛。
  - **梁丘 + 内关 + 中脘**：治胃心胸急症。内关通阴维脉，中脘为胃之募穴，梁丘为郄穴，三穴合用，对急性胃痛伴恶心、心慌者效佳。
  - **梁丘 + 太冲**：治乳痈。太冲泻肝火，梁丘清胃热，肝胃同治，乳络自通。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》中讲到梁丘时，原汁原味的金句如下：

> “梁丘穴是胃经的郄穴。郄穴就是专门治急症的。你胃痛，痛得哇哇叫，先下梁丘，再下足三里，针一下去，痛就去掉了。郄穴是气血最深的地方，就像水潭一样，你把它一打开，气血就通了。”

> “梁丘在膝盖外上缘直上两寸。你找穴的时候，叫病人膝盖弯起来，膝盖骨外上角往上摸，摸到一块肌肉鼓起来，那就是梁丘。针下去一寸，病人会感觉酸胀往膝盖走。”

> “膝盖痛，尤其是外侧痛，梁丘一下去，痛就松了。为什么？因为胃经气血从这里过，你把它疏通，膝盖就得到气血了。所以梁丘治膝盖痛，是近取穴的道理。”

> “还有乳痈，乳房红肿热痛，这是胃热。梁丘是胃经郄穴，你针梁丘，再针太冲，胃热肝火一起清，乳房就消了。”

倪师在临床上用梁丘，最常与足三里搭配。他讲过一个医案：一位病人急性胃痛，痛得弯着腰进来，倪师先针梁丘，再针足三里，针刚下去，病人就说“不痛了”。倪师说，这就是郄穴的威力——急症找郄穴，这是针灸的秘诀。
