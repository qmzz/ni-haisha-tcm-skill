# 悬颅

## 📍 经络归属与精准取穴法

- 悬颅穴，足少阳胆经腧穴。胆经在头部循行曲折环绕，悬颅位列其中一穴。它**不是**井荥输经合、原络郄募俞、八会穴里的任何一个，就是胆经在头侧的一个**要穴**，倪师常讲“头上无正穴，跌破头也没关系”，但悬颅这种穴，用得对，效果如神。胆经五行属木，悬颅虽无特定穴名分，但脱离不了胆木之气化，以胆经气血流注为根基来运用。

- 倪师动态取穴：你让病人正坐或仰卧。先找**头维**，头维在额角入发际五分。再从**曲鬓**沿耳廓向前推，推到颧弓上缘，这是胆经在头侧的一条弧线。悬颅就位于**头维与曲鬓之间的弧形连线中点**，大约在头维穴下方、曲鬓穴斜上方的凹陷处。《针灸大成》说“在曲周颞颥中”，曲周就是曲鬓一带，颞颥就是太阳穴旁边那一块，你摸到那个“骨缝空陷”的感觉，指下有隙，就是穴。骨度折量：头维至曲鬓，折作一段弧线，悬颅居其中点。

- 下针深度：**沿皮刺，横刺透向曲鬓或头维方向，针入三分，最多到半寸**。因为下面就是颞肌与骨膜，直刺容易伤及骨膜，病人会剧痛。倪师强调头部穴位“多沿皮刺、多斜刺”，不留针太久。**禁灸**——头为诸阳之会，艾灸悬颅容易引火上行，胆火一旺，头更痛。除非是特殊虚寒证，倪师一般不灸头部。

## ⚡ 倪师经穴气化与破局心法

- 悬颅的气化，要从胆经的循行来看。胆经“上抵头角，下耳后，循颈……”，悬颅就在头角至耳后这一段。倪师讲，胆经是**半表半里**的枢机，少阳主开阖，悬颅这个位置正好在太阳、少阳经脉交错地带。它的开阖机理，是**疏泄胆木郁火，清气头面**。就像春天树木抽芽，胆木之气要升发。若胆火上炎，头角胀痛，悬颅就是引气开窗的穴，把郁火从颞颥这个“天窗”散出去。倪师心法：**“凡是偏头痛、太阳穴痛、眼珠子痛，你用手按悬颅，病人说酸胀难忍，一针下去，气就通了。”**

- 子母补泻：悬颅不属于胆经五输穴，所以不能用“虚补母、实泻子”直接套在悬颅上。但是倪师有变通心法：**“穴是死的，气是活的。”** 临床若见胆经虚证（如胆气不足、头晕目眩、目无所见），可以在悬颅处用**补法**（捻转角度小、频率慢、顺经为补），配合胆经母穴侠溪（水穴，水生木）、本穴足临泣来补。若见胆经实证（如偏头痛剧烈、目赤肿痛、耳暴鸣），用**泻法**（捻转角度大、频率快、逆经为泻），配合胆经子穴阳辅（火穴，木生火，实则泻其子）。倪师一再讲：“你不要被子母补泻套死，哪个穴能开门，哪个穴能泄热，要在大脑里想清楚。”

## 🎯 临床主治与配穴组合手印

- 核心特效主治病症：
  1. **偏头痛、太阳穴痛、颞部跳痛**——少阳经头痛的核心穴
  2. **目赤肿痛、目眩、视物不清**——胆经连目系，悬颅能清头目
  3. **耳鸣、耳暴聋**——胆经入耳中
  4. **齿痛、面肿**——胆经循颊车一带，少阳郁火引发齿痛，悬颅透刺可解
  5. **小儿惊风**——小儿高热抽搐，悬颅配人中、合谷，清泻少阳之火以息风

- 倪师经典对穴与排针组合：
  - **悬颅 + 头维 + 率谷**：治偏头痛三针，沿皮透刺，像三支箭射向痛区
  - **悬颅 + 合谷 + 太冲**：开四关兼疏少阳，治头痛兼情绪郁怒引发者
  - **悬颅 + 太阳 + 风池**：太阳放血，悬颅透刺，风池平刺，专治目赤偏头痛
  - **悬颅 + 听宫 + 翳风**：治耳鸣耳聋，尤其胆火上扰型
  - **悬颅 + 外关 + 足临泣**：手足少阳同名经配穴，通调少阳枢机，治一切少阳头痛、胁痛

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲胆经头面部穴位时，原话是这么说的（意会还原）：

**“悬颅这个穴，你看名字，悬是悬挂，颅是头骨。它就在你头骨侧边那个悬缝里。你摸到曲鬓往上一点，颧骨弓上面那个凹陷，就是它。偏头痛的病人在这里按下去，哇哇叫，你就知道是它了。针怎么下？你不要直刺，直刺病人像被电到一样弹起来，沿皮往下刺，刺到曲鬓，或者往上刺到头维，一针透两穴，头痛当场松一半。太阳穴青筋冒出来的那种偏头痛，你在悬颅下针完，再把太阳穴放几滴血，几乎一次就好。但是记住，这个穴禁灸！头上你灸下去，胆火窜上来，眼睛红肿、流鼻血，不要说我没讲过。悬颅是通少阳之气的窗户，窗户是拿来开阖透气的，不是拿来烤火的。”**

他还讲过实战体会：**“针悬颅，得气的时候，病人会觉得有一股酸胀感从颞部往后脑或者往前额走，那是胆经的气在循行。你捻针要轻，像春风拂柳，不要暴力猛捣，头部的穴不是足三里，不是让你大补大泻的，它是让你调气开窗的。窗子打开了，风就出去了，痛就没了。”**

至于医案，倪师提过一个很经典的情形：一位偏头痛十几年的太太，西药吃到胃都快坏了，来诊时太阳穴痛到眼睛张不开。倪师取悬颅透曲鬓，留针二十分钟，期间在太阳穴点刺放血，颜色由紫黑转鲜红，病人当场说“头轻了，像拿掉一块石头”。倪师说：**“这就是少阳郁火从颞颥窗口透出去了。悬颅不是止痛药，它是给你开一扇窗。”**
