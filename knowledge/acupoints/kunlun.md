# 昆仑穴 (BL60)

**归经：** 足太阳膀胱经  
**定位：** 足部外踝后方，当外踝尖与跟腱之间的凹陷处  
**特定穴：** 经穴

## 📍 穴位定位

### 标准定位
**《针灸大成》：** "在足外踝后，跟骨上陷中。"

### 取穴方法
外踝尖与跟腱之间的凹陷处。

---

## 🩺 功能主治

### 功效
- **舒筋活络** - 筋脉拘挛
- **清头明目** - 头痛目眩
- **理气止痛** - 难产腹痛

### 主治病证

**倪海厦：**
> "昆仑为膀胱经经穴，主舒筋活络，清头明目。
> 凡头痛、项强、难产，皆可取昆仑。"

| 系统 | 病证 |
|------|------|
| **头项病** | 头痛、项强、目眩、鼻衄 |
| **腰腿病** | 腰骶疼痛、足踝肿痛、下肢痿痹 |
| **妇科病** | 难产、胎衣不下 |
| **其他** | 癫痫 |
