# 颧髎

## 📍 经络归属与精准取穴法

颧髎穴，属于**手太阳小肠经**。它不是一个五输穴，也不是原穴、络穴、郄穴、募穴、背俞穴或八会穴。它在《针灸大成》里的定位是：**“面頄骨下廉，锐骨端陷中”**——也就是颧骨最高点往下摸，摸到颧骨下缘那个凹陷的地方，就是颧髎。手太阳小肠经的循行经过面颊，颧髎正坐在颧骨下缘的骨缝里，是小肠经经气在面部汇聚、转输的一个要冲。

倪师在讲面部穴位的时候，反复强调一件事：**脸上的穴道，你摸骨要找缝，不要拿尺子量。** 颧髎这个穴，你让病人闭着嘴，从颧骨最高点顺着骨面往下推，推到骨头边缘突然感觉指下空了一点——那就是颧髎。骨缝里的穴，扎对了针是“咬”在骨头边上的，扎错了就滑开了，病人痛得要命还没效果。

下针深度，倪师在《人纪》里讲面部穴位一般**针三分到五分**，颧髎也不例外。直刺或者斜刺都可以，针尖可以略微朝内下方，因为它的经气是往面颊深部走、往牙龈和上颌关节方向布散的。**禁灸**——这是面部阳经穴位，灸了容易上火，脸上也不适合留疤。面部穴位倪师基本都主张**不灸**，因为“面为诸阳之会”，灸法偏温补升散，面部本就阳气充盛，一灸就容易面热、目赤、口干，反而引邪上行。

## ⚡ 倪师经穴气化与破局心法

颧髎的气化机理，要从小肠经的“液”和面部的“气血通道”两个角度来推。小肠经是**“液所生病”**的经络——注意，小肠主液，这个“液”不是膀胱的“水”，而是**津液**，是润滑关节、濡养孔窍、贯通筋膜间隙的清液。颧髎位于面颊骨缝，正是津液容易停滞或者津液不足容易显出问题的地方。倪师在推演小肠经面部穴位时讲过一句话：**“小肠经走到面颊，管的是液的通透。液不通，面就僵；液不养，面就枯。”** 颧髎所主，正是面部津液的通透与布散。

从开阖角度看，颧髎是一个**“开面窍、通颊络”**的穴。面颊这个区域，上接阳明胃经（地仓、颊车），下连少阳胆经（听会、上关），颧髎正好卡在这几条经的交汇缝隙里。倪师的心法是：**面部有问题，不要只盯着一条经，要看“骨缝里走的是哪几条经的混合气”。** 颧髎能开面颊之窍，能通牙龈之络，所以面痛、面肿、牙关不利这些病，针颧髎就是在“把骨缝里堵住的液气给顶开”。

至于子母补泻与五行生克，这里要特别说明：颧髎**不是五输穴**，所以不存在“虚则补其母，实则泻其子”的直接五行配穴关系。但是倪师在临床心法里有一个变通——**面部穴位可以通过表里经和同名经来借五行**。小肠经与心经相表里，心属火，小肠属火，这是火经上的穴；小肠经本身在五行中属火，颧髎虽不是井荥输经合，但它所在的这条经是火经。倪师在讲面部热证时会说：**“面颊红肿热痛，这是火气浮在脸上，颧髎能把它拉下来。”** 怎么拉？靠的是小肠经“从手走头”的经气回流之势，配合针法上的**“泻法”**——针尖朝上、快速出针、不闭针孔，让浮火随经气散开。

如果病人是面颊肌肉萎缩、麻木不仁，这是气虚不能上濡，那就不能泻了，要**补**。补法怎么做？针尖朝下、慢慢出针、按闭针孔，引导气血往面颊深部灌注。这就是倪师讲的**“同一穴，方向不同、手法不同，补泻就分出来了”**，不是每一个穴都要套子母补泻，要看你在这个穴上怎么调气。

## 🎯 临床主治与配穴组合手印

颧髎的核心主治，倪师在《人纪》里讲得很清楚：**面痛、面肿、牙痛、口眼歪斜、眼睑瞤动、面肌痉挛。**

**第一，面部疼痛与三叉神经痛。** 这是颧髎的看家本事。三叉神经第二支（上颌支）痛，痛在颧骨、上唇、鼻翼这一带，倪师取穴就是**颧髎配下关、地仓、合谷**。颧髎通骨缝，下关开牙关，地仓走唇颊，合谷引气下行——这一组针下去，面部的气就通了。倪师特别强调：**“三叉神经痛，你不要光扎脸上，要扎合谷。合谷是面口的大开关，脸上一针，手上针一针，上下呼应，痛才止得住。”**

**第二，牙关不利、颞下颌关节紊乱。** 病人张嘴咔咔响，或者张不开嘴，颧髎配上**颊车、下关、听宫**。颧髎在下颌骨关节的前方，针进去能松解关节周围的筋膜张力。倪师说：**“牙关不开，先取颧髎透一点，再取颊车，两个骨缝一起开。”**

**第三，面瘫（口眼歪斜）。** 急性期和恢复期用法不同。急性期（七天以内），倪师主张**面部少针、远端多针**——取合谷、太冲开四关，取足三里补中气，面部颧髎浅刺、轻刺，不重刺激。恢复期（七天以后），颧髎配**阳白、四白、地仓透颊车、翳风**，再加**足三里、三阴交**补气血。倪师的口诀是：**“面瘫不是脸的问题，是气上不来。光扎脸没用，要扎脚上的足三里、三阴交，把气拉上来，脸才会正。”**

**第四，面肌痉挛、眼睑瞤动。** 这属于“风动”之象。倪师取颧髎配**太阳、攒竹、四白、风池、太冲**。颧髎在这里的作用是“镇住骨缝里的风”，不让它乱窜。倪师讲：**“眼皮跳，你不要只扎眼睛旁边，要扎颧髎，因为风是从骨缝里钻出来的。”**

倪师经典对穴组合里，颧髎常配的有：
- **颧髎 + 合谷**：面口一切痛证、肿证、热证
- **颧髎 + 下关 + 颊车**：牙关不利、颞下颌关节病
- **颧髎 + 地仓透颊车**：面瘫恢复期
- **颧髎 + 翳风 + 风池**：面肌痉挛、风动之证
- **颧髎 + 足三里 + 三阴交**：面瘫虚证、面肌萎缩

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲面部穴位时，有一段非常经典的话，原汁原味地记在这里：

**“颧髎这个穴，在颧骨下面那个凹进去的地方。你摸，颧骨最高点往下推，推到底下有个缝，针就扎在缝里。你不要扎太深，三分就够了。这个穴道呢，主要治面部的病——面痛、面肿、牙痛、嘴歪眼斜。你看它在小肠经上面，小肠经是液所生病，所以它是通津液的。脸上如果干枯、萎缩、麻木，那是液不到；脸上如果红肿、热痛，那是液堵住了。同一个穴，你手法不一样，效果就不一样。”**

**“针颧髎，针感是什么？病人会感觉整个面颊酸胀，有时候会传到牙龈，有时候会传到耳朵前面。如果病人说‘像电一样麻到嘴唇’，那是扎到神经了，要退一点。正常的是酸胀感，不是电击感。你扎对了，病人会觉得面颊松开了，像一块布被扯平了。”**

倪师还讲过一个面瘫的医案。一个中年妇女，早上起来半边脸不会动了，眼睛闭不上，嘴角漏水。倪师取**颧髎、地仓透颊车、阳白、四白、翳风**，再加**合谷、足三里、三阴交**。针了三次，脸就正了七成。倪师在课上讲：**“面瘫你不要怕，越早针越好。但是你要分清虚实——刚得的，脉浮紧，那是风邪在表，你针浅一点，泻合谷；拖了半个月的，脉沉细，那是气血虚了，你针足三里、三阴交，补气血，脸才会回来。颧髎在中间，是通面颊骨缝的，不管你补还是泻，它都是开路先锋。”**

还有一段关于面肌痉挛的实录：**“有的人眼皮跳、嘴角抽，跳了几个月，你扎颧髎、太阳、四白，再扎太冲。太冲是肝经的，肝主风，风动了才抽。颧髎是镇风的，太冲是熄风的，两个一起用，风就平了。你不要光扎脸，光扎脸风还是会回来，因为根本在肝。”**

倪师最后强调：**“脸上的穴，针要细，手法要轻，不要捻得太重。面部是阳气最盛的地方，你一重刺激，病人第二天脸就肿了。颧髎尤其要注意——它挨着颧骨，针尖碰到骨膜会很痛，你要贴着骨缝进去，不要戳骨头。”**
