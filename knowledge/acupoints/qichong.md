# 气冲

## 📍 经络归属与精准取穴法

气冲穴，归属**足阳明胃经**。在《针灸大成》中，气冲又名“气街”，是胃经与冲脉交会之处，这一点极为关键——冲脉为血海，起于胞中，出于气街，所以气冲一穴，先天就带着“血”与“气”双重身份。

从五输穴体系来看，气冲并非井荥输经合任何一类，它属于**胃经在腹部的重要穴位**，更准确地说，它是**冲脉所起之处**。《灵枢·海论》讲：“胃者水谷之海，其输在气街。”这个“气街”就是气冲所在。所以此穴不是一般的胃经穴，它的定位在**水道下一寸，归来下二寸，去中行二寸**，也就是肚脐正中线旁开两寸，再往下五寸的位置。倪师在讲腹部穴位时反复强调：**“肚脐以下，从曲骨往上排，曲骨上一寸是中极，中极旁开两寸就是气冲。”** 这是最直白的找法。

**骨度折量法**：先找到耻骨联合上缘，也就是曲骨穴，从曲骨旁开两寸，按到腹股沟动脉搏动处，那就是气冲。倪师常说：**“气冲这个地方，你摸上去，病人会感觉到酸胀，甚至有动脉在跳，你手按下去，那个脉动就是冲脉的气血在动。”**

下针深度：**《针灸大成》明言“针三分，灸七壮”** ，但倪师在视频中特别提醒：“气冲这个地方，不深针，因为里面有动脉，你针太深，扎到动脉会出血，甚至形成血肿。”所以实操时，**直刺三分到五分，得气即止，不可猛插深刺**。灸法可以用，但不宜多灸，因为此穴靠近腹股沟，灸多了容易伤津动血。孕妇禁针，这一点没有任何商量余地——动了冲脉，胎气不安。


## ⚡ 倪师经穴气化与破局心法

倪师在推演气冲的气化机理时，把它的功能归结为四个字：**“引气下行”** 。冲脉起于气街，与胃经并行，冲脉是“十二经之海”，也是“血海”。气冲作为冲脉的起点，它就像是一个**气机的闸门**——闸门一开，上焦的浮火、中焦的积滞、下焦的瘀阻，统统可以往下走。

倪师的原话大意是：**“气冲这个穴，你把它想成一条水管的总开关。冲脉的气血从这里冲出去，如果冲得太快、太猛，人就气逆、打嗝、吐血；如果冲不出去，气就堵在腹股沟，小腹胀、睾丸痛、月经不来。所以气冲的作用就是调节这个冲势。”**

从五行生克看，胃经属土，冲脉属血海，气冲所治的核心是**“土不制水，水气上冲”** 之证。倪师常用气冲配合**足三里、三阴交**来引火归元、引血下行。比如妇女倒经、经期流鼻血，倪师会说：“这是冲脉的气往上冲了，你扎气冲，再扎三阴交，气就下来了。”子母补泻在这里不是靠本穴的五行属性，而是靠**配穴的五行生克**——胃土虚则补足三里（土经土穴），冲脉实则泻气冲（引气血下行）。所以气冲在倪师手中，是一个**“实则泻之”的泄冲要穴**。


## 🎯 临床主治与配穴组合手印

气冲穴的核心主治，按《针灸大成》和倪师讲义归纳，主要集中在以下几类：

**第一，妇科冲脉诸疾。** 月经不调、痛经、崩漏、倒经、不孕、产后恶露不尽。冲脉为血海，气冲是血海的开关，凡血海之气上逆或瘀滞，此穴必用。

**第二，少腹与生殖器痛症。** 小腹胀痛、疝气、睾丸肿痛、阴茎痛、阴挺（子宫脱垂）、阴部肿痛。倪师讲：“气冲能治疝气，因为冲脉绕阴器，气冲一开，疝气就散。”

**第三，腹痛与肠胃急症。** 腹中有气攻冲、肠鸣、奔豚气（气从少腹上冲心）、便秘、痢疾。倪师特别指出：“奔豚气，气从少腹上冲咽喉，好像有只小猪在肚子里跑，这时候气冲配公孙，一针下去，气就平了。”

**第四，下肢与腹股沟病症。** 腹股沟淋巴结肿、大腿内侧痛、下肢痿痹。

**倪师经典配穴手印：**

- **气冲 + 公孙 + 内关**：治奔豚气、胃心胸气逆。公孙通冲脉，内关通阴维，气冲引冲气下行，三穴一组合，上冲之气立平。
- **气冲 + 三阴交 + 血海**：治月经不调、痛经、倒经。三阴交调三阴，血海引血归经，气冲开闸放血下行。
- **气冲 + 关元 + 中极**：治不孕、子宫脱垂、疝气。关元培元，中极利膀胱，气冲引冲脉之气归位。
- **气冲 + 足三里 + 天枢**：治腹胀、肠鸣、便秘。足三里降胃气，天枢通大肠，气冲引浊气下行。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲腹部穴位时，讲到气冲这一段，原汁原味的金句是这样的：

**“气冲，你看这个名字，气从这里冲出来。冲脉从这里开始，所以它管的是冲脉的病。冲脉是什么？血海。女人月经的问题，倒经、经期流鼻血、经期头痛，都是冲脉的气往上冲。你在气冲上下一针，气就往下走了，鼻血就止了。”**

**“气冲下针，你要小心，这个地方有动脉。你摸到动脉跳的地方，针尖稍微偏一点点，不要直接扎在动脉上。针下去三分，病人感觉酸胀，那就是气到了。你不要猛扎，扎到血管，腹股沟肿一个大包，病人吓得半死。”**

倪师还讲过一个实战体会：**“有个太太，每次月经来就头痛欲裂，鼻子还出血。我一看，冲脉上逆。我扎气冲、三阴交、血海，针一下去，她说头不痛了，鼻子也不出血了。为什么？气冲把冲脉的气一泄，血就往下走，不往上冲了。”**

**“还有疝气，睾丸肿得像鸡蛋大，痛得不能走路。我扎气冲、关元、三阴交，针完痛就减了。气冲这个穴，你记住，它是冲脉的起点，冲脉一旦冲得太猛，你就从起点泄它。”**

倪师最后总结一句：**“气冲，顾名思义，气从这里冲。你把这个冲字搞懂了，妇科、疝气、奔豚、倒经，统统能治。”**
