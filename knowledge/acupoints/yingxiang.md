# 迎香穴 (LI20)

## 📍 经络归属与精准取穴法

- **所属经络**：手阳明大肠经。迎香为手足阳明之会——大肠经与胃经两条阳明经气在此交汇。倪师讲经络时反复强调，阳明经多气多血，迎香又处在面部终端，所以它不是一个孤立的鼻孔旁穴位，而是阳明经气从面颊向内灌注鼻窍的“最后一道闸口”。
- **五输穴/特定穴属性**：迎香不属于井荥输经合五输穴体系，它是手阳明大肠经的末端腧穴，接续足阳明胃经的起点（承泣）。倪师在讲大肠经循行时点明：大肠经从商阳一路沿臂上行，过肩入缺盆，上颈贯颊，入下齿，还出口唇交叉于人中——左之右、右之左——最终止于迎香。所以迎香的气血来自对侧经气的交叉贯注，这就是为什么它能“通”鼻窍：经气在此完成左右交贯后注入鼻翼两侧，鼻塞就是这条通路堵住了。
- **倪师动态取穴与骨度折量法**：鼻孔外缘向外摸，摸到鼻翼旁有个凹陷，再往上推到鼻唇沟（法令纹）上端——那个沟里的凹陷就是迎香。倪师原话大意是：“你从鼻孔旁边往外摸，摸到那个沟，沟的根底、鼻翼旁五分的地方，就是迎香。”不用死记“鼻翼外缘中点旁开五分”这种书面语，手一搭、一推，凹陷自然落在指尖下。
- **下针深度与角度**：倪师讲面部穴位下针一律“针不要深，浅浅的”。迎香一般直刺或斜刺，针尖朝向鼻根方向（向上向内斜刺），进针三到五分即可。他特别强调面部穴道“针到气到就够了，不要硬扎深”，因为面部的血管神经密布，扎深了容易出血、容易肿。迎香透内迎香或透四白是治疗鼻塞重症的手法，但那是特殊刺法，初学者不要随便玩。
- **禁针禁灸法则**：迎香禁灸。倪师原文意思是，面部穴位“一律不灸”，因为灸会留疤，脸上留疤不好看。迎香本身可以针，但要注意出血——出针后按压片刻，避免瘀血肿胀。


## ⚡ 倪师经穴气化与破局心法

- **经气流注与开阖机理**：倪师推演迎香的气化机理，核心就一个字——“通”。阳明经多气多血，气血循行到迎香这里，要从面颊内侧灌入鼻窍。鼻为肺之窍，但肺经本身不走鼻子旁边——肺经止于拇指少商，它的表里经大肠经却把气血送到了鼻翼两侧。这就是倪师常讲的“表里经气化互补”：肺主气、主鼻窍的功能，靠大肠经的经气在面部“接口”来兑现。迎香堵了，阳明经气灌不进鼻窍，鼻塞、不闻香臭就来了。所以迎香的本事，是打通阳明经气入鼻窍的“关隘”，让清气能上通、浊涕能下行。
- **倪师对“迎香”二字的解读**：迎者，迎接；香者，气味。倪师说这个穴名本身就告诉你它的功能——鼻子通了，才能“迎香”，才能闻到气味。名字就是心法，不用绕弯子。
- **子母补泻与五行生克**：迎香不在五输穴之列，所以严格来说不直接套用“虚则补其母，实则泻其子”的井荥输经合补泻体系。但倪师在讲大肠经整体五行属性时指出：大肠经属金，阳明燥金之气。迎香位居末端，是金气入鼻窍的出口。如果肺气不宣导致鼻塞（金气壅滞），取迎香就是“开金气之塞”；如果脾虚湿盛导致鼻流清涕不止（土不生金），迎香只是治标，根本还要去补脾（取足三里、三阴交之类）。倪师原话的意思：迎香是开窍的“钥匙”，但身体虚不虚、该补该泻，要看根本——钥匙开门，但屋里的粮仓空不空，得另外去管。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
    - **鼻塞、鼻不通气**：这是迎香第一主治，不论外感风寒鼻塞还是过敏性鼻炎鼻塞，迎香一针下去，留针时患者往往就感觉鼻子通了。
    - **不闻香臭（嗅觉减退或丧失）**：倪师讲这个症状时直接取迎香，配合合谷。阳明经气通了，嗅觉自然回来。
    - **鼻窦炎、鼻流浊涕**：迎香配上星、合谷，引阳明经气上行通窍，浊涕自下。
    - **面痒、面部浮肿**：迎香能疏通面部阳明经气，面部的“气滞”用它来开。
    - **口眼歪斜（面瘫）**：迎香是面部局部取穴，配合地仓透颊车、阳白透鱼腰等，是倪师治疗面瘫排针中的一针。
- **倪师经典对穴与排针组合**：
    - **迎香 + 合谷**：这是治鼻病的“金牌组合”。合谷是大肠经原穴，管整条大肠经的气；迎香是末端开窍穴，管鼻子局部的通。一远一近，一原一末，上下呼应。倪师说“面口合谷收”，鼻子在面部，合谷本身就管，再加迎香直接开窍——鼻塞再顽固也得通。
    - **迎香 + 上星 + 印堂**：治鼻窦炎、前额痛的排针。上星在督脉头上，印堂在眉心，迎香在鼻旁——三针把鼻窍的前后上下都罩住了。
    - **迎香 + 足三里 + 三阴交**：治过敏性鼻炎反复发作、体虚鼻流清涕。迎香开窍治标，足三里补胃气、三阴交补三阴之血，这是倪师“标本兼治”的思路——鼻子的问题根子在脾胃虚寒、气血不足。
    - **迎香透四白 / 迎香透内迎香**：重症鼻塞、鼻息肉、嗅觉完全丧失时的透刺法。针从迎香进，沿皮下向上向内透到四白或内迎香，一针贯两穴，通窍力更猛。倪师说这种透刺法要得气、要轻巧，不能硬捅。


## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味金句（据讲义实录精神还原）**：
    “迎香这个穴道呢，在大肠经的最后一个穴道。你从鼻孔旁往外摸，摸到那个沟——法令纹的根底、鼻翼旁边那个凹洞，就是迎香。”

    “迎香治鼻病，效果很好。针下去，鼻子就通了。你不需要灸，脸上不灸的，灸了留疤。”

    “合谷配迎香，一个在手上、一个在鼻旁，上下呼应。合谷是原穴，管整条经的气；迎香是末端的穴道，管鼻子局部的通。两个一起用，鼻塞再重也能给你打开。”

    “迎香透四白，透针法。针从迎香进去，沿着皮下面，针尖到四白。一针透两穴，通鼻窍的力道更足。但这是特殊的刺法，手法要轻、要快，不要硬扎。”

- **实战手下针感体会**：倪师讲面部穴位下针，针尖碰到骨头或碰到鼻翼软骨时，会有一种“抵住”的感觉，这时候不要再硬推，稍微退一点、调整角度，让针尖滑入凹陷处。患者常常会感觉鼻子一酸、一胀，或者像有气往鼻腔里钻——这就是得气。得气之后鼻子就通了，不用留针太久，五到十分钟即可。

- **医案故事（据讲义实录精神还原）**：倪师讲过，有个病人鼻塞十几年，西药喷剂用了无数，嗅觉几乎全没了。倪师取迎香透四白，加上合谷、上星，针下去留了十分钟。病人当场就说：“哎，我闻到味道了。”倪师说这就是阳明经气贯通的瞬间——经气堵了十几年，一针打开，就像水管堵了通了的那一下，水哗地就过来了。但他也强调，这种陈年鼻病，一次针通只是暂时的，要巩固还得调理脾胃、补气血，否则阳明经气后继无力，过几天又堵回去了。

- **倪师针灸秘要提醒**：迎香下针出针后，一定要让患者自己按一会儿，防止出血。面部的穴道血管多，出针见血是常事，但迎香位置靠近鼻翼，出血容易肿，肿了反而更堵鼻子。所以倪师常说：面部穴道，手法要“轻、浅、快”，出针要“按、揉、压”——这六个字就是面部针灸的总诀。
