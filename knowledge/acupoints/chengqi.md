# 承泣

## 📍 经络归属与精准取穴法

- 承泣穴归属**足阳明胃经**，为**阳跷脉、任脉、足阳明胃经**三脉之会。足阳明胃经多气多血，承泣位于目下，是胃经经脉之气上注于面的第一个穴位（胃经起于承泣，止于厉兑）。在五输穴体系中，承泣不在井荥输经合之列，但它作为胃经起穴，承接胃腑水谷之气上输头面，为胃经气血外溢于眼部的第一道关口。

- **倪师动态取穴法**：倪师讲，承泣穴找起来很简单——**眼睛正前方看，瞳孔直下，眼球和下眼眶骨之间那个凹陷就是**。你叫病人眼睛平视前方，瞳孔正中对下来，沿着眼眶骨下缘摸，摸到一个明显的凹洞，按下去病人会觉得酸胀，那就是承泣。不要用力按，眼球就在旁边，轻触即得。

- **下针法则**：倪师特别强调，承泣这个穴**只针不灸，禁灸**。下针时叫病人眼睛闭好，用左手食指轻轻把眼球往上推、往外推，让眼球离开下针路线，然后沿眼眶骨下缘**直刺或微微斜刺三到五分**，不要深刺，不要大幅度提插捻转。出针时**慢慢出，出到皮下停一下再拔出**，防止出血。眼周血管丰富，扎完要用干棉球按压片刻。这个穴不能灸，一灸眼睛就出问题，热邪上攻眼底，后果严重。


## ⚡ 倪师经穴气化与破局心法

- **气血流注机理**：倪师讲，胃经的气血是从承泣开始的。胃是水谷之海，消化了食物以后，气血往上走，第一个出来的口子就在眼睛下面。所以承泣这个穴，等于是胃气上注于目的**闸门口**。眼睛能看清楚东西，靠的是肝血和胃气的濡养，胃气上来到眼睛第一步就是走承泣。承泣如果堵住了，胃气上不来，眼睛就干涩、流泪、看东西模糊。

- **引火归元与开窍醒神**：倪师推演，承泣的气化机理在于**引胃气上行、开目窍之闭**。眼睛是神明外露的窗户，承泣紧贴眼球下方，针之可以引胃中清气上冲于目，把郁闭在眼部的风热痰浊冲开。临床上眼目红肿、热痛、流泪不止，取承泣能开窍泄热；眼睑下垂、视物昏花，取承泣能升提胃气、鼓舞目系。

- **五行生克心法**：胃属土，目属肝木所主。承泣一穴，土气上承于木窍，本身就有**培土荣木**之意。倪师讲，眼睛的病不能只盯着肝治，脾胃是后天之本，胃气一衰，眼睛就跟着坏。承泣在五行上体现的是“**土能载木、土润木荣**”的机理。虚证当补胃气以荣目，实证当泻胃热以清目。子母补泻上，胃经属土，若目病因胃虚而起，取胃经母穴解溪（火生土）补之；若因胃火上炎，取胃经子穴厉兑（土生金）泻之，承泣作为局部近取，与远端子母穴配合，一近一远、一上一下，形成合力。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **目赤肿痛、暴发火眼**：承泣配太阳、攒竹、合谷，泻胃经郁热，针到痛减。
  - **迎风流泪、泪囊炎**：承泣配睛明、风池、肝俞，取“胃气上承、肝血养目”之意，虚补实泻。
  - **眼睑瞤动、面肌痉挛**：承泣配四白、地仓、颊车，局部近取疏通阳明经气。
  - **近视、视物昏花、夜盲**：承泣配光明（胆经络穴，明目要穴）、足三里、肝俞，培土荣木、补肝养血。
  - **眼睑下垂（上胞下垂）**：承泣配攒竹、丝竹空、足三里，升提中气、鼓舞胃气上承。
  - **口眼歪斜**：承泣配地仓、颊车、合谷、太冲，这是倪师常用的面部中风组合。

- **倪师经典对穴与排针组合**：
  - **承泣 + 四白 + 地仓 + 颊车**：面部阳明经一排针，治面部中风、口眼歪斜、面肌痉挛。倪师讲，面部中风的病人，针完这一排，再配合合谷、太冲开四关，效果立竿见影。
  - **承泣 + 睛明 + 太阳 + 风池 + 合谷**：治一切目赤肿痛、急性结膜炎。承泣引胃气下行泄热，睛明通足太阳经气，太阳点刺放血，风池疏风，合谷面口合谷收，一整套下来热退肿消。
  - **承泣 + 光明 + 肝俞 + 足三里**：治慢性眼病、近视、视物模糊。光明是胆经络穴，别走肝经，专治目疾；肝俞补肝血；足三里补胃气；承泣局部开窍。倪师讲，眼睛的病，**近取承泣开窍，远取光明、肝俞、足三里培本**，远近结合，标本兼治。


## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲足阳明胃经的时候，第一针就讲承泣。他说：“**承泣穴，在眼睛下方。你叫病人眼睛闭着，眼球往上推，下针在眼眶骨和眼球之间，直进直出，不要捻针，不要灸。** 这个穴是胃经的第一个穴，胃气从这里上到眼睛。眼睛红肿、流泪、看不清楚，都可以在这里下针。”

- 倪师原话：“**承泣针下去，眼泪就止住了。为什么？胃气上来了，把下面堵住的水湿冲开了。** 但是记住啊，这个穴**禁灸**，一灸眼睛就完蛋，热上加火，眼底出血你不知道怎么收场。”

- 倪师实战体会：“针承泣的时候，针尖碰到眼眶骨边缘，病人会有**酸胀感一直传到眼球里面**，有的人当场就觉得眼睛亮了。出针的时候要慢，出到皮肤底下停个几秒钟再拔出来，不然容易皮下出血，眼圈乌青好几天。”

- 倪师医案故事：曾有一位中年妇女，眼睛红肿、流泪、怕光，西医说是急性结膜炎，点了眼药水退不下去。倪师取**承泣、太阳、合谷、风池**，承泣轻刺不留针，太阳点刺放血，合谷、风池泻法。针完当场病人说眼睛松了，第二天红肿消了大半，第三天再来一次就好了。倪师讲：“你看到眼睛红肿，不要只想着肝火，**足阳明胃经的热也会上眼**，承泣就是泄胃热的第一个出口。”

- 倪师特别叮嘱：承泣这个穴**初学者不要轻易下针**，眼周太危险，手法不熟容易伤到眼球。但是它的理论和位置必须搞清楚，因为这是胃经的起点，也是胃气上注于目的第一道关口。眼睛的病，**近取承泣，远取光明、肝俞、足三里，虚实辨清楚，补泻分明白**，效果又快又好。
