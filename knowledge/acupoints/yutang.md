# 玉堂

## 📍 经络归属与精准取穴法

- **所属经络**：任脉。《针灸大成》明言“玉堂：紫宫下一寸六分”，归任脉，非五输穴、非原络郄募、非八会穴，乃任脉脉气所过之普通腧穴，但在倪师体系中，凡任脉胸段穴道皆与“气会膻中”一带合看，玉堂正当膻中之上、紫宫之下，是胸气上达喉咙的关隘。
- **穴义与定位**：玉者，金玉之精；堂者，正室中枢。此穴在胸骨正中线上，平第三肋间。倪师讲骨度折量，取穴要从天突往下量：天突至膻中为“八寸”，膻中至鸠尾亦为“八寸”。玉堂在膻中上二寸还是三寸多，别死记寸数——用指头顺着胸骨柄正中线往下摸，摸到胸骨角和第三肋软骨结合处的凹陷，正中线上那个点，就是玉堂。换句话说，从膻中往上推，推过紫宫，再上一寸六分，骨面正中的凹处便是。
- **倪师动态取穴法**：让病人仰卧，两臂自然放下，胸骨正中线暴露。倪师强调“摸骨找穴”——先定膻中（两乳中间），再定紫宫（膻中上一寸六分），再上推一寸六分，胸骨正中线上的凹陷就是玉堂。不要拿尺子硬卡，胸骨有弧度，肥胖之人寸要放宽，瘦人寸要收紧。
- **下针深度与禁针禁灸**：玉堂**禁针**，古书明言“禁针”，因为胸骨正中的骨膜极薄，下面直通纵隔，针下去容易刺到骨膜，病人剧痛，且胸骨后就是心脏与大血管，深刺有气胸、心包填塞之险。倪师在《人纪》里反复交代：“胸骨上的穴，像玉堂、紫宫、膻中，你用手按按、指压可以，下针不要深，一寸针下去半分到一分，得气就起，绝不能留针久。”**可灸**，但不多灸，艾炷如小麦粒，三五壮即可，灸多了胸口燥热、心烦。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：玉堂在任脉胸段，任脉为“阴脉之海”，胸中又是“气海”所在。倪师推演：玉堂的气化功能，一言以蔽之——**“开胸气、利咽喉、降逆上之痰火”**。任脉之气从会阴上行，过丹田、过中脘、过膻中，到玉堂这里已经是接近喉咙的“气口”。所以玉堂是胸中宗气上输喉咙的关卡。胸中气机郁滞、痰浊上泛、肺气不降，都会在玉堂这一带表现为闷、痛、咳、喘、喉中如有物阻。
- **引火归元与降逆**：倪师讲，玉堂不是补穴也不是泻穴，它是**“开关穴”**。你胸口燥热、咳逆上气、喉咙像有东西堵着，这是胸中浮火上冲。在玉堂上轻轻一按一灸，或者指压，等于把胸骨正中这条“气路”打开，浮火自然下降，归入丹田。这不是直接引火归元，而是“开胸降逆，气降火自归”。
- **子母补泻与五行生克**：玉堂不在五输穴之列，没有井荥输经合的子母关系。但倪师心法：任脉属阴，胸段穴位以“开、降、通”为用。若伴有心火旺、肺金燥，可配少府、太渊；若伴肝气上逆，可配太冲。玉堂本身不主补泻，它是配穴中的“开气门”角色。虚证时灸玉堂以温胸阳，实证时指压玉堂以开胸闭——这是倪师常用的“以指代针”法门。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **胸痛、胸闷、胸骨后闷痛**：玉堂正当胸骨正中，凡胸骨后疼痛、闷胀、压迫感，指压玉堂配合膻中，可迅速开胸顺气。
  - **咳逆上气、气喘、喉中痰鸣**：倪师讲，玉堂配上中府、云门，治咳喘痰多，胸中气塞。
  - **咽喉不利、梅核气**：喉咙如有物梗，吞不下吐不出，玉堂配天突、廉泉，开胸利咽。
  - **心烦、胸中烦热**：玉堂配内关、神门，清胸中烦热。
  - **乳腺相关**：玉堂在胸骨正中，与膻中同用，对乳汁不通、乳房胀痛有辅助开气作用。
- **倪师经典对穴与排针组合**：
  - **玉堂 + 膻中 + 内关 + 公孙**：治一切胃心胸疾患。内关公孙通冲脉，膻中玉堂开胸气，四穴合用，胸中气机立通。
  - **玉堂 + 天突 + 列缺**：治咽喉不利、咳喘。列缺通任脉，天突利喉，玉堂开胸。
  - **玉堂 + 中脘 + 足三里**：治痰饮停胸、胃气上逆。中脘足三里降胃气，玉堂开胸膈。
  - **玉堂 + 太冲 + 合谷**：开四关兼开胸，治气郁胸痛、梅核气。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲任脉胸段时，原话大意如下：

“膻中穴你们知道了，气会膻中。膻中上面一寸六是玉堂，再上面一寸六是紫宫，再上面是天突。玉堂这个穴，你摸胸骨正中，摸到第三肋间那个凹凹的地方，一按，病人如果胸口闷，他马上觉得松了。这个穴**禁针**，你千万不要拿针往胸骨上扎，扎到骨膜病人会跳起来，而且胸骨后面是什么？是心脏、是大血管，你扎深了会出事。灸可以，灸个三五壮，胸口的热气就散开了。临床上我常常用指压，病人胸闷、喘不过气，我手指头按在玉堂上，让他吸气，吸到底，再慢慢吐，按个一分钟，胸口的闷就开了。这就是‘以指代针’，比下针还安全。”

倪师还讲过一则实战体会：有病人胸痛、咳喘、喉中痰声漉漉，他先针公孙、内关，再指压玉堂、膻中，病人当场咳出一口痰，胸痛大减。“玉堂不是治病的穴，是开门的穴。门开了，后面的药、后面的针，才进得去。”这句话是倪师对玉堂最精到的定位。
