# 三焦俞穴 (BL22)

## 📍 经络归属与精准取穴法

三焦俞穴，归足太阳膀胱经。背俞穴之一，为三焦腑气转输、输注于背部之处。倪师在人纪针灸篇讲，背俞穴皆在膀胱经第一侧线上，督脉旁开一寸半，各脏腑精气由此灌注入背。三焦者，决渎之官，水道出焉，总司人体上中下三焦气化。三焦俞即是三焦之气在背部出入的门户。

倪师讲背部穴位时反复强调：先找督脉，再找一寸半。骨度折量法，从脊中线到肩胛骨内缘为三寸，一半即一寸半。三焦俞定位在第十三椎下——即第一腰椎（L1）棘突下——旁开一寸半。

怎么摸骨找穴？倪师讲得极为直白：你从大椎往下数，第七椎是至阳，第九椎是肝俞，第十椎是胆俞，第十一椎是脾俞，第十二椎是胃俞，第十三椎就是三焦俞。用手指沿着脊椎骨一节一节推，推到第十二椎下旁开一寸半，再往下推一节，就是第十三椎。第十三椎下旁开一寸半，就是三焦俞。

倪师特别提醒：不要把第十二椎和第十三椎搞混，胃俞和三焦俞就差一节。摸的时候让病人趴着，两肩自然放松，肩胛骨下缘平第七椎，再往下数就清楚了。或者从骨盆上缘往上找，髂嵴最高点平第四腰椎，往上数一节就是第三腰椎，再往上两节就是第一腰椎。倪师说宁可从下往上找，因为腰椎位置比胸椎稳定，不会因为胖瘦而偏移太大。

下针深度：倪师讲背部穴位不可深针，一般三到五分，最多不超过一寸。因为背部内藏脏腑，深刺有伤及内脏之虞。尤其三焦俞下方就是肾脏，倪师特别警告：背部第十一椎到第十四椎这一段，下针务必浅刺，斜刺或平刺，不可直刺深入。针尖朝向脊柱方向斜刺，得气即止。

禁灸法则：三焦俞可灸，但倪师讲，凡背部俞穴，灸可以，但不宜多灸、重灸。三焦俞灸多了，三焦火旺，反而口干舌燥、水道失调。一般灸五到七壮即可，虚寒水停者适宜，阴虚火旺者慎灸。倪师的原则是：灸后背俞穴，取温通阳气之意，见好就收，不可贪多。

## ⚡ 倪师经穴气化与破局心法

倪师讲三焦俞的气化，先从三焦这个腑说起。三焦不是一块具体的肉，它是脏腑之间的油膜、空隙、通道。上焦如雾，中焦如沤，下焦如渎。三焦俞就是三焦水道在背部的一个总开关。

倪师推演此穴的气血流注：膀胱经是人体最大的排毒通道，三焦俞是水道调节的枢纽。水液代谢出了问题——不管是水肿、小便不利、还是水湿泛滥——三焦俞就是打开水道的那把钥匙。倪师常说：三焦俞引水归经，让该排的水从小便走，该润的地方得到津液滋润。它不是直接补肾，而是把三焦的水道打通，让肾水能够上济，心火能够下降，这叫引火归元、水火既济。

更深的机理，倪师讲：三焦俞主气化。中焦脾胃运化出来的水谷精微，要通过三焦输送到全身。三焦俞就是中焦输送到下焦、上焦的中转站。所以这个穴能健脾行水——水湿困脾，三焦不通，人在中间胀满；三焦俞一通，水下得去，脾就轻松了。

子母补泻与五行生克：三焦俞本身不是五输穴，但它是三焦的背俞穴，膀胱经属水，三焦属相火。倪师讲，三焦俞的运用要看虚实。三焦实证——水肿、胀满、小便不通——用泻法，提插捻转，针尖略向外，引邪外出；三焦虚证——气化无力、水道迟缓、倦怠乏力——用补法，缓缓进针，得气后轻微捻转，留针候气。倪师说：实则泻其子，三焦的子是水，水道不通就是实证，要泻；虚则补其母，三焦的母是木，木生火，三焦火弱就是虚证，要补。但倪师更强调：三焦俞这个穴，补泻不在手法多复杂，在于针尖方向和得气后的气感传导。你针下去，病人感觉气往腰部走、往腹部走，那就对了。

## 🎯 临床主治与配穴组合手印

三焦俞的核心特效主治，倪师归纳为三大类：

第一，水肿、小便不利、水道不通。这是三焦俞的看家本领。倪师讲，不管是肾小球肾炎引起的水肿，还是心脏性水肿，还是不明原因的下肢浮肿，三焦俞配合水分、阴陵泉、三阴交，通利三焦水道，利水消肿如开闸放水。

第二，腰脊强痛、腰肌劳损。三焦俞在腰部，局部取穴治腰痛是常规。倪师讲，这种腰痛不是肾虚那种酸软，而是水湿停在腰部、三焦气机不畅导致的沉重疼痛。三焦俞配肾俞、委中，效果立竿见影。

第三，腹胀、肠鸣、消化不良。三焦气机不畅，中焦运化受阻，三焦俞能从背部调节中焦气机。倪师讲，这种胀不是食积，是气水互结，三焦俞配脾俞、胃俞、足三里，上下通气，胀满自消。

妇科方面：三焦俞配次髎、三阴交，调理月经不调、痛经属于水湿下注者。

倪师经典对穴与排针组合：

- 三焦俞 + 水分 + 阴陵泉：通利三焦水道，治全身水肿。
- 三焦俞 + 肾俞 + 委中：治腰脊强痛、腰肌劳损。
- 三焦俞 + 脾俞 + 胃俞 + 足三里：治中焦气滞、腹胀肠鸣。
- 三焦俞 + 气海 + 关元：三焦俞从背调气，气海关元从腹固本，前后配穴，治下焦虚寒、小便频数。
- 三焦俞 + 合谷 + 太冲：开四关，调全身气机，三焦水道通，四关开，气血周流。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在人纪针灸篇讲到背部俞穴时，有一段原汁原味的讲义实录：

“三焦俞，第十三椎下。你从第七椎至阳开始，肝、胆、脾、胃，然后三焦。第十三椎就是三焦俞。三焦者，决渎之官，水道出焉。所以三焦俞是治水很重要的穴。”

倪师讲手下针感：“你针三焦俞，针下去的时候，病人会感觉腰里面在动，热热的。得气以后，你提一下针，气就往上下走。有的人你针下去，他会觉得小腹在动，想要小便，这就是三焦的气被引动了。”

倪师还讲过一个医案：“有个病人来找我，两条腿肿得像馒头，按下去一个坑，不回弹。我一看，这不是心脏的问题，也不是肾的问题，是三焦水道堵住了。我下针三焦俞、水分、阴陵泉、三阴交，留针二十分钟。针取出来，病人就讲，想去小便。小便完了回来，腿肿就消了三成。第二天再来，三焦俞加肾俞，一次比一次好。这个水道一通，水就排掉了。”

倪师特别强调的针灸秘要：“三焦俞这个穴，你不要把它看成只治三焦的病。三焦是全身气化的总管道。你三焦俞一通，上焦的咳嗽气喘、中焦的胀满、下焦的小便不利，统统都能调整。这叫一穴通三焦。针三焦俞，你手法不用太花哨，针尖斜向内刺，得气就好。得气以后，你心里想着让水往下走，病人就能感觉到。针灸这个东西，意念很重要。”

倪师还说：“平常用三焦俞，最好是配合腹部的水分穴。前面水分，后面三焦俞，前后一夹，水就没有地方跑了。你们记住这个对穴，临床上治水肿，效果非常好。”

倪师最后叮嘱：“背部下针，不可深。三焦俞斜刺，针尖向脊柱。一寸的针进去三分到五分就够了。不要贪深，深了伤内脏。灸可以，但不要灸到口干舌燥。病人感觉温热就够了。针灸是调气，不是烤肉。”
