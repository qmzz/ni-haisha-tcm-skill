# 天溪

## 📍 经络归属与精准取穴法

- 天溪穴归属**足太阴脾经**，在胸外侧部。倪师讲脾经时特别强调：脾经在胸部的穴位，从周荣、胸乡、天溪、食窦一路下来，都在胸外侧、肋骨之间走。天溪不是五输穴，也不是原络郄募，它是脾经在胸膺部的一个**局部要穴**，倪师说这一带穴位“以穴所在、治穴所在”，就是近取穴。

- 骨度折量：乳头向外旁开二寸，再直上数到**第四肋间隙**。倪师取穴从来不叫你去背“第四肋间”这种死板定位。他的大白话是：**先找到乳头，乳头往外横开两寸，然后你顺着肋骨一根一根摸，摸到乳头正上方那一根肋骨的缝隙，就是天溪**。你摸到肋骨与肋骨之间的凹陷，那个“缝”才是穴。倪师说：**穴道永远在骨缝、筋缝、肉缝之间，不在骨头上面，也不在肌肉鼓起来的地方**。天溪在第四肋间隙，你用手指轻轻按，会有一个酸胀的点，那就是它。

- 下针手法：倪师讲胸部穴位一律**斜刺或平刺**，绝对不能直刺。天溪是**沿皮刺，针尖向乳房方向斜刺0.5～0.8寸**。为什么？因为胸壁薄，下面是肺。倪师原话大意是：**胸部下针，你直刺下去，深了就是气胸，病人当场喘不过气来**。所以他反复叮嘱：胸部穴位“宁浅勿深”，针尖贴着肋骨面走，不要往肋间隙深处扎。禁灸：天溪一般不灸，因为胸部多灸容易伤津动火，尤其对妇人乳部，倪师说“灸了反而坏事”。

## ⚡ 倪师经穴气化与破局心法

- 天溪的气化机理，倪师从脾经的性来推。脾主运化、主统血、主肌肉，脾经的气到了胸外侧，天溪这个位置正好在**胸膺、乳房外侧**。倪师说：**天溪就是脾经的气血在胸部“开窗透气”的地方**。它的名字“天溪”，天者上部也，溪者水沟也，就是上焦胸中气血像溪水一样流通的通道。所以它的核心机理是**宽胸理气、通乳散结、降逆止咳**。

- 从五行生克看，脾经属土，天溪是脾经在胸部的穴位，它承接的是脾土之气向心肺区域输布。倪师心法是：**土能生金，脾经的穴能治肺的问题；土能制水，脾经的穴也能化胸中的痰饮水气**。所以天溪治咳嗽、胸痛、乳痈，它不是直接去攻，而是把脾土的气引到胸中，让胸中的气血自己转起来。这就是“引土气入胸中，以土化金、以土制水”的思路。

- 子母补泻：天溪本身不是五输穴，不能直接套“虚则补其母、实则泻其子”。但倪师讲，如果你要在脾经上做补泻，脾经的母穴是**大都**（荥穴，火生土），子穴是**商丘**（经穴，土生金）。天溪作为胸部局部穴，配大都补脾气、配商丘泻脾实，再取天溪引气到胸，这才是倪师的立体用法。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **产后乳汁不通、乳少**：这是天溪第一特效。倪师说妇人产后奶下不来，胸胀得难受，天溪、食窦、膻中一起用，针下去胸口的闷胀就松了。
  - **乳痈、乳房硬块**：天溪配肩井、膻中，倪师讲“肩井是通乳降逆的大穴，天溪是局部开结的钥匙”。
  - **胸痛、胁肋痛、咳嗽气喘**：胸外侧痛，深呼吸就痛，天溪配内关、公孙。
  - **呃逆、噎膈**：脾气不升、胃气不降，天溪配中脘、足三里。

- **倪师经典对穴与排针**：
  - **天溪 + 膻中 + 少泽**：通乳三针。少泽是小肠经井穴，专治乳汁不出，倪师说“少泽一下去，奶水就来了”。
  - **天溪 + 肩井 + 足三里**：乳痈组合。肩井消乳部硬块，足三里补脾胃之气，天溪局部开导。
  - **天溪 + 内关 + 公孙**：治胸痛、胸闷、心口痛。内关公孙是胃心胸的八脉交会配法，天溪在胸外侧加强局部开阖。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲脾经胸部穴位时，原汁原味的话是：**“天溪这个穴，你摸，在乳头外开两寸，往上到第四肋间。妇人乳房的问题，胀奶、硬块、发炎，天溪一下去，胸口的压力就解掉了。”**

- 他讲针感体会：**“针天溪是斜刺，针尖朝着乳房方向，不要直直扎进去。你扎对了，病人会感觉胸口一阵酸胀往乳房那边扩散，那就对了。如果病人咳一声，你赶紧退针，那是扎到肺了。”**

- 实战医案故事：倪师讲过，有妇人产后乳房胀硬如石，痛得哭，西医说要开刀引流。倪师取**肩井、天溪、膻中、少泽**，针下不到二十分钟，病人说胸口松了，奶水开始滴。倪师说：**“中医不是去开刀，是把气一通，奶自己就下来了。天溪就是那个开胸通乳的开关。”**

- 他还特别叮嘱：**“胸部穴位，尤其是妇人，取穴要准，下针要浅，手法要轻。天溪不是让你扎深的穴，是让你扎巧的穴。”**
