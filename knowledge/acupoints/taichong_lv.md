# 太冲穴 (LR3)

**归经：** 足厥阴肝经  
**定位：** 足背，第 1、2 跖骨结合部前凹陷中  
**属性：** 输穴、原穴

## 📍 穴位定位

**《针灸大成》：** "在足大指本节后二寸。"

### 取穴方法
1. **简便取穴法：** 足背第 1、2 跖骨结合部前方凹陷处。
2. **骨度分寸法：** 足背第 1、2 跖骨结合部前凹陷中。

### 解剖结构
- **肌肉：** 第 1 骨间背侧肌
- **神经：** 腓深神经、腓浅神经
- **血管：** 足背静脉网、第 1 跖背动、静脉

---

## 🩺 功能主治

### 功效
- **疏肝解郁** — 胁痛、急躁
- **平肝潜阳** — 头痛、眩晕、高血压
- **理气调经** — 月经不调、疝气

### 主治病证

**倪海厦：**
> "太冲为肝经输穴、原穴。
> 肝主疏泄，太冲为疏肝要穴。
> 配合谷为四关穴，凡气血不和、抽搐痉挛、失眠焦虑，四关穴必取。
> 头痛、眩晕、高血压，太冲可平肝潜阳。"

| 系统 | 病证 |
|------|------|
| **肝胆病** | 胁痛、口苦、急躁 |
| **头面病** | 头痛、眩晕、目赤、高血压 |
| **妇科病** | 月经不调、痛经、崩漏 |
| **神志病** | 癫狂、痫证、失眠 |
| **其他** | 疝气、遗尿 |

## 🔌 配伍应用

| 配伍穴位 | 功效 | 主治 |
|----------|------|------|
| **太冲 + 合谷** | 开四关 | 气血不和、抽搐 |
| **太冲 + 风池** | 平肝熄风 | 头痛、眩晕 |
| **太冲 + 三阴交** | 理气调经 | 月经不调 |
| **太冲 + 内关** | 疏肝理气 | 胁痛、胸闷 |

## 💉 刺灸法

### 针刺方法
- **进针方向：** 直刺 0.5-0.8 寸
- **针感：** 局部酸胀，可向足背放射

### 艾灸方法
- **艾条灸：** 10-15 分钟
- **艾炷灸：** 3-5 壮
