# 然谷二

## 📍 经络归属与精准取穴法

- **所属经络**：足少阴肾经。
- **五输穴属性**：然谷为肾经**荥穴**，五行属**火**。肾经属水，其荥穴为火穴，水性润下，火性炎上，此穴为水中之火，即**水中藏火**之穴，亦即**龙雷之火**所寄之处。倪师常言：肾经的荥穴，阴经荥穴属火，所以然谷是肾经的**火穴**。
- **倪师动态取穴**：倪师讲，然谷穴怎么找？**从内踝骨往前方推，推到那个高骨（舟状骨粗隆）下方，紧贴着骨头下缘，就是然谷**。你不要死记什么一寸两寸，你就顺着内踝大骨往前摸，摸到前面那块突起的骨头，骨下凹陷处便是。倪师原话大意是：**然谷在脚内侧，内踝前方大骨（舟状骨）下缘，贴着骨头下针**。
- **下针深度**：直刺或斜刺，**针入三分**，不要深。倪师讲，这个地方肉不多，贴着骨头下，得气即止。
- **禁针禁灸法则**：倪师在《人纪》中特别强调，然谷穴**禁灸**。为什么？因为它是水中之火，是龙雷之火寄居之处，你一灸，火上加火，龙雷之火妄动，病人会出问题。所以然谷只针不灸。倪师说：**然谷禁灸，灸了会让人烦躁不安，火气上冲**。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：然谷是肾经荥穴，五行属火，肾属水，此穴为**水中之火**，即**龙雷之火**、**命门真火**潜藏之地。倪师讲，肾水之中藏有一点真火，这一点真火就是人的命根子，它不能妄动，也不能熄灭。然谷就是管理这一点真火的开关。如果这一点火跑出来了，人就会**消渴**、**烦躁**、**咽喉肿痛**、**心烦不寐**——这叫**龙雷之火上奔**。然谷穴的作用，就是把这一点火**引火归元**，让它回到肾水之中去。
- **子母补泻**：肾经属水，水生木，木为肝；水克火，火为心。然谷是肾经的荥火穴。按五行生克，**虚则补其母，实则泻其子**。肾经的母穴是经穴**复溜**（属金，金生水），子穴是合穴**阴谷**（属木，水生木）。然谷本身是火穴，肾水克心火，所以然谷是肾经用来**泻心火**、**引火归元**的穴。倪师讲，当你看到病人**咽喉干燥、烦渴、晚上睡不着、心火往上冲**，你就知道是肾水不能制心火，龙雷之火上奔，这时然谷下去，火就归位了。
- **破局心法**：倪师说，然谷最擅长的就是**引火归元**。什么叫引火归元？就是病人上面火很大——口干舌燥、咽喉痛、心烦、失眠、口腔溃疡，你一看舌头，舌尖红，脉象浮数。但你再一摸他脚，脚是冰的。上面热下面寒，这就是**火不归元**，火跑到上面去了。这时你不能用苦寒药去泻火，越泻火越大。你要用然谷，把火引回到肾水里面去。火一归元，上面的热就退了，下面的脚也暖了。这就是倪师常说的：**火要藏在水中，龙要潜藏在深渊**。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **消渴（糖尿病）** ：倪师讲，然谷是治疗消渴的大穴。病人渴饮千杯不能解渴，这是龙雷之火上奔，然谷下去，火归元，渴就止了。
  2. **咽喉肿痛、口腔溃疡**：上面火大，下面脚冷，这是火不归元，然谷引火归元。
  3. **心烦不寐、失眠**：心火不能下交于肾，肾水不能上济于心，然谷沟通心肾。
  4. **遗精、阳痿、早泄**：肾经荥穴，水中之火，能温补肾阳，固摄精关。
  5. **足跗肿痛、脚不能着地**：然谷在脚内侧，近取穴治局部脚痛。
  6. **小儿脐风、抽搐**：倪师讲，小儿脐风、角弓反张，然谷可以针，但小儿用针要浅。
  7. **妇科**：月经不调、痛经、崩漏，凡属肾虚火旺者，然谷可用。

- **倪师经典对穴与排针组合**：
  - **然谷 + 太溪**：太溪是肾经原穴，补肾水；然谷是肾经荥火穴，引火归元。一补一引，水火既济。倪师常用这对穴治**消渴、失眠、心烦**。
  - **然谷 + 复溜**：复溜是肾经经穴，属金，金生水，是肾经母穴，补虚；然谷引火归元。倪师讲，肾虚火旺者，复溜补母，然谷引火，效果很好。
  - **然谷 + 涌泉**：涌泉是肾经井穴，属木，水生木。涌泉引气下行，然谷引火归元。倪师用这对穴治**上热下寒、虚火上冲**。
  - **然谷 + 三阴交**：三阴交是肝脾肾三经交会，调阴血；然谷调肾火。倪师讲，妇科病、月经不调、痛经，这对穴很好。
  - **然谷 + 关元**：关元是元气所居，然谷引火归元。倪师讲，遗精、阳痿、早泄，灸关元，针然谷，效果很好。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师讲然谷取穴实录**：倪师在《人纪》中讲：**然谷穴怎么找？从内踝大骨往前推，推到前面那个高骨，舟状骨粗隆，骨下凹陷处就是然谷。你贴着骨头下针，针入三分，得气即止。然谷禁灸，灸了火气上冲，病人烦躁不安。**

- **倪师讲然谷气化实录**：倪师讲：**然谷是肾经的荥穴，五行属火。肾是水，荥穴是火，所以然谷是水中之火，是龙雷之火寄居的地方。这一点火不能妄动，也不能熄灭。它要是跑出来了，人就会消渴、烦躁、咽喉痛、失眠。然谷下去，把火引回到肾水里面去，这叫引火归元。**

- **倪师讲然谷主治实录**：倪师讲：**然谷最擅长治消渴。病人渴饮千杯不能解渴，这是龙雷之火上奔，你针然谷，火一归元，渴就止了。然谷还治咽喉肿痛、口腔溃疡，凡是上面火大、下面脚冷的，都是火不归元，然谷引火归元，一针见效。**

- **倪师讲然谷针感实录**：倪师讲：**然谷下针，针入三分，得气后，病人会感觉有一股热流从脚内侧往上走，走到肾里面去。这就是火归元了。你摸病人脚，本来是冷的，针完然谷，脚就暖了。**

- **倪师讲然谷医案实录**：倪师讲：**有个病人，糖尿病，渴饮千杯不能解渴，脚是冰的，上面火很大。我针然谷，引火归元，针完病人就说口不渴了。第二天来，脚也暖了。这就是然谷的妙用。**

- **倪师讲然谷禁忌实录**：倪师讲：**然谷禁灸，切记切记。灸了火气上冲，病人烦躁不安，甚至发狂。然谷只针不灸，这是规矩。**

- **倪师讲然谷与复溜、太溪配伍实录**：倪师讲：**然谷配太溪，一补一引，水火既济。然谷配复溜，复溜补母，然谷引火，肾虚火旺者，这对穴很好。然谷配涌泉，引气下行，引火归元，上热下寒者，一针见效。**
