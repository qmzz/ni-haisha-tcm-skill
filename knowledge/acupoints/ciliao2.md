# 次髎二

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。次髎是膀胱经在腰骶部八髎穴中的第二穴，八髎即上髎、次髎、中髎、下髎，左右各一，共八穴，对应骶骨八个骶后孔。次髎居第二骶后孔中，为八髎中针感最强、最常用于妇科与腰骶疾患之要穴。
- **特定穴属性**：次髎非五输穴、非原络郄募，但为膀胱经与胞宫、腰骶气血转输之要冲。八髎整体可视为“骶部俞穴群”，与肾、膀胱、胞宫、大肠、小肠皆相通应。次髎尤与胞宫、精室、腰骶关节关系至密。
- **倪师动态取穴与骨度折量法**：
    - 先找髂后上棘。髂后上棘与骶骨正中线之间可摸到一凹陷，此为第一骶后孔，即上髎。
    - 沿骶正中嵴向下，每隔约一横指（同身寸约0.8～1寸）依次为第二、第三、第四骶后孔，分别对应次髎、中髎、下髎。
    - 倪师常讲：**“八髎最难找，但找到后最好用。你用手去摸，骶骨上面有一排小孔，像蜂窝一样，孔与孔之间距离很近。手指按下去，病人会酸到跳起来，那就是了。”**
    - 次髎定位：第二骶后孔中。简便法：髂后上棘与骶正中线连线中点向内下少许，按压有明显酸胀凹陷处即是。
    - **下针深度**：直刺1～1.5寸。倪师强调：**“次髎要下得深，要扎进骶孔里，针感会往阴部、大腿内侧、少腹放射，那才叫到位。”** 亦可用3寸针深刺2～2.5寸，使针感达胞宫或膀胱。
    - **禁针禁灸法则**：八髎区域一般可灸，尤其虚寒妇科病，倪师常用隔姜灸或艾条温灸八髎。但次髎深刺时须注意角度，不可胡乱向上斜刺过深，以免进入骶管。局部皮肤感染、溃疡、孕妇腰骶部慎针慎灸。

## ⚡ 倪师经穴气化与破局心法

- **气化机理推演**：
    - 膀胱经主一身之表，但次髎所处之位，内应胞宫、精室、大肠、膀胱。倪师认为：**“八髎是骨盆的开关，次髎是开关中的开关。”** 次髎能通调下焦气血，引气血下行，温养胞宫，利湿化浊。
    - 次髎之气化，重在“通”与“温”。通，则腰骶气血不滞，痛经、腰痛可解；温，则下焦寒湿可化，带下、阳痿、不孕可调。
    - 倪师常以“火在水中”为喻：肾为水脏，命门火藏于水中。次髎近命门、肾俞、膀胱俞，针之可激发命门之火，使水中有火，寒湿自散，经水自调。
- **子母补泻与五行生克运用心法**：
    - 膀胱经属水，五行中水为肾之子、肝之母。次髎虽非五输穴，但倪师在运用时，常结合子母补泻之意：
        - **虚则补其母**：膀胱虚寒、肾阳虚衰之腰痛、遗尿，可配肾俞、命门、太溪（肾经原穴）以补母气。
        - **实则泻其子**：膀胱湿热、痛经、癃闭，可配委中、承山、昆仑以泻子气。
    - 倪师心法：**“次髎本身不补不泻，它是个通道。你配补药它就补，你配泻药它就泻。关键看你把什么气引进去。”** 故次髎常与三阴交、关元、气海同用，引后天之气入下焦；与太冲、合谷同用，开四关以行气血。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
    - **妇科特效**：痛经、月经不调、带下、不孕、盆腔炎、子宫脱垂。倪师称次髎为“妇科第一要穴”，凡妇人腰骶酸胀、少腹冷痛、经行不畅，首选次髎。
    - **男科特效**：阳痿、遗精、早泄、前列腺增生。次髎可通精室、利湿浊。
    - **腰骶痛症**：腰骶关节炎、坐骨神经痛、腰椎间盘突出、骶髂关节错缝。次髎针感可直达腰骶深部，松解痉挛。
    - **下焦急症**：癃闭、尿潴留、急性膀胱炎。次髎可通利膀胱气机。
    - **慢性调理**：慢性盆腔炎、慢性前列腺炎、肠易激综合征、便秘、腹泻。
- **倪师经典对穴与排针组合**：
    - **次髎 + 三阴交**：妇科百病之基础组合。次髎通胞宫，三阴交调肝脾肾三经，一上一下，气血同调。
    - **次髎 + 关元 + 气海**：温下焦、补元气。适用于虚寒性痛经、不孕、阳痿。
    - **次髎 + 肾俞 + 命门**：补肾壮腰，治肾虚腰痛、遗尿。
    - **次髎 + 委中 + 昆仑**：治膀胱经腰痛、坐骨神经痛。
    - **次髎 + 合谷 + 太冲**：开四关，行气血，治痛经、闭经。
    - **次髎 + 阴陵泉 + 丰隆**：利湿化浊，治带下、盆腔炎。
    - 倪师排针法：常先针次髎，得气后，再针三阴交、关元。针次髎时，针尖略向内侧、向下，使针感向少腹或阴部放射。**“针下次髎，病人感觉像触电一样往下走，那效果就出来了。”**

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：
    - **“八髎穴，上髎、次髎、中髎、下髎，这是膀胱经在骶骨上的四个孔。次髎是第二个孔，这个穴道，妇人用得最多。你只要看到妇人腰痛、痛经、月经不顺，次髎一下去，效果马上出来。”**
    - **“次髎怎么找？你摸她的骶骨，上面有一排小洞，像蜂窝一样。你用指头按，按到第二个洞，病人会叫起来，那就是次髎。你不要怕，针直接扎进去，扎到孔里，针感会往下走。”**
    - **“我治痛经，次髎是主穴。针下去，再灸，艾条一烤，病人说肚子暖起来，痛就减轻了。为什么？因为次髎通胞宫，灸能温通，寒散了，痛就没了。”**
    - **“次髎不单单治妇科，男人阳痿、遗精，一样用次髎。为什么？因为次髎近精室，能通下焦气血。你配关元、肾俞，效果很好。”**
- **实战手下针感体会**：
    - 倪师针次髎，常用2寸或3寸针，直刺或略向内下斜刺。进针后，病人常有酸、麻、胀、重感，并向会阴、大腿内侧、少腹放射。倪师称此为“得气如触电”。
    - 若针感不明显，倪师会调整针尖方向，或轻轻提插捻转，或加灸以温通。**“次髎不得气，效果差一半。你一定要找到那个酸胀点。”**
- **医案故事**：
    - 倪师曾治一妇人，痛经十余年，每次经行少腹冷痛、腰骶酸胀，甚则呕吐。倪师取次髎、三阴交、关元，针后加灸次髎与关元。第一次治疗后，病人即感少腹温暖，疼痛大减。连续治疗三个月经周期，痛经基本消失。
    - 又治一男子，阳痿两年，伴腰骶酸冷。倪师取次髎、肾俞、命门、关元、三阴交，针后加灸。治疗一月余，患者晨勃恢复，腰骶转暖。
    - 倪师总结：**“次髎是下焦的钥匙，你把它打开，气血就通了。通则不痛，温则寒散。妇科、男科、腰骶病，都离不开它。”**
