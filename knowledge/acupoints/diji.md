# 地机

## 📍 经络归属与精准取穴法

- **所属经络**：足太阴脾经，膝下内侧。
- **特定穴属性**：**脾经郄穴**。郄穴者，气血深聚之孔窍，专司急症、血证、痛证。脾主统血，地机为脾经气血深聚之处，故一切脾不统血之出血、女子月事失常、急性胃痛，皆可取此。郄穴如江河之深潭，水流至此盘旋蓄积，故能调治本经气血突然壅滞或涣散之急症。其五行属土经之郄，土能统水，亦能摄血，此为地机之本性。
- **穴名释义**：地者，土也，脾属土；机者，机关、枢机也。地机者，脾土气血运行之枢纽机关。土气运转则水湿得化、血有所统；土气一滞，则湿停血溢，此穴正是重启脾土枢机之钥匙。
- **精准取穴（骨度折量）**：从阴陵泉（胫骨内侧髁下方凹陷处，脾经合穴）直下三寸，再往胫骨后缘取之。先以手摸到胫骨内侧髁最高点，其下凹陷即阴陵泉；从此处沿胫骨内侧后缘往下量三寸（约患者四横指再加一横指），在胫骨后缘与腓肠肌之间的缝隙中，按之有明显酸胀感，即是地机。**取穴诀窍**：让患者正坐屈膝，膝盖内侧隆起骨头之下沿骨缝往下推，推到有一处肌肉与骨头交界凹陷感特别明显的地方，用拇指按压，患者会“嘶”地一声——那就是地机。
- **下针深度**：直刺一寸至一寸五分。针尖略向后缘贴骨进针，得气后患者自觉酸麻胀感从小腿内侧向脚踝乃至足底放散。
- **禁针禁灸法则**：本穴无绝对禁针禁灸。然脾经郄穴多用于实急之症，**虚寒崩漏日久者宜灸**，针则补法轻刺；**急性痛证、血热妄行者宜针泻**，不灸。孕妇慎针，因脾经与冲任相关，郄穴调血之力峻猛，恐动胎气。


## ⚡ 倪师经穴气化与破局心法

- **气化机理**：倪师常言，脾经气血从足大趾隐白（井）出发，经大都（荥）、太白（输）、商丘（经），一路升腾至阴陵泉（合），如地气上为云。而地机在阴陵泉之下三寸，恰是地气升腾前**最深蓄、最浓缩的关卡处**。脾土之水湿、气血之精微，皆在此处汇聚、筛选、转化。若脾虚运化无力，则水湿停聚于此，发为小腿肿胀、沉重、按之凹陷；若脾不统血，则血不归经，从下窍溢出，此穴正是截断之关口。地机如大地之枢纽，转则地气升、浊阴降，不转则水停血乱。
- **倪师破局心法**：倪师讲脾经郄穴地机，用于**痛经急性发作**时针刺，痛立缓，因其能开脾土之郁结，气血一通则痛去。又用于**妇人月经淋漓不断、崩中漏下**，此脾不统血之证，针地机以收紧脾土之摄血功能。更有一法：**小腿内侧莫名肿胀、按之如泥、久立加重者**，此脾虚水湿下注，地机配阴陵泉、三阴交，导湿外出如开渠放水。
- **子母补泻与五行心法**：地机为脾经郄穴，不属五输穴，子母补泻需回归脾经五行（脾属土）。脾经虚证，当补其母——心经少冲（火生土）；脾经实证，当泻其子——肺经经渠（土生金）。然郄穴之用法**更直接更峻猛**：不论虚实，凡本经气血 suddenly 壅滞或涣散之急症，郄穴一针下去，如直接拧动枢机，跳过了子母补泻的慢调步骤。倪师常言：“郄穴是急救队，子母穴是调理组。痛经痛得打滚，你还去补少冲？先扎地机止住痛，回头再慢慢补母泻子。”地机虽不直接参与五行补泻，但它是脾土枢机之开关，开关一开，补泻之法才能运转。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **痛经、月经不调、崩漏**：脾经郄穴，调血第一。痛经急性发作，双侧地机齐下，提插泻法，多数患者针入痛减。月经淋漓不尽者，补法轻刺，加灸隐白。
  - **急性胃痛、腹胀**：脾与胃相表里，地机开脾土枢机，胃痛时针之，配中脘、足三里，立见松缓。
  - **小便不利、水肿**：脾虚水湿不运，地机配阴陵泉、三阴交、水分，导水下行。
  - **小腿内侧肿痛、足踝无力**：近取穴原理，地机正在病所，针之舒筋活络。
  - **遗精、带下**：脾虚湿注下焦，地机配关元、三阴交，升提中气以固下元。
- **倪师经典对穴与排针组合**：
  - **痛经组合**：地机 + 三阴交 + 关元（或中极）。三阴交调三阴经气血，关元暖下焦，地机开脾土枢机止急痛。此方倪师常用于急诊痛经。
  - **崩漏组合**：地机 + 隐白（灸）+ 公孙。隐白为脾经井穴，灸之摄血归经；公孙通冲脉，地机郄穴收紧脾土统血之力。
  - **急性胃痛组合**：地机 + 中脘 + 足三里 + 内关。地机郄穴止急，余者调气和胃。
  - **水肿组合**：地机 + 阴陵泉 + 水分 + 三焦俞。地机开脾枢，阴陵泉利水，水分分利水湿。
  - **小腿肿痛组合**：地机 + 承山 + 昆仑。近远配穴，通经活络。


## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原话（痛经实战）**：“女孩子痛经，痛得在地上打滚，你针什么？三阴交？太慢了。你摸她小腿内侧，地机穴一按，她叫得比痛经还大声——就是这里。两边一针下去，提插几下，痛经当场松掉。为什么？地机是脾经的郄穴，郄穴就是气血最深积的地方，痛经就是血积在子宫出不来，你在地机上一开，脾土一运，子宫的血就动了，痛就去掉了。这是急则治标，先让她不痛，回头再慢慢调。”
- **倪师原话（崩漏与脾统血）**：“月经来个不停，滴滴答答十几天，这是脾不统血。你怎么知道是脾？脸色苍白、四肢无力、舌淡脉弱，一看就是脾虚。地机穴，补法，轻轻下针，再加灸隐白，血就收住了。为什么地机管脾不统血？因为它是郄穴，郄穴是气血深聚之处，脾土的血气在这里最深最浓，你在这里一补，等于把脾土摄血的力量重新提起来。脾统血，脾土一强，血就归经了。”
- **倪师手下针感实录**：“针地机，针尖要贴着胫骨后缘进去，得气的感觉是酸胀从地机往下窜到内踝，有的病人说一直麻到脚底。这种针感越往下走，效果越好。如果针下去病人只觉得表皮刺痛，那是没扎到穴，要重新调整角度。地机得气，你的手下会有一种‘吸针’的感觉，针被肌肉轻轻裹住，这时候不要捻转太猛，轻轻提插三五下即可。”
- **倪师医案（急性胃痛）**：“有个病人半夜胃痛，痛得直不起腰。我先针足三里、中脘，痛减了三分，但还胀。再针两边地机，一针下去，他说肚子里面好像有东西松开了一样，咕噜咕噜响，放了几个屁，痛就全消了。地机开脾土之机，脾与胃表里，脾土一转，胃气就降了。所以胃痛不一定是胃的问题，脾土枢机不转，胃气就不降，地机正是转枢机之穴。”
