# 期门穴 (LR14)

## 📍 经络归属与精准取穴法

期门穴，足厥阴肝经之募穴，亦为肝经与脾经、阴维脉之交会穴。在五输穴体系之外，募穴是脏腑之气直接汇聚于胸腹部的门户，肝之募即期门。倪师在《人纪·针灸篇》中讲得非常明白：募穴是“开口的地方”，脏气从这里出入，因此治肝病、调肝气，期门是核心大穴，与背后的肝俞形成“俞募配穴”的经典组合——前面期门，后面肝俞，一前一后，把肝夹在中间。

取穴法：乳头直下，第六肋间隙。倪师的标准取法是“从乳头往下数两根肋骨”，乳头在第4肋间，往下数第5、第6，即第6肋间隙，前正中线旁开4寸。注意是肋间隙，不是肋骨上——针要下在两根肋骨之间的缝隙里，贴着骨膜边缘进去，不要扎在骨头上面。找穴时让患者仰卧或正坐，先定乳头位置，男子以乳头为准，女子因乳房下垂，以锁骨中线第4肋间为基准再往下推两个肋间。

下针手法：倪师强调——**斜刺**，绝不是直刺。因为期门穴下方就是肝脏本体，直刺深刺会伤肝，这是绝对禁忌。正确做法是沿着肋间隙，针尖斜向内下方或沿肋骨走向斜刺，进针深度控制在**五分到八分**，最多一寸，绝不深刺。得气即止，患者会感到局部胀满或沿肋间放射。留针十五到二十分钟。

禁灸法则：期门不宜灸。肝为刚脏，体阴而用阳，灸法助火，火上加火，肝气上逆更甚，故**禁灸**。这一点倪师在课堂上反复交代过。

## ⚡ 倪师经穴气化与破局心法

倪师在《人纪》中用了大量篇幅讲肝的生理与病理，期门作为肝之募穴，其气化机理与肝的疏泄功能直接挂钩。肝气要条达，要升发，要疏泄周身气机。期门就是肝气在胸腹部向外疏泄的“闸口”。

第一层心法：**开胸解郁，引气下行**。肝气郁结的人，气堵在胸胁，两肋胀痛，善太息（老想叹气），情绪压抑。期门一针下去，配合背后的肝俞，等于把胸胁部的郁气打开一个口子，让肝气有出路，这是“开阖”之理。倪师常说，治肝要“疏”不要“堵”，期门就是那个疏的出口。

第二层心法：**木土相克，泻肝扶脾**。肝属木，脾属土，木克土。肝气太过则横逆犯脾，出现“见肝之病，知肝传脾”的连锁反应——胁痛、腹胀、食欲不振、大便不调。期门作为肝之募，能泻肝之实，配合脾经的太白、足三里，就是“实脾”以防火乘土。倪师在《金匮》里讲“当先实脾”，在针灸上的落点就是：泻期门以制肝，补足三里、太白以实脾。

子母补泻与五行运用：肝经五输穴是——大敦（井·木）、行间（荥·火）、太冲（输·土）、中封（经·金）、曲泉（合·水）。肝属木，木之子为火，实则泻其子——肝实证取行间（荥火）。木之母为水，虚则补其母——肝虚证取曲泉（合水）。期门不在这条子母补泻链上，但它是募穴，直接作用于肝的“气口”。倪师的心法是：**急性实证用行间泻火，慢性虚证用曲泉补水，而期门是疏通道路的总开关**——不管虚证实证，道路不通，补泻都打折扣，所以期门常常是“开路先锋”。

## 🎯 临床主治与配穴组合手印

**核心特效主治：**

1. **胸胁胀痛、两肋刺痛**——最直接的主治。不管是情绪郁结导致的胀痛，还是跌打损伤导致的瘀血刺痛，期门都是首选。倪师说“胸胁苦满”，首选就是期门配肝俞，前后夹击。

2. **肝病（肝炎、肝硬化早期、脂肪肝）** ——俞募配穴，期门配肝俞，再配太冲、足三里。这是倪师治肝病的经典排针。

3. **乳痈、乳房胀痛**——肝经循行过乳房，乳头属肝，乳房属胃。期门配膻中、太冲、肩井，疏肝通乳，对乳腺炎初期、经前乳房胀痛特效。

4. **呕吐、吞酸、呃逆**——肝气犯胃的表现。期门配中脘、内关、足三里。倪师讲“呕逆”时特别提到，如果是情绪波动后加重的，一定要加期门。

5. **奔豚气**——患者自觉有气从小腹上冲胸咽，这是肝气挟冲脉上逆。期门配公孙、内关（公孙内关治胃心胸）、太冲，降逆平冲。

**倪师经典对穴与排针组合：**

- **期门 + 肝俞**：俞募配穴，治一切肝病，前门后门一起打开。
- **期门 + 太冲**：肝经募穴配原穴，原募同用，疏肝力量倍增。
- **期门 + 中脘 + 足三里**：肝胃不和、胃痛吞酸的标准组合。
- **期门 + 章门 + 太冲**：章门是脏会，期门是肝募，两穴配合调五脏气机，专治胁痛、腹胀。
- **期门 + 膻中 + 内关**：胸胁苦满、心慌胸闷，开胸顺气。
- **开四关（合谷 + 太冲）再加期门**：顽固性郁证、全身气机不畅。

排针顺序：倪师习惯先针背部肝俞，再针前面期门，最后针四肢的远道穴（太冲、足三里）。背部针完不要马上翻面，先让患者趴着留针十分钟，再翻身仰卧针期门。期门的针一定要斜刺，留针时患者会感觉肋间有温热感或轻微跳动，这是气至的表现。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲到期门时，原话大意如下：

“期门穴怎么找？乳头正下方，第六肋间。你不要直刺啊，直刺扎到肝，那不得了。斜着刺，沿着肋骨缝进去，五分到八分，不要深。这是肝的募穴，肝气从这里出来。”

“你们记住，肝有病，前面期门，后面肝俞，两个穴一起用。这是募穴配俞穴，一前一后，气就通了。你光针一个不行，要前后夹击。”

“很多太太小姐乳房胀痛，尤其是月经来之前，脾气大，胸胁胀，乳头胀——这是肝气郁结。期门、太冲、肩井，针下去，当场就松了。为什么？乳头属肝，乳房属胃，你把肝气一疏，它就不胀了。”

“期门禁灸。肝是刚脏，你还要用火去烤它？那肝气更旺，火上浇油。所以期门只针不灸，而且不深针。”

倪师还讲过一个实战体会：有个患者肝硬化腹水，胁痛得不能侧卧，倪师先针肝俞、期门（浅斜刺），再针水分、阴陵泉、三阴交。针完当天晚上患者就能侧睡了。倪师说：“期门不是治水的，但它把肝气疏通以后，水道就通了。木能疏土，土能治水，这是连环的。”

另一则故事：一位女士长期情绪抑郁，两胁胀了三年，到处看不好。倪师一搭脉，弦紧，舌苔薄白，判断是肝气郁结。取期门、太冲、内关、公孙，针了三次，患者说“胸口那块石头好像被人搬走了”。倪师在课堂上感慨：“肝气一郁，什么病都来了。期门就是给肝气开一扇窗，窗户开了，闷气就散了。”

针感体会：倪师说，期门斜刺得气后，患者常常会觉得肋间有一阵温热感向外扩散，有时候会沿着肋骨边缘传到背后。如果患者感觉刺痛、灼痛，那是扎到骨膜或肋间神经了，要立刻调整角度。得气的感觉应该是“胀”，不是“痛”。这一点在临床上要仔细分辨。
