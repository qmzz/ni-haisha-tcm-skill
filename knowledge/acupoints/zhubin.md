# 筑宾

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：筑宾穴，足少阴肾经第七穴，为**阴维脉之郄穴**。郄穴者，气血深聚之孔隙也，专主急症、痛症、血症。肾经 itself 属水，筑宾在此经上扮演的角色，不是井荥输经合那一路气血渐行的常规关卡，而是**阴维脉与肾经交汇的能量闸门**。阴维脉维络一身之阴，筑宾作为其郄，意味着五脏阴精的急迫问题——阴维为病苦心痛——皆可从此处撬动。

- **倪师动态取穴与骨度折量法**：倪师讲筑宾，从不叫你死记“太溪上五寸”。他的取法是活的：先找**太溪**——内踝尖与跟腱之间那个凹陷，那是肾经的原穴，肾气的根。从太溪往上循，循过**复溜**——太溪上二寸，跟腱前缘。再往上三寸，就是筑宾。但倪师强调，你不能拿尺子量，你得**用手指循**：从太溪沿着跟腱前缘往上推，推到腓肠肌肌腹开始隆起的那条沟里，病人会告诉你“哎，这里酸”——那就是筑宾。它在**腓肠肌内侧肌腹下端**，太溪上五寸，跟腱内侧前缘。找穴要**揣穴**，不是量穴。

  下针深度：倪师说，**针一寸到一寸五分**，直刺。这个穴在腓肠肌上，肌肉厚实，针下去要有**得气感**——病人感到酸胀麻，有时会往下窜到足底，有时往上走。**禁灸**——倪师明确讲，筑宾不灸，因为它是阴维郄穴，主阴急，灸则助火，反伤阴络。孕妇禁针，因其通阴维、动肾气，恐扰动胎元。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师在《人纪》中讲，肾经的气血从**涌泉**出来，一路往上，到**太溪**是原气所注，到**复溜**是经气所行——复溜者，复其流也，肾水从此处开始有“复”的力量，就是把水气重新蒸化。再往上到**筑宾**，就是**阴维脉的郄穴**，阴维主一身之里，维络诸阴。筑宾的机理，倪师一句话点破：**“阴维为病苦心痛，筑宾能解阴维之急。”** 什么意思？当五脏阴气绷得太紧——比如痉挛、抽筋、癫痫、腹部绞痛、心中急痛——那是阴维脉在“紧”。筑宾作为郄穴，就是**松解阴维之紧**的开关。它不直接补也不直接泻，它是**开闸放水**，让绷紧的阴络松下来。所以倪师用它治**癫痫、狂症、抽筋、腹痛、心痛**，道理在此。

- **子母补泻与五行生克运用心法**：筑宾本身不是五输穴，所以子母补泻不直接落在它头上。但倪师的心法是：**筑宾是阴维郄，阴维与肾经相通，肾为水，阴维急则水不涵木，木急生风。** 所以虚则补其母——肾水虚导致阴维失养而拘急，你要补肾，取**复溜**（肾经母穴？不对，肾经母穴是复溜？肾为水，金生水，母穴是**复溜**——复溜属金，金生水，故复溜为肾经母穴，补之。实则泻其子——肾水实、阴维绷紧，你要泻**涌泉**（肾经子穴，木为水之子，涌泉属木）。而**筑宾**呢？倪师说，**筑宾是郄穴，郄穴治急，你不管虚实，急则取郄**。先松解，再谈补泻。所以临床心法是：**先针筑宾解阴维之急，再按虚实取复溜或涌泉调其根本。**

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：筑宾是倪师口中的**“癫痫要穴”**。大人癫痫、小儿惊风、狂症、精神分裂，筑宾配**鸠尾、后溪、申脉**，这是倪师治癫狂的经典组合。第二，**阴维为病苦心痛**——筑宾治**心绞痛、心悸、胸腹急痛**，配**内关**（通阴维脉）、**公孙**（通冲脉），这是八脉交会配郄穴的用法。第三，**小腿抽筋、腓肠肌痉挛**——筑宾局部就是腓肠肌，郄穴治急，针下去抽筋立缓。第四，**腹痛、痛经、疝气**——阴维急则少腹拘急，筑宾配**三阴交、太冲**。第五，倪师用筑宾治**脚气水肿、肾脏炎**，因为它是肾经穴，能利水。

- **倪师经典对穴与排针组合**：
  - **筑宾 + 鸠尾 + 后溪 + 申脉**：治癫痫、狂症。鸠尾是任脉络穴，膏之原，治癫狂；后溪通督脉，申脉通阳跷，筑宾解阴维——**阴阳跷维同调，癫狂自平**。
  - **筑宾 + 内关 + 公孙**：治心痛、胃心胸急痛。内关通阴维，公孙通冲脉，筑宾是阴维郄——**郄穴加交会，急痛立止**。
  - **筑宾 + 三阴交 + 太冲**：治痛经、少腹绞痛、疝气。三阴交调三阴，太冲开四关，筑宾松阴维——**下焦急痛一针解**。
  - **筑宾 + 复溜 + 太溪**：治肾虚腰痛、水肿、脚气。太溪原穴补肾，复溜母穴补金生水，筑宾郄穴利水急——**补肾利水，标本兼治**。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲筑宾时，原话是这么说的：

**“筑宾穴，太溪上五寸，跟腱的内侧。这个是阴维脉的郄穴。阴维脉呢，维系诸阴。阴维为病，苦心痛。所以筑宾穴，你看，它治癫痫、狂症、抽筋、腹痛、心痛。为什么？因为阴维脉绷紧了嘛。郄穴就是治急的，所以筑宾一下去，阴维就松开了。”**

他又讲：

**“你们看，癫痫的人，发病的时候，全身绷紧，角弓反张，那是阴维在急。筑宾针下去，阴维一松，那个紧就解掉了。再配合鸠尾、后溪、申脉，这是治疗癫痫的经典组合。小孩子惊风，也是这个道理。所以筑宾不要小看它，它是解阴维之急的钥匙。”**

倪师手下针感的描述：

**“针筑宾，你要下到一寸半。针进去以后，病人会感觉到酸胀，有时候会往上走，走到大腿内侧，有时候往下走，走到脚底。这是气在通阴维。你捻针，要配合病人的呼吸。病人吸气的时候你进针，呼气的时候你捻针，这样气走得快。得气以后，病人的抽筋、腹痛，当场就缓了。”**

医案故事：倪师讲过一个案例，一个妇人痛经，痛到在地上打滚，少腹拘急，像有人拿绳子勒紧。倪师先针**三阴交、太冲**，痛减了三分，但拘急还在。倪师再针**筑宾**，针下去，捻了两下，妇人说“松了，松了”。倪师说：**“这就是阴维急。三阴交、太冲调气血，但阴维绷紧的那根弦，要靠筑宾来松。郄穴治急，就是这个道理。”**
