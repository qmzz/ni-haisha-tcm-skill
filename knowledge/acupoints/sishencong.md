# 四神聪

## 📍 经络归属与精准取穴法

- **经络归属**：四神聪属**经外奇穴**，不在十二正经与任督二脉的循行体系之内，因此**没有五输穴（井荥输经合）属性，也没有原穴、络穴、郄穴、募穴、背俞穴、八会穴这些特定穴的五行生克定位**。倪师在讲正经穴位时反复强调，五输穴的五行属性、子母补泻，是依附于十二经的，四神聪是奇穴，不套这一套。但四神聪的位置在头顶，紧贴**督脉与足太阳膀胱经**的交会区域——它就在百会的前后左右，百会本身是督脉穴，也是足太阳膀胱经与督脉的交会处，所以四神聪的气化，借的是**督脉升阳与膀胱经主表、主水**的底子，倪师讲奇穴时从不把它当孤立的点看，一定放在它所在的那片经络气场里。

- **精准取穴法（倪师大白话讲透）**：
  四神聪一共**四个点**，不是一针，是四针。先找**百会**——百会在头顶正中线，两耳尖直上，连一条线，与头顶正中线的交点，你用手按，按到一个**小小的凹陷**，那个就是百会。百会在《针灸大成》里是“三阳五会”，是诸阳之会，四神聪就围着百会转圈：
  - **前神聪**：百会往前一寸；
  - **后神聪**：百会往后一寸；
  - **左神聪**：百会往左一寸；
  - **右神聪**：百会往右一寸。
  倪师取穴不用尺子量，他用**同身寸**：病人自己**中指弯曲，中节两侧横纹头之间**为一寸，或者**拇指指间关节的宽度**为一寸。头顶上你拿病人自己的中指去比，百会前、后、左、右各量一寸，四个点就出来了。四个点围起来像一个**小小的十字花**，把百会包在正中间。

- **下针深度与禁针禁灸**：
  四神聪在头顶，头皮上，倪师下针的原则是**平刺或斜刺，不是直刺**。头顶骨头是圆的，你直刺下去，扎到骨膜，病人痛得跳起来，而且没有意义。正确的手法是**沿头皮平刺，针尖朝向百会方向，刺入0.5到0.8寸**，针身贴在帽状腱膜与颅骨之间，你会感觉针下**松软如绵**，没有阻力，病人不痛或者只有微微的酸胀。倪师说，头顶的穴位，**得气的感觉不是像合谷那样强烈的酸麻，而是头皮发紧、发麻，有时候像有蚂蚁在爬，或者头顶一片温热感**，这就是气到了。
  - **禁针**：**小儿囟门未闭者禁针**。小孩子头顶囟门还是软的，你一针下去扎到脑膜，那是要出大事的，倪师特别强调这一点。
  - **禁灸**：四神聪**一般不灸**。头顶是诸阳之会，阳气已经最旺，你再用艾火去烧，容易**引火上头**，病人会头痛、烦躁、失眠加重。除非是极个别的**阳气下陷、清阳不升**的虚寒证，倪师才会考虑用**小艾炷隔姜灸百会**，但四神聪本身几乎不灸。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理（倪师推演）**：
  倪师讲四神聪，不跟你讲解剖上它下面是哪块肌肉、哪根血管，他讲**气**。四神聪围在百会四周，百会是**督脉与足太阳膀胱经的交会**，督脉主一身之阳，膀胱经主一身之表，也是**水经**。所以四神聪这个区域，是**阳气最集中、最表浅、最容易受风也最容易把风散出去**的地方。倪师推演它的机理，核心是四个字：**升阳、开窍**。
  - **升提中气**：中气下陷的人，清阳不升，人会**头昏、眼花、耳鸣、脱肛、子宫下垂、胃下垂**。四神聪在头顶最高处，针尖朝向百会，等于**把下陷的气往上提**，像一只手把塌下来的帐篷顶起来。倪师说，头顶的穴，天生就是**升提**的，你一下针，病人的感觉是**头顶发紧，然后眼睛好像亮了一点，脑子好像清了一点**，这就是清阳上来了。
  - **开窍醒神**：四神聪对**神志病**有奇效——失眠、健忘、癫痫、小儿多动、脑鸣。倪师讲，头顶是**元神之府**的对应区，四神聪围住百会，等于**四面向中心聚气**，把散乱的神收回来。失眠的人，神在外面飘，你针四神聪，神就归位了；癫痫的人，神乱窜，你针四神聪，神就定住了。
  - **引火归元**：有些病人**虚阳上浮**，脸红、烦躁、失眠、血压高，但脚是冷的，这是火不在该在的地方。倪师用四神聪，不是去泻火，而是**通过头顶的阳气把浮火往下引**——听起来矛盾，但倪师说，头顶的阳气一通，**任督二脉循环起来**，火自然就往下走，回到命门去。所以他常配**涌泉**，一上一下，火就归元了。

- **子母补泻与五行生克运用心法**：
  四神聪是奇穴，**本身没有五行属性，不套子母补泻**。但倪师在临床上，会**借它所在经络的气场**来用五行。四神聪紧贴督脉与膀胱经：
  - 膀胱经属**水**，督脉统领**诸阳**。如果病人是**肾水不足、水不涵木、肝阳上亢**导致头晕头痛，倪师会在四神聪基础上，**补太溪（肾经原穴，属水）、泻太冲（肝经原穴，属木）**，这叫**滋水涵木**；
  - 如果病人是**心火不足、神不守舍**，倪师会配**神门（心经原穴，属土）**，用四神聪升清阳，神门安神，这叫**火土相生，神有所归**。
  倪师的心法是：**奇穴不争五行，但它站在哪条经的地盘上，就借哪条经的五行之气来用**。四神聪站在督脉与膀胱经的地盘上，所以它天生带**水与火**的双重性格——既能升阳（火），又能利水（水），所以它治**脑积水、脑鸣、水气上冲到头**也有效，机理就在这里。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **急症救逆**：**中风昏迷、癫痫发作、小儿惊风**。倪师说，急症时用四神聪**点刺放血**，或者**强刺激不留针**，能**开窍醒神**，让病人快点醒过来。
  - **慢性病调理**：**失眠、健忘、神经衰弱、脑鸣、头晕、头痛（尤其是头顶痛）**。头顶痛是**厥阴肝经**的问题，但倪师用四神聪，因为它在最高处，**居高临下，把厥阴的郁火散掉**。
  - **妇科/儿科特效**：**小儿多动症、小儿智力发育迟缓、小儿夜啼**。倪师讲，小孩子头顶囟门未闭时**禁针**，但囟门闭合后，四神聪**浅刺、不留针**，对小儿脑发育有好处。妇科方面，**子宫脱垂、产后抑郁**，四神聪升提中气，配**百会、足三里、三阴交**，效果很好。
  - **痛症特效**：**偏头痛、巅顶痛、颈椎病引起的头晕**。倪师说，头顶的痛，你针四神聪，针尖朝向百会，**痛就往上散掉了**，像把一盆水从头顶泼出去。

- **倪师经典对穴与排针组合**：
  - **四神聪 + 百会**：这是**君臣配**。百会是君，四神聪是臣，四针围一针，**聚气于顶**，治一切**清阳不升、神志不安**。
  - **四神聪 + 涌泉**：这是**上下配**。四神聪升阳，涌泉引火归元，治**虚阳上浮、失眠、高血压、更年期潮热**。倪师说，这一上一下，**水火既济**，人就安了。
  - **四神聪 + 神门 + 三阴交**：这是**安神配**。神门安心神，三阴交调肝脾肾，四神聪收神归位，治**顽固性失眠、焦虑、心悸**。
  - **四神聪 + 合谷 + 太冲（开四关）**：这是**通调配**。四关通气血，四神聪升清阳，治**气血瘀阻导致的头痛、头晕、情绪抑郁**。倪师说，开四关是**把全身的气血通道打开**，四神聪是**把头顶的气场理顺**，两个合起来，**上下贯通，一气周流**。
  - **四神聪 + 足三里 + 三阴交**：这是**补虚配**。足三里补中气，三阴交补三阴，四神聪升清阳，治**中气下陷、脱肛、子宫下垂、久病体虚头晕**。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：
  “四神聪，你们不要把它当四个穴，它是一组穴，**四个针围着一个百会**，像四个卫士守着皇帝。百会是诸阳之会，四神聪就是**把阳气聚在头顶，不让它散掉**。”
  “头顶的穴，**下针要平刺，贴着皮刺**，你不要直直地扎下去，扎到骨头，病人痛死，而且没用。你平刺进去，针身躺在头皮下面，**气就在头皮上走**，病人感觉头顶发紧、发麻，那就是气到了。”
  “四神聪治失眠，**神在外面飘的人，你针四神聪，神就回来了**。你不要去管它是什么神经衰弱，你只管**神归位**，神归位了，人就睡着了。”
  “小孩子囟门没闭，**绝对不能针四神聪**，你一针下去，扎到脑膜，那是要命的。等囟门闭了，你**浅浅地刺，不留针**，对小孩子脑发育有帮助。”
  “四神聪配涌泉，**一上一下，水火既济**。上面升阳，下面引火，火就回到命门去了，人就不烦躁了，脚也热了。”

- **实战手下针感体会**：
  倪师说，针四神聪，**针尖要朝向百会**，四个针从四个方向**向中心聚**。你得气的感觉，不是像合谷那样强烈的酸麻，而是**头皮一片温热，或者像有蚂蚁在爬**，有时候病人会感觉**头顶好像有什么东西松开了**，然后**眼睛亮了一下，脑子清了一下**。这就是**清阳上来了**。如果病人**没有感觉**，你要**轻轻捻针**，或者**把针稍微提出来一点，换个方向再刺**，直到**头皮发紧**为止。

- **医案故事**：
  倪师讲过一个案例：一个**五十多岁的太太，失眠十几年**，西医说是**神经衰弱**，吃安眠药越吃越重。倪师看她**脸色苍白，脚是冷的，但头面是热的**，这是**虚阳上浮**。倪师针**四神聪，针尖朝向百会，平刺**，再针**涌泉，引火归元**，留针二十分钟。起针后，太太说**头顶好像卸了一块石头，眼睛亮了，脑子清楚了**。当天晚上，**没吃安眠药，睡了五个小时**。倪师说，这就是**清阳升、浊阴降、火归元**，神就安了。
  还有一个**小儿多动症**的案例：一个**七八岁的小男孩**，上课坐不住，注意力不集中。倪师针**四神聪，浅刺不留针**，再配**神门、三阴交**，每周两次。三个月后，**老师说他能坐得住了，成绩也上来了**。倪师说，小孩子**脑发育不全，清阳不升**，四神聪**升清阳、开脑窍**，脑窍开了，人就静下来了。
