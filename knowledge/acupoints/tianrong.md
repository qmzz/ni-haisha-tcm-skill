# 天容

## 📍 经络归属与精准取穴法

天容穴，隶属于**手太阳小肠经**。在倪海厦先生的五输穴体系中，手太阳小肠经的井穴是少泽，荥穴是前谷，俞穴是后溪，经穴是阳谷，合穴是小海。天容不在五输穴之列，但它是**手太阳小肠经与足少阳胆经的交会穴**——这个交会身份极为要紧，因为天容的气化路径同时接通小肠经与胆经两条经脉的经气，一穴管两经。

从特定穴角度看，天容不属于原、络、郄、募、俞、八会等常见类别，但它的位置在**下颌角后方、胸锁乳突肌前缘**，正好卡在颈侧咽喉与头面之间的气机枢纽上。

**倪师动态取穴法：**

你让病人正坐，头微微偏向对侧（比如取右侧天容，头就微微往左偏）。这时候你用手去摸他的下颌角，摸到那个最尖的骨角后，手指往后一滑，滑到下颌角正后方，你会摸到一条大筋——这条筋就是胸锁乳突肌。天容穴就藏在**下颌角后缘与胸锁乳突肌前缘之间的凹陷**里。

倪师原话的意思：不要死记“下颌角后方一寸”这种纸上谈兵的说法，人的脖子粗细不一样，胖瘦不一样，你要用手去感受那个凹陷。手指按下去，病人会有酸胀感往喉咙方向窜——那就对了。

**下针深度：** 倪师说这里**只针五分到八分，不可深针**。为什么？因为颈侧血管神经密布，深刺容易伤及颈内静脉、颈外动脉分支以及迷走神经。针下去的方向是**直刺或略向内下方斜刺**，得气即止，不要在里面乱捣。

**禁灸与否：** 天容穴在古代文献中多不主张灸法。倪师在讲授颈项部穴位时反复强调一个原则——**颈部穴位以针为主，极少用灸**。因为颈侧肌肉薄、血管浅，艾火的热力容易灼伤皮肉，且颈部为诸阳之会，温热过度反而助火上炎。天容这个位置，倪师的态度是：**可针不可灸，针宜浅不宜深。**

另外，天容穴下针前一定要让病人**保持安静，不要说话吞咽**，因为你一吞咽，胸锁乳突肌就动了，针尖容易移位伤及深部结构。倪师非常注重这种下针前的细节交代，这是保命的东西。

## ⚡ 倪师经穴气化与破局心法

天容穴的气化机理，要从它所属的两条经脉来说。

**先看手太阳小肠经。** 小肠经的循行是从手小指少泽开始，沿着手臂外侧后缘上行到肩胛，然后上头面。它的经脉别络和经筋都经过颈侧。小肠在中医里是“受盛之官，化物出焉”——它承担着分清泌浊的功能。小肠经的经气走到颈部天容这个位置时，正是清阳之气要上达头面、浊阴之气要下归大肠的分水岭。

**再看足少阳胆经。** 胆经循行经过颈侧、下颌角附近，天容是两经的交会点。胆主疏泄、主决断，少阳为枢。天容作为交会穴，就成了**少阳枢机与太阳清浊分利之间的一个开关**。

**倪师推演的气化机理是这样的：**

天容穴的核心作用是“**利咽开窍、清热降逆**”。为什么？因为它的位置正好在咽喉外侧、气机上下出入的关口上。当外邪束表、少阳枢机不利时，经气堵在这个关口，就会出现**咽喉肿痛、吞咽困难、耳聋耳鸣、颈项强痛**这些症状。天容的作用就是把堵在这个关口的经气疏通开——往上走的清阳让它上去濡养头面，该降的浊气让它降下来从肠道排出。

倪师常说，天容这个穴像是一个“**颈部的十字路口交警**”。小肠经的气要从这里上头面，胆经的气要从这里往下走，两条经气在这里交汇，容易堵车。你在这个路口下一针，等于派了个交警上去指挥——上头的放行，下头的疏通，各走各的道，气机就顺了。

**子母补泻与五行生克：**

天容本身不在五输穴上，没法直接用它做子母补泻。但倪师的心法是：**通过天容调节小肠经与胆经的经气平衡，间接实现子母补泻的效果。**

小肠经属火，胆经属木。木生火，胆经是小肠经的“母经”。如果小肠经虚寒（比如受寒后颈项僵硬、耳聋），你在天容上下针，可以引胆经木气来生小肠经火气——这叫“虚则补其母”的变通用法。反过来，如果胆经火旺上炎（比如偏头痛、目赤、咽痛），天容可以泻小肠经之火来平胆经之亢——因为火泄则木不焚。这就是倪师常讲的“**经脉交会处就是五行生克的调节阀**”。

## 🎯 临床主治与配穴组合手印

**核心特效主治：**

天容穴的第一大主治就是**咽喉疾病**。咽喉肿痛、扁桃体发炎、声音嘶哑、吞咽困难——天容是近取穴，直接作用于咽喉外侧，针下去酸胀感往喉咙里窜，效果立竿见影。

第二大主治是**耳部疾病**。耳鸣、耳聋、中耳炎——尤其是那种伴随颈项僵硬的耳鸣，天容配听宫、听会效果极好。因为小肠经“入耳中”，胆经“从耳后入耳中”，天容同时调节两经入耳之气。

第三大主治是**颈项强痛**。落枕、颈椎病引起的颈侧疼痛、转头困难，天容配上风池、肩井，松解胸锁乳突肌和斜方肌的紧张。

第四大主治是**瘿气（甲状腺问题）** 。古代文献中天容主治“瘿”——就是脖子前面肿大一类的病。倪师在讲颈部穴位时提过，天容配合天突、水突、缺盆这一组穴位，可以疏通颈部气机，对甲状腺肿大有辅助调理作用。

**倪师经典配穴组合：**

- **天容 + 少商（放血）** ：急性咽喉肿痛。少商点刺放血泄热，天容下针疏通局部气机。这是倪师处理喉咙痛的经典组合——一个从远端泄热，一个从近端通关。

- **天容 + 听宫 + 翳风**：耳鸣耳聋。听宫是手太阳小肠经的末端穴，翳风是手少阳三焦经的穴，天容居中调度，三穴合用把耳周的气机全部打开。

- **天容 + 风池 + 大椎**：颈项强痛伴随外感。风池散风，大椎通阳，天容松解局部，三穴把太阳、少阳、督脉的气机一起疏通。

- **天容 + 合谷 + 列缺**：咽喉问题配合远端取穴。合谷是手阳明大肠经的原穴，列缺是手太阴肺经的络穴——肺与大肠相表里，咽喉是肺之门户，远端近端一起用，效果翻倍。

倪师排针的规矩是：**先针远端，再针近端**。比如治喉咙痛，先针合谷、列缺，让病人感觉气血开始动了，再针天容。这样病人对天容的针感会更敏锐，得气更快。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲颈部穴位时，关于天容穴有一段非常生动的讲法。他的大意是：

“这个天容啊，你们看名字，天是上面，容是容纳。它就在脖子这里，承受着上面的头面之气往下走。你看一个人喉咙痛、脖子肿，你去按他的天容，一按就酸得要命，为什么？气堵在这里了嘛。你一针下去，不用深，五分就够了，针尖稍微往喉咙方向斜一点，病人马上感觉喉咙里有一股气在动，有的人当场就觉得喉咙松了。”

倪师还讲过他自己处理**急性扁桃体发炎**的案例。病人是个小孩子，喉咙肿得水都喝不下去，西医说要开刀。倪师先在小孩子少商上点刺放了两滴血，然后在两边天容各下一针，留针十分钟。小孩子当场就说喉咙没那么痛了，能咽口水了。倪师说：“你看，天容这个穴，它不治扁桃体本身，它治的是**气堵在脖子这个‘容’字上面下不去**。气一通，肿就消。”

关于针感，倪师描述天容得气的感觉是“**酸胀感从颈侧往喉咙深处窜，有时候往耳朵方向走**”。如果病人说针下去像触电一样往手臂跑，那说明扎到神经了——倪师说这种情况要立刻退针，换个角度再进，不要硬来。

倪师还特别强调过天容穴在**针灸急救**中的角色。有一种情况是病人突然咽喉痉挛、说不出话、呼吸困难，在没有其他工具的情况下，天容配天突可以紧急疏通咽喉气机。但倪师也警告：**这属于急救手段，非专业人士不要轻易尝试颈部深刺。**

最后，倪师讲天容时反复叮嘱一句话：“**颈部无深针，得气即止。**”这是他用几十年临床经验换来的铁律。天容穴的妙处在于“四两拨千斤”——浅浅一针，轻轻一捻，气机转动，病邪自散。你不需要用力，不需要深刺，你只需要找对那个“容”的位置，让气有地方可容，就够了。
