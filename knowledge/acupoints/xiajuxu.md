# 下巨虚

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经，为小肠之下合穴。倪师在《人纪·针灸篇》中讲得明白——**合穴治腑病**，小肠的毛病，取小肠经的合穴小海，但更常用的是下巨虚，因为「合治内府」，下巨虚就是小肠之气下合于足阳明经的部位。倪师原话的意思是：小肠有东西堵到了，腹大、腹痛，就在下巨虚上治。

- **五输穴属性**：下巨虚本身是胃经的穴位，在上巨虚之下。倪师讲足三里、上巨虚、下巨虚、条口这一线时说得非常直白——**足三里是胃经的合穴**，属土，是胃经的本穴；上巨虚是大肠的下合穴；下巨虚是小肠的下合穴。这几个穴从上到下排列，分管不同的腑。所以下巨虚不是胃经自己的五输穴，它是**小肠经气下合于胃经**的特定穴，专门治小肠。

- **倪师动态取穴法**：
    - **骨度折量**：外膝眼（犊鼻）下三寸是足三里，足三里下三寸是上巨虚，**上巨虚再下三寸就是下巨虚**。倪师取穴从来不是拿尺子量，他的方法是——先找到足三里。怎么找？病人正坐，膝盖弯起来，从外膝眼往下摸，摸到胫骨外侧，离胫骨一寸都不到的那个凹窝，按下去很酸很胀，那就是足三里。找到足三里之后，手指往下比三个同身寸，再找到上巨虚；再往下三个同身寸，就是下巨虚。倪师特别强调：**同身寸以病人的手指为准**，不是医生的手指。高矮胖瘦不同，寸不一样。
    - **骨度分寸**：犊鼻至外踝尖为十六寸。犊鼻下三寸足三里，下六寸上巨虚，下九寸下巨虚。倪师也讲，你找得到足三里，就找得到下巨虚，它们在同一条线上，**贴着胫骨外缘往下摸**，指下会有凹陷感。
    - **下针深度**：倪师讲，下巨虚针下去，**一寸到一寸半**。这条线上的穴位，针下去要贴着胫骨后面走。倪师的原话大意是，你针足三里、上巨虚、下巨虚，**针尖要稍微往后，贴着骨膜**，不要往前面扎——前面是胫骨前肌，扎太前面了效果不好，要贴着胫骨后缘下去，针感会很强。
    - **禁针禁灸**：下巨虚没有特殊的禁针禁灸。倪师讲，**孕妇禁针**足三里、上巨虚、下巨虚这一线，因为这条线动了会动胎气。平常人针深一寸至一寸半，没有危险。灸的话可以灸，但小肠的问题一般用针不用灸，因小肠为火腑，灸了反而助热。

## ⚡ 倪师经穴气化与破局心法

- **气化机理——小肠下合，分清泌浊**：
    倪师讲，小肠者，**受盛之官，化物出焉**。小肠的功能是把胃里腐熟过的食物再进一步消化，然后**分清泌浊**——清的（营养）交给脾去运化，浊的（糟粕）传给大肠，水液渗入膀胱。所以小肠一旦出问题，会出现两个方向：一是**腹痛、腹胀、肠鸣**，因为东西堵在小肠里不走了；二是**大小便异常**，因为分清泌浊的功能乱了。倪师讲下巨虚，就是从**小肠的气化**入手——小肠的募穴在关元，小肠的背俞在关元俞，但你要**直接调小肠的蠕动和分清泌浊**，就用下巨虚。足三里管胃，上巨虚管大肠，下巨虚管小肠，三个穴合起来把整个消化道从胃到小肠到大肠全部管住。这就是倪师讲的**合穴治腑**的精神。

- **倪师的开阖推演**：
    小肠是火腑，心与小肠相表里。倪师讲，心脏的火要下行到小肠，靠的是什么？靠的是**肾水把心火导下来**。如果心火下不来，小肠的温度就不够，小肠冷了，东西就化不掉。下巨虚在小肠的下合穴上，针刺能**引心火下达小肠**，恢复小肠的火力。倪师特别讲，小肠有火，才能把食物煮熟；小肠没火，吃下去的东西就停在那边。所以下巨虚这个穴，表面上是治小肠，实际上是在调**心火下达、小肠受热**这个循环。

- **子母补泻与五行生克**：
    下巨虚是胃经上的穴，胃经属土。小肠经属火。倪师讲子母补泻，要回到小肠经本身的五输穴上——小肠经的井穴少泽属金，荥穴前谷属水，俞穴后溪属木，经穴阳谷属火，合穴小海属土。小肠经属火，火生土，所以**小海是子穴**；木生火，**后溪是母穴**。小肠虚证补后溪，小肠实证泻小海。但下巨虚作为小肠的下合穴，倪师讲它的用法是**不论虚实，腑病皆可取**。实证——小腹硬满、肠鸣腹痛，针下巨虚泻之；虚证——小腹冷痛、消化不良，针下巨虚配合灸关元补之。倪师说，**合穴治腑，腑病没有补泻之分，把腑气通了就是补**。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
    - **小肠疝气**：倪师讲，小肠坠下来，掉到阴囊里，就是小肠疝气。这个病很痛，取**下巨虚配关元、大敦**。下巨虚针下去，关元灸，大敦放血，这是倪师的急症组合。
    - **小腹痛、肠鸣**：肚脐周围痛，咕噜咕噜响，食物不消化，下巨虚针下去，**小肠的蠕动马上就恢复**。倪师说，你针下去，病人会感觉到肚子里面在动。
    - **痢疾、腹泻**：小肠分清泌浊的功能出问题，水液不走膀胱而直接排出去，就是下利。倪师讲，下巨虚配**足三里、天枢**，把肠胃的功能一起调回来。
    - **下肢痿痹、脚痛**：下巨虚在腿上，倪师也用它治**脚无力、足不收**。因为胃经主宗筋，阳明经多气多血，下巨虚在阳明经上，针之能**强下肢**。
    - **乳房胀痛**：倪师在讲乳房硬块时提到，阳明经经过乳房，下巨虚作为阳明经的穴，能**引气下行**，配合肩井、足三里，可以通乳房的气血。

- **倪师经典对穴与排针组合**：
    - **下巨虚 + 关元 + 大敦**：治小肠疝气。关元是小肠募穴，灸之温小肠；大敦是肝经井穴，放血止痛；下巨虚直接通小肠腑气。
    - **下巨虚 + 足三里 + 上巨虚**：三穴同下，倪师叫**通肠三针**。足三里管胃，上巨虚管大肠，下巨虚管小肠，整个消化道一起调。腑气不通、腹胀如鼓，这一组针下去，病人的肠子就开始转了。
    - **下巨虚 + 天枢 + 中脘**：天枢是大肠募穴，中脘是胃募穴，加上下巨虚，**腹三针**，治一切腹痛、腹胀、消化不良。
    - **下巨虚 + 公孙 + 内关**：公孙配内关治胃心胸，下巨虚加强小肠的分清泌浊，对**肠鸣、水泻**有特效。
    - **下巨虚 + 三阴交**：三阴交管脾肝肾三经，下巨虚管小肠，一阴一阳，**调理下焦气机**，治小腹冷痛、妇科腹痛。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原味金句**：
    倪师在讲足三里、上巨虚、下巨虚这一线时，原话大意是：「足三里下来三寸，叫上巨虚；再下来三寸，叫下巨虚。**上巨虚是大肠的下合穴，下巨虚是小肠的下合穴**。所以你有大肠的问题，针上巨虚；有小肠的问题，针下巨虚。那你说，我怎么知道是大肠还是小肠？肚脐以下、关元附近痛，多半是小肠；肚脐两旁、天枢附近痛，多半是大肠。**小肠的病，关元穴会有压痛；大肠的病，天枢穴会有压痛**。你找到痛点，再决定扎上巨虚还是下巨虚。」

- **实战手下针感**：
    倪师讲，下巨虚针下去，**针感会往脚上走**，病人会觉得脚踝那边酸胀。如果针感往上走，走到膝盖，那也有效，但倪师说，这条线的穴位，气往下走的多。针下巨虚时，**要贴着胫骨后缘进针**，不要扎到胫骨前肌里面去。针到一寸半的时候，病人会有**肚子里面咕噜响**的感觉，那就是气到了。

- **医案故事**：
    倪师讲过一个案例，大意是：一个病人小腹硬满、痛得不能碰，西医说是肠梗阻，要开刀。倪师一看，**关元穴压痛明显，天枢穴压痛不明显**，判断是小肠的问题。急针**下巨虚、关元、足三里**，针下去不到二十分钟，病人放了一个长屁，肚子就松了。倪师说，**小肠的气一通，病就去掉了**。他又讲，你们不要小看下巨虚，这个穴专门管小肠，小肠是受盛之官，东西堵在那里，针下巨虚**就是给小肠一个信号，让它动起来**。他还补了一句，这种急症，**针比药快**，你们学针灸，就是要学这种**一针下去、气机立转**的本事。

- **倪师的特别提醒**：
    下巨虚和内关、公孙不一样，内关公孙是**调气**的，下巨虚是**通腑**的。腑病要通，不能补。倪师讲，你针下巨虚，**不要用补法**，用平补平泻，甚至泻法，让腑气通下去就对了。还有一点，下巨虚和条口很近，条口在下巨虚下面一寸左右，倪师讲，**条口治脚无力、脚麻**，下巨虚治小肠，两个穴不要搞混了。
