# 巨骨

## 📍 经络归属与精准取穴法

- **所属经络**：手阳明大肠经。巨骨为手阳明大肠经与阳跷脉之会穴（《针灸大成》归为手阳明、阳跷脉之会）。倪师在讲大肠经时特别指出，手阳明经从合谷一路往上，经曲池、肩髃，再上就是巨骨，然后交会于大椎，再入缺盆。所以巨骨穴正好卡在肩髃与缺盆之间的肩峰端，是大肠经经气从肩臂向颈项躯干过渡的“关隘”。

- **穴名释义与定位**：巨骨，顾名思义，就是“巨大的骨头”。你摸自己的肩膀，肩胛骨外端与锁骨外端之间那个最高最突起的大骨头，就是肩峰。巨骨穴就在这个肩峰与锁骨肩峰端之间的凹陷里。倪师取穴从来不讲“寸”，他讲“你就沿着肩髃往上摸，摸到肩头最高骨头的缝缝里，那个大骨头的缺口，就是巨骨”。通俗讲：手臂自然下垂，肩膀头最高点往脖子方向摸，摸到骨头之间的那个大凹陷，按下去酸胀感直窜脖子，那就是巨骨。

- **下针深度与手法**：倪师在《人纪》里讲到这个穴时专门叮嘱——**巨骨禁深针，直刺不可超过五分**。怎么下？要**沿着肩峰内缘斜刺**，针尖朝向颈部方向，进针三到五分即可。为什么不能深？因为下面就是肺尖。倪师原话意思很明白：你扎太深，扎到肺，就是气胸，那是要出人命的。所以这个穴，倪师的手法就是“浅刺、斜刺、不留针久”，得气即止，引气到肩颈即可。

- **禁灸与否**：《针灸大成》载巨骨“禁针，灸三壮”，但倪师在临床上并不完全拘泥于此。倪师认为这个穴用灸法，是针对**肩颈寒气凝结、手臂抬不起来**的虚寒证，灸壮如米粒，三五壮足矣，不可多灸，多灸则燥，燥则引火上肩，反而导致肩颈僵痛加重。属于“可灸不可多灸，可针不可深针”的穴位。


## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师讲大肠经的循行时反复强调——大肠经的经气从商阳（井金）一路走到曲池（合土），再到肩髃，然后**在巨骨这个位置有一个“关节式”的气机转换**。巨骨是大肠经与阳跷脉的交会点，阳跷脉主一身左右之阳气的动静。所以巨骨穴的气化机理，倪师概括为八个字：**“通阳跷、利肩项、开胸膈”**。它就像是肩膀这个“大门”的转轴，阳气要从这里过，如果这里堵住了，肩抬不起来、脖子转不动、气上不了头面。

- **倪师破局心法——从“气机卡在肩缝”讲起**：倪师说，五十肩、肩周炎、肩膀抬不起来，很多时候不是肩膀本身的骨头坏了，是**气在巨骨这里卡住了**。就像水管在拐弯的地方最容易堵。巨骨就是大肠经经气从手臂上行入体的那个“拐弯处”。你在这里浅刺一针，再用阳跷脉的道理一引，气就过去了，肩膀就松了。

- **五行生克运用**：大肠经五行属金（手阳明庚金），巨骨本身不是五输穴（五输穴为商阳、二间、三间、阳溪、曲池），所以**子母补泻不直接作用于巨骨本身**。但倪师在临床上有个变通心法：如果病人是**大肠经虚证**（肩臂无力、麻木、抬举不能），他会在巨骨浅刺后，再取**曲池（合土，土生金，为母穴）** 补之，这是“虚则补其母”；如果是**大肠经实证**（肩颈红肿热痛、拒按），则在巨骨用泻法（针尖向外、摇大针孔），再取**二间（荥水，金生水，为子穴）** 泻之，这是“实则泻其子”。巨骨在这里的作用是**引气到关隘**，母穴或子穴才是真正补泻的开关。

- **与阳跷脉的深层联动**：倪师特别看重巨骨是阳跷脉的交会穴。阳跷脉从足跟外侧起，循外踝上行，过肩，上颈，入脑。所以巨骨一穴，不单单治肩膀，还能**治阳跷脉的病**——比如癫痫白天发作、目不得闭、下肢外侧拘紧无力。倪师说，阳跷脉病，你在巨骨上做文章，比在脚上去摸，效果来得快，因为这里是阳跷脉上行入脑的“咽喉要道”。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：

  1. **肩臂痹痛、五十肩、肩关节抬举不能**——这是巨骨的第一号主治。倪师说，肩髃治肩前，巨骨治肩上，两个配在一起，整个肩关节的前上后都松开了。
  2. **颈项强痛、落枕、脖子转不过去**——巨骨在大肠经上，大肠经“从缺盆上颈”，所以肩颈问题取巨骨，引气到颈，脖子就柔了。
  3. **瘰疬、瘿瘤（甲状腺肿大、淋巴结结核）** ——巨骨靠近缺盆，能开胸膈、散结气。《针灸大成》主“惊痫、吐血、肩臂不得屈伸”。倪师在讲瘿瘤时提到，肩颈这一带的穴位，巨骨、肩髃、天突，配起来用，能引郁结之气下行。
  4. **吐血、胸膈瘀血**——这是《针灸大成》记载的巨骨主治。倪师说，这是因为巨骨能通阳跷、开胸膈，胸膈一开，瘀血自然下行。
  5. **阳跷脉病：癫痫白日发、目不得闭**——配申脉、照海，调阴阳跷脉。

- **倪师经典对穴与排针组合**：

  - **巨骨 + 肩髃 + 曲池**：治一切肩臂痛。针序是肩髃先针，巨骨次之（浅刺），曲池最后（深刺引气下行）。倪师说这叫“上引下导”，气从肩到肘到手，一条线就通了。

  - **巨骨 + 大椎 + 后溪**：治颈项强痛、落枕。大椎是阳气之会，后溪通督脉，巨骨引大肠经气到颈，合起来脖子就松了。

  - **巨骨 + 缺盆 + 天突 + 膻中**：治瘿瘤、胸膈满闷。这是倪师用来“开胸散结”的组合，巨骨在上引气，膻中在中调气，天突在喉咙通利，缺盆在局部散结。

  - **巨骨 + 合谷 + 太冲（开四关）** ：治全身气机郁滞、肩膀僵硬连及全身。四关开气血，巨骨松肩关，这是上下配合的排针法。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲手阳明大肠经走到肩部这一段时，关于巨骨，原汁原味的讲法是这样的：

> “肩髃再上去，就是巨骨。这个大骨头，你摸肩膀头，有个大骨头突起来的，骨头和骨头中间的缝，就是巨骨。这个穴，**禁深针**。你针下去五分，就够了。为什么？下面就是肺啊。你扎一寸，扎到肺，病人当场咳血，气胸，那是你的事。所以这个穴，我只做引气用，斜刺，针尖对着脖子方向，浅浅一针，得气就出针。”

讲到五十肩的时候，倪师的实战体会是：

> “五十肩，手抬不起来，你光扎肩髃不够。你要加巨骨。你知道为什么？因为气卡在肩缝里出不去。巨骨就是那个缝。你在这里浅刺一针，像开锁一样，‘咔’一下，气过去了，肩膀就松了。病人当场说，哎呀，轻松了。你试试看。”

讲阳跷脉的时候，倪师又提到巨骨：

> “阳跷脉从脚上来，过肩，上头。巨骨是阳跷脉的交会穴。所以癫痫白天发作的，你可以在巨骨上做文章。还有，眼睛张不开的，白天想睡睡不着的，阳跷脉的问题，巨骨都可以帮忙。”

关于禁针禁灸的实战态度：

> “书上写巨骨禁针，那是古代。古代针粗，你现在针细，浅刺五分，没事。但是你不能深，深了就是气胸。灸可以，三五壮，米粒灸，肩膀冷的，灸一灸，很舒服。但你灸多了，火气上来，肩膀反而痛。所以什么东西都是——中病即止。”
