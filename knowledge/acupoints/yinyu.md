# 殷门

## 📍 经络归属与精准取穴法

殷门穴，归属于**足太阳膀胱经**。在倪海厦先生的五输穴子母补泻体系中，殷门并非井荥俞经合五输穴，也非原穴、络穴、郄穴、募穴、背俞穴或八会穴，它是膀胱经在承扶与委中之间的**经气转输大穴**，性质上偏于**通络行滞、舒筋利节**。但从气血循行角度看，殷门所处的位置非常关键——它坐落在**大腿后侧正中，承扶下六寸**，正是膀胱经经气自臀部下注腘窝的**中枢通道**，所以倪师在讲下肢挛急、腰背痛连腿的病机时，常把殷门当作**开阖枢机中的“转关”**来用。

倪师动态取穴法，大白话讲：

**怎么摸骨找穴？** 让病人**趴着**，大腿后侧正中线。你先找到**承扶穴**——就是臀部下缘、臀横纹正中间那个点。从承扶往下量**六寸**，就是殷门。六寸怎么折？倪师讲骨度分寸，从**承扶到委中**一共是**十四寸**，殷门在承扶下六寸，也就是承扶到委中连线的**靠近上三分之一处偏上**。你不要死记六寸，用手去摸：病人大腿后侧肌肉最丰厚、最鼓的地方，正中间那条缝，**按下去酸胀感往膝盖方向窜的**，那就是殷门。

**下针深度：** 倪师讲，殷门穴**直刺，针一寸到一寸五分**。大腿后侧肌肉厚，你扎浅了在脂肪层没感觉，扎到**肌肉层中间**，病人会有酸、麻、胀，有时候**像电一样往委中或往臀部窜**，那就是得气了。殷门**不灸**，为什么？膀胱经这条线本来就是**多气多血之经**，殷门位置又深，灸了容易**助热**，导致**局部红肿**，反而坏事。倪师反复强调：**殷门禁灸，只针不灸**。还有，**这条经络靠近坐骨神经**，你下针不要乱捻转，**直进直出，得气即止**，不要猛捣，否则病人腿会麻半天。

## ⚡ 倪师经穴气化与破局心法

倪师推演殷门的气血流注，把它放在**膀胱经“从臀走腿”的气化链条**里看。膀胱经主**一身之表**，太阳经气从头顶沿后背下行，过了**承扶**之后，经气要**穿过大腿后侧厚厚的肌肉层**，才能到达腘窝的**委中**。殷门正好在这个通道的中点。倪师说，**殷门就是膀胱经经气在腿部肌肉中的“关隘”**。如果这个关隘堵住了，经气下不去，就会出现**大腿后侧牵拉痛、腰背痛放射到腿、膝盖后侧拘紧**。所以殷门的气化机理，倪师归纳为八个字：**通经透络，舒筋利节**。它不是补穴，也不是泻穴，它是一个**“开关穴”**——你把它打开，经气就过去了。

子母补泻怎么用？殷门本身不参与五输穴生克，但倪师心法里有一条：**殷门可以配合委中（合穴，属土）和委阳（三焦下合穴）来做“母子协同”**。膀胱经属水，委中属土，土克水，所以委中是膀胱经的**“实邪泻穴”**。当腰腿痛属于**实证、热证、拘挛不能屈伸**时，倪师会在委中放血，然后**在殷门上下针**，引经气下行，这叫**“泻子开母”**——委中泻实，殷门开道，让邪有出路。反过来，如果是**虚证、酸软无力、腿抬不起来**，倪师会用**肾俞、关元补气**，再针**殷门**，这叫**“补母启关”**——肾水足了，殷门一开，经气才能灌到腿上去。

## 🎯 临床主治与配穴组合手印

殷门的核心特效主治，倪师在临床上主要抓这几条：

**第一，大腿后侧连及腰背的牵掣痛、坐骨神经痛。** 这是殷门最拿手的。病人一来，说**腰不舒服，痛一直串到屁股、大腿后面、甚至到脚**。倪师常常**先针殷门，再针委中**，然后让病人**慢慢活动腰腿**，很多病人当场就觉得**松了**。

**第二，膝盖后侧拘挛、腘窝紧痛、不能屈伸。** 殷门下针，气往委中走，委中一放血，**膝盖后面那根大筋就松开了**。

**第三，下肢痿软无力、肌肉萎缩。** 这种虚证，倪师会用**殷门配足三里、三阴交**，先补脾胃，再开殷门，让气血能灌到腿上去。

倪师经典对穴与排针组合：
- **殷门 + 委中**：治腰背痛连腿、坐骨神经痛。殷门开道，委中泻实放血。
- **殷门 + 承扶 + 环跳**：治臀部连大腿后侧痛。环跳是少阳太阳交会，承扶是膀胱经臀部大穴，殷门是通道，三针一排，**从臀到腿一条线打通**。
- **殷门 + 足三里 + 三阴交**：治下肢痿软、肌肉萎缩。足三里补胃气，三阴交补三阴，殷门引气血下行。
- **殷门 + 肾俞 + 命门**：治肾虚腰痛连腿。先补肾俞命门，再针殷门，这叫**“补火生土，开道通经”**。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在视频里讲殷门的时候，原话我记不太全了，但意思我给您还原出来：

**“殷门这个穴，你趴着取，承扶下六寸。你不要拿尺子量，你用手去摸，大腿后侧最厚的那块肉，正中间，一按，病人‘噢’一声，那就是殷门。针下去，一寸半，得气就停。这个穴专门治什么？治腰背痛痛到腿上去，大腿后面像有一条筋扯着，你针殷门，再针委中，委中放几滴血，病人当场就松了。记住，殷门不灸，只针。为什么？膀胱经本来就多血，你一灸，血热妄行，腿肿起来，你还要收拾。还有，殷门不要深刺，不要乱捻，你扎到坐骨神经，病人腿麻三天，你不好交代。”**

倪师还讲过一个医案：一个五十多岁的男人，**腰痛了十几年，痛一直串到左脚**，西医说是**坐骨神经压迫**，准备开刀。倪师一看，**舌苔白厚，脉沉紧**，这是**寒湿堵在膀胱经**。他**先针殷门，再针委中，委中放血**，然后**针肾俞、命门，加灸**。病人第一次针完，**腰就能弯了**，腿也不那么扯了。倪师说，**殷门就是膀胱经在腿上的“闸门”**，闸门一开，寒湿才有路走。你这个闸门不开，只在腰上扎，气下不去，病怎么会好？

还有一点，倪师强调：**殷门下针，针感要往两个方向走**——**往上走到承扶，往下走到委中**，这才叫**气至病所**。如果病人只说**局部酸**，那说明经气没通，你要**轻轻提插一下**，引气下行。但**不要反复提插**，一次得气就够了。
