# 肩外俞

## 📍 经络归属与精准取穴法

- **所属经络**：手太阳小肠经。肩外俞是手太阳小肠经在肩背部的腧穴，位于肩胛区。
- **特定穴属性**：肩外俞不属于五输穴（井荥输经合）、原穴、络穴、郄穴、募穴、背俞穴、八会穴中的任何一类。它是手太阳小肠经在肩胛骨内侧缘的特殊定位穴，与肩中俞并列，一外一内，分别对应肩胛骨外缘与内缘的气血转输。
- **倪师动态取穴与骨度折量法**：
  倪师讲，肩外俞的找法，你首先叫病人正坐或者俯卧，手自然下垂。先找到第七颈椎，也就是大椎穴。大椎往下数，第一胸椎棘突下就是陶道。再从陶道旁开三寸——注意，是三寸，不是一寸半——这个位置就是肩外俞。肩中俞呢，是旁开两寸，在肩外俞的内侧。你要分清楚，肩中俞和肩外俞差一寸，一个靠脊柱近，一个靠脊柱远。肩外俞再往外就是肩胛骨的外缘了。
  **下针深度**：倪师说，这个地方是肩胛骨上方、脊柱旁开的肌肉层，一般斜刺或直刺五分到一寸。不要太深，深了容易扎到肺尖。**禁灸**：肩外俞一般不灸，因为靠近肺尖区域，灸法容易引热入肺，原则上禁灸或者慎灸。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师讲，肩外俞在小肠经上，小肠属火，与心相表里。这个穴的位置在肩胛骨外上方，正是小肠经气血从颈部向肩胛、上肢转输的关口。肩外俞的气化机理，关键在于**通阳散结、宣痹开肩**。小肠经的阳气从这里向外布散到肩胛和上臂，如果这里堵住了，肩背就僵硬、酸痛，手臂抬不起来。
  倪师特别强调，肩外俞靠近肺尖，肺主气，小肠经的阳气要借肺气的宣发才能布达肩背。所以肩外俞有**宣肺气、通小肠、利肩背**的三重作用。临床上肩背冷痛、脖子转不动、落枕、肩周炎，都取肩外俞来开肩破结。
- **子母补泻与五行生克运用心法**：小肠经属火，五行中火生土，土为火之子。小肠经的母穴是后溪（木穴，木生火），子穴是小海（土穴，火生土）。肩外俞本身不是五输穴，没有直接的子母补泻属性。但倪师讲，你在肩外俞上下针，实际上是在调小肠经整条经的气血。虚证——肩背酸软无力、手臂发麻——你配合补后溪；实证——肩背红肿热痛、脖子硬得像石头——你配合泻小海。这就是子母补泻在肩外俞上的活用。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **肩背酸痛、肩胛区疼痛**——肩外俞的第一大主治。尤其是肩胛骨内侧缘到外侧缘这一片的酸胀、刺痛，针肩外俞立减。
  2. **落枕、颈项强痛**——脖子转不过去，不能回头，肩外俞配天柱、大椎。
  3. **肩周炎、手臂不能上举**——肩外俞透肩中俞，再配肩髃、肩髎，肩膀就松了。
  4. **肺炎、咳嗽、气喘**——肩外俞靠近肺尖，能宣肺气。倪师说，肺的问题在肩背有反应点，肩外俞就是其中一个。
- **倪师经典对穴与排针组合**：
  1. **肩外俞 + 肩中俞**：一外一内，同时下针，专治肩胛骨内侧缘的酸痛，像背了一块石头一样的感觉，这两针下去就松了。
  2. **肩外俞 + 大椎 + 天柱**：治落枕、颈项强痛。大椎通阳，天柱利颈，肩外俞开肩，三针一排，脖子就转得动了。
  3. **肩外俞 + 肩髃 + 肩髎 + 曲池**：治肩周炎、手臂不能上举。这是倪师治肩的“四大金刚”排针法，肩三针加曲池，再配肩外俞加强开肩之力。
  4. **肩外俞 + 肺俞 + 膻中**：治咳嗽、气喘、胸闷。肩外俞宣肺，肺俞补肺，膻中理气，三穴合用，胸肺就开了。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：
  倪师在讲肩外俞的时候说：“肩外俞，你看这个名字，肩的外面嘛。这个穴道呢，你摸上去，在肩胛骨上面，脊柱旁开三寸。你下针的时候，不要直直地扎进去，稍微斜一点，往肩胛骨的方向斜刺。针下去，病人会有一种酸胀感，像电流一样往肩膀外面走。这是气到了。”
  “肩外俞和肩中俞，一个在外一个在内，你这两个穴道一起用，肩胛骨的酸痛啊，当场就去掉大半。我常常讲，肩背的问题，你不要只盯着肩膀头，肩胛骨内侧缘才是关键。肩外俞就是管这一片的。”
  “这个穴道呢，靠近肺尖。你下针不要太深，也不要灸。肺是娇脏，你一灸，热就进去了，病人会咳得更厉害。所以肩外俞，我们只针不灸。”
- **实战手下针感体会**：
  倪师说，肩外俞下针，针尖要稍微朝外斜刺，针到五分到一寸。病人会有一种酸麻胀的感觉，从肩胛骨向手臂外侧放散。如果病人说“像有东西在肩膀里面爬”，那就是气至了。这时候你再配合提插捻转，虚实补泻，效果最好。
- **医案故事**：
  倪师讲过一个个案。有个病人，肩膀痛了半年，手臂抬不起来，晚上痛得睡不着。倪师一看，肩胛骨内侧缘一条线都是硬的，像一条钢筋。倪师先取肩外俞、肩中俞，再配肩髃、肩髎、曲池。针下去，病人说肩膀里面“咔嚓”一声，像什么东西松开了。留针二十分钟，起针后，病人手臂当场就能抬起来了。倪师说：“这就是肩外俞的威力。你不要小看这一个穴道，肩胛骨的问题，它专门管。”
