# 交信二

## 📍 经络归属与精准取穴法

- **所属经络**：足少阴肾经。交信是**阴跷脉的郄穴**。郄穴者，气血深聚之处，主急性痛症与血症。倪师常言：郄穴是炎症、急痛、出血的“开关”，下针立效。
- **穴名释义**：交信。“交”者，交会也，阴跷脉与肾经在此交会；“信”者，信约也，喻气血出入有信、按期而至。此穴即肾经与阴跷脉之气相交相通的关卡。
- **精准定位**：内踝尖直上二寸，胫骨内侧缘后方。先摸到内踝最高骨尖，沿胫骨内侧面往上推，推过三寸是三阴交，二寸就是交信。它在三阴交的下方，紧贴胫骨后缘的缝隙里。
- **倪师动态取穴法**：从内踝尖往上量二寸（用患者本人的同身寸，即中指第二节横纹间距为一寸），按到胫骨内侧缘，手指往骨头后方一滑，滑入骨与筋之间的凹陷处，按压有明显的酸胀感，这就是交信。不要按在胫骨面上，要贴着骨后缘取穴。
- **下针深度**：直刺或略向后斜刺，**五分到八分深**。针尖贴着胫骨后缘进针，得气后局部酸胀，有时会向足底或小腿内侧放散。
- **禁针禁灸**：此处无特殊禁针。灸法可灸三壮至五壮，但倪师强调：**阴跷脉的郄穴，偏于血分，实证热证以针泻为主，不宜多灸**；虚寒崩漏方可温灸。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：交信是阴跷脉的郄穴，阴跷脉起于照海，沿内踝上行，主一身左右之阴气。交信就是阴跷脉气与肾经经气在此“交信”的关口，郄穴又主血分。所以此穴的核心机理是：**调理下焦血分、固摄阴跷、约束经血**。倪师讲：阴跷脉管的是“阴”的开关，交信就是开关上的锁扣，下针等于把这个锁扣拧紧，血就不会乱跑。
- **气化功能**：肾主水，主封藏，主生殖。交信通过阴跷脉与肾经的双重联系，能把下焦的水湿与血浊分开：该利的水从小便走，该固的血不外溢。倪师推演此穴为**“调经止漏、通利下焦”**的破局点。
- **子母补泻与五行生克**：交信属足少阴肾经。肾五行属水，肾经母穴是复溜（金生水），子穴是涌泉（水生木）。交信本身不是五输穴，但它是阴跷脉的郄穴。倪师心法：**郄穴治急，不分母子，直接开合**。若崩漏急性发作，取交信先止其血，再配复溜补其母以固本；若小便急痛、淋涩不通，取交信泻其急，再配涌泉泻其子以通利。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **妇科血症**：月经不调、崩漏、经血淋漓不断。倪师说交信配三阴交、血海，是止崩漏的“三针定血”组合。
  - **下焦湿热/淋症**：小便淋涩、尿频尿急、阴部肿痛。交信配中极、膀胱俞，通利下焦。
  - **腹泻/痢疾**：大便脓血、里急后重。郄穴止急，交信配天枢、上巨虚。
  - **下肢内侧痛**：小腿内侧酸痛、足内踝肿痛。交信配太溪、照海，疏通局部经气。
- **倪师经典对穴与排针组合**：
  - **交信 + 三阴交 + 血海**：治一切妇科出血症。三阴交统调三阴，血海引血归经，交信锁住阴跷的“开关”，三针齐下，血止而经调。
  - **交信 + 照海 + 列缺**：照海通阴跷，列缺通任脉，交信锁阴跷之郄。治咽喉干痛、阴虚火旺、夜不能寐。
  - **交信 + 太冲 + 合谷**：开四关再加交信，治下焦气滞血瘀引起的痛经、少腹痛。太冲合谷开气血之关，交信引气至下焦血分。
  - **交信 + 复溜**：补肾固本，治肾虚腰痛、下肢萎软。复溜补母，交信调郄，一补一调，肾气自复。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原话金句**：“交信这个穴，是阴跷脉的郄穴。郄穴是什么？就是气血最深的地方。你把它想成一口井的井底，平时水藏在底下不露，一旦急症来了，就是井底的水翻涌上来了。交信就是井口的那个盖子，你针一下去，盖子一盖，水就稳了。”
- **手下针感体会**：“针交信，针尖要贴着胫骨后缘进去。你进去以后，病人会感觉酸胀往脚底下窜，有时候会像触电一样往脚心走。为什么？因为阴跷脉从这里一路通到照海、通到脚底。你得气以后不要马上捻针，先守气，让气自己走到脚底去，再轻轻提插，那个血就止住了。”
- **医案故事**：倪师讲过一个案例——某妇人崩漏三月不止，西医刮宫两次仍复发。倪师取交信、三阴交、血海，交信用泻法，针入八分，得气后患者自觉小腹一紧，当天血量减半，三诊而止。倪师说：“交信是阴跷的郄穴，郄穴治急，这笔账要算在阴跷脉上。阴跷管的是阴血的开关，你把开关拧紧了，血自然就归经了。”
- **针灸秘要**：倪师强调，交信与复溜只差一寸，但功用天壤之别。复溜是肾经的母穴，补虚固本；交信是阴跷的郄穴，治急调血。**急症取交信，虚症取复溜**，这是倪师临床的不传之秘。
