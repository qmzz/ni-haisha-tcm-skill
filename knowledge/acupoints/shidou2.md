# 食窦二

## 📍 经络归属与精准取穴法

- **所属经络**：足太阴脾经。食窦穴在胸外侧，天溪下一寸六分。倪师在《人纪·针灸篇》讲脾经时明确讲过，胸乡、天溪、食窦这一排穴道，统统是**脾经的大络**，散布在胸腔侧面。它不与五输穴的井荥输经合直接挂钩，也不属于原、络、郄、募、背俞、八会那一套特定穴体系——它是脾之大络向胸胁布散的气化窗口，走的是"**从阴引阳、从胸走胁**"这条路子。

- **倪师动态取穴与骨度折量法**：倪师原话的意思是这样——你先找到**天溪**，天溪在乳头外开二寸。从乳中往外量两寸是天溪，从天溪再往下**一寸六分**就是食窦。倪师特别交代：**一寸六分不是一个死板死数**，你要按病人体型来折。肋间隙宽的人，一寸六分可能要稍微多一点；瘦人肋骨一根根清楚，你就贴着肋间隙取。实际上食窦落在**第五肋间隙**附近，你摸到乳头下一根肋骨，再往下数，在肋间按进去，病人会有酸胀感直往胸胁深处走，那才是食窦真正的穴点。**不要拿尺子死量**，要沿着肋骨间隙去切。

- **下针深度与禁针禁灸**：倪师反复强调，胸部的穴道**一律斜刺、沿皮刺**，绝对不可直刺。食窦下针，针尖要顺着肋骨方向**斜刺或平刺**，深度控制在**三分到五分**，贴着肋间隙浅层下，把气引到胸胁侧面来。因为胸腔里有肺，你直刺深刺就是气胸，倪师讲这一段时非常严肃。灸法上，食窦可灸，但倪师说他临床上**这个穴很少用灸**，因为胸胁部位艾火容易熏灼，他更倾向于针后加一点温和的导引，让胸胁的气自己散开。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师推演食窦的气化，核心一句话——**脾之大络，从胸布胁，主行水散结**。脾主运化，脾的大络从大包出来，散布胸胁，食窦就是这个布散网络上的一个节点。所以它的开阖机理是：**脾不能运化，水湿就停在中焦，中焦一堵，胸胁的气就闷在那里，病人就会觉得胸胁胀满、咳逆、喘、甚至胸痛彻背**。食窦的作用就是把脾的大络这一段打开，让停在中焦的水湿有出路，让胸胁的气重新流通。倪师说这个穴有点像"**胸胁部的下水道口**"，你不通它，水湿就漫上来。

- **子母补泻与五行生克**：食窦不是五输穴，本身没有子母补泻的直接属性。但倪师在讲脾经整体气化时说了——**脾经的补泻要看它跟胃经的表里关系，和跟心经的生克关系**。食窦用针，方向上偏于**泻**，因为它治的是胸胁胀满、气结、水停，邪气实的时候要开、要散。什么时候用补？当病人脾虚日久，胸胁虽然没有大实邪，但气短、胸胁隐隐不舒服、咳声无力，这时食窦可以配合脾经的母穴（大都）一起用，**先补大都，再浅刺食窦导气**——虚则补其母，母气足了，食窦这个络脉口才有气可布。倪师的意思很实在：**食窦不单独论补泻，它看的是脾经整体的虚实大局**。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：食窦这个穴，倪师讲义里讲得最重的是三条。第一，**胸胁胀满、胸痛彻背**——脾的大络堵住了，病人感觉胸胁这一圈绷得紧，甚至痛到后背去。第二，**咳逆、气喘、痰多**——脾为生痰之源，食窦开了，痰湿有出路，喘就缓。第三，**食入即吐、翻胃、噎膈**——脾胃的气机在胸膈这里过不去，食窦能把这个关卡打开。此外，**乳痈、乳腺增生、产后缺乳**这类乳房周围的病，食窦配合天溪、膺窗，效果来得很快，因为脾之大络布散胸胁，乳房正在它的覆盖范围之内。

- **倪师经典对穴与排针组合**：
  - **食窦 + 大包**：脾之大络的**根与梢**同用。大包是总络，食窦是分支口，两个一起下，胸胁的气整个打开，治**全身重痛、胸胁大满**。
  - **食窦 + 公孙 + 内关**：公孙通冲脉、内关通阴维，管胃心胸。食窦在胸胁外面把络脉打开，公孙内关从里面调，**内外合击**，治**胸膈胀满、胃反酸、心口痛**。
  - **食窦 + 足三里 + 中脘**：这是倪师治**翻胃、食入即吐**的排针思路。中脘、足三里重建中焦的气化，食窦把胸膈的出口打开，气机就有上有下，呕吐就止。
  - **食窦 + 天溪 + 膻中**：治**乳痈、乳房胀痛**。膻中理上焦气，天溪食窦疏通脾之大络在胸胁的分支，让乳房的郁滞有路可退。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲到食窦这一段，语气是很平实的，他原话的意思大概是——**"食窦这个穴，你们不要小看它。脾经的大络布在胸胁，食窦就是这条络脉上的一个口子。胸胁胀满、咳逆、喘、翻胃，你在这个口子上轻轻一针，气就通了。针不要深，三分五分，斜着进去，贴着肋骨走，病人会感觉胸胁里面一阵酸胀散开，那就对了。"**

他还讲过一句很形象的话——**"脾为生痰之源，肺为贮痰之器。你光去肺上化痰，化不完的。你要在脾的大络上开口子，痰才有出路。食窦就是脾在胸胁上开的那个口子。"**

在临床手感上，倪师说食窦下针后，病人常会觉得**胸胁侧面有一条线往下窜，或者胸口原来闷着的地方突然松开**。如果病人咳得厉害，针完食窦再让他咳，往往痰声就松了，没那么紧。倪师用这个穴不贪多、不贪深，就是**浅刺、斜刺、留针时间也不长**，十来分钟就起针，让气自己走。他说胸胁的穴道，**像开窗户一样，开一下透气就好，不要拿针在里面搅**。
