# 阴廉

## 📍 经络归属与精准取穴法

阴廉穴，足厥阴肝经之穴。其在上肢不过肘、下肢不过膝以下的井荥输经合体系中，阴廉位于大腿内侧近端，已过膝关之上，属肝经在下肢循行于阴股部的重要腧穴。肝经五行属木，阴廉虽非井荥输经合之特定穴，但其位置紧贴足五里之上、急脉之下，介于阴股气街与冲门之间，是肝经气血从足部向上灌注腹腔的必经关隘。倪师在《人纪·针灸篇》中反复强调：**“肝经的穴道，从大敦一路往上，过了阴包、五里，到了阴廉这个位置，已经接近腹股沟了，这里的穴道开始跟腹腔、跟生殖系统发生直接关联。”**

**倪师动态取穴与骨度折量法：**

倪师讲骨度分寸，从不叫你死记“气冲穴下二寸”这种干瘪条文。他一定叫你动手去摸。阴廉的取法，倪师在课堂上讲得极直白：**“你叫病人躺着，腿稍微弯起来，大腿内侧你顺着肝经往上推，推到腹股沟那条大筋——就是耻骨结节旁边那条筋，筋的外侧、肌肉鼓起来的那条缝，就是阴廉。”**

具体操作：患者仰卧，下肢微屈，大腿外展。先定**气冲穴**（胃经，腹股沟动脉搏动处），再定**急脉穴**（肝经，气冲穴外下方，耻骨结节下缘旁开二寸半，按之有动脉应手）。在急脉之下、足五里之上的区域，于**耻骨结节下缘、长收肌与股薄肌之间的凹陷**中，按之有明显酸胀感处，即为阴廉。

倪师明言：**“足五里在阴廉下一寸，你从阴廉再往下一寸就是五里。所以你先找到五里，往上推一寸，就是阴廉。或者你从急脉往下推，推过那根大筋，碰到一个凹陷，病人会喊酸，那就是阴廉。”**

**下针深度：** 倪师说：**“阴廉这个地方，下面有大血管、有神经，你不要蛮干。一般针下去五分到八分，最多一寸。针下去之后，病人会有酸胀感往腹股沟甚至往阴部放散，这就是气到了。”**

**禁针禁灸法则：** 阴廉穴下有**旋股内侧动脉、闭孔神经前支**经过，倪师特别叮嘱：**“阴廉不可深刺，深刺伤血管则内出血，伤神经则腿内侧麻木。灸法方面，阴廉一般不多灸，因为这个地方皮薄肉少，靠近阴部，灸多了容易伤阴动火。如果一定要灸，艾炷如米粒大，三五壮即可，不可多。”**


## ⚡ 倪师经穴气化与破局心法

**倪师推演阴廉的气血流注与开阖机理：**

倪师在讲肝经时，把阴廉放在一个很特殊的位置来看。他说：**“肝经的穴道，越往上走，越接近腹腔，就越跟生殖、跟子宫、跟睾丸、跟少腹这些地方挂钩。阴廉就在腹股沟这个关口上，它是肝经气血从腿内侧进入少腹的最后一个大穴。”**

在倪师的气化体系中，阴廉的核心机理是**“疏肝通络、调畅冲任”**。肝经环绕阴器，抵少腹，阴廉正当其气机出入之枢。倪师说：**“女人少腹痛、月经不调、白带多，男人疝气、睾丸痛，你光扎太冲不够，你要想到阴廉。阴廉一针下去，肝经的气从下面通到上面来，堵在腹股沟的气就散开了。”**

更深一层，倪师讲阴廉可**“通阳化湿”**。大腿内侧是阴经所过，湿浊易聚。阴廉位于阴股与少腹交界，针之可引阴经之湿浊下行，又可助肝木升发之阳。倪师说：**“有的人大腿内侧老是潮湿、发痒，甚至起湿疹，这是肝经湿热下注。你在阴廉、五里、阴包上做文章，把湿热导下去，上面就不痒了。”**

**子母补泻与五行生克运用心法：**

肝经属木。阴廉非井荥输经合，故不直接参与“虚则补其母（曲泉，水穴）、实则泻其子（行间，火穴）”的子母补泻。但倪师在临床中，将阴廉当作肝经气血的“关卡穴”来用：

- **肝经实证（气滞、血瘀、湿热）：** 可取阴廉配**行间**（荥穴，属火，实则泻其子），以泻法为主，针阴廉用**呼吸补泻之泻法**，吸气进针，呼气退针，摇大针孔，引邪外出。
- **肝经虚证（血少、筋脉失养）：** 可取阴廉配**曲泉**（合穴，属水，虚则补其母），以补法为主，针阴廉用**呼吸补泻之补法**，呼气进针，吸气退针，按闭针孔，使气不外泄。
- **肝木克脾土（木旺乘土，腹痛泄泻）：** 倪师说：**“肝木克脾土的时候，你光补脾不够，你要从肝经上泄一点。阴廉配上足三里、三阴交，肝脾同治。”**

倪师还特别强调：**“阴廉这个穴，你把它当成肝经的‘开关’。肝经的气在下面堵住了，阴廉一开，上面就通了；上面堵住了，阴廉一开，下面的气也能上来。它是个双向调节的穴，关键是你的手法是补还是泻。”**


## 🎯 临床主治与配穴组合手印

**核心特效主治病症：**

1. **妇科病：** 少腹疼痛、月经不调、痛经、白带过多、子宫内膜炎、不孕症（肝郁型）。倪师说：**“女人少腹冷痛，你扎阴廉、关元、三阴交，针下去小腹就暖了。”**
2. **男科病：** 疝气、睾丸肿痛、精索静脉曲张、阳痿（肝郁型）。倪师说：**“疝气从肝经论治，阴廉是主穴。你扎阴廉，配合大敦放血，效果很好。”**
3. **痛症：** 大腿内侧痛、腹股沟痛、髋关节内侧痛、坐骨神经痛（内侧型）。
4. **皮肤病：** 大腿内侧湿疹、阴部瘙痒（肝经湿热下注）。
5. **急症：** 倪师特别提到：**“有的人突然少腹绞痛，你扎阴廉、太冲，用泻法，痛马上就减。”**

**倪师经典对穴与排针组合：**

| 病症 | 对穴组合 | 倪师心法 |
|------|----------|----------|
| 痛经、月经不调 | **阴廉 + 关元 + 三阴交** | 阴廉开肝经之关卡，关元暖子宫，三阴交调三阴经气血。 |
| 疝气、睾丸痛 | **阴廉 + 大敦（放血） + 太冲** | 大敦是肝经井穴，急症放血，太冲平肝，阴廉通少腹之络。 |
| 少腹冷痛 | **阴廉 + 气海 + 归来** | 气海补气，归来温少腹，阴廉引气下行。 |
| 大腿内侧湿疹 | **阴廉 + 阴陵泉 + 血海** | 阴陵泉利湿，血海凉血，阴廉通肝经之湿热。 |
| 腹股沟痛 | **阴廉 + 居髎 + 环跳** | 居髎、环跳通髋部气血，阴廉解肝经之拘急。 |

倪师特别强调：**“阴廉和足五里，常常一起用。你扎阴廉，气往下走，你再扎五里，气就继续往下走到膝盖。这两个穴配在一起，肝经从腹股沟到膝盖这一段就全通了。”**


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲肝经时，关于阴廉的原文实录如下：

**“阴廉这个穴，在足五里上一寸。你从气冲穴往下摸，摸到那根大筋，大筋外侧的缝就是阴廉。针下去五分到八分，不要深。针感会往腹股沟放散，有的人会感觉到阴部有酸胀感，这就是气到了。”**

**“阴廉主治什么？少腹痛、月经不调、疝气、睾丸痛。女人少腹冷痛，你扎阴廉、关元、三阴交，针下去小腹就暖了。男人疝气，你扎阴廉，配合大敦放血，效果很好。”**

**“阴廉和五里，是肝经在腿内侧的两个重要关卡。你扎阴廉，气往下走，你再扎五里，气就继续往下走到膝盖。这两个穴配在一起，肝经从腹股沟到膝盖这一段就全通了。”**

**“有的人大腿内侧老是潮湿、发痒，甚至起湿疹，这是肝经湿热下注。你在阴廉、五里、阴包上做文章，把湿热导下去，上面就不痒了。”**

**“阴廉这个穴，你把它当成肝经的‘开关’。肝经的气在下面堵住了，阴廉一开，上面就通了；上面堵住了，阴廉一开，下面的气也能上来。它是个双向调节的穴，关键是你的手法是补还是泻。”**

**实战手下针感体会：**

倪师描述自己扎阴廉的手感：**“针下去，你手指头感觉到针尖穿过一层薄薄的肌肉，然后底下是空的，那个‘空’的感觉一出来，你就知道到位了。这时候你轻轻捻针，病人会说酸胀往腹股沟窜，甚至往阴部窜。你不要再深了，再深就扎到血管了。”**

**医案故事：**

倪师讲过一个案例：**“有个太太，少腹痛了三年，西医说是慢性盆腔炎，吃抗生素吃了两年，越吃越痛。她来找我，我一看，舌苔黄厚，脉弦数，少腹拒按，这是肝经湿热瘀阻。我扎阴廉、行间、三阴交，用泻法。针下去十分钟，她说小腹里面在动，像有什么东西化开了。留针二十分钟，起针后她说痛减了大半。我让她每周来两次，扎了一个月，痛就没了。”**

倪师总结：**“阴廉这个穴，看起来不起眼，但在妇科、男科、少腹痛这些病上，它是肝经的一个大穴。你只要辨证准了，手法对了，效果立竿见影。”**
