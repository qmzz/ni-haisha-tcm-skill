# 内庭穴 (ST44)

**归经：** 足阳明胃经  
**定位：** 足背第 2、3 趾间，趾蹼缘后方赤白肉际处  
**属性：** 荥穴

## 📍 穴位定位

**《针灸大成》：** "在足大指次指外间陷者中。"

### 取穴方法
1. **简便取穴法：** 足背第 2、3 趾缝纹端凹陷处。
2. **骨度分寸法：** 第 2、3 趾间缝纹端赤白肉际处。

### 解剖结构
- **神经：** 足背内侧皮神经
- **血管：** 足背静脉网、趾背动、静脉

## 🩺 功能主治

### 功效
- **清胃泻热** — 牙痛、咽喉肿痛
- **通络止痛** — 足背肿痛
- **理气止痛** — 腹胀、痢疾

### 主治病证

**倪海厦：**
> \"内庭为胃经荥穴，属水。
> 胃经属土，土克水，内庭为子穴。
> 实则泻其子，胃热实证，取内庭泻之。
> 牙痛、口臭、咽喉肿痛，内庭必用。\"

| 系统 | 病证 |
|------|------|
| **头面病** | 牙痛、口臭、咽喉肿痛、鼻衄 |
| **胃肠病** | 腹胀、腹痛、痢疾、便秘 |
| **经络病** | 足背肿痛、趾屈伸不利 |
| **热病** | 发热、恶寒 |

| 配伍穴位 | 功效 | 主治 |

| **内庭 + 足三里** | 调理肠胃 | 腹胀、腹痛 |
| **内庭 + 下关** | 清热止痛 | 牙痛、口噤 |

## 💉 刺灸法

### 针刺方法
- **进针方向：** 直刺 0.3-0.5 寸
- **针感：** 局部酸胀

### 艾灸方法
- **艾条灸：** 10-15 分钟
- **艾炷灸：** 3-5 壮
