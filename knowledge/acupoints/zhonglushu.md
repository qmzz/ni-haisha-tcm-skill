# 中膂俞

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。背俞穴之列，内应胞宫精室，为督脉与膀胱经经气贯注腰脊之枢。
- **五输属性**：膀胱经属水，本穴居背部正中线旁开一寸五分，第二十椎下（即第十九胸椎棘突下）旁开一寸五分。膀胱经五输穴在远端：井穴至阴（金）、荥穴通谷（水）、俞穴束骨（木）、经穴昆仑（火）、合穴委中（土）。中膂俞不属五输，但位居背俞段，与肾俞、大肠俞、小肠俞、膀胱俞同列，为脏腑经气转输于腰脊之要冲。
- **倪师动态取穴法**：倪师讲背部俞穴取法，必先定大椎，再数脊突。从大椎往下数，第一椎下为陶道，第二椎下为身柱，第三椎下为神道……一路数到第十九椎下（即第二十节脊椎下），旁开一寸五分，便是中膂俞。倪师原话：“你不要死记二十椎，你摸脊椎嘛，一个一个往下按，按到第十九椎下，病人说‘就是这里酸’，好，就是它了。”
- **骨度折量**：两肩胛骨下角连线横平第七椎下（至阳），两髂嵴最高点连线横平第四腰椎下（腰阳关）。从至阳往下数七个椎体，至第十四椎下（命门），再往下数六椎，即第十九椎下。旁开一寸五分——以患者本人食、中、无名、小指四指并拢为三寸，一半即一寸五分。
- **下针深度**：倪师教学针背部俞穴，“针下去五分到八分，不要深针，深针会扎到内脏”。中膂俞下针取一寸针，进针五至八分，方向微向内斜，针尖朝向脊柱。
- **禁针禁灸法则**：倪师于背部俞穴反复强调：“背部下针，得气即止，不可深刺，不可久留。”本穴靠近肾脏，深刺过一寸有伤肾之虞。灸法可温和灸五至七壮，但倪师提醒：“背上灸，要看病人有没有热证，有热证不灸。”

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：中膂俞居腰脊正中段，为膀胱经气自肾俞、大肠俞、小肠俞、膀胱俞贯注而过的中间站。倪师讲，这一排背俞穴就像一条河流上的码头——肾俞是水源头，中膂俞是中游枢纽，膀胱俞是下游出口。膀胱经气在此处向内温煦胞宫精室，向外濡养腰脊骨节。腰为肾之府，中膂俞正当腰部核心，故其气化功能在于**温通腰脊阳气、固摄下焦精微**。倪师常言：“腰背的问题，你要从膀胱经上找，因为膀胱经主表，但背俞穴通里，表里一治，腰就松了。”
- **子母补泻与五行生克**：膀胱经属水，水生木，木为膀胱经之母。中膂俞虽非五输穴，但位居膀胱经背俞段，与肾经经气相通。倪师心法：**腰脊冷痛属肾阳虚者，补中膂俞配灸命门，此为“虚则补其母”——补水以生木，木旺则筋骨柔**。若腰脊强痛、转侧不利属膀胱经气实证，则泻中膂俞配委中放血，此为“实则泻其子”——膀胱经水实，泻其土（委中为合土）以折其势。
- **倪师破局心法**：中膂俞的“膂”字，倪师特别拆解：“膂就是脊梁骨旁边的肉，你摸腰后面那两条大筋，就是膂。中膂俞就是治这条大筋和脊骨之间毛病的关键。”凡腰肌劳损、腰椎错位、腰酸不能久立者，倪师先取中膂俞，再取委中，一上一下，如提壶揭盖，腰气立通。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **腰脊强痛**：中膂俞所在即腰部核心，凡腰酸、腰冷、腰重、腰肌劳损、腰椎间盘突出压迫之痛，皆可下针。倪师取穴后常让病人活动腰部，针到痛减。
  2. **消渴（糖尿病）**：膀胱经背俞段与肾经相通，中膂俞能固摄下焦精微。倪师治消渴，常在肾俞、中膂俞、膀胱俞一线取穴，配合然谷、太溪，固肾气以摄尿糖。
  3. **痢疾、肠炎**：中膂俞邻近大肠俞、小肠俞，能分清泌浊。倪师治下利赤白，取中膂俞配天枢、上巨虚，通调肠腑。
  4. **妇科下焦虚寒**：腰为胞宫之邻，中膂俞温通腰脊，可治妇人带下清稀、月经不调属寒湿者。
  5. **坐骨神经痛**：中膂俞下针，针感可沿臀腿后侧向下传导，倪师配环跳、委中、承山，一气贯通。
- **倪师经典对穴与排针组合**：
  - **中膂俞 + 委中**：腰背委中求，一上一下，通调膀胱经气，治一切腰腿痛。
  - **中膂俞 + 肾俞 + 命门**：治腰冷如坐水中，阳痿早泄，五更泄泻。
  - **中膂俞 + 天枢 + 上巨虚**：治痢疾、肠鸣、腹痛。
  - **中膂俞 + 三阴交 + 关元**：治妇人带下、月经不调、不孕。
  - **中膂俞 + 环跳 + 阳陵泉**：治坐骨神经痛、髋关节痛。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲背部俞穴时，原话实录：

“诸位看，从大椎开始，第一椎下陶道，第二椎下身柱……你一路数下来，数到第十九椎下，旁开一寸半，就是中膂俞。这个‘膂’啊，就是腰后面那两条大筋。你摸病人腰后面，脊椎骨旁边那两条肉，就是膂。中膂俞就是治这条大筋的。”

“临床上，病人腰酸背痛，你问他哪里痛，他手按着腰后面说‘就这里’，你一看，正好是中膂俞的位置。你针下去，五分深，病人马上说‘酸胀’，你让他慢慢转腰，针留到十分钟，腰就松了。为什么？因为膀胱经气通了。膀胱经气一通，腰部的阳气就回来了。”

“我治一个腰痛十几年的病人，西医治不好，说他是腰椎间盘突出，要开刀。我一看，他痛的位置就在中膂俞。我针中膂俞、委中，针完叫他起来走走，他不敢，我说你走走看，他一走，咦，不痛了。后来针了五次，到现在几年了都没再犯。”

“还有消渴，西医叫糖尿病。你光降血糖没用，你要固肾。肾俞、中膂俞、膀胱俞这一排针下去，再针太溪、然谷，把肾气固住，小便里的糖就少了。这是治本。”

“记住，背部下针，得气即止。你不要给我深针，深针扎到肾脏，病人会尿血。五分到八分，最多一寸，够了。灸的话，五壮七壮，温和灸，不要起泡。”

“中膂俞这个穴，你只要记住：腰脊中间的病，找它准没错。配上委中，就是腰背委中求的加强版。针下去，病人说腰热了，那就是气到了。气到了，病就好了一半。”
