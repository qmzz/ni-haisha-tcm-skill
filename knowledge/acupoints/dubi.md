# 犊鼻

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经。犊鼻是胃经在膝部的要穴，位于膝盖骨外侧的凹陷处。倪师在《人纪·针灸篇》讲足阳明胃经时明确指出，膝盖骨两旁一边一个凹洞，形似牛鼻子，故称犊鼻，又称外膝眼。胃经多气多血，犊鼻正当膝关节屈伸之枢机，是经气深聚、筋骨交会之所。
- **五输穴/特定穴属性**：犊鼻不属于井荥输经合五输穴体系，但它是膝部局部取穴的核心要穴。胃经本身属土，倪师在讲五行生克时反复强调：脾胃为后天之本，土生万物。犊鼻虽非五输，但其治膝之力，正是胃土之气灌渗筋骨、濡养关节的体现——土旺则四肢健，土衰则膝软无力。从子母补泻角度看，胃经之母为心包经（火生土），胃经之子为大肠经（土生金），临床膝痹属虚寒者，可补心包经以生胃土，再取犊鼻引气至膝。
- **倪师动态取穴与骨度折量法**：倪师取犊鼻，从不死板。他教的方法是：让病人坐着，膝盖弯成九十度，用手摸膝盖骨——膝盖骨正下方有一条大筋（髌韧带），筋的外侧、膝盖骨下缘旁边，有一个天然的凹洞，按下去会酸胀，那个洞就是犊鼻。倪师特别强调“以痛为腧”的活法：膝盖痛的人，你在凹洞周围轻轻按，找到最痛的那一点下针，比死守教科书位置准得多。下针深度，倪师说一般直刺五分到一寸，针尖略向内侧（朝向内膝眼）斜刺，效果更佳。禁灸？倪师在讲膝五针时明确讲：犊鼻可以灸，但急性红肿热痛时禁灸，要先放血。他特别提醒：膝盖积水、红肿发烫时，犊鼻周围不要灸，要用三棱针点刺放血，再下针。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师在《人纪》中讲，膝盖是筋之府，所有筋脉都汇聚在膝。犊鼻这个位置，正是胃经气血从大腿往下灌入小腿的关口，像一道闸门。胃经多气多血，气血到这里如果被风寒湿堵住，膝盖就肿、就痛、就不能弯。倪师推演犊鼻的气化机理是：胃土之气从这里渗入关节腔，濡养髌骨与韧带，同时把关节里的湿浊之气往下导引，从足三里、上巨虚一路排出去。所以犊鼻的作用不是单纯的“止痛”，而是打开胃气下行的通道——气一通，水湿就化，肿就消，膝就利。倪师常讲，治膝盖不能只盯着膝盖，要想到胃经这条大水管，犊鼻就是水管的龙头，龙头一开，整条管子的水就活了。
- **子母补泻与五行生克运用心法**：胃经属土，土之母为火（心包经、三焦经），土之子为金（大肠经、肺经）。倪师在讲补泻时明确：膝盖冷痛、无力、遇寒加重，这是胃土虚寒，虚则补其母——先针心包经内关或三焦经外关，再取犊鼻，等于给胃土加一把火，土暖了，膝就热了。膝盖红肿热痛、拒按，这是胃土壅实，实则泻其子——先针大肠经曲池或合谷，再取犊鼻，把土中的实热从金的方向泄出去。倪师还特别强调：临床上膝五针（犊鼻、内膝眼、鹤顶、阳陵泉透阴陵泉、足三里）就是一套完整的五行套路——阳陵泉属胆木，木能疏土；足三里属胃土，土能制水；犊鼻引气至膝，鹤顶提气上行，内膝眼通阴经。五针齐下，土木水火金全动，膝盖的问题就解了。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **膝关节痛与退化性关节炎**：这是犊鼻的第一主治。倪师说，膝盖痛不能蹲、上下楼梯痛、膝盖无力，犊鼻是必取之穴。不论风湿、劳损、退化，犊鼻都能引气至病所。
  - **膝盖积水与肿胀**：倪师讲，膝盖肿得像馒头、按下去有波动感，这是水湿停在关节。犊鼻配足三里、阴陵泉，三穴同下，导水下行。急性期先在犊鼻周围放血，再下针，肿消得很快。
  - **膝软无力与老年人行走困难**：胃经气血不足，膝盖失养，犊鼻配足三里、绝骨（悬钟），补胃土、填髓海，腿脚就有力了。
  - **鹤膝风**：膝盖肿大如鹤膝、小腿细，倪师说这是寒湿深伏，犊鼻配阳陵泉透阴陵泉、足三里，再加灸，慢慢把寒湿化掉。
- **倪师经典对穴与排针组合**：
  - **犊鼻 + 内膝眼**：一外一内，像两只眼睛同时看住膝盖，把阴阳两面的气血都调动起来。倪师说这两个穴一起下，膝盖的“门”就全打开了。
  - **犊鼻 + 足三里**：这是胃经的母子配。足三里是胃经合穴属土，犊鼻是膝部要穴，两穴同经相引，气血从足三里一路灌到犊鼻，膝盖就得到滋养。
  - **犊鼻 + 阳陵泉 + 阴陵泉**：阳陵泉属胆木，阴陵泉属脾土，木土相合，疏筋健脾利水。倪师治膝盖积水，这三穴是铁三角。
  - **犊鼻 + 鹤顶**：鹤顶在膝盖骨上缘正中，犊鼻在膝下外侧，一上一下，像提壶揭盖，把膝盖的气机上下贯通。
  - **倪师膝五针完整组合**：犊鼻、内膝眼、鹤顶、阳陵泉透阴陵泉、足三里。倪师说，这五针下去，膝盖的问题基本就罩住了，再根据寒热虚实加减。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味金句**：
  - “膝盖痛，你摸那个膝盖骨旁边，有个洞，像牛鼻子一样，那就是犊鼻。你针下去，病人会感觉酸胀一直透到膝盖里面去，那个酸胀感一出来，膝盖就松了。”
  - “膝盖肿，你不要急着灸，先放血。三棱针在犊鼻周围点几下，黑血出来，肿就消一半。然后再下针，效果才好。你灸下去，热上加湿，反而更肿。”
  - “治膝盖不能只扎膝盖，要想到胃经。胃经多气多血，你把足三里和犊鼻一起下，气血从上面冲下来，膝盖就像干田得到水一样，马上就不痛了。”
  - “鹤顶、犊鼻、内膝眼，这三个穴把膝盖骨围住，像三根柱子撑住一个屋顶，膝盖就稳了。”
- **实战手下针感体会**：倪师说，犊鼻下针，针尖要略向内侧斜，朝着内膝眼的方向，不要直直地扎。针进去以后，轻轻提插，病人会感觉膝盖里面有一股热流或者酸胀感在扩散。如果病人说“酸到小腿了”，那说明气已经通了；如果只是皮痛，那是没扎到位置，要调整角度再进。倪师特别讲，犊鼻这个穴，针感比位置更重要——你扎对了，病人自己会告诉你“就是这里”。
- **医案故事**：倪师在《人纪》中讲过一个案例：一位老太太膝盖痛了十几年，蹲不下去，西医说要换关节。倪师看她膝盖不红不肿，就是冷、痛、无力，这是虚寒。他先灸足三里、关元，再针犊鼻、内膝眼、鹤顶、阳陵泉透阴陵泉，留针二十分钟。起针后，老太太当场就能蹲下去一半，自己都吓了一跳。倪师说，这就是胃气回来了，土能生万物，膝盖的筋脉得到滋养，自然就灵活了。他还讲过一个膝盖积水的年轻人，膝盖肿得发亮，他先在犊鼻周围放血，黑血喷出来，肿立即消了一圈，再针膝五针，三次就好了。倪师总结：犊鼻这个穴，看似简单，但它是膝盖的开关——开关一开，气血就通，通则不痛。
