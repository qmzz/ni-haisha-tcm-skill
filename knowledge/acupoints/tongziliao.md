# 瞳子髎

## 📍 经络归属与精准取穴法

瞳子髎，足少阳胆经第一穴，也是胆经的起始穴。胆经起于眼外角，第一个穴就是瞳子髎。

**经络归属**：足少阳胆经。瞳子髎并非五输穴（井荥输经合），也不是原穴、络穴、郄穴、募穴、背俞穴或八会穴。它是胆经与手太阳小肠经、手少阳三焦经的交会穴——三焦经和胆经的阳气都在这里汇聚。在倪师的体系中，这个穴的定位很特殊：它是胆经的“门口”，所有的胆经气血从这里出发，沿身体侧面一路走到脚趾。

**倪师动态取穴与骨度折量法**：

倪师讲得很直白——你摸眼睛外边，眼眶骨外侧有一个凹陷。闭着眼睛取穴最准，因为眼睛闭起来的时候，眼眶骨的边缘摸得最清楚。就在眼外角旁开五分，也就是瞳孔正中线往外延伸，到了眼眶骨外缘，那个凹陷就是瞳子髎。

你用手去按，会感觉到一个明显的骨缝凹陷。倪师说，你摸到这个凹陷，针下去是贴着骨边下的。下针的方向很重要——不是直刺，是**沿皮刺**，针尖朝着太阳穴的方向平刺进去，或者是向后平刺。因为眼睛周围都是筋骨，你直刺下去很危险。下针的深度是**三分到五分**，绝对不能深针。深针就扎到眼球后面去了，那是要出事的。

**禁针禁灸法则**：瞳子髎这个穴，倪师明确说——**禁灸**。眼睛周围的穴道，一律不灸。你拿艾条去烤眼球旁边，那是自己找麻烦。针可以下，但是要浅，要沿皮刺，手法要轻。如果是新手，倪师说你宁可拿指尖去按揉，也不要随便下针，因为眼睛周围毛细血管丰富，扎出血了就是一个黑眼圈，病人还以为你把他扎坏了。

## ⚡ 倪师经穴气化与破局心法

瞳子髎的气化机理，倪师是从胆经的阳气生发来讲的。

胆经是一条阳气很旺的经络，少阳主枢。瞳子髎作为胆经的起点，它承接的是肝胆的精气上注于目。倪师说，眼睛能看东西，靠的是肝血和胆气的温煦。瞳子髎这个位置，正好是胆经阳气往外发散的出口。所以它的气化机理是**开窍明目、疏散风热、清泄肝胆之火**。

倪师推演这个穴的时候，把它和胆经的循行路线连在一起看：胆经从瞳子髎出发，一路走到风池、肩井，再沿着身体侧面往下走到环跳、阳陵泉，最后到足窍阴。整条胆经的阳气，都是从瞳子髎这个“龙头”开始往下灌的。所以瞳子髎堵住了，整条胆经的阳气就不畅。反过来说，瞳子髎开了，胆经的阳气就顺了。

**子母补泻与五行生克**：瞳子髎本身不是五输穴，所以不存在直接的子母补泻。但倪师讲，胆经属木，木生火，胆经的母穴是侠溪（荥穴，属水，水生木），子穴是阳辅（经穴，属火，木生火）。瞳子髎虽然不参与子母补泻，但它是胆经的“开口穴”，你在瞳子髎下针，等于把胆经的门口打开了，后面的气血才好流通。这就是倪师常说的“先开门，后运货”。

## 🎯 临床主治与配穴组合手印

**核心特效主治**：

瞳子髎的主治，倪师归结为两大类——眼睛的毛病和偏头痛。

第一，**目赤肿痛、目翳、青盲、怕光流泪**。眼睛红肿、眼屎多、见风流泪，这是肝胆风热上攻。瞳子髎能清肝胆之热，散风明目。倪师说，眼睛红肿的时候，你拿三棱针在瞳子髎点刺放血，挤一两滴血出来，眼睛立刻感觉清凉，红退得很快。

第二，**偏头痛、眉棱骨痛**。胆经走身体侧面，偏头痛十有八九是胆经的问题。瞳子髎配上率谷、风池，是倪师常用的偏头痛组合。尤其是痛在眼睛外侧到太阳穴这一段的，瞳子髎是近取穴，直接疏通局部的气血。

第三，**面瘫、眼睑下垂、眼肌痉挛**。眼睛闭不拢、眼皮跳个不停，这是局部经气不畅。瞳子髎配合攒竹、阳白、四白，能疏通眼周经气。

**倪师经典对穴与排针组合**：

- 瞳子髎 + 攒竹 + 太阳 + 合谷：治目赤肿痛、眼睛红肿
- 瞳子髎 + 率谷 + 风池 + 外关：治偏头痛
- 瞳子髎 + 阳白 + 四白 + 地仓 + 颊车：治面瘫、眼睑闭合不全
- 瞳子髎 + 肝俞 + 肾俞 + 光明：治青盲、视物模糊（肝开窍于目，肾水养肝木）

倪师特别强调，眼睛的毛病不能只扎眼睛旁边。他说，眼睛是标，肝胆是本。你光扎瞳子髎、攒竹，当时舒服了，过两天又来了。要加肝俞、肾俞、光明、太冲，从根上治。这就是倪师的“标本兼治”思路。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲瞳子髎的时候，原话是这样的：

“瞳子髎在眼外角的地方，你摸那个眼眶骨，旁边有个凹洞，那就是瞳子髎。这个是胆经的第一个穴道，胆经从这里开始。你下针的时候，不要直刺，要沿着皮刺，针尖对着太阳的方向刺进去，三分就好了，不要深。深了扎到眼睛里面去，那还得了。”

“眼睛旁边的穴道，一律禁灸。你拿艾条去烤眼睛，那是开玩笑。眼睛的穴道，我们都是放血。眼睛红肿、痛得不得了，你在瞳子髎、攒竹、太阳点刺放血，血一挤出来，病人眼睛就亮了。这就是‘实则泻其子’，胆经的实热，从瞳子髎放血泻掉。”

倪师还讲过一个实战体会：

“偏头痛的病人来，痛在眼睛后面、太阳穴这一带，你问他，他指给你看，就是瞳子髎这个地方痛。你先在瞳子髎下针，针下去的时候，病人会觉得酸胀感往太阳穴那边走。你再配率谷、风池，针下去，病人当场就说头松了。这就是近取穴的威力——穴在痛处，针到痛除。”

倪师最后强调，瞳子髎虽然是小穴，但它是胆经的“龙头”。龙头一开，整条胆经的阳气就活了。所以你不要小看它，眼睛的毛病、偏头痛、面瘫，都离不开这个穴。但是记住——**浅刺、禁灸、可放血**。这三个原则，一个字都不能忘。
