# 石关

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：石关穴归属**足少阴肾经**，位于腹部，为**冲脉与足少阴肾经之会穴**（八脉交会穴中冲脉所过之处）。在五行属性上，石关不属井荥输经合五输穴体系，但它是肾经在腹部的重要关卡穴，与冲脉气血直接相通。倪师常言：肾经在腹部的穴位，每一个都是“水气转输的关卡”，石关顾名思义，就是“石头一样的关卡”，说明此穴有攻坚破积、通利关窍之功。

- **倪师动态取穴与骨度折量法**：倪师讲石关，一定先让你找到**肚脐与胸剑联合的中点**——这是**中脘穴**。从中脘再向上量**一寸**，就是**建里穴**；从建里再旁开**五分**，就是石关。更直白地说：**在肚脐上三寸、再向外旁开五分**的位置。倪师特别强调，肚脐到胸剑联合是**八寸**的标准骨度，你先折半得四寸为中脘，再上半寸，再旁开半寸，就是石关。下针时，倪师说：**“直刺一寸到一寸五分，针下去要贴着腹壁往下走，不要往深处刺，因为下面是胃和肠子。”** 石关**可灸**，尤其对寒性呕吐、胃气上逆者，灸比针更稳。**禁针禁灸法则**：倪师讲腹部穴位，**孕妇禁针**，尤其石关这种与冲脉相通的穴，怀孕时一动冲脉，胎气就不稳。过饱、过饥、极度虚弱时不宜针。腹部有肿瘤或急腹症时，不可深刺。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演气血流注与开阖机理**：倪师讲石关，第一句话就是：“**石关是大肠与胃之间的关卡。**”肾经从下往上走，到了腹部，水气要经过石关这个“闸门”才能上达胸膈。如果这个关卡堵住了，水气就停在胃里，病人就**呕吐、吃不下、胃脘胀满**。所以石关的核心机理是：**开闸放水、降逆止呕、通利关格**。倪师说：“**石关一开，水就往下走；石关一闭，水就往上泛。**”这就是为什么呕吐、呃逆、噎膈，倪师都会考虑石关。

- **子母补泻与五行生克运用心法**：石关属肾经，肾属水。按五行，**水生木**，肝为肾之子；**金生水**，肺为肾之母。石关本身不是五输穴，但倪师在临床上用石关时，常常配合**肾经的母穴复溜**（经穴，属金，金生水）来补，或配合**肾经的子穴涌泉**（井穴，属木，水生木）来泻。如果是**肾水泛滥、水气凌心**导致呕吐清水，倪师会在针石关的同时，补复溜、泻涌泉，这叫“**引水归源、釜底抽薪**”。如果是**胃气上逆**，倪师会配**足三里**（胃经合穴，土经土穴），用泻法，把胃气往下导，石关在上游开闸，足三里在下游疏导，这叫“**上下呼应、关开逆降**”。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **呕吐、呃逆、噎膈**——倪师说石关是“止呕的专穴”，尤其是**朝食暮吐、暮食朝吐**的胃反证，针石关配上脘、中脘，效果立竿见影。
  2. **胃脘痛、腹胀、食欲不振**——石关能通利胃与大肠之间的气机，对**胃胀气、打嗝、消化不良**有奇效。
  3. **便秘、肠鸣、水气病**——石关开闸，水气下行，大便就通。倪师常讲：“**石关一针，大便就通，小便就利。**”
  4. **妇科：痛经、月经不调、不孕**——因石关与冲脉相通，冲脉为血海，石关能调冲任、通血脉。倪师治**寒凝痛经**，石关配关元、三阴交，灸比针更佳。
  5. **急症救逆**：倪师讲，**霍乱吐泻**时，石关配**内关、公孙**，能迅速止吐止泻，稳定中焦。

- **倪师经典对穴与排针组合**：
  - **石关 + 中脘 + 足三里**——治一切胃病、呕吐、胃胀。倪师说这是“**中焦三针**”，石关开上关，中脘镇中州，足三里导下焦。
  - **石关 + 内关 + 公孙**——治胃心胸急症。公孙通冲脉，内关通阴维，石关直接通冲脉，三针齐下，**心胸胃的病一起解**。
  - **石关 + 天枢 + 关元**——治便秘、腹胀、水气病。天枢是大肠募穴，关元是小肠募穴，石关在中间开闸。
  - **石关 + 三阴交 + 血海**——治妇科痛经、月经不调。倪师说：“**石关调冲脉，三阴交调三阴，血海活血，三针一下，血就活了。**”

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：倪师在讲石关时，是这样说的：“**石关这个穴道，你看名字就知道，像石头一样关住了。哪里关住了？水关住了。肾水从下面上来，到了石关这里，如果关住了，水就往上逆，病人就呕吐。**” 他又说：“**石关针下去，病人会感觉到胃里面一阵蠕动，然后就想放屁，或者打嗝，这就是气通了。**” 倪师特别强调：“**石关不要深针，一寸到一寸半，针尖要稍微朝上，顺着肾经往上走的方向，这样气才顺。**”

- **实战手下针感体会**：倪师说，他针石关时，**针尖碰到腹壁筋膜，病人会有酸胀感，有时会有一股热流往下走**。如果病人胃寒，针下去后加灸，病人会感觉**胃里面暖暖的，像喝了姜汤一样**。倪师讲：“**石关针下去，如果病人打嗝，你就知道气通了；如果病人放屁，你就知道水下来了。**”

- **医案故事**：倪师在讲义中讲过一个案例：一位**中年妇女，呕吐三个月，吃什么吐什么，西医查不出原因**。倪师一看，病人**舌苔白滑，脉沉迟**，这是**肾水寒，水气上泛**。倪师针**石关、中脘、足三里**，石关加灸，针下去不到五分钟，病人**打了一个长嗝，然后说胃里舒服了**。倪师再针**复溜**补母，**涌泉**泻子，引水归源。三次治疗后，病人呕吐止，胃口开。倪师说：“**这就是石关的妙用——开一关，通全局。**”
