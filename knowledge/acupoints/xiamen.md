# 侠白

## 📍 经络归属与精准取穴法

- 侠白属**手太阴肺经**，位于天府穴下**一寸**，肘横纹上**五寸**。肺经五输穴为：少商（井·木）、鱼际（荥·火）、太渊（输·土·原）、经渠（经·金）、尺泽（合·水）。侠白不在五输之列，为肺经臂部腧穴，与天府同气，属肺经经气在臂内侧面循行通路上的重要节点。其穴名"侠白"——"侠"通"挟"，"白"属肺金之色，意指此穴挟于肺气布散之道，与肺之白色相应，为肺气外应于臂部之门户。

- 倪师取穴心法：先定天府。让患者手臂**平举**，鼻尖对准上臂内侧，鼻尖所触之处即**天府**。倪师原话："你把手臂举起来，鼻尖贴上去，碰到的地方就是天府。"从天府**直下一寸**，便是侠白。骨度折量上，肘横纹至腋前纹头为**九寸**，侠白在肘横纹上**五寸**，即居臂内侧面之中段。

- **下针深度**：直刺**三至五分**。倪师强调，侠白与天府皆在肌肉丰厚处，针感以**酸胀**为主，有时会向上臂内侧放射。**禁灸**之说不成立，此穴可灸，但临床以针为主。注意避开肱动脉搏动处，取穴时以指按压，找到酸胀最明显处再下针。禁针之说古籍虽有所载，倪师认为系指深刺伤及血脉而言，常规浅刺无碍。

## ⚡ 倪师经穴气化与破局心法

- 侠白之气化，根在**肺主气、主皮毛**。肺经经气从云门、中府而出，循天府而下，侠白正当经气由肩臂向肘部流注之中途。倪师推演：此穴气血流注如**瀑布中段**，上承天府之宣发，下接尺泽之汇合。肺气郁闭于臂内侧、不得宣散时，侠白为开阖之枢。其机理在于**宣肺气、通臂络**——肺气不宣则臂内侧痛、上肢不遂；肺气壅滞则胸满喘逆。侠白能引肺气下行，又能助其外散，一穴而兼升降之用。

- 五行生克上，肺属金，侠白虽非五输穴，但居于肺经，其气化不离金性。虚则补其母——肺金之母为脾土，故肺虚之证，侠白可配**足三里**（胃经合土）、**太白**（脾经输土）以培土生金。实则泻其子——肺金之子为肾水，故肺实之证，侠白可配**复溜**（肾经经金）、**阴谷**（肾经合水）以金水相生、泻肺之实。倪师常用侠白配尺泽，一上一下，一宣一降，治肺气不宣之胸闷臂痛。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **臂内侧痛、上肢不遂**——侠白所在即肺经臂段，凡臂内前廉疼痛、麻木、无力，取侠白透刺或深刺，配合**天府、尺泽**，一针下去患者即感酸胀传导。
  - **胸闷、气短、喘咳**——肺气不宣所致胸满喘逆，侠白配**膻中、中府**，开胸顺气。
  - **心痛**——古籍载侠白主"心痛"，倪师解为肺气郁闭导致心阳不展，取侠白配**内关、公孙**，肺心同治。
  - **干呕、上气**——肺气上逆之候，侠白配**太渊、经渠**，降肺气则呕逆自止。

- **经典对穴与排针组合**：
  - **侠白 + 天府**：同经同段，一上一下，治臂痛不遂如鼓应桴。
  - **侠白 + 尺泽 + 太渊**：肺经臂段三针齐下，宣肺、降气、补虚，治喘咳胸满。
  - **侠白 + 内关 + 公孙**：开四关之变局，肺心胃同治，治心痛、胸闷、干呕。
  - **侠白 + 足三里 + 三阴交**：培土生金、金水相生，治肺虚久咳、气短乏力。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲肺经时，对天府、侠白一带的取穴有一句原汁原味的金句："你鼻尖贴上去，碰到哪里，哪里就是天府。天府下一寸就是侠白。这两个穴，你针下去，病人说'哎哟'，酸到肘弯里去了，那就对了。"

- 倪师手下针感体会：侠白下针后，针感**酸胀**沿上臂内侧向下传导至肘窝，有时上行至肩。若针感只在局部，说明经气未通，可稍提针再进，或加**捻转**手法。倪师特别讲到，治臂痛时，侠白与天府**一针透两穴**（从侠白进针，针尖向上透至天府皮下），效果比单刺更佳，患者感觉整条臂内侧都松开了。

- 医案故事：倪师曾治一妇人，**右臂内侧痛三个月**，手不能上举，西医治以止痛药无效。倪师取**侠白透天府**，配**尺泽**、**外关**，针下即感酸胀遍及全臂，留针二十分钟，起针后患者手臂已能抬高过半。倪师解曰："肺经的气堵在臂弯里，你把它通开就好了。侠白就是那个关卡，针一下去，气就过去了。"
