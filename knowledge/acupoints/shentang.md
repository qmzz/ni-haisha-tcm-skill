# 神堂

## 📍 经络归属与精准取穴法

神堂穴，归足太阳膀胱经。它不在井荥输经合这五输穴里头，也不是原穴络穴郄穴募穴，它是**背俞穴**——膀胱经在背后那一整条排开的脏腑之气转输之处。神堂在第5胸椎棘突下、旁开3寸处。注意，旁开3寸不是1.5寸——1.5寸那一排是肺俞、心俞、肝俞这些，3寸这一排靠外，是神堂、魄户、魂门、意舍、志室这一路。

倪师在讲背部穴位的时候反复强调一个东西——**先找脊椎，再量旁开**。怎么找第5胸椎？不要埋头去数“一、二、三、四、五”，数错了就全错。倪师的取法是：先找肩胛骨内缘，肩胛骨下角平第7胸椎，往上推两节就是第5胸椎。这个骨度折量法比从头往下数靠谱得多，因为每个人的颈椎胸椎数目偶有变异，但从肩胛骨定位是最稳的。

找到第5胸椎棘突下之后，旁开3寸。怎么定3寸？以患者本人的手指做折量——四指并拢为3寸。从脊椎正中往外拉到四指宽的位置，再上下对准第5胸椎水平线，两线交会处就是神堂。

下针深度，倪师说背部的穴位一般斜刺或平刺，**不可深刺**。神堂在肩胛骨内侧缘附近，下面是肋骨和胸腔，直刺深了容易伤到肺脏，造成气胸。倪师的原话是“背后这些穴位，针下去半寸到一寸就够了，斜着往脊柱方向刺”，得气即止，不追求深。

灸法方面，神堂可以灸，但不多灸。《针灸大成》里说“可灸五壮”。倪师在讲灸的时候提过，背部穴位艾灸要谨慎，因为靠近肺和心脏区域，灸量过大会扰动心肺之气，五壮为限，不要贪多。

## ⚡ 倪师经穴气化与破局心法

神堂这个穴名，关键在“神”字。倪师讲中医里“神”是什么？心藏神，神是心神的外舍。神堂在膀胱经上，膀胱与肾相表里，肾主骨生髓，髓通于脑，脑为元神之府。所以神堂这个穴——它不直接治心脏，但它通过膀胱经的阳气转输，把胸中阳气打开，让心神能安居其位。

倪师的推演逻辑是这样的：膀胱经是人体最大的阳经，从头走到脚，背后这一整排背俞穴是阳气出入脏腑的“门户”。神堂在第5胸椎旁，这个位置对应的是心包的区域。心包者，心之宫城也。神堂就是心包阳气往外转输的窗口。如果这个窗口堵住了，胸阳不振，心神不安，人就容易心悸、怔忡、失眠、健忘、胸闷。

从气血流注来看，膀胱经的气血在申时（下午三点到五点）最旺，这时候阳气从巅顶往下走，经过背部各俞穴，把阳气分注到对应的脏腑。神堂这一穴，气血注到心包区域，起到的是**宽胸理气、宁心安神**的作用。倪师说这就像“开窗透气”——胸中憋闷的时候，把这扇窗户打开，阳气进来了，浊气出去了，心神自然就安了。

子母补泻方面，神堂本身不是五输穴，不能直接套用“虚则补其母、实则泻其子”的规则。但它所在的膀胱经是水经，心包是相火，水能制火。如果心火太旺导致烦躁失眠，取神堂可以借膀胱经的水气来制约心火，这是五行生克里的“水克火”。反过来，如果心阳不足、神疲乏力，那就在神堂上做补法——用艾灸温补，或者针刺用紧按慢提的补法，把阳气补进去。

倪师特别讲过一个心法：**背后所有带“神”字的穴——神道、神堂、神门——都跟心神有关，但各有分工**。神门在手少阴心经上，是直接管心神的；神道在督脉上，是通阳安神的；神堂在膀胱经上，是从背后把阳气推到心胸去安神的。三个穴配合用，效果比单用一个强得多。

## 🎯 临床主治与配穴组合手印

神堂的核心主治，倪师归纳为三大块：

**第一，心胸病症。** 胸闷、胸痛、心悸、怔忡、气喘、咳嗽。特别是那种感觉胸口像压了块石头、喘不上气来的，针神堂配上内关，效果很快。内关是心包经的络穴，管心胸的，神堂从背后打开胸阳，一前一后，前后夹击。

**第二，神志病症。** 失眠、多梦、健忘、焦虑、心神不宁。倪师说这种病人你一看，舌淡苔白，脉细弱，问他睡不好，再问他是不是容易心慌，他说对。这就是胸阳不振、心神失养。取神堂、心俞、神门，三穴合用。神堂从背后温通胸阳，心俞直接补心气，神门安神定志。

**第三，肩背痛。** 神堂所在的区域是肩胛骨内侧，很多人的背痛就在这个位置。特别是长期伏案工作的人，肩胛骨内侧缘酸痛，转头都难受。这种痛不是骨头的问题，是膀胱经的气堵在这个地方了。针神堂，配上肩井、天宗，松解背部阳气，痛就散了。

倪师的经典配穴组合：

- **神堂 + 内关 + 公孙**：治胸闷、心痛、胃心胸这一整片的问题。公孙配内关是八脉交会穴的经典组合，通冲脉和阴维脉，管胃心胸。再加神堂，从背后把胸阳打开，三层保险。
- **神堂 + 心俞 + 神门**：治失眠、心悸、心神不宁。这是倪师最常用的安神组合。
- **神堂 + 肺俞 + 膏肓**：治久咳、气喘、虚劳。膏肓穴在神堂旁边，第4胸椎旁开3寸。倪师说膏肓是治虚劳的要穴，配上神堂和肺俞，补肺气、宽胸膈、安心神，对那种久病体虚、咳喘无力的病人特别好。
- **神堂 + 天宗 + 肩井**：治肩背痛。天宗在肩胛骨正中间，肩井在肩膀最高处，神堂在肩胛骨内侧。三个穴把整个肩胛区域的气血都调动起来。

倪师还讲过一个急症用法：**突然心绞痛发作，手边没有药，重按神堂穴**。用大拇指按压，力度以病人能承受为度，持续按揉，同时让病人深呼吸。神堂在背后，自己按不到，需要别人帮忙。倪师说这个法子能暂时缓解，为送医争取时间。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲背部穴位的时候，讲到神堂这一段，原话大意是这样的：

“神堂这个穴，你看名字就知道，神住的地方。心藏神，神住在心里面，但心外面有心包，心包是心的大臣。神堂就在心包的外围，第5胸椎旁开3寸。你针下去的时候，不要直刺，斜着往脊柱方向刺，半寸到一寸。针下去以后，病人会感觉背后一阵热，或者胸口松开了，那就是气到了。”

“我在临床上碰到失眠的病人，你问他，他告诉你晚上翻来覆去睡不着，心里慌慌的，好像有什么事放不下。这种病人，你在他背后神堂上按一按，他会喊痛，痛得比别的地方厉害。为什么？因为气堵在那里了。你针神堂、心俞、神门，针完当天晚上就能睡个好觉。”

“还有一个经验，有些女病人，月经来之前乳房胀痛、胸闷烦躁，你在神堂上针一下，再配上太冲，疏肝理气，症状很快就缓解了。因为神堂能开胸膈，太冲能平肝火，两个配起来，上下通气。”

倪师还讲过一段关于针感的体会：

“神堂针下去，得气的感觉跟别的穴不太一样。别的穴是酸麻胀，神堂有时候是**热**。病人说好像有一股热气从背后往胸口窜，那就对了。这就是阳气被调动起来了。如果针下去病人没感觉，你要稍微提插捻转一下，或者把针尖方向调一调，往脊柱方向斜一点，气就来了。”

“记住，背部的穴位，尤其是胸椎这一段，**绝对不能深刺**。你针下去半寸到一寸，斜刺，得气就停。不要想着针深一点效果更好，深了会出问题。肺就在肋骨下面，针穿过去就是气胸，这是要命的事。”

关于灸法，倪师说：

“神堂可以灸，但不要多灸。三五壮就够了。灸的时候用艾条悬灸，不要用大艾炷直接灸，因为这个地方皮肤薄，下面就是肺。悬灸的时候，病人感觉热往里透，胸口暖暖的，很舒服，那就到位了。”

倪师还提过一个医案：

“有一个病人，男的，五十多岁，胸闷了半年多，西医检查心脏没问题，但就是觉得胸口堵得慌，喘气不顺。我一看，舌苔白腻，脉弦滑，这是胸阳不振、痰浊内阻。我在他背后神堂、心俞、肺俞上针，前面针内关、公孙。针了三次，他说胸口那块石头搬掉了。为什么？神堂把胸阳打开了，肺俞把痰浊化了，心俞把心气补了，内关公孙把胸膈的气理顺了。这就是针灸的全局思维，不是头痛医头。”

“所以你们学针灸，不要只记穴位治什么病。要理解**气**是怎么走的。神堂这个穴，它不直接治病，它是帮你把阳气送到该去的地方。阳气到了，神就安了，病就好了。”
