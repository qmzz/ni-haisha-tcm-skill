# 大肠俞穴 (BL25)

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：大肠俞穴归属于**足太阳膀胱经**。它是**大肠的背俞穴**。背俞穴是脏腑之气输注于背腰部的腧穴，全部分布在足太阳膀胱经的第一侧线上。因此，大肠俞是诊断和治疗大肠腑证及大肠相关病变的核心要穴。在五行生克定位上，大肠属金，本穴作为背俞穴，是调理大肠金气、通降腑气的关键门户。

- **倪师动态取穴与骨度折量法**：倪师讲，找大肠俞，先找第十四椎（即命门穴）。命门穴怎么找？你让病人正坐或趴着，两个手肘自然下垂，背后两个肩胛骨下缘连线的中点，大约是第七椎（至阳穴）。从第七椎往下数，数到第十四椎，就是命门。命门旁开一寸五分，就是大肠俞。倪师强调，一寸五分怎么量？用病人的中指头，弯起来，两个指头关节之间的宽度是一寸。一寸五分就是再加一半。当然，更精准的方法是“一夫法”，即用病人食、中、无名、小指四指并拢，以中指近端指关节横纹为准，四指宽度为三寸，从中取一半即为一寸五分。下针的时候，倪师说，大肠俞可以直刺，针深一寸到一寸五分。因为下面就是腹后壁，深处有腰神经丛和血管，所以不可深刺，以免伤及内脏。通常灸法比针法更常用，因为背俞穴灸之可以温阳通腑，尤其对虚寒性的便秘、泄泻效果极佳。

## ⚡ 倪师经穴气化与破局心法

- **倪师如何推演此穴的气血流注与开阖机理**：倪师认为，背俞穴是“脏气所注”的地方。大肠俞就是大肠的腑气在背部转输、开阖的枢纽。大肠为传导之官，变化出焉。它的核心气化机理是**通降腑气、导滞泄浊**。当大肠气机壅滞，就会出现便秘、腹胀；当大肠气虚不固，就会出现泄泻、脱肛。大肠俞通过膀胱经的阳脉之气，能够温煦大肠，恢复其传化糟粕的功能。倪师常讲，这个穴还能“引气下行”，对于因腑气不通导致的浊气上逆、头晕脑胀，有很好的降逆破局之效。

- **子母补泻与五行生克运用心法**：大肠属金。在五行生克中，土生金，所以大肠的“母”穴是土穴（曲池），大肠的“子”穴是水穴（二间）。但大肠俞作为背俞穴，其补泻更侧重于**俞穴本身的调节**。倪师心法：**虚则补其母，实则泻其子**。若大肠虚寒，运化无力，出现久泻、脱肛，可在灸大肠俞的同时，配合补足三里（胃经土穴，土生金，补土以生金）。若大肠实热，燥屎内结，出现便秘、腹痛，可针泻大肠俞，并配合泻二间（大肠经水穴，金生水，泻子以夺实）。这是倪师在临床上灵活运用五行生克，通过背俞穴调腑的典型思路。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
    - **急症救逆**：对于急性肠梗阻、肠套叠引起的剧烈腹痛，针泻大肠俞可迅速缓解肠腑痉挛。
    - **慢性病调理**：各种慢性肠炎、肠易激综合征、习惯性便秘、慢性痢疾。
    - **妇科/儿科特效**：小儿疳积、消化不良引起的腹泻，灸大肠俞有奇效。对妇科中因盆腔瘀血导致的腹胀、便秘，也有调理作用。
    - **痛症特效**：腰腿痛，尤其是腰脊强痛、坐骨神经痛，属于大肠腑气不通、经络瘀阻者，大肠俞是局部取穴的必用之穴。

- **倪师经典对穴与排针组合**：
    - **大肠俞 + 天枢**：这是倪师常用的“俞募配穴法”。天枢是大肠的募穴，在腹部；大肠俞是背俞穴。一前一后，一阴一阳，直通大肠腑气，对便秘、泄泻有双向调节作用。
    - **大肠俞 + 支沟 + 上巨虚**：支沟是通便要穴，上巨虚是大肠的下合穴（“合治内腑”）。三穴合用，是治疗各种便秘的黄金组合。
    - **大肠俞 + 肾俞 + 命门**：用于治疗因肾阳不足、命门火衰导致的五更泄泻。灸此组合，可温肾暖脾，固肠止泻。

## 🗣️ 倪师讲义实录与针灸秘要

- **视频讲义中倪师讲此穴的原汁原味逐字稿金句**：
    “大肠俞，你看，在第十四椎下，旁开一寸半。你只要记得，第十四椎就是命门。命门旁开一寸半，就是大肠俞。所以，你找到命门，就找到大肠俞了。”
    “这个穴，针和灸都可以。但一般来说，我们用灸得多。因为很多大肠的问题，都是寒证、虚证。你灸大肠俞，一壮一壮地灸，那个热力透进去，肠子就开始蠕动，寒气和湿气就化掉了。”
    “你看那个病人，便秘很久了，肚子胀得很大。你针天枢，再针大肠俞，针一下去，病人就感觉到肠子里面在动，气在转。这就是俞募配穴，前后夹击，把那个堵住的气给通开。”
    “有的人，拉肚子拉了好几年，吃什么拉什么。这是大肠虚寒，不能收涩。你灸大肠俞，再灸足三里。足三里是胃经的合穴，属土。土能生金。你补土，就是补大肠。这叫‘虚则补其母’。灸几次，大便就成形了。”

- **实战手下针感体会**：倪师说，针大肠俞，针下去后，病人会有一种酸胀感，有时候会往下肢放散。如果是便秘的病人，针感好的话，病人会觉得肚子里面“咕噜咕噜”响，这就是气通了。如果是灸，灸到一定程度，病人会感觉一股热气从腰部透到肚子里面去，非常舒服。

- **医案故事**：倪师曾讲过一个案例。一个老太太，便秘十几天，肚子胀得像鼓一样，吃不下饭，人很虚弱。倪师一看，脉很弱，舌苔白厚。这是虚秘，不能再用泻药了。倪师就灸她的大肠俞和天枢，各灸七壮。灸完不到半小时，老太太就排了很多气，肚子就软下来了。第二天，大便就通了。倪师说，这就是艾灸的温通之力，它不像大黄、芒硝那样霸道，而是用温和的热力，把肠子里面的寒冰慢慢融化掉，让大肠恢复自己的蠕动功能。这就是“以火助气，以气行滞”的奥妙。
