# 百会穴 (GV20)

## 📍 经络归属与精准取穴法

- **所属经络**：督脉。百会为督脉与手足三阳经、足厥阴肝经之会，故又称“三阳五会”。在五输穴体系中，督脉本身不设井荥输经合，但百会居于头顶正中，为督脉入络脑之要穴，阳气极盛之处。
- **穴性定位**：百会不是五输穴，但它是**诸阳之会**。倪师讲，全身的阳气都往头上走，百会就是阳气聚得最满的地方，像一个“阳气总开关”。它统摄一身之阳，所以能升提、能醒神、能开窍。
- **倪师动态取穴法**：倪师取百会，不管是督脉还是膀胱经，都会用同一个手法——**两个耳朵尖对上去，画一条线；再把人中到后脑勺正中画一条线，两条线的交点就是百会**。这在《针灸大成》里叫“耳尖直上，前后正中”。倪师特别强调，不用背“前顶后一寸五分”那种死尺寸，耳朵一折，线一拉，直接定穴，当场就能摸到那个凹陷。针的时候，**沿皮刺，不是直刺**——百会肉薄，直刺容易扎到骨膜，沿皮平刺或者向前、向后斜刺五分到八分即可。灸的话，百会可以灸，而且适合灸，尤其是中气下陷、脱肛、久泻这些阳气升不上来的病，灸百会效果很好，壮数不拘，五壮、七壮、九壮都可以。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：百会的气化核心是“**引阳气上升，引浊阴下降**”。倪师讲，人头为诸阳之会，百会就是阳气的顶巅，像一根旗杆的顶端。当人阳气虚、中气下陷的时候，百会这个“顶巅”就塌了，所以要在这上面施针施灸，把阳气重新提起来。反过来，当人肝阳上亢、气血并走于上，百会又是“泄阳”的出口——比如头痛、眩晕、高血压，在百会放血或者针刺泻法，就是把上冲的阳气从这里放掉，引火归元。所以同一个百会，**虚则升提，实则泻降**，全看手法和辨证。
- **子母补泻与五行生克运用心法**：督脉本身不以五行配穴，但百会与肝经相交，与肾经相通。倪师常讲，**肾主骨生髓，脑为髓海，百会通脑**。所以下焦肾精不足、髓海空虚导致的头晕、健忘、痴呆，在百会施灸，就是“虚则补其母”——补火生土、补土生金、补金生水，最终把肾精提上来濡养脑髓。而肝阳上亢、面红目赤、头痛如裂，在百会放血或行泻法，就是“实则泻其子”——肝木生心火，泻百会就是泻心火以降肝阳。倪师在视频里说，你不要去死记五行生克，你只要记住：**百会这个穴，是阳气的总开关，该上的时候上，该下的时候下。**

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **急症救逆**：中风昏迷、晕厥、休克、癫痫发作——百会配人中、十宣放血，这是倪师急救的常用组合。
  - **中气下陷**：脱肛、胃下垂、子宫脱垂、久泻久痢——灸百会，配合灸关元、足三里。
  - **头痛眩晕**：巅顶头痛（厥阴头痛）、高血压头晕、美尼尔氏症——百会放血，或百会配太冲、风池。
  - **神志病**：失眠、健忘、痴呆、焦虑——百会配四神聪、神门、内关。
  - **鼻病**：鼻塞、鼻窦炎、过敏性鼻炎——百会配迎香、合谷。
  - **妇科/儿科**：小儿惊风、夜啼——百会配印堂、人中；子宫脱垂——百会配关元、三阴交。
- **倪师经典对穴与排针组合**：
  - **百会 + 关元 + 足三里**：这是倪师治中气下陷的“铁三角”。关元固本培元，足三里补中焦之气，百会升提阳气，三穴合用，把下陷的气机整个提起来。
  - **百会 + 人中 + 十宣**：急救三宝。中风、晕厥、中暑，先十宣放血，再人中、百会，这是倪师在急救法里反复强调的顺序。
  - **百会 + 太冲 + 风池**：肝阳上亢型头痛眩晕。百会泻阳，太冲平肝，风池疏风，从上到下把上冲的肝气降下来。
  - **百会 + 四神聪 + 神门**：失眠、健忘、脑力衰退。四神聪在百会前后左右各一寸，倪师说这是“给脑部通电”，百会为总开关，神门安神定志。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》督脉篇讲百会时原话（据视频讲义实录）：“**百会，你看这个名字，百会，百脉之会。你两个耳朵尖一拉，拉到头顶，正中一条线，后面从人中——不对，从后脑勺到人中拉一条线，交叉点就是百会。你摸上去，头顶正中间有个凹下去的地方，那就是百会。**”
- 倪师讲针法时特别强调：“**百会你不要直刺，直刺下去扎到骨头，病人痛死。你沿皮刺，往前刺、往后刺，五分、八分，够了。百会肉很薄，针下去要贴着皮走。**”
- 倪师讲临床体会：“**百会这个穴，你灸它，灸个五壮七壮，那个阳气一下就提起来了。脱肛的病人，你灸百会，灸关元，当场肛门就收上去了。小儿五六岁还在尿床，你灸百会，效果也好，为什么？阳气升不上来嘛。**”
- 倪师讲头痛案例：“**有个病人头痛十几年，痛在头顶，就是巅顶痛，厥阴头痛。我在百会放血，放出来那个血是黑的了，放完痛就去了大半。你记住，头顶痛，百会放血，一放就好。**”
- 倪师讲急救：“**中风昏迷，你先十宣放血，再人中，再百会。百会扎上去，针一进去，病人眼皮就动了。这个穴是通脑的，脑为髓海，百会就是髓海的盖子。**”
