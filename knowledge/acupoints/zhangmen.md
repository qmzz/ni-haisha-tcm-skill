# 章门穴 (LR13)

## 📍 经络归属与精准取穴法

章门穴，归属于足厥阴肝经。它是**脾之募穴**，同时又是**八会穴中的脏会**——也就是说，五脏的气血精微都在这扇门后汇聚。

倪师在讲肝经的时候特别强调：章门虽然长在肝经上，但它真正的身份是脾的募穴。募穴是什么？募者，幕也，就是脏腑之气在胸腹部汇聚开合的那个口子。章门就是脾脏在腹壁上的门户。而脏会又是什么？五脏六腑各有其精气，脏会就是统摄五脏精气的总开关。所以这一穴，一针扎下去，是同时打开了“脾之募”和“脏之会”两扇门。

关于取穴，倪师教的是**动态摸骨法**——不是拿尺子死量，是让病人手肘弯起来，整个手臂自然贴着胸胁壁。你顺着病人腋中线往下摸，摸到第十一肋骨的游离端，也就是那根肋骨最前端、软软尖尖的地方。倪师说：“你摸到那个肋骨头尖尖的地方，穴道就在那个尖端下方。”具体操作时，病人侧卧或者正坐都行，手肘弯着，你从腋中线一路往下推，推不动了——那就是第十一肋游离端，章门就在那里。

**下针深度**：倪师说，这里是肋间，不能深针。一般斜刺或平刺，0.5到0.8寸。你贴着肋骨边缘下针，不要直直地往腹腔里面捅。针尖方向可以沿着肋弓往内下方斜刺。

**禁针禁灸**：古籍有“章门禁灸”之说，倪师也讲，这里靠近肋骨末端和腹腔脏器，一般不灸。至于禁针，并不是绝对不能针，而是不能深针、不能直刺。你不懂解剖、不懂肋间结构，那就不要乱针。针章门，靠的是你手下的分寸感。

## ⚡ 倪师经穴气化与破局心法

倪师在《人纪·针灸篇》里讲肝经的时候，讲章门这一段是有层次的。

首先你要明白，肝经从大敦一路往上走，走到章门这里，经气已经开始进入腹胸区域了。章门在第十一肋游离端，这个位置正好是膈肌下方、脾脏附近。倪师说：章门的气化机理，关键在于“**引肝气入脾**”。肝属木，脾属土，木克土是常态，但正常的克是制约，不是伤害。章门就是肝木之气输注到脾土的一个转换站。肝气太旺的时候，这里会胀、会痛、会让你吃不下饭——那就是木在克土克得太过了。你针章门，或者灸章门（如果不怕灸的话），就是在疏通这个转换站，让肝气不要堵在这里跟脾土过不去。

再往深一层，章门是脏会。倪师讲八会穴的时候说，脏会章门、腑会中脘、气会膻中、血会膈俞、筋会阳陵、脉会太渊、骨会大杼、髓会悬钟（倪师取绝骨）。这八个会穴各有各的门道。章门作为脏会，它的气化范围是整个五脏系统——不局限于脾，不局限于肝。五脏之精气在这里汇聚、交换、流转。所以倪师在临床上用章门，不光治脾的病、肝的病，五脏中任何一个脏器的慢性虚损、气血不通，都可以在章门这里找到切入点。

关于子母补泻——这里要分清楚。章门在肝经上，肝经的五行属木。肝经的子穴是行间（荥穴，属火，木生火），母穴是曲泉（合穴，属水，水生木）。这是肝经本身的子母补泻。但是章门本身是脾之募穴，它在治疗脾虚证的时候，它的补泻逻辑要结合脾经的五行来走。脾属土，脾经的母穴是大都（荥穴，属火，火生土），子穴是商丘（经穴，属金，土生金）。所以你说“虚则补其母”——如果章门用来补脾，你要配脾经的母穴大都；如果章门用来泻脾，你要配脾经的子穴商丘。倪师说，募穴有双向调节作用，虚证可补，实证可泻，关键看你的手法和你配的穴。

## 🎯 临床主治与配穴组合手印

章门在倪师临床上的主治范围非常广，归纳起来有几大块：

**第一，一切脾虚腹胀、消化不良。** 倪师说，很多人吃完饭肚子胀得像鼓一样，你按他章门这里，他会觉得酸胀得受不了。这就是脾的募穴堵住了。针章门，再配上中脘、足三里，这是倪师常用的“开脾三针”组合。中脘是胃募、腑会，足三里是胃经的合土穴，章门是脾募、脏会，三者合起来，从上中下三个层面把脾胃的气机枢转开。临床上消化不良、胃胀、脾虚泄泻，这套组合是基础方。

**第二，肝脾不和、胁肋胀痛。** 倪师讲，现代人压力大，肝气郁结，郁久就克脾土。症状是什么？两胁胀痛、唉声叹气、吃不下饭、大便不调。这时候章门配上期门（肝之募穴）、太冲（肝经原穴），就是疏肝健脾的标准组合。期门在前，章门在侧，太冲在脚上——三针下去，肝脾同治。

**第三，痞块、癥瘕积聚。** 倪师在讲痞块的时候特别提到章门。他说，腹部有硬块、有积聚，不管是肝肿大、脾肿大还是腹部的良性肿块，章门是近取穴。你在痞块的旁边或者章门附近下针，用报刺法（就是针对痞块中心刺一针，再在周围刺几针），可以引导气血去冲击那个瘀滞。当然，这要配合远取穴，比如配上足三里、三阴交来扶正，配上太冲、行间来疏肝。

**第四，慢性虚劳、五脏亏虚。** 脏会章门，五脏的精气都在这。倪师说，一个人久病体虚、面色苍白、脉象细弱，不管他是什么病，你在章门这里轻轻下针，再配上关元、足三里、三阴交，这就是补五脏的正气。关元补元气，足三里补胃气，三阴交补三阴经的气血，章门把五脏的气机打开——这套组合，是倪师临床上用来“托底”的。

**经典对穴**：
- 章门 + 中脘 + 足三里 → 脾胃一切虚证、胀证
- 章门 + 期门 + 太冲 → 肝脾不和、胁肋胀痛
- 章门 + 关元 + 三阴交 → 虚劳、五脏亏虚
- 章门 + 脾俞 + 胃俞 → 脾虚泄泻、不思饮食（俞募配穴法）
- 章门 + 支沟 + 阳陵泉 → 胁肋痛、带状疱疹后遗痛

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲肝经章门这一段，原话大意是这样的：

“章门穴怎么找？你从腋中线往下摸，摸到第十一肋，那个肋骨头尖尖的地方，穴道就在骨头的下方。这个是脾的募穴，也是脏会。所以它管的范围很大——五脏的病都可以在这里治。你针下去的时候，不要直刺，要沿着肋骨边缘斜刺，因为里面就是脾脏，你直刺深针会扎到脾。”

“临床上最多用在哪里？肝硬化、脾脏肿大、腹部有积块。还有脾虚的人，你按他章门，他一按就痛，那就是脾有问题。你针章门，再配合脾俞，这是俞募治疗法，专门治脾的病。”

倪师还讲过一段很关键的话：“脏会章门。什么叫脏会？就是五脏之气在这里会合。所以一个人如果五脏都虚了，你问他哪里痛？他可能说不出来。但你去按他章门，他一定有反应。你针章门，再配关元、足三里，这就是把五脏的气机重新打开。这个穴，是治疗内科慢性病的钥匙。”

在针感体会方面，倪师说：“针章门，病人会有一种酸胀感从胁肋往里面透。有的人会感觉到气往中脘那边走。你手法要轻，不要捻得太重，因为这里是肋间，太重了病人受不了。”

还有一段关于痞块治疗的实录：“肚子上有硬块，你可以在章门附近下针，用报刺法。什么叫报刺？就是你摸到硬块，中心刺一针，然后在硬块的上下左右各刺一针。针完以后，你再灸一灸。但是记住，痞块的病，根源在肝脾。你光在局部刺，不解决肝郁脾虚的问题，痞块还会再长。所以章门配上太冲、足三里，这才是治本。”

倪师最后还强调了一句：“章门这个穴，是肝经上的脾募，是木土交界的地方。肝木克脾土，克得太过，就在章门这里堵住了。你把章门打开，肝气能疏，脾气能运，这就是木土合德。所以你看，一个穴，把肝和脾都管了。这就是针灸的妙处。”
