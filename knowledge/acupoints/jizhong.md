# 脊中

## 📍 经络归属与精准取穴法

- **所属经络**：督脉第十一椎下，即第十一胸椎棘突下凹陷处。督脉者，都纲诸阳，脊中位于督脉中段，前对中焦脾胃，后应肾间动气，为阳气升降之要道。
- **特定穴属性**：脊中非五输、非原络、非郄募、非八会，但倪师在《人纪·针灸篇》中将其归入“督脉中段调中焦”的枢要穴，与筋缩、至阳同列，属“以位取效”之穴——即不靠五行生克，而靠所处节段对应脏腑来治病。
- **倪师动态取穴与骨度折量法**：
  1. 先找大椎（第七颈椎下），再找至阳（第七胸椎下，约与肩胛骨下缘平齐），至阳下数四个椎突，即为第十一胸椎。  
  2. 倪师讲得直白：“你从大椎往下摸，摸到第七椎（至阳），再往下四个骨头，就是第十一椎。不要背尺寸，背了没用，要摸骨头。”  
  3. 取穴时病人俯卧或正坐低头，使胸椎棘突显露。  
  4. **下针深度**：倪师说“针五分，不可深”。因为脊中下紧贴脊髓腔，深刺入椎管，轻则气泄，重则伤髓。  
  5. **禁针禁灸法则**：《针灸大成》明言“禁灸”，灸之令人腰背佝偻。倪师补充：“禁灸，但可以针。针不过五分，得气即止，不留针或短暂留针。”此处古书有一说“禁针”，是怕粗针刺入椎管，倪师认为细针浅刺五分无害，但绝不深刺，也不灸。


## ⚡ 倪师经穴气化与破局心法

- **气机破局**：脊中不靠“子母补泻”，靠位置破局——第十一椎下，内应脾胃。倪师讲：“脊中能治脾胃，为什么？因为它在第十一椎下，正是中焦的地盘。癫痫、狂证、小儿疳积、脱肛，全在这里动手。”
- **开阖机理**：  
  - 督脉阳气在此处与脾胃之气相交，故能**醒脾开窍**、**镇痉安神**。  
  - 对癫、痫、狂，是借督脉阳气从背脊灌入脑髓，把蒙蔽神明的痰浊冲开。  
  - 对小儿疳积、脱肛，是升提中气、收摄下陷。  
  - 倪师原话：“脊中是治癫、痫、狂的大穴，也是治小儿疳积、脱肛的特效穴。你针下去，阳气就从后背往头上冲，痰浊就化开了。”
- **五行生克运用**：脊中非五输，不讲虚补母、实泻子。但倪师以“位”代“性”——第十一椎属中焦，中焦属土，土能生金、制水、培木。故脊中调土，即调全身气机之中轴。实证可配肝经太冲以泻风痰，虚证可配脾经足三里以补中气。


## 🎯 临床主治与配穴组合手印

**核心特效主治**：
- **癫痫、狂证**：倪师治癫、痫、狂，脊中配申脉、照海、鸠尾、少商。  
- **小儿疳积**：脊中配四缝、足三里、中脘。  
- **脱肛、痔疮下血**：脊中配长强、百会、承山。  
- **腰脊强痛**：脊中配肾俞、命门、委中。  
- **黄疸、脾胃虚弱**：脊中配至阳、脾俞、足三里。

**倪师经典对穴与排针组合**：
- 脊中 + 至阳：一上一下，督脉中段一线通，治黄疸、脾胃病。  
- 脊中 + 长强：一前一后，提肛举陷。  
- 脊中 + 百会：升提阳气，治脱肛、子宫下垂。  
- 脊中 + 鸠尾 + 少商：倪师治癫狂的“开窍三针”，脊中在后，鸠尾在前，少商放血，前后夹击。  
- 脊中 + 申脉 + 照海：治癫痫昼夜发作者，申脉通阳跷，照海通阴跷，脊中镇中轴。


## 🗣️ 倪师讲义实录与针灸秘要

> “脊中在第十一椎下。这个穴，禁灸。灸了会驼背。针可以，但不要深，五分。为什么？因为下面就是脊髓。你扎太深，病人腿就瘫了。”

> “脊中是治癫、痫、狂的大穴。你看癫痫的人，第十一椎下往往有压痛。你针下去，阳气从督脉往上冲，痰就化开了。我治癫痫，脊中、鸠尾、少商放血，效果很好。”

> “小儿疳积，肚子大大的，四肢瘦瘦的，你针脊中，再配合四缝放血，足三里、中脘，几次下来，小孩子胃口就开了。”

> “脱肛，你针脊中、长强、百会。百会往前顶，脊中往上提，长强收住，三针一下去，肛门口就紧起来了。”

> “这个穴，古人说禁针，是怕你扎太深。我用细针，扎五分，得气就停，从来没出过事。但你要记住——**脊中不灸，深刺必瘫**。”

**手下针感体会**：倪师说，针脊中得气时，病人常觉一股热流从背脊往上下走，或觉腰腹一紧。若针下如刺豆腐，空滑无阻，是刺入椎管之兆，须立即退针。
