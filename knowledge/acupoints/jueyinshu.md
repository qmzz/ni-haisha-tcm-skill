# 厥阴俞

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：厥阴俞属足太阳膀胱经，是**心包之背俞穴**。心包为心之外围，代心受邪，故厥阴俞本质上是心包络之气在背部转输、灌注的窗口。它不属于五输穴体系（井荥输经合），而是**背俞穴**这一特定穴类别。在五行归经上，心包经属火（厥阴风木配相火），故厥阴俞所聚之气与**火**密切相关，但又不同于心俞直接主火——厥阴俞偏于**相火之郁**与**心包络之气血瘀滞**。四穴并列于背：肺俞（金）、心俞（火）、厥阴俞（相火/心包）、膈俞（血会），厥阴俞恰处心俞与膈俞之间，主**上焦气机与心包络的交通**。

- **倪师动态取穴与骨度折量法**：倪师讲背俞穴取法，一贯强调“**先找骨，再量寸，后摸穴**”。厥阴俞在第4胸椎（T4）棘突下，旁开1.5寸。怎么摸？让病人低头，颈后最凸起的骨头是大椎（T1），往下数：T1、T2、T3、T4——第4个凸起骨节的下缘就是T4棘突下。旁开1.5寸怎么量？倪师说，用病人自己的**中指同身寸**不准，要用**骨度法**：肩胛骨内缘到后正中线的距离是3寸，取一半就是1.5寸。所以从T4棘突下向外摸到肩胛骨内缘，取中点，就是厥阴俞。倪师特别强调：**“背部的穴道，摸骨比量寸重要。骨节一摸到，穴道就八九不离十。”** 下针深度：倪师说背部穴位**斜刺或平刺**，针尖朝向脊柱方向，**斜刺0.5～0.8寸**，不可直刺深刺，因为内为肺脏，直刺深刺易造成气胸。禁灸？倪师不主张背部俞穴大量艾灸，尤其厥阴俞靠近心肺，**温和灸可，但不可大炷重灸**，以免火气入心包，反增烦躁。

## ⚡ 倪师经穴气化与破局心法

- **倪师如何推演此穴的气血流注与开阖机理**：倪师讲背俞穴，从来不是孤立地讲一个点，而是讲**一条气街**。他说：“**背部的俞穴，是五脏六腑之气通到背部的门户。** ”厥阴俞是心包络之气在背部的转输点。心包络是什么？倪师打比方：**“心是君主，心包是君主的城墙。外邪要来犯心，先打心包。所以厥阴俞这个穴，就是城墙上的烽火台。”** 它的气血流注机理偏于**开郁破滞、宽胸利膈**。当心包络被痰浊、瘀血、气郁所困，出现胸闷、心痛、心悸、呃逆、郁证时，厥阴俞处往往摸到**结节、条索或明显压痛**。倪师说，这就是**“气堵在城墙上了”**。针厥阴俞，等于在烽火台上点火——**引心包之气血重新流通，郁开则火自散，滞破则痛自止**。它不同于心俞直接补心火或泻心火，厥阴俞更偏于**调畅心包络的气机开阖**，使相火归位，不郁不亢。

- **子母补泻与五行生克运用心法**：厥阴俞本身不是五输穴，不直接参与子母补泻。但倪师在临床上会**借道厥阴俞来调心包经的虚实**。心包经属火，火之母为木（肝），火之子为土（脾）。若心包火虚（心悸、脉弱、四肢冷），倪师会在针厥阴俞的同时，**补肝经之母穴（行间）或补心包经之母穴（中冲）** ，此谓“虚则补其母”；若心包火实（心烦、口疮、胸痛、脉数），则**泻脾经之子穴（商丘）或泻心包经之子穴（大陵）** ，此谓“实则泻其子”。倪师心法：**“背俞穴是总开关，五输穴是分开关。总开关打开，分开关才好调。”** 厥阴俞就是心包络的总开关之一。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：厥阴俞的核心主治围绕**心包络气血瘀滞**展开。①**心胸痛症**：胸闷、胸痛、心痛彻背、心悸、怔忡，尤其是情绪激动后加重的胸痛，厥阴俞处必有压痛，针之立缓。②**郁证与失眠**：倪师讲，心包络郁则心神不宁，厥阴俞配神门、内关，专治**焦虑、抑郁、入睡困难、多梦**。③**呃逆与呕吐**：心包络之气上逆则呃逆，厥阴俞配膻中、中脘，降逆止呕。④**肩背痛**：厥阴俞所在位置的背痛、肩胛内缘痛，属心包络经气不利，针之特效。⑤**妇科**：心包络与肝经同属厥阴，厥阴俞配太冲、三阴交，治**痛经、月经不调**属气滞血瘀者。

- **倪师经典对穴与排针组合**：倪师用厥阴俞，从不单打独斗。①**厥阴俞 + 内关 + 公孙**：内关是心包络穴，公孙通冲脉，三穴合治**胃心胸一切疾患**。②**厥阴俞 + 心俞 + 膈俞**：三穴并列，治**冠心病、心绞痛**，倪师称之为“**背三针**”。③**厥阴俞 + 太冲 + 合谷**：开四关，调厥阴与阳明，治**郁证、失眠、更年期综合征**。④**厥阴俞 + 膻中 + 中脘**：治**呃逆、呕吐、食不下**。⑤**厥阴俞 + 天宗 + 肩井**：治**肩背痛连及心包**。倪师排针原则：**“先针背，后针腹；先针阳，后针阴。背俞穴用斜刺，腹募穴用直刺，一前一后，气就通了。”**

## 🗣️ 倪师讲义实录与针灸秘要

- **视频讲义中倪师讲此穴的原汁原味逐字稿金句**：倪师在《人纪·针灸篇》讲背部俞穴时，原话大意如下——“**你们看这个厥阴俞，在心俞的旁边。心包络的俞穴。心包是什么？心包是心外面的包膜。心脏有问题的时候，第一个反映在心包上面。所以你要治心脏病，不一定要针心俞，针厥阴俞一样有效。临床上，心脏病的病人，厥阴俞一按就痛，痛得跳起来。你针下去，针感会传到胸口，病人当场就感觉胸闷松开了。** ”倪师又说：“**背部的俞穴，我很少直刺。都是斜刺，针尖往脊柱方向走。为什么？因为你要引气到脊柱，脊柱是督脉，督脉是诸阳之海。气到督脉，阳气就起来了。** ”

- **实战手下针感体会**：倪师描述针厥阴俞的手感——“**针尖穿过皮肤，再进一层，会感觉针下有一层薄薄的阻力，那是背部的筋膜层。再轻轻推进，阻力突然消失，针下有一种空虚感，那就是气到了。这时候你轻轻捻针，病人会说，哎，有一股热流往胸口跑，或者往肩膀跑。这就是气至病所。** ”倪师强调，厥阴俞的针感路径不定，有人往心口走，有人往腋下走，有人往手臂内侧走——**“每个人堵的地方不一样，气自己会去找路。”**

- **医案故事**：倪师在讲义中举过一个案例——一位中年妇人，长期**胸闷、心悸、失眠**，西医诊断为“心脏神经官能症”，服药无效。倪师诊其脉，**左寸浮数，关部弦**，舌暗红。倪师先在**厥阴俞**处按压，妇人痛得叫出声来。倪师针厥阴俞，斜刺向脊柱，再针**内关、神门、三阴交**。留针二十分钟，妇人说**胸口像被打开了一扇窗**，当晚安睡。倪师说：“**这就是心包络郁住了。你不去解心包的郁，只吃安眠药，永远治不好。厥阴俞就是解心包郁的第一把钥匙。** ”还有一例**呃逆不止**的老先生，倪师针厥阴俞配膻中，针入呃止，倪师笑称：“**气一顺，嗝就停了。** ”
