# 中脘二

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：中脘属**任脉**，为**胃之募穴**，同时是**八会穴之腑会**。任脉本身无五输穴，但中脘作为胃募，直接通调胃腑之气；作为腑会，总管六腑（胆、胃、小肠、大肠、膀胱、三焦）之气机。胃属土，中脘位于任脉，任脉统诸阴，中脘居中焦，正当胃体中央，是土中之土、腑气总汇之处，故凡六腑之病，皆可取此穴调治。

- **倪师动态取穴与骨度折量法**：倪师讲，中脘取穴要找**心蔽骨（胸骨剑突）与肚脐的正中间**。所谓“心蔽骨至脐中为八寸”，中脘在脐上四寸。怎么摸？先摸到胸骨下缘那个尖尖的骨头（蔽骨），再摸到肚脐，两者连线取中点，就是中脘。不要用尺子量，用手指比，蔽骨到肚脐折成八寸，一半就是四寸。**下针深度**：倪师说，中脘可以针**一寸到一寸半**，看病人胖瘦。瘦人针一寸，胖人可针一寸半。**禁针禁灸法则**：中脘可灸，尤其虚寒胃痛、中焦寒湿，灸中脘效果极好。但针中脘时，倪师强调要注意**不可深针伤胃**——针到胃壁会有抵触感，不要再硬推。另外，**孕妇禁针中脘**，因其通腑气、动中焦，恐伤胎气。还有一条：**饭后不宜立即针中脘**，至少等一小时，否则胃气正盛，针刺易致恶心呕吐。

## ⚡ 倪师经穴气化与破局心法

- **倪师如何推演此穴的气血流注与开阖机理**：倪师讲，中脘是**中焦气化之总枢**。任脉之气从会阴上行，到中脘处正是**脾胃之气交汇的枢纽**。中脘的气化机理，倪师归纳为“**升清降浊、斡旋中焦**”八个字。胃主受纳，脾主运化，中脘居二者之间，针中脘能**引胃气下行**，同时**助脾气上升**。倪师特别强调：中脘能**引火归元**——当虚火上炎、面赤烦躁、胃气上逆时，针中脘可导上焦浮火下行，归于中焦土中，火生土，土伏火，火自归元。此外，中脘能**健脾行水**，中焦土虚则水湿泛滥，针中脘旺土制水，水湿自化。还能**升提中气**，中气下陷、胃下垂、子宫脱垂，取中脘配百会，一升一降，气机复位。

- **子母补泻与五行生克运用心法**：中脘为胃募，胃属土。倪师讲，**土之子为金，土之母为火**。虚则补其母——胃虚寒、纳呆、乏力，取中脘配**足三里**（胃经合穴，土经土穴）和**解溪**（胃经经穴，火穴，火生土），此即补母之法。实则泻其子——胃实热、便秘、口臭，取中脘配**厉兑**（胃经井穴，金穴，土生金）或**内庭**（胃经荥穴，水穴，土克水，泻水即泻土之实），此即泻子之法。倪师更强调，中脘本身作为腑会，**无论虚实皆可取**，虚则用补法（捻转补法、灸法），实则用泻法（提插泻法、留针久），但核心是**恢复中焦斡旋之能**，使土气自平。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **急症救逆**：中脘配**人中、内关、足三里**，治晕厥、休克、中暑昏仆。倪师讲，针中脘能引气归中，中气一复，神志自清。
  2. **慢性病调理**：一切**胃病**（胃痛、胃胀、反酸、嗳气、纳呆），中脘是首选。**脾虚湿盛**（腹胀、便溏、水肿），中脘配阴陵泉、三阴交。**胆胃不和**（口苦、胁胀、呕吐），中脘配阳陵泉、胆囊穴。
  3. **妇科/儿科特效**：**妊娠恶阻**，中脘配内关、足三里，和胃降逆止呕。**小儿疳积**，中脘配四缝、足三里，健脾消积。**痛经**属寒凝中焦者，中脘配关元、三阴交，温中散寒。
  4. **痛症特效**：**胃脘痛**，中脘配梁丘、足三里，急则治标。**腹痛**绕脐，中脘配天枢、气海。

- **倪师经典对穴与排针组合**：
  - **中脘配足三里**：倪师称此为“**治胃第一组合**”。中脘是胃募，足三里是胃经合穴，“合治内腑”，一募一合，前后呼应，虚实皆宜。
  - **中脘配内关、公孙**：内关通阴维，公孙通冲脉，二穴合治胃、心、胸之疾。再加中脘，直调胃腑，三层合围，治**胃心胸一切病证**。
  - **中脘配关元、气海**：此为“**中下二焦同调**”之法。中脘斡旋中焦，关元培元固本，气海升提气机。倪师讲，凡**虚劳、久病、中气下陷**，此三穴同用，灸针并施，效果如鼓应桴。
  - **中脘配百会**：治**胃下垂、子宫脱垂、脱肛**。中脘升中焦之气，百会升一身之阳，一针一灸，气机上行，下垂自复。
  - **中脘配四关（合谷、太冲）**：倪师讲，四关开气血之关隘，中脘调中焦之枢机。凡**气机郁滞、升降失常**之证，先开四关，再针中脘，气机通畅，诸症自解。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：倪师在讲中脘时，原话是：“**中脘这个穴啊，你千万不要小看它。它是胃的募穴，又是腑会。什么叫腑会？就是六腑的气都在这儿会。所以你不管胆有病、胃有病、小肠有病、大肠有病、膀胱有病、三焦有病，统统可以在中脘上做文章。**”倪师又说：“**中脘针下去，病人会感觉到一股热气往下走，胃里暖暖的，这就是中焦气化恢复的表现。如果病人喊痛，那是针到胃壁了，要退一点。**”

- **实战手下针感体会**：倪师讲，针中脘时，**针尖穿过皮肉，到达胃壁外层时，会有一种“抵触感”**，像针尖碰到一个气球，有弹性。此时不要再推，留针即可。病人会感觉**胃部有温热感、蠕动感**，甚至有人会打嗝、排气，这都是**中焦气机恢复、升降复位**的好现象。倪师说，如果针中脘后病人**呕吐**，那是手法太重，或饭后针之，要立即起针，让病人平卧休息。

- **医案故事**：倪师讲过一个案例：**一位中年妇女，胃痛十年，西医诊断为慢性胃炎、胃下垂。** 病人面黄肌瘦，纳呆腹胀，饭后胃坠胀，大便溏。倪师取**中脘、足三里、百会、气海**，中脘针一寸半，百会灸五壮，足三里针补法。第一次针后，病人即感胃部温暖，胀气大减。连续针治一个月，配合灸中脘、关元，病人胃痛消失，食欲大开，体重增加。倪师说：“**这就是中脘升提中气、斡旋中焦的力量。你光治胃不行，要治中气。中气一升，胃自然复位。**”

- **针灸秘要**：倪师特别强调，**中脘与下脘、上脘配合使用**，上脘治上焦胃气，中脘治中焦胃体，下脘治下焦幽门。三脘同用，治**一切胃病**。另外，**中脘透下脘**，是倪师常用手法，一针贯三脘，通调胃腑全程。但倪师警告：**透针要小心，不可伤及胃壁血管**，手法要轻柔，得气即止。最后，倪师说：“**中脘是胃的根，根深则叶茂。你把这个穴用好了，一半的胃病都不用愁。**”
