# 光明

## 📍 经络归属与精准取穴法

光明穴，足少阳胆经之络穴，别走厥阴肝经。络穴者，一穴通两经，胆肝同治之枢机也。足少阳胆经气血在此穴化光而动，故名“光明”——胆经之清阳之气从此处透达肝经，如烛照幽暗，开人眼目。

**经络属性定位：**

- 所属经络：足少阳胆经
- 特定穴属性：**络穴**，别走足厥阴肝经
- 五行归属：胆经属木，光明为络穴，沟通肝胆两经
- 位置：外踝尖上五寸，腓骨前缘

**倪师动态取穴法（大白话）：**

从外踝尖直上量五寸——这个“五寸”怎么来？用你自己手指的“一夫法”，四指并拢为三寸，再加两指就是五寸。或者从外踝尖到膝盖窝（委中）是十六寸，折半再取合适比例。摸到腓骨，贴着腓骨前缘下针，不要扎到骨头上。这是骨度折量法在光明穴上的具体运用。

**下针深度：** 直刺五分至八分，针感可向上下扩散。

**禁针禁灸：** 光明穴无特殊禁针禁灸之忌，但倪师强调——**孕妇禁针**，因胆经与肝经相通，肝主血室，动之恐扰胎气。灸法可温通，但络穴一般以针法为主，灸则助热，胆经有热者不宜灸。


## ⚡ 倪师经穴气化与破局心法

倪师讲光明穴，核心在一个“**通**”字。胆经是少阳，少阳为枢，枢机不利则目不明、耳不聪、胁肋胀。光明穴是胆经的络穴，络穴的作用是什么？**一穴通两经，胆肝同治。**

**气血流注与开阖机理：**

足少阳胆经从目锐眦起，循头角，下耳后，走人身之侧，至肩井，入缺盆，下腋，循胁，过季胁，至环跳，沿大腿外侧下行，出膝外廉，下辅骨之前，直下抵绝骨之端（光明穴所在），下出外踝之前，循足跗上，入小指次指之间。

光明穴位于小腿外侧中段，是胆经气血从“经”转入“络”的关口。**胆经多气少血**，其气清而扬，至光明穴处，经气如光透发，一支继续循胆经下行至足窍阴，一支从光明穴别出，走入肝经。所以光明穴是**胆气通肝、肝血养胆**的枢纽。

倪师心法：**胆经的气不通，肝经的血就过不来；肝经的血不足，胆经的气就无根。** 光明穴就是让这两者重新接上的开关。所以眼睛不好、看东西模糊、夜盲、目翳——不是眼睛本身的问题，是胆气不能上达、肝血不能上濡于目。光明穴一扎，胆肝之间的路打通了，清阳升上去，眼睛自然亮。

**子母补泻与五行生克：**

胆经属木，肝经也属木。肝胆相表里，五行同气。光明穴是络穴，络穴本身**不主补泻，而主通调**。但倪师讲，临床上用光明穴，要分虚实：

- **实则泻其子**：胆经实证，如偏头痛、胁肋胀痛、口苦、目赤，可在光明穴用**泻法**（针尖向外，迎而夺之），引导胆经实热从络脉泄出。
- **虚则补其母**：胆经虚证，如头晕目眩、视物昏花、夜盲、胆怯易惊，可在光明穴用**补法**（针尖向内，随而济之），引肝经气血来滋养胆经。
- **平补平泻**：一般眼疾、慢性调理，用**平补平泻**手法，得气即止，不需强求补泻。

倪师原话精神：**“光明穴是眼睛的开关，胆经的气通到肝经，肝开窍于目，所以眼睛的问题，光明穴统统可以治。”**


## 🎯 临床主治与配穴组合手印

**核心特效主治：**

1. **眼疾第一要穴**：目痛、夜盲、视物模糊、目翳、青光眼、白内障早期、眼睛干涩、迎风流泪。倪师说，眼睛的问题，不管虚实，光明穴都可以下针，再配合其它穴位。
2. **偏头痛、侧头痛**：胆经循行于头侧，光明穴通胆经，对少阳头痛有特效。
3. **胁肋胀痛**：胆经布于胁，肝经也布于胁，光明穴通两经，胁痛、胆囊炎、胆结石引起的胁痛均可取。
4. **下肢痿痹**：光明穴位于小腿外侧，近穴取治，可治小腿酸痛、腓骨神经痛、足踝无力。
5. **乳房胀痛**：胆经循胸过乳，肝经也过乳，光明穴通肝胆，对乳腺增生、经前乳房胀痛有辅助疗效。
6. **癫痫、狂证**：络穴通两经，少阳枢机不利导致的癫狂，光明穴可配太冲、丰隆。

**倪师经典对穴与排针组合：**

- **光明 + 睛明 + 太阳 + 风池**：眼疾全套。睛明局部取穴，太阳、风池疏风清热，光明远端通络，远近呼应，引气至目。
- **光明 + 太冲 + 期门**：肝胆同病，胁痛、口苦、目赤。太冲是肝经原穴，期门是肝之募穴，光明通肝胆，三穴合力，疏肝利胆。
- **光明 + 阳陵泉 + 悬钟**：胆经下肢组合。阳陵泉是胆经合穴（筋会），悬钟是髓会，光明是络穴，三穴同用，治下肢痿痹、筋骨无力。
- **光明 + 足三里 + 三阴交**：眼疾兼气血不足。足三里补中气，三阴交补三阴，光明通目络，此为补虚明目之组合。
- **光明 + 肝俞 + 肾俞**：肝肾两虚之目暗。肝俞、肾俞补肝肾，光明引气血上达于目，治老年性视力衰退。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》中讲光明穴时，话语直白，一针见血。以下为讲义实录精神：

**“光明穴，顾名思义，就是让眼睛光明。它是胆经的络穴，别走肝经。肝开窍于目，胆经的气通过光明穴络到肝经，肝血再往上走，眼睛就亮了。”**

**“你们看，胆经从眼睛旁边开始走，一路走到脚上。光明穴在小腿外侧，是胆经的络穴。什么叫络穴？就是这条经和那条经之间的联络站。胆经和肝经是表里经，光明穴就是它们的联络站。所以眼睛的问题，你扎光明穴，胆气通了，肝血上来了，眼睛就好了。”**

**“临床上，眼睛不好的人，你在他光明穴上下针，得气以后，他会觉得眼睛那边有感觉——有的说我眼睛亮了，有的说我眼睛发热，有的说我眼睛不干了。这就是气到了。”**

**“光明穴下针，不要太深，五分到八分就够了。针下去以后，要候气，得气后再行手法。眼疾一般用平补平泻，不要强求补泻。针尖可以稍微向上，引气上行到目；如果治下肢病，针尖向下，引气下行。”**

**“你们记住，眼睛的问题，光明穴是远端取穴的大将。近处取睛明、太阳、风池，远处取光明、太冲、足三里。远近配合，效果才好。”**

**“光明穴还有一个妙用——治偏头痛。胆经走头侧，偏头痛是少阳头痛。你在光明穴下一针，再配太阳、风池，头痛立减。为什么？因为胆经的气通了，头上的郁结就散了。”**

倪师还提到一个实战体会：**“有的病人眼睛模糊，你扎光明穴，针一下去，他马上觉得眼睛松了。这不是心理作用，是胆经的气真的通了。络穴的作用就是这样，一穴通两经。”**

**针灸秘要总结：**

1. 光明穴是**眼疾远端取穴第一要穴**，不论虚实，皆可下针。
2. 针尖方向决定气的走向：**向上引气至目，向下引气至足**。
3. 络穴以**通**为主，手法以平补平泻为常，实则泻、虚则补。
4. 配穴要**远近呼应**：局部取睛明、太阳、风池，远端取光明、太冲、足三里。
5. 孕妇禁针，胆经有热者慎灸。
