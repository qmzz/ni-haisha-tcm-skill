# 臂臑外

> 说明：倪海厦人纪针灸篇与《针灸大成》原典中，**“臂臑外”并非十四经穴中的一个独立标准穴名**，而属于**臂臑穴外侧邻近区域**的取穴经验说法。若临床上要严格归经论治，臂臑穴本体属**手阳明大肠经**，为**手阳明络脉之分野**，与手太阳、手少阳、阳维脉气相交会；所谓“臂臑外”，倪师常用以指**臂臑穴向外侧循按所触及的敏感点、压痛点或结节点**，按“以痛为腧”与经络所过取之，归入手阳明大肠经外侧支别来用。下面按倪师讲法，把它当作**臂臑外应点**来彻底展开。

---

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：臂臑本穴归**手阳明大肠经**，为**手阳明络之会**，又为**手阳明、阳维之会**（《针灸大成》）；倪师讲“臂臑外”时，不把它死守成一个点，而是以手阳明经筋、络脉外侧循行处为界，凡臂臑向外侧扪及**筋结、凹陷、压痛、麻电感**者，皆可作臂臑外应点用。论五行，大肠经属**金**；论气血开阖，臂臑居肩髃之下、曲池之上，是**阳明经气由肩走肘的转输关卡**。倪师临床若取此区，母穴多取**曲池**（土生金）、子穴多取**二间**（金生水），这是手阳明大肠经“虚则补其母、实则泻其子”的正法；臂臑外应点则按“阿是”与“经筋所过”配合使用，不另立五行穴性。

- **倪师动态取穴与骨度折量法**：倪师取穴从来不是死量寸，而是先叫病人**手臂自然下垂，或者手叉腰、肘微屈**，让三角肌与肱二头肌放松，然后从**肩髃**往下摸，摸到三角肌止点附近，再往**外侧**旁开一点，按到那根**又酸又胀、甚至往肘或肩头窜**的点，这就是“臂臑外”的活穴。用骨度讲：肩髃至曲池为**一尺**（12寸），臂臑在**肩髃下七寸**，曲池上五寸；臂臑外则应点常在此穴**向外旁开约半寸到一寸**之间，以手下筋结为准。下针法：**直刺或略向肩方向斜刺八分到一寸半**，得气为度，**不灸或慎灸**；若局部红肿热痛、皮肤溃烂、明显感染，**禁针**；孕妇臂臑区一般不做强刺激，倪师也不主张在此处乱用重泻。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师讲，手阳明大肠经从**商阳**起，一路沿臂外侧上走，到**肩髃**、**巨骨**，再上颈贯颊。臂臑这个位置，正好是**阳明经气由肘上肩的“关口”**。如果这里被风寒湿痹、劳损伤筋、或长期抬重物卡住，气就不上肩，肩臂就出现**抬不起、举不直、酸麻扯痛**。所以臂臑外应点的作用，不是单纯“止痛”，而是**开肩臂之关、通阳明之络、散局部结气**。倪师常用一句话：**“这里一松开，气就能上肩；气一上肩，手才有力。”** 若兼颈项强、肩背沉，则配合**天宗、肩外俞、曲池**，使阳明、太阳、少阳的气一起转开；若因脾胃虚弱、痰湿流注臂络，则要回到**足三里、阴陵泉、丰隆**健脾行湿，再取臂臑外点做局部开结，这叫**先理中焦，再开外关**。

- **子母补泻与五行生克心法**：手阳明大肠经属金。**虚则补其母**——土生金，母穴是**曲池**；**实则泻其子**——金生水，子穴是**二间**。倪师心法不是死记，而是看证：若臂痛**隐隐、无力、遇劳加重、脉弱**，偏虚，取**曲池补之**，再配臂臑外应点轻刺久留，使气血慢慢灌过去；若臂痛**胀、热、拒按、脉实**，偏实，取**二间泻之**，再在臂臑外点用较强手法开泄。若病在筋、在络、在局部结滞，则以臂臑外应点为主，配**合谷、曲池、肩髃**，这是“经络所过，主治所及”；若病人还有**颈项强、头痛、牙痛、鼻塞**等阳明头面证，则臂臑外点可作辅助，真正主线仍在**合谷、曲池、迎香**。倪师反复强调：**五行补泻是调气机，阿是开结是通道路，两者一主一辅，不能混。**

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：臂臑外应点在倪师讲法里，最拿手的是**肩臂痛、抬举不利、臂麻、臂外侧酸胀、肩周炎、三角肌劳损、肱二头肌肌腱炎、颈肩综合征**；也可用于**肩臂局部寒湿痹痛、外伤后筋结不散**。若是阳明经气壅滞引起的**肩前痛、肘外侧痛**，取之最合。急症方面，若突然**肩臂不能举、痛连颈项**，先取**合谷、曲池、肩髃**，再在臂臑外点找压痛点下针，常常针下痛减。慢性调理方面，若**脾胃虚、痰湿重、手臂沉重麻木**，则不能只扎局部，要配**足三里、阴陵泉、丰隆**，从脾胃化痰湿，再取臂臑外点开络。妇科、儿科一般不用此穴作主穴；但产后或体虚妇人若臂痛，仍以**补气血、调脾胃**为主，局部轻取即可。

- **倪师经典对穴与排针组合手印**：
  - **臂臑外点 + 肩髃 + 曲池 + 合谷**：治肩臂痛、抬举困难，是手阳明主线组合。
  - **臂臑外点 + 天宗 + 肩外俞 + 后溪**：治颈肩背牵连痛，太阳、阳明同调。
  - **臂臑外点 + 曲池 + 手三里 + 外关**：治臂外侧麻痛、肘腕不利，兼顾少阳、阳明。
  - **臂臑外点 + 足三里 + 阴陵泉 + 丰隆**：治痰湿流注、臂重麻、体胖湿盛者。
  - **臂臑外点 + 合谷 + 太冲（开四关）**：若臂痛兼气机郁滞、痛无定处，先开四关，再取局部。
  - **臂臑外点 + 内关 + 公孙**：若臂痛兼胸闷、胃心胸不舒，先调胃心胸，再治臂。
  - **臂臑外点 + 阳陵泉 + 绝骨**：若筋痛、痿软、颈肩筋急，取筋会、髓会，再开局部。
  倪师排针讲究**先远后近、先上后下、先调气后开结**；不是哪里痛就只扎哪里。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师讲肩臂痛时常说：**“你不要只盯着肩髃，肩髃下面、臂臑外面那一带，你去按，常常有一个点，病人会叫出来。那个点就是你的穴。”** 这就是臂臑外应点的活法。
- 又讲：**“手阳明从手走到头，臂臑这里卡住，气上不去，肩就抬不起来。你把它松开，再针曲池、合谷，气一过去，手就轻了。”**
- 手下针感：倪师描述此区得气，不是单纯酸，而是**酸胀中带一点往肩或往肘窜的感觉**；有时针下去病人会说“热热的散开”，这是阳明经气被引动。若针下**空空如也、无酸无胀**，说明取点不准，或者病人气血太虚，要先补**足三里、气海**，不能硬泻。
- 医案故事：倪师曾讲一位肩痛患者，肩髃、曲池都扎了，效果一半；后来在**臂臑外侧**摸到一个硬结，针下去后病人肩头一松，手当场抬高许多。倪师说：**“经穴是固定的，病点是活的；固定穴治经，活点治结。两个合起来，才是针灸。”**
- 又提醒：**“臂臑外这一带，靠近筋和络，针不要乱深刺，也不要用艾灸猛烧；局部有炎症、红肿、肿瘤、不明硬块，先查清楚，不要乱针。”** 这是倪师在实战中反复交代的秘要。
