# 中府

## 📍 经络归属与精准取穴法

- **所属经络**：手太阴肺经。中府为**肺之募穴**，同时是**手足太阴二脉之会**（《针灸大成》明确记载：“中府，云门下一寸，乳上三肋间陷中，动脉应手，仰而取之。肺之募也。手足太阴二脉之会”）。募穴者，脏腑之气汇聚于胸腹部之穴也，肺气直接在此处汇聚、转输。倪师在讲肺经时特别强调：中府是肺的募穴，肺有病，在这里下针，效果最直接。它不是五输穴里的井荥输经合，但它管的是整个肺的气化大局，比五输穴更贴近脏腑本身。

- **倪师动态取穴与骨度折量法**：怎么找？倪师讲得非常白话——你先在胸前摸到锁骨，锁骨外端往下走，找到第一个凹陷，那个凹陷就是云门。云门下一寸，就是中府。但这个“一寸”不是拿尺子量出来的死板一寸，倪师说：**你摸到云门后，手指往下一按，按到那个肋骨缝隙里，病人会酸胀得想躲，那就是中府**。更精准的找法：从乳头往上数，数到第三根肋骨间隙，在锁骨中线外侧一点点，你按下去，有个凹陷，那个地方就是中府。仰而取之——让病人仰卧或者仰靠，手臂自然放松，胸部展开，穴位才露得出来。倪师反复交代：**找穴不能死记尺寸，要用手去感受那个凹陷和动脉应手的感觉**。中府穴下有大动脉（腋动脉分支），你按到正确位置，指下会有微微的动脉搏动感。

- **下针深度与禁针禁灸法则**：倪师在视频里讲得很清楚：中府下针，**针尖向着肋骨方向斜刺或者平刺，深度约一寸到一寸半**。绝对不可以直刺太深，因为底下就是肺脏。尤其瘦人，胸壁薄得像纸，你直刺下去，针尖穿过肋间隙，直接扎到肺，那就是气胸，会出大问题。倪师的原话大意是：“你扎中府，针下去要贴着肋骨走，不要往里面钻。心里要有数，底下是肺，你把肺扎破了，病人当场就喘不过气来。”至于灸法，中府可以灸，但倪师说肺热、肺燥、咳黄痰、吐血的时候不灸，因为灸是火，火克金，肺已经热了你还加火，那是火上浇油。虚寒性的咳嗽、气喘、胸闷，可以温和灸中府，配合肺俞、膏肓，效果很好。


## ⚡ 倪师经穴气化与破局心法

- **中府的气血流注与开阖机理**：倪师从五行生克来推演——肺属金，金主气，主肃降，主皮毛。中府是肺的募穴，是肺气在胸壁上的“开口”。你可以把它想象成肺在体表开的一扇窗户。肺气从这里面透出来，也从这里收回去。当肺气壅塞、痰浊闭阻的时候，中府这个地方按下去会痛、会闷、会酸胀，那就是肺气在这个窗口堵住了。倪师说：**中府开，则肺气宣发肃降有路；中府闭，则胸闷气短咳喘齐来**。所以中府这个穴，本质上是一个“开肺窍、利肺气、降肺逆”的开关。它不直接补肺，也不直接泻肺，它的作用是让肺的气机恢复流转。肺气一降，水液跟着下行，小便就通畅了——这就是倪师常讲的“肺为水之上源，提壶揭盖”的道理。中府就是那个揭盖子用的穴位。

- **子母补泻与五行生克运用心法**：严格来说，中府不是五输穴，不能直接套用“虚则补其母，实则泻其子”的子母补泻公式（肺经的子母补泻在太渊、尺泽上做）。但倪师在实际运用中，把中府的五行属性归到“金中金”——它本身就是肺金之气汇聚之处，所以它体现的是肺金最本真的状态。当你需要补肺气的时候，中府配合太渊（肺经母穴，土生金）一起用，中府打开窗户，太渊把土气灌进来生金，这叫“开门迎母”。当你需要泻肺实的时候，中府配合尺泽（肺经子穴，金生水）一起用，中府把实邪透出去，尺泽把金气导入水中泄掉，这叫“开闸放子”。倪师的心法是：**募穴是脏气的门，五输穴是调整脏气的手。门开了，手才能伸进去干活**。没有中府这个门，你光在五输穴上做补泻，效果隔靴搔痒。

- **中府与云门的先后关系**：倪师专门讲过云门和中府的区别。云门在上一寸，中府在下一寸。云门更偏向于宣散肺气到皮毛，中府更偏向于调理肺气在胸中的升降。咳嗽初起、表邪束肺，先取云门开表；咳嗽日久、痰阻胸中，必取中府化痰降逆。两个穴常常一起用，一上一下，一开一降。


## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **急性咳嗽、气喘、胸闷憋气**：中府是首选穴之一。尤其是那种感觉气吸不到底、胸口像压了块石头的，针中府立竿见影。倪师说这叫“开胸降气”。
  - **慢性支气管炎、肺气肿、哮喘缓解期**：中府配肺俞、膏肓、足三里，长期调理，能显著减少发作频率。
  - **胸痛、肋间神经痛**：中府所在的位置正好是胸壁，局部取穴，疏通胸中气机，痛随气散。
  - **肺经循行部位的痛症**：比如肩膀前侧痛、手臂内侧前缘痛，中府作为肺经起始附近的穴位，能疏通整条经的气血。
  - **皮肤病**：倪师讲“肺主皮毛”，很多皮肤病根源在肺。中府开肺气，配合合谷、曲池，对荨麻疹、湿疹有辅助效果。

- **倪师经典对穴与排针组合**：
  - **中府 + 肺俞**：这是俞募配穴法。前面募穴中府，后面背俞肺俞，一前一后，一阴一阳，把肺的气机从前后同时打开。倪师说这是治肺病的基本盘。
  - **中府 + 太渊 + 尺泽**：咳喘急性发作时，中府开胸，太渊补肺气，尺泽泻肺实。三针下去，气就顺了。
  - **中府 + 膻中 + 内关**：胸闷、心慌、气短，感觉气堵在胸口上不来。膻中是气会，内关通阴维脉治心胸，中府开肺窍。三穴合用，胸中大气一转，诸症自消。
  - **中府 + 云门 + 天府**：肺经在胸臂部的三连穴，从胸到臂一路通气，治上肢内侧痛麻效果极好。


## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味金句**：
  “中府是肺的募穴，募就是召集、汇聚的意思。肺的气在这里集合，所以你肺有问题，这里一定会有反应。你按按看，咳喘的人，中府按下去，十个有九个会痛得叫出来。”

  “下针中府，你要记住，针是贴着肋骨走的，不是往肺里面扎的。你心里要有解剖的概念，底下是肺，你扎深了就是气胸。胆大心细，这四个字在这里最要紧。”

  “云门和中府，一个是开门的，一个是关门的。肺气该出的时候出不去，用云门；肺气该降的时候降不下来，用中府。一开一降，肺就舒服了。”

  “肺为水之上源。你肺气一降，小便就通了。所以有些病人小便不利，你以为是膀胱的问题，其实是肺气不降。中府一下去，肺气一降，小便哗啦就出来了。这叫提壶揭盖。”

- **实战针感体会**：倪师在视频里演示过，针中府的时候，病人会有一种**气往下走、胸口突然松开**的感觉。有的病人当场就会深呼吸一口，说“唉，舒服了”。针尖到达肋骨面的时候，医者手下会有一种**针尖抵住骨面的抵触感**，这时候不能再进针，就在这个深度做捻转，让气机往周围扩散。如果病人说针感往手臂内侧窜，那是气循经走，效果更好。

- **医案故事**：倪师讲过一个案例——有个老太太，咳了三个月，西药吃了无数，止咳糖浆当水喝，就是不好。倪师一看，老太太胸闷，痰白黏，咳起来弯着腰，中府一按就痛得缩手。倪师取中府、肺俞、太渊、丰隆，针下去不到十分钟，老太太说胸口那块石头搬开了。留针二十分钟，起针后老太太咳出一大口白痰，当场就说“好了大半”。倪师说：这就是募穴的力量，你把肺的门打开，痰自己就出来了，不需要你用力去咳。
