# 大横

## 📍 经络归属与精准取穴法

- 大横穴归属于**足太阴脾经**，在腹中部，距脐中旁开四寸。此穴在《针灸大成》中归入足太阴脾经，是脾经在腹部横行而过的要穴——大横，顾名思义，横者，横行之谓也，从腹侧横行向内联络脾经腹部的气血网络。

- 倪师在讲脾经腹部穴位时特别强调：**大横不是五输穴，也不是原络郄募**。你在五输穴的子母补泻体系里找不到它，它走的是另一条路。大横的定位关键在于“四寸”这个数——不是三寸，不是五寸，是以肚脐为中心，旁开四寸。你跟天枢要分清楚：天枢在旁开两寸，大横在旁开四寸。倪师原话：“肚脐正中，旁开两寸是胃经的天枢，再外开两寸，就是脾经的大横。”

- 倪师动态取穴法：让病人仰卧，先找到神阙穴（肚脐正中），然后以乳头到中线的距离作八寸折量来算——这个骨度折量法倪师讲得很直白：“你从乳头往下拉一条垂直线，乳头到腹部正中线是八寸，取一半就是四寸。”从肚脐水平往外量四寸，就是大横。你摸的时候不要太用力按，大横这个位置在腹外斜肌和腹横肌的交界区域，肌肉层不厚，**针下去不要深，一寸左右就到了**。倪师讲腹部穴位进针有一个大原则：**腹部像豆腐，针下去要像蜻蜓点水一样，慢慢地、缓缓地进，不要猛扎**。大横直刺一寸到一寸五分，针感是局部酸胀，有时候会往旁边扩散。

- 禁针禁灸法则：大横这个穴，倪师在《人纪》里没有特别强调禁针，因为它在腹壁肌肉层，相对安全。但有一个大原则你必须守住——**孕妇禁针，腹部穴位一律禁深刺**。尤其是大横这种在腹侧偏外位置的穴位，如果针得太深，伤到内脏的风险不是没有。倪师反复讲：“肚子上扎针，你摸到的是皮和肉，但里面是什么？是肠子！你扎太深，肠子穿孔了，那是要命的。”所以一寸到一寸五分，得气即止，不要贪深。灸法方面，大横可以灸，尤其是脾虚寒证、腹部冷痛的时候，艾灸大横能温运脾阳。但热证、阴虚火旺者不灸。

- 大横与带脉的关系：倪师提到过，大横虽然不是带脉的穴位，但它所在的位置跟带脉循行高度重合。带脉“约束诸经”，绕腰一周，大横正好在带脉的路径上。所以你针大横的时候，实际上是在调动带脉和脾经两条系统的气血。这一点在配穴上非常有用。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演大横的气血流注机理，核心就一个字：**横**。脾经的气血从足大趾隐白穴起来，一路沿腿内侧往上走，到了腹部，它需要有一个横向的分布和扩散。大横就是脾经气血在腹部横向布散的关键节点。倪师的原意是：**脾主运化，运化不是一条线在走，是整个面在布散**。大横的作用就是帮助脾的气血在腹部这个“面”上均匀铺开，不让气血堵在一条线上。

- 从开阖机理来讲，大横走的是**开**的路子。它把脾经的气血从纵向的经络主干上“开”出去，布散到腹壁的每一寸。所以当脾的运化功能不足、气血布散不均匀的时候，腹部就会出现各种问题——胀、痛、硬块、冷。大横就是用来打开这个横向布散通道的。

- 倪师在讲脾经时反复强调一个核心病机：**脾虚则生湿，湿盛则困脾**。大横的气化功能，倪师归纳为“**健脾行水、通调腹气**”八个字。它不让水湿停留在腹部，通过脾的运化把水湿推走。同时它还有一个作用——**升提中气**。你注意，大横虽然在腹侧，但它的经气跟中焦的气机升降有密切关系。脾气主升，胃气主降，大横在腹部横向的位置，恰好是调节这个升降的枢纽。

- 关于子母补泻与五行生克在大横上的运用，倪师讲得很实在：**大横本身不是五输穴，所以不能直接用它来做子母补泻**。但是你可以通过大横来配合脾经的五输穴，达到补母泻子的效果。脾经五行属土，脾经的母穴是少府（荥火穴，火生土），子穴是大都（荥火穴？不对，脾经的子穴是商丘，经穴，金，土生金）。倪师在《人纪》里的用法是：**虚证，你取大横配上脾经的母穴（大都穴，荥穴属火，火生土）来补；实证，你取大横配上脾经的子穴（商丘穴，经穴属金，土生金）来泻**。大横在这里的角色，是把补泻的效果横向扩散到整个腹部。光扎母穴子穴，效果是纵向的、线性的；加上大横，效果就变成了面状的、整体的。这就是倪师讲的“**点面结合**”。

- 还有一层心法：大横配合带脉。倪师讲过，带脉病“腰溶溶如坐水中”，整个腰腹松松垮垮的，没有约束力。大横能调动带脉的约束功能。所以在治疗中气下陷、腹部坠胀、内脏下垂这类病的时候，大横是一个隐藏的杀手锏。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **腹痛、腹胀、腹泻**：大横最直接的主治。尤其是那种绕脐腹痛、腹部胀满、肠鸣泄泻，属于脾虚湿盛的类型，针大横效果来得快。倪师的刺法是直刺一寸，得气后留针二十分钟，配合艾灸更佳。
  - **便秘**：大横能通调腹气，对脾虚型便秘（大便不硬但排不出来，没有力气推）效果很好。倪师会用大横配支沟、照海。
  - **痢疾、肠鸣**：大横对肠道的气机紊乱有调节作用。倪师在讲针灸治疗肠胃病时，腹部取穴常用天枢、大横、关元一组。
  - **腹部肥胖、水湿积聚**：大横能健脾行水，对腹部水肿、水湿型肥胖有辅助作用。倪师说“肚子大大的、松松的，那是脾的问题，针大横、水分、阴陵泉。”
  - **妇科病**：痛经、月经不调属脾虚血少者，大横可以配三阴交、血海。
  - **中气下陷、内脏下垂**：大横配百会、气海、足三里，有升提中气的效果。

- **倪师经典对穴与排针组合**：
  - **大横 + 天枢**：一脾一胃，一内一外。天枢在旁开两寸，大横在旁开四寸，两个穴一起针，脾胃同调，腹部的气机就整个转动起来了。倪师讲“天枢是胃经的穴，大横是脾经的穴，两个并在一起用，肚子中间的气就活了。”
  - **大横 + 中脘 + 关元**：这是倪师常用的腹部“三焦排针”变法——中脘在中焦，关元在下焦，大横在侧旁。三针一下，整个腹部的气血全覆盖。治一切腹痛、腹胀、消化不良。
  - **大横 + 足三里 + 阴陵泉**：脾虚湿盛的标准组合。足三里补脾胃之气，阴陵泉利水湿，大横把运化的效果横向布散到全腹。倪师说“这是治肚子胀、大便稀、身体重的一组好穴。”
  - **大横 + 公孙 + 内关**：公孙通冲脉，内关通阴维，这是八脉交会穴的经典组合，治胃心胸的病。加上大横，把治疗的范围从胸胃扩展到整个腹部。倪师在讲公孙内关时特别提到“如果你肚子也胀，加上大横或天枢，效果更好。”
  - **大横 + 带脉 + 五枢**：治疗带脉病、腰腹松弛、中气下陷的隐藏组合。这三个穴都在腰腹一圈上，针下去能重新“勒紧”带脉。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲脾经腹部穴位时，原汁原味的讲法是：“**大横呢，在肚脐旁开四寸。你看，天枢在两寸，大横在四寸。这个穴道我们下针的时候，不要太深，一寸就到了。它的功能是什么？是帮助脾脏运化，让肚子里的气能够散开。** ”

- 倪师讲腹部扎针的手下体会：“**你针大横的时候，针尖穿过皮肤，再往下一点，会感觉到一层薄薄的肌肉，那就是腹外斜肌。这时候针下有一种韧韧的感觉，不是很硬，也不是空的。你得气的时候，病人会觉得局部酸酸的、胀胀的，有时候会往旁边扩散开。这就对了。** ”

- 倪师在讲腹部穴位禁忌时的原话：“**肚子上扎针，你想想看，下面是肠子。你针太深，肠子破了，那就是腹膜炎，要开刀的。所以腹部穴位一律浅刺，一寸到一寸半，得气就好。你不要想着扎深一点效果更好，那是外行。** ”

- 倪师的医案故事：在讲脾经与腹部病证时，倪师提到过一个案例——有个病人肚子胀得像鼓一样，吃不下饭，大便稀，人没力气。倪师取了中脘、天枢、大横、足三里、阴陵泉，针了一次，病人就说肚子松了，当天晚上大便就正常了。倪师说：“**这就是脾虚湿盛的腹胀，你光补脾不行，还得让气散开。大横就是干这个的——把脾经的气横着散出去，肚子就不胀了。** ”

- 倪师还有一个很重要的提醒：“**大横这个穴，你如果遇到孕妇，绝对不要针。腹部穴位，怀孕的时候一律避开。你可以在腿上取穴，足三里、三阴交（孕妇也禁针三阴交，此处倪师原意是取脾经其他穴位配合），但腹部不要动。这是规矩。** ”

- 倪师讲大横与水分穴的配合：“**水分穴在肚脐上一寸，是分开水跟气的。大横在旁开四寸，是让脾把水运走的。两个穴一起用，一个分水，一个运水，肚子里的水湿就没有了。** ”
