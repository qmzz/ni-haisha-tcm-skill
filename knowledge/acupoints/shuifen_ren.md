# 水分二

## 📍 经络归属与精准取穴法

- **所属经络**：任脉。水分穴是任脉上的穴位，位于脐上一寸。
- **特定穴属性**：水分穴是任脉的**分水穴**，在倪海厦老师的体系中，它被视为**任脉的“水分”穴**，是**水液代谢的分水岭**。它并非五输穴，但它是**任脉上调理水液代谢的关键穴位**。
- **倪师动态取穴与骨度折量法**：
    - **怎么找**：从肚脐（神阙穴）正中心，**沿着任脉（前正中线）往上量一寸**（也就是一个大拇指的宽度）。倪师强调，你要先找到肚脐，然后**往上摸**，摸到一寸的位置，那里就是水分。
    - **摸骨找穴**：肚脐中央是神阙，往上就是水分、下脘、建里、中脘……倪师说，你摸的时候，**不要只摸皮**，要摸到**腹白线**（腹正中线）的缝隙，穴位就在这条线上。
    - **下针深度**：**针一寸到一寸半**。倪师说，水分穴下针，**一般是直刺**，针下去后，病人会感到**酸胀**，有时候会**扩散到整个腹部**。
    - **禁针禁灸法则**：
        - **禁针**：倪师特别强调，**水分穴下针要小心**。如果是**腹水、水肿**的病人，**不要针**，因为针下去水会跑出来，容易感染。**孕妇禁针**，因为会动胎气。
        - **禁灸**：**一般不灸**。倪师说，水分穴是**水分岭**，灸了反而会让水液停滞，除非是**虚寒性的水肿**，才考虑用灸，但也要谨慎。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演的气血流注与开阖机理**：
    - 倪师说，**水分穴是“水”的分界点**。肚脐以上是**水**，肚脐以下是**水**，但水分穴是**水液代谢的枢纽**。
    - 它的机理是：**健脾行水、分利水湿**。当人体水液代谢失常，水湿停滞，就会在腹部形成**水肿、腹水、小便不利**。水分穴能**打开水液代谢的开关**，让水湿从小便排出。
    - 倪师比喻：**水分穴就像水龙头**，打开它，水就能流走。如果关着，水就积在肚子里。
    - 它还能**引火归元**，因为水能克火，当水液代谢正常，虚火就不会上炎。
- **子母补泻与五行生克运用心法**：
    - 水分穴本身不是五输穴，但倪师在运用时，会结合**五行生克**。
    - **虚则补其母**：如果病人**脾虚水肿**，倪师会**补水分**，因为脾属土，土生金，但水分是任脉穴，任脉属**水**，所以补水分就是**补土生金**，再间接**金生水**，让水液代谢恢复。
    - **实则泻其子**：如果病人**水湿泛滥**，倪师会**泻水分**，因为水能生木，泻水分就是**泻水**，让水湿不泛滥。
    - 倪师说，**水分穴的补泻，不是用捻针**，而是用**呼吸补泻**。病人吸气时进针，呼气时出针，就是**补**；反之就是**泻**。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
    - **急症救逆**：**腹水、水肿、小便不通**。倪师说，如果病人**小便解不出来**，肚子胀得像鼓一样，**针水分**，再**灸关元**，小便就出来了。
    - **慢性病调理**：**慢性肠炎、腹泻、消化不良**。水分穴能**分利水湿**，让大便成形。
    - **妇科/儿科**：**痛经、月经不调**，因为水分穴能**调理任脉**，任脉主胞胎。**小儿腹泻**，针水分效果很好。
    - **痛症特效**：**腹痛、腹胀**，尤其是**水湿引起的腹痛**，针水分立刻缓解。
- **倪师经典对穴与排针组合**：
    - **水分 + 关元**：**治腹水、水肿**。倪师说，这是**治水组合**，水分分水，关元利水，两针下去，小便就通了。
    - **水分 + 足三里 + 三阴交**：**治慢性肠炎、腹泻**。足三里健脾，三阴交利湿，水分分水，三针下去，大便就成形了。
    - **水分 + 公孙 + 内关**：**治胃心胸**。公孙配内关是**八脉交会穴**，治胃心胸，再加水分，就是**治水湿引起的胃心胸病**。
    - **水分 + 合谷 + 太冲**：**开四关**，再加水分，就是**治水湿引起的痛症**。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：
    - “水分穴，就是**水液的分界点**。你肚脐以上，水是水；肚脐以下，水是水。但水分穴，就是**水龙头**。你打开它，水就流走了。”
    - “水分穴下针，**不要深**，一寸到一寸半。你针下去，病人会感到**酸胀**，有时候会**扩散到整个腹部**。这就是**气到了**。”
    - “如果是**腹水**的病人，**不要针水分**。你针下去，水会跑出来，**容易感染**。你要**灸关元**，再**针水分**，但**不要针太深**。”
    - “水分穴，**禁灸**。你灸了，水反而**停滞**。除非是**虚寒性的水肿**，才考虑用灸，但也要**谨慎**。”
- **实战手下针感体会**：
    - 倪师说，他针水分穴时，病人会感到**酸胀**，有时候会**扩散到整个腹部**。这就是**气到了**。如果病人**没有感觉**，就是**气没到**，要**调整针的方向**。
    - 他还说，针水分穴，**不要捻针**，因为**水分穴是水液代谢的枢纽**，捻针反而会让水液**乱跑**。要用**呼吸补泻**，让病人**吸气时进针，呼气时出针**。
- **医案故事**：
    - 倪师讲过一个医案：有个病人**腹水**，肚子胀得像鼓一样，**小便解不出来**。倪师**针水分**，再**灸关元**，**小便就出来了**。病人**肚子就消了**。
    - 还有一个医案：有个病人**慢性肠炎**，**腹泻**，**大便不成形**。倪师**针水分**，再**针足三里、三阴交**，**大便就成形了**。病人**胃口也开了**。
