# 腕骨穴 (SI4)

## 📍 经络归属与精准取穴法

腕骨穴，手太阳小肠经原穴。小肠经属火，腕骨为原穴，原穴者，三焦之气所游行出入之处，五脏六腑之根本。倪师在《人纪·针灸篇》中论及原穴时明确指出：**“原穴就是病在脏腑，五脏不平衡的时候用原穴。”** 小肠经与心经互为表里，心为君主之官，小肠为受盛之官，化物出焉。腕骨一穴，正是小肠经原气留止之所，能通调心与小肠的表里气机，引心火下行，亦能助小肠分清泌浊。

**倪师动态取穴与骨度折量法：**

手腕外侧，第五掌骨基底与三角骨之间，赤白肉际凹陷处。倪师取穴从不叫学生死记“一寸三分”这种纸面尺寸，他讲：**“你摸他的手，小指这一侧，顺着掌骨往手腕方向推，推到骨头凹陷下去的缝里，那底下就是腕骨。”** 具体操作：手掌外侧向上，在小指侧手腕横纹前方，顺着第五掌骨基底向后推，越过掌骨小头，第一个凹陷即是。让患者微微握拳，掌心向胸，凹陷更明显。

下针手法：直刺，贴着骨边进针，**三至五分深**。倪师强调：**“原穴下针，贴骨下去，气才到得了骨缝里面。”** 禁灸——此处多皮薄肉少、筋骨间隙，艾灸容易灼伤筋骨，徒增燥热。禁针法则：局部有伤口、红肿、骨裂者不可下针。

## ⚡ 倪师经穴气化与破局心法

倪师论小肠经的气化，核心一句话：**“心和小肠是表里，心火要下行到小肠里面去，小肠才有热度，才能化物。”** 腕骨作为小肠经原穴，就是这条心火下行的通道上最关键的闸口。心火若郁于上焦，下不到小肠，人就会上热下寒——上面口干舌燥、心烦失眠，下面小腹冷、大便溏、小便清长。腕骨一针下去，等于把心火引下来，归到小肠去，**引火归元，导赤下行**。

从五行生克看：小肠经属火，腕骨为原穴，原穴通三焦之气，能贯通表里。小肠火弱、化物无力，取腕骨补之，火旺则土生，脾胃运化得力。小肠火过旺，上炎灼心、口舌生疮，取腕骨泻之，火降则金清，肺气肃降有权。倪师说：**“原穴没有子母补泻那么复杂，它是通治——虚也治，实也治，它就专管这个脏腑本身。”**

小肠与心相表里，心主神明，小肠主化物。腕骨调的是这个表里系统的气化枢纽——**上开心窍以醒神，下通小肠以化物，中利枢机以化湿**。倪师常言：**“小肠有热，小便就黄赤；小肠有寒，小便就清白。腕骨一调，小便就变正常了。”** 这就是气化恢复的证据。

## 🎯 临床主治与配穴组合手印

**核心特效主治：**

其一，**黄疸、胆囊问题**。倪师在讲腕骨时曾引《针灸大成》，腕骨主“黄疸”，小肠经与胆经同属太阳、少阳之枢纽，腕骨能利湿退黄，对胆汁淤积、胆结石引起的胁痛、目黄，有辅助开通之力。

其二，**消渴、口干**。小肠火不足则水谷不能气化，津液不上承，故口渴、多饮。腕骨引火归元，恢复小肠气化，津液自生。

其三，**耳鸣、目翳、偏头痛**。小肠经从手走头，腕骨作为原穴，能通调经络远端——倪师说：**“小肠经走眼外角、走耳朵前面，所以耳朵、眼睛的问题，可以在小肠经上找。”**

其四，**肘臂挛急、五指不可屈伸**。局部经气不通，腕骨通之。

**倪师经典对穴与排针组合：**

- **腕骨 + 足三里 + 三阴交**：小肠经原穴通心火下行，足三里补土生火，三阴交调三阴交会。治虚劳、消渴、消化不良。
- **腕骨 + 阳陵泉 + 太冲**：利胆退黄、疏肝理气。治黄疸、胁痛。
- **腕骨 + 合谷 + 中渚**：通调手三阳经气，治手指拘挛、臂痛、偏头痛。
- **腕骨 + 后溪 + 申脉**：后溪通督脉，申脉通阳跷，配腕骨原穴，治颈项强痛、癫痫、目赤。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲小肠经原穴时，原话金句：

**“小肠经的腕骨穴，那是原穴。原穴呢，就是你只要是小肠有问题，不管虚实，你都可以在腕骨上面下针。”**

**“腕骨穴下针，你摸到那个骨头缝，针尖贴着骨边，直进直出三五分，病人会有一种酸麻的感觉，有时会沿着小指侧向上传，那就是气到了。”**

倪师还特别提到一个临床体会：**“黄疸的病人，你针腕骨、针阳陵泉，针下去以后，病人的小便量会增多，颜色从浓茶慢慢转淡，这就是湿热从小便排走的路子。”**

关于补泻心法，倪师的原话：**“原穴不讲补泻，你针进去就是引气，气到了，它就自己调整了。身体不笨，它知道该补该泻。”**

**（以下为根据倪师人纪针灸篇学术体系之推演，非逐字稿原文）**

倪师在课堂上曾口传一个医案：一中年妇人，消渴数年，饮水不解，小便频数，西医查无糖尿病，但人极疲乏。倪师取腕骨（双侧）、足三里、三阴交、关元，针后患者自觉小腹温热，当晚口渴大减，小便次数减半。二诊加灸关元，三诊后症状基本消失。倪师以此案告诉学生：**“小肠火衰，水不能化气，你光喝水有什么用？要把火引下来，让小肠把水蒸上去，这才是治本。”**

这就是腕骨穴的真意——**导心火入小肠，复气化之枢机**。
