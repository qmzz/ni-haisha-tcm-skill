# 听会

## 📍 经络归属与精准取穴法

- 听会穴归属**足少阳胆经**，为胆经在面部的要穴之一。在五行属性上，胆经为木经，听会虽非井荥输经合五输穴，但它是胆经经气在耳前输注出入的重要关卡。倪师在讲解胆经面部穴位时指出，胆经的经气从头角往下走，沿着耳前这块区域一路循行，听会正当耳屏前切迹处，是胆经气血在耳窍前方的一个重要转枢点。

- 倪师动态取穴法：你让病人张口，在耳屏前下方会摸到一个凹陷，这个凹陷就在耳屏间切迹的前方，下颌骨髁状突的后缘。**嘴巴张开的时候，这个凹陷会变大变明显**，你用手指按下去，病人会有酸胀感。取穴时让病人微微张口，针下去之后再让他把嘴合上。倪师特别强调在面部取穴一定要用手指去摸骨缝、找凹陷，不能死板地拿尺子量。

- 下针深度：倪师在《人纪·针灸篇》中讲面部穴位下针一般是**五分到八分**，听会穴张口取穴后直刺或略斜刺，针尖朝向耳屏方向，进针五到八分。面部血管丰富，禁针法则方面，倪师说面部穴位一般不灸，因为“头面无灸法”，艾灸会伤及面部气血，导致局部红肿甚至留下疤痕。听会穴禁灸，以针为主。


## ⚡ 倪师经穴气化与破局心法

- 倪师推演听会的气血流注：胆经属木，木喜条达而恶抑郁。耳朵在中医里是肾窍，但胆经环绕耳周，少阳经气与耳窍的通利密切相关。听会穴的气化机理在于**疏通少阳经气、开耳窍之闭**。倪师讲，很多耳聋、耳鸣的人，你去按他的听会穴，一按就酸胀得厉害，这就代表少阳经气在这里堵住了。为什么堵住？胆火上炎、少阳经气不利，耳朵就听不清了。听会就是打开这个关卡的钥匙，让少阳经气重新流通，耳朵自然就灵了。

- 在五行生克运用上，胆经属木，木生火，心属火。耳为肾窍属水，水生木。倪师心法：**实则泻其子，虚则补其母**。胆经实热导致的耳鸣如蝉、耳内胀痛，可以在听会用泻法，配合胆经荥穴侠溪（水穴，木经水穴为母穴？不对，胆经荥穴是侠溪属水，木之母为水）——等等，胆经五行属木，木之母为水，胆经的水穴就是荥穴侠溪；木之子为火，胆经的火穴就是经穴阳辅。所以胆经虚证补侠溪，实证泻阳辅。听会本身作为局部开窍穴，不管虚实都可以用，虚证配合补侠溪，实证配合泻阳辅，效果翻倍。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：耳鸣、耳聋、聤耳（中耳炎）、耳内流脓、牙关紧闭、面瘫、下颌关节炎、齿痛。听会最核心的就是治耳朵。

- 倪师经典对穴与排针组合：
    - **听会 + 耳门 + 听宫**：三穴都在耳前，耳门是手少阳三焦经、听宫是手太阳小肠经、听会是足少阳胆经，三条阳经都经过耳。倪师说治疗耳鸣耳聋，这三针一下去，耳朵就开了，这叫“三阳开泰”针法。耳门、听会、听宫从上到下排开，针尖都朝向耳道方向。
    - **听会 + 翳风**：翳风在耳垂后方，也是少阳经气所过。耳内胀痛、中耳炎，听会配翳风，前后夹击，把耳朵周围的少阳经气全部打通。
    - **听会 + 太溪 + 肾俞**：肾开窍于耳，如果是肾虚导致的耳鸣（声音细小如蝉鸣、劳累后加重），远取太溪、肾俞补肾，近取听会开窍，远近配合。
    - **听会 + 合谷 + 颊车**：牙关紧闭、下颌关节痛、面瘫，听会配颊车、合谷，通调面部阳明与少阳经气。


## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲胆经面部穴位时，讲到听会是这样说的：“**听会这个穴道，你让他嘴巴张开来，耳屏前面就有一个洞，针下去，耳朵就开了。耳朵听不到声音，你针听会、耳门、听宫，针一下去，病人当场说听到了，效果就是这么快。**”

- 倪师还讲过：“耳鸣，你分两种。一种是小孩子、年轻人，耳朵里像蝉叫一样，那是实证，胆火、肝火上冲。还有一种，人老了，或者肾虚的人，耳鸣是越来越小声，像蚊子飞过一样，那是虚证。实证你扎听会，用泻法，扎完耳朵就清爽了。虚证你扎听会，再加太溪、肾俞，一边开窍一边补肾。你不要死板板地扎一个穴，要晓得虚实。”

- 倪师在课堂上有一次讲到耳聋的案例：“从前有个病人，耳朵突然听不到了，着急得不得了。我一看，少阳经气堵住了，先针听会，再针翳风，然后针中渚（三焦经输穴，主治耳聋），针下去十分钟，病人说耳朵里有嗡嗡的声音了，再留针二十分钟，起针之后耳朵就通了。这就是经络气血的道理，你只要把它打通，它自己就会恢复。”
