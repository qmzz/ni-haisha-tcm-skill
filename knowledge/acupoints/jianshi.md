# 间使穴 (PC5)

**归经：** 手厥阴心包经  
**定位：** 腕横纹上 3 寸，掌长肌腱与桡侧腕屈肌腱之间  
**属性：** 经穴

## 📍 穴位定位

**《针灸大成》：** "在掌后三寸，两筋间。"

### 取穴方法
1. **简便取穴法：** 内关穴上 1 寸，掌长肌腱与桡侧腕屈肌腱之间。
2. **骨度分寸法：** 腕掌横纹上 3 寸。

### 解剖结构
- **肌肉：** 指浅屈肌、指深屈肌
- **神经：** 正中神经掌支、前臂内侧皮神经
- **血管：** 骨间掌侧动、静脉

## 🩺 功能主治

### 功效
- **宽胸解郁** — 胸闷、心痛
- **宁心安神** — 心悸、失眠
- **化痰通络** — 痰多、癫狂

### 主治病证

**倪海厦：**
> \"间使为心包经经穴。
> 心包主代心受邪，间使可宽胸解郁。
> 胸闷、心痛、心悸，间使可安之。
> 癫狂、痫证，间使可化痰开窍。\"

| 系统 | 病证 |
|------|------|
| **心系病** | 心悸、心痛、胸闷 |
| **神志病** | 癫狂、痫证、失眠 |
| **胃肠病** | 胃痛、呕吐 |
| **其他** | 疟疾、腋肿 |

## 💉 刺灸法

### 针刺方法
- **进针方向：** 直刺 0.5-1.0 寸
- **针感：** 局部酸胀

### 艾灸方法
- **艾条灸：** 10-15 分钟
- **艾炷灸：** 3-5 壮
