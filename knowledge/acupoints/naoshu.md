# 臑俞

## 📍 经络归属与精准取穴法

- 臑俞属**手太阳小肠经**，为**手太阳、阳维脉、阳跷脉之交会穴**。倪师在《人纪·针灸篇》中明言：小肠经与阳维、阳跷相交于此，故一穴通三脉之气，既能调小肠腑气，又能疏利肩背阳维之结、通畅阳跷之脉。此穴非五输穴，亦非原络郄募，其要义在于“交会”二字——阳维主一身之表，阳跷主一身左右之阳，小肠经又主液所生病，故臑俞一穴，实则肩背阳气交接之枢。

- 倪师动态取穴法：先找**肩贞穴**——手臂自然下垂，腋后纹头上一寸即是肩贞。从肩贞直上，推到**肩胛骨下缘**（肩胛冈根部），在肩胛冈下缘与肩胛骨外缘形成的凹陷中，按之酸胀处，便是臑俞。倪师强调：**“你摸到肩胛骨那个角，角的下方有个缝，缝里就是臑俞。”** 不必死记几寸几分，以骨度折量为准——肩胛冈下缘至肩贞，约当肩贞上一寸半至二寸之间。下针**直刺或斜刺一寸至一寸半**，针感可向肩臂放散。**禁灸**——倪师明确指出，此穴靠近肩胛骨与肺尖区域，灸之易引热入里，古法多不灸，以针通为要。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演臑俞气化：小肠经属火，主液所生病；阳维维系诸阳，阳跷司运动矫健。臑俞居肩胛之后、腋后纹上，正当**阳气从肩背向内收合、从阳跷向阳维过渡**的关口。倪师说：**“肩背僵紧、手臂抬不起来，这是阳跷与阳维的气在这里打结了。”** 臑俞的作用，就是**解散阳维之结、疏通阳跷之滞**，使小肠经的液气能够润泽肩臂关节。凡肩背冷痛、臂不能后伸、肩胛骨内缘酸痛，皆可取此穴以开阳维阳跷之闭。

- 子母补泻与五行生克：臑俞非五输穴，不直接论母子。但倪师心法：小肠经属火，**火生土**，小肠经之气最终要助脾胃运化。臑俞交会阳维阳跷，若因**阳维不维、阳跷不跷**导致肩背阳气不能内收，进而影响小肠腑气通降，可取小肠经**母穴后溪（木穴，木生火）** 补之，再取臑俞通其交会；若肩背实热、肩胛红肿，则取小肠经**子穴阳谷（火穴，火生土）** 泻之，臑俞作为交会穴，引阳维阳跷之热外散。此为倪师“**交会穴引气，五输穴调虚实**”的变通心法。

## 🎯 临床主治与配穴组合手印

- 核心特效主治：
  - **肩臂痛不能后伸**——臑俞是肩胛骨外缘与肩关节后方的枢纽，倪师治肩痛，若患者说“手往后背摸不到脊梁骨”，必取臑俞。
  - **肩胛骨内缘酸痛（膏肓痛）** ——倪师常取臑俞透向肩胛骨内缘，配合膏肓俞，一前一后松解肩胛。
  - **颈项强痛牵连肩背**——阳维阳跷交会，故颈椎病引起的肩背牵拉痛，臑俞是远端疏导要穴。
  - **手臂麻木、小肠经循行线上的酸胀**——从臑俞沿小肠经下针，可引气至小海、养老。

- 倪师经典对穴与排针组合：
  - **臑俞 + 肩贞 + 天宗**：小肠经肩背三针，专治肩胛痛、肩关节活动受限。倪师谓之“**肩三针**”的变体，先针天宗，再针臑俞，最后肩贞，针感如三股绳拧在一起，肩背立松。
  - **臑俞 + 后溪 + 申脉**：后溪通督脉，申脉通阳跷，臑俞交会阳跷，三穴合治**颈项强痛伴肩背僵直**。倪师说：“后溪申脉是通督通跷的老搭档，臑俞在中间帮它们把肩背的气接上。”
  - **臑俞 + 肩髃 + 曲池**：治肩臂痛不能上举，臑俞从后方松解，肩髃从前开肩，曲池引气下行，三穴成“**肩臂三角**”。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师《人纪·针灸篇》讲小肠经时，原话实录：**“臑俞这个穴，在肩贞上面，肩胛骨那个角的下方。你摸到肩胛骨，它有一个外角，角下方凹陷就是臑俞。这个是阳维、阳跷、小肠经三脉交会。所以肩痛，手抬不起来，你针下去，针感会跑到手臂上去。你问病人，酸不酸？胀不胀？他说像电一样传到手指，那就对了。”**

- 倪师手下针感体会：**“针臑俞，不要直直插，稍微斜一点，向肩胛骨内缘透。透过去，病人会觉得肩胛骨里面酸胀，像有人用指头在抠他的膏肓。这就是阳维阳跷的气被调动了。留针二十分钟，肩背松一半。”**

- 医案故事一则：倪师曾治一五十肩患者，手臂不能后伸，穿衣服要人帮。倪师取**臑俞、天宗、肩贞**，再取对侧**条口透承山**。针臑俞时，患者说肩胛骨里面“热热的，像有东西在化开”。倪师留针二十分钟，起针后让患者试伸手后摸，当场就能摸到后腰。倪师笑言：**“臑俞是开肩胛后方的钥匙，你光扎肩髃在前面开，后面锁着也没用。”** 此案可见臑俞在肩背痛中的关键地位——非以穴性补泻取胜，而以**交会通阳、开结散滞**见长。
