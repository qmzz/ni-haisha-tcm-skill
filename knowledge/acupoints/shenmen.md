# 神门穴 (HT7)

## 📍 经络归属与精准取穴法

- **所属经络**：手少阴心经。五行属土。
- **五输穴属性**：心经的**输穴**（俞穴），同时也是心经的**原穴**。倪师在讲五输穴时反复强调：阴经的输穴就是原穴，这是阴经的规矩。“病在时间者取俞穴”，神门本身就有双重身份——既是输穴，又是原穴，所以它的治疗范围比一般穴位宽得多。
- **五行定位**：心经属火，神门是心经的输穴，阴经输穴五行属土。所以神门这个穴，是火经里的土穴——**心火生脾土**。这就决定了它的补泻方向：**虚则补其母**，心经之母是木穴（少冲），但神门本身是土穴，若从子母补泻看，心经的子穴是神门（火生土，土为火之子）。所以**实则泻其子——心经实证，泻神门**。

- **倪师动态取穴法**：手掌朝上，手腕自然微屈。先找腕横纹，从腕横纹往小指方向推到尺骨小头内侧，在腕横纹上摸到一条大筋——尺侧腕屈肌腱。这条筋的**桡侧（拇指侧）凹陷处**，就是神门。倪师原话的意思就是：你摸到那条筋，贴着筋的内侧下针，不要扎到筋上，扎到筋上病人会痛得跳起来。
- **下针深度**：直刺，**三分到五分**。倪师说手腕这里穴道都很浅，不要深扎，扎到筋上或穿过筋都会伤到经筋，病人手会麻。
- **禁针禁灸**：神门**可针不宜灸**。手腕关节处，灸了容易留疤，影响关节活动。倪师在讲心经时特别提过，手腕以下、手指这些地方，多用针，少用灸。

## ⚡ 倪师经穴气化与破局心法

- **经气流注与开阖机理**：神门是心经原穴，原穴就是脏腑元气经过和留止的地方。“五脏不平衡时用原穴”——这是倪师在针灸篇里反复讲的原则。心藏神，神门顾名思义就是**心神出入的门户**。心的气血从极泉出来，沿着手臂内侧后缘一路下行，到了神门这里，经气汇聚成原气，再从神门灌注入掌后，流向少府、少冲。所以神门这个穴，等于是心经气血的一个**总闸门**。
- 倪师推演：当人心神不宁、失眠、焦虑，这是心的原气在神门这个位置堵住了、开阖失司。你下针神门，等于把这道门打开，让心气重新流转。所以它能**开窍醒神、宁心安神**，同时因为它是土穴，心火生脾土，它还能把心火往下导，引到脾胃去，这是**引火归元、心脾同调**的路子。
- **子母补泻心法**：心经的实证——比如心火亢盛、口舌生疮、心烦易怒，这是实，**实则泻其子**，心经之子上就是神门（火生土），所以你要**泻神门**，用针法上的捻转泻法。反过来，心经的虚证——心悸、怔忡、失眠多梦、健忘，这是虚，**虚则补其母**，心经之母是少冲（木穴），你应该补少冲，但临床上也常配神门，因为神门是原穴，能调动心经原气来扶助心气。倪师的意思就是：神门虽然本身是子穴，但作为原穴，它虚实都能调，关键看你的手法和配穴。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **心神病**：失眠、多梦、心悸、怔忡、健忘、焦虑、抑郁、癫狂痫。这是神门的主战场，倪师说“心藏神”，神门就是管神的。
  - **心火实证**：口舌生疮、心烦、小便黄赤。
  - **痛症**：手腕痛、腕关节扭伤、胸痛、胁痛。
  - **儿科/妇科**：小儿夜啼、小儿惊风、妇女脏躁（类似更年期综合征的情绪问题）。
  - **急症**：癫痫发作时，配人中、涌泉、百会，醒神开窍。

- **倪师经典对穴与排针组合**：
  - **神门 + 内关 + 三阴交**：这是倪师治失眠的经典组合。内关通阴维脉，管胃心胸；神门安神；三阴交调三阴经气血。三个穴一下去，心神归位。
  - **神门 + 少海 + 心俞**：治心悸、怔忡。少海是心经的合穴（水穴），能清心火；心俞是心之背俞穴，从后背调心气。
  - **神门 + 太冲 + 合谷**：治焦虑、烦躁、易怒。太冲配合谷开四关，调气血升降；神门再一针，把心神定住。
  - **神门 + 内关 + 公孙**：治胃心胸的问题伴随心烦失眠。公孙通冲脉，内关通阴维，神门宁心，这是倪师常用的“心胃同治”思路。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲心经时，原汁原味的话是这样说的：

> “神门穴，你摸到手腕上那条大筋，筋的内侧就是神门。这是心经的输穴，也是原穴。心经的虚症、实症，通通可以在这里治。”

> “失眠，你下神门，再配内关、三阴交，针下去病人就睡着了。为什么？神门是心神的门户，你把门打开，神就回来了。”

> “神门这个穴，不要灸，手腕这个地方灸了会伤到筋。针三分到五分就够了，不要深，深了扎到筋，病人手会麻。”

> “心经的实症，比如心火大、口舌生疮，你要泻神门；虚症，比如心悸、失眠，你要补少冲，但神门也可以配着用，因为它是原穴，能通调心气。”

倪师还讲过一个医案的意思：有个病人长期失眠，吃了很多安眠药，倪师就取神门、内关、三阴交，针了三次，病人就能自然入睡了。他强调，这不是神门一个穴的功劳，是**心、胃、脾三条经一起调**，神门是那个“开门”的钥匙。
