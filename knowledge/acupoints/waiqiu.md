# 外丘

## 📍 经络归属与精准取穴法

- **所属经络**：足少阳胆经。胆经属木，外丘为胆经**郄穴**。郄穴者，气血深聚之缝隙也，专主急症、痛症、血证。阳经郄穴善治急性痛证，阴经郄穴善治急性血证。外丘为阳经郄穴，故胆经循行所过之急性疼痛、气滞剧痛，取之外丘，如钥匙开锁，一针下去，气机立通。

- **穴名解**：外，外侧也；丘，土丘也。穴在外踝之上，腓骨前缘，隆起如丘，故名外丘。倪师常言：穴名即穴性，外丘在外踝上，贴着骨头边缘，少阳经气在此汇聚成丘，一按就酸胀，那就是穴。

- **精准取穴（倪师骨度折量法，大白话）**：
  1. 先找**外踝尖**——脚外侧那个凸起的骨头尖。
  2. 从外踝尖往上量**七寸**。七寸怎么折？用你自己的手指：一夫法，四指并拢为三寸，再往上加四指，大概七寸。或者用骨度法：从外踝尖到膝盖腘横纹是十六寸，取一半就是八寸，再稍微往下一点点，大约七寸。
  3. 七寸找到后，关键来了——**贴着腓骨前缘**。倪师原话：你摸到那根长长的腓骨，外丘就在腓骨的前面，骨头的边上，不是骨头后面。骨头前面那条缝隙，按下去酸酸麻麻的，就是外丘。
  4. 跟**阳交穴**的区别：阳交也在外踝上七寸，但阳交在腓骨**后缘**，外丘在腓骨**前缘**。一前一后，差之毫厘，主治不同。倪师说：你摸骨头，前缘是外丘，后缘是阳交，别扎错了。

- **下针深度与手法**：直刺，针入**五分到七分**，不宜过深。倪师说：这穴在骨头边上，你扎太深就扎到骨膜了，病人会痛得跳起来。针下去得气后，酸胀感会往脚踝或小腿外侧放散，那就是气至了。留针二十分钟，不急不缓。

- **禁针禁灸**：外丘无特殊禁针，但**不宜灸**。倪师讲：郄穴是气血深聚之处，主急症，你用艾灸一烤，气机反而壅滞，急症要的是通，不是温。所以外丘一般**只针不灸**。除非是极虚寒之证，那也要配其他穴位，不在外丘上做文章。


## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：
  胆经属木，木性条达，主疏泄。外丘为郄穴，是胆经气血在踝上七寸处深聚的“蓄水池”。倪师讲：郄穴就像河道上的一个深潭，平时水静静蓄着，一旦上游发大水——也就是急性病、剧痛、气机突然壅塞——这个深潭就是泄洪口。你针外丘，等于把深潭的闸门打开，壅塞之气一泻而下，痛就解了。

  外丘的气化机理，倪师归结为八个字：**疏木通络，开郁破结**。胆经循行过胁肋、过颈项、过外踝，凡是这条线上因为气郁、血瘀、痰凝导致的急性堵塞，外丘都能破。什么叫破局？局就是气机被锁死了，外丘就是那把砸锁的锤子。

- **子母补泻与五行生克**：
  胆经属木，木之母为水（肾），木之子为火（心/小肠）。但外丘是郄穴，不是五输穴，所以子母补泻**不直接在外丘上做**。倪师心法是：外丘用来“通”，通之后再在胆经的子母穴上做补泻。胆经的母穴是侠溪（荥水穴），子穴是阳辅（经火穴）。实证、急证、痛证——先针外丘开郄，再针阳辅泻子；虚证、慢性证——先针外丘通络，再针侠溪补母。

  倪师特别强调：郄穴是**急则治标**的穴，你用它把标解了，回头还得治本。比如胆经痛证，外丘一下去痛止了，但为什么痛？是肝气郁？是痰湿阻？是瘀血停？你得再辨。外丘是先锋，不是主帅。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **急性胁肋痛、胆绞痛**：少阳经气突然壅塞，胁肋剧痛，外丘针下，气机立通。倪师常配阳陵泉，一上一下，胆经两头一开，痛如云散。
  2. **急性颈项痛、落枕**：胆经循颈，外丘郄穴能破颈部气滞。倪师说：落枕你别只扎落枕穴，胆经的郄穴外丘一针，脖子当场松一半。
  3. **急性外踝扭伤**：外丘在外踝上七寸，郄穴治急，扭伤当下针外丘，配合丘墟、解溪，消肿止痛极快。
  4. **胸胁胀满、郁证**：凡胆气不舒、两胁胀痛、善太息者，外丘能开郁破结。倪师配太冲、期门，疏肝利胆。
  5. **狂犬病、毒虫咬伤（古法）**：《针灸大成》载外丘治“猘犬伤毒不出”，倪师讲这是古法，郄穴能泄血中毒热，但现代还是要打疫苗，针灸只能辅助。

- **倪师经典对穴与排针组合**：
  1. **外丘 + 阳陵泉**：胆经郄穴配胆经合穴，上下呼应，主治一切胆经急性痛证、胁肋胀痛。
  2. **外丘 + 丘墟**：郄穴配原穴，急则开郄，缓则调原，主治外踝扭伤、胆经虚实夹杂之证。
  3. **外丘 + 太冲**：胆经郄穴配肝经原穴，肝胆同治，主治郁证、胁痛、情志不遂。
  4. **外丘 + 风池 + 肩井**：治急性颈项强痛、落枕，一针外丘通络，风池肩井疏风解肌。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲足少阳胆经时，专门提到外丘。原汁原味的金句如下：

> “外丘这个穴，在外踝上七寸，你摸腓骨，骨头的前面，那个地方就是外丘。它是胆经的郄穴。郄穴是什么？就是气血最深的地方，像水潭一样。你遇到急症——胆绞痛、胁肋突然痛、脖子突然转不过来——你针外丘，一针下去，气就通了。这叫急则治标。”

> “我常常跟学生讲，你学针灸，郄穴一定要记住。每条经都有一个郄穴，阳经的郄穴治痛，阴经的郄穴治血。外丘是阳经郄穴，所以它治痛。胆经的痛，你就在外丘上做文章。”

> “外丘和阳交，差一点点，一个在腓骨前，一个在腓骨后。你扎的时候，手指先摸骨头，摸到腓骨，往前一点点就是外丘。不要扎太深，五分到七分就够了。扎下去病人酸胀，你就停。得气就好了。”

> “胆经的郄穴，你不要拿来补，它是开路的，不是补药的。你补要用侠溪，泻要用阳辅。外丘就是通，通完了你再补泻。这个顺序不能乱。”

倪师还讲过一个实战案例：有病人胆结石急性发作，胁肋剧痛，痛得弯着腰进来。倪师先针外丘、阳陵泉，针下去不到五分钟，病人说痛减了七成。然后再针胆俞、日月，留针二十分钟，痛全消。倪师说：这就是郄穴的威力，急症先开郄，把气机打开，后面再慢慢调。

倪师最后叮嘱：**外丘是先锋穴，不是主帅穴**。急症用它开路，缓症用它辅助。你把它当主帅用，那就用错了。记住这句话，一辈子受用。
