# 阴都

## 📍 经络归属与精准取穴法

- **所属经络**：足少阴肾经，为冲脉与足少阴肾经之会穴（冲脉并少阴上行，阴都即少阴、冲脉之交会）。
- **穴名解**：阴者，少阴也；都者，会聚也。本穴为少阴肾经与冲脉气血交会之处，故名“阴都”。
- **特定穴属性**：非五输穴、非原络郄募，属交会穴。倪师在《人纪·针灸篇》中明确将腹正中线旁开诸穴以“冲脉并少阴”论治，阴都即为冲脉与少阴经气汇聚的关窍。
- **五行定位**：肾经属水，阴都位于肾经之上，为水经之穴。其邻近上脘（任脉），位处中焦，故又兼土气，为水中之土，主调肾水之上泛与中焦气机之升降开阖。

### 倪师动态取穴与骨度折量法

倪师取穴讲究“离穴不离经，守经不守穴”，对于阴都这种腹部的穴位，必须以骨度折量法配合动态摸骨为准：

1. **先定肚脐（神阙）**：肚脐是任脉与冲脉汇合之地，也是腹诊的重要参考点，以肚脐为水平基准线。
2. **上量一寸取中脘**：从神阙直上四寸为中脘（胃之募穴），从神阙直上一寸为水分，直上两寸为下脘，直上三寸为建里，直上四寸为中脘。
3. **旁开半寸定阴都**：中脘旁开半寸（即距腹正中线五分），即是阴都穴。倪师在课堂上反复强调：“肚脐到心蔽骨之间是八寸，这是铁打的骨度。”先在心蔽骨与神阙连线中点取中脘，再从腹正中线旁开五分，即为阴都。
4. **摸骨找穴**：倪师教学生时，让患者平躺放松，用手指沿腹白线旁开，在肚脐与中脘之间细细按压，**阴都穴处常有轻微凹陷或筋结感**，尤其是胃气不舒之人，此处按之会酸胀应手。倪师说：“你摸到腹肌纹理之间的缝隙，那个凹下去的点，就是穴道。”

### 下针深度与禁针禁灸法则

- **下针深度**：倪师在腹部穴位上教学一贯谨慎。阴都穴**一般针五分至八分**，视患者腹部厚薄而定。胖人可稍深，瘦人宜浅。倪师说：“肚子上的针，不要一下子扎太深，五分六分就够了，得气即止。”
- **针刺方向**：可直刺，亦可向下斜刺，视调气目标而定。若引气下行，针尖略向下；若升提中气，针尖略向上。
- **禁针禁灸**：
  - 《针灸大成》载阴都“针三分，灸五壮”。倪师在讲解时特别提到：“腹部接近中焦，**灸可以，但不宜多灸**，三五壮足矣。”
  - **禁忌**：腹部有癥瘕积聚、肿块，或妇人妊娠期间，阴都穴慎针或禁针。倪师说：“肚子里面有硬块，你不要在硬块上扎针。”
  - 过饥、过饱、大怒之后不宜在腹部中焦取穴下针，此乃倪师“针前必察气机”的规矩。


## ⚡ 倪师经穴气化与破局心法

### 一、气血流注与开阖机理：通冲脉、降肾水、安中焦

阴都穴的气化机理，倪师是从冲脉与少阴肾经的并联关系来讲的。

**1. 冲脉并少阴——阴都是冲脉在腹部的一个重要关窍。**

倪师说：“冲脉是十二经之海，它并着少阴肾经往上走。你扎阴都，等于同时调动了冲脉和肾经的气。”冲脉起于胞中，下出会阴，从气街起与肾经并行，挟脐上行。阴都正处于冲脉与肾经在腹部并行线上的交会处。

**2. 肾水泛滥，阴都主开阖。**

肾属水，水正常时藏于下焦，靠命门火化气上行。若肾阳不足、水气内停，水湿上泛中焦，人就会出现**腹胀、肠鸣、心下烦闷、喘息**等症。倪师在《人纪》中讲：“阴都这个穴，是肾水通往中焦的一个关口。你把它打开，水气就能下去；你把它阖住，中焦的气就不至于被水气冲散。”

**3. 中焦枢纽的辅助调节。**

阴都虽属肾经，但它紧贴中脘，是中焦气机升降的辅助关口。倪师经常把阴都、中脘、下脘配在一起用，他说：“阴都是从中焦旁边协助开阖的，中脘是总开关，阴都就是旁边的副开关。”

### 二、子母补泻与五行生克心法

- 肾经属水，阴都非井荥输经合，不走本经子母补泻的主路。但倪师说：“穴位不一定是五输穴才有补泻，交会穴有交会穴的补泻法。”
- **实则泻其子**：肾经实证，水气上泛，针阴都用**泻法**（捻转提插，逆经气方向），引水下行。
- **虚则补其母**：肾经虚证，肾气不固，中焦失养，针阴都用**补法**（顺经气方向，轻捻缓按），配合艾灸三五壮，温养肾气。
- 倪师特别指出：**腹部的穴位，补泻不要太猛**，因为中焦是气机运化之地，猛补猛泻反而打乱气机。他通常用“平补平泻”，得气后静留针十五到二十分钟，让气自己调整。


## 🎯 临床主治与配穴组合手印

### 一、核心特效主治

根据《针灸大成》与倪师《人纪》讲义，阴都穴主治可归纳为以下几大类：

**1. 中焦肠胃病（特效）**
- **腹胀、肠鸣、胃脘痛**：阴都最核心的主治。凡肾水犯胃、中焦虚寒引起的腹胀、肠鸣、食物不化，针阴都立效。
- **心下烦闷、呃逆**：水气凌心，中焦气逆，配内关、公孙。

**2. 妇科与冲脉病**
- **月经不调、痛经、不孕**：冲脉为血海，阴都通冲脉，妇人冲脉失调诸症皆可取之。
- **带下、胞中冷**：肾阳虚寒，冲脉失温，针阴都配关元、三阴交，温冲散寒。

**3. 肺系病（水寒射肺）**
- **喘息、气短**：肾水上泛，水寒射肺，阴都降肾水，配肺俞、太渊。
- **咳逆上气**：肾不纳气之咳，阴都补肾降逆。

**4. 急症救逆**
- **霍乱吐泻**：中焦气机逆乱，针阴都配中脘、天枢、足三里，调中焦、分利水谷。
- **急性胃痛**：阴都配梁丘、中脘，缓急止痛。

### 二、倪师经典对穴与排针组合

1. **阴都 + 中脘 + 足三里**——中焦肠胃病基本组合。倪师说：“中脘是胃的募穴，足三里是胃的合穴，阴都在旁边协助开阖，三个一起下去，中焦的气就活了。”
2. **阴都 + 关元 + 三阴交**——妇科冲脉病组合。关元通冲脉，三阴交调三阴，阴都引气入冲脉。
3. **阴都 + 公孙 + 内关**——治胃心胸。公孙通冲脉，内关通阴维，阴都助冲脉，三穴合治心胃胸膈之病。
4. **阴都 + 水分 + 阴陵泉**——水肿、小便不利。水分分利水谷，阴陵泉健脾利水，阴都降肾水。
5. **阴都 + 太溪 + 复溜**——肾虚诸证。太溪补肾原气，复溜调肾水，阴都通冲脉，三穴同用，补肾调冲。


## 🗣️ 倪师讲义实录与针灸秘要

### 一、倪师讲阴都的原汁原味金句

倪师在《人纪·针灸篇》讲解足少阴肾经腹部穴位时，关于阴都，有这样几段话：

> “阴都这个穴，在中脘旁边五分。你们看，中脘是胃的募穴，阴都就在它旁边。为什么肾经的穴道跑到胃旁边来了？因为冲脉并少阴上行，它经过中焦，肾水要经过这里上去。所以阴都这个穴，是管肾水到中焦的这个关口。”

> “有的人肚子胀，肠鸣咕噜咕噜响，你问他，他说喝冷水就胀，吃饭也胀。这是肾水不能化气，水停在肚子里。你针中脘、针阴都，水气一排掉，肚子就不胀了。”

> “阴都扎针，你不要扎太深，五分就够了。肚子上扎针，得气就行。什么叫得气？病人觉得酸酸的、胀胀的，你的针下感觉沉沉的、紧紧的，这就是气到了。气到了，你不要再捻针了，让它留在那里，留十五分钟，气自己会走。”

> “妇人月经不调，冲脉的问题。冲脉是血海，阴都通冲脉，你针阴都、关元、三阴交，月经就正常了。你不要只扎三阴交，三阴交是管三条阴经，但冲脉你还要靠阴都、公孙来通。”

### 二、实战手下针感体会

倪师在课堂上让学生互相练习时，对阴都的针感有精细描述：

- **进针时**：皮肤阻力不大，但过了皮下脂肪层后，针下会有一种“穿过筋膜”的突破感。
- **得气时**：针下感觉沉紧，患者自觉局部酸胀，有时会向周围扩散，或向下腹传导。
- **注意事项**：若针下感觉空滑无阻力，说明气未至，可将针稍提再进，或轻轻捻转以候气。若患者感觉剧痛或放电感，说明碰到了神经或血管，应立即退针调整方向。

倪师说：“腹部扎针，最怕扎到血管。你一扎进去，病人喊痛，针下松松的，拔出来有血，那就是扎到血管了。你要退出来，换个方向再扎。”

### 三、医案故事

倪师在《人纪》中讲过一个案例：

> “有个太太，四十多岁，肚子胀了半年，西医说是肠胃胀气，给她吃消胀的药，吃了就好，停药又胀。她来找我，我看她舌头淡白，脉沉细，这是肾阳虚，水气不能化。我针中脘、阴都、关元、足三里，针了三次，肚子就不胀了。为什么？中脘是胃的募穴，阴都是肾水到中焦的关口，关元是补肾的，足三里是调胃的。你把肾水一温，水能化气了，胃气一降，胀气就散了。”

> “还有一个小女孩，痛经，每次月经来肚子痛得打滚。我针她阴都、关元、三阴交，针了两个月，就不痛了。阴都通冲脉，冲脉是血海，血海一温，月经就顺了。”

这些医案印证了倪师对阴都穴“通冲脉、降肾水、安中焦”的核心定位。


**总结**：阴都一穴，虽非五输、非募络，但因其为冲脉与少阴之会，位居中焦之旁，故在倪师的人纪针灸体系中，是调节肾水、通调冲脉、安和中焦的重要关窍。取穴以肚脐上四寸旁开五分为准，针五分至八分，得气即止；主治腹胀肠鸣、妇人冲脉失调、水寒射肺诸证；配中脘、足三里、关元、三阴交，可通调中下二焦，为倪师临床常用之组合。
