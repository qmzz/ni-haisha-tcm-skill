# 翳风

## 📍 经络归属与精准取穴法

- 翳风穴归属**手少阳三焦经**，为**手足少阳之会穴**。三焦经本身属相火，内寄命门之火，循行于耳周，翳风正是少阳经气转入耳窍的枢纽。它不属于井荥输经合五输穴体系，但它是**手足少阳交会之穴**——三焦经的经气与胆经的经气在此交汇，所以它同时调节两条少阳经的气化，这是它的独特之处。三焦主气化、主水道，胆主决断、主疏泄，二经交会，翳风就成了“耳窍开关”的总闸。

- **倪师动态取穴法**：倪师取翳风，不叫你死记分寸，而是叫你用手去摸。耳垂向后一按，耳垂边缘贴住骨面，在耳垂根部的后方，下颌骨与颞骨乳突之间，会摸到一个**明显的凹陷**，像一个柔软的坑。你让病人微微张口，这个凹陷会更深、更松；让病人闭口，它会略微收紧。倪师说：“你找到那个坑，按下去病人说“啊”一声，有酸胀感往耳朵里钻，那就是翳风。”

  具体操作：正坐或侧卧，耳垂向前折，耳垂根部所抵住的骨缝就是。骨度折量上，它在耳垂后方，平耳垂根部，距耳垂根约0.5寸。倪师特别强调，**不要死板地在耳后乱按，要顺着耳垂根去摸那个自然的凹陷**，那个凹陷是上天造人时就留好的，不是拿尺子量出来的。

  **下针深度**：倪师在《人纪》里讲，翳风一般**针五分到八分**，不要深刺。因为这个地方下面有面神经、耳后动脉、颈静脉，深刺容易伤及血管神经。他原话大意是：“翳风你扎五分就够了，得气就行，不要贪深。这个穴是靠‘气到’治病，不是靠‘针深’治病。”

  **禁针禁灸法则**：**禁灸**。翳风靠近耳窍，艾火一烤，少阳相火更旺，容易引发耳鸣加重、耳内流脓、甚至头晕目眩。倪师明确说这个穴**只针不灸**。另外，耳后有疮疡、瘰疬溃破者，局部禁针。小儿囟门未闭者，此处亦当慎针。孕妇一般不用，因为少阳经气与胎气有联动。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：倪师推演翳风的气化，是从三焦经的“少阳相火”入手的。三焦者，决渎之官，水道出焉，内寄相火。翳风位于耳后，正是相火入耳窍的关口。**耳为肾之窍，但耳病多从少阳论治**，为什么？因为少阳胆经绕耳而行，三焦经也绕耳而行，二经的经气都在翳风这个关卡交汇。倪师说：“耳朵是空窍，空窍最怕两样东西——一是火太旺，把耳窍烧得嗡嗡响；二是水太堵，把耳窍闷得听不见。翳风就是管这个开关的。”

  具体而言，翳风的气化功能有三层：**第一层是“开耳窍”** ，凡耳聋、耳鸣、耳中闭塞如物阻，都是少阳经气在翳风这个关卡堵住了，针翳风就是把这个关卡打开，让经气重新灌入耳窍。**第二层是“清少阳相火”** ，三焦相火妄动，循经上扰耳窍，导致耳内鸣响、耳中胀痛，翳风能引火下行、散火外出。**第三层是“息风通络”** ，翳风靠近面神经出口，面瘫、口眼歪斜，是风邪客于少阳、阳明之络，针翳风能息风通络，引邪外出。

  倪师特别讲到，翳风对**“耳中如蝉鸣，按之稍减”**的虚证耳鸣，和**“耳中如潮水，按之更甚”**的实证耳鸣，针法完全不同。虚证要**补**，针尖略向上，得气后轻轻捻转，如春风拂柳；实证要**泻**，针尖略向下，得气后大幅度捻转，如秋风扫叶。这是倪师手下才能体会的细腻。

- **子母补泻与五行生克**：翳风本身不是五输穴，但它所在的**三焦经属火**（少阳相火），三焦经的五行归属是火。三焦经的子母补泻：**实则泻其子**，三焦经属火，火生土，土为子，三焦经的土穴是**天井穴**（合穴，属土）；**虚则补其母**，火之母为木，三焦经的木穴是**中渚穴**（输穴，属木）。但翳风作为手足少阳之会，它的补泻要结合胆经来看。胆经属木，木生火，胆经是母，三焦经是子。所以**胆经实、三焦经虚**时，取翳风用补法，借胆经木气生三焦火气；**胆经虚、三焦经实**时，取翳风用泻法，泻三焦火气以平胆经木气。这是倪师讲的“手足少阳同气连枝，翳风是调节这两条经气平衡的枢纽”。

  倪师在临床上还有一个心法：**翳风配听宫、听会，治一切耳病**。听宫是手太阳小肠经穴，听会是足少阳胆经穴，翳风是手足少阳之会。三穴同用，等于把耳窍的前、后、上三个方向的经气全部打通。针法上，翳风用泻法开窍，听宫、听会用平补平泻，这是倪师治耳鸣耳聋的经典组合。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **耳病**：耳鸣、耳聋、耳中闭塞、耳内流脓、耳痛。这是翳风的第一主治。倪师说：“耳病先取翳风，不管你是虚是实，先把关卡打开再说。”
  - **面瘫**：口眼歪斜、面肌痉挛、眼睑瞤动。翳风是面神经出颅处，针之能直接作用于面神经，是倪师治面瘫的**主穴之一**，常配地仓、颊车、合谷。
  - **牙关紧闭**：下颌关节炎、咀嚼肌痉挛。翳风能松解下颌关节周围的经筋，配颊车、下关。
  - **腮腺炎**：中医叫“痄腮”，少阳经气郁滞化火，翳风配外关、合谷、少商放血。
  - **急症救逆**：倪师在讲急救时提到，**翳风配人中、内关**，能治突发性耳聋、眩晕昏厥。因为翳风能引少阳相火下行，使清阳上升、浊阴下降。

- **倪师经典对穴与排针组合**：
  - **翳风 + 听宫 + 听会**：治一切耳病。翳风开耳后关卡，听宫开耳前关卡，听会开耳下关卡，三穴合围，耳窍无路可逃。
  - **翳风 + 地仓 + 颊车 + 合谷**：治面瘫。翳风息风通络，地仓、颊车局部取穴，合谷“面口合谷收”，四穴一列，面瘫必除。
  - **翳风 + 外关 + 足临泣**：治少阳经气郁滞引起的偏头痛、耳后痛、颈项痛。外关通阳维，足临泣通带脉，翳风开少阳关卡，三穴共奏和解少阳之功。
  - **翳风 + 中渚 + 液门**：治三焦经热引起的耳鸣、耳痛、咽喉肿痛。中渚、液门是三焦经的输穴和荥穴，能清三焦热，翳风引热外出。
  - **翳风 + 风池 + 天柱**：治后头痛、颈项强痛、眩晕。翳风、风池、天柱都在后脑勺一线，是倪师治“后头痛三针”。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲三焦经时，讲到翳风，原话大意是：“翳风这个穴，你摸到耳垂后面那个坑，针下去五分，得气以后，病人会感觉耳朵里面突然一亮，像开了一扇窗。耳鸣的人，针完以后，蝉鸣声会变小；耳聋的人，针完以后，能听见一点声音。但是你要记住，翳风是开窍的穴，不是补虚的穴。如果病人肾虚耳鸣，你光针翳风，当时有效，过两天又回来了。要配肾俞、太溪、关元，补肾才是根本。”

- 倪师讲过一个医案：有个病人突发耳聋，西医说是“突发性耳聋”，打了激素、高压氧都没用。倪师一看，病人耳后翳风穴按下去**硬邦邦的，像一块石头**，而且病人说按下去特别痛。倪师说：“这就是少阳经气堵死了。”他在翳风穴下针，针尖略向上，得气后大幅度捻转，病人突然说“耳朵里面像通了电一样”。倪师再配听宫、听会，留针二十分钟。起针后，病人能听见手表的声音了。倪师说：“这不是我厉害，是翳风这个关卡，你把它打开了，经气自己就进去了。”

- 倪师还有一个手下针感的体会：**翳风针下去，得气的感觉是“酸胀往耳朵里面钻”** ，有的病人会感觉半边脸发麻，有的病人会感觉耳内发热。倪师说：“如果针下去病人没感觉，说明你扎浅了，或者扎偏了。翳风的得气感，一定要往耳朵里面走，不往耳朵里走，效果就出不来。”他还说，翳风这个穴，**手法比穴位更重要**。同样的翳风，有人针了有效，有人针了没用，差别就在手法。虚证要轻捻慢转，如春风拂柳；实证要重捻快转，如秋风扫叶。这是倪师的不传之秘。

- 倪师最后叮嘱：**翳风禁灸**。他讲过一个教训，有个学生给耳鸣病人灸翳风，结果病人耳内流脓，耳鸣更严重了。倪师说：“少阳相火的地方，你拿艾火去烤，等于火上浇油。翳风只针不灸，这是铁律。”
