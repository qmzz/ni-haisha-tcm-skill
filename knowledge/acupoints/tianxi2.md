# 天溪二

## 📍 经络归属与精准取穴法

- **所属经络**：足太阴脾经。天溪者，脾经从腹上胸之要穴也。倪师常言，足太阴脾经自隐白起，循腿内侧上行，入腹属脾络胃，再上膈挟咽，其胸段穴位自周荣、胸乡、天溪一路排开，皆在胸外侧壁。天溪不属五输穴，亦非原络郄募俞，乃脾经在胸的经气转输之穴，别具开胸利膈之能。

- **倪师动态取穴法**：倪师讲此穴，必先叫人“先找乳头，再找肋骨，别拿尺子瞎量”。手法是：令患者仰卧或正坐，先定乳头（男取乳头，女取第四肋间隙锁骨中线外开一寸为准），乳头向外横开二寸，再向下数到**第四肋间隙**——天溪就在第四肋间隙，前正中线旁开六寸处。倪师强调，肋间隙是一格一格数的，“你摸到的肋缝，就是穴位的上下层”。骨度折量上，两乳之间为八寸，乳中线到前正中线为四寸，天溪再向外开两寸，故为旁开六寸。倪师说：“不要死记六寸，你在肋骨上一卡，正好在第四肋间、胸大肌外缘凹陷处，那就是天溪。”

- **下针深度与禁针禁灸法则**：倪师明言，胸部穴位“浅刺为要，斜刺为稳”。天溪平刺或斜刺，进针深度**不可超过一寸**，一般五分至八分即可，针尖沿肋间隙向外斜刺，绝不可直刺深刺——内有肺脏，深刺必成气胸，此为倪师反复告诫之铁律。灸法方面，倪师认为此穴可灸，但灸量宜轻，三壮五壮即可，不可大炷猛灸，胸为宗气所聚，过灸反躁。另：凡胸部穴位，患者瘦弱、肋骨显露者，更当浅刺；孕妇则胸腹诸穴皆慎，天溪亦不例外。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：倪师解天溪，不从解剖神经血管讲，而从气化讲。脾经升至胸段，经气已由下焦升入中焦，再至上焦。天溪者，“天”指上部胸肺，“溪”指气血如溪流缓行至此。倪师推演其开阖：天溪是脾经向胸中宗气转输的门户，能**宽胸利膈、降逆止咳、通乳散结**。气机不畅、胸膈满闷、咳逆上气者，取天溪可开胸中气结，使脾之清气上达胸中而不过亢，浊气下降而不上逆。倪师特别点出：乳痈、乳汁不通，看似乳房局部病，实则脾经气血瘀滞于胸，天溪正能疏通此段溪流，故为通乳要穴。

- **子母补泻心法**：天溪非五输，不直接论母子补泻。但倪师教人，要从脾经整体五行看——脾属土，土生金，肺属金。天溪位于胸，与肺相邻，脾土之气上输于肺金，此为“母生子”的自然转输。若肺虚气弱而咳，脾土不能生金，可在天溪轻补（浅刺、留针、微捻），助脾土上输以养肺金；若胸中气滞、咳逆喘满属实，则在天溪泻之（针尖向外斜刺，得气后摇大针孔，疾出），泻其有余之气。倪师言：“胸中气实，泻天溪如开窗；胸中气虚，补天溪如添柴。”此外，若配肺经太渊补之，更合“虚则补其母”之意——脾土生肺金，天溪通脾肺之气，太渊补肺气，母子相配，气化自周。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：天溪主胸胁满痛、咳逆上气、喉中痰鸣、乳痈、乳汁不通、乳少。倪师临床最常用此穴治**产后乳汁不通**，认为其效不在少。又有胸膜炎、肋间神经痛之胸痛，天溪配内关、公孙，宽胸理气，针下痛止。急症方面，若见胸中窒闷、气逆欲绝，可急取天溪、内关、公孙同施，开胸降逆以救逆。

- **倪师经典对穴与排针组合**：
  - **天溪 + 内关 + 公孙**：倪师治胃心胸诸疾之经典组合。内关通阴维，公孙通冲脉，二穴合治胃心胸，天溪在此局中开胸利膈，三者相合，气机自胸至腹一路通畅。倪师言：“内关公孙是主轴，天溪是开胸的钥匙。”
  - **天溪 + 膻中 + 少泽**：治产后乳汁不通。膻中为气会，天溪通脾经之乳络，少泽为通乳经验要穴（小肠经井穴），三穴合用，气行乳通。
  - **天溪 + 丰隆 + 太渊**：治咳逆痰多。丰隆化痰，太渊补肺气，天溪宽胸降逆，此为痰咳标本兼治之局。
  - **天溪 + 期门 + 支沟**：治胸胁满痛、肋间神经痛。期门疏肝，支沟通胁，天溪开胸，气滞得散。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲胸腹部穴位时，曾言：“天溪这个穴，你们不要小看它。胸部的穴，我平常下针不多，但天溪我常用，尤其是太太们生完小孩，奶水出不来，胀得痛得要命，天溪针下去，再配少泽，奶水就下来了。这个穴，我告诉你，就是在乳头外开两寸，再往下摸到第四肋间。你摸到肋骨缝，针斜斜地进去，不要深，五分就够了。得气的时候，病人会感觉胸中一松，像窗户打开一样。”

- 倪师又云：“胸部扎针，最怕气胸。我讲天溪，你们记住一句话——**胸穴如履薄冰，浅刺斜刺是王道**。你不要给我直直地捅进去，那是会出人命的。针尖顺着肋间隙走，方向对了，气就顺了。”

- 关于乳痈，倪师曾讲一医案：“有个太太，乳房红肿热痛，西医说要开刀。我一看，脾经郁热。天溪、膻中、少泽、足三里，针了三次，肿消痛止。为什么？脾经通到胸，天溪把郁气一散，奶水通了，炎就退了。中医不是去杀细菌，是给邪气一条出路。”

- 倪师针天溪的手下体会：“针进去后，轻轻捻转，病人会说胸中有点酸胀，往乳房方向走。那就是气到了。这时候不要再捻了，留针二十分钟，让气自己走。你捻多了，气反而乱。”
