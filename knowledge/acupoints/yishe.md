# 意舍

## 📍 经络归属与精准取穴法

- 意舍穴属**足太阳膀胱经**，在背部，当第**十一胸椎棘突下，旁开三寸**。其定位与脾俞（第十一胸椎棘突下旁开一寸五分）、胃俞（第十二胸椎棘突下旁开一寸五分）紧密相邻，同处一条水平带。
- 意舍非五输穴，亦非原络郄募，它是膀胱经背部穴位中**与脾脏功能直接关联**的重要腧穴。倪师在讲背部穴位时反复强调：膀胱经在背部的俞穴群，是**脏腑之气转输于体表的窗口**，意舍虽不属背俞穴正列，但位于脾俞、胃俞之旁，其气化功能与脾胃运化息息相关。
- **骨度折量法（倪师大白话讲透）**：先找肩胛骨下缘平第七胸椎棘突，往下数到第十一胸椎棘突下。倪师原话：“从第七椎往下走，七八九、十、十一，第十一椎下。旁开三寸怎么找？你叫病人正坐，两个肩胛骨内缘到脊柱的距离是三寸——肩胛骨内缘到脊柱这条线，刚好是三寸。所以意舍就在第十一椎下，肩胛骨内缘这条垂直线上。”
- **下针手法**：倪师讲背部穴位一律强调——**斜刺，针尖朝脊柱方向**，与皮肤呈约三十到四十五度角，**针深五分到八分，不可深刺**。因为背部内应肺脏，直刺深刺有气胸之险。倪师原话：“背上扎针，你给他直直捅进去，扎到肺，变成气胸，那是你自找的。”
- **灸法**：意舍可灸，倪师常用艾灸温补脾胃，尤其对虚寒腹胀、脾阳不振者，灸意舍配合脾俞、胃俞，效果极佳。但热证、实证明显者不宜多灸。

## ⚡ 倪师经穴气化与破局心法

- 意舍之“意”，在中医里属**脾所主**——脾藏意，这是《黄帝内经》明训。倪师在五脏与情志关系的推演中讲过：“脾藏意，意就是思虑、意念。意舍这个穴，就是脾的意思在那个地方舍居之所。”所以意舍的核心气化机理，是**调理脾意、斡旋中焦、运化水湿**。
- 从气血流注的角度看，意舍位于膀胱经背部第十一椎下旁三寸，内应**脾胃之区域**。倪师推演其开阖机理：膀胱经主一身之表阳，背部俞穴群是阳气转输的通道；意舍居脾俞、胃俞之旁，是**脾阳借膀胱经之道外达于表、内通于里的枢纽**。它能引脾胃之气上行外达，又能将中焦积滞从膀胱经的渠道疏散出去。
- **五行生克与子母补泻**：脾属土，意舍虽非脾经本穴，但作用于脾土之功能区。倪师在讲子母补泻时强调，脾经的母穴是**大都（荥火穴）**，子穴是**商丘（经金穴）**。意舍作为脾之功能在背部的反应点，临床上可**配合脾经子母穴**使用：虚则补脾，针意舍加灸脾俞，再取大都补之；实则泻脾，针意舍配商丘泻之。倪师原话：“你光扎意舍不扎脾经的本穴，就好像你敲人家门，敲了门不进去，在外面喊有什么用？”
- 倪师特别指出：意舍还有一个**开窍醒意**的作用。什么叫醒意？就是当一个人**思虑过度、脾意被困**——整天胡思乱想、食欲不振、肚子胀、大便不通或者溏泄——这是脾的“意”被湿气困住了。意舍能**化湿醒脾、开意解困**，让脾的运化功能重新启动。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **腹胀、肠鸣、泄泻**——意舍最核心的主治。脾失运化、水湿内停、气机壅塞于中焦，意舍能通调脾气、分利水湿。
  - **消化不良、食欲不振**——脾意被困，意舍配脾俞、胃俞同用，恢复脾胃的受纳运化功能。
  - **呕吐、吞酸**——中焦气逆，意舍配合中脘、内关，降逆和胃。
  - **背脊痛、胸胁胀满**——意舍所在的背部区域疼痛，局部取穴，兼调脾胃气机。
  - **消渴、黄疸**——倪师讲脾胃与湿热的关联时提到，意舍能利湿退黄，配合脾经、胆经穴位使用。

- **倪师经典对穴与排针组合**：
  - **意舍 + 脾俞 + 胃俞**：背部三点一线，同处第十一、十二椎旁，形成**脾胃背俞组合**。倪师常用这一排针法治疗一切慢性脾胃病。针法：脾俞、胃俞、意舍均斜刺向脊柱，留针二十分钟。
  - **意舍 + 中脘 + 足三里**：前有募穴中脘，后有意舍，下有合穴足三里——**募、背、合**三面合围脾胃，这是倪师治疗一切中焦虚寒、胀满泄泻的经典组合。中脘针深一寸，足三里针深一寸半，意舍斜刺五分。
  - **意舍 + 天枢 + 关元**：治疗脾虚久泄、五更泻。天枢是大肠募穴，关元是小肠募穴兼培元固本，意舍从背部转输脾阳，三穴合用，**温脾固肠**。
  - **意舍 + 公孙 + 内关**：公孙通冲脉、络胃，内关通阴维、络心包，这是倪师治**胃心胸**的经典组合。再加意舍从背部调脾，对胃痛、胸闷、反酸、腹胀有奇效。
  - **意舍 + 章门 + 期门**：章门是脾之募穴，期门是肝之募穴。意舍配章门，**前后呼应脾之募俞**；配期门，则**肝脾同治**，对胁胀、脾肿大、消化障碍尤佳。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲背部穴位时，从第七椎讲到第十四椎，一路讲下来。讲到意舍时，他是这样说的：

  **“第十一椎下，外开三寸，就是意舍。脾藏意，意舍就是脾的意思舍在这个地方。你下针的时候，从第十一椎下，肩胛骨内缘这条线，斜刺进去，五分。你不要直直捅，捅到肺里面去，那就变成气胸了。这是治腹胀、肠鸣、消化不良的穴。”**

- 倪师在讲脾胃病治疗大法时，有一段经典论述：

  **“你看这个人肚子胀，吃什么都不消化，你问他大便好不好？有的便秘，有的下利。这种长期的脾胃问题，你光扎足三里、中脘，效果有，但不够。为什么？因为背后的阳气没有调动起来。背部的俞穴是脏腑的窗口，你把意舍、脾俞、胃俞一起下针，前面中脘、足三里跟上，后面阳气一转动，前面胃气就降下来，脾气就升上去。这就是‘升清降浊’。”**

- 倪师在讲灸法时提到意舍的运用：

  **“虚寒的人，肚子老是咕噜咕噜叫，吃什么拉什么，你灸意舍、灸脾俞、灸胃俞，再灸关元。灸完他会觉得肚子暖暖的，这就是脾阳回来了。脾阳一回来，意就醒了，他就想吃东西了。”**

- 倪师还有一个临床心法——**“治脾先治意”**。他讲：很多人的脾胃病，根子在思虑太过。思伤脾，脾藏意，意一伤，脾就不运化。你问他为什么肚子胀？他说最近烦心事多。这种病人，你针意舍，再加**神门、内关**，把心脾一起调，效果比单纯扎脾胃穴好得多。因为**心脾是母子关系**，火生土，心火能够温煦脾土；神门宁心，意舍醒脾，心脾同调，这才是治本。
