# 颔厌

## 📍 经络归属与精准取穴法

- **所属经络**：足少阳胆经。颔厌是胆经在头侧部的第三个穴位，从瞳子髎上来，经过听会、上关，第四个就是颔厌。
- **特定穴属性**：颔厌不是井荥输经合，也不是原络郄募俞。它是胆经头面部的 ** 交会穴**——手足少阳、足阳明之会。这一点很重要：颔厌同时是三条阳经（足少阳胆经、手少阳三焦经、足阳明胃经）的气血交会处，所以它调的是“三阳经的气”，能同时清胆火、利三焦、降胃逆。
- **倪师动态取穴与骨度折量法**：
  - 找穴时，先让病人咬紧牙关，下巴骨（下颌骨）会鼓起来一块，那个鼓起的骨头上缘就是下颌骨髁状突。颔厌在髁状突的上方、颞肌的前缘。
  - 倪师讲得更直白：你从瞳子髎往上，沿着发际的弧度往后摸，摸到一个凹陷，那个地方就在眉梢和发际之间、额角发际上五分的位置。你用一个指头顺着额角往上推，推到发际边缘那个小凹坑，就是颔厌。
  - 更简单的找法：额角发际上0.5寸，头维穴（胃经）和曲鬓穴（胆经）连线的上1/4处。你拿手按下去，病人会觉得酸胀，有时候会往眼睛方向窜。
  - **下针深度**：沿皮刺，往下（向曲鬓方向）平刺0.5～0.8寸。倪师强调，这个地方是头骨和颞肌交界处，不要直刺，直刺容易扎到骨膜，病人会疼得跳起来。平刺，顺着经络走的方向透刺。
  - **禁灸**：颔厌一般不灸。头面部穴位，倪师说的“阳经不灸”，这里灸了容易上火，而且头发烧焦了味道很难闻。禁针禁灸法则里，颔厌不禁针，但禁灸。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演的气血流注与开阖机理**：
  - 颔厌的气血流注，是胆经气血从听会、上关上来之后，在颔厌这个位置有一个 ** 横向的开阖**。为什么叫“颔厌”？颔就是下巴，厌就是“压下去、合上”的意思。你看下巴一咬合，颞肌一收缩，颔厌这个位置的气血就被“合”住了。所以这个穴是管“开合”的——眼睛的开合、嘴巴的开合、牙关的开合。
  - 胆经的气在这里有一个“向内灌”的动作，它把足少阳的相火、手少阳的三焦气、足阳明的胃气，三股阳气交会在一起，往下灌到下颌关节、耳朵、眼睛。所以颔厌开的是“上焦三阳之气”，偏头痛、眼睛痛、牙关紧、耳朵闷，都是这个“开阖”卡住了。
  - 倪师的心法叫 **“开阖利窍、引火下行”** 。胆火往上冲，冲到额头、眼睛，你会偏头痛、眼睛红、耳鸣。颔厌就是那个“阀门”，你一下针，三阳经的气就往下走，火就降下来了。
- **子母补泻与五行生克运用心法**：
  - 胆经属木。木生火，胆经的经穴（阳辅）属火，是子穴；胆经的荥穴（侠溪）属水，是母穴。颔厌本身不是井荥输经合，所以它不是子母补泻的“直接操作点”。但倪师说，颔厌是胆经头面部的“气口”，你在颔厌下针，配合侠溪（母穴，补水）或阳辅（子穴，泻火），效果翻倍。
  - 虚则补其母：胆虚的人，胆子小、易惊、眼睛发花、偏头痛隐隐的，你在颔厌平刺，再加侠溪（水穴，补水养木），这叫“母穴补虚，子穴引气”。
  - 实则泻其子：胆实的人，偏头痛剧烈、眼睛胀红、耳朵暴鸣、嘴苦，你在颔厌下针，再加阳辅（火穴，泻木之子），这叫“泻子降火，颔厌开门放气”。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **偏头痛**：尤其是胆经循行部位的偏头痛，从太阳穴到额角到耳后，颔厌是首选。倪师说，偏头痛你扎颔厌、太阳透率谷，当场就松了。
  - **眼睛痛、目眩、目外眦痛**：颔厌是手足少阳之会，少阳经别“散于目”，所以眼睛外角痛、见风流泪、目眩，颔厌有效。
  - **耳鸣、耳聋**：胆经的气从颔厌往里灌耳，所以耳鸣、耳朵闷、听力下降，颔厌配听会、翳风。
  - **牙关紧闭、下颌关节炎**：颔厌配颊车、下关、合谷。倪师说，下巴咬合不利索，颔厌一针下去，颞肌就松了。
  - **面瘫、口眼歪斜**：颔厌配地仓透颊车、阳白透鱼腰、四白，这是胆经和胃经一起调。
  - **癫痫、抽搐**：颔厌是手足少阳、阳明之会，三阳经的气都在这里会合，抽搐、癫痫、惊风，颔厌配筋缩、阳陵泉。
- **倪师经典对穴与排针组合**：
  - **颔厌 + 太阳透率谷**：偏头痛的经典组合。颔厌平刺，太阳向率谷透刺，一针下去，整个头侧部的胆经就松开了。
  - **颔厌 + 听会 + 翳风**：耳鸣耳聋。颔厌开三阳之气，听会通耳窍，翳风散少阳风热，三个穴位一起，耳朵的问题就解决了。
  - **颔厌 + 合谷 + 太冲（开四关）**：头面部一切气机闭阻的问题，开四关调气血，颔厌开局部气机，上下呼应。
  - **颔厌 + 足三里 + 中脘**：胆火犯胃、恶心呕吐、偏头痛伴随胃不舒服，颔厌降胆火，足三里、中脘降胃气，那就上下都通了。
  - **颔厌 + 风池 + 外关**：偏头痛伴随颈项强、发烧、少阳证，颔厌配风池、外关，和解少阳，解表散邪。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：
  - “颔厌这个穴，你看名字就知道了，颔就是下巴，厌就是合起来。你咬紧牙关，这里一鼓，那就叫颔厌。所以它管什么？管你下巴的开合，管你眼睛的开合，管你耳朵的通闭。凡是‘开合’不利索的病，你都可以在这里下针。”
  - “偏头痛，痛得眼睛都睁不开，你扎颔厌、太阳透率谷，当场就好一大半。胆经的气从这里过，你一针下去，气就通了。这个穴是胆经的‘气口’，专门放胆火的。”
  - “颔厌是手足少阳、阳明之会。三条阳经的气都在这里碰头，所以你一针下去，胆火也降了，三焦也通了，胃气也顺了。偏头痛、耳朵响、牙齿咬不住，统统管。”
  - “下针的时候，不要直刺，要平刺，顺着经络往下透。你直刺，扎到骨头上，病人疼得跳起来骂你。平刺，贴着皮，往下透到曲鬓，气就顺下去了。”
  - “这个穴禁灸，头面上的阳经穴，你灸了火上浇油，偏头痛更厉害。针可以，灸不行。”
- **实战手下针感体会**：
  - 倪师说，颔厌下针，针尖下去之后，病人会有一种“酸胀往眼睛方向窜”的感觉，有时候会窜到太阳穴，有时候会窜到耳朵。如果病人说“酸到眼睛了”，那就是气到了。如果病人说“痛”，那就是扎到骨膜了，你要退针，重新平刺。
  - 偏头痛急性发作时，颔厌一针下去，针还没捻，病人就说“松了”，这是气机一下子就通了。
- **医案故事**：
  - 倪师讲过一个案例：一个太太偏头痛二十年，痛起来眼睛都睁不开，西医说是“丛集性头痛”，止痛药吃到胃出血。倪师在她颔厌、太阳透率谷、风池、外关下针，第一次针完，头就不痛了。连续针了五次，配合中药（小柴胡汤加减），二十年的偏头痛就断根了。倪师说：“你看，胆经的气堵在颔厌这里，你把它一开，火就下来了，痛就好了。中医不是止痛，是开气机。”
  - 还有一个案例：一个年轻人牙关咬紧，嘴巴张不开，西医说是“颞下颌关节紊乱”，要开刀。倪师在他颔厌、颊车、下关、合谷下针，针了三次，嘴巴就能张开了。倪师说：“颔厌管开合，你这里一针，颞肌就松了，下巴就开了。开刀？开什么刀？”
