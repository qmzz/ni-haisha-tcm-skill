# 青灵

## 📍 经络归属与精准取穴法

青灵穴，属**手少阴心经**。心经的井荥俞经合五输穴依次是：少冲（井木）、少府（荥火）、神门（俞土）、灵道（经金）、少海（合水）。青灵穴在灵道与少海之间，**不属于五输穴**，它是心经上一个专门的穴道，倪师在讲心经时把它单独点出来，就是因为它有专门的用处。

怎么找青灵？倪师的法子是：**叫病人手肘弯曲，肘内侧横纹头找到少海穴，少海往上三寸就是青灵。** 三寸怎么折？从肘横纹到腕横纹是十二寸，分四段，每段三寸。你先找到少海，再往上量一个三寸，贴着肱骨内侧面，就是在**肱二头肌内侧沟**里面。倪师原话：“青灵在少海上面三寸，你摸上去，在骨头旁边、肌肉中间那个凹陷就是。”

下针的时候，**直刺，针一寸到一寸半**。倪师强调：“青灵这个穴，你扎下去，病人会有酸麻胀的感觉往手臂内侧窜，有时候会窜到小指。”禁灸——倪师在《人纪》里面提到青灵的时候说得很清楚：“**青灵禁灸**，你灸了反而不好，因为它靠近大血管，灸了容易出问题。”所以这个穴是**只针不灸**。


## ⚡ 倪师经穴气化与破局心法

青灵的气化机理，要从心经的整个气血循行来看。心经属火，从极泉出来，沿着手臂内侧后缘下行。灵道是心经的经穴（属金），少海是合穴（属水）。青灵夹在灵道和少海之间，倪师认为它的作用是**“通心脉、利肩臂”**。

心主血脉，当心火不足、气血不能通达四肢的时候，手臂内侧会痛、会麻、会冷。青灵这个穴，倪师说它是**“把心火引到手臂上去的通道”**。你一下针，心火顺着经络就下来了，肩膀、手臂的寒凝之气就被冲开了。这个就是倪师常讲的**“引火归元”**在手臂上的具体运用——不是引到下焦，而是引到上肢末端。

子母补泻方面，青灵本身不是五输穴，所以不直接用它做子母补泻。但倪师的心法是：**如果你要补心经，用少冲（井木为母）来补；要泻心经，用少海（合水为子）来泻。** 青灵夹在中间，是配合这些穴道做**辅助通经**用的。比如你补了少冲，心气起来了，但手臂还是痛，这时候加青灵，让气能通过去。这个就是倪师的**“补了还要通，通了才算补到位”**的心法。


## 🎯 临床主治与配穴组合手印

青灵的核心主治，倪师归纳为三条：

**第一，肩臂痛、手臂内侧痛。** 这是青灵最拿手的。不管是五十肩、手臂举不起来、还是内侧扯痛，青灵一下去，配合对侧合谷，效果立竿见影。

**第二，心痛、心悸、胸闷。** 心经的穴道都能治心病。青灵配合**内关**（心包经络穴）、**公孙**（冲脉交会穴），这是倪师治胃心胸的经典组合。内关公孙一通，胸腔的气就打开了，再加青灵把心火引到手臂，病人当场就觉得胸口松了。

**第三，瘰疬、腋下肿。** 青灵靠近腋下，对于腋下淋巴结核、肿胀，倪师会**近取青灵、远取太冲**，用太冲开四关来疏导肝气，因为淋巴系统跟肝经关系密切。

倪师经典对穴组合：
- **青灵 + 少海 + 灵道**：心经三穴连用，治手臂内侧整条线的痛麻。
- **青灵 + 内关 + 公孙**：治心痛、心悸、胸闷。
- **青灵 + 合谷 + 太冲**：开四关，配合青灵通手臂，治肩臂痛兼有气滞血瘀的。
- **青灵 + 肩髃 + 曲池**：治五十肩，手臂不能上举。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲手少阴心经时，讲到青灵穴，原话大意如下：

“青灵在少海上面三寸。这个穴道呢，**禁灸**。你下针的时候，针下去一寸到一寸半。病人手弯起来，你从少海往上找三寸，就在那个肌肉和骨头中间。青灵专门治什么？**手臂内侧痛、肩膀痛、心痛。** 你看这个人手抬不起来，你下青灵，对侧合谷一针，叫他动一动，当场就好了一半。这个穴道很少人用，但是很好用。你们记住，**心经的穴道都跟心有关系**，青灵也一样，心气不通的时候，青灵一下去，气就通了。”

倪师还特别提到一个实战体会：“青灵这个穴，你扎对了，病人会感觉**一股热流从手肘往小指方向走**，那就是心火被引下来了。如果病人说没感觉，那就是你扎偏了，或者扎得太浅，要再深一点，贴到骨边上去。”

医案方面，倪师讲过：有个病人手臂内侧痛了半年，西医说是神经压迫，要开刀。倪师取了**对侧青灵、合谷，同侧肩髃、曲池**，针完当场手臂就能抬起来了。倪师说：“这种痛，你只要知道经络走向，心经从胸走手，青灵把中间堵住的地方打通，上面下面都通了，痛就去掉了。”
