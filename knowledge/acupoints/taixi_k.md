# 太溪穴 (KI3)

## 📍 经络归属与精准取穴法

太溪穴，肾经上的大穴。肾经的走向是从脚底涌泉穴起来，沿着内踝一路往上走。太溪在哪里？在内踝骨跟脚后跟大筋的中间，两个骨头和筋之间的凹陷处，你手一摸，内踝高骨和跟腱之间那个缝隙，正中间就是太溪。

倪师讲取穴的时候，最反对死记硬背“内踝尖与跟腱之间凹陷处”这种干巴巴的定位。他的原话意思是——你摸到内踝那个高骨，往后推，推到跟腱边上，骨和筋中间有个坑，那个坑就是太溪。你拿手一按，酸酸胀胀的，那就是穴道没跑。这种“骨筋之间求凹陷”的手感，比看多少书都管用。

肾经的五输穴排列：涌泉是井穴（木），然谷是荥穴（火），太溪是俞穴（土），复溜是经穴（金），阴谷是合穴（水）。太溪在五行里属土，而肾经本身属水。土克水——所以太溪是肾经的“母穴”吗？等等，这里要分清楚：肾经属水，太溪属土，土克水，克我者为“所不胜”……不对，子母补泻要看“生我”和“我生”。肾经的水，生我者是用金（复溜），我生者是用木。但五输穴的五行归属是按阴经的规则：井木、荥火、俞土、经金、合水。所以肾经（水）的俞穴太溪属土，这是“我克”的穴，不是母穴。肾经真正的母穴是复溜（金），因为金生水；子穴是涌泉（木），因为水生木。

但太溪还有另一重身份——它是肾经的**原穴**。倪师讲原穴时说过一句很重要的话：“五脏不平衡时用原穴。”原穴就是脏腑元气经过和留止的地方，不管虚实寒热，原穴都能调。太溪作为肾经原穴，它的地位比一般俞穴要高出一截——它是肾脏元气直接透出来的窗口。所以倪师临床上，遇到肾的问题，太溪是必取的。

下针深度：倪师人纪里讲，太溪下一寸左右，也就是针进去大概五分到一寸。不能太深，因为底下就是骨头。针下去的时候，病人会有酸麻胀的感觉，有时候会往脚底窜。禁灸？太溪不是禁灸穴，但倪师一般以针刺为主，灸也可以，尤其是虚寒的人，灸太溪能温补肾气。


## ⚡ 倪师经穴气化与破局心法

太溪这个穴，倪师在《人纪·针灸篇》里讲得很有味道。他说肾是“先天之本”，是“作强之官，伎巧出焉”。太溪作为肾经原穴，它能把肾的元气直接调动起来。什么概念？就是当一个人肾气虚弱到一定程度，你按太溪，他可能没什么感觉——穴道都“陷”下去了，摸不到那个饱满的坑。反过来，肾气足的人，太溪按下去是饱满的、有弹性的。

倪师推演太溪的气化机理，核心在于“**引火归元**”和“**通调水道**”两个层面。

引火归元是什么意思？中医讲肾水上面是心火，正常情况下水火既济。但如果你肾水太寒、太虚，心火就下不来，上面热得要死，下面冷得要命——这叫“火不归元”。太溪能把上面浮越的虚火引下来，让它回到肾水里面去。倪师临床上治失眠、治烦躁、治更年期潮热，取太溪就是取这个“引火归元”的作用。

通调水道呢？肾主水，主二便。太溪能通肾气，肾气一通，水道就利。所以水肿、小便不利、尿频、遗尿，太溪都能治。倪师特别讲到，很多老年人夜尿多，一晚上起来七八次，太溪配复溜、配关元，效果很好。因为肾气足了，膀胱的固摄能力就回来了。

子母补泻怎么用？太溪是俞穴（土），按五行生克，肾经属水，水生木，木是子；金生水，金是母。所以肾经的补泻要看复溜（金，母）和涌泉（木，子）。但太溪作为原穴，本身就有“调和虚实”的功能。倪师说，你如果分不清到底是虚是实，那就扎原穴，原穴自己会调。太溪就是这样一个“万能调节器”——虚的人扎了能补，实的人扎了能泻，因为它调动的是肾脏的根本元气。


## 🎯 临床主治与配穴组合手印

太溪的主治范围，倪师在讲义里归纳得很清楚。核心就是：**一切肾虚之证，一切与水液代谢相关的病，一切与元气不足相关的慢性病。**

具体来说：

**第一，肾病本身。** 肾炎、肾结石、肾功能衰竭，太溪是必取穴。倪师讲过，肾结石痛得要命的时候，太溪配肾俞、配京门，能迅速缓解疼痛。为什么？因为太溪是肾经原穴，能直接作用于肾脏本身。

**第二，生殖系统疾病。** 遗精、阳痿、早泄、性冷淡，太溪配关元、配命门。倪师说，男人的精子问题是肾在管，太溪能补肾精。女人的月经不调、不孕、带下，太溪配三阴交、配血海。

**第三，呼吸系统疾病。** 肾主纳气。很多人喘，不是肺的问题，是肾不纳气。太溪配太渊、配膻中，能纳气归元。倪师治气喘，尤其是那种吸不进气的感觉，太溪是关键的穴。

**第四，五官科疾病。** 肾开窍于耳。耳鸣、耳聋，尤其是虚证耳鸣（那种蝉鸣声、低沉的嗡嗡声），太溪配听宫、配翳风。倪师讲过，实症耳鸣是声音大、突然发作，那是肝胆火，要扎外关、听宫；虚症耳鸣是声音小、慢慢来的，那是肾虚，要扎太溪、复溜。

**第五，腰痛。** 腰为肾之府。肾虚腰痛，太溪配肾俞、配委中。倪师特别讲，那种隐隐的、酸酸的、按一按舒服的腰痛，是肾虚，扎太溪；那种刺痛、不能碰的腰痛，是瘀血，要扎委中放血。

**经典配穴组合：**

- **太溪 + 肾俞 + 关元 + 命门**：补肾固本，治一切肾虚。
- **太溪 + 复溜**：肾经母子配穴，补泻兼施，治水肿、小便不利。
- **太溪 + 三阴交**：肝脾肾同调，治妇科病、生殖病。
- **太溪 + 太渊 + 膻中**：补肾纳气，治虚喘。
- **太溪 + 听宫 + 翳风**：补肾聪耳，治虚证耳鸣耳聋。
- **太溪 + 照海**：肾经原穴配阴跷，治咽喉干痛（肾水不能上济）。
- **太溪 + 昆仑**：原络配穴，治腰背酸痛。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲太溪的时候，有一段非常精彩的实录。他说：

“太溪穴，你看它在内踝高骨和跟腱的中间。你摸上去，有个动脉在跳，那就是肾气在跳。肾气强的人，太溪脉是很明显的；肾气弱的人，你按半天都摸不到。所以太溪这个地方，本身就是一个诊断点——你按病人的太溪，如果脉跳得很弱，甚至摸不到，那这个人肾气已经大虚了。”

他还讲过一个实战案例：有个病人来找他，说两条腿肿得像馒头，小便又少。倪师一看，这是肾阳不足，水泛为肿。他取太溪、复溜、三阴交、阴陵泉，针下去以后，病人当场就说想上厕所。倪师说：“你看，肾气一动，水就下来了。太溪就是我们调动肾气的那把钥匙。”

倪师还特别强调太溪的针感。他说：“太溪针下去，不是那种剧烈的麻，它是一种酸胀，有时候会往脚底涌泉那边窜。病人会感觉脚底热热的，那就是肾气起来了。如果你针下去，病人一点感觉都没有，那说明肾气太虚了，你要考虑用灸法，慢慢温它。”

倪师还有一个心法：太溪配复溜，一补一泻，治水肿如神。他说：“复溜是经穴，属金，是肾经的母穴；太溪是原穴，是肾气的根。两个穴一配，一个从源头上补，一个从根上调，水肿没有不消的。”

最后倪师说了一句很重的话：“很多人只知道太溪治腰痛、治耳鸣，不知道太溪能治心脏病。为什么？因为心肾是相交的。你肾水足了，心火才能下来。太溪把肾水一补，心火自然就归位了。所以心律不齐、心悸、失眠，太溪都能治。这就是中医的整体观，你不能把肾和心分开看。”
