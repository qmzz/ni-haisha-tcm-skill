# 头临泣

## 📍 经络归属与精准取穴法

- 头临泣是**足少阳胆经**的腧穴，同时是**足太阳膀胱经、足少阳胆经、阳维脉**三条经脉的**交会穴**。在五输穴体系中，足少阳胆经的腧穴排列是：井穴足窍阴（金）、荥穴侠溪（水）、输穴足临泣（木）、经穴阳辅（火）、合穴阳陵泉（土）。头临泣**不在五输穴之列**，但它是胆经头部气血与阳维脉交汇的关卡，倪师常把它当作胆经在头部的“气街开口”来用。

- 倪师取穴从来不拘于书本上那句“入发际五分”，他要求你先在病人头上找到**瞳孔正中线**，再从**眉毛正中直上入发际五分**定一点，然后让病人**微微仰头**，你的手指沿这条线从神庭（督脉）往外摸，摸到第一个**骨缝凹陷**处，这就是头临泣。倪师特别强调：不要死板地用尺子量，要用手去“循”，《针灸大成》讲“以手按之，患者感酸胀，如空谷应声”，这就是穴位的“应手”。

- 具体骨度折量：前发际至后发际为12寸，头临泣在**前发际正中直上0.5寸，再旁开0.75寸**（约当瞳孔直上入发际0.5寸处）。倪师的口诀是：“眉心上，入发半，瞳孔线，旁开七五，陷中藏。”就是让你从两眉之间向上摸半寸，再沿瞳孔直线往外挪一点点，指尖下有个小凹窝，一按病人眼睛会发酸、鼻根发胀，头临泣就在这里。

- 下针深度：倪师说头临泣**沿皮刺**，针尖向下或向后方平刺**0.5~0.8寸**，千万不要直刺深刺。因为下面就是额骨，深刺会伤及骨膜，病人会剧痛。禁灸。灸了之后，头面会肿，热邪上壅，眼睛红肿，所以倪师在视频中反复告诫：**头临泣禁灸，只针不灸**。小儿囟门未闭者，此处禁针。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演头临泣的气化机理，核心一句话：**“胆经的精气到头上，要从临泣这个口子渗出去，润养眼睛、鼻子、脑窍。”** 足少阳胆经从风池上来，经过脑空、承灵、正营、目窗，一路走到头临泣，就在这里**“临”**——居高临下，如泣如诉地灌注。头临泣的气血物质是**天之上部的凉湿水气**，它从胆经的阳热中蒸化而来，到了这里冷凝成“泣”——像屋檐的露珠一样往下滴灌。所以头临泣主治的都是**上窍不通**的病：眼翳、鼻塞、头痛、目眩、小儿惊风。

- 倪师把这种机理叫做**“开天窗，引阳入阴”**。头临泣是阳维脉的交会穴，阳维主一身之表，所以头临泣打开之后，阳气可以从此处灌入脑络，阴液可以从此处降下目窍。临床上遇到**眼睛红肿、迎风流泪、鼻窦炎前额痛**，倪师就在头临泣下针，针尖向后方平刺，引胆经的阳气回头，同时让上部的郁热从这个小口子泄出去。这叫**“上病上取，开窍泄热”**。

- 子母补泻方面，头临泣不属于五输穴，所以不直接按“虚则补其母，实则泻其子”来操作。但倪师有一个变通心法：**头临泣是胆经的“气口”**，胆经的木气（足临泣为输木）如果升发太过，冲到头上，你就会偏头痛、眼睛胀；如果升发不及，你就会头晕、目涩。这时候针头临泣，**顺经而刺（向后）为补**，**逆经而刺（向前）为泻**。补法用于胆气升不上来的头晕眼花；泻法用于胆火上冲的偏头痛、目赤。倪师说这比死记子母穴还管用。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **头痛**：少阳经偏头痛、前额痛连及目眶。
  - **眼疾**：目赤肿痛、迎风流泪、目翳、青光眼眼压高、视物模糊。
  - **鼻病**：鼻窦炎、鼻塞、前额昏痛。
  - **神志病**：小儿惊风、癫痫、失眠多梦（胆虚不得眠）。
  - **其他**：中风后遗症的头面浮肿、面神经麻痹、牙痛牵及太阳穴。

- **倪师经典对穴与排针组合**：
  - **头临泣 + 足临泣**：上下呼应，一在头，一在足，同属胆经，专治**偏头痛、目眩、胁肋痛**。倪师说“上临泣开天窗，下临泣通地户”，上下一起针，胆经就通了。
  - **头临泣 + 阳白 + 攒竹**：治**前额痛、眉棱骨痛、眼睑下垂**。三针齐下，针尖都向后平刺，像梳子一样把额头的经气梳开。
  - **头临泣 + 风池 + 合谷**：治**感冒头痛、鼻塞流涕**。风池解表，合谷开四关，头临泣把药引到头上。
  - **头临泣 + 百会 + 太冲**：治**肝阳上亢型高血压头痛**。百会升清，太冲降浊，头临泣在中间调枢机。
  - **头临泣 + 神庭 + 印堂**：治**小儿惊风、夜啼**。针浅刺，不留针，哭完就好。

- 倪师提醒：头临泣配穴，**针尖方向就是药引子**。你要它往眼睛走，针尖就向下；要它往脑后走，针尖就向后；要它往鼻子走，针尖就向内上方。同一个穴，方向不同，主治完全不同，这叫**“一穴多向，如药之归经”**。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲到足少阳胆经头临泣时，原话是：**“头临泣，你摸那个瞳孔直上，入发际五分，一按下去，病人说哎哟酸，那就是了。针下去，平刺，针尖朝后，不要朝前。朝后是顺经，补；朝前是逆经，泻。头面上的穴，一律平刺，不灸。”**

- 倪师手下针感体会：**“针头临泣，你手法要轻，像蜻蜓点水。针进去五分，病人觉得整个前额像被凉水泼了一下，眼睛突然亮了，这就是气到了。你不要捻太重，头面经气薄，一重就头晕。”**

- 医案故事：倪师讲过一个**眶上神经痛**的病人，痛了三年，西医当三叉神经痛治，卡马西平吃到整天昏昏沉沉。倪师一看，痛在眉毛棱骨，正是头临泣的位置。**针头临泣，针尖向后平刺，再配阳白、攒竹，留针二十分钟，病人起来就不痛了。** 倪师说：“这不是神经痛，是胆经的气堵在临泣这个口子，我把它一针通开，就像下水道通了，水就不漫出来了。”

- 还有一次，倪师治**小儿高烧惊厥**，孩子抽风，眼睛往上吊。倪师**急针头临泣，平刺泻法，再配人中、涌泉**，针下去孩子就哭出来了，烧也退了。倪师说：“头临泣是阳维脉的交会，阳维主表，一针下去，表气一通，热就散了。你们不要小看这个穴，它上通脑窍，下通胆腑，是少阳经在头上的总开关。”

- 倪师最后叮嘱：**“头临泣，禁灸。灸了，火气上头，眼睛会瞎。记住，头上的穴，除了百会、上星可以小灸，其他一律不灸。”**
