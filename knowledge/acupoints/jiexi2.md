# 解溪二

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经。解溪为胃经**经穴**，五行属**火**。胃经本身属土，其经穴属火，火生土，故解溪为胃经之**母穴**。虚则补其母，胃经虚证，补解溪。
- **五输穴定位**：胃经五输——厉兑（井金）、内庭（荥水）、陷谷（输木）、解溪（经火）、足三里（合土）。解溪在经穴位置上，是气血从输穴陷谷汇聚后、向合穴足三里灌注的中继站，气化力强。
- **精准取穴**：脚腕前方，踝关节正中两筋之间。让病人脚稍用力往上翘（背伸），脚腕前面会出现两条大筋（趾长伸肌腱与拇长伸肌腱），两筋之间、横纹正中就是解溪。
- **倪师动态取穴心法**：倪师讲，解溪穴要“从脚腕横纹上摸，两筋之间凹进去的缝隙”，让病人动一下脚踝，筋绷起来，穴道就露出来了。手法上稍微拨开筋，贴着筋缝下针。
- **下针深度**：针入**五分**，不宜过深。方向可直刺，也可略向后（跟腱方向）斜刺，引气下行。
- **禁针禁灸**：解溪可针可灸，但**不宜重灸**。胃经火穴，灸多则火上炎，反致口干、烦躁。倪师一般不在此穴用灸，以针为主。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：解溪为胃经火穴，火能生土，是胃经气血的“加温站”。胃经多气多血，但气血行至踝前，容易因湿浊壅滞而运行不畅。解溪作为经穴，正当踝关节枢机之处，能**通利关节、清降胃火、化湿浊下行**。倪师讲，脚腕是整个下肢气血的“关口”，解溪就是开关，一开则胃气下行、湿浊从足下泄。
- **引火归元与升提中气的双向调节**：解溪五行属火，能温养胃土，对胃中虚寒者可微微振奋中阳；同时它位于下肢远端，又具沉降之性，能把上焦浮火引下来。倪师在讲阳明经时反复强调“阳明主降”，解溪正是阳明经气下行的一个关键节点——胃火牙痛、面肿、目赤，取解溪，就是引火下行。
- **子母补泻心法**：胃经属土，解溪属火，火生土，故解溪为**胃经母穴**。**虚则补其母**——胃气虚、消化不良、食后腹胀、面色萎黄、脉弱无力者，针解溪用补法（顺经而刺，或捻转补法），以火气生土气，助胃运化。**实则泻其子**——胃经实证当泻厉兑（井金，土生金，金为土之子），不在解溪上做泻。倪师明确区分：解溪是补胃的，不是泻胃的，泻胃热要找厉兑或内庭。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **踝关节痛、扭伤、足下垂**：解溪正当踝前，是治踝关节局部病变的第一穴。倪师讲脚踝扭伤，先在对侧解溪下针，再让病人活动脚踝，往往当时痛减。
  - **胃热上攻之头痛、牙痛、目赤**：阳明经循面入齿，胃火循经上炎，取解溪引火下行。
  - **腹胀、便秘、消化不良（胃虚型）**：作为胃经母穴，补解溪能振胃气、助消化。
  - **癫疾、惊悸、头面浮肿**：倪师讲解溪能清阳明之热、降浊气，对阳明热盛引起的烦躁、面肿有效。
  - **足膝无力、下肢水肿**：阳明经多气多血，解溪通利关节、行气化湿，配足三里可治下肢萎软。
- **倪师经典对穴与排针组合**：
  - **解溪 + 足三里**：胃经母穴配本穴合土，虚证补胃的黄金组合。足三里补中气，解溪生胃火，先后天同调。
  - **解溪 + 内庭**：一补一泻，解溪补胃虚，内庭泻胃热，虚实夹杂之胃病常用。
  - **解溪 + 丘墟 + 商丘**：三踝穴合用，治踝关节周围所有问题。倪师讲踝痛要分经：外侧少阳取丘墟，内侧太阴取商丘，前方阳明取解溪。
  - **解溪 + 合谷 + 颊车**：治胃火牙痛、面肿。合谷通面，颊车局部，解溪引火下行，上下呼应。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原话金句**：“解溪在脚腕前面两条筋的正中间，你让病人脚往上翘一下，两条筋一绷，穴道就出来了。这是胃经的母穴，属火，胃经属土，火生土，所以胃虚的人，你要补解溪。”
- **手下针感体会**：倪师讲，针解溪时，针尖穿过两筋之间，病人会感觉一股酸胀从踝前向下窜到脚背甚至脚趾，有时向上到小腿。得气后，如果病人胃虚，你用手按脉，胃脉（右关）会慢慢起来，这就是“火生土”的应验。
- **实战医案故事**：倪师讲过一类案例——病人脚踝扭伤，肿得很大，西医叫他冰敷休息。倪师说，你先在对侧的解溪下针，针下去让病人慢慢转脚踝，这边转那边针，痛当场就松了。因为解溪正当踝前气机枢纽，一针下去，气通了，肿就退。他还特别强调，脚踝扭伤不要急着冰敷，冰敷会把瘀血寒气封在里面，应该先下针通气，再用药活血化瘀。
- **针灸秘要**：倪师强调，解溪是胃经的“火穴”，火穴能温胃，所以**胃寒的人**（吃冷东西就胃痛、喜温喜按），补解溪效果很好。但**胃热的人**（口臭、牙龈出血、便秘、喜冷饮），不要补解溪，要泻厉兑或内庭。这是五行生克的临床铁律，不可混淆。另外，解溪下针要贴着筋缝走，不要扎到筋上，扎到筋病人会抽痛，而且容易伤筋。
