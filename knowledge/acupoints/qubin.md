# 曲鬓

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：曲鬓穴归属**足少阳胆经**，为**足太阳、足少阳之会**（《针灸甲乙经》载“在耳上入发际曲隅陷者中，鼓颔有空”）。此穴非五输穴、非原络郄募，但它是胆经入耳前、上头角的**气化转枢要穴**，在倪师体系中常用于**少阳经气壅滞于耳颊头角**之证的开阖调畅。

- **倪师动态取穴与骨度折量法**：
  1. **摸骨手法**：先寻**耳尖**，正坐或侧卧位，将耳廓向前折，耳尖直上入发际处为**角孙穴**。从角孙向前平移约一横指（约0.5~1寸），再用拇指沿颞骨鳞部骨缝凹陷处轻推，触到“骨槽陷缝”即是曲鬓。倪师常言：“**耳尖上一条弧线，前到眉尾后到风池，中间摸到骨缝就是曲鬓**。”
  2. **骨度折量**：以**耳尖至前发际正中**为基准，曲鬓在耳尖上缘与发际间形成的小凹处，约当**颔厌与率谷之间**。
  3. **下针深度**：倪师强调“**头皮针浅刺，沿皮透刺**”，一般**平刺0.5~0.8寸**，可向率谷或颔厌方向透刺。**禁灸**——头面为诸阳之会，艾火易引火上炎，倪师明言“此穴不灸，灸则目昏耳聋”。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：曲鬓位于**少阳经脉入耳上角、曲折回旋之所**，故名“曲鬓”。倪师推演其气化曰：“**胆经气从风池上来，绕耳后，折入耳前，到曲鬓这里转一个弯，像鬓发打卷一样**。”故本穴主**少阳经气在耳颞部的开阖转枢**。凡**偏头痛、耳后痛、目锐眦痛、齿痛、颊肿**，皆少阳风火上扰、经气瘀阻，取曲鬓可**折其风势、开其壅塞**。

- **子母补泻与五行生克**：胆经属木，曲鬓非经穴，但倪师在临床上**以本穴为胆经在头侧的“气口”**，配合胆经子母穴使用——
  - 胆经**母穴为侠溪**（水穴，水生木），**子穴为阳辅**（火穴，木生火）。
  - **虚则补其母**：胆气虚、目眩耳鸣、怯怯不安者，先取**侠溪**补之，再取**曲鬓**以引气上头，开耳窍之闭。
  - **实则泻其子**：胆火实、偏头痛如裂、耳中轰轰者，先取**阳辅**泻之，再取**曲鬓**点刺放血或平刺，**引火下泄**。
  - 倪师更以**五行生克**推演：“**曲鬓是少阳木气在头面转弯的关节，木郁则折，折则火生。所以曲鬓治头痛，要分虚实——木不足则补侠溪，木太过则泻阳辅，曲鬓本身是调气机的枢纽，不是补也不是泻的穴**。”

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **偏头痛（少阳头痛）**：痛在耳上、太阳穴至眉棱骨一带，曲鬓平刺透率谷，针后痛减如失。
  - **耳疾**：耳鸣、耳聋、耳中痛，少阳风热上壅耳窍，曲鬓配**听会、翳风**，针后耳内如有风出。
  - **目疾**：目锐眦痛、目眩、视物模糊，曲鬓配**瞳子髎、风池**，清少阳而明目。
  - **颊肿齿痛**：下牙痛、颊车肿，曲鬓配**颊车、合谷**，可立缓。
  - **急症救逆**：倪师曾以**曲鬓点刺放血**治“**少阳中风、头面肿痛、目不能开**”之急性症，引血泄热，风散肿消。

- **倪师经典对穴与排针组合**：
  - **曲鬓 + 率谷 + 太阳**：偏头痛三针，从曲鬓透刺率谷，太阳点刺放血，专治少阳头痛。
  - **曲鬓 + 听会 + 中渚**：耳鸣耳聋组合，中渚为三焦经输穴，通上焦气机，引少阳之气入耳。
  - **曲鬓 + 风池 + 合谷**：风池祛风，合谷开面口之窍，曲鬓为引经报使，治头面风热肿痛。
  - **曲鬓 + 阳辅 + 侠溪**：胆经母子补泻配头部气口，调胆经虚实之偏。

## 🗣️ 倪师讲义实录与针灸秘要

- **原汁原味逐字稿金句**：
  > “曲鬓这个穴，你看它名字——‘曲’，弯曲；‘鬓’，头发打卷的地方。胆经的气从风池上来，到了耳朵前面，转一个弯，像鬓发一样卷一下，就是这个穴。所以它是**少阳之气转弯的枢纽**。你偏头痛、耳朵痛，就是气在这里转不过去，堵住了。针下去，气一转，痛就去掉了。”

  > “**曲鬓不灸**，你拿艾条一烤，火气上头，病人耳朵更聋，眼睛更花。头面穴位，除非特别虚寒，否则少灸。针法用**平刺**，沿着头皮，针尖刺进去像在皮下穿一条线，不要直刺太深，深则伤骨膜，病人剧痛。”

- **实战手下针感体会**：
  > “针曲鬓，病人会有一种**酸胀感往耳朵里面走**，有时候会觉得**耳内一阵热**，那就是气到了。如果病人说**像有东西从耳前滑到耳后**，那就是少阳经气通了。留针二十分钟，偏头痛当场松掉。”

- **医案故事**：
  > “有个病人偏头痛十几年，痛起来抱着头撞墙。我一看，痛在耳朵上面，太阳穴跳，这是少阳头痛。我先在**曲鬓、率谷**平刺，再取**阳辅**（胆经子穴）泻之，**侠溪**（母穴）补之。针下去不到五分钟，病人说**耳朵里好像有风吹出来**，头就不痛了。后来我再教他，平时按揉曲鬓，配合深呼吸，让少阳之气不要上冲。这个穴，是少阳头痛的**开关**。”
