# 脑空

## 📍 经络归属与精准取穴法

- 脑空穴归属**足少阳胆经**，位于后头部。此穴是足少阳胆经与阳维脉的交会穴，倪师在讲义中特别点出“脑空”这个穴名本身就说明了它的功能——专治脑部空空荡荡、眩晕不止的毛病。在五输穴体系中，脑空不属于井荥输经合任何一类，但它是胆经在脑后的重要关窍，与风池、肩井一气贯通，倪师称之为“胆经在后脑的三大门户”之一。

- **倪师动态取穴法**：先找风池。风池在脑空的正下方，倪师讲“你手摸到后脑勺，两边各有一个凹陷，那就是风池”。从风池往上，沿着胆经的线往上推，推到一个骨头缝——你摸到枕骨外粗隆的下缘，往外侧走，会摸到一个明显的凹窝，这个凹窝就是脑空。倪师原话：“你从风池往上摸，摸到那个骨缝里面的小坑，一按下去病人眼睛会亮一下，或者喊一声酸，那就是脑空。”更直接的方法是用肩井定位法：先定肩井（大椎与肩峰连线中点），从肩井垂直往后脑方向画一条弧线，在枕骨下缘摸到的陷窝，与风池基本在一条水平线稍上方，就是脑空。左右各一。

- **骨度折量**：脑空在枕骨外隆凸的上缘外侧，距后正中线约2.25寸（约三横指加半指），与风池平齐或略高。倪师强调“这个穴不用死记分寸，你手一摸，那个骨缝凹窝就在那里，老祖宗不会骗你。”

- **下针深度**：倪师讲“脑空下针，**针尖要朝着风池的方向斜刺**，不要直着往里捅。平刺或斜刺五分到八分，最多一寸。你直刺进去，病人会感觉整个后脑勺发胀，那是气到了；你要是刺太深，病人会头晕加重，甚至恶心。”

- **禁针禁灸法则**：脑空**禁灸**。倪师明确讲“后脑的穴道，风池、脑空、天柱，这些地方一律不灸。你拿艾条一熏，病人马上头更晕，血压往上冲。”至于针，倪师说脑空可以针，但“不能深，不能提插太猛，得气就停，留针二十分钟足矣。”小儿囟门未闭者，脑空部位禁针。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：倪师讲脑空的气化，核心就一句话——“**引胆经之气上达脑窍，再引脑窍之浊阴下行归经**”。胆经主决断，少阳为枢，脑空是胆经在脑后的枢机转轴。当人胆气不降、痰浊上蒙清窍时，脑空这里的气就堵住了，病人表现就是眩晕、头重、眼睛发黑、耳朵嗡嗡响。倪师推演：脑空一针下去，**开的是后脑的天窗**，让清阳能上来，浊阴能下去。所以它治眩晕不是“止晕”，而是让气机重新转起来——晕自然就停了。

- **子母补泻心法**：胆经属木，木生火，胆经的母穴是侠溪（荥水穴，水生木），子穴是阳辅（经火穴，木生火）。脑空本身不是子母穴，但倪师讲“脑空用补，就是引侠溪之气往上灌；脑空用泻，就是引阳辅之气往下泄。”具体操作：**虚证（气血不足之眩晕、耳鸣）用补法**——针尖朝上，顺经而刺，配合捻转补法，意念引气上行入脑；**实证（肝阳上亢、痰浊蒙窍之头痛眩晕）用泻法**——针尖朝下，逆经而刺，配合捻转泻法，引浊气下行。倪师原话：“你心里要有一幅图，气从脚上来，从脑空出去，再从前面下来入胃经。这个圈转起来，人就不晕了。”

- **五行生克**：胆木克脾土。脑空若见脾土湿浊上泛（晕起来恶心、吐痰涎），倪师会在脑空用泻法后，**加针足三里、阴陵泉**，这是“泻胆经以松土，补脾胃以固本”。若见肾水不能涵木（头晕伴腰酸、耳鸣如蝉），则在脑空用补法后，**加针太溪、肾俞**，这是“滋水涵木，引气归元”。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **眩晕**：倪师讲“脑空治晕，不管你是美尼尔氏、还是高血压、还是贫血引起的，脑空一针下去，晕就定住了。”尤其对**旋转性眩晕**（天旋地转、不能睁眼）效果最快。
  - **后头痛**：胆经后头痛，痛在枕骨、牵连到脖子和肩膀，脑空是首选。
  - **耳鸣耳聋**：少阳经入耳中，脑空能引胆气通耳窍，对**突发性耳鸣**（尤其是生气后加重的）特效。
  - **颈项强痛**：脑空配风池、肩井，治落枕、颈椎病引起的后脑胀痛。
  - **癫痫**：倪师在癫狂痫章节提到，脑空配筋缩、身柱，能安脑定痫。

- **倪师经典对穴与排针组合**：
  - **脑空 + 风池 + 肩井**：治一切后脑、颈项、肩背之痛。倪师排针顺序：先风池，再脑空，最后肩井，这叫“从上往下通胆经”。
  - **脑空 + 中脘 + 足三里 + 公孙**：治晕起来恶心呕吐的。中脘降胃气，足三里补中土，公孙通冲脉，脑空开脑窍，四穴合用，标本兼治。
  - **脑空 + 太冲 + 合谷**：治肝阳上亢之头痛眩晕。太冲泻肝，合谷开四关，脑空引气下行，倪师讲“这叫釜底抽薪”。
  - **脑空 + 听宫 + 翳风**：治耳鸣耳聋。听宫开耳窍，翳风通少阳，脑空调气机。
  - **脑空 + 百会 + 涌泉**：治失眠、健忘、脑鸣。百会升清，涌泉降浊，脑空在中转站调枢机。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲后脑穴位时，原话实录：“**脑空这个穴，你摸到那个骨缝，针一下去，病人眼睛当场就亮了。为什么？因为气通了。** 很多眩晕的病人，针完脑空，从床上坐起来，第一句话就是‘哎呀，不晕了’。你说神不神？一点都不神，气通了而已。”

- 倪师手下针感体会：“**针脑空，你得气的感觉是什么？病人说像有一股凉水从后脑勺往下淌，或者像有人拿手指头在他后脑勺弹了一下。** 你要是针下去病人没感觉，那就是没扎到气，你得稍微提插一下，但别猛，一提一放，气就来了。气一到，你把针往下一按，让它顺着胆经往下走，这叫‘按针引气’。”

- 倪师医案故事：倪师在课堂上讲过一例。一个五十多岁的太太，眩晕十几年，西医说是美尼尔氏症，每次发作天旋地转，连床都下不了。倪师看她舌苔白腻，脉弦滑，这是痰浊上蒙。倪师取**脑空（泻法）、风池、中脘、足三里、公孙**。针完脑空，病人说“后脑好像开了一扇窗，凉风进来了”。留针二十分钟，起针后病人自己坐起来，走了几步，说“不晕了，十几年没这么清爽过”。倪师说：“**你以为是脑空治好了她？不是。是脑空把胆经的枢纽打开了，痰浊往下走，清阳往上走，身体自己把自己治好了。** 针灸不过是帮它一把。”

- 倪师针灸秘要：倪师特别强调，**脑空配风池时，先针风池，得气后再针脑空，这叫“开门引路”**。如果反过来先针脑空，气容易堵在后脑下不来。另外，脑空留针时，倪师会让病人**眼睛闭着，意念放在后脑勺，想象那里有一团乌云慢慢散开**。这是“以意引气”，针药达不到的地方，意念能到。
