# 足三里二

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经，本穴为胃经**合穴**，五行属**土**。胃经本身属土，足三里为土经之土穴，是**本穴**（属性与经同），也是倪师反复强调的「**胃经大穴**」。
- **五输穴定位**：足阳明胃经五输依次为——厉兑（井金）、内庭（荥水）、陷谷（输木）、解溪（经火）、**足三里（合土）**。合穴主治「逆气而泄」，即气血在此汇聚入内脏，能降逆、能止泻、能通调整条胃经。
- **回阳九针之一**：倪师在《人纪》中明言，足三里属于**回阳九针**（哑门、劳宫、三阴交、涌泉、太溪、中脘、环跳、足三里、合谷），是救逆起死的重要穴位。
- **倪师动态取穴法（骨度折量 + 摸骨找穴）**：
  - 先找**犊鼻**（膝盖外侧凹陷，膝眼），再找**外膝眼**直下。
  - 倪师的标准手法：从外膝眼往下量**三寸**（用自己的手指同身寸，四指并拢为三寸），然后用**拇指从胫骨前缘往外推**，推到胫骨外侧肌肉隆起处，指下会摸到一个**凹陷**——这就是足三里。
  - 倪师口诀大白话：「膝盖眼往下三寸，胫骨往外一推，那个坑就是足三里。」摸的时候要**沿着胫骨外缘往外侧推**，推到肌肉缝隙处，穴位就在胫骨前肌与胫骨之间的凹陷中。
  - **下针深度**：倪师讲，针足三里要**直刺**，针入**一寸到一寸半**（体壮者可至两寸），针感要往下走，最好能引到**脚背或脚趾**，这叫「气至病所」。
  - **禁针禁灸**：足三里**可针可灸**，是保健灸第一要穴。倪师特别强调，**无病之人灸足三里，可保长寿**，但若**胃热炽盛、口臭便秘**者，不宜重灸，宜针泻。另外，**孕妇**不宜深刺足三里，因其能引气下行，恐动胎气。


## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：
  - 足三里为胃经合穴，胃经多气多血，气血在此**汇聚如海**。倪师讲，胃经的气血从头面下来，经过胸腹，到腿上，在足三里这里「合」住，然后继续往下走到脚趾。所以足三里是**胃气的中转站**。
  - 倪师推演的核心机理：**「胃主受纳，脾主运化，足三里能健脾和胃、升清降浊。」** 胃气以降为顺，足三里能降胃气上逆（打嗝、呕吐、反酸）；脾气以升为健，足三里又能助脾升提（胃下垂、脱肛、子宫脱垂）。
  - **引火归元**：倪师讲，有些人虚火上炎，牙痛、面肿、口疮，看似热证，实为胃中虚火。针足三里（补法），能引火下行，归入胃土，火一降，诸症自消。
  - **健脾行水**：胃经与脾经相表里，足三里能通调脾胃，脾主水湿运化，故足三里能治**水肿、腹水、小便不利**。倪师常讲，肚脐以下的水病，足三里配三阴交、阴陵泉，效果如神。
  - **升提中气**：倪师讲，中气不足则脏器下垂。足三里补法，能升提中气，配合百会灸，治**胃下垂、子宫脱垂、脱肛**，效果立竿见影。
- **子母补泻与五行生克运用心法**：
  - 胃经属**土**，足三里为**土穴**，是本穴。按五行生克：**土生金，土克水**。
  - **虚则补其母**：胃经之母为**火**（火生土），胃经的经穴**解溪**属火，故胃虚（胃寒、胃动力不足、消化不良）可补解溪，也可直接补足三里（本穴补法）。
  - **实则泻其子**：胃经之子为**金**（土生金），胃经的井穴**厉兑**属金，故胃实（胃热、便秘、口臭）可泻厉兑，也可泻足三里（本穴泻法）。
  - 倪师心法：**「足三里是胃经的本穴，不管虚实，针下去都能调。虚则补之，实则泻之，捻针方向不同，补泻就在其中。」** 补法：顺经捻转（往下），或呼气时进针；泻法：逆经捻转（往上），或吸气时进针。


## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **急症救逆**：回阳九针之一，治**中风脱证、休克、晕厥**，配百会、涌泉、人中，能回阳救逆。
  - **胃病第一穴**：**胃痛、胃胀、反酸、打嗝、呕吐、消化不良、食欲不振**，无论寒热虚实，足三里皆可调。
  - **慢性病调理**：**虚劳羸瘦、贫血、免疫力低下、久病体虚**，灸足三里能大补元气，倪师称其为「**长寿穴**」。
  - **妇科特效**：**痛经、月经不调、子宫脱垂、产后虚弱**，配三阴交、关元，效果显著。
  - **儿科特效**：**小儿疳积、消化不良、发育迟缓**，灸足三里（温和灸）能健脾开胃。
  - **痛症特效**：**膝关节痛、下肢痿痹、坐骨神经痛**，足三里能通经活络，配阳陵泉、环跳。
  - **水病**：**水肿、腹水、小便不利**，配阴陵泉、三阴交、水分。
- **倪师经典对穴与排针组合**：
  - **足三里 + 三阴交**：倪师常用组合，一阳一阴，一表一里，调脾胃、补气血、通经络，治一切虚劳、妇科、消化病。
  - **足三里 + 中脘**：胃的募穴配胃的合穴，治一切胃病，针到病除。
  - **足三里 + 内关 + 公孙**：倪师讲「公孙内关胃心胸」，再加足三里，治**胃、心、胸**一切病症，如胃痛、胸闷、心悸。
  - **足三里 + 合谷 + 太冲**：开四关（合谷太冲）加足三里，能通调全身气血，治**中风后遗症、痹症、痛症**。
  - **足三里 + 百会（灸）**：升提中气，治**胃下垂、子宫脱垂、脱肛**。
  - **足三里 + 阴陵泉 + 水分**：健脾行水，治**水肿、腹水**。


## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原话金句**：
  - 「足三里是胃经的合穴，合穴就是气血汇合的地方，像河流入海一样。你针下去，胃气就通了。」
  - 「无病灸足三里，胜吃老母鸡。这是保健第一穴，日本人称它『长寿灸』。」
  - 「足三里能升能降，胃下垂的补它，胃气上逆的泻它，一个穴道双向调节，这就是中医的智慧。」
  - 「回阳九针里面，足三里是少不了的。人昏死过去，针足三里、涌泉、人中，气就回来了。」
- **实战手下针感体会**：
  - 倪师讲，针足三里，**针感要往下走**，病人会感觉一股酸胀从膝盖往下窜到脚背，甚至到脚趾。如果针感只停在局部，说明经气不通，要**捻针导气**，或加**提插**手法，让气往下走。
  - 补法：**顺经捻转，往下**，病人感觉温热、舒服；泻法：**逆经捻转，往上**，病人感觉酸胀、发散。
- **医案故事**：
  - 倪师讲过一个案例：一位**胃下垂**的病人，西医说要开刀，倪师用**足三里（补法） + 百会（灸） + 中脘**，针了三次，病人胃就提上来了，食欲大开。
  - 又讲：一位**中风脱证**的老人，昏迷不醒，四肢冰冷，倪师急针**足三里、涌泉、人中、百会**，用**烧山火**手法，病人慢慢回温，眼睛睁开了。
  - 还有：一位**小儿疳积**，面黄肌瘦，肚子鼓大，倪师用**足三里（温和灸） + 四缝（点刺）**，几次就好了，小孩开始吃饭，脸色也红润了。
- **针灸秘要**：
  - 倪师强调，**足三里是胃经的本穴，不管什么胃病，先针足三里，再配其他穴，效果加倍**。
  - 灸足三里，**要用陈艾**，温和灸，每次**15-20分钟**，灸到皮肤微微发红，不要起泡。
  - 针足三里，**要得气**，得气后根据虚实补泻，**虚证用补法，实证用泻法**，不要死板。
  - 倪师最后叮嘱：**「足三里是老天爷给我们的长寿穴，每天灸一灸，健康又长寿。」**
