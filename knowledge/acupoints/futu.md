# 扶突

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：扶突穴归属**手阳明大肠经**。大肠经与肺经相表里，肺主气、司呼吸，大肠主传导、排浊。扶突乃大肠经在颈部的**天窗穴**，是承接肺气、通利咽喉、消散颈项结滞的**气化出入之关窍**。在五行生克体系中，大肠经属**金**，扶突虽非井荥输经合之特定穴，但居于“天部”（颈项为天气所过），与天气相通，主治**气分之疾**。倪师常言：**“扶突者，扶助阳气以突出重围也”**——此穴能令郁闭于颈项的气机重新流通，犹如打开天窗，引清阳上达，浊阴下降。

- **倪师动态取穴与骨度折量法**：
  1. **摸骨定位**：先令患者**微微仰头**，找到喉结（甲状软骨）与胸锁乳突肌。倪师强调：**“先摸到人迎脉（喉结旁开1.5寸，颈动脉搏动处），再往外摸到胸锁乳突肌的前缘——这就是扶突。”** 具体操作：从人迎穴向外平移至胸锁乳突肌前缘，**与喉结上缘平齐**处即是穴。
  2. **骨度折量**：以喉结为基准，**喉结上缘水平线与胸锁乳突肌前缘交点**，即为扶突。倪师说：**“你摸到病人吞咽时这块肌肉（胸锁乳突肌）一鼓一鼓的，前缘就是扶突，后缘就是天窗。”**
  3. **下针深度与手法**：**直刺0.5—0.8寸**，针尖略向内下方。倪师警告：**“此穴下针不可深，超过一寸就危险，因为底下是肺尖和颈动脉窦。”** 进针后得气即止，**不做大幅度提插捻转**，以轻微雀啄法引气至咽喉部为度。
  4. **禁针禁灸法则**：倪师明确：**“扶突可以针，但禁灸——灸了火气上冲，病人会喉咙肿痛、咳血。”** 凡颈动脉搏动明显处、甲状腺肿大者，**禁针**。孕妇慎用。

## ⚡ 倪师经穴气化与破局心法

- **经穴气化与开阖机理**：倪师推演扶突的气化核心在于**“开天窗，利咽喉，降逆气”**。大肠经之气从手走头，至扶突处已是“天气”范畴，通过此穴与肺经的天府、云门形成**气机循环**。扶突如**颈部的气闸**，当外邪束肺、痰气交阻、肝火上逆时，此穴能**开郁散结、引火下行**。倪师说：**“咽痛、失音、暴喑，都是天气闭塞，扶突一开，肺气就下来了。”** 其机理类似**“提壶揭盖”**——上窍一通，下窍自利；又似**“开鬼门”**——颈项之气一开，胸膈痰浊自降。

- **子母补泻与五行生克运用心法**：
  - 大肠经属**金**，扶突虽无明确母子穴关系，但倪师常从**表里经五行**入手：肺经属金，大肠亦属金；金生水（肾），金克木（肝）。
  - **虚则补其母**：若肺气虚、咽中气短不足以息，取扶突配合**太渊（肺经母穴，属土）**——土生金，补土以实金。
  - **实则泻其子**：若痰热壅盛、咽喉肿痛，取扶突配合**二间（大肠经子穴，属水）**——金生水，泻水以清金。
  - 倪师心法口诀：**“扶突配太渊，气足咽自安；扶突配二间，热退喉不干。”**

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **急症救逆**：**暴喑（突然失音）**、**喉痹（急性咽喉肿痛）**、**痰厥（痰堵咽喉、呼吸困难）**。倪师说：**“急性的喉咙堵住，针扶突，气就通了，比喉镜还快。”**
  2. **慢性病调理**：**梅核气（咽中如有物梗）**、**慢性咽炎**、**甲状腺结节（瘿瘤）**、**颈项淋巴结肿大（瘰疬）**。
  3. **妇科/儿科特效**：**小儿急惊风（痰热闭窍）**、**妊娠恶阻（肝胃气逆）**。
  4. **痛症特效**：**颈项强痛（落枕、颈椎病）**、**肩臂放射痛**。

- **倪师经典对穴与排针组合**：
  - **扶突 + 合谷 + 太冲（开四关）**：治咽喉肿痛兼有肝郁化火者。倪师说：**“合谷太冲开四关，再取扶突，上下气机一打通，咽痛如失。”**
  - **扶突 + 列缺 + 照海**：治慢性咽炎、梅核气。列缺通任脉，照海通阴跷，扶突开天气——**三穴合治“喉中如有炙脔”**。
  - **扶突 + 天突 + 膻中**：治痰厥、暴喑。倪师称此为**“通天彻地三针”**——天突降逆，膻中理气，扶突开窗。
  - **扶突 + 少商（放血）**：治急性喉痹。少商点刺出血，扶突下针，**“一开一泄，喉火自灭”**。
  - **扶突 + 足三里 + 三阴交**：治甲状腺结节、瘿瘤。足三里健脾化痰，三阴交调肝脾肾，扶突开颈项气结。

## 🗣️ 倪师讲义实录与针灸秘要

- **原汁原味逐字稿金句**：
  > “扶突这个穴，在大肠经上面。你摸到人迎脉，往外一点点，胸锁乳突肌的前面，就是扶突。下针的时候，病人仰头，你用手把肌肉拨开，针直接下去，五分就到。**气一到，病人会说喉咙松了**。”
  >
  > “喉咙痛、失音、突然说不出话，针扶突，再配合少商放血，效果立竿见影。为什么？**大肠经的阳气在这里突出来，把堵住的天窗打开，肺气就通了啊**。”
  >
  > “**扶突禁灸**！你拿艾条一灸，火气往上冲，病人当场喉咙肿起来，咳血都有可能。记住，颈部的穴道，除了天突可以稍微灸一下，其他绝大多数禁灸。”

- **实战手下针感体会**：
  - 倪师弟子问：“扶突下针什么感觉？”师答：**“病人会觉得喉咙里有一股凉凉的气往下走，或者突然想咳嗽，那是气通了。如果病人说脖子酸胀，那是针尖偏了，碰到肌肉了，要退针再进。”**
  - **针感传导**：得气后，气感可向**咽喉部、耳后、肩井**放射。倪师说：**“最好的针感是病人吞口水，说‘好像有什么东西松开了’。”**

- **医案故事**：
  > “有个病人，感冒后突然失音，三天说不出话。西医药说什么声带麻痹。我一看，脉浮紧，舌苔白，这是风寒闭肺。**针扶突、合谷、列缺，留针二十分钟**。起针后，病人当场说‘谢谢’——声音虽然沙哑，但能出声了。第二天再针一次，全好。”
  >
  > “还有一个太太，喉咙里总觉得有东西堵着，吞不下吐不出，西医叫‘癔球症’。我取**扶突、内关、公孙**。内关公孙通冲脉，扶突开天气。针了三次，她说那团东西没了。这就是**气机一开，痰浊自散**。”
