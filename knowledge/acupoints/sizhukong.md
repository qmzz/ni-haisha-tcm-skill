# 丝竹空

## 📍 经络归属与精准取穴法

丝竹空，隶属**手少阳三焦经**。三焦经的循行，起于无名指端关冲穴，沿着手臂外侧一路向上，过肘、上肩、入缺盆，然后散布于膻中，联络心包，下膈，遍属三焦。它的支脉从膻中上出缺盆，上项，挟耳后，直上出耳上角——丝竹空就在这条支脉的末端区域，位于**眉梢外侧凹陷处**。

丝竹空不是五输穴，不是原穴，不是络穴，不是郄穴，不是募穴，不是背俞穴，不是八会穴。它是**手少阳三焦经的最后一个穴位**，也是三焦经在头面部的收尾之处。三焦经的气血走到这里，已经接近末端，气血细弱如丝，穴在眉梢骨缝之空隙处，故名“丝竹空”。

倪师在讲三焦经的时候特别提到：三焦经的穴道，很多都在耳朵周围、眉毛周围、眼睛周围，这些地方是**少阳枢机**出入的门户。丝竹空就在眉毛尾巴上，是少阳之气从目系向外疏泄的窗口。

**怎么摸骨找穴？**

倪师讲得很直白：你顺着眉毛往外摸，摸到眉毛尽头，骨头有个小凹陷，手指按下去有酸胀感，那就是丝竹空。不用什么复杂的折量，眉毛你总找得到吧？眉毛长到哪儿，穴就在哪儿尾端。有些人眉毛稀，你别把眉毛剃了去找，就按解剖位置——眼眶上缘外侧，眉梢的凹陷中。

**下针深度**：倪师说，丝竹空这个地方，**禁灸**，但可以**平刺或斜刺**。针尖向后沿皮刺，进针**三分到五分**。不要直刺，直刺容易扎到眼眶骨或者损伤眼球周围组织。倪师的原话是“针下去，沿着皮往后面透，不要往眼睛方向扎”。

**禁灸**：面部的穴位，尤其是眼睛周围的，一般不灸。丝竹空靠近眼球，艾火的烟和热对眼睛不好。倪师强调，针灸针灸，针和灸是两回事，该禁灸的地方你就老老实实禁灸，别逞能。

另外，倪师在讲三焦经的时候提过一句：**丝竹空透率谷**，这是治疗偏头痛的一个透刺法。从丝竹空进针，沿着皮下往后透到率谷穴，一针透两穴，少阳经的气机就打通了。

## ⚡ 倪师经穴气化与破局心法

倪师讲三焦经的气化，核心就一句话：**三焦者，决渎之官，水道出焉**。三焦是水液运行的大通道，也是元气升降的枢纽。丝竹空作为三焦经在头面末端的穴位，它的气化机理，要从“**少阳枢机**”和“**水道末端**”两个角度来理解。

先说**少阳枢机**。少阳介于太阳和阳明之间，是人体气机表里出入的枢轴。三焦经属于少阳，丝竹空在眉梢，眉毛在中医里是**目系**的一部分，目系连肝，肝与胆互为表里，胆经也是少阳。所以丝竹空这个位置，是少阳之气在头面开阖的“窗户”。倪师说，眼睛周围的穴位，很多都是在**开窍**，把郁闭在头面的气机打开。

再说**水道末端**。三焦通调水道，水液代谢的终点在头面，表现为眼泪、汗液、鼻腔分泌等。丝竹空能治**目赤肿痛、眼睑瞤动、流泪**，就是因为它能调节三焦水液在眼部的输布。倪师讲，水液停在眼睛周围，该走的不走，该散的不散，你就找三焦经，找丝竹空。

**子母补泻与五行生克**：三焦经的五行属性是**相火**。丝竹空不是五输穴，没有直接的子母补泻关系。但是倪师在讲针灸的时候反复强调一个原则：**虚则补其母，实则泻其子**，这个原则要用在**经络整体**上。三焦经虚，你要找它的母经——**肝经**（木生火），或者在三焦经里找母穴——**中渚穴**（输穴，属木）。三焦经实，你要找它的子经——**脾经**（火生土），或者在三焦经里找子穴——**天井穴**（合穴，属土）。丝竹空本身不补不泻，它是个**局部开窍穴**，配合子母补泻的远端取穴，才能发挥最大效果。

倪师的破局心法：**上病下取，左病右取**。丝竹空治眼病、偏头痛，你不能只盯着丝竹空扎。倪师会配上**中渚**或者**临泣**，或者在对侧的**合谷**、**太冲**上做文章。头面的病，往往是脏腑气机失调在局部的表现，你光扎局部，那是“头痛医头”，倪师不干这种事。

## 🎯 临床主治与配穴组合手印

丝竹空的**核心主治**，倪师归纳得很清楚：

**第一，偏头痛。** 少阳经循行于头侧，丝竹空在眉梢，是少阳经气最容易郁堵的地方。偏头痛发作时，眉梢、太阳穴、耳后一线胀痛，丝竹空透率谷，立刻缓解。倪师说，偏头痛你扎丝竹空，针尖往后透，一针下去，患者会觉得一股气往后窜，痛就去掉大半。

**第二，目赤肿痛、眼睑瞤动、迎风流泪。** 肝开窍于目，少阳胆经连目系，三焦经也到目系周围。丝竹空能清少阳郁热，通眼部气血。倪师治眼病，经常在**攒竹、丝竹空、太阳、瞳子髎**这一圈做文章，配合远端的**光明穴**（胆经络穴，治眼病特效）。

**第三，眼睑下垂、面瘫。** 面瘫的时候，眼睛闭不上，眉毛抬不起来，丝竹空配上**阳白、攒竹、四白、地仓、颊车**，再加**合谷**（面口合谷收），这是倪师治面瘫的常规排针。

**第四，牙痛。** 上牙痛属大肠经，下牙痛属胃经，但少阳经也过牙床。丝竹空治牙痛，尤其是偏侧牙痛连带头痛的，配上**下关、颊车、合谷**，效果很好。

**倪师经典对穴组合**：

- **丝竹空 + 太阳 + 率谷**：治偏头痛。太阳直刺或点刺放血，丝竹空透率谷，一气呵成。
- **丝竹空 + 攒竹 + 瞳子髎 + 光明**：治眼病。局部三穴加远端光明，少阳气血一升一降。
- **丝竹空 + 合谷 + 太冲**：开四关，治头面一切痛症。合谷主气，太冲主血，丝竹空引气至头面，气血一开，痛就止。
- **丝竹空 + 阳白 + 四白 + 地仓 + 颊车**：治面瘫。这是面部排针，丝竹空管眉梢，阳白管额纹，四白管眼下，地仓颊车管口角，各司其职。

倪师特别提醒：**丝竹空禁灸**，所以你配穴的时候，别在这个穴上做艾灸。要温通，你在远端做，比如足三里、关元，别在脸上烧。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲三焦经的时候，讲到丝竹空，原话大致是这样的：

> “丝竹空在哪里？眉毛尾巴这里。你顺着眉毛摸，摸到尽头，有个凹洞，那就是丝竹空。针怎么下？**沿着皮往后刺，不要直刺**。直刺扎到骨头，患者疼得跳起来。你平刺，针尖往后，透到率谷，偏头痛当场就好。**禁灸**，脸上不要灸，眼睛周围的穴道，你一灸，眼睛就红了，眼泪直流，那不是治病，那是找病。”

倪师还讲过一个医案：

> “有个病人偏头痛十几年，左边眉毛尾巴痛，太阳穴痛，耳朵后面痛。我一看，少阳经嘛。我针丝竹空透率谷，对侧合谷，脚上扎侠溪、足临泣。针下去，病人说，哎，一股气从眉毛后面往后跑，跑到耳朵后面，痛就散了。留针二十分钟，起针，病人说十几年没这么轻松过。你说神不神？不神，**经络通了嘛**。”

倪师反复强调手下针感：

> “你针丝竹空，针尖往后透的时候，手指要感觉到针下**滑利**，像在皮下穿行，没有阻力。如果感觉涩，那是气滞，你要稍微提插一下，把气引过来。患者会有**酸、胀、麻**的感觉，有时候会往太阳穴放射，有时候往耳后放射，这就是**得气**。得气了你再留针，不要乱动。”

倪师的针灸秘要，归根结底一句话：**穴位是死的，气是活的**。丝竹空在眉梢，但你用它的时候，心里想的是少阳经的枢机，是三焦的水道，是头面气血的开阖。你心里有这个大局，针下去才有神。
