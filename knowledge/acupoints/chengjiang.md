# 承浆穴 (RN24)

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：承浆穴归属于**任脉**，是任脉与足阳明胃经的**交会穴**。在五输穴体系中，任脉不设井荥输经合，承浆为任脉末穴，位居下唇之下、颏唇沟正中。倪师在《人纪·针灸篇》中将任脉穴位的讲解从中极、关元一路循行向上，至廉泉、承浆收尾，承浆正是任脉在头面部的最后一个门户。

- **倪师动态取穴与骨度折量法**：倪师讲承浆取穴，一句话就讲透了——**“下嘴唇拉开来，唇下正中间那个凹窝，就是承浆。”** 大白话就是：你微微张嘴，下唇与下巴之间自然形成一道横沟，沟的正中央、按下去有个小坑的地方，就是承浆穴。倪师强调不要死记“颏唇沟正中”这种术语，而是用手去摸——嘴巴一张，沟一现，坑一按，穴就定了。

  关于针刺深度，倪师在讲义中说承浆是**“针三分”**，也就是针入0.3寸左右，浅刺即可。针法是**向上斜刺**，针尖朝向嘴唇方向，不宜向内深刺。承浆一般不灸，古法有禁灸之说，倪师在讲头面部穴位时反复提醒：**头面诸穴，多针少灸，承浆尤甚。** 因为承浆位于口唇附近，灸疮容易影响饮食和面容，所以以针刺为主。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：承浆的“承”是承接、承受，“浆”是水浆、津液。倪师讲这个穴名本身就点出了它的气化功能——**承接口中津液，主司口唇开阖与涎液收摄。** 任脉为“阴脉之海”，上行至咽喉、环唇、入目，承浆正处于任脉与胃经交会之处。胃经循行也环口绕唇，所以承浆是任脉阴津与胃经气血在口唇部位的交汇点。

  倪师推演承浆的气机：**口为脾窍，唇为脾之外候，涎为脾之液。** 承浆能收敛口涎、通利口齿，靠的正是任脉总摄一身阴液、胃经多气多血的本钱。他在讲中风、口眼歪斜时特别提到，承浆这一带的气机如果通畅，口唇肌肉就能收放自如；如果气机在这里卡住了，就会出现流涎不止、口唇麻木、说话漏风。所以承浆的破局心法，就在一个“**收**”字——收摄津液、收束口唇、收敛阳明经气。

- **子母补泻与五行生克运用心法**：承浆不是五输穴，无法直接套用“虚则补其母、实则泻其子”的井荥输经合补泻。但倪师在讲任脉与胃经交会穴时，用的是**经脉层面的母子关系**来推演——任脉属阴、主血、主静，胃经属阳、主气、主动，两者一阴一阳、一静一动，在承浆处交会，本身就是一种天然的阴阳相济。临床上，如果口唇松弛、流涎属**虚**，就取承浆配合足三里（胃经合穴，补胃气以充养口唇）；如果口舌生疮、牙龈肿痛属**实**，就取承浆配合内庭（胃经荥穴，泻胃火以清口齿）。倪师的心法是：**不执泥于穴本身的五行，而看穴所在经脉与交会经脉的五行气血盛衰，以经脉之子母定补泻。**

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **口眼歪斜、面部中风**：这是承浆最经典的主治。倪师在讲面部中风时，地仓透颊车、承浆配人中是常配的组合。
  2. **流涎不止、口唇不收**：无论小儿流涎还是中风后遗流涎，承浆都有收摄之效。
  3. **口舌生疮、牙龈肿痛、口腔溃疡**：承浆能清口齿之热，引胃火下行。
  4. **暴喑不能言、口噤不开**：承浆近舌根，能通利舌窍。
  5. **面肿、唇肿、口周疱疹**：承浆通调口周气血，消肿散结。

- **倪师经典对穴与排针组合**：
  - **承浆配人中（水沟）**：一上一下，一督一任，交通任督，专治口眼歪斜、口噤不开。倪师说这是“**前后对刺，阴阳交泰**”的手法。
  - **承浆配地仓、颊车**：地仓透颊车治面瘫，承浆收口唇，三穴一组，是面部中风排针的常用组合。
  - **承浆配廉泉**：两穴相距不远，一在唇下，一在舌上，同属任脉，合用能通利舌咽，治舌强不语、吞咽困难。
  - **承浆配合谷**：合谷是面口合谷收的“总开关”，承浆是口唇局部的“分开关”，一远一近，远近配穴，治一切口面部疾患。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲到任脉承浆穴时，原文实录如下：

> **“承浆穴呢，在下嘴唇的下方，嘴巴一张开，这边有个沟，沟的正中间就是承浆。针呢，针三分，向上斜刺。承浆穴呢，你们看它靠近嘴巴，所以它能治口唇的病、口水的病。有的人嘴巴闭不紧，一直在流口水，承浆可以收。面部中风，嘴巴歪到一边去，承浆配人中，一针下去，嘴巴就正回来了。你不要想着承浆是什么大穴，它就在嘴边上，就近取穴，可是它管的事不少。头面上的穴道，大部分都是针，很少灸，承浆也是一样，你不要去灸它，灸了嘴巴起泡，病人怎么吃饭？所以记住，针三分，向上斜，不灸。”**

倪师在讲到面部中风医案时，还提到一个临床体会：给面瘫患者针承浆时，**针一下去，患者常常会感觉下唇一紧、口水一收**，这就是“承浆”名字的来由——它真的能承接住口里的浆液。他还说，有些小孩子常年流涎，口水把下巴都沤红了，针承浆一两次，口水就明显少了，这不是承浆直接“止涎”，而是它把任脉和胃经在口唇交会处的气机重新接通了，气能摄津，涎自然就收住了。
