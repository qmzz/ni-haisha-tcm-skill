# 太乙二

## 📍 经络归属与精准取穴法

- **所属经络与五输穴/特定穴属性**：太乙二归属**足阳明胃经**。在《针灸大成》与倪师人纪讲义中，太乙二并非五输穴（井荥输经合）体系内的穴位，而是胃经在**腹部（上腹部）** 循行路线上的一个重要腧穴。其定位与**滑肉门**、**天枢**同处于胃经腹段的气街地带。足阳明胃经属**土**，本穴虽无特定穴之五行属性，但因其位居中焦腹地，与**脾胃气机升降**直接相关，倪师常将其纳入“中焦气化”体系中使用，以调理脾胃、通降腑气为要。

- **倪师动态取穴与骨度折量法**：倪师讲腹部穴位，一贯强调“**先找天枢，再定上下**”。太乙二在天枢穴**上二寸**，滑肉门**下一寸**，横开脐中**旁开二寸**。实际操作时，倪师会先让患者**平躺，松腹**，用指腹从**肚脐中心**向外摸到腹直肌外缘（旁开二寸），再以**神阙到中脘**的距离（八寸）折量，从**天枢（脐旁二寸）向上推二寸**即是太乙二。**下针深度**：倪师讲腹部穴一般**针五分到一寸**，视患者胖瘦而定，胖人可稍深，瘦人宜浅。**禁针禁灸法则**：腹部穴位**不宜深刺**，以防伤及内脏；**孕妇禁针**，尤其腹部穴；**灸法**可温和灸，但倪师提醒腹部灸法要防烫伤，且**热证、实热证**不宜灸。

## ⚡ 倪师经穴气化与破局心法

- **倪师如何推演此穴的气血流注与开阖机理**：倪师讲胃经腹部穴位时，常以“**中焦如沤**”作比喻。太乙二位居中焦，是胃气**升降出入**的枢纽地带之一。倪师认为，此穴的气化机理在于**健脾行水、通降腑气**。胃经多气多血，太乙二能助**胃气下行**，使水谷精微得以运化，糟粕得以传导。若中焦气机壅滞，出现**腹胀、痞满、食不化**，倪师会取太乙二以**开中焦之闭**，引气下行。此外，倪师也将其用于**升提中气**的配伍中，与**百会、足三里**同用，治**胃下垂、脱肛**等中气下陷之证。

- **子母补泻与五行生克运用心法**：足阳明胃经属**土**，其**母穴为解溪（火穴）**，**子穴为厉兑（金穴）**。太乙二本身非五输穴，故不直接参与子母补泻。但倪师在临床上，若遇**胃虚证**（如胃纳差、胃寒），会以太乙二配合**解溪（补母）** 或**足三里（合土）** 同用，以**补土生金**或**温养胃气**；若遇**胃实证**（如胃热、便秘、腹胀），则配**厉兑（泻子）** 或**内庭（荥水）** 以**泻胃火、通腑实**。倪师强调，太乙二在此体系中是**辅助气机流转**的穴位，而非主力补泻穴，其价值在于**调和上下、疏通中焦**。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **急症救逆**：倪师用太乙二治**急性胃痛、胃痉挛**，配**梁丘、足三里**，针后痛减。
  - **慢性病调理**：**慢性胃炎、胃溃疡、消化不良、腹胀**，太乙二配**中脘、足三里、内关**，长期调理。
  - **妇科/儿科**：**小儿疳积、食欲不振**，太乙二配**四缝、足三里**；**妇女经行腹胀**，配**三阴交、天枢**。
  - **痛症特效**：**腹痛、绕脐痛**，太乙二配**天枢、气海**，针后痛止。

- **倪师经典对穴与排针组合**：
  - **太乙二 + 天枢 + 足三里**：治**一切腹胀、消化不良**，倪师称此为“**通降中焦三针**”。
  - **太乙二 + 中脘 + 内关 + 公孙**：治**胃心胸之疾**，如**胃痛、胸闷、恶心**，此为倪师常用的**八脉交会配穴法**延伸。
  - **太乙二 + 关元 + 三阴交**：治**妇科虚寒性腹痛、月经不调**，温针或灸法并用。
  - **太乙二 + 百会 + 足三里**：治**胃下垂、脱肛**，升提中气，倪师强调**百会必针**，太乙二辅助升提。

## 🗣️ 倪师讲义实录与针灸秘要

- **视频讲义中倪师讲此穴的原汁原味逐字稿金句**：
  “太乙二这个穴，你们不要小看它。它在胃经上面，肚脐旁边上二寸。你摸到天枢，再往上推两寸，就是太乙二。**下针的时候，针下去五分，不要太深。** 这个穴，是治**腹胀、胃气不降**的。你看病人肚子胀得像鼓一样，你针太乙二、天枢、足三里，针一下去，**气就往下走**，肚子就消了。这就是**中焦的气机**被打通了。”

  “我常常讲，**胃经是多气多血的经络**，太乙二在腹部，能**行气、活血、通腑**。有些妇人月经来的时候，**肚子胀痛**，你针太乙二、三阴交，**针下去痛就减**。为什么？因为**气行则血行**，中焦一通，下焦就通了。”

- **实战手下针感体会**：
  倪师讲，针太乙二时，**针感要往下走**，病人会有**酸胀感向腹股沟或大腿方向传导**，这是**气至病所**的表现。若针后病人觉得**肠鸣蠕动**，是**气机开始运转**的好现象。若针下**空滑无感**，多为**气虚**，需配合**补法**或**加灸**。

- **医案故事**：
  倪师曾治一**中年妇人**，**腹胀如鼓，食不下，便秘**，西医查无异常。倪师取**太乙二、天枢、足三里、内关、公孙**，针后**肠鸣频频**，当晚**排气多次，腹胀大减**。倪师说：“这就是**中焦气机一通，上下就通了**。太乙二在这里，就是**开中焦之锁**的钥匙。”
