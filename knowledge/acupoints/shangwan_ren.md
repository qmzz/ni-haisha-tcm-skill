# 上脘二

## 📍 经络归属与精准取穴法

- **所属经络**：任脉。上脘为任脉与足阳明胃经、手太阳小肠经之会穴（《针灸大成》任脉考证：上脘，一名上管，巨阙下一寸，去蔽骨三寸，任脉、足阳明、手太阳之会）。
- **特定穴属性**：任脉上行于巨阙（心之募）与中脘（胃之募）之间，位居上焦与中焦交界的“关口”位置。倪师在《人纪·针灸篇》中论任脉时指出，巨阙为心募、中脘为胃募，上脘挟在两募之中，其气化功能偏向于“胃上口”与“心下发源”的交通地带——主治胃脘痛、呕吐、反胃、心胃痛等症。
- **倪师动态取穴与骨度折量法**：
  - 倪师讲任脉时反复强调“先找大穴定标尺”。让患者仰卧，先定**中脘**——在胸骨体下端（蔽骨，即鸠尾）与肚脐正中间取中脘。中脘与鸠尾之间是四寸（蔽骨下至脐共八寸，中脘居中），中脘上二寸即为**上脘**。
  - 倪师白话：你摸到胸口那块剑突骨头（蔽骨），再摸到肚脐，这条线折成八段，中脘在正中间（脐上四寸），上脘就在中脘再往上两寸（脐上五寸），离剑突骨还有三寸。不要拿尺子量，看的是患者身形比例。
  - **下针深度**：倪师讲任脉上腹段通常针**一寸到一寸半**。上脘不宜过深，因为内应胃体与肝左叶边缘，深刻有刺伤内脏之虞。《针灸大成》载“针八分，留七呼，灸五壮”。
  - **禁针禁灸法则**：上脘在《针灸大成》中有“针八分，灸五壮”之说，但倪师特别提醒——**“胃胀满、气逆冲心时，上脘可针可灸，但若肝区肿大、心下有痞块硬结者，不可深针，只宜浅刺或艾灸”** 。孕妇上腹禁针（任脉上腹诸穴皆不宜深刺）。另外，《针灸大成》引《铜人》经云上脘“针入八分，得气即泻，灸亦良”，与中脘的“针八分，灸二七壮”相呼应。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：倪师讲任脉时，把上脘、中脘、下脘三穴看作胃气上中下三段的调节闸门。上脘在胃之上口（贲门附近），其气化作用侧重于“胃气上逆的镇降”与“心胃之间的气机沟通”。当胃气上冲、恶心反胃、心下发闷时，上脘是“第一道关闸”，先在这里导气下行，气就不会冲到胸口和咽喉。倪师说：**“上脘是管胃上面那一段的，打嗝、反酸、心口痞闷，你先在上脘下针，气一降，中脘再补，胃就顺了。”** 上脘与中脘之间，一降一补，一泻一温，这是倪师调理中焦气机的“双闸法”。
- **子母补泻与五行生克运用心法**：
  - 任脉本身不归五输穴体系，但倪师在《人纪》中把**上脘—中脘—下脘**看成一个“胃腑气化的三段分工”。中脘为胃募，属土，主受纳与运化；上脘在上，主降逆与开壅。若胃气虚（土虚），取中脘补之（本穴补法），再取足三里（胃经合土，补土）、公孙（脾经络穴，通冲脉）配之，这是“虚则补其母”——补火生土（足三里属土，合于胃，为土经土穴，补土即补中）。
  - 若胃气实、气逆冲心（土实），取上脘泻之，再取内关（心包络穴）泻之，这是“实则泻其子”——心包属火，胃土之子为金？倪师临床取法是直接在上脘行泻法（捻转提插令气下行），配合内关、足三里平补平泻，以“降逆泄实”。
  - 倪师心法一句话：**“上脘管降，中脘管化，下脘管通。降用泻，化用补，通用的平。你搞清这三段，胃病没有治不好的。”**

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **急症救逆**：胃气上逆之急性呕吐、反胃、打嗝不止、心胃绞痛。倪师说急性胃痛、恶心想吐时，先针**上脘**，再针**内关**，气一转就松了。
  - **慢性调理**：慢性胃炎、胃下垂（配中脘、足三里、百会升提）、反流性食管炎（配膻中、内关、公孙）、消化不良（配中脘、天枢、足三里）。
  - **心胃同病**：心口痛、胸闷属胃气犯心者（非真心痛），上脘配巨阙（心募）、内关（心包络穴），导胃气下行则心胸自宽。
  - **妇科/儿科**：小儿吐奶（浅刺上脘配内关，不留针），妊娠恶阻（上脘浅刺配内关、足三里，手法宜轻）。
- **倪师经典对穴与排针组合**：
  - **上脘 + 中脘 + 下脘**：三脘同用，调理中焦气机之“总开关”。倪师说这是“胃腑三段调气法”。
  - **上脘 + 内关 + 公孙**：公孙通冲脉、内关通阴维脉，上脘居中镇胃，专治胃心胸之痞、痛、逆。这是倪师治“胃气冲心”的经典组合。
  - **上脘 + 巨阙 + 中脘**：三穴同在任脉上，巨阙心募、中脘胃募、上脘居中为桥梁，治心胃同病、胸脘痞满。
  - **上脘 + 足三里 + 中脘**：治慢性胃病、胃下垂、食欲不振，针后加灸中脘、足三里，补土温中。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲任脉上腹段时，原话大意：
  - **“巨阙下一寸是上脘，上脘再下一寸就是中脘？不对，中脘在脐上四寸，上脘在脐上五寸，中间差一寸……你不要死记，你就记住：剑突骨到肚脐是八寸，中脘在中间（四寸），上脘在四寸上面再一寸（五寸），下脘在四寸下面再一寸（三寸），这样三脘就出来了。”**
  - **“上脘和巨阙靠得很近，中间只差一寸。所以这两个穴常常一起用。巨阙是心募，上脘是胃的上口，心胃之间的病，你就这两个穴一起下针。心下痞、心口痛、胃反酸，针下去气就通了。”**
  - **“上脘下针，你不要太深。肚子上的针，一寸就到胃了，你在上脘扎一寸半，那是给胃做针灸。针到胃壁上，病人会有感觉——一种闷闷的胀感往旁边走。这时候你捻针，让它往下走。气往下走，呕逆就止了。”**
- **实战针感体会**：倪师讲，上脘下针后，若得气，患者常感到一股热流或胀感从上腹向中脘、下脘方向扩散。若患者本来有胃气上逆（打嗝、反酸），针后常有“气往下落”的感觉，甚至当场打一个长嗝或放屁，症状即缓。倪师说这就是“气机已转”的验证。
- **医案故事**：倪师在课堂上讲过一例——患者饭后突发胃绞痛，痛得弯腰抱腹，面色发白。倪师先针**上脘**、**中脘**，再针**内关**、**足三里**。上脘针入八分，行泻法捻转，患者当场打了一个大嗝，痛减大半。再针中脘补法、足三里补法，留针二十分钟，痛止。倪师总结：“胃痉挛、胃气上冲，上脘是第一个关，你把上脘的气一泻，胃就不往上顶了。中脘再一补，胃就安了。”
