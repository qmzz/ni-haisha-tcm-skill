# 滑肉门

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经，腹部的穴位。足阳明胃经多气多血，滑肉门正在胃经循行线上，位于上腹部。
- **特定穴属性**：滑肉门不是井荥输经合、不是原络郄、不是募俞、也不是八会穴，它是足阳明胃经的普通腧穴，但因为它所在的位置特殊——正在胃的下方、脾的上方区域——所以它的作用偏向于脾胃之间的气机转枢。从五行角度，胃属土，滑肉门在胃经上，它的功用离不开"土"这个核心，土要运化、要升降，滑肉门就是帮助土去"滑"的一个关口。
- **倪师动态取穴与骨度折量法**：
  - 滑肉门的位置，从下往上找，先找到肚脐（神阙），从肚脐正中往上量一寸，这是水分穴；水分再上一寸，是下脘；下脘再上一寸，是中脘。滑肉门不在正中线上，它在正中线旁开两寸的位置，和水分穴平齐。也就是说：**肚脐上正中一寸（水分），旁开两寸，就是滑肉门**。
  - 倪师讲取穴时反复强调，肚脐到心蔽骨（胸骨剑突）是八寸，从肚脐往上量一寸就是水分。你用同身寸——病人自己的手指去量——从肚脐往上比一寸，再往旁边比两寸，这个位置就是滑肉门。
  - **下针深度**：一般来说，针一寸到一寸半。但倪师特别提醒，腹部的穴位，尤其是中脘以下、肚脐周围的区域，下针不可过深。为什么？因为下面就是肠子，你扎太深，针尖穿到肠壁上，尤其是小肠、大肠这个区域，很容易造成肠穿孔。所以倪师说，腹部的针，你摸到腹壁的厚度，心里有个数，一般一寸到一寸半足矣，不要贪深。
  - **禁针禁灸法则**：滑肉门本身没有绝对的禁针或禁灸，但有一个大原则——**孕妇禁针**。凡是在腹部、尤其是肚脐以下的穴位，怀孕的妇人一律不针。为什么？动了胎气，容易堕胎。滑肉门虽然在上腹部，但孕妇整个腹部都不宜针刺。灸法方面，滑肉门可以灸，但如果是热证、实证，比如胃火旺盛、口臭便秘，就不宜灸，灸了反而助热。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演滑肉门的气血流注与开阖机理**：
  - 滑肉门这个名字，取得很妙。"滑"，是滑利、滑动的意思；"肉"，指的是肌肉、脾胃所主的肌肉；"门"，是门户、关口。合起来看，**滑肉门就是让脾胃的肌肉气血能够滑利通畅的一个门户**。
  - 倪师讲，胃经的气血，从梁门、关门一路下来，到了滑肉门这里，正好是胃气要往下走、脾气要往上散的一个交接口。滑肉门在中间，起到了"转枢"的作用。如果这个门户堵住了，胃气降不下去，就会出现恶心、呕吐、胃胀、打嗝；脾气升不上来，就会出现腹胀、泄泻、四肢无力。
  - 从气化角度讲，滑肉门的核心机理是**健脾行水、和胃降逆**。脾主肌肉，滑肉门在胃经上，胃和脾是表里关系，所以滑肉门一穴，能同时调理脾胃。脾气虚了，水湿停在中焦，人就觉得肚子胀、身上重、大便稀，滑肉门能利湿。胃气上逆了，人就打嗝、反酸、呕吐，滑肉门能和胃降逆。
  - 倪师还提到，滑肉门对于**痰饮**类的病有特殊作用。中医讲"脾为生痰之源"，脾胃功能不好，水湿不化，就变成痰。滑肉门能健脾行水，所以对于痰多的病人，不管是咳嗽痰多，还是肥胖痰湿体质，滑肉门都可以用。
- **子母补泻与五行生克运用心法**：
  - 胃经属土，滑肉门是胃经上的腧穴，它的五行属性也是土。从子母补泻的角度，胃经的母穴是解溪（火穴，火生土），子穴是厉兑（金穴，土生金）。滑肉门本身不是子母穴，但它在脾胃区域，可以直接调补脾胃。
  - 倪师在讲子母补泻的时候说，你如果遇到脾胃虚弱的病人，可以补解溪（母穴），或者直接灸足三里、灸滑肉门，效果都很好。如果是胃火实证，比如牙龈肿痛、口臭，你可以泻厉兑（子穴），同时针滑肉门来疏通中焦。
  - 滑肉门在五行生克中的关键作用是**"培土生金"**。脾胃属土，肺属金，土生金。脾胃虚弱的人，肺气也不足，容易感冒、咳嗽。滑肉门健脾，脾强了，肺自然就强。倪师讲，很多小孩子反复感冒咳嗽，你光治肺没用，要治脾胃，滑肉门就是一个很好的选择。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **急症救逆**：滑肉门本身不是急救穴，但如果遇到因脾胃气机紊乱导致的急性呕吐、胃痉挛，针滑肉门配合中脘、足三里，可以迅速缓解。
  - **慢性病调理**：慢性胃炎、胃下垂、消化不良、腹胀、泄泻、便秘，滑肉门都是常用穴。尤其是胃下垂，倪师讲，滑肉门配上中脘、足三里、百会，能升提中气。
  - **妇科/儿科特效**：妇人月经不调、痛经，如果伴随脾胃虚弱、气血不足，滑肉门可以用。小儿疳积、消化不良、面黄肌瘦，滑肉门配上四缝、足三里，效果很好。
  - **痛症特效**：滑肉门对于腹部疼痛、胃痛、肠鸣腹痛有很好的缓解作用。倪师讲，肚脐周围痛、上腹痛，滑肉门可以针。
- **倪师经典对穴与排针组合**：
  - **滑肉门 + 中脘 + 足三里**：这是调理脾胃的黄金组合。中脘是胃的募穴，足三里是胃经的合穴，滑肉门在中间疏通，三针下去，脾胃的气机就活了。
  - **滑肉门 + 天枢 + 关元**：这是调理肠道、妇科的组合。天枢是大肠的募穴，关元是小肠的募穴，滑肉门在中间转枢，对于便秘、泄泻、月经不调都有效。
  - **滑肉门 + 公孙 + 内关**：公孙配内关是治胃心胸的经典组合，再加上滑肉门，对于胃痛、胸闷、恶心、呕吐，效果倍增。
  - **滑肉门 + 合谷 + 太冲**：合谷配太冲是开四关，滑肉门在中间，能疏通中焦气机，对于气滞型的腹胀、腹痛有效。
