# 风市二

## 📍 经络归属与精准取穴法

- **所属经络**：足少阳胆经。风市为胆经大腿外侧要穴，倪师在《人纪·针灸篇》讲腿部穴位时明确归入胆经。平时大家讲风市多指大腿外侧正中线、直立垂手中指尖所到之处，这是风市一，也就是通常针灸书上的风市。风市二就是在风市一的基础之上再往下取，二者同属胆经，位置相近、气机相通，但风市二更偏于向下、向膝的方向走，对下肢风痛、膝腿无力、半身不遂的引气下行之力更专。
- **特定穴属性**：风市本身不是井荥输经合，也不是原络郄募俞，它是胆经在腿部祛风通络的经验要大穴，倪师常常把它当作风邪在下肢的出口来用。胆经属木，风市一带是少阳风木之气外泄、下肢风邪汇聚的门户，所以凡是“风”字辈的穴，都带有祛风、熄风、搜风的天然属性。
- **倪师动态取穴**：倪师讲风市的时候，最反对一上来就死背几寸几分。他教的手法是：让病人先站直，手自然下垂，中指尖贴着大腿外侧，那个点就是风市一。然后你让病人把腿稍微弯曲，或者干脆躺平，从风市一沿着胆经往下摸，摸到肌肉开始变厚、按下去有酸胀感、病人会“啊”一声的那个点，往往就是风市二。以骨度折量来说，风市一在腘横纹上七寸，风市二大约在风市一下一寸到一寸半之间，也就是腘横纹上五寸半到六寸上下。你不要拿尺子死量，要让病人自己告诉你哪里最酸最胀，那个就是穴。
- **下针深度**：直刺一寸到一寸半，针下去要贴着骨膜旁边走，不要扎到骨头上。胖人可到两寸，瘦人一寸即可。针感要往下窜，最好能窜到膝盖或者小腿外侧，那说明气到了。
- **禁针禁灸法则**：风市二一般来说针比灸好用，因为它是祛风通络的穴，灸多了反而助风热。但如果是虚寒性的下肢冷麻，可以温和灸五到十分钟，不要灸出大水泡。局部皮肤溃烂、红肿热痛的时候禁针。孕妇慎针，因为胆经与肝经相表里，动了少阳容易牵动厥阴。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师认为，风市二的气化机理是“引风下行、疏木达郁”。胆经是少阳枢机，主半表半里，风市二在大腿外侧中下段，像是胆经在腿上的一个排风扇。上面头面、肩颈的风邪，还有肝胆郁结化出来的风火，走到这里的时候，风市二把它往下引，从腿外侧散出去。所以倪师说，风市二不是补穴，它是开穴、泄穴、通穴。它的作用不是往里灌能量，而是把堵在少阳经上的风、湿、郁热打开一个口子放掉。下肢萎软无力的人，风市二一针下去，气往下走，腿就感觉轻了；半身不遂的人，风市二配上环跳，能把气血从胯部引到膝盖、引到脚踝。
- **子母补泻与五行生克**：胆经属木。木的母是水，木的子是火。风市二本身不是五输穴，不能直接套母子补泻，但倪师在临床上会借用胆经的母子关系来配穴。比如胆经虚证，下肢酸软无力、遇冷加重，这是木气不足，要补母，取胆经的水穴——侠溪，因为荥穴属水，再配风市二引气下行，这叫补母通子。胆经实证，大腿外侧痛、偏头痛、口苦，这是木气太过，要泻子，取胆经的火穴——阳辅，因为经穴属火，再配风市二把风火往下引，这叫泻子开结。倪师反复讲，你不要被五行绕晕，你只要知道风市二是个通道，虚的时候你给它源头加水，实的时候你给它下游开口，这就是子母补泻在风市二上的活用法。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
    - **下肢风痛、游走性关节痛**：风市二最拿手的就是风邪引起的膝盖痛、小腿外侧痛、痛处跑来跑去的那种。倪师说，风善行而数变，风市二就是专门对付这种跑来跑去的痛。
    - **半身不遂、中风后遗症**：风市二配环跳、阳陵泉，是倪师治疗中风腿无力、足内翻、足外翻的经典排针。针下去要让病人试着抬腿，很多人当场就能抬高几寸。
    - **皮肤痒、荨麻疹**：风市二能祛风止痒，尤其是大腿外侧、下半身起的风疹块，针风市二加血海、三阴交，效果很快。
    - **坐骨神经痛**：胆经走向的坐骨神经痛，从环跳痛到风市二再到阳陵泉，风市二是必经之路，针它能把痛往下引、往外散。
- **倪师经典对穴与排针组合**：
    - **风市二 + 环跳**：治下肢萎软、半身不遂。环跳是起点，风市二是中继站，两针一上一下，气就串起来了。
    - **风市二 + 阳陵泉**：治膝盖痛、筋痛。阳陵泉是筋会，风市二引气到膝，一个管筋，一个管风，搭配起来筋风并治。
    - **风市二 + 足三里 + 三阴交**：治下肢气血两虚、冷麻无力。足三里补阳明之气，三阴交补三阴之血，风市二把气血引到腿外侧，三针下去，整条腿都暖了。
    - **风市二 + 血海**：治下肢风疹、皮肤痒。血海养血熄风，风市二祛风外散，血行风自灭。
    - **风市二 + 悬钟（绝骨）**：治脚无力、踝关节痛。悬钟是髓会，风市二引气到腿，一上一下，骨髓里的气也动了。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原味金句**：倪师在《人纪·针灸篇》讲风市的时候说：“风市这个穴，你千万不要把它当成一个死点。你看病人站到，手自然垂下来，中指尖到处是风市。那风市二在哪里？你顺着胆经再往下摸，摸到那个病人一按就酸到骨头里的点，那就是风市二。针灸不是叫你背一寸两寸，是叫你去找那个‘气’的点。你找到那个点，针下去，病人会说，哎呦，一股电下去了。那就对了。”
- **手下针感体会**：倪师说，针风市二，手法要快，进针要干脆。针尖透皮之后，稍微偏一点方向，不要直直地扎，要顺着胆经往下斜刺。你得气的时候，病人会感觉一股酸胀从大腿外侧往膝盖窜，有的甚至窜到脚背。这时候你不要再捻针了，让它气自己走。如果病人说痛，那是你扎到肌肉纤维了，退一点，换个角度再进。风市二的针感，应该是胀多于酸，窜多于痛。
- **医案故事**：倪师讲过一个案例，一个五十多岁的男人，中风后右腿完全抬不起来，西医说神经坏了，没救了。倪师取环跳、风市二、阳陵泉，针风市二的时候，病人突然说“我的脚趾头会动了”。倪师说，你不要高兴太早，这是气到了，不是神经长回来了。然后他继续针，留针二十分钟，起针后让病人试着抬腿，病人当场把腿抬高了三十度。倪师说，不是我厉害，是风市二把胆经的气引下去了。胆经的气一通，腿的力就回来了。他还特别强调，中风病人针风市二，一定要配合病人的呼吸，病人吸气的时候进针，呼气的时候引气下行，这样效果加倍。
- **针灸秘要**：倪师最后嘱咐，风市二这个穴，你不要天天针。它是开泄的穴，针多了人会虚。一般一周针两到三次，连续针两周就要停一停，让正气自己恢复。如果是虚证，针完风市二之后，一定要加针足三里或者关元，把气固住，不然风是祛了，人也没力了。这就是倪师讲的“祛风不忘固本，开泄不忘收敛”。
