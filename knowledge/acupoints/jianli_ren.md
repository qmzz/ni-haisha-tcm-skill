# 建里二

## 📍 经络归属与精准取穴法

- 建里穴属任脉，在脐上三寸。任脉本身无井荥输经合五输穴属性，建里亦非原、络、郄、募、背俞、八会等特定穴。它的定位靠的是任脉全线的骨度分段——从胸骨下端（岐骨）到肚脐（神阙）折作八寸，建里正在脐上三寸处，也就是中脘（脐上四寸）下一寸、下脘（脐上二寸）上一寸的中间点。

- 倪师取穴从来是“先找中脘，再找下脘，当中就是建里”，甚至更简单——先找肚脐，从肚脐往上量三寸（四指并拢为三寸，或用骨度一寸一寸往上推），按到那个点就是。按的时候不要死按，用大拇指轻轻往里探，常能在腹白线上摸到一个微微凹陷或有酸胀反应的“坑”，那就是建里。

- 下针深度：倪师讲任脉脐上这一段，一般针五分到一寸，建里位于中焦，针太深容易伤到胃壁和内脏，所以以五到八分为主，针感以酸胀向四周扩散或向下传导为得气。可灸，艾灸建里对中焦虚寒、腹胀肠鸣效果好。禁针禁灸方面，建里本身不禁，但孕妇腹部诸穴一律禁针，这是底线。有腹主动脉瘤、腹部手术后局部疤痕粘连的，也要避开或浅刺。

## ⚡ 倪师经穴气化与破局心法

- 倪师讲任脉中段这三个穴——中脘、建里、下脘——是一条线上的三个“水闸”。中脘是胃募、腑会，主纳；下脘主磨；建里夹在中间，主的是“运”。上焦下来的水谷到这里如果堵住了，就是中焦气机不转，人的感觉就是肚子胀、吃一点就饱、肠子咕噜噜响却不排气。建里的作用就是把这个“堵”掰开，让中焦的气机重新转动起来。

- 从气化角度看，建里属脾土所主的腹部区域，能健脾行水、升清降浊。它把胃里停着的浊水往下导，把脾该升的清阳往上提，所以对“水停中焦”造成的腹胀、水肿、肠鸣有直接的破局作用。倪师常说中焦如沤，建里就是那个“沤”的搅动棒，中焦不动的时候要想到它。

- 子母补泻方面，任脉没有五行五输穴的母子关系，但倪师在临床取类比象时会这样用：建里与足三里、阴陵泉同属中焦土系，脾虚不运时补足三里、阴陵泉，再针建里导气，等于“母补子通”；胃实胀满时泻内庭、公孙，再针建里行气，等于“子泻母安”。建里本身以平补平泻或导气为主，不偏补也不偏泻，它是给中焦让路的一个穴。

## 🎯 临床主治与配穴组合手印

- 核心特效主治：腹胀、腹痛、肠鸣、消化不良、食欲不振、胃下垂感、中焦停水、恶心呕吐。倪师特别指出建里对“胃下垂”和“中气下陷导致的腹部坠胀”有升提中气之效，因为它在中脘之下、下脘之上，正好托住中焦，不让气往下掉。

- 妇科方面，建里配关元、三阴交，可治经期腹胀、经前小腹坠满。儿科方面，小儿疳积、腹胀如鼓，建里浅刺加灸，配合四缝放血，是倪师常用的“开中焦”组合。

- 倪师经典对穴与排针组合：
  - 建里 + 中脘 + 下脘：三针齐下，叫“开中焦三关”，治一切中焦气滞、食积、腹胀。
  - 建里 + 足三里 + 公孙：公孙通冲脉，管胃心胸，足三里补中土，建里导中焦之气，治胃胀、胃痛、消化不良。
  - 建里 + 内关 + 足三里：治恶心呕吐、晕车晕船、妊娠恶阻（孕妇建里禁针，可改灸或指压）。
  - 建里 + 天枢 + 气海：治腹胀肠鸣、大便不爽，天枢行大肠之气，气海鼓动下焦，建里转中焦，三焦气机一起转。
  - 建里 + 阴陵泉 + 水分：治中焦停水、水肿、小便不利，阴陵泉利水，水分分利水道，建里运中焦，水湿从下焦走。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在针灸篇讲任脉这一段时的原话大意是：“中脘、建里、下脘，这三个穴你把它们看成一条管子上的三个节。中脘是胃的门口，建里是胃的中间，下脘是胃的出口。门口堵了针中脘，中间堵了针建里，出口堵了针下脘。你问病人哪里胀？病人说肚脐上面一点胀，那就是建里。”

- 手下针感体会：倪师讲针建里的时候，针下去要“等气”，不要急着捻针。得气的感觉常常是病人觉得肚子里面有一股气在转，或者针下有一种沉紧感，像针被什么东西轻轻咬住了。这时候再轻轻提插捻转，病人会觉得胀感从建里向四周扩散，有时候会听到肠子“咕噜”一声，那就是中焦气机开始动了，这一针就到位了。

- 医案故事：倪师讲过一例，病人胃下垂，吃完饭就胀得难受，站久了小腹坠。倪师取中脘、建里、下脘，加足三里、百会。针建里的时候，病人当场觉得肚子里有东西往上提了一下，连续针了三次，配合灸百会，胃下垂的坠胀感明显减轻。倪师说这就是建里“托中焦”的作用，它不直接升提，但它把中焦的气机转起来，中气自己就会往上走。
