# 中髎穴 (BL33)

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。八髎穴之一，即次髎、中髎、下髎三穴并列于骶后孔中，中髎居其中。八髎整体是膀胱经在腰骶部与盆腔内脏沟通的关键枢转区，中髎正当第三骶后孔，为下焦气血出入盆腔之要冲。
- **穴性定位**：中髎不属井荥输经合五输体系，但它是八髎之核心穴之一，与次髎、下髎协同，构成膀胱经腰骶段“腰-盆-腿”三联调节枢纽。从五行角度看，腰骶部属水，膀胱经亦属水，中髎居水中之水中，专司通调下焦水道、转枢盆腔气血。
- **倪师动态取穴**：八髎怎么找？倪师讲得很直白——从骶骨最上端往下摸，摸到第一对骨孔就是上髎，再往下第二对是次髎，第三对是中髎，第四对是下髎。怎么确认？用手指按在骶骨面上，从上往下慢慢推，推到有孔洞感、手指能陷进去的地方，那就是髎穴。中髎在次髎正下方，约当第三骶后孔。倪师强调：八髎穴要按骨度折量，不要死板地数寸——每个人的骶骨长短不同，孔的位置也略有差异，你摸到的孔才是真正的穴。
- **下针深度与方向**：中髎穴下针，倪师说一般是直刺，进针深度约一寸到一寸半，针尖进入骶后孔后，会有一种明显的“落空感”——针穿过骨孔的感觉，这就是气至。八髎穴的针感非常强烈，病人常常会有酸胀感向下肢放射，或者小腹内部有收紧、酥麻的感觉，这是骶神经丛被刺激的表现。禁针禁灸方面，中髎本身无绝对禁针，但孕妇慎用，因为八髎区域直接联通盆腔，强刺激可能引发宫缩。灸法可用，但多用于虚寒型下焦病症，实热证不灸。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：倪师在讲八髎时反复强调一个核心概念——八髎是**膀胱经与盆腔之间的气化枢纽**。中髎正当第三骶后孔，下焦的水道代谢、子宫卵巢的气血循环、大肠的传导功能，全赖此处气机开阖。膀胱经主一身之表，但八髎区域是它联络内里的窗口——通过骶后孔，膀胱经的经气可以直接灌注到盆腔内脏。中髎的气化特点是“通”与“转”：通则水道利，转则盆腔气血活。倪师说，很多妇女月经不调、痛经、白带异常，你按她的八髎，一按就痛，甚至屁股冰凉——这就是下焦气化不利，中髎在这里就是破局点。
- **子母补泻与五行生克**：中髎虽非五输穴，但放在膀胱经水行的大框架下看，八髎区域属水，肾亦属水，膀胱与肾相表里。倪师心法：**实则泻中髎，虚则补中髎**。实证——比如急性腰扭伤、盆腔炎急性发作、痛经剧烈——用中髎配次髎、下髎，强刺激泻法，通之即所以泻之。虚证——比如慢性腰膝酸软、宫寒不孕、遗尿遗精——中髎配关元、肾俞，温针或灸法以补之，补膀胱经之阳气，即是水生木、木生火，引下焦之火以暖全身。倪师特别指出：八髎穴的补泻不在针法花哨，而在**针感的方向**——针感向下走（向下肢放散），偏于泻，通经活络；针感向小腹内收，偏于补，温暖下焦。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **妇科病**：痛经、月经不调、赤白带下、宫寒不孕、产后腰痛。中髎是妇科要穴，倪师说妇人腰痛配八髎，几乎百发百中。
  - **下焦水道病**：小便不利、淋证、遗尿、前列腺增生导致的排尿困难。中髎通利膀胱气化，利水通淋。
  - **腰腿痛**：尤其是腰骶部疼痛、坐骨神经痛、下肢痿痹。八髎区域直接对应骶神经丛，中髎对坐骨神经痛有特效。
  - **男科病**：遗精、阳痿、早泄。中髎配肾俞、关元，温补下焦元阳。
  - **肛肠病**：便秘、痔疮、脱肛。中髎与下髎协同，可调节直肠和肛门括约肌的气机。
- **倪师经典对穴与排针组合**：
  - **中髎 + 次髎 + 下髎**（八髎倒马针）：三针齐下，覆盖整个骶后孔区域，主治一切盆腔、妇科、腰骶病症。这是倪师最常用的八髎排针法，三穴同时下针，形成一个“气化矩阵”，把整个下焦的气血搅动起来。
  - **中髎 + 关元 + 三阴交**：妇科不孕、痛经、月经不调的经典组合。关元补元气，三阴交调肝脾肾三经，中髎转枢盆腔气血，三穴合用，标本兼治。
  - **中髎 + 肾俞 + 委中**：腰痛、腰肌劳损、坐骨神经痛。肾俞补腰肾，委中（膀胱经合穴，“腰背委中求”）疏通经气，中髎局部破局，远近配穴一气呵成。
  - **中髎 + 阴陵泉 + 水道**：水肿、小便不利、前列腺增生。阴陵泉健脾利水，水道穴专司水道，中髎通利膀胱，三穴合力，从脾到肾到膀胱，一条龙利水。
  - **中髎 + 合谷 + 太冲（开四关）**：痛经剧烈时，开四关调气血，中髎局部破瘀滞，上下呼应，止痛如鼓应桴。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲八髎穴时，原话大意如此：

> “八髎穴，你找到骶骨上的孔，上髎、次髎、中髎、下髎，这是老天爷设计好的八个洞，膀胱经的经气就从这八个洞穿过去，跟盆腔里面的脏腑通气。妇人痛经，你按她的中髎，一按就痛得跳起来，这就是气堵在那里了。针下去，针尖穿过骨孔，她整个人会松掉。”

> “中髎下针，你不要怕，针进去以后有一种落空感——像针刺穿一层纸，突然空了——那个就是气到了。病人会有酸、麻、胀，有时候像电一样往下肢窜，你不要慌，那是气在走。”

> “八髎穴治疗妇科，效果到什么程度？月经痛得在地上打滚的，针下去，十分钟，不痛了。为什么？因为中髎把盆腔的气血一打开，瘀滞一散，痛就没有了。中医讲通则不痛，八髎就是通下焦的钥匙。”

- **针感体会**：倪师特别强调，中髎的针感与一般穴位不同。一般穴位下针是酸胀，中髎下针是**深层的、向内脏渗透的感传**，病人常常描述为“小肚子里面在动”“子宫在收缩”“有一股热气往下面走”。这就是骶后孔被针刺后，直接激活了盆腔内脏的自主神经调节。
- **医案故事**：倪师曾讲过一个案例，一位妇人痛经十余年，每次月经来潮都要卧床三天，止痛药吃到胃出血。倪师取八髎穴——上髎、次髎、中髎、下髎全部下针，加关元、三阴交，留针二十分钟。针到十分钟，病人说“肚子不痛了，热热的”。此后每次月经前一周来针一次，连续三个月，痛经痊愈。倪师说：“这不是我厉害，是八髎穴本来就该这么用，老祖宗几千年前就告诉我们了。”

- **秘要心传**：倪师特别叮嘱，八髎穴下针，**针要够长**——至少一寸半以上，因为骶后孔有深度，针短了刺不到孔里，效果大打折扣。另外，八髎穴最好**双侧同取**，不要只针一边，因为盆腔的气机是左右对称的，双侧同针才能形成完整的气化场。最后，留针时间要够，一般不少于二十分钟，虚寒证可以加温针或艾灸，让阳气从骶孔渗透进去，暖透整个下焦。
