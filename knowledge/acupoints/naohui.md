# 臑会

## 📍 经络归属与精准取穴法

- 臑会属**手少阳三焦经**，为**手少阳与阳维脉之会**。三焦经井荥输经合五输穴另有所属（关冲、液门、中渚、支沟、天井），臑会不属五输，但它是三焦经臂上大穴，与阳维脉相交，管的是**肩臂阳气交通**的枢纽。
- 倪师讲，三焦者，决渎之官，阳气之道。阳维维系诸阳，臑会正是阳气在臂上汇聚交换的关口——这也是「臑会」二字的本义：臑者，臂上肉也；会者，阳气交会也。
- **骨度折量法**：先找**肩髎**（肩峰后下方凹陷，臂外展时凹陷明显），再找**肘尖（尺骨鹰嘴）** 。从肩髎到肘尖连一条线，取中点，再往下一寸，按之有明显酸胀处，就是臑会。倪师大白话：肩头到肘尖拉一条直线，对折取中点，中指往下一按，按到那个「啊」一声的点，就是它。
- **简易摸法**：手臂自然下垂，另一手从肩头往下推，推到三角肌后缘止住、下面出现一个凹陷，就是臑会。倪师说，你不要死记「肩髎下三寸」，你就顺着骨头摸，摸到那个凹陷，按下去病人会缩手，对了。
- **进针深度**：直刺**五分到一寸**。倪师强调：臂上肉薄，不可深刺。针下得气即止，不要贪深。
- **禁针禁灸**：此穴可灸，但**不宜直接化脓灸**。倪师说，臂上阳面，灸可以，但用米粒灸壮数宜少，三五壮即可，不可大炷久灸，以免伤津动火。


## ⚡ 倪师经穴气化与破局心法

- 臑会的气化机理，倪师归为四个字：**通阳散结**。三焦经走到臂上，阳气要从这里过，如果阳气在这里堵住了，肩臂就开始痛、酸、举不起来。臑会就是**打开这个阳气关卡的钥匙**。
- 倪师推演气血流注：三焦经的气从关冲一路沿臂外侧上行，过天井、走臑会、上肩髎、入缺盆。臑会这个位置，正好是阳气从肘到肩的**接力站**。阳气在这儿接不上力，肩就抬不起来，这就是「五十肩」的由来之一。
- 更深一层，倪师讲：臑会与阳维脉相交，阳维主一身之表阳。所以臑会不光是治肩臂，它还能**引阳气达表**，把身体深处的阳气调到体表来，用来对抗表寒、表湿。比如有人肩背常年怕冷、像背着冰块，倪师会在臑会上下针，再配阳维脉的**外关**，一针下去，阳气就到了。
- **子母补泻**：臑会不属五输，不能直接套子母补泻。但倪师有变通法——三焦经属火，其母为木（木生火），其子为土（火生土）。若臑会区域因阳气不足而酸痛无力，这是**虚证**，当补其母，取**中渚**（三焦输穴，属木）以生火；若臑会区域红肿热痛、拒按，这是**实证**，当泻其子，取**天井**（三焦合穴，属土）以泄火。臑会本身则是**通调穴**，虚补实泻的引气关口。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **肩臂痛、五十肩、臂不能举**：这是臑会第一主治。倪师说，肩膀痛到手抬不起来，你在臑会下一针，再让病人慢慢抬手臂，针到痛减，立竿见影。
  2. **肩胛骨痛、肩背冷痛**：阳气不到肩背，臑会通阳，专治这种「冷痛」。倪师常配**天宗**（小肠经，肩胛骨上）同用，一前一后，把肩胛骨的阳气打开。
  3. **瘿气、瘰疬（甲状腺肿、颈淋巴结核）** ：臑会近肩，阳气通到颈部，倪师说三焦经与淋巴系统相通，臑会能散结。常配**天井**、**少海**一起用。
  4. **臂神经痛、上肢麻木**：手少阳经气不通，臑会开气，配**外关**通阳维，效果倍增。

- **倪师经典对穴与排针组合**：
  1. **臑会 + 肩髎 + 天宗**：治肩臂痛三针。倪师说，肩髎在肩上、臑会在臂上、天宗在肩胛上，三针下去，肩膀前后上下都通了，五十肩无处可逃。
  2. **臑会 + 外关**：治阳维脉病，肩背冷痛、怕风。外关通阳维，臑会开气，一气一血，一表一里。
  3. **臑会 + 中渚**：虚证补气法。中渚补木生火，臑会引气到肩，治手臂无力、酸软。
  4. **臑会 + 天井**：实证泻火法。天井泻土，臑会散结，治臂上红肿热痛、瘰疬。


## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲三焦经臂上穴位时，原话大意如下：

> 「臑会这个穴，你看名字就知道，臑是手臂上的肉，会是阳气交会。所以它是阳气在手臂上聚会的地方。你肩膀举不起来，你就在臑会上下针。你摸到那个凹陷，针下去，病人说酸，你就对了。你不要死记几寸，你就摸，摸到那个凹陷，按下去病人会叫，就是它。」

> 「五十肩，我们叫肩凝，肩膀像冻住一样。西医说要开刀，我们不用。你在臑会、肩髎、天宗上针，针完让病人抬手，当场就能抬。为什么？阳气通了嘛。阳气堵在那边，像水管打了结，你把结打开，水就过去了。臑会就是解那个结的。」

> 「臑会跟外关配，是很好的一对。外关通阳维，阳维管一身表阳。你肩背怕冷，像背冰块，这是表阳虚。你外关针下去，再加个臑会，阳气就从里面透到表面来。病人当场觉得肩膀热起来，这不是我吹牛，你试试看。」

> 「瘿气、瘰疬，脖子上长东西，你在臑会上下针，再配天井。天井是合穴，属土，土能克水，水就是痰湿。痰湿凝结成块，你用天井去克它，用臑会去散它，一克一散，块就小了。这不是一天两天的事，要耐心。」

> 「臑会针下去，得气的感觉是酸胀，有时候会往肩膀方向走。你不要刻意去追求针感传导，气到了就好。臂上肉薄，你针太深，病人会不舒服。五分到一寸，够了。你针下去，病人说肩膀松了，这就是气到了。」

- **倪师手下针感体会**：倪师说，臑会下针，针尖要稍微**向肩髎方向斜刺**，效果比直刺更好。为什么？因为你要引气往肩上走，顺着经气方向斜刺，气就跟得快。直刺是守穴，斜刺是引气。你要通肩，就斜刺；你要守中，就直刺。

- **医案故事**：倪师讲过，有个五十多岁太太，肩膀痛了半年，手抬不到头。倪师在臑会、肩髎、天宗下针，留针二十分钟。起针后让太太抬手，太太一抬就抬到头顶，当场哭了。倪师说，不是我厉害，是阳气通了。她肩膀的阳气堵了半年，你打开它，它自己就过去了。后来倪师教她每天自己按臑会，按到酸胀，肩膀就不会再痛。这就是「通阳」的道理。
