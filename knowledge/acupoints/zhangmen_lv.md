# 章门二

## 📍 经络归属与精准取穴法

- **所属经络**：足厥阴肝经。章门是**肝经的腧穴**，但它的身份远不止于此——它同时是**脾之募穴**，又是**脏会章门**（八会穴之一，五藏之气在此会聚）。一个穴身兼三重身份，站在肝经上，管的是脾的事，统的是五脏的气。

- **特定穴属性**：脾募 + 脏会。募穴是脏腑之气在胸腹部汇聚之处，章门是脾的募穴，所以一切脾的问题——脾虚、脾湿、脾肿大——都可从这里入手。而脏会章门，意味着心、肝、脾、肺、肾五脏中任何一脏出问题，章门都能调。倪师说：“脏会章门，所有的脏病，都可以在章门治。”

- **倪师动态取穴法（大白话版）**：章门怎么找？你让病人侧躺，手屈起来，肘尖自然贴着胁肋侧面。肘尖所触之处，就是章门。这是最简便的取穴法。倪师在讲课时就让学生自己用手肘尖去顶胁肋，一顶就中。另一种找法：从肚脐往外侧量，旁开六寸（脾经大横是旁开四寸，再往外两寸即是），但这个“六寸”是骨度折量，不是拿尺子死量。关键是要摸到**肋骨的下缘端**——十一肋游离端下方。你顺着胁肋往下摸，摸到第十一肋骨头尖，章门就在这个骨头尖的下方、稍微偏内侧一点。倪师强调：“你不能拿尺子去量，要用手去摸骨头，摸到那个肋尖端，顺着骨缘下针就对了。”

- **下针深度与禁针禁灸法则**：章门**可针可灸**。针法一般是**斜刺或平刺**，针尖顺着肋缘方向刺入，深度约**五分到八分**，不宜直刺深刺。为什么？因为章门内侧就是**脾脏**，左侧章门更深层还靠近**胰尾**，再往内就是腹腔大血管。倪师原话：“你直刺太深，扎到脾脏，那要开刀的。”所以倪师教学生：**贴着肋骨下缘斜刺，针尖朝向背后方向，不要朝内直戳**。灸法方面，章门可以灸，尤其是脾虚、腹胀、痞块的时候，灸章门能温脾散寒、化积消痞。但如果是**局部有肿块、痞块坚硬**的情况，倪师主张先针后灸，或者针而不灸，视具体情况而定。禁忌上：**孕妇慎针章门**，因其近腹腔，动胎气。

## ⚡ 倪师经穴气化与破局心法

- **气机推演——脾之募，脏之会，引气归脏**：章门的气化机理，倪师是从“募穴”和“脏会”两个角度来讲的。募穴是什么？是脏腑之气直接灌注到胸腹壁的窗口。脾的募穴在章门，意味着脾气在这里汇聚、在这里出入。所以当脾气虚弱、运化无力的时候，章门这个窗口就“堵住了”或者“空掉了”。倪师说：“脾有问题的，章门一按就痛。”这是诊断，也是治疗的入口。

  更深一层，脏会章门。五脏——心肝脾肺肾——的气都在这附近交会。章门就像五脏气机的**总调度站**。倪师推演：当一个人五脏气机紊乱、气血不能归位的时候，针章门可以**引气归脏**，让散乱的气重新回到五脏的轨道上去。这就是为什么章门能治的范围那么广——它不只是治脾，它能调五脏。

- **开阖机理——健脾行水、消痞散积**：脾主运化水湿。脾气一虚，水湿就停聚，停在上则胸闷，停在中则腹胀，停在下则脚肿。章门作为脾募，针之能**振奋脾阳、开通水道**。倪师讲：“腹胀、水肿、痞块，章门是近取穴，针下去，脾气一行，水就动了。”尤其是**肝脾肿大、腹部痞块**这类病，倪师常用章门配期门（肝募），一肝一脾，两个募穴同调，能破癥消积。他讲过：肝病后期脾也肿大，章门和期门一起用，能通肝脾之气，这是治本的思路。

- **子母补泻与五行生克**：章门属肝经，肝属木，脾属土。木克土，肝木过旺则克脾土。章门既是肝经穴又是脾募，所以它天然具备**调和肝脾**的功能。倪师在五行生克上的运用心法：如果是**肝木克脾土**导致的脾虚（比如人一生气就胃痛、拉肚子），针章门能**平肝木、扶脾土**。这时候的手法：如果以脾虚为主，用补法（因为脾募本身偏补）；如果以肝郁为主，用泻法或平补平泻。倪师说：“你一看这个人，脉弦、胁痛、又腹胀、又没胃口，这就是木克土。章门一下去，肝也平了，脾也醒了。”

  子母补泻方面，肝经的子穴是行间（荥穴，属火，木生火），母穴是曲泉（合穴，属水，水生木）。但章门不在五输穴之列，它是募穴，所以它的补泻不按子母穴走，而是按**募穴的特性**走——虚则补其募（直接补脏腑之气），实则泻其募（直接泄脏腑之邪）。倪师用法：脾虚的人，章门用补法（针尖顺经气方向，或加灸）；脾实（如痞块、胀满）的人，章门用泻法（针尖逆经气方向，或点刺放血）。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：

  1. **脾虚诸症**：腹胀、肠鸣、消化不良、食欲不振、四肢无力、面色萎黄。章门是脾募，直接振奋脾阳，这是它的看家本领。
  2. **痞块积聚**：肝脾肿大、腹部癥瘕、痞块。倪师常讲：“脏会章门，有块的地方，章门能化。”
  3. **胁痛**：尤其是两胁胀痛、肝区痛。章门在胁部，近取穴，能疏通局部气血。
  4. **水肿**：脾虚水泛，下肢浮肿，章门能健脾行水。
  5. **黄疸**：肝脾同病，章门配期门、阳陵泉，能利胆退黄。
  6. **急症救逆**：脏气脱绝的时候，灸章门能回阳固脱——这是脏会的作用，把五脏之气收回来。

- **倪师经典对穴与排针组合**：

  1. **章门 + 期门**：肝募配脾募，治肝脾同病、痞块、胁痛。倪师说：“这两个募穴一起用，肝脾一起调，这是治大病的路子。”
  2. **章门 + 足三里**：脾募配胃合，治一切脾胃虚弱、消化不良、腹胀肠鸣。足三里补胃气，章门补脾气，脾胃同补。
  3. **章门 + 中脘 + 足三里**：这是倪师治脾胃病的“铁三角”。中脘是胃募，章门是脾募，足三里是胃合，三穴同用，脾胃通调。
  4. **章门 + 三阴交**：脾募配三阴交（肝脾肾三经交会），治妇科病、脾虚湿盛、月经不调。
  5. **章门 + 水分 + 阴陵泉**：治水肿。水分通水道，阴陵泉利湿，章门健脾，三穴合力，水湿自去。
  6. **章门 + 肝俞 + 脾俞**：俞募配穴法。肝俞配期门，脾俞配章门，前后呼应，治肝脾慢性病。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原话金句**：

  “章门，你手肘一弯，肘尖到处就是章门。这是脾的募穴，也是脏会。所有的脏病，都可以在章门治。”

  “脾有问题的人，章门一按就痛，痛得叫起来。你不用问他脾好不好，一按就知道。”

  “章门你不要直刺，直刺下去太深，扎到脾脏，那要开刀的。你要顺着肋骨下缘，斜着刺，针尖朝背后方向。”

  “脏会章门，什么意思？就是五脏的气都在这里会。你五脏气乱的时候，针章门，让气归位。”

  “腹胀、痞块、水肿，你针章门，再配期门，一肝一脾，两个募穴一下去，气就通了。”

  “脾虚的人，章门用补，加灸更好。脾实的人，章门用泻，或者点刺放血。虚实一定要分清楚。”

- **实战手下针感体会**：倪师讲，针章门的时候，针尖贴着肋骨下缘进去，病人会有一种**酸胀感从胁部往腹部深处透**。有时候针下去，病人会觉得**肚子里有东西在动**，那是气机被搅动了。如果病人脾虚严重，针章门的时候，针下会感觉**虚软无力**，像扎在棉花上，这时候要加灸，用艾火把脾气暖回来。如果病人有痞块，针下去会感觉**针尖碰到硬物**，这时候不要硬戳，要退针，改用斜刺或加灸，慢慢化。

- **医案故事**：倪师讲过一个个案。有个病人，肝硬化后期，脾也肿大，腹胀如鼓，吃不下东西，西医说要抽腹水。倪师一看，脉弦细，舌苔白腻，这是肝木克脾土，脾虚水泛。他取章门、期门、足三里、水分、阴陵泉，针用平补平泻，章门加灸。针了三次，病人腹胀明显消了，开始想吃东西。倪师说：“这就是脏会章门的作用，你把肝脾的气一通，水就自己走了，不需要抽。”后来这个病人坚持针了两个月，腹水基本消退，脾肿大也缩小了。倪师总结：“章门这个穴，你看起来不起眼，但它是治大病的穴。关键是你要会用，要知道它是脾募，是脏会，要把它和期门、足三里配起来用。”

  还有一个案例：有个妇人，常年腹胀、肠鸣、拉肚子，西医说是肠易激综合征，治了几年没好。倪师一按她章门，她痛得缩起来。倪师说：“这就是脾虚。”针章门、足三里、三阴交，章门加灸，针了五次，腹胀好了大半，大便也成形了。倪师说：“你按章门痛，就是脾在求救。你针下去，脾就醒了。”
