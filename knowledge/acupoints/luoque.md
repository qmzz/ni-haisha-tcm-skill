# 络却

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。络却穴是膀胱经在头部后侧的重要腧穴，位于通天穴之后、玉枕穴之前。《针灸大成》载其“在通天之后一寸五分，夹玉枕骨上两旁各一寸三分”。

- **五输穴/特定穴属性**：络却非井荥输经合，亦非原络郄募俞。它是足太阳膀胱经在头顶部的经穴之一，与通天、玉枕、天柱一气贯注，属于膀胱经“从头走足”循行通路上的头部要穴。

- **倪师动态取穴与骨度折量法**：
  - 先找通天穴：通天在承光穴后一寸五分，承光在五处后一寸五分。倪师在《人纪·针灸篇》讲头部穴位时，最强调“先定基准线”——从百会往前找，百会到前发际正中是五寸，到后发际正中是七寸。通天从百会往前一寸（百会前一寸旁开一寸五分），通天再往后一寸五分就是络却。
  - **倪师的简单摸法**：你先找到百会穴（两耳尖直上，头顶正中），然后往后摸，摸到头顶后侧开始往下坡走的地方，旁开一寸五分，按下去有空软感或病人说“酸”，那就是络却。倪师常说：“头顶的穴道，要拿指尖去感受骨缝。络却就在通天后面那个凹陷里，你摸到骨头斜坡上缘那个坑，就是它。”
  - **下针深度**：沿皮刺，针尖向后或向前平刺，深度约0.3～0.5寸。倪师特别强调：“头部的穴，除了百会、风府这些特殊穴道，多数是平刺，不是直刺。直刺进去扎到骨膜，病人痛得要命，效果反而不好。”
  - **禁针禁灸**：《针灸大成》未言络却禁针，但倪师提醒：小儿囟门未闭者，头顶诸穴一律禁针。灸法可温灸3～5壮，但倪师说头顶灸要小心，“灸多了头发焦，病人也不舒服”。实热证、肝阳上亢头痛剧烈者，不宜灸。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：络却的“络”是联络、网络之意，“却”有退却、祛除之意。倪师在讲膀胱经头部穴位时指出：膀胱经是人体最长的阳经，从睛明起，上额头，通头顶，下后颈，沿着脊柱两旁一路下行到小趾。头顶这一段，是阳气最旺盛的地方。络却的“络”就是联络诸阳——手足三阳经在头部交汇，络却像一个“阳气的联络站”。它的气化机理是：**升清阳、通脑络、开耳窍、散风邪**。
  - 为什么能治耳聋、耳鸣？倪师说：膀胱经在头顶的穴道，下面就是脑。脑为髓海，肾主骨生髓，膀胱经与肾经相表里。络却一穴，联络脑络与肾气，能把肾精上输到脑和耳窍。耳聋耳鸣不是耳朵本身的问题，是肾精上不去、脑络不通。络却就是把路打通的那个“开关”。
  - 为什么能治头晕、目眩？倪师讲：膀胱经从头顶入脑，络却正在头顶后方，阳气要升到头面，络却就是“清阳上升的通道口”。人头晕目眩，很多时候是清阳不升、浊阴不降。络却一针下去，引清阳上达，浊阴自降。

- **子母补泻与五行生克运用心法**：
  - 络却属足太阳膀胱经，膀胱与肾相表里，膀胱经五行属水（壬水），肾经属癸水。络却本身不是井荥输经合，所以不直接用子母补泻。但倪师在临床上会从“表里经”的角度来用：**膀胱经实证（如头项强痛、目赤肿痛）** ，可以在络却用泻法（针尖逆经而刺，或捻转泻法）；**膀胱经虚证（如头晕眼花、耳鸣如蝉、腰膝酸软）** ，可以在络却用补法（针尖顺经而刺，或捻转补法）。
  - 再往深一层，倪师说：膀胱经的通天、络却、玉枕这一排，是“引肾水上头”的通道。肾虚头晕耳鸣的人，你在络却轻轻补一下，再配太溪（肾经原穴）补一下，这就是“子母相生”的活用——膀胱（水）得肾（水）之助，水足则脑髓充，耳聪目明。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **头晕目眩（急慢性皆可）** ：倪师常用络却配百会、风池。头顶晕、天旋地转的，先针百会提气，再针络却通脑络，最后风池收尾。倪师原话：“百会是升，络却是通，风池是降，三个一升一降一收，头就不晕了。”
  - **耳鸣、耳聋（神经性耳聋、老年性耳鸣）** ：络却配耳门、听宫、听会、翳风。倪师说：耳门、听宫、听会三穴都在耳朵前面，是局部取穴；络却在头顶后方，是远端取穴，从后面打开脑络通往耳窍的路。再配太溪补肾，这就是“标本兼治”。
  - **鼻塞、鼻炎、嗅觉减退**：络却配迎香、通天、印堂。倪师讲：膀胱经从头顶下行到鼻根部，络却和通天都是治鼻子的“远端总开关”。
  - **癫狂、痫证、神志病**：络却配百会、神庭、本神、丰隆。倪师说：头顶的穴道大多能安神定志，络却从后侧联络脑络，对癫痫、精神分裂、躁郁有辅助作用。
  - **颈项强痛、后头痛**：络却配天柱、大杼、风池、后溪。后头痛连项背的，这是膀胱经气机不通，络却通头顶，天柱通颈部，后溪通督脉，一上一下一后，把整条膀胱经打开。

- **倪师经典对穴与排针组合**：
  - **络却配百会**：百会升清阳，络却通脑络。倪师说：“头顶两个穴，一个在前一个在后，前面百会提，后面络却通，像两个人抬轿子，把清气抬到头顶。”
  - **络却配风池**：一前一后，一升一降。络却在头顶后侧通脑络，风池在枕骨下散风邪。倪师治偏头痛、巅顶痛，常用这一组。
  - **络却配太溪**：膀胱（水）得肾（水）之助。倪师讲：耳鸣耳聋、头晕眼花、腰膝酸软，这是肾精不足。太溪补肾精，络却通脑络，精足络通，耳聪目明。
  - **络却配通天**：两穴都在头顶，通天偏前，络却偏后。倪师治鼻窦炎、鼻塞严重时，两穴同用，再配迎香、合谷，鼻子立刻通。
  - **络却配后溪、申脉**：后溪通督脉，申脉通阳跷，络却通脑络。倪师治癫痫、抽搐、角弓反张，用这一组“通督、通跷、通脑”的三通法。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师讲络却的定位原话**：
  “络却这个穴，在通天后面一寸五分。你从百会往前找通天，通天再往后就摸到络却。头顶的穴道，你摸的时候要顺着骨缝找，不要硬按。病人说酸胀，那就是穴道到了。”

- **倪师讲络却治耳聋的实战体会**：
  “耳朵听不到，你不要只扎耳朵前面的穴。耳朵前面是局部，你要从后面打开。络却、玉枕、天柱这一排，你针下去，病人会觉得从头顶到耳朵后面有一条线在跳，那就是气到了。这时候你再问他，耳朵是不是松了一点？他说‘哎，好像有声音了’。这就是气通脑络的表现。”

- **倪师讲络却治头晕的医案**：
  “有个老太太，头晕了十几年，天旋地转，西医说是美尼尔氏综合症，吃药没用。我一看，脉是沉细的，舌头胖大有齿痕，这是清阳不升、水湿停在中焦。我先扎百会、络却、风池，再扎中脘、足三里、阴陵泉。第一次扎完，她说头轻了。第三次来，她说十几年没这么清爽过。这就是‘升清阳、降浊阴’的道理。络却就是把清阳从后面托上去的那个穴。”

- **倪师讲络却的针感**：
  “络却平刺进去，得气的时候，病人会觉得头顶后方有酸胀感，有时候会往耳朵后面扩散。你要守住那个气，轻轻捻针，不要大动。头顶的穴道，气很轻薄，你大动反而把气打散了。针络却，手法要轻、要慢、要守。”

- **倪师讲络却的禁忌**：
  “小儿囟门未闭的，头顶一律不针。还有，肝阳上亢、血压很高的病人，络却不要灸，针也要轻。你灸下去，火上浇油，病人头更晕。这时候要平肝潜阳，太冲、涌泉才是重点，络却只是辅助。”

- **倪师讲络却与鼻子的关系**：
  “鼻子不通，你扎迎香、合谷，这是常规。但你要知道，膀胱经从头顶下行到鼻根，络却和通天就是鼻子的‘远端开关’。我治过一个鼻窦炎十年的病人，鼻子完全闻不到味道。我扎迎香、通天、络却、合谷，三次以后，他说闻到饭香了。为什么？因为膀胱经的气通了，鼻窍自然开。”

- **倪师在《人纪》中穿插的总结**：
  “头顶的穴道，你不要小看。百会、通天、络却、玉枕，这一排下来，是阳气从头走到颈的通道。阳气通，头面七窍都通；阳气堵，头晕、耳鸣、鼻塞、眼花全来了。络却就是这条通道上的一个关口，你把它打开，后面的气就顺了。”
