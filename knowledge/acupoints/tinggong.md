# 听宫

## 📍 经络归属与精准取穴法

- **所属经络**：手太阳小肠经。听宫是手太阳小肠经与手少阳三焦经、足少阳胆经的交会穴。注意——它不是五输穴（井荥输经合），也不是原穴、络穴、郄穴、募穴、背俞穴或八会穴。它是**手足少阳与手太阳之会**，《针灸大成》里列得很清楚。在五行属性上，听宫本身不直接归五行，但倪师在讲小肠经时反复强调：小肠属火，心与小肠相表里，听宫的耳窍开阖功能根源于小肠经气血的蒸腾上达。

- **倪师动态取穴与骨度折量法**：听宫在哪里？嘴巴一张开，耳屏正前方就有一个凹陷，那个凹陷就是听宫。倪师原话的意思是——你叫病人把嘴巴张开，耳屏前面那个坑就出来了，你用手一按，正好按在颧弓下缘、下颌骨髁状突的后方。**关键手法**：一定要让病人张口取穴，闭口穴就没了。下针的时候，针尖微微向内、向下，直刺或微向后斜刺，深度**五分到一寸**。倪师在讲耳部穴位时特别提醒：听宫、听会、耳门这三个穴靠得非常近，耳门在听宫上面，听会在听宫下面，但取穴和主治都在耳窍。**禁灸**——耳朵前面的穴位不要灸，一灸耳朵就聋了，这是倪师反复强调的死规矩。针也不宜过深，过深伤及耳道深部组织。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师讲小肠经时讲过，小肠者，受盛之官，化物出焉，属火。手太阳小肠经的经气从手小指少泽穴一路循行上来，经过腕、肘、肩，从颈项上到面颊，最终入耳中。听宫正是小肠经气入耳的门户。**它的开阖机理是什么？** 倪师用一句话讲透——耳朵之所以能听，靠的是肾气通于耳，而小肠经的经气到达耳窍，是把心火下济于小肠之后、小肠蒸化出来的清阳之气上奉到耳。所以听宫不是在治耳朵本身，是在**打开耳窍与小肠经气之间的那道门**。耳聋、耳鸣，如果是小肠经气堵在上面下不来，针听宫一开，气一通，耳朵就灵了。它偏于开窍醒神、通利耳窍，不是引火归元的路子，也不是健脾行水的路子——那是足三里、阴陵泉的活。听宫的本事就在耳朵这一亩三分地上。

- **子母补泻与五行生克**：听宫不在五输穴体系里，所以没有直接的子母补泻。但倪师讲过一个心法：小肠经属火，它的母穴是后溪（木生火），子穴是小海（火生土）。如果耳朵的问题伴随小肠经的虚实——比如小肠火太旺、耳内轰鸣，你可以在小肠经的子穴小海上下针泻之，再取听宫开耳窍，这叫**泻子开窍**。如果是小肠经气虚、耳内蝉鸣低微，你取小肠经母穴后溪补之，再取听宫通窍，这叫**补母启闭**。倪师的意思从来是活的——穴是死的，法是活的。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：听宫是**耳病第一穴**。倪师在临床上主要用它治：耳鸣、耳聋（突发性耳聋尤其有效）、耳内流脓、聤耳。此外，因为它靠近下颌关节，倪师也用它治下颌关节痛、牙关紧闭。癫痫、狂证有时也取听宫，因为耳窍通脑，开耳窍可以醒神。小儿惊风、耳朵听不见的，听宫也是要穴。注意——听宫不治全身病，它就是一个**局部通窍穴**，不要指望它去调脾胃、补肾腰。

- **倪师经典对穴与排针组合**：
    - **听宫 + 听会 + 耳门**：三穴齐下，专攻耳聋耳鸣。倪师说这三个穴像三兄弟站在耳朵前面，一起下针，耳窍大开。
    - **听宫 + 翳风 + 中渚**：这是倪师常用的耳病组合。翳风在耳后，中渚在手少阳三焦经上，专治耳聋。三穴合用，从耳前、耳后、手部三路围攻耳病。
    - **听宫 + 外关 + 足临泣**：外关通阳维，足临泣通带脉，这组配穴倪师用来治少阳经气堵在耳部引起的偏头痛伴随耳鸣。
    - **听宫 + 合谷 + 太冲（开四关）**：如果耳病伴随全身气机郁闭，先开四关，再取听宫，气通了耳朵才开。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲手太阳小肠经时，讲到听宫这一段，原汁原味的话是这样的——

“听宫这个穴，你看嘴巴张开，耳屏前面那个洞，就是听宫。你叫他嘴巴张开，针下去，五分到一寸。耳朵的问题，耳鸣、耳聋，听宫是近取穴，效果很好。但是记住，耳朵前面的穴道统统**禁灸**，你一灸，耳朵就聋掉了，变成终身耳聋，这是大原则。”

倪师还讲过一个临床上的体会：“耳朵突然听不见的，你针听宫、针听会，针下去病人就讲，哎，听到了。这个不神奇，因为气通了嘛。耳朵不是真的坏了，是气堵到了，你把它打开就好了。”

还有一个医案故事，倪师讲过：有个病人耳鸣三个月，西医说是神经性耳鸣，治不好。倪师一看，病人在小肠经上有压痛点，就在听宫下针，配合中渚、翳风，针了三次，耳鸣就停了。“你叫西医去治耳鸣，他给你吃类固醇，吃到月亮脸也治不好。为什么？因为他不知道耳朵是小肠经气上来的门户。你把门户打开，气通了，耳鸣自己就停了。”——这是倪师在课堂上拍着桌子讲的。
