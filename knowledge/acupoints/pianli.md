# 偏历

**定位：** 前臂背面桡侧，阳溪与曲池连线上，腕横纹上 3 寸  
**归经：** 手阳明大肠经（LI6）  
**功效：** 通调水道，清热利湿

## 📍 穴位定位

前臂背面桡侧，阳溪与曲池连线上，腕横纹上 3 寸

---

## 🔍 取穴方法

### 标准定位
**《针灸大成》：** "在腕后三寸。"

### 取穴方法
1. **简便取穴法：** 阳溪与曲池连线上，腕横纹上 3 寸。
2. **骨度分寸法：** 前臂背面桡侧，阳溪与曲池连线上。

### 解剖结构
- **肌肉：** 桡侧腕长伸肌、拇短伸肌
- **神经：** 前臂背侧皮神经、桡神经
- **血管：** 桡动、静脉分支

## 💡 功效主治

### 功效
- **通调水道** — 水肿、小便不利
- **清热利湿** — 耳鸣、鼻衄
- **疏经通络** — 手腕酸痛

### 主治病证

**倪海厦：**
> "偏历为大肠经络穴，别走太阴肺经。
> 肺与大肠相表里，偏历通调水道，治水肿。
> 鼻衄、耳鸣，偏历可清肺热、通耳窍。"

| 系统 | 病证 |
|------|------|
| **水液病** | 水肿、小便不利 |
| **耳鼻病** | 耳鸣、鼻衄 |
| **经络病** | 手腕酸痛、肩膊酸痛 |
| **其他** | 口干、喉痹 |
