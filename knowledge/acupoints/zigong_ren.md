# 紫宫二

## 📍 经络归属与精准取穴法

- 紫宫二属任脉。任脉者，起于中极之下，以上毛际，循腹里，上关元，至咽喉，上颐循面入目。任脉为“阴脉之海”，总任一身之阴经，紫宫二正在胸骨正中线上，为任脉之气上达胸膺、转输心肺宗气之要站。
- 紫宫二非五输穴，亦非原络郄募俞，然其位在膻中之上、华盖之下，为任脉与肾经、胃经、心肺之气交会之所。倪师常言：“任脉诸穴，不可只当一条线看，要知它前面是胸骨，后面是心肺，里面是宗气与肾气相通之路。”紫宫二居任脉胸段，上承华盖、璇玑之天气，下接膻中、中庭之宗气，为气机升降之枢纽。
- 其穴性属阴中之阳，以调胸中气机、宣肺利膈、宽胸止痛、降逆平喘为主。五行属金，与肺相应；又因任脉通肾，故兼有纳气归元之能。倪师言：“胸骨上这些穴，你当它是气机升降的电梯按钮，按对了，上面闷住的气就往下走，下面提不上来的气就往上提。”

- 倪师取穴，不主张死记肋骨分寸，而重“骨度折量”与“动态揣穴”。紫宫二在胸骨正中线上，平第二肋间。倪师说：“你先找天突，天突在胸骨上窝正中间，你手指按进去有个坑，那就是天突。从天突往下，你摸到胸骨柄和胸骨体交界那个微凸的横嵴，这叫胸骨角，平第二肋。胸骨角正中间就是紫宫二。”
- 若患者胖瘦不同，倪师教“以指循骨”：食指从胸骨上窝往下推，推至胸骨角最凸处，以指甲轻掐一横纹，此即紫宫二。再以同身寸验证：天突至膻中为八寸，紫宫二在天突下二寸五分许。倪师强调：“不要拿尺子量，要用手摸骨。胖人胸骨陷在肉里，瘦人胸骨凸出来，你摸到骨头再定穴，才不会扎到肋骨缝里去。”
- 下针手法：倪师取紫宫二，多用平刺或斜刺，针尖向下，沿胸骨表面刺入三至五分。绝不可直刺深入，因胸骨后方即纵隔、心包、大血管，深刺则危。倪师厉声告诫：“胸骨上的穴，一律平刺，贴着骨头走，针尖向下，像滑滑梯一样滑下去，不要立起来扎。你立起来一扎，后面就是心脏，那就是闯大祸。”
- 禁灸与否：倪师认为紫宫二可灸，但宜少灸、轻灸。若用艾条悬灸，距皮肤三寸，灸五至七分钟即可，以温通胸阳。若用化脓灸，则非其所宜，因胸骨表面皮肤薄，易伤及骨膜。倪师言：“胸骨上灸，意思到了就行，不要灸到出水泡，那会留疤，而且胸骨发炎很麻烦。”

## ⚡ 倪师经穴气化与破局心法

- 倪师推演紫宫二的气化，首重“宗气”。他说：“宗气积于胸中，出于喉咙，以贯心脉而行呼吸。紫宫二就在宗气之海上头，它像一个阀门，管着胸腔里气的开阖。”肺主气，司呼吸，紫宫二平第二肋间，内应肺之上叶，故刺之能宣肺气、利膈膜、开胸中郁结。
- Secondly，紫宫二又关乎“肾气上承”。倪师讲任脉与肾经相通，他说：“任脉是阴脉之海，肾经也属阴，肾气要上来到喉咙，必经任脉。紫宫二就是肾气上来的一个中间站。有些人肾不纳气，吸气吸不到底，你针紫宫二，再配关元，气就下去了。”此即“降逆纳气”之理。
- Thirdly，紫宫二有“开胸利膈”之功。倪师常以“胸中如天”作比，紫宫二如天中之云门，刺之能使胸中阴霾消散，阳光普照。对胸痹、心痛、咳逆、喘促，皆有破局之效。

- 子母补泻：紫宫二五行属金，对应肺。肺属金，其母为脾土，其子为肾水。倪师言：“紫宫二本身不是五输穴，不能直接补母泻子，但你可以用它来调肺金的气机。肺虚的人，你针紫宫二，再针太渊（肺经母穴），这就是补母；肺实的人，你针紫宫二，再针尺泽（肺经子穴），这就是泻子。”
- 更深一层，倪师从五行生克论紫宫二与肝木、心火的关系：“胸中气郁，往往是肝木侮金。你针紫宫二，再针太冲，平肝木，肺金就安宁了。胸中火旺，心火刑金，你针紫宫二，再针少府，泻心火，肺金就清凉了。”此即“隔二隔三”之治法，倪师谓之“不要头痛医头，要看到五行生克的链条”。

## 🎯 临床主治与配穴组合手印

- 急症救逆：紫宫二配膻中、内关，治突发胸痛、胸闷欲绝、气短不足以息。倪师言：“有人胸口突然闷住，像一块石头压着，你针内关、公孙，再针紫宫二，针一下去，病人就喘过气来了。”
- 慢性调理：紫宫二配肺俞、膏肓，治久咳、虚喘、肺痨。倪师说：“膏肓治虚劳，紫宫二开胸，两个配起来，一补一开，肺就活了。”
- 妇科：紫宫二配膻中、太冲，治乳痈、乳少、胸胁胀满。倪师言：“妇人乳房属胃，乳头属肝，但胸中气机不畅，乳汁也不通。紫宫二开胸，膻中理气，太冲平肝，乳汁就下来了。”
- 儿科：紫宫二配天突、列缺，治小儿咳喘、喉中痰鸣。倪师说：“小儿推拿，你揉紫宫二，再揉天突，痰就化开了。不要用针，用手指揉，三百下。”
- 痛症：紫宫二配内关、阳陵泉，治胸胁痛、肋间神经痛。倪师言：“胸胁痛，你针阳陵泉（筋会），再针内关（心包络），再针紫宫二，针尖向下，气就顺了。”

- 倪师经典对穴：
  - 紫宫二 + 膻中：宽胸理气，治一切胸中气机病。
  - 紫宫二 + 内关 + 公孙：治胃心胸之疾。倪师说：“公孙内关，管胃心胸，你再加紫宫二，就是三层保险。”
  - 紫宫二 + 太渊 + 尺泽：调肺金虚实。虚补太渊，实泻尺泽，紫宫二居中调气。
  - 紫宫二 + 关元：降逆纳气，治肾不纳气之喘。
  - 紫宫二 + 太冲：平肝开胸，治肝气郁结之胸闷。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师讲紫宫二，原话实录：“紫宫二这个穴，在胸骨角上。你们不要小看胸骨上这些穴，它离心脏最近，离肺最近，气机一乱，这里最敏感。病人一来，说胸口闷，你手一按紫宫二，他哎呀一声，那就是气堵在这里了。你针一下去，平刺，针尖向下，他马上觉得胸口松了。为什么？因为气往下走了。”
- 手下针感体会：倪师说：“针紫宫二，手下感觉是空的，像针在骨头上滑。你不要捻转太厉害，因为下面是骨头，捻多了病人痛。你轻轻进去，得气后，病人会觉得胸中有东西在动，像水波一样散开。这就是气机开了。”
