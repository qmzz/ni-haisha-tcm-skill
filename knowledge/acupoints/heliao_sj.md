# 和髎

## 📍 经络归属与精准取穴法

- **所属经络**：手少阳三焦经。和髎为手少阳三焦经、足少阳胆经、手太阳小肠经之**三脉交会穴**——此穴是三焦经与胆经、小肠经气血交汇之所，三焦经气血在此冷降后化为地部经水，故为三经交会。
- **穴性定位**：和髎并非五输穴（井荥输经合），亦非原络郄募俞八会等特定穴。它是**手少阳三焦经在耳门之前的最后一个腧穴**，紧接耳门穴，位于耳廓根前方。倪师讲三焦经时强调：三焦经在耳部周围布穴极密，耳门、和髎、颅息、瘈脉一路排过去，各有各的气化层次。和髎所处的位置，正好是**手足少阳与手太阳三气交汇的关卡**，相当于三焦经气从颅侧转向耳前的一个“转弯处”。
- **倪师动态取穴与骨度折量法**：
  - 先找**耳门穴**——张口时耳屏上切迹前方凹陷处。倪师原话：让病人把嘴巴张开，耳屏前面会出现一个洞，那个洞就是耳门。
  - 和髎在耳门之前，**约在耳廓根前缘，颧弓上缘**。你用手指从耳门往前推，推到耳廓根部前方、颧弓上缘的凹陷处，摸到一个小坑，那就是和髎。
  - 倪师教取穴时反复讲：**“你要去摸骨，不要死记寸数。”** 颧弓你摸得到——颧骨往后延伸的那一条横骨就是颧弓。和髎就在颧弓上缘、耳廓根前缘交角处的凹陷中，用手掐一下，病人会有酸胀感。
  - **下针深度**：**浅刺，针入二至三分**，不宜深刺。此处皮下就是颞浅动脉和耳颞神经，深刺容易出血。
  - **禁针禁灸法则**：倪师在针灸篇中特别警告——**和髎禁灸**。此处靠近耳部和颞浅动脉，艾火一烧容易伤及血脉与耳窍。下针宜浅、宜快，不留针或短留针，出针后按压针孔片刻以防出血。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：和髎的气血特征为**空虚态**——三焦经上行的气血至和髎处已化为冷降的地部经水，穴内气血如同云气般飘散无力。倪师推演此穴的机理时说：三焦经一路从无名指走到耳部，中途经过肩颈、颅侧，阳气在耳周被打开。和髎所处的位置是**耳窍之前的前哨站**。它的核心功能是**开耳窍、疏风热、通络止痛**——当风热之邪壅塞耳窍，或三焦气机在耳前区域堵塞不通时，和髎就是引气开闭的开关。
- **子母补泻与五行生克运用心法**：和髎非五输穴，不能直接套用“虚则补其母、实则泻其子”的井荥输经合补泻。但倪师讲五行生克时强调：**三焦经属相火，胆经属木，小肠经属火。** 和髎是三经交会，木生火、火生土，当胆木郁而化火、三焦相火妄动时，和髎可作为**疏木泻火**的辅助穴。手法上以**浅刺、点刺、雀啄泻法**为主——因为此穴气血本虚，不宜久留，点到即止，引气一通即可。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **耳部急症**：耳鸣、耳聋、耳中痛、耳内生疮——尤其是**突发性耳聋、风热耳鸣**，和髎配耳门、听宫、听会，一针下去耳窍就开了。
  - **头面痛症**：偏头痛（少阳头痛）、颞部疼痛、面瘫、面肌痉挛——和髎正在颞侧，对少阳经循行部位的偏头痛有特效。
  - **口眼歪斜**：面瘫初期，和髎配地仓、颊车、阳白，能疏风通络、引气达面。
  - **牙关不利**：下颌关节痛、张口困难——和髎近颧弓与下颌关节，可通利关节。
- **倪师经典对穴与排针组合**：
  - **和髎 + 耳门 + 听宫 + 听会**：耳三针加和髎，专治耳鸣耳聋。倪师讲耳部取穴时，听宫（小肠经）主耳聋如物填塞，听会（胆经）主耳鸣不止，耳门（三焦经）主耳中痛，和髎在前方引气，四穴合用，**耳窍前后内外全部打开**。
  - **和髎 + 太阳 + 率谷 + 风池**：偏头痛排针。太阳点刺放血，率谷沿皮透刺，风池引气下行，和髎在前方局部通络，**少阳经从头到颈一条线全部疏通**。
  - **和髎 + 合谷 + 太冲（开四关）**：面瘫、口噤不开时用。四关调气血，和髎局部通络，上下呼应。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原话**：和髎这个穴，在耳门的前面。你看，耳门已经快到耳朵了，和髎还在它前面一点。你摸那个颧弓，颧弓的上缘、耳朵根的前面，有一个凹下去的地方，那就是和髎。
- **针法体会**：倪师讲下针时说——**“这个地方针下去，不要深，两三分就好。你针一下去，病人耳朵前面会有麻电感，有时候会传到耳朵里面去，那就到位了。”** 他强调，和髎下针后，病人如果觉得耳内有一股气在动、或者耳内突然通了的感觉，那就是气至病所。
- **实战案例**：倪师在针灸篇中讲过一个案例——有病人突发耳聋，西医说要开刀。倪师取耳门、听宫、听会、和髎，和髎用点刺法，针入两分即出。病人当场就说耳朵里有声音了，像什么东西通了。倪师说，**“和髎是前方的引气穴，气要从前面引到耳朵里面去，前面不开，后面针再多也没用。”**
- **针灸秘要**：倪师再三告诫——和髎**禁灸**。为什么？因为这个地方有颞浅动脉和静脉，你用艾火一烤，血管一扩张，容易出血，血瘀在耳前反而添病。所以和髎**只针不灸，浅刺速出，出针按孔**，这是规矩。
