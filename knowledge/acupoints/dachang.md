# 大迎

## 📍 经络归属与精准取穴法

- 大迎穴归属**足阳明胃经**。足阳明胃经多气多血，五行属土，为十二经中气血最盛之经。大迎并非井荥输经合五输穴，也不属原穴、络穴、郄穴、募穴、背俞穴、八会穴等特定穴体系，它是胃经在面颊部的重要穴位，位置在下颌骨转角前方，专门作用于口齿、面颊、下颌这一片区域。

- **倪师动态取穴心法**：倪师讲穴位从不叫你死记“某某寸”，一定是先摸骨头。大迎怎么找？你先让病人把下巴微微往前伸、或者咬牙，你会看到下颌角前方有一条隆起的肌肉——那是咬肌。沿着这条肌肉往上摸，摸到下颌骨的下缘，在下颌骨下缘、咬肌前缘的凹陷处，就是大迎。更直白地说：你从地仓穴往下摸，摸到下颌骨的角上，在骨头边缘的凹陷里，按下去有酸胀感，那就是大迎。倪师常说“穴道在骨边、筋边、凹陷处”，大迎正是标准的“骨边穴”。

- **下针深度与角度**：大迎穴**斜刺或平刺0.3～0.5寸**，针尖朝向地仓或颊车方向透刺。因为这个地方有面动脉经过，倪师特别强调：**避开动脉**，下针前先用手指拨开血管，看到或摸到跳动的地方不要扎。**禁灸**——面部穴位一般不灸，大迎尤其不宜直接灸，会留疤。禁针的情况：面部有感染、溃疡时不可针。

- 倪师取穴从来不靠尺子量，靠的是“手感”——摸到骨缝、摸到凹陷、摸到病人喊酸，那就对了。大迎就是这样一个“以手代尺”的典型穴位。


## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：足阳明胃经的气血从承泣开始，一路往下走，经过四白、巨髎、地仓，然后到大迎。大迎所处的位置，正是胃经气血从面部向下颌、向颈部传导的**关键枢纽**。倪师讲，胃经的气血在这个位置有一个“分流”：一部分继续向下走颊车、下关，另一部分通过大迎这个口子，向内灌注到口齿、牙龈、下颌关节。所以大迎的气化功能，核心就四个字——**通利口齿**。

- 从开阖的角度看，大迎像是一个“闸门”。当风寒外邪闭阻胃经，或者胃火上炎壅塞面颊时，这个闸门就关住了，气血过不去，于是出现面颊肿痛、牙关紧闭、口眼歪斜。大迎的作用就是**重新打开这个闸门**，让胃经的气血重新灌注到面颊口齿区域。倪师常说“穴道就是气血的开关”，大迎正是面颊部的开关。

- **五行生克与子母补泻心法**：胃经属土，大迎本身非五输穴，因此不直接参与“虚则补其母、实则泻其子”的子母补泻配穴体系。但倪师在临床中运用大迎时，常从**胃经整体气血虚实**来考虑。若胃经实热上攻，面颊红肿、牙痛剧烈，可在泻内庭（胃经荥穴，属水，水为土之子，实则泻其子）的同时，取大迎局部点刺放血或针刺泻法，引火热下行。若胃经气血不足、面肌萎软无力，可在补足三里（胃经合穴，属土，土为土之本穴）的基础上，取大迎用补法或温针（但面部禁灸，多以轻柔捻转补法为主），引气血上荣面颊。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **面颊肿痛、牙关紧闭**——大迎是面颊局部消肿开噤的第一选择。腮腺炎、下颌淋巴结炎、颞颌关节炎引起的面颊肿胀、张口困难，大迎配颊车、下关、合谷，效果立竿见影。
  2. **牙痛（尤其是下牙痛）**——下牙属于胃经循行区域，胃火牙痛取大迎配内庭、颊车，泻胃火而止痛。倪师常讲“上牙痛取合谷，下牙痛取大迎、内庭”，这是分经论治的典范。
  3. **口眼歪斜（面瘫）**——大迎配地仓、颊车、阳白、合谷，是倪师治疗面瘫的常用排针组合。大迎在这里的作用是“引气到颊”，帮助面部肌肉恢复张力。
  4. **面颊部疼痛、三叉神经痛**——大迎配下关、听宫、翳风，局部近取与远端远取结合，通络止痛。
  5. **口噤不语、舌强难言**——大迎配廉泉、通里、哑门，开关利窍。

- **倪师经典对穴与排针组合**：
  - **大迎 + 颊车 + 下关**：面颊三穴齐下，专治面颊肿痛、颞颌关节紊乱、牙关紧闭。倪师排针讲究“包围之势”，三穴从不同角度向面颊中心透刺，形成合围，气血无处不到。
  - **大迎 + 合谷 + 内庭**：这是治牙痛和面颊肿痛的“铁三角”。合谷通面口，内庭泻胃火，大迎局部开闸，三穴一上一下一局部，层层递进。
  - **大迎 + 地仓 + 阳白 + 合谷**：面瘫专用组合。倪师针面瘫常取患侧，大迎和地仓相互透刺，再加阳白提眉、合谷通络，形成“面瘫复原阵”。
  - **大迎 + 翳风 + 听宫**：耳前耳后区域的疼痛、下颌关节痛，三穴合力疏通少阳阳明经气。


## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲到大迎穴时，原话大意是：“**大迎在下颌骨这个地方，你摸，骨头旁边有个凹洞，咬牙的时候咬肌会鼓起来，就在咬肌前面、骨头下缘的凹陷里。** 这个穴道专门治什么？面颊肿、牙关打不开、牙痛。你下针的时候，针尖朝着地仓的方向透过去，不要直直地扎，因为下面有动脉，你要先摸一摸，有脉动的地方闪开。”

- 倪师在面瘫的章节里特别提到：“面瘫的病人，地仓透颊车是主穴，但你不要忘了大迎。**大迎一下去，整个面颊的气就活了。** 你看他脸颊歪的、垮的，大迎针下去，再用补法轻轻捻转，那个脸颊的肉就会慢慢回来。这个穴道看起来不起眼，但在面部是很好用的。”

- 倪师讲牙痛时有一段非常生动的实战体会：“**下牙痛，你针大迎、内庭，针一下去，病人马上说‘哎，不痛了’。** 为什么？因为胃经的火从这里泄掉了。内庭是荥穴，荥主身热，大迎是局部开关，两个一配合，火有出路，痛就止了。你不要只知道合谷，合谷是通用的，但分经论治才是针灸的精髓。”

- 倪师在讲针刺手法时还说过一个细节：“大迎这个穴道，**针下去不要深，三分到五分就够了**，因为底下就是骨头和血管。你针尖进去，病人有酸胀感，那就到了。面部的穴道都是这样，浅浅的、轻轻的，不要像扎环跳那样猛。你猛扎，病人脸肿起来，那就不是治病，是添病了。”

- 倪师的医案里有一个经典场景：一位五十多岁的妇人，早上起来突然嘴巴歪到一边，眼睛闭不上，脸颊肿得老高。倪师取患侧地仓透颊车、大迎、阳白、四白，加双侧合谷，针了三次，脸颊消肿，嘴巴正了七成，再针五次，基本恢复。倪师总结说：“**面瘫要早针，大迎要早用，拖久了气血僵在那里，恢复就慢了。** ”
