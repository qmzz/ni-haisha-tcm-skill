# 中枢

## 📍 经络归属与精准取穴法

- **所属经络**：中枢穴属**督脉**。督脉者，起于少腹以下骨中央，女子入系廷孔，循阴器，合篡间，绕篡后，别绕臀，至少阴与巨阳中络者合，少阴上股内后廉，贯脊属肾，与太阳起于目内眦，上额交巅上，入络脑，还出别下项，循肩膊内，挟脊抵腰中，入循膂络肾；其男子循茎下至篡，与女子等；其少腹直上者，贯脐中央，上贯心，入喉，上颐环唇，上系两目之下中央。督脉为“阳脉之海”，总督一身之阳经。中枢穴位于背部，为督脉阳气在背脊中段转输之关键穴，脊中与筋缩之间。

- **五输穴/特定穴属性**：中枢穴**不属于五输穴**（督脉无井荥输经合），亦**非原穴、络穴、郄穴、募穴、背俞穴、八会穴**。但它在督脉中处于重要位置——第10胸椎棘突下凹陷中。其下平**胆俞**，内应**肝、胆、脾、胃**之气。倪师常言：督脉上的穴位，不要拘泥于特定穴名，要看它**当第几椎、下方应何脏腑**，这才是活法。中枢正当第10椎下，第10椎平**胆俞**，故中枢与**胆、脾、胃**关系密切。胆为中正之官，主决断；脾胃为后天之本，主运化。中枢穴有**调理中焦、疏利胆气、健脾和胃**之功。从五行生克看：胆属木，脾胃属土。木能疏土，亦能克土。中枢位于胆俞之上，故其气化与**木土关系**最为相关——木气太过则克土，木气不及则土壅。中枢为转枢之地，能**调木以安土**。

- **倪师动态取穴与骨度折量法**：倪师讲督脉穴位，从不要求学员死记“第几椎下”，而是教大家**先找大椎，再找至阳，再找命门，然后用手去摸**。具体手法如下：
  1. **俯卧或正坐低头**，使背部肌肉放松，棘突间隙张开。
  2. **从大椎往下数**：大椎为第1椎上（第7颈椎棘突下），第1胸椎棘突下为陶道，第2胸椎棘突下为身柱，第3胸椎棘突下为神道，第4胸椎棘突下为灵台，第5胸椎棘突下为至阳，第6胸椎棘突下为灵台（注意：此处倪师讲义有混用，实际第6椎下为灵台，第7椎下为至阳者，当以《针灸大成》为准，此处从倪师口语习惯——从至阳再往下数）。
  3. **简便定位**：倪师说，你让病人趴着，**先找到肩胛骨下角**，平第7胸椎棘突下，即**至阳穴**。至阳再往下数：第8椎下为**筋缩**，第9椎下为**中枢**（注：倪师讲义中有时将筋缩与中枢互换，但根据《针灸大成》，筋缩在第9椎下，中枢在第10椎下。倪师强调，临床以**摸到凹陷**为准，不必死抠椎数。你摸到至阳后，往下两个凹陷就是中枢，往下三个凹陷就是筋缩，再往下就是脊中。重要的是**下针时手指要按住穴位下方的椎骨，向上推，使穴位暴露**）。
  4. **进针深度**：倪师说，督脉上的穴位，**一般针3到5分，最多不超过8分**。为什么？因为督脉在脊中，**两旁是膀胱经**，**下面就是脊髓**。针太深，会伤到脊髓，那是大忌。所以**进针要浅，得气即止**。得气的感觉是**酸、麻、胀**，有时会**往上下扩散**。
  5. **禁针禁灸**：督脉穴位在背部，**一般不禁灸**，但**中枢穴要注意**——倪师说，如果病人**有内热、有炎症、有出血倾向**，不要灸。至于**禁针**，中枢穴**不禁针**，但**孕妇禁针**，因为督脉与任脉相通，针督脉可能动胎气。另外，**小儿囟门未闭者，背部穴位慎针**。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：倪师讲，督脉是**阳脉之海**，行于背脊。中枢穴在第10椎下，**内应肝胆脾胃**。它的气化机理，可以从三个层次看：
  1. **转枢中焦**：中枢者，**中焦之枢**也。脾胃在中焦，肝胆亦在中焦。中枢穴能**调畅中焦气机**，使清者上升，浊者下降。倪师说，很多人**胃胀、胁痛、消化不良**，其实是**中焦气机卡住了**，就像门轴生锈了。中枢就是**给门轴上油**的穴位。针中枢，能**疏利肝胆，健脾和胃**，使木不克土，土不壅木。
  2. **升提中气**：中枢位于背部中段，**督脉阳气在此转输**。倪师说，**中气下陷**的人——胃下垂、子宫下垂、脱肛、久泻不止——是因为**督脉阳气升不上去**。中枢能**升提中气**，就像**用手把下陷的东西往上托**。针中枢，配合百会、气海，效果很好。
  3. **开窍醒神**：督脉入络脑。中枢虽不在头部，但**督脉之气相通**。倪师说，**癫痫、癫狂、小儿惊风**，有时是**痰浊蒙蔽清窍**。中枢能**化痰开窍**，因为它在肝胆脾胃之交，能**斩断生痰之源**。针中枢，配丰隆、人中，能**醒神开窍**。

- **子母补泻与五行生克**：督脉无五输穴，故**无严格子母补泻**。但倪师说，我们可以**借用脏腑五行**来用中枢。中枢内应**胆（木）与脾胃（土）**。**木生火，火生土**——这是相生。**木克土**——这是相克。临床心法：
  - **虚则补其母**：若**脾胃虚寒**（土虚），当**补火**——火为土之母。火在脏腑为**心、小肠**。可针**心俞、小肠俞**，或灸**关元、气海**，再配中枢，以**火暖土**。倪师说，这就是**“虚则补其母”**的变通用法。
  - **实则泻其子**：若**肝胆火旺**（木实），当**泻火**——火为木之子。火在脏腑为**心、小肠**。可针**少府、前谷**（心与小肠之荥穴），再配中枢，以**泻木之子**，使木不克土。倪师说，这就是**“实则泻其子”**的活用。
  - **木土同调**：若**木不疏土**（肝胆气滞，脾胃壅塞），当**疏通木土**。针中枢，配**太冲、足三里**。太冲为肝经原穴，足三里为胃经合穴。一木一土，一疏一运，**木土同调**，中焦自安。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **急症救逆**：中枢能**升提中气**，故可用于**中气下陷之脱证**——如**胃下垂、子宫脱垂、脱肛**。倪师说，急症时，针中枢配**百会（灸）、气海（灸）**，能**升阳举陷**，救人于顷刻。
  2. **慢性病调理**：中枢能**调理中焦**，故可用于**慢性胃炎、胃溃疡、十二指肠溃疡、消化不良、胁痛、黄疸**。倪师说，这些病，**根在木土不和**。针中枢，配**肝俞、胆俞、脾俞、胃俞**，能**调木安土**，缓图其功。
  3. **妇科/儿科特效**：中枢能**调畅中焦**，故可用于**月经不调、痛经、带下**。倪师说，妇科病，**多从肝脾论治**。针中枢，配**三阴交、血海、关元**，能**调肝脾，和气血**。儿科方面，中枢能**化痰开窍**，故可用于**小儿惊风、癫痫**。针中枢，配**人中、丰隆、涌泉**，能**醒神开窍**。
  4. **痛症特效**：中枢位于背部，故可用于**背痛、脊强、胁痛**。倪师说，**脊强**的人，**督脉阳气不通**。针中枢，配**大椎、至阳、命门**，能**通督止痛**。**胁痛**的人，**肝胆气滞**。针中枢，配**支沟、阳陵泉**，能**疏肝利胆**。

- **倪师经典对穴与排针组合**：
  1. **中枢配至阳**：至阳在第7椎下，中枢在第10椎下。两穴同属督脉，**一上一下**，能**通调督脉阳气**。倪师说，**背痛、脊强、中气下陷**，针至阳、中枢，**上下呼应**，效果倍增。
  2. **中枢配筋缩**：筋缩在第9椎下，中枢在第10椎下。两穴相邻，能**舒筋活络**。倪师说，**抽搐、痉挛、筋急**，针筋缩、中枢，能**柔筋缓急**。
  3. **中枢配脊中**：脊中在第11椎下，中枢在第10椎下。两穴相邻，能**健脾利湿**。倪师说，**腹泻、痢疾、黄疸**，针脊中、中枢，能**运脾化湿**。
  4. **中枢配胆俞、脾俞、胃俞**：胆俞在第10椎下旁开1.5寸，脾俞在第11椎下旁开1.5寸，胃俞在第12椎下旁开1.5寸。中枢与三俞**同平面或相近**，能**肝胆脾胃同调**。倪师说，**木土不和**之证，针中枢，再针胆俞、脾俞、胃俞，**前后呼应**，能**调木安土**。
  5. **中枢配太冲、足三里**：太冲为肝经原穴，足三里为胃经合穴。中枢配二穴，能**疏肝健脾**。倪师说，**肝胃不和**的人，**胁痛、胃胀、反酸**，针中枢、太冲、足三里，能**木土同调**，诸症自平。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师讲此穴的原汁原味逐字稿金句**：
  > “中枢这个穴，在第十椎下。你摸，从大椎往下数，数到第十个，就是中枢。它下面就是胆俞。所以中枢跟胆有关系。胆是中正之官，主决断。胆气不顺，人就**犹豫不决、胁痛、口苦**。针中枢，能**疏利胆气**。”
  > “中枢能**升提中气**。什么叫中气？就是脾胃之气。脾胃在中焦，中气不足，人就**胃下垂、子宫下垂、脱肛**。你针中枢，再灸百会、气海，**就像用手把下陷的东西往上托**。”
  > “督脉上的穴位，下针要浅。为什么？因为**下面就是脊髓**。你针太深，伤到脊髓，那是**大忌**。所以**进针三到五分，得气即止**。得气的感觉是**酸、麻、胀**，有时会**往上下扩散**。”
  > “中枢配太冲、足三里，能**疏肝健脾**。太冲是肝经原穴，足三里是胃经合穴。一木一土，一疏一运，**木土同调**，中焦自安。这是**子母补泻的活用法**。”

- **实战手下针感体会**：
  倪师说，针中枢，**针感很重要**。你针下去，病人会觉得**局部酸胀**，有时会**往上下扩散**。如果**针感往胁肋扩散**，说明**胆气被疏通了**；如果**针感往胃脘扩散**，说明**胃气被调畅了**；如果**针感往少腹扩散**，说明**中气被升提了**。倪师强调，**针感不到，不要强行捻转**，要**调整针尖方向**，或**让病人深呼吸**，气机自然通畅。

- **医案故事**：
  倪师讲过一个案例：一位**胃下垂**的病人，**胃脘胀满、饭后加重、形体消瘦**。倪师针**中枢、百会（灸）、气海（灸）、足三里**。针后，病人**胃脘胀满减轻**。倪师说，这就是**升提中气**的效果。他又讲过一个案例：一位**癫痫**的小儿，**发作时抽搐、口吐白沫**。倪师针**中枢、人中、丰隆、涌泉**。针后，小儿**发作减少**。倪师说，这就是**化痰开窍**的效果。他还讲过一个案例：一位**胁痛**的病人，**口苦、咽干、目眩**。倪师针**中枢、支沟、阳陵泉**。针后，病人**胁痛消失**。倪师说，这就是**疏肝利胆**的效果。
