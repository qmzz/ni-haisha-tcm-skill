# 中渚穴 (SJ3)

## 📍 经络归属与精准取穴法

- **所属经络**：手少阳三焦经。三焦经起于无名指端关冲穴，循手背第四、五掌骨间上行，过腕背阳池，沿前臂两骨间上肘，循臑外上肩，入缺盆，络心包，下膈，属三焦。中渚为三焦经之**输穴**，五行属**木**。三焦经本身属火（相火），其输穴属木，木生火，故中渚为三焦经之**母穴**。

- **倪师动态取穴与骨度折量法**：手背朝上，沿第四、五掌骨之间往上推，推到两掌骨结合处（掌指关节后方）的凹陷中，就是中渚。大白话讲：你把手握成半拳，从无名指和小指指缝往手腕方向摸，刚过掌指关节那个骨头缝里，按下去有点酸胀的地方，就是它。进针时从骨缝凹陷处直刺，针尖贴着第四掌骨外缘进，**针深五分到一寸**。此穴**可针可灸**，无特殊禁针禁灸之限，但手掌背面皮薄肉浅，下针不宜过深，过深则穿透掌骨间隙伤及掌心侧肌腱。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演气血流注与开阖机理**：三焦者，决渎之官，水道出焉。三焦经的气血从中渚这个“输穴”位置开始由浅入深、由井荥的浅表之气转入较深层的输转。倪师讲，中渚这个穴，顾名思义，“中”是中间、中枢，“渚”是水中小块陆地——水液运行当中一个关键的“中转站”。三焦主通调水道，中渚就是三焦水道在手腕以下的一个闸口。当三焦气机不利、水液停滞时，针中渚可以**通利三焦、开窍聪耳、清热散邪**。倪师常常讲，耳朵的病、偏头痛、手臂酸痛，你别看中渚在手上，它的气是往头上走的，三焦经“从膻中上出缺盆，上项系耳后”，所以耳朵堵、耳鸣、耳聋，中渚一针下去，气就通到耳朵去了。

- **子母补泻与五行生克运用心法**：三焦经属火，中渚为木穴，木生火，所以中渚是三焦经的**母穴**。倪师讲：**虚则补其母**——三焦经虚证，比如耳聋日久、听力减退、手臂酸软无力，你要补中渚，用补法（顺经而刺、捻转补法）。反过来，三焦经的实证，比如突发的耳聋耳鸣、手臂红肿热痛、偏头痛剧烈，那就要**实则泻其子**——三焦经的合穴天井属土，火生土，天井为子穴，实证泻天井。但中渚这个穴特殊，它虽然是母穴，可它本身就有很强的通窍清热作用，所以临床上半数情况不论虚实，中渚都能用，只是手法不同而已。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **耳鸣、耳聋、耳痛**：中渚是治疗耳疾的远端取穴要穴。倪师常讲，耳朵突然听不见，先扎中渚，再配耳门、听宫、听会，耳周三针加中渚，效果立竿见影。
  - **偏头痛、后头痛**：三焦经循行过耳后、上肩、入缺盆，偏头痛属少阳者，中渚是远端引流要穴。
  - **手臂酸痛、手指屈伸不利**：尤其是无名指和小指麻木、僵硬，中渚就在旁边，近端取穴直达病所。
  - **咽喉肿痛、口干**：三焦经“上项系耳后”，其气通于咽喉，中渚配少商放血，咽喉痛立减。
  - **疟疾、寒热往来**：这是《针灸大成》里明确记载的主治。倪师讲，三焦主半表半里，疟疾就是半表半里的病，中渚能和解少阳、调和寒热。

- **倪师经典对穴与排针组合**：
  - **中渚 + 耳门 + 听宫 + 听会**：耳疾四针组合，远近配穴，通耳窍如开锁。
  - **中渚 + 外关 + 合谷**：手臂酸痛、肩背痛的排针，从手背一路通到肩颈。
  - **中渚 + 足临泣**：手足少阳经同名经配穴，上下呼应，治偏头痛、目眩、胁痛，一针在手一针在足，少阳经气贯通。
  - **中渚 + 翳风 + 角孙**：治耳后肿痛、腮腺炎，三焦经与胆经同取，消散少阳郁热。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲三焦经时，讲到中渚这一段，原话大意如此：

“中渚穴怎么找？你把手背翻过来，无名指和小指，这两个掌骨之间，你从指缝往上推，推到骨头缝那个凹下去的地方，就是中渚。针下去，大概五分到一寸。这个穴，我告诉你，耳朵突然聋了、耳鸣，你扎中渚，再扎耳朵前面的耳门、听宫、听会，针一下去，病人当场就说耳朵通了。从前有个病人，坐飞机下来耳朵堵了好几天，听什么都是闷的，我在中渚上下针，用泻法，针一进去他就说‘哎，通了通了’。为什么？三焦经的的气从手上一直通到耳朵后面去，中渚就是那个开关。”

“中渚还是三焦经的母穴，属木。三焦属火，木生火，所以中渚是三焦经的妈妈。三焦经虚了，你就补中渚；三焦经实了，你泻天井。这就是《难经》上讲的‘虚则补其母，实则泻其子’。但是中渚这个穴，你别看它是补穴，它开窍的力量很强，所以实证用它来通窍，也有效，只是手法要用泻法，逆着经气方向捻针。”

倪师还强调过中渚治疟疾的用法：“《针灸大成》上说中渚主疟疾，寒热往来。疟疾就是忽冷忽热，三焦主半表半里，少阳为枢，中渚能把这个枢转开。现代人虽然不得疟疾了，但是忽冷忽热、少阳不和的症状很多，比如更年期潮热恶寒、感冒后期的往来寒热，中渚配外关、足临泣，一针就解。”
