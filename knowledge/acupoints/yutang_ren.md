# 玉堂二

## 📍 经络归属与精准取穴法

- 玉堂穴属**任脉**，位于胸膺正中线。任脉者，总任一身之阴经，为“阴脉之海”，起于胞中，出于会阴，沿腹胸正中上行，至咽喉、环唇、入目。玉堂居任脉胸段，在**紫宫下一寸六分，两乳之间膻中之上**，正当胸骨体上段之中点。非五输穴，非原络郄募，乃任脉经气在胸中段转输之要穴。
- 倪师取穴心法：找玉堂，先定**膻中**（两乳连线中点，平第四肋间），再定**紫宫**（膻中上三寸二分），紫宫再上一寸六分即是玉堂。倪师常用“**一寸一穴半寸间**”的口诀，让学子以拇指同身寸从膻中往上推，摸到胸骨正中线上第一个骨节间隙凹陷处，按之酸胀，便是玉堂。他说：“**你不要拿尺去量，拿手去摸，胸骨上那个棱棱一条，两边肋骨交会的地方，凹下去的那个点，就是玉堂。** ”
- 进针手法：倪师强调**平刺或向下斜刺**，针尖沿胸骨骨面缓缓刺入**三分至五分**，不可直刺深入。因胸骨后方即纵隔，再深则伤心肺。留针十五至二十分钟，得气即止。**禁灸**——玉堂靠近心肺，灸火之气易扰胸阳，倪师明言：“**胸膺诸穴，除了膻中可温灸，玉堂、紫宫、华盖一律禁灸，你灸了病人胸闷气短，火气窜心包，反而坏事。** ”

## ⚡ 倪师经穴气化与破局心法

- 倪师推演玉堂气化：任脉主一身之阴，阴者，藏精而起亟也。玉堂位于**膻中之上、紫宫之下**，恰是**宗气与阴津交会**之所。倪师说：“**玉堂者，玉者金之精，堂者中正之室。肺主气，心主血，玉堂居心肺之间，能调气血之交，开胸中郁结。** ”其气化机理在于**宣肺利膈、宽胸散结、降逆止呕**，使上焦之气得以肃降，中焦之气得以通调。
- 子母补泻运用：玉堂非五输，不直接套用子母补泻，但倪师以**五行归经**论之。任脉属阴，胸段应肺金。肺金虚则补其母（脾土），实则泻其子（肾水）。倪师心法：“**玉堂这个穴，你把它当成肺的门户。肺气不降，咳逆胸闷，你在玉堂上斜刺一针，再配太渊（肺经原穴）补气，配尺泽（肺经合穴）泻实，一补一泻，胸中气机就转开了。** ”若痰饮停胸、阴寒闭肺，则配丰隆、阴陵泉，导水下行，此即“**实则泻其子**”之意——泻肾水以消痰饮之根。
- 倪师特别指出：玉堂与**膻中**一气相通。膻中为气会，玉堂为气之**堂室**。膻中主气之**出**，玉堂主气之**布**。凡胸中气机不利，先取膻中开气会，再取玉堂布气津，两针相合，胸膺之郁结如云开雾散。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **胸痛胸闷、咳逆上气**：玉堂斜刺三分，配膻中、内关，宽胸理气，立见松快。
  2. **喉痹咽塞、声音不出**：玉堂配天突、廉泉，降逆开音。倪师云：“**喉中如有物梗，吞不下吐不出，玉堂针下去，气一降，喉就开了。** ”
  3. **呕吐呃逆、胃气上逆**：玉堂配中脘、足三里，降胃气如釜底抽薪。
  4. **乳腺胀痛、乳汁不通**：玉堂配乳根、少泽，通调胸络，此倪师妇科常用组合。
  5. **心绞痛、心悸怔忡**：玉堂配内关、神门，宁心定悸，为急症救逆之辅穴。

- **倪师经典对穴与排针组合**：
  - **玉堂 + 膻中 + 内关 + 公孙**：治一切**胃心胸**之疾。公孙配内关通冲脉、阴维脉，玉堂配膻中调任脉、气会，四穴合用，胸腹气机全线贯通。
  - **玉堂 + 太渊 + 尺泽**：肺经子母补泻法，治虚实咳喘。
  - **玉堂 + 中脘 + 足三里 + 内关**：治呕吐、呃逆、胃气上逆之**降逆四针**。
  - **玉堂 + 乳根 + 少泽 + 太冲**：治乳痈、乳汁不通，疏肝通络，消胀止痛。
  - 倪师急救心法：**“心痛彻背，背痛彻心，先针内关、公孙，再针玉堂、膻中，最后针心俞、厥阴俞，前后呼应，痛立减。”**

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》中讲玉堂时，原话实录：“**玉堂这个穴道，在紫宫下一寸六分。你从膻中往上找，膻中在两乳之间，紫宫在膻中上三寸二分，玉堂就在紫宫和膻中的正中间偏上。针玉堂，针下去用斜刺，不要直刺，直刺扎到胸骨上，病人痛死，你也扎不进去。斜刺沿着胸骨面下去，三分到五分，得气即止。** ”
- 倪师手下针感体会：“**针玉堂，病人会有一种热气从胸中往上冲的感觉，好像胸口开了一扇窗。有的病人当场就打嗝，或者咳出一口老痰，那是气机通了。你不要慌，这是好现象。** ”
- 医案故事：倪师曾治一妇人，**梅核气**三年，喉中如有物梗，吞不下吐不出，遍服半夏厚朴汤无效。倪师取玉堂斜刺，配天突、膻中、内关、公孙，针入五分钟，妇人突觉喉中一松，当场能咽口水，连针三次，三年之苦若失。倪师笑曰：“**玉堂开胸，天突利咽，内关公孙通阴维冲脉，气一顺，痰就化了。半夏厚朴汤治的是形，针灸治的是气，气行则形散。** ”
- 倪师又云：“**你们不要小看玉堂，它跟膻中只差一寸多，但膻中主气之会，玉堂主气之堂。膻中是广场，玉堂是厅堂。广场开，气能出；厅堂开，气能布。两个穴一起用，胸中大气一转，百病消。** ”
- 最后倪师叮嘱：“**胸膺之穴，针宜浅，不宜深；宜斜，不宜直。玉堂更是如此。你记住，胸骨后面是心和肺，你扎深了，病人气胸，你赔不起。三分五分，得气即止，这是铁律。** ”
