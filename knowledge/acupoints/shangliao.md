# 上髎

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。上髎为足太阳膀胱经在腰骶部的重要腧穴，八髎穴之一（上髎、次髎、中髎、下髎），定位在第一骶后孔中。
- **特定穴属性**：八髎穴并非五输穴体系中的井荥输经合，而是以“骶后孔”为定位标志的一组孔隙穴。倪师强调，八髎统管盆腔气化，上髎居八髎之首，对应第一骶后孔，与小肠、膀胱、子宫、大肠及腰骶神经丛关系最密。五行属性从膀胱经本气——壬水论，水能生木，与肝胆疏泄、宗筋所聚相通。
- **倪师动态取穴心法**：找上髎不能死记“第一骶后孔”，要用“手摸法”。倪师讲：先找髂后上棘，髂后上棘内下方可摸到一颗骨性突起，那就是第一骶椎的棘突下缘，旁开约一横指（1寸左右）即是上髎。另一个办法：从督脉的腰俞穴往上推，摸到第一个明显骨缝——第一骶后孔，便是上髎。倪师特别交代：八髎穴要“从上往下摸”，很多人按书上画的位置扎不准，因为骶骨有胖瘦、有弧度，必须以“手下有空隙、针尖能滑入孔中”为准。
- **下针深度**：直刺或略向内下斜刺，进针1～1.5寸。倪师说，针入骶后孔时有种“针尖滑入骨缝”的落空感，这才是扎准了。若顶在骨面上，则需上下左右稍移再探。
- **禁针禁灸法则**：八髎穴可灸，尤其适合艾灸温通盆腔。禁针的情况：孕妇腰骶部禁针，尤其上髎、次髎不可深刺，以免动胎气。局部皮肤溃烂、感染时禁针禁灸。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演气血流注**：上髎位于足太阳膀胱经第一骶后孔，是膀胱经气从腰臀转入盆腔的“第一道关口”。倪师以“沟渠灌溉”作比喻：八髎就像腰骶部的八个泉眼，上髎是最高处的泉眼，膀胱经的经气到这里如水流遇孔则渗，能直接灌入胞宫、精室、大肠、小肠。因此上髎的气化核心是“渗灌下焦、通利关窍”。若上髎闭塞，则腰骶僵紧、月经不调、小便不利、痔疾便血。
- **开阖机理**：倪师讲八髎统管“开阖”。上髎主开，次髎主阖，中髎、下髎主枢转。上髎开则盆腔气机流通，月经能下、小便能出、大便能通；上髎阖则不固，可见遗尿、带下清稀、脱肛。
- **子母补泻与五行生克**：上髎从膀胱经壬水，水之母为金（肺经），水之子为木（肝经/胆经）。虚则补其母——若膀胱经气虚、下焦失约，可配肺经太渊或膀胱经本经金穴（委中为合土，土生金，金生水，故灸委中能间接补上髎气化）。实则泻其子——若膀胱经实热、小便赤涩、痛经拒按，可配胆经阳陵泉或肝经太冲以泻木，木泻则水自清。倪师特别指出：八髎穴更偏于“通”而非“补”，临床上以通为补。上髎配关元、气海，灸之能温阳化气，这是“水中补火”的思路。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - 妇科：月经不调、痛经、闭经、带下、子宫脱垂、不孕、更年期腰骶酸痛。上髎配次髎是倪师治痛经的“腰骶双针”。
  - 男科：遗精、阳痿、早泄、前列腺增生、小便频数或癃闭。
  - 腰腿痛：腰骶关节炎、坐骨神经痛、腰椎间盘突出引起的下肢麻痛，上髎是局部取穴要穴。
  - 肛肠：痔疮、脱肛、便血、便秘。
  - 急症：急性腰扭伤，上髎点刺放血加拔罐，倪师称为“腰骶开闸法”。
- **倪师经典对穴与排针组合**：
  - **上髎 + 次髎 + 中髎 + 下髎**：八髎排针，治所有盆腔病。倪师说，这四针下去，像四把钥匙打开下焦四道门。
  - **上髎 + 关元 + 三阴交**：妇科痛经、月经不调的黄金组合。关元温下焦，三阴交调肝脾肾，上髎通局部气血。
  - **上髎 + 膀胱俞 + 中极**：膀胱气化不利、小便问题。中极是膀胱募穴，配上髎形成“俞募配穴+局部开孔”。
  - **上髎 + 大肠俞 + 长强**：痔疮、脱肛。长强为督脉络穴，上髎通骶孔，一前一后，一上一下。
  - **上髎 + 环跳 + 阳陵泉**：坐骨神经痛、下肢外侧麻痛。上髎治根，环跳治路，阳陵泉治筋。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲八髎时原话：“八髎穴，你不要一个一个去背，你只要知道它在骶骨上面。你手去摸，髂后上棘下面，一个个骨孔。上髎就是第一个孔。你针下去，要像针插到钥匙孔里面一样，有那个落空感，病人会有酸胀感往下走，甚至走到肛门、会阴那里，那就对了。”
- “妇人痛经，你针上髎、次髎，针一下去，病人腰骶一热，痛就去掉一半。为什么？因为膀胱经的阳气被引下来了。上髎是第一个关口，它一开，下面的次髎、中髎、下髎就跟着开了。八髎是连在一起的，像一排窗户，你开一扇，其他的都好开。”
- 倪师讲过一个医案：“有个太太，月经三个月不来，小腹硬邦邦的，腰酸得不能弯。我针上髎、次髎，配合三阴交、血海。针上髎的时候，她跟我说，有一股气从腰往小腹窜。留针二十分钟，起针后第二天，月经就来了。这就是上髎开阖的作用——它把闭住的气血重新打开。”
- 手下针感体会：倪师说，针上髎得气时，针体会有微微的“吸住感”，病人感觉酸胀向臀部、会阴或大腿后侧放散。若针尖顶在骨上，病人只有刺痛，无酸胀，需退针再探。灸上髎时，热感能透入盆腔，病人觉得小腹温暖，这是灸感入里。
- 倪师秘要：“八髎穴放血，治急性腰扭伤，效果如神。你用三棱针在上髎、次髎点刺，拔上火罐，血一出来，腰就能动了。这叫‘去宛陈莝’，把瘀血放掉，新血才生。”
