# 天枢穴 (ST25)

## 📍 经络归属与精准取穴法

天枢穴，归足阳明胃经。此穴是**大肠之募穴**——募穴者，脏腑之气汇聚于胸腹之处也。大肠为传导之官，变化出焉，天枢一穴，正是大肠经气直接输注于腹壁的窗口。倪师在讲大肠经时反复强调：大肠募穴不在大肠经上，而在胃经上，此中自有深意——胃与大肠同属阳明，经气相通，胃气下降则大肠传导有力，胃气上逆则大肠壅滞不通。因此天枢能通大肠，根子在胃。

天枢又是**足阳明胃经与冲脉的交会穴**。冲脉为血海，起于胞中，上行至胸腹。女子以血为本，天枢通冲脉，故能调经血、理胞宫。倪师讲妇科时常用天枢，理即在此。

**骨度折量取穴法**：天枢在腹中部，脐中旁开二寸。倪师教取穴，大白话讲：先找**神阙**（肚脐正中），以肚脐为中心，向左右各量二寸，即是天枢。二寸怎么量？倪师说，**从肚脐到我们胸骨蔽骨（鸠尾）是八寸**，从肚脐到耻骨联合上缘是五寸。用自己的手指去比，**同身寸**——中指弯曲，中节两端横纹头之间为一寸；食指、中指、无名指三指并拢，宽度为二寸。以患者自己的手为准，高矮胖瘦各不同，同身寸最准。

倪师临床取天枢，常叫病人平躺，先定神阙，再以三指并拢一搭，左右各取一穴。有时候病人腹部有脂肪，倪师会让病人**微微屈膝**，腹肌放松，穴位自然显现。若有宿便积在腹中，天枢处往往按之硬满或有压痛，这也是倪师诊断大肠通畅与否的随手一摸。

**下针深度与禁针禁灸**：天枢**直刺一寸到一寸五分**，视病人腹壁厚薄而定。倪师说，腹深如井，扎针时一定要病人**吸气**，针入后病人**吐气**，这样腹壁放松，针不易弯。天枢**可灸**，尤宜隔姜灸或艾条温和灸，对虚寒性便秘、久泄不止效果好。但倪师也告诫：**孕妇禁针天枢**，因其通冲脉、近胞宫，针之恐动胎气。腹部有肿瘤或急腹症者，不可深刺。

## ⚡ 倪师经穴气化与破局心法

天枢的气化机理，倪师从**“天”与“枢”**两个字讲透。他说，“天”者，上部之气也；“枢”者，门户之转轴也。天枢一穴，正是**中焦气机升降的枢纽**。清气上升归肺，浊气下降归大肠，一升一降，全赖天枢这个转轴灵活。转轴一卡，上面胀满，下面不通——上面打嗝嗳气，下面便秘不放屁，倪师说这种人“满肚子都是气，就是走不动”。

从五行生克看，天枢属胃经，胃为**土**。大肠为**金**，土生金，胃气下降则大肠传导有力。若胃土虚寒，不能生金，则大肠无力推动，此为**虚秘**；若胃火过盛，灼伤津液，则大肠燥结，此为**实秘**。天枢治便秘，虚实皆可，关键在于**调中焦以通下焦**。

倪师尤为重视天枢的**“引气下行”**之功。他说，很多人病在气机不降——气逆则喘、则呕、则胀。天枢能引气下行，使上逆之气归于大肠，从后阴而出。所以**气喘、呕吐、腹胀、便秘**，倪师常在天枢上做文章，一穴通而诸症平。

**子母补泻心法**：天枢为大肠募穴，大肠属金。金之母为土，金之子为水。临床若见**大肠虚证**（久泄、脱肛、肠鸣辘辘），倪师会在天枢上用**补法**——针尖向下，顺经气方向，或加艾灸，补土生金，助大肠收摄。若见**大肠实证**（便秘、腹痛拒按、里急后重），则用**泻法**——针尖向上，逆经气方向，或强刺激不留针，泻金之子水，通利大肠。倪师说，天枢一穴，补泻全在针尖方向与手法轻重，用对了，比吃药快。

## 🎯 临床主治与配穴组合手印

**核心特效主治**：

- **便秘与腹泻**：天枢是双向调节穴。便秘者，针天枢配**支沟、照海**；腹泻者，灸天枢配**足三里、三阴交**。倪师说，天枢治大肠病，不管便秘还是下利，都是**首选**。
- **腹胀、肠鸣、消化不良**：天枢配**中脘、气海**，三穴同用，中焦气机全通。
- **妇科病**：痛经、月经不调、带下，天枢配**关元、三阴交、血海**。倪师讲，天枢通冲脉，冲脉为血海，调血必调冲，调冲必用天枢。
- **泌尿生殖病**：小便不利、遗尿，天枢配**中极、膀胱俞**。
- **急症救逆**：急性肠梗阻、阑尾炎初起，倪师在天枢附近找**压痛点**，重刺不留针，引邪外出。

**倪师经典对穴与排针组合**：

- **天枢 + 中脘 + 关元**：腹部三针，上中下三焦气机全调。倪师称之为“腹三针”，治一切腹病。
- **天枢 + 足三里 + 上巨虚**：大肠募穴配大肠下合穴（上巨虚），再配胃经合穴足三里，专治肠痈、痢疾、便秘。
- **天枢 + 支沟 + 照海**：倪师治便秘的**铁三角**。支沟通三焦气机，照海滋肾水润肠，天枢转中焦枢机，三穴一用，大便立通。
- **天枢 + 三阴交 + 血海**：妇科痛经、月经不调，天枢调冲任，三阴交调三阴，血海调血，三穴合用，经血自顺。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲天枢穴时，原话是这样说的：

> “天枢你们记住，这是大肠的募穴。大肠募穴怎么会在胃经上？因为胃跟大肠是连到的。你天枢一针下去，大肠就开始蠕动。所以便秘的病人，你针天枢、支沟、照海，针下去不到二十分钟，病人就跑厕所了。”

> “天枢这个穴，我常常用来诊断。你手按下去，如果病人天枢这里硬邦邦的，或者一按就痛，大便一定不好。有的人几天不大便，天枢按下去像石头一样，这就是燥屎堵在里面了。”

> “妇人怀孕的时候，天枢不要针。为什么？天枢通冲脉，冲脉起于胞中，你一针下去，动了胎气，这个责任你负不起。所以孕妇禁针天枢，这是规矩。”

倪师在讲腹部穴位时，还讲过一个**医案**：

> “有个太太，便秘十几年，什么药都吃过，就是不好。来找我，我一看她天枢两边都硬邦邦的，按下去还痛。我说你这不是单纯的便秘，是胃气不降，大肠没有力量推。我针天枢、中脘、足三里、支沟、照海，第一次针完，她回去就排了。连续针了一个礼拜，十几年的便秘好了。所以你们不要小看天枢，这个穴是通大肠的总开关。”

倪师手下针感体会：针天枢时，**针尖穿过腹壁，会有突破感**，然后病人会觉得**腹部一阵酸胀，有时会放射到整个腹部**。倪师说，如果针下去病人觉得**肚脐周围在动**，那就是气到了，效果最好。若针下空虚无物，说明气未至，需留针候气，或加**温针**，使阳气来复。

倪师还特别强调：**天枢针后，病人可能会放屁或排便**，这是好现象，说明气机通了。若针后腹痛加剧，可能是刺伤肠管，需立即起针，观察病情。所以天枢下针，**不可过深，不可猛刺**，以得气为度。
