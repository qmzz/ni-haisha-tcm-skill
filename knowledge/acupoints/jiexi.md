# 解溪穴 (ST41)

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经。胃经多气多血，解溪为胃经之**经穴**，五行属**火**。胃经本身属土，其经穴属火，土生火，故解溪为胃经**母穴**——虚则补其母，胃虚当补解溪。

- **倪师动态取穴**：解溪穴在足背踝关节横纹中央凹陷处，两大筋之间。倪师讲法，你让病人脚微翘，在脚腕前方正中间、两条大筋（趾长伸肌腱与拇长伸肌腱）之间，横纹正中掐进去，有个凹陷，就是解溪。摸骨法：先找到足背最高点的冲阳脉（足背动脉），再往踝关节方向推，推到腕横纹正中两筋间，那个坑就是解溪。

- **下针深度与法则**：直刺，针尖对准脚踝方向，进针**五分到八分**。浅刺即可得气，不宜过深，过深则伤骨膜。**可灸**，灸三壮到五壮，虚寒者尤宜。禁针者少，但局部红肿热痛（如痛风急性发作）时禁针禁灸，先放血泄热。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：胃经气血从厉兑（井金）出发，经内庭（荥水）、陷谷（输木），到解溪（经火），再到足三里（合土）。解溪是气血从足趾末端汇聚后，**由浅入深、由末梢向踝关节汇聚的关口**。倪师讲，解溪像脚腕上的一道“闸门”，胃经的阳气与津液在此处汇聚、转枢。火穴能温通，故解溪能**引火归元、清胃热而通经活络**。脚腕是气血回流的要道，解溪一开，整条胃经的经气就活了。

- **子母补泻心法**：解溪属火，胃属土，**火生土，解溪为胃经母穴**。虚则补其母——胃气虚、胃寒、消化无力、饭后胀满、面色萎黄，针解溪用补法（顺经而刺，捻转徐出），补胃之母气。实则泻其子——胃经实证，如胃火牙痛、口臭、消谷善饥，则取胃经子穴**厉兑**（井金）泻之，而非解溪。倪师反复强调：**母穴补虚，子穴泻实**，解溪是补胃虚的关键穴，别拿它去泻实。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **脚腕扭伤、踝关节痛**——解溪是局部取穴第一选择，针下去让病人活动脚腕，针到痛除。
  - **胃热、口臭、牙痛**——解溪清胃火，配内庭、合谷。
  - **头痛、眩晕、眉棱骨痛**——胃经循行上头，解溪引气血下行，对前额痛、眉棱骨痛特效。
  - **癫狂、惊悸、失眠**——倪师讲，解溪能清胃热、安神定志，“胃热上冲脑”导致的烦躁、失眠、癫狂，针解溪泄热。
  - **足下垂、脚无力**——解溪近踝，能振奋胃经经气，配足三里、阳陵泉。

- **倪师经典对穴与排针组合**：
  - **解溪 + 足三里**：胃经母子同调，补虚泻实，治一切胃病、脚膝无力。
  - **解溪 + 内庭**：一清一泄，专治胃火牙痛、口臭。
  - **解溪 + 丘墟 + 商丘**：踝关节三面围刺，治脚腕扭伤、肿胀。
  - **解溪 + 百会 + 太冲**：引气血下行，治肝胃火升之头痛、眩晕。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师原话（大意）：“解溪穴在脚腕横纹中间，两条大筋之间。你摸到那个凹洞，针下去五分。脚扭伤，针解溪，一边针一边让病人转脚腕，当场就好。胃经的母穴，虚症补它。胃火大、口臭、牙痛，解溪配上内庭，一针下去，火就往下走。”

- 针感体会：倪师说，解溪针下去，病人常感觉**脚背一阵酸胀，像电流往脚趾方向窜**，有时整个脚腕松开。得气后，让病人轻轻活动脚踝，效果倍增。

- 医案故事：倪师讲过，有人脚腕扭伤肿得像馒头，西医治了半个月不消。他针解溪、丘墟、商丘，三针下去，让病人站起来走，病人不敢，他说“你走”，一走发现不痛了，肿也消了大半。倪师笑说：“脚腕的伤，针在筋间，气一到，肿就散，哪要什么消炎药？”
