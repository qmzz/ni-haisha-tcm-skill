# 曲泉穴 (LR8)

## 📍 经络归属与精准取穴法

- **所属经络**：足厥阴肝经。肝经五输穴之**合穴**，五行属**水**。肝属木，木之母为水——曲泉即肝经的“母穴”。倪师原话：肝经的合穴就是曲泉，属水。阴经的合穴都属水，所以曲泉是肝经的母穴。肝经气血在此如泉水汇聚，由小腿内侧上行汇入膝腘，有润养肝木、滋水涵木之性。

- **倪师动态取穴与骨度折量法**：
  先把腿弯起来——屈膝，膝盖内侧会出现一条横纹，就是膝横纹。从膝横纹头沿着大腿内侧往上摸，摸到两筋之间、肌肉凹陷处——那个“筋间陷中”就是曲泉。倪师大白话：你顺着膝盖内侧那条横纹往上推，推到骨头边上有个凹洞，一按就酸酸胀胀的，那就是曲泉。
  - **下针深度**：直刺或稍向膝腘方向斜刺，**0.8～1寸**。倪师强调，这个位置血管多，扎针时一定要避开大血管，慢慢进针，不要猛扎。
  - **禁针禁灸法则**：曲泉可针可灸。但倪师提醒，膝内侧为血络汇聚之地，《针灸大成》有“刺曲泉，血出不可止”的警示。所以进针后不要大幅度提插捻转，手法要轻，捻转幅度要小。灸法可用艾条温和灸，不宜直接大炷化脓灸。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：肝经属木，木生于水。曲泉作为肝经的合穴属水，等于是肝木的“母亲穴”。倪师讲，肝经从大敦（木穴）开始，一路走到曲泉（水穴）——木气到了这里，要靠水来滋养、来归根。所以曲泉的气化特点就是**滋水涵木、引血归经**。它能将上浮的肝阳、妄行的肝血重新拉回下焦，归于肝肾之根。这就是倪师所说的“引火归元、引血归肝”的思路在肝经上的体现。
  临床上常见的膝盖内侧痛、小便不利、阴部瘙痒、月经不调，都是肝经气血在下焦出了岔子。曲泉一针下去，好比把泉水重新灌回肝木的根上，木得水润则条达，下焦气化自然通畅。

- **子母补泻与五行生克心法**：肝经五行属木。木之母为水，木之子为火。曲泉是水穴，即**肝经的母穴**。倪师在针灸篇里反复强调：虚则补其母，实则泻其子。肝经虚证——比如肝血不足导致的眼干、眼涩、筋脉拘挛、月经量少色淡、爪甲不荣——就在曲泉上下针，用补法。补法就是顺经而刺、捻转时拇指向前为补（倪师补泻手法：顺经脉方向转针为补，逆为泻）。相反，肝经实证——比如肝火上炎导致的目赤肿痛、烦躁易怒、胁肋胀痛、小便黄赤——那就不能扎曲泉了，要去找肝经的荥穴行间（属火，为肝经子穴），用泻法。倪师口诀：肝经虚了找曲泉，肝经实了找行间。这一补一泻之间，五行生克的道理全在里头。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  1. **下焦泌尿生殖系统**：小便不利、小便涩痛、癃闭、遗精、阳痿、阴部瘙痒、阴肿。倪师说，肝经环绕阴器，曲泉又是合穴，凡是阴部的问题、小便的问题，曲泉是首选大穴。
  2. **妇科特效**：月经不调、痛经、闭经、带下异常。尤其是肝血虚寒型痛经——经期小腹冷痛、腰膝酸软、经色淡红量少——曲泉配三阴交、关元，温针或艾灸，效果立竿见影。
  3. **膝关节内侧痛**：这是曲泉的近治作用。倪师常讲，膝盖内侧痛，你就在曲泉附近找压痛点下针，一针下去就能松。
  4. **肝血不足诸证**：眼干眼涩、视物模糊、筋脉拘挛、爪甲枯脆、失眠多梦。

- **倪师经典对穴与排针组合**：
  - **曲泉 + 三阴交 + 太冲**：肝脾肾同调，治月经不调、痛经、肝血虚。
  - **曲泉 + 关元 + 中极**：温下焦、利小便，治癃闭、遗尿、阳痿。
  - **曲泉 + 阴陵泉 + 足三里**：健脾利湿、通利下焦，治小便不利兼湿重者。
  - **曲泉 + 行间**：一补一泻，母子同用，调和肝经虚实夹杂之证。
  - **曲泉 + 委中**：膝内侧与膝后侧对刺，治膝关节屈伸不利。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在针灸篇讲到肝经时，原汁原味的金句是这样的：

“肝经的合穴叫曲泉。合穴呢，属水。阴经的合穴统统属水。所以曲泉是肝经的母穴。肝经虚的时候，我们要补它的母——在曲泉上下针。诸位记得，肝经虚了，人会怎么样？眼睛干、筋抽、月经少，你就在曲泉用补的手法。”

“曲泉在哪里？你把腿弯起来，膝盖内侧横纹头，沿着横纹往上推，推到筋和筋之间有个凹陷，那就是曲泉。针下去不要太深，一寸左右。旁边有血管，你扎针的时候要避开，不要扎到血管上。”

“临床上，曲泉用得最多的是妇科病和泌尿系统的病。肝经络阴器，所以阴部的问题、小便的问题，曲泉是主治。你只要看到病人膝盖内侧痛，你按按曲泉，如果有压痛，那就是肝经的问题，针曲泉就对了。”

倪师还讲过他的实战体会：有一回一个女病人，月经三个月没来，小腹隐隐作痛，眼睛也干涩。倪师一按她曲泉，痛得叫起来。倪师就在曲泉下针，用补法，再配三阴交、关元。针了三次，月经就来了。倪师说，这就是“虚则补其母”的道理——肝血虚了，你补肝经的母穴曲泉，水足了，木自然就旺了。

倪师特别提醒：曲泉这个穴，下针时手法要轻，捻转要慢。因为膝内侧血管多，你手法太重，病人容易出血、淤青。而且曲泉的针感是酸胀为主，有时候会往下窜到小腿内侧，这是气至的表现，是好事情。不要追求强烈的触电样针感，那是扎到神经了，不对。
