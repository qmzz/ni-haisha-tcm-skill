# 交信

## 📍 经络归属与精准取穴法

- **所属经络**：足少阴肾经。交信是阴跷脉的**郄穴**。郄穴善治急症、血证、痛证，阳跷郄穴是跗阳，阴跷郄穴就是交信，所以交信专门管阴跷脉这一路来的急症。五行属性上，肾经属水，交信是肾经在小腿内侧的一个重要关卡穴，它不属五输穴（井荥输经合）里的任何一个，但它是阴跷脉的郄穴，定位在肾经的循行线上，内踝上二寸，跟复溜只差半寸。

- **倪师动态取穴与骨度折量法**：
  先找内踝骨，从内踝骨最高点往上摸，摸到二寸的位置。注意，复溜是内踝上二寸，交信也是内踝上二寸，两个穴并排——复溜在跟腱前面，交信在复溜再往前半寸，贴着胫骨后缘。倪师原话讲：“复溜跟交信差半寸，从复溜往前半寸，就是交信。”所以你要先定复溜，再往前挪半寸。手指按下去，贴着胫骨后缘那个凹陷就是。下针深度：直刺或斜刺**五分到八分**，不要太深，这里血管多，扎深了容易出血。禁灸？交信可以灸，但不宜多灸，因为它本身管阴跷脉的血证，灸多了容易动血。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演的气血流注与开阖机理**：
  交信是阴跷脉的郄穴。阴跷脉从照海起来，沿着内踝往上走，交信就是它往上走的关键闸口。倪师讲，阴跷脉主一身左右之阴，管的是下肢内侧的阴血运行。交信作为郄穴，就是这条阴脉的“急救开关”。当阴跷脉的气血堵住了，下肢内侧痛、月经 suddenly 停了、崩漏不止，都是交信的事。它的核心机理是**调阴跷、理血分、通利下焦**。肾经本身主水，交信又贴着胫骨后缘，靠近脾经的地界，所以它还能**健脾利湿、调经止血**，等于一脚踩在肾经上，一脚跨到脾经的活儿上。

- **子母补泻与五行生克运用心法**：
  交信不是五输穴，所以严格来说不走“虚则补其母、实则泻其子”那套五输穴的子母补泻。但倪师讲，郄穴本身就是**急则治标**的用法——阴跷脉急症，直接取交信，不用绕五行生克。如果要配五行，肾经属水，水生木，肝木藏血，交信调血分，实际上是在**肾水与肝木之间做枢纽**。所以临床上月经病、血证，交信配肝经的太冲、脾经的三阴交，就是水木相生、脾肾同调的思路。虚证崩漏，补交信配补三阴交；实证闭经，泻交信配泻太冲。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **妇科血证第一**：月经不调、崩漏、淋漓不尽、闭经、痛经。阴跷郄穴专管阴血，这是交信最拿手的。
  - **急症**：阴跷脉的急性下肢内侧拘挛、抽搐。
  - **泌尿生殖**：小便不利、淋证、疝气、睾丸肿痛。
  - **大便**：泄泻、痢疾，尤其是那种里急后重、大便带脓血的，交信能清下焦湿热。
  - **下肢毛病**：小腿内侧酸痛、脚气、足内翻无力。

- **倪师经典对穴与排针组合**：
  - **交信 + 三阴交**：这是倪师治月经病、崩漏的经典组合。三阴交是肝脾肾三条阴经的交会，交信是阴跷郄穴，两个一起下，等于三条阴经一起调，血分的问题跑不掉。
  - **交信 + 太冲**：治痛经、闭经。太冲开肝气，交信调阴血，气行则血行。
  - **交信 + 复溜**：肾经的两个重要穴位并排，复溜补肾水，交信调阴跷，治水肿、小便不利、下肢沉重。
  - **交信 + 照海**：阴跷脉的起点和郄穴一起用，治阴跷脉全线拘挛、癫痫夜间发作（阴跷主夜）。
  - **交信 + 公孙**：公孙通冲脉，交信通阴跷，冲脉为血海，阴跷主阴血，两个配一起治妇科血证效果翻倍。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲足少阴肾经的时候，讲到复溜附近，原话大概是这么说的：

> “复溜再往前半寸，就是交信。交信是阴跷脉的郄穴。郄穴呢，就是专门治急症的。所以阴跷脉的急症——什么叫阴跷脉的急症？妇人月经突然停掉，或者突然大量出血，崩漏不止，这是急症，你就下交信。还有的人脚内侧突然抽筋，阴跷脉拘挛，也是交信。郄穴就是这个时候用的，不要等到慢性了再想到它。”

倪师还讲过一段实战体会：

> “交信这个穴，你下针的时候要贴着胫骨后缘，针下去不要太深，五分就够了。针感会往下走，走到内踝，甚至走到脚底。病人会感觉一阵酸麻，这个就是气到了。气到了，血就动了。所以治月经不来，你交信配三阴交，针一下去，病人小腹就开始有感觉，有的人当场月经就来了。”

倪师讲妇科血证的医案：

> “有个太太，月经来了三个月都不停，滴滴答答的，西医说是功能性子宫出血。我看她脸色苍白，舌淡，脉细。这是阴跷脉管不住血了。我下针：交信、三阴交、隐白（灸）。隐白是脾经井穴，专治崩漏，灸它。交信和三阴交用针。针完第一天，血量就减少了。第三天就干净了。为什么？阴跷脉的郄穴把闸门关上了。”

倪师还特别强调交信和小便的关系：

> “有的人小便排不出来，或者小便涩痛，你下交信，再配复溜、阴陵泉。交信管阴跷脉，阴跷脉经过阴器，所以它对泌尿生殖系统有直接作用。你不要只想到它是妇科穴，男的疝气、睾丸痛，交信一样管。”

最后倪师讲禁针禁灸的规矩：

> “交信这个地方，下面有胫后动脉的分支，你不要拿粗针乱扎，扎深了会出血。芍药甘草汤证那种脚抽筋，你灸交信可以，但灸个三壮五壮就好了，不要灸到起泡。阴跷脉本身就管阴血，灸多了动血，反而不好。”
