# 地仓

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经，为阳跷脉、手足阳明经之交会穴。
- **特定穴属性**：地仓并非井荥输经合五输穴，亦非原络郄募俞八会穴。它是**阳跷脉与手足阳明经的交会穴**，倪师在讲面部穴位时特别点出，凡交会穴必是气血汇聚转输之枢纽，地仓所汇者，乃胃经多气多血之经气与水谷精微上承之气。
- **倪师动态取穴法**：嘴角旁开，瞳孔直下取之。倪师原话是“**地仓在嘴角旁边，眼睛正中对下来**”——你先让患者正视前方，从瞳孔中心垂直往下画一条线，这条线与嘴角水平线的交点就是地仓。简便取法：**口角旁开约四分，大约半横指宽**。倪师强调嘴要闭着取穴，让患者自然合口，嘴角纹头外缘即是穴处。
- **下针手法**：倪师讲面部穴位用**32号细针**，地仓常规是**斜刺或平刺，针尖朝向颊车方向透刺**，这是倪师常用的“**地仓透颊车**”手法。深度**三到五分**，不宜深刺。
- **禁针禁灸法则**：面部穴位一般**不灸**，倪师原话“脸上我们很少灸，一灸就起水泡，很难看”。地仓可针不可灸。针时注意避开面动脉分支，出针后按压片刻即可，面部容易出血。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：地仓者，“地”为土，“仓”为仓廪，脾胃属土，仓廪之官。倪师在讲胃经时反复强调，**胃经的气血上到头面**，地仓就是胃经气血在口唇周围的转输关卡。它的核心机理是——**阳明经气上达口面，濡养唇口、司开阖**。所以凡是口唇不能开合、流涎、面肌瘫痪，都是地仓这个“仓”开阖失司。
- **倪师推演的核心机理**：倪师讲这个穴时，把它归结为“**引阳明经气达于口面**”的开关。阳明经多气多血，气血一旦不能上达，口眼就歪斜。地仓透颊车，一针贯两穴，等于把胃经的气血从口角一路引到下颌关节，**通经活络、调和气血、开关通窍**。
- **子母补泻与五行运用**：地仓非五输穴，本身不直接用子母补泻。但倪师讲胃经时说过，胃属土，**土生金，土克水**。面部口眼歪斜多与风中经络有关，风属木，木克土。地仓调胃土之气，**壮土以御木**，这是五行层面的大心法。临床上面瘫久不愈者，倪师会在胃经上取穴补土，地仓是其中要穴。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **面部中风（口眼歪斜）**——这是地仓的第一主治。倪师讲面部中风时，地仓透颊车是主穴组合。
  - **流涎不止**——脾开窍于口，胃经环绕口唇，地仓能约束口唇开阖，小儿流涎、老人流涎皆效。
  - **口唇麻木、口角抽动、三叉神经痛**——阳明经气不利所致者。
  - **牙关紧闭、口噤不开**——配合颊车、下关。
- **倪师经典对穴与排针组合**：
  - **地仓透颊车**——面部中风的黄金组合，一针透两穴，从口角刺入，针尖朝向颊车方向，得气后留针。
  - **地仓 + 合谷 + 太冲（开四关）**——“面口合谷收”，合谷配太冲开四关调气血，再取地仓局部引气至病所，这是倪师治面瘫的经典排针。
  - **地仓 + 承浆 + 廉泉**——治流涎、口舌不利。
  - **地仓 + 下关 + 颊车 + 翳风**——治面部中风全套组合，倪师在视频中演示过这套面部排针。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲面部穴位时，原汁原味的讲法是这样的：

“**地仓在嘴角旁边，眼睛正中对下来，这个穴道呢，你下针的时候，针从地仓刺进去，往颊车方向透，叫地仓透颊车。面部中风的时候，嘴角歪到一边去了，你一下针，把气引过去，嘴巴就正回来了。**”

倪师讲到这里特别提醒学生：“**脸上下针，用细针，三十二号的针，不要用粗针，脸部很敏感。你扎下去，病人感觉酸酸胀胀的，那就对了。**”

关于流涎，倪师在讲课时提到一个临床体会：“**小孩子口水流不停，你在地仓上轻轻下一针，一两次就好了。为什么？胃经环口，地仓管的就是口唇的开合。**”

倪师还讲过面部中风的治疗次第：“**先扎健侧，再扎患侧，地仓透颊车是两边都可以用的。但是你要记得，针地仓的时候，针尖要朝着颊车的方向，不要直直扎进去，要透过去。透针的意义就是把经气接通，让气血重新布散到面部。**”

关于针感，倪师说：“**病人会感觉到整个嘴角、脸颊这边有酸胀感，有时候会传到牙齿这边，这是气到了。气到了，效果就出来了。**”
