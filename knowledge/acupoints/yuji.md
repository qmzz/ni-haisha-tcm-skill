# 鱼际

## 📍 经络归属与精准取穴法

- **所属经络**：手太阴肺经。肺经起于中府，出腋下，沿上肢内侧前缘下行，入寸口，上鱼际，出大指之端少商穴。鱼际正是肺经气血从寸口脉向手指末端灌注的关键节点。
- **五输穴属性**：鱼际为肺经**荥穴**，五行属**火**。肺属金，金生水，金克木，而荥穴主“病变于色者取之荥”。肺经属金，鱼际为其火穴，火能克金，故此穴为肺经的“子穴”——实则泻其子，肺经实证、热证皆可取鱼际泻之。
- **倪师动态取穴心法**：手仰掌，在大拇指掌骨中点赤白肉际处。倪师讲：“你顺着大拇指第一掌骨摸，摸到骨头正中间，一边是肉一边是皮，赤白肉际那个缝就是鱼际。”不必死记一寸二分，手一握，大拇指根鼓起来那块肉——大鱼际，正中最高点，赤白肉际交界处，一针下去就中。倪师强调“穴在骨边”，贴着掌骨边缘进针，不要扎在肉当中。
- **下针深度与方向**：直刺，针尖向掌心方向斜刺，进针**三分至五分**。倪师说：“鱼际这个地方肉薄，别深扎，三分就到，得气即止。”得气时局部酸胀，有时向拇指端或掌心放散。
- **禁针禁灸**：鱼际一般不禁灸，但倪师讲肺经荥穴多用于清热，**实证热证以针泻为主，少用灸法**；若肺气虚寒需温补，可小艾炷灸三至五壮，但不宜多灸，恐助肺火。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：肺经气血从太渊（俞土）流注到鱼际（荥火），再从鱼际流向少商（井木）。鱼际是肺气从“沉”转“浮”、从“内”达“外”的关口。倪师讲：“肺主皮毛，主气，荥穴主色。你脸上、皮肤上的颜色不对，病在色，就取荥穴。”鱼际把肺经的阴液热气化开，像雾露一样布散到肌表。所以鱼际能**清肺热、利咽喉、凉血止血、润皮毛**。
- **五行生克心法**：肺属金，鱼际属火（荥火）。火克金，故此穴为肺经**子穴**。倪师在《人纪》中反复强调：“实则泻其子，虚则补其母。”肺经实证——咳嗽声粗、胸痛痰黄、咽喉肿痛、发热汗出——这是金实，实则泻其火，取鱼际泻之，针用泻法（捻转提插，吸气时进针，呼气时出针）。肺经虚证——气短乏力、干咳无痰、声低懒言——则补其母穴太渊（俞土），不取鱼际。
- **破局心法**：倪师讲鱼际能“引肺热下行，从水道排出”。肺为水之上源，肺热则水道不通，小便黄赤、咳嗽咽痛。鱼际清金降火，火降则水通，热从小便走。又因肺与大肠相表里，鱼际泻火，也能通大肠之热，故**痔疮出血、肠热便秘**亦可取鱼际辅助。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **咽喉急症**：咽喉肿痛、扁桃体炎、声音嘶哑——鱼际放血或针刺，立竿见影。倪师说：“喉咙痛得讲不出话，鱼际一针下去，让他吞口水试试，当场松一半。”
  - **肺热咳喘**：咳黄痰、气喘、胸痛发热——鱼际配少商点刺放血，清肺泻热。
  - **咳血、鼻衄**：肺热伤络，血从上溢——鱼际清肺凉血，配孔最（郄穴）止血。
  - **小儿疳积、消化不良**：倪师讲小儿手掌大鱼际发青、发紫，是“积”在肺脾，鱼际可调和肺脾之气。
  - **手腕痛、拇指痛**：局部近取，疏通经气。
  - **乳腺炎、乳房胀痛**：肺经循行过乳上，鱼际配太冲、膻中，疏肝清肺。
- **倪师经典对穴与排针组合**：
  - **鱼际 + 少商**：肺热咽喉肿痛，少商点刺放血，鱼际针刺泻热，表里上下同清。
  - **鱼际 + 合谷**：风热感冒、发热无汗，合谷解表，鱼际清里热。
  - **鱼际 + 太渊**：肺气虚而有热，太渊补母，鱼际泻子，母子同调。
  - **鱼际 + 孔最**：咳血、鼻衄，郄穴止血，荥穴清热。
  - **鱼际 + 照海**：咽喉干痛、阴虚火旺，照海滋肾水，鱼际清肺火，金水相生。

## 🗣️ 倪师讲义实录与针灸秘要

- **原汁原味逐字稿金句**：倪师在《人纪·针灸篇》中讲：“鱼际穴，在赤白肉际，大拇指掌骨中间。你手一握，那块鼓起来的肉，正中间就是。这是肺经的荥穴，属火。肺经的实症，你在这个穴上泻它。什么叫实？咳嗽声音大、胸痛、痰黄、喉咙痛，这是肺里面有实热，针鱼际，用泻法。虚症呢？气短、乏力、干咳，那你要补太渊，别碰鱼际。”
- **手下针感体会**：倪师说：“鱼际进针，三分深，针尖稍微朝掌心方向斜。你捻针的时候，病人会觉得酸胀往大拇指那边窜，有时候整个手掌心发热。这就是气到了。气一到，热就退。”
- **医案故事**：倪师讲过一个案例——有个病人喉咙痛三天，吞口水像吞刀片，西医说是急性扁桃体炎。倪师在鱼际、少商两穴点刺放血，血出如豆，病人当场咽口水，说“不痛了”。倪师说：“肺经的热，从鱼际放掉，就像高压锅掀了盖子，气一泄，火就散了。”又讲小儿手掌大鱼际发青，是“肺脾有积”，用鱼际配四缝，挑出黄水，小儿胃口就开了。倪师强调：“鱼际是肺经的关口，热从这儿过，也从这儿泄。”
