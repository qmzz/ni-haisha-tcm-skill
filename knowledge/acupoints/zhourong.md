# 周荣

## 📍 经络归属与精准取穴法

- **所属经络**：足太阴脾经。周荣在《针灸大成》中归足太阴脾经，位于胸乡上一寸六分，天溪上一寸六分。从经络走向看，脾经从足大趾隐白起，循腿内侧上行，过冲门、府舍、腹结、大横、腹哀，再上至胸外侧，经食窦、天溪、胸乡、周荣，最终上接于肺经之中府。周荣即是脾经在胸部的最后一个穴位，是脾气由胸膈向肺系转输的关口。

- **五输穴/特定穴属性**：周荣不是井荥输经合，不是原络郄募俞，也不是八会穴。它属于《针灸大成》所称的“胸乡周荣”一线上的穴位，是脾经布胸的最后一站。倪师在讲十二经纳天干地支时指出，脾经对应“己土”，五行为土。周荣虽无子母补泻的特定穴身份，但它的穴性可从脾经土气通肺金的角度理解：脾土生肺金，周荣正是土气转输为金气的关键节点，所以它的气化作用是“升脾精以润肺”，这是周荣最核心的定位。

- **倪师动态取穴与骨度折量法**：
  倪师讲胸部穴位时，反复强调“不要死记几寸几分，要用手去摸肋骨”。周荣的取法：先找乳头，乳头平第四肋间。从乳头向外侧摸到第二肋间隙，那一带就是胸乡、周荣所在。实际上，倪师在《人纪·针灸篇》讲脾经胸段时，通常是从食窦往上一路推：天溪在乳头外开二寸，胸乡在天溪上一寸六分，周荣在胸乡上一寸六分。也就是从第四肋间往上，依次是周荣、胸乡、天溪。

  更直白的摸法：手摸到锁骨下方，沿着肋骨间隙往外侧推，大约在第二肋间、前正中线旁开六寸的位置，就是周荣。倪师常说：“你摸到骨头缝，针就下在骨缝里，不要扎在骨头上。”

  **下针深度**：周荣在胸部，肌肉浅薄，倪师主张“浅刺”，一般针入三分，最多五分，不可深刺。胸部穴位深刺有刺入胸腔、伤及肺脏的风险，倪师特别警告过“胸部的穴道，要嘛你就斜刺，要嘛你就浅刺，千万不能直刺太深”。

  **禁针禁灸**：周荣可灸，但倪师对胸部穴位灸法持审慎态度，因为灸法温热，胸部靠近心肺，灸太过会助热上扰。一般禁直接灸，可温和灸。针刺方面，不可深刺，肺气肿患者更要小心。倪师在讲胸部穴位时说过：“凡是胸部的穴道，你下针的时候，针身要贴着肋骨走，不要往里面扎。”


## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：
  周荣的穴名本身就说明了一切。“周”是周全、周遍，“荣”是荣养、荣润。倪师在讲脾经时指出，脾主运化，将水谷精微上输于肺，再由肺朝百脉、布散周身。周荣就是脾精上输于肺、化为荣气周遍全身的关口。如果这个关口堵住了，脾精不能上达，就会出现胸胁胀满、咳嗽、气逆，甚至皮肤干枯不荣。

  从气血流注看，脾经的气血从下肢上行到腹部，再上到胸部，到了周荣这里是“由脾入肺”的转换点。倪师推演它的开阖：周荣开了，脾气就顺畅地变成肺气，呼吸就深长，胸中就不闷；周荣阖了，脾气上不去，肺气也下不来，就会胸闷、咳逆、皮肤粗糙。所以周荣的核心机理是“升脾精、润肺金、布荣气”。

- **子母补泻与五行生克运用心法**：
  周荣本身不是五输穴，但倪师在讲五行生克时，经常把穴位放到整条经的五行属性里去用。脾经属土，肺经属金，土生金。周荣是脾经在胸部的末端，紧接肺经中府，等于土气生金气的最后一棒。所以：

  - **虚则补其母**：如果肺气虚，除了补肺经的母穴太渊，还可以补脾经，因为脾是肺之母。周荣作为脾经向肺经转输的关口，可以在此处用补法（捻转补法、呼气进针），帮助脾气上输以补肺气。倪师说：“肺虚的人，你光补肺不够，要补脾，脾胃一强，肺气就足了。”
  - **实则泻其子**：如果脾实证，比如湿困脾土、胸脘痞满，可以泻肺经的母穴？不对，实则泻其子，脾之子为肺。倪师在五行生克中讲，脾实的时候，泻肺金可以耗脾土之势。但周荣本身在胸部，更多用于疏通局部气机，而非直接做子母补泻。实务中，倪师常用周荣配肺经穴位来调胸中气机。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  1. **胸胁胀满、胸痛**：周荣在胸部，近取穴能疏通胸中气机。倪师说胸部穴位“近取治近病”，胸胁胀满、咳引胸痛，周荣配合内关、公孙，效果很好。
  2. **咳嗽、气逆**：脾精不能上润肺金，肺气上逆而咳。周荣能升脾精以润肺，配合肺经的中府、云门、太渊，可降气止咳。
  3. **食不下、噎膈**：脾气上输受阻，胃口虽好但咽不下去，周荣能开胸膈之闭。配中脘、足三里、内关。
  4. **皮肤干燥不荣、脱发**：倪师在讲脾主肌肉、肺主皮毛时提到，脾肺之气不能周荣于表，皮肤就干枯。周荣配足三里、三阴交、肺俞，能布荣气于肌表。

- **倪师经典对穴与排针组合**：
  - **周荣 + 内关 + 公孙**：内关通阴维，公孙通冲脉，合于胃心胸。周荣开胸膈，三穴合用治一切胸胁胀满、心胸闷痛。这是倪师常用的“胸三针”变阵。
  - **周荣 + 中府 + 太渊**：中府是肺募，太渊是肺经母穴（输穴，属土），周荣是脾经转输肺经的关口，三穴合用，补脾润肺，治久咳虚喘。
  - **周荣 + 足三里 + 三阴交**：足三里补胃气，三阴交补脾阴，周荣布散荣气。治脾虚不运、面色萎黄、肌肤不仁。
  - **周荣 + 膻中 + 巨阙**：膻中是气会，巨阙是心募，周荣开胸中气机。治胸痹、心痛彻背。


## 🗣️ 倪师讲义实录与针灸秘要

- **逐字稿金句**：
  “周荣这个穴，你看它的名字就知道了，周荣就是周遍荣养。脾脏吸收的营养，要经过这里送到肺里面去，再由肺送到全身。所以周荣一堵，全身都得不到营养。”

  “胸部的穴道，像周荣、胸乡、天溪，你下针的时候，针要贴着肋骨下去，不要往里面扎。你扎太深，扎到肺，病人一咳嗽，气胸就来了。”

  “周荣可以治咳嗽，但你不要以为它是专门治咳嗽的。它是让脾气上去润肺的，肺得到润，咳就停了。这是治病求本。”

  “你看这个人皮肤干干的，头发也掉了，你以为是肺的问题？也是脾的问题。脾精上不去，肺怎么布荣气？周荣一针下去，脾气上来了，肺气就开了。”

- **实战手下针感体会**：
  倪师在视频中演示胸部穴位时，手法极轻。他用一寸针，斜刺入周荣，针尖朝向肺经方向。他说：“你针一下去，病人会感觉到一股气从胸口往里面散开，有的病人会深呼吸一下，那就是气机通了。”他还提到，周荣下针后，如果病人感到胸中一热，那是脾精上输的表现，效果最好。

- **医案故事**：
  倪师在《人纪》中讲过一例：一位中年妇女，长期胸闷、咳嗽、皮肤干痒，看了很多医生，都当肺病治，吃清肺的药也不见好。倪师一看，脉右关沉弱，舌淡苔白，这是脾虚不能上输。他取了周荣、中府、太渊、足三里、三阴交。针了三次，病人胸闷大减，咳嗽也少了，皮肤也开始润了。倪师说：“你看到的是肺病，我看到的是脾病。周荣就是那个把脾和肺连起来的穴。”
