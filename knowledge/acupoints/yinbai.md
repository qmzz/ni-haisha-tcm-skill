# 隐白

## 📍 经络归属与精准取穴法

- **所属经络**：足太阴脾经。脾经起于足大趾内侧端，隐白正是脾经的第一穴，**井穴**，五行属**木**。
- **五输穴定位**：脾经五输穴依次为：隐白（井·木）、大都（荥·火）、太白（输·土）、商丘（经·金）、阴陵泉（合·水）。脾属土，隐白为木穴，**木克土**——这是脾经上唯一一个“本经克本脏”的穴道。正因为这个“逆反”的属性，隐白才能泻脾实、清脾热、摄血止血，成为脾经上治血证第一要穴。
- **倪师动态取穴**：倪师讲得很直白——**“隐白穴在大脚趾内侧，脚指甲旁边，大概在指甲根部那个角角那里，你摸下去有一点点凹。”** 通俗讲：从大脚趾指甲内侧角，沿着指甲边缘往外侧（往第二趾方向）约一分（0.1寸）的地方，赤白肉际处，就是隐白。你不用去量什么“去爪甲角如韭叶”，倪师说“你就看那个指甲角旁边，一摸有个小凹陷，就是它。”脚趾小，穴也小，你摸的时候要仔细，别一针扎到指甲盖上去。
- **下针深度与手法**：隐白穴极浅，倪师说“脚趾头就那么点大，你针下去**一分到两分**就够了，不要深，深了扎到骨头没用。”通常用**一寸针或半寸针**，浅刺后**点刺出血**或者**留针三五分钟**即可。
- **禁针禁灸注意**：隐白可灸，尤其是**米粒灸**。倪师在讲灸法时专门提到，隐白的经典用法之一就是**米粒灸三五壮**，尤其是妇人崩漏不止，灸隐白止血效果立竿见影。但倪师也强调：**脚趾末端肉少皮薄，艾灸时用米粒大即可，不要用大艾炷，否则容易烫伤起泡。** 另外，若局部有严重感染或溃烂时，禁针禁灸。

## ⚡ 倪师经穴气化与破局心法

- **气化机理——木克土、摄血归经**：隐白是脾经井穴，五行属木。脾主统血，正常情况下脾气把血统摄在脉管里面，不让它乱跑。但**脾土一旦虚了，或者脾里面有了实热瘀堵，统血的力量就散了，血就到处乱窜**——崩漏、便血、尿血、皮下出血都来了。隐白这个木穴，恰恰能**以木疏土**，把脾经郁结的气机打开，让脾恢复统血的功能；同时井穴本身就有**引气下行、开窍醒神**的作用，能把上溢的血引回正经。倪师常说：“**隐白就是脾经上的止血开关，你把它一开，血就归经了。**”
- **井穴共性——病在脏取井**：倪师在讲五输穴用法时反复强调“**病在脏取井穴**”。什么叫病在脏？心肝脾肺肾出了大问题，急症、重症、神志昏迷、出血不止，这时候下井穴，**像打开水龙头一样把脏气放出来**。隐白就是脾脏的“水龙头”。脾经出了问题——不管是脾虚崩漏、脾不统血，还是脾经热盛导致的狂躁、梦魇、惊风，隐白都能破局。
- **子母补泻心法**：脾经属土，土生金（商丘为金，是脾经的子穴），火生土（大都为火，是脾经的母穴）。隐白是木穴，**既不是脾经的母穴也不是子穴**，它是“克穴”。倪师说：“**这个穴你不用补它，它是专门用来泻的——泻脾实、泻脾热。**”什么时候用？脾经有实热、有瘀堵的时候用。虚证崩漏能不能用？也能，但这时候取隐白更多是取其**井穴引气下行、摄血归经**之功，而不是补虚。真正补脾虚，母穴是大都（荥穴），虚则补其母，要在大都上行补法。
- **开阖升降枢纽**：脚大趾是人体最下端，隐白在最下端的最内侧。倪师说：“**井穴的气是往下沉的，像一口井的底。**”所以隐白擅长把上焦浮越的气血往下引——**鼻出血、脑充血、狂躁不安、上热下寒**，都可以用隐白引火归元、引血下行。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **妇科血证第一穴**：妇人**崩漏、月经不止、淋漓不尽**，灸隐白三五壮，效果立竿见影。倪师原话：“**妇人月经停不下来，你灸隐白，第二天就少了。**”
  - **便血、尿血、鼻衄**：脾不统血导致的各种出血。
  - **小儿惊风、夜啼、梦魇**：脾经井穴开窍醒神，小儿脾虚受惊、晚上哭闹不睡，点刺隐白出血，一两次就好。
  - **癫狂、多梦、心神不宁**：脾经有热上扰心神，隐白泻脾热，热一退神就安。
  - **足大趾麻木、肿痛**：局部近取，疏通脾经末梢气血。
- **倪师经典对穴与排针组合**：
  - **隐白 + 三阴交**：这是倪师治崩漏的经典组合。三阴交统调肝脾肾三经，隐白专摄脾血，一上一下，标本兼治。倪师说：“**三阴交是总开关，隐白是分开关，两个一起下，血就乖乖回去了。**”
  - **隐白 + 大敦**：大敦是肝经井穴，也治疝气、崩漏。二穴相配，肝脾同调，尤其适合**情绪波动引发的月经不止**——肝郁脾虚型崩漏。
  - **隐白 + 足三里**：足三里补脾胃之气，隐白摄血归经。**脾虚日久、气血双亏、出血不止**的慢性病，用这个组合。
  - **隐白 + 厉兑**：厉兑是胃经井穴，脾胃表里经井穴同用，**清脾胃热、治梦魇癫狂**，效果加倍。
  - **隐白 + 百会**：百会升提中气，隐白引血归经，**中气下陷型崩漏、脱肛**，一升一摄。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师讲隐白止血的实录金句**：“**妇人月经来了不停，或者是滴滴答答半个月还不干净，你灸隐白。怎么灸？拿一点点艾绒，搓成米粒那么大，放在隐白上面，用香一点，灸三壮五壮。她第二天就告诉你，少了。这个效果非常快，比吃药还快。**”
- **倪师手下针感体会**：“**隐白那个地方很小，你针下去，不要贪深。针尖进去一点点，病人会感觉脚大趾头酸酸的、胀胀的，有时候会像触电一样往脚背上面窜一下。这就对了。**”
- **倪师讲井穴急救**：“**病在脏取井。什么叫病在脏？比如说这个人突然昏倒了，你取井穴放血。脾脏的问题，你取隐白，把黑血挤两滴出来，人就醒过来了。**”倪师还特别提到，隐白放血对**小儿高烧惊厥**有奇效——点刺挤出两三滴血，烧就往下退。
- **倪师医案故事**：倪师在讲针灸时提到过一个案例——有位妇人崩漏几个月，西医说要刮宫，她害怕，来找倪师。倪师就在她**隐白和三阴交**上下针，隐白用灸，三阴交用针，留针二十分钟。起针后病人就说肚子不坠了。倪师让她回家自己每天灸隐白，灸了五天，血就彻底干净了。倪师说：“**你不要小看这个脚趾头上的小穴，它管的是脾经的气血总开关。**”
- **倪师针灸秘要**：“**隐白是脾经的井穴，井穴就是源头。源头的血是干净的。你把它打开，脏血排掉，新血才能归经。**”倪师还提醒：**隐白放血，挤到血色由黑变红就停，不要一直挤，挤多了伤正气。** 另外，**灸隐白治崩漏，要灸到血止就停，不可久灸**，因为井穴灸多了会耗气。
