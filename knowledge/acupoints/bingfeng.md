# 秉风

## 📍 经络归属与精准取穴法

秉风穴，归手太阳小肠经。在《针灸大成》里，秉风被列为“手太阳、阳明、手足少阳之会”——它是小肠经上唯一一个跟阳明、少阳四脉交会的穴位。这个“会”字很关键，意味着秉风的气化层次跨越了多条阳经，倪师在讲肩背区块时常说，凡是“会穴”，你下针就等于在同时调动好几条经的气，比单经穴位的覆盖面大得多。

秉风不是五输穴，不是原络郄募，它在小肠经的肩胛区块里扮演的是“散风舒筋”的角色。为什么叫“秉风”？“秉”是执掌、承受之意，这个穴在肩胛骨上面，是风邪容易客居的地方，也是肩背风气汇聚之所，所以倪师说它是“肩背风气的总开关”。

**倪师动态取穴法（大白话）：**

你先让病人坐着或者趴着，找到肩胛骨。肩胛骨上有一条横着的骨脊，叫肩胛冈。倪师的取穴口诀是：天宗穴往上找，在肩胛冈中点的上方凹陷处就是秉风。具体来说，你把肩胛冈想象成一条山脊，山脊正中间上方有一个“软坑”，那个坑就是秉风。

如果你从天宗穴定位，天宗在肩胛冈下窝的正中央，秉风就在天宗的正上方，跨过肩胛冈的那条线上。倪师喜欢用“手摸法”——你用大拇指从肩胛冈的外端（肩峰那边）往内推，推到中段的时候，会感觉骨头上面有个浅浅的凹窝，指头一按，病人会有酸胀感往肩臂放射，那就是秉风。

**下针深度：** 倪师说秉风直刺或斜刺，一般针五分到一寸。因为这个位置肌肉层比较薄，扎太深容易碰到骨头或者伤到肺尖（极瘦的人尤其注意），所以倪师反复强调“肩背的穴，得气即止，不要贪深”。

**禁针禁灸：** 秉风可灸，但倪师不主张在这里直接灸，因为肩背多筋骨，艾灸火力不容易渗透反而容易灼伤皮肤。他更倾向用针后加拔罐的方式来替代灸法，让风邪从针孔和罐口一起散出去。

## ⚡ 倪师经穴气化与破局心法

倪师讲秉风的气化，核心就一句话：**“秉风者，秉风而治风也。”**

这个穴的气血流注机理，从经络循行看，手太阳小肠经从手走头，经过肩胛，秉风正好在肩胛冈上。太阳经主表，是人体最大的“藩篱”，风邪袭人首犯太阳。秉风在肩胛这个位置，就像一面旗帜插在肩背上——风邪来了，它第一个接住，然后通过四脉交会的关系（阳明、少阳），把风邪从不同通道散出去。

**破局心法有三个层面：**

第一层，**散风解表、舒筋活络**。肩背僵硬、脖子转不动、落枕，倪师说这是风邪客于太阳经输，你在秉风下针，等于在风邪的老巢里开了一个口子，让风气从这里泄走。

第二层，**通调四经气血**。因为秉风是手太阳、阳明、手足少阳之会，倪师认为它有一种“中枢调度”的功能。肩臂痛、上肢麻木，不管是阳明经（手臂前侧）的问题，还是少阳经（手臂外侧）的问题，你都可以在秉风这里下一针，它能把几条经的气血同时疏通。

第三层，**降逆止咳、宽胸利膈**。这一点很多人不知道。倪师讲过，秉风虽然在肩胛上，但它下有肺脏的气机所过，针刺秉风可以间接调畅胸膈气机，对咳嗽气喘、胸胁满闷有辅助效果。这就是“经络所过，主治所及”加上“会穴互通”的双重作用。

**子母补泻与五行生克：**
秉风本身不是五输穴，所以严格来说不走子母补泻。但倪师讲，你要用五行思维来看它——小肠经属火，秉风在肩胛（上焦通心肺），小肠火要生脾土，秉风就是火生土路上的一个转动点。临床上肩背痛伴随消化不良的人，倪师会在秉风加针，再配合足三里，就是用小肠火去暖脾土的意思。

## 🎯 临床主治与配穴组合手印

**核心特效主治：**

第一，**肩胛疼痛、肩周炎**。这是秉风的第一主治。倪师说肩胛骨周围的痛，你分不清是哪条经的时候，秉风一针下去，整个肩胛区域的气就活了。尤其那种“肩胛骨缝里酸痛、手够不到后背”的症状，秉风是首选。

第二，**上肢酸麻无力**。从肩胛到手指的酸麻，秉风配合天宗、肩髃，三针一排，整条手臂的气血就通了。

第三，**落枕、颈项强痛**。倪师治落枕，常用秉风配后溪。后溪通督脉，秉风散太阳风邪，两个穴一远一近，一上一下，效果立竿见影。

第四，**咳嗽气喘、胸胁满闷**。这是秉风的“隐藏技能”，通过四脉交会的关系调畅胸膈。

**倪师经典对穴与排针组合：**

- **秉风 + 天宗 + 肩髃**：肩三针的变体，治肩周炎、肩臂不举。倪师说这三针扎完，让病人当场活动肩膀，往往针下痛减。
- **秉风 + 后溪**：治落枕、颈项强痛。后溪在手，秉风在肩，上下呼应。
- **秉风 + 曲池 + 合谷**：治上肢风邪麻木。曲池清阳明热，合谷开手阳明关，秉风散太阳风，三穴合用，从肩到指一路通到底。
- **秉风 + 膻中 + 肺俞**：治胸满咳嗽。秉风宽胸，膻中理气，肺俞宣肺，三穴合用，胸膈气机就转开了。
- **秉风 + 大椎 + 风池**：治外感风邪、肩背恶寒。大椎总督诸阳，风池散少阳风，秉风散太阳风，三穴把阳经的风邪一网打尽。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲肩背区块的时候，讲到秉风，原话大致是这样：

> “秉风这个穴，你看它的名字就知道了——秉，就是拿着、掌握着；风，就是风邪。这个穴就是专门管风邪的。它在肩胛骨上面，肩胛冈的中点上方。你摸到肩胛冈，正中间上面有个凹洞，那就是秉风。”

> “肩胛骨这一块的痛，你有时候分不清是太阳经还是少阳经，没关系，秉风一下去，它是四脉交会，太阳、阳明、少阳统统管到了。针下去以后，你让病人动一动肩膀，往往当场就松了。”

> “落枕的病人来，脖子歪着不能转，你先下后溪，再下秉风。后溪是通督脉的，秉风是散太阳风的，两个穴一配，脖子马上就松开了。这是我们临床上非常常用的一组对穴。”

> “秉风不要扎太深，五分到一寸就够了。肩背的穴，都是得气即止。你扎太深，第一容易碰到骨头，第二极瘦的人肺尖就在下面，扎深了会气胸。所以我说，肩背的穴，手法要轻，得气就好。”

倪师还特别提到一个临床体会：秉风下针后，针感不是那种剧烈的触电样感觉，而是一种“酸酸胀胀、往肩胛骨里面渗透”的感觉。他说这种针感说明气到了，效果就好。如果病人只有刺痛没有酸胀，那说明没扎到穴上，要调整角度。

在医案方面，倪师讲过他用秉风治肩周炎的经验：有个病人肩膀痛了半年，手举不起来，倪师在秉风、天宗、肩髃下针，留针二十分钟，起针后让病人举手，病人当场就能举过头顶。倪师说这不是神奇，是气通了而已——肩胛这块的气被秉风打开了，整个肩关节的气血就跟着活了。
