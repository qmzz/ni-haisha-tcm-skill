# 三焦俞

## 📍 经络归属与精准取穴法

- **所属经络**：足太阳膀胱经。背俞穴之一，为三焦之腑气转输、输注于背部的腧穴。
- **穴性定位**：三焦俞是背俞穴，不属五输穴体系（井荥输经合），但背俞穴本身即是脏腑之气在背部出入的门户。三焦为“决渎之官”，主通调水道，总司人体气化。三焦俞即是三焦之气在背部汇聚转输之处。
- **倪师动态取穴法**：倪师讲背俞穴的找法，一律以“骨度折量”为准，绝不能含糊。三焦俞在第1腰椎棘突下（即第13椎下——倪师讲督脉时习惯从大椎往下数），旁开1.5寸。怎么摸？先找命门穴——命门在第2腰椎棘突下，与肚脐正对，这是最好找的标杆。命门上一椎，就是第1腰椎，旁开1.5寸，即是三焦俞。两旁各一穴。倪师特别强调：1.5寸是同身寸，以患者本人的中指第二节横纹两端之间的距离为1寸，四指并拢为3寸，对折即1.5寸。不能拿医生的手去量病人的身体。
- **下针深度**：倪师讲背部穴位，针法是“斜刺”，不是直刺。三焦俞向下斜刺5分到1寸，针尖朝向脊柱方向斜入。为什么斜刺？因为背部靠近内脏——第1腰椎旁对应肾脏上缘区域，直刺深刺有风险。倪师原话：背部的针，一律斜刺，不要直刺，直刺容易扎到内脏。斜刺一样能得气，而且安全。
- **禁针禁灸法则**：三焦俞可灸可针，但灸法多用艾条温和灸或隔姜灸，不用直接疤痕灸，因为背部皮肤较薄。针刺时不可直刺过深，向内斜刺时注意角度，以得气为度。倪师强调膀胱经背部穴道“一概斜刺”，切记。


## ⚡ 倪师经穴气化与破局心法

- **经气气化机理**：三焦俞的气化核心在于“通调水道、总司气化”。三焦在中医里不是一块具体的肉，它是一个“腔”——上焦主纳、中焦主化、下焦主出。三焦俞就是三焦这个大腔的气在背部汇聚的“总开关”。倪师讲，三焦如果堵住了，水就停在那里不走——停在上焦胸闷，停在中焦腹胀，停在下焦小便不利。三焦俞的作用就是把这个“开关”打开，让气化重新运转起来。所以它治的是水的问题，但根子在气化。
- **倪师推演**：倪师讲背俞穴的排列，本身就是一幅人体气机运转的地图。从肺俞、心俞、肝俞、脾俞、肾俞一路下来，三焦俞夹在脾俞和肾俞之间——为什么？因为三焦的气化，上要靠脾的运化，下要靠肾的蒸腾。三焦俞在这里就是“中间协调员”，把上面的脾气和下面的肾气串联起来。所以三焦俞能“引火归元”吗？间接可以——它让下焦之火有路可走，不至于浮游在上。能“健脾行水”吗？当然可以——脾运化水湿，三焦通调水道，两套系统一个管“化”，一个管“通”，配合用效果倍增。
- **子母补泻与五行生克**：三焦俞本身是背俞穴，不是五输穴，没有直接的“虚则补其母、实则泻其子”的母子关系。但倪师讲，三焦经属火（三焦与心包络皆属相火），五行中火生土、水克火。三焦俞的运用心法：若三焦气虚、水道不通，可在三焦俞上施补法（捻转补法），同时配合脾俞补土以生金、以土制水；若三焦实热、水液壅滞，可在三焦俞上施泻法（捻转泻法），配合肾俞、膀胱俞以助排泄。倪师的原话精神是：背俞穴不讲母子，讲的是“通”——通就是补，堵就是实。


## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **水液代谢病症**：小便不利、水肿、腹水、尿少。三焦俞配膀胱俞、肾俞、水分，通利水道。
  - **中焦气滞**：腹胀、肠鸣、消化不良、泄泻。三焦俞配脾俞、胃俞、足三里。
  - **腰脊痛**：第1腰椎附近的腰背酸痛，三焦俞是局部取穴，配委中、昆仑通经止痛。
  - **消渴（糖尿病辅助调理）**：三焦气化不利导致的津液输布失常，倪师讲消渴要治三焦，三焦俞配胰俞（胃脘下俞）、肾俞、太溪。
  - **妇科水湿病症**：带下、月经不调属于水湿下注者，三焦俞配三阴交、阴陵泉。
- **倪师经典对穴与排针组合**：
  - **三焦俞 + 水分 + 阴陵泉 + 三阴交**：治水肿、小便不利。水分通利下焦水道，阴陵泉健脾利湿，三阴交调肝脾肾三经，三焦俞总司气化。这一组下去，水就动了。
  - **三焦俞 + 脾俞 + 胃俞 + 足三里**：治腹胀、消化不良。背部三俞齐下（三焦、脾、胃），前面再加足三里，前后呼应。
  - **三焦俞 + 肾俞 + 命门 + 委中**：治腰痛。局部取穴加远取，标本兼治。
  - **三焦俞 + 合谷 + 太冲（开四关）**：三焦气滞引起的全身气机不畅、情绪郁结，开四关理气，三焦俞调水道，气水同调。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲膀胱经背部俞穴时，三焦俞的篇幅不算最多，但倪师讲背俞穴的整体精神贯穿始终。以下是倪师讲义中与此穴相关的原汁原味精神要语：

倪师讲背俞穴总论时原话大意：
“背部的俞穴，统统是斜刺，你不要拿个针直直地扎进去，背后是肺、是心、是肝、是肾，你直刺下去，扎到肺就是气胸。所以从肺俞开始，一路下来，都是斜刺，针尖向脊柱方向斜进去，五分到一寸，得气就够了。”

倪师讲三焦的功能时原话大意：
“三焦是什么？三焦是决渎之官，水道出焉。决渎就是挖水沟、通水道。你身上水液代谢的问题，统统跟三焦有关系。三焦不通，上面喝水下面肿，中间肚子胀，这都是三焦堵住了。三焦俞就是管这个的。”

倪师讲三焦俞的定位时原话大意：
“三焦俞在哪里？你先找命门。命门跟肚脐正对，这是最好找的。命门上一椎，就是第十三椎下，旁开一寸半，就是三焦俞。你不要去数什么第几胸椎第几腰椎，肚脐对过去就是命门，简单明了。”

倪师讲治水肿的实战思路时原话大意：
“治水肿，你在三焦俞、水分、阴陵泉上下针，针一下去，小便就通了。为什么？三焦俞管气化，水分管分清泌浊，阴陵泉管脾，脾主运化水湿。三个穴道一配合，水就往下走。这就是针灸的巧妙，不用吃药，针下去水就动了。”

倪师讲背俞穴配腹募穴的排针心法（精神要语）：
“背部的俞穴和前面的募穴，一前一后，一阴一阳，配合用效果加倍。三焦的募穴是石门穴，在三焦俞和石门上下针，这叫俞募配穴法，前后夹击，三焦的气就通了。”

倪师讲针感体会时原话大意：
“针扎到三焦俞，得气的时候，病人会感觉到一种酸胀感，从背部往旁边扩散。有时候病人会告诉你，肚子里面好像在动，好像有气在跑——这就是三焦的气被引动了。这种针感，比吃药快得多。”

倪师讲课反复叮咛的一条铁律：
“背部的穴道，除了大椎、陶道可以直刺之外，其余的一律斜刺，而且不要深。你记住，背部扎针，安全第一，得气第二，不要贪深。斜刺下去，气到了，效果一样好，而且不会出事。”
