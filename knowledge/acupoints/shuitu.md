# 水突

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经，位于颈部，在颊车穴与气舍穴的连线上。
- **特定穴属性**：水突非五输穴、非原络郄募、非八会穴，它是足阳明胃经在颈部的经穴之一，紧邻人迎穴、气舍穴，是阳明经气自头面下行入缺盆、贯膈属胃这一气化通路上的关口要穴。
- **倪师动态取穴与骨度折量法（大白话）**：你从人迎穴往下摸，人迎在喉结旁开一寸半，有脉在跳。再往下一点，摸到脖子两侧有块大筋，就是胸锁乳突肌。水突就在这块大筋的前缘，人迎和气舍中间。你先摸到人迎，再摸到气舍，两个穴道正中间就是水突。找到后，你用手按下去，病人会觉得一块地方酸酸胀胀的，那就是穴道所在。下针的时候，针尖朝着脖子内侧方向，贴着皮肉慢慢进针，大概刺三分，不要太深。**禁灸**——脖子这个地方血管太多，一灸容易伤到血脉，倪师再三强调“颈项部禁灸”。下针也要避开颈动脉，看到动脉跳动的地方，针要闪开，不能直接扎在跳动的血管上。

## ⚡ 倪师经穴气化与破局心法

- **气化机理**：水突这个名字取得好，“水”是指水液、痰饮，“突”是冲撞、上突之意。阳明经多气多血，胃经的气血从这里往上传导到头部，如果阳明有热，或者痰饮随气上逆，就会在这地方堵住。水突就是把上冲的水气痰饮往下泄、往外散的一个穴道。它的作用机制是——降逆、利咽、散结。你把人迎到缺盆这一线想成一条河道，水突正好在河道拐弯的地方，下针就是给这条河道清淤，让水液顺利下行，不要往咽喉和胸腔冲。
- **子母补泻与五行生克**：水突属足阳明胃经，胃为戊土。倪师讲，阳明经多气多血，水突不是五输穴，但你要用五行生克来思考——土克水，水突这个“水”字，本身就暗示了它与水液的代谢有关。当胃土虚弱，不能制水，水气就上泛到咽喉。这时候你要在胃经上取穴，水突就是帮你把多余的水液代谢掉，同时你还得补土——比如足三里（胃经合穴，属土），或者补脾经的母穴大都（脾经荥穴，属火，火生土），让土强起来去制水。实症时，水突可以泻，用针尖朝上、逆着经脉方向斜刺，就是泻法，把多余的水气散掉。虚症时，水突一般不补，你去找足三里补，或者灸脾经的母穴，让土自己去治水。

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - 咽喉肿痛、声音嘶哑、咽中如有物阻（梅核气）、吞咽困难。
  - 咳逆上气、气喘、支气管炎、痰多。
  - 颈项强痛、甲状腺肿（瘿瘤）、淋巴结肿大。
  - 现代常用于治疗咽喉炎、扁桃体炎、支气管哮喘、甲状腺功能亢进、膈肌痉挛等。
- **倪师经典对穴与排针组合**：
  - **水突 + 天突 + 廉泉**：治咽喉一切疾患。天突降气，廉泉开音，水突利咽散结，三穴合力把咽喉这块的痰气冲开。
  - **水突 + 缺盆 + 膻中**：治咳逆上气、胸满。缺盆是胃经穴，在锁骨上窝，膻中是气会，水突把咽喉的逆气降下来，缺盆接住，膻中再一散，气就顺了。
  - **水突 + 合谷 + 少商（放血）**：治急性咽喉肿痛、扁桃体发炎。少商点刺放血，合谷通阳明经气，水突直接作用在病灶上。
  - **水突 + 足三里 + 丰隆**：治痰多、梅核气。足三里补土，丰隆化痰，水突利咽，三穴把痰湿从源头到出口全部打通。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在讲足阳明胃经颈部穴位时，提到人迎、水突、气舍这一排穴道，原话大意是——**“人迎这个地方，你摸，有脉在跳，这是胃经的大动脉。水突在它下面一点点，你找到人迎，再往下找，就是水突。这个穴道下针要小心，太深了不行，旁边就是血管。我们下针的时候，你拿手先把动脉拨开，然后贴着皮肉扎进去，针下去病人会感觉酸酸胀胀的，这就对了。禁灸，脖子上一律禁灸。”**

他又说：**“水突这个穴，顾名思义，水在这边突起来嘛。你咽喉肿痛，声音讲不出来，或者喉咙里面老是感觉有东西堵着，吞不下去吐不出来，这就是水气痰饮堵在这里。你在水突下针，针尖微微朝上，引气到咽喉，病人当场就觉得松了。小孩子扁桃体发炎，你水突配少商放血，效果很快。”**

关于针感，倪师描述：**“针下水突，病人会感觉整个脖子胀胀的，有时候会感觉一股气往下走，走到缺盆，再走到胸口。这就是逆气降下来了。你不要捻针太猛，脖子上的穴道，轻轻引气就好，强刺激反而伤气。”**

医案方面，倪师讲过他用**水突配天突、廉泉**治疗一位长期声音嘶哑的患者，患者是教师，讲课后喉咙干痛、声音出不来。倪师在水突下针，针尖朝上，天突朝下，廉泉朝上，三针齐下，留针二十分钟，起针后患者当场声音清亮许多。倪师说：**“这就是气机通了嘛。你光在喉咙上做文章不行，你要找它的源头，水突就是源头之一。”**
