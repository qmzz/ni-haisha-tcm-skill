# 浮白

## 📍 经络归属与精准取穴法

- 浮白穴属**足少阳胆经**，为足太阳、足少阳之会。在倪师的人纪针灸体系中，胆经多气少血，浮白位于耳后入发际处，与足太阳膀胱经交会，故能兼调太阳之表气。此穴非井荥输经合五输穴，亦非原络郄募俞八会，其定位重点在于“浮”字——浮者，浅也，阳气浮越于表，故取穴在头皮浅层。
- 倪师动态取穴法：先找**天冲穴**。天冲在耳根后缘直上，入发际两寸处。从天冲向后平移一寸，即为浮白穴。用手指沿耳廓向后摸，触到耳后高骨（乳突）后缘，再向上推入发际，天冲与浮白一前一后，相距一寸。倪师常讲：“耳后这一排穴，天冲、浮白、窍阴，像糖葫芦串在一条线上，你摸到天冲，往后一横指就是浮白。”骨度折量：耳后入发际一寸为天冲，后一寸为浮白，再后一寸为头窍阴。
- 下针深度：倪师强调**平刺或斜刺，针尖向后沿皮刺入五分至八分**，不可直刺过深。此处头皮薄，下方紧贴骨面，直刺深刺易伤骨膜，引发剧烈疼痛。禁灸——倪师明确说：“浮白这个穴，我从来不灸，为什么？头上本来阳气就浮，你再一灸，火上浇油，病人偏头痛更厉害。”故浮白禁灸，只针不灸。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演浮白的气化机理，核心在一个“浮”字与“白”字。浮者，阳气浮于表；白者，肺主白色，金气也。胆经属木，木能生火，浮白位于胆经而近太阳，倪师认为此穴能**引浮越之阳气归经，清上焦郁热**。当人愤怒、焦虑、思虑过度，阳气上浮不降，出现偏头痛、目痛、耳鸣、项强，浮白能像一根针扎破气球一样，把浮在头面的郁气泄掉。
- 临床开阖机理：浮白开耳后气机，使胆经郁火从太阳表散而出。倪师说：“胆经的气本来应该从脚走到头，从头再往下走。浮白在耳后，是胆经气机的一个转折点。病人如果胆经堵了，气冲到耳朵后面胀痛，你针浮白，气就从这个口子泄出去了。”
- 子母补泻：胆经属木，木之母为水（膀胱），木之子为火（小肠/三焦）。浮白非五输穴，倪师不直接用子母补泻，但以经络五行论，浮白近太阳膀胱，太阳为水，故浮白有“补水润木”之效。虚则补其母——胆经虚证（胆气不足、惊悸、目昏），可配膀胱经穴以补水养木；实则泻其子——胆经实火（偏头痛、目赤、耳聋），可配三焦经或小肠经穴以泻火。倪师心法：“浮白是胆经在头上的一个透气孔，实则开孔泄热，虚则引水润木，全看手法捻转。”

## 🎯 临床主治与配穴组合手印

- 核心特效主治：倪师临床用浮白，首重**偏正头痛**，尤其是耳后痛、后脑痛牵引至肩颈者。其次为**耳鸣、耳聋、目痛、齿痛**，属胆火上炎者。再有**项强、瘿气（甲状腺肿）、肩背痛**，因浮白近天冲、窍阴，能通利耳后经气。急症方面，倪师曾用浮白配风池、太阳放血，治急性偏头痛如裂。慢性病调理，浮白配足临泣、太冲，调胆经气机。
- 倪师经典对穴与排针组合：
  - **浮白 + 翳风 + 听宫**：治耳鸣耳聋。倪师排针：先针听宫（张口取穴），再针翳风，最后浮白平刺，三针成三角，气至耳中。
  - **浮白 + 风池 + 太阳**：治偏头痛。太阳放血，风池向对侧眼睛方向刺，浮白沿皮向后刺，三穴合围。
  - **浮白 + 天冲 + 头窍阴**：倪师称“耳后三针”，专治耳后神经痛、枕大神经痛。三针平行向后平刺，如三支箭射向风池方向。
  - **浮白 + 足临泣 + 阳陵泉**：治胆经实火之偏头痛、目赤。足临泣为胆经输穴，阳陵泉为合穴，下病上取，上病下取，上下呼应。
  - **浮白 + 合谷 + 太冲**：开四关基础上加浮白，治头面诸痛兼气机郁结。倪师说：“四关是总开关，浮白是耳后分开关，一起打开，头面气就通了。”

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在《人纪·针灸篇》讲浮白时原话：“浮白这个穴，你们看名字，浮是浮起来的浮，白是白色的白。什么浮起来？阳气浮起来。白色是肺，金。所以这个穴能清金降火，把浮在头上的热往下撤。偏头痛、耳朵后面痛，你针浮白，针下去不用深，五分就够了，沿皮刺，病人马上觉得耳朵后面松了。”
- 手下针感体会：倪师描述进针浮白时，针尖穿过头皮浅层，有轻微阻力，过皮后阻力顿失，针身可轻易沿骨面滑行。病人常有**耳后酸胀感向耳内或头顶放散**，少数敏感者会觉得一股凉气从耳后窜到脖子。倪师提醒：“如果病人喊痛得厉害，是你扎到骨膜了，赶紧退针，调整角度，沿皮再进。”
- 医案故事：倪师曾治一妇人，偏头痛二十年，痛在右耳后如锥刺，发作时呕吐、眼红。倪师取右侧浮白、天冲、风池，左侧合谷、太冲。浮白平刺后，行捻转泻法，病人当即说“像有人把耳朵后面的绳子剪断了”。留针二十分钟，头痛大减。倪师叹：“胆经的气堵在耳后，你不把它放出来，吃多少止痛药都没用。浮白就是那个放气的阀门。”
- 针灸秘要：倪师强调浮白禁灸，且**孕妇慎针**，因耳后诸穴近脑，气机敏感。针浮白时，手法宜轻，捻转角度不超过一百八十度，频率宜缓，以引气为主，不可猛泻。倪师说：“头上穴位，像在豆腐上扎针，你用力过猛，豆腐就烂了。要像蜻蜓点水，点到即止，气到病除。”
