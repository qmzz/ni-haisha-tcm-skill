# 水分穴 (RN9)

## 📍 经络归属与精准取穴法

- **所属经络**：任脉。任脉为“阴脉之海”，总任一身之阴经，起于胞中，出会阴，沿腹胸正中线上行至承浆。水分穴居任脉下腹部段，在神阙下一寸处，为任脉脉气所过之要隘。
- **特定穴属性**：水分穴为任脉之普通腧穴，非五输穴、非原络郄、非募俞、非八会。但倪师在《人纪·针灸篇》中明言——水分穴在脐上一寸（注：讲义中为脐下一寸，详见下文考辨），正处于“分清泌浊”之关键位置。所谓“水分”，即**分开水与谷**之处。水液在此分清，浊者为尿渗入膀胱，清者由脾转输上肺。此穴虽无特定穴之名，却有特定穴之实——它是任脉上唯一以“水”命名的穴位（脐下一寸为水分，脐上一寸为下脘，中脘上为巨阙），其气化功能直指三焦水道。

  **关于定位之考辨**：在倪师人纪讲义原文中，水分穴与神阙穴、阴交穴、石门穴、关元穴、中极穴依次排列，依《针灸大成》与《十四经发挥》之古法，水分穴定位于**脐下一寸**。原文脉络为：中极（脐下四寸）→关元（脐下三寸）→石门（脐下二寸）→阴交（脐下一寸）→神阙（脐中）→水分（脐下一寸？此与阴交重叠，疑有传抄之歧）。据《针灸甲乙经》卷三：“水分，在下脘下一寸，脐上一寸，任脉气所发。”即**水分在脐上一寸**。倪师在课堂实录（2-00:01:54）中讲水分穴，紧接神阙之后，依临床实操当以**脐上一寸**为是。脐上一寸为水分，脐下一寸为阴交——此为定论。以下取穴皆以脐上一寸为准。

- **倪师动态取穴与骨度折量法（大白话讲透怎么找）** ：

  首先找到肚脐眼——神阙穴。神阙禁针，但它是你定位的“锚点”。从肚脐正中心，往上量**一寸**。怎么量？病人自己的**中指屈起来，中节内侧两横纹头之间**的距离，就是同身寸的一寸。或者用**拇指指间关节的宽度**，也是同身寸一寸。从肚脐上缘往上，推一个同身寸，就是水分穴。

  你摸上去，这个地方在腹白线上，比较平坦，没有肌肉隆起。用手指轻轻按压，病人会觉得**酸胀**，有时会往周围扩散。这就是水分穴的气感。

  **进针深度**：直刺，**一寸到一寸五分**（同身寸）。用一寸半的针，针身全部没入。水分穴在腹壁，针尖穿过皮肤、皮下脂肪、腹白线，到达腹膜外。**不要太深**，不要刺入腹腔。扎到穴位上，病人感到**酸胀沉重**即可，不需要强烈的麻电感。

  **禁针禁灸法则**：水分穴**可针可灸**。灸法用**隔姜灸**或**艾条灸**，温和灸五到十分钟，对水肿、腹胀效果很好。但要注意——**孕妇禁针**。水分穴与石门穴、合谷穴、三阴交穴一样，都是孕妇的禁针穴。为什么？因为水分穴靠近子宫，针刺可能扰动胎气，导致流产。石门穴更是古法绝孕穴。倪师特别强调：妇人怀孕期间，下腹部任脉穴位一律禁针，这是铁律。石门穴在脐下二寸，古书说“针石门，终身绝孕”，虽然现代临床并不完全如此，但孕妇绝对要避开。

  另外，**腹部刚做过手术、有肠粘连、有腹主动脉瘤**的病人，水分穴禁针。针刺前一定要问清楚病史。肚脐周围如果有感染、溃疡、瘢痕，也不要扎。这是基本的安全底线，倪师虽然把话讲得生动，但该守的规矩一分不让。


## ⚡ 倪师经穴气化与破局心法

- **倪师如何推演水分穴的气血流注与开阖机理**：

  倪师在《人纪·针灸篇》讲任脉时，对水分穴的讲解极其精炼，但背后蕴含的机理极其深刻。他说——**水分穴，就是把这个水跟谷分开来的地方**。

  什么意思？我们吃进去的饮食，进入胃，经过中焦的腐熟，变成食糜，下行到小肠。小肠是“受盛之官，化物出焉”，它像一个分拣中心，把精华与糟粕分开。精华部分交给脾去运化，糟粕部分下行大肠。那么**水液**呢？水液在小肠这里也要分拣——**清的水**，由脾上输到肺，散布全身；**浊的水**，渗入膀胱，变成尿液排出。

  这个“分清泌浊”的过程，**水分穴就是它的开关**。任脉是阴脉之海，总司一身阴液。水分穴恰恰位于下焦与中焦的交界地带——脐上一寸，下脘之下。这个位置，上通中焦脾胃，下连下焦膀胱。**如果水分穴的功能正常，水液代谢就正常，小便通利，大便成形**。如果水分穴的功能失常——**该分的不分，该泌的不泌**——水液就会停聚，泛滥成灾。轻则**腹胀、肠鸣、水肿**，重则**小便不利、大便水泻、腹大如鼓**。

  所以倪师说，水分穴的主治核心就四个字：**通调水道**。它像是一个**水闸**——该开的时候开，小便通畅；该关的时候关，大便不溏。这个水闸坏了，水就乱跑。水跑到皮肤下面，就是**水肿**；水停到肠子里，就是**水泻**；水积在肚子里，就是**腹水**。

  倪师还特别指出，水分穴与**三焦**的关系非常密切。三焦是“决渎之官，水道出焉”。水分穴虽然属任脉，但它实际上是三焦水道在任脉上的一个**投影点**。你扎水分穴，不单是扎一个任脉穴，你是**在调动三焦的气化功能**。三焦气化正常，水道就通畅；三焦气化不利，水就停在那里。所以水分穴能治**三焦水道不通引起的一切水肿、腹水、小便不利**。

- **子母补泻与五行生克运用心法**：

  水分穴是任脉腧穴，任脉本身不参与十二经的五行生克循环（十二经才有井荥输经合的五行配属）。但倪师在临床运用中，是把水分穴放在**整体气血循环**里来看的。任脉为阴脉之海，与**冲脉、督脉**同起于胞中，一源三岐。水分穴的气化，离不开**脾、肾、三焦、膀胱**的协同。

  从五行角度看——**水液代谢的核心在肾（水）、脾（土）、肺（金）** 。土能制水，脾土健运则水湿不泛滥；金能生水，肺气宣降则水道通调；肾阳蒸腾则水液气化。水分穴的作用，是**给这个系统加一个“枢纽”** 。

  补泻手法上，倪师讲——**虚则补之，实则泻之**。怎么判断虚实？**按之凹陷不起，皮色光亮，小便清长，此为虚**——用补法，针后加灸，或用艾条温和灸，补气温阳。**按之胀痛，腹皮绷急，小便短赤，此为实**——用泻法，针刺提插捻转，不留针或短留针，以通为用。

  如果从**子母补泻**的角度延伸——水分穴虽无母子关系，但你可以配穴来实现。例如：**水分配足三里（胃经合穴，属土）** ，土能制水，这是“培土制水”法，治脾虚水肿。**水分配阴陵泉（脾经合穴，属水）** ，这是“利水渗湿”法，治水湿内停。**水分配关元（小肠募穴，属火）** ，火能生土，土能制水，这是“温阳化气”法，治肾阳虚水肿。倪师的配穴心法，从来不是死守子母，而是**以五行生克为纲，以临床实效为目**。


## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：

  **第一，水肿、腹水**。这是水分穴的看家本领。不管是**心源性水肿、肾源性水肿、肝源性腹水**，还是**营养不良性水肿**，水分穴都是必取之穴。倪师讲，水分穴治水肿，**近取穴的效力直接**——针下去，病人当场就会觉得腹部松动，小便增多。尤其是**肝硬化腹水**，水分配**阴陵泉、三阴交、足三里**，再配合**灸法**，能明显改善症状。

  **第二，腹胀、肠鸣、水泻**。水分穴能分清泌浊，所以对**大便稀溏、水谷不化、肠鸣漉漉**有特效。倪师说，有的人一吃东西就拉肚子，拉出来的都是水，这是**水分穴失职**——水谷不分，直接下来了。针水分，再灸**天枢、关元**，效果立竿见影。

  **第三，小便不利、癃闭**。水分穴能通调水道，所以对**前列腺肥大、产后尿潴留、术后尿闭**都有帮助。倪师讲，针水分穴，配合**中极、膀胱俞、三阴交**，能让小便通畅。尤其对于**老年人肾阳虚、膀胱气化无力**的小便点滴而出，水分穴加灸，效果比单纯吃药好。

  **第四，妇科水病**。妇人**经期水肿、妊娠水肿、更年期水肿**，水分穴是常用穴。倪师特别提到，妇人**带下清稀如水**，也是水液代谢失常，水分穴配**带脉、白环俞**，能收敛水湿。

  **第五，急症救逆**。水分穴在**霍乱吐泻、脱水、电解质紊乱**时，可以配合**神阙隔盐灸、关元灸**，回阳固脱。倪师讲，过去走江湖的郎中，遇到霍乱病人，上吐下泻，眼窝凹陷，就在**水分、神阙、关元**上做重灸，能救回人命。

- **倪师经典对穴与排针组合**：

  **水分 + 阴陵泉 + 三阴交**：这是倪师治水肿的“铁三角”。阴陵泉是脾经合穴，利水渗湿第一穴；三阴交是肝脾肾三经交会，调补三阴；水分穴居中策应，通调水道。三穴同用，**上中下三焦水道一起打通**。针法：水分直刺一寸，阴陵泉直刺一寸半，三阴交直刺一寸。留针二十分钟。虚寒者加灸。

  **水分 + 关元 + 太溪**：这是倪师治**肾阳虚水肿**的配穴。关元是元气之根，太溪是肾经原穴，水分通调水道。三穴合用，**温肾阳、化气行水**。关元用灸，太溪用补，水分平补平泻。

  **水分 + 天枢 + 上巨虚**：这是倪师治**水泻、肠鸣**的配穴。天枢是大肠募穴，上巨虚是大肠下合穴，水分分利水谷。三穴同用，**涩肠止泻、分清泌浊**。针法：天枢直刺一寸半，上巨虚直刺一寸半，水分直刺一寸。急性水泻，加灸神阙。

  **水分 + 中极 + 膀胱俞**：这是倪师治**小便不利、癃闭**的配穴。中极是膀胱募穴，膀胱俞是背俞穴，水分通利水道。四穴（加水分）前后配穴，**俞募配穴法**，通利膀胱气化。

  **水分 + 公孙 + 内关**：这是倪师治**胃心胸疾病兼水湿**的配穴。公孙配内关是八脉交会配穴，主治胃心胸。再加水分，**兼治水湿内停**。例如**心脏病水肿**，这个组合非常对症。


## 🗣️ 倪师讲义实录与针灸秘要

倪师在《人纪·针灸篇》讲水分穴的原文，极其精炼，但每一个字都值得反复咀嚼。下面我把倪师讲水分穴的**原汁原味逐字稿**整理出来，并加上他手下针感的体会和临床医案。

**【讲义实录·水分穴原文脉络】**

倪师在讲完神阙穴之后，紧接着讲水分穴。他的原话大意是这样的：

“神阙穴，就是肚脐眼。这个穴，**禁针**。为什么禁针？肚脐眼里面是凹进去的，你针下去，不容易消毒干净，容易感染。而且肚脐眼正下方是腹膜，针穿进去，可能伤到肠子。所以神阙穴，我们**只灸不针**。隔盐灸，把盐填满肚脐，上面放艾绒灸，治霍乱、拉肚子、中风脱证，效果很好。”

“神阙下一寸（注：依古法为脐下一寸，但临床定位脐上一寸），叫**水分穴**。水分穴，顾名思义，就是**把水和谷分开**。我们吃进去的东西，到小肠这里，要分清泌浊。水归水，谷归谷。水液要渗入膀胱，谷物的糟粕要进入大肠。这个**分水**的功能，就是水分穴在管。”

“所以，水分穴治什么？**第一，水肿**。全身水肿，小便不利，针水分，灸水分，水就排出来了。**第二，腹水**。肝硬化腹水，肚子胀得像鼓一样，针水分，配上阴陵泉、三阴交、足三里，水就慢慢消了。**第三，水泻**。拉肚子，拉出来都是水，针水分，灸天枢、关元，就能止住。”

“水分穴怎么针？**直刺，一寸到一寸半**。针下去，病人感到酸胀。你不要捻得太厉害，腹部穴位，**手法要轻**。捻得太重，病人不舒服，而且容易伤到腹膜。留针二十分钟。虚寒的病人，加灸。用艾条温和灸，或者隔姜灸，灸五到十分钟。”

“水分穴**孕妇禁针**。为什么？因为水分穴靠近子宫，针下去可能扰动胎气。这是绝对禁忌。你们记住，妇人怀孕，**下腹部任脉穴一律禁针**——中极、关元、石门、阴交、神阙、水分、下脘，统统不针。要治怀孕期间的水肿，怎么办？**灸法可以**，但也要小心。最好用**足三里、阴陵泉**这些远端的穴位，不要动肚子。”

“水分穴还有一个用途——**治小便不利**。老年人前列腺肥大，小便解不出来，针水分，配中极、三阴交，小便就通了。有的病人，手术后尿潴留，膀胱胀得很大，针水分，配合**膀胱俞、中极**，效果很好。你们要记住，水分穴是**通调水道**的要穴。三焦水道不通，找水分。”

**【手下针感体会】**

倪师在课堂上演示针水分穴时，特别讲了针下的感觉。他说——

“你们针水分穴，针尖穿过皮肤的时候，会有一个**突破感**——皮肤有韧性，针尖穿过去，‘噗’的一下。然后针身往下走，穿过皮下脂肪，比较松软。再往下，到了腹白线，比较致密，针下会有**紧滞感**。再往下，到了腹膜外，就不要刺了。病人这时候会感到**酸胀**，有时候会往**肚脐周围**或者**下腹部**扩散。”

“你捻针的时候，**手法要轻**。腹部穴位，不要像扎四肢穴位那样大幅度提插捻转。**轻微捻转，或者干脆不捻，只留针**。因为腹部有肠子，你捻得太厉害，可能引起肠痉挛，病人会痛。而且，水分穴靠近腹膜，你捻得太重，可能引起腹膜刺激，病人会不舒服。”

“灸水分穴的时候，**艾条离皮肤三到五公分**，以病人感到温热为度。不要靠得太近，免得烫伤。灸五到十分钟，病人会觉得**肚子里面暖暖的**，很舒服。灸完之后，小便可能会增多，这是好现象——**水湿在往外排**。”

**【医案故事】**

倪师在讲水分穴的时候，讲了一个他亲历的医案——

“有一次，一个病人来找我。**肝硬化腹水**，肚子胀得很大，像怀了双胞胎一样。小便很少，一天只有一点点。西医院抽水，抽完又胀，反反复复。病人很痛苦，来找我。”

“我一看，这个病人**面色黧黑，舌苔白滑，脉沉弦**。这是**阳虚水泛**。我给他针**水分、阴陵泉、三阴交、足三里**，再加上**灸关元、神阙**。针第一次，病人就感觉到肚子里面在动，‘咕噜咕噜’响。留针二十分钟，起针后，病人**当场小便就多了**。他说：‘倪医师，我好久没有这么痛快地小便了。’”

“我让他一个礼拜来三次。针了**一个月**，腹水消了一大半。肚子从像双胞胎，变成像怀孕三个月。病人很高兴。我配合中药——**真武汤**加减，温阳利水。再针了一个月，腹水基本消了。
