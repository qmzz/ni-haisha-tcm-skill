# 养老

## 📍 经络归属与精准取穴法

- **所属经络**：手太阳小肠经。小肠经与手少阴心经相表里，心属火，小肠亦属火，此经多气多血，主液所生病。
- **特定穴属性**：**郄穴**。郄穴者，气血深聚之处，专治本经急性痛证与血症。手太阳小肠经郄穴即养老穴，阳经郄穴善治急性痛证，尤以肩背颈项急性疼痛、目赤肿痛、急性腰痛为要。
- **五行定位**：小肠经属火，养老为郄穴，郄穴不参与井荥输经合的五行配属，但以火经论之，郄穴有 **“泄热开郁、通调小肠之气”** 之功。小肠主泌别清浊，养老一穴能助小肠气化，分清泌浊，故对小便不利、目视不明、肩臂疼痛皆有通达之力。
- **倪师动态取穴与骨度折量法**：

  **取穴口诀**：**“掌心向胸，骨缝中取”** 。

  倪师在人纪针灸篇中反复强调，养老穴的取法跟一般穴位不一样，它 **“藏在骨缝里”** ，你必须用手去摸、去拨，才能找到那个真正的穴道。具体手法如下——

  **大白话讲透**：你让病人把手掌翻过来，掌心朝向自己的胸口，手背朝外，手肘弯曲，前臂横放胸前。这个时候，你在尺骨小头（手背侧腕后那个凸起的高骨）的桡侧缘——就是靠近大拇指那一侧——用大拇指顺着骨缝往里推，会摸到一个明显的**凹陷骨缝**。这个凹陷，就是养老穴。

  **为什么叫“养老”？** 倪师说，这个穴道藏在骨缝之中，好像人老了之后，骨头之间的缝隙显露出来，穴道也藏在那里。另外一个意思是，这个穴道能治很多老年人的毛病——眼睛看不清、肩膀抬不起来、腰酸背痛，所以叫“养老”。它在骨缝里，你按下去的时候，病人会有一种**酸胀感往手掌或肩膀方向传导**，那就找准了。

  **下针深度**：倪师讲，养老穴下针，一般**针入五分至七分**即可，不要深刺。因为它在骨缝之间，深刺容易伤到骨膜，反而不好。针下去之后，针尖是**沿着骨缝斜刺**，方向朝向肘部或腕部，顺着骨缝的角度走。

  **禁针禁灸法则**：养老穴一般**不灸**。倪师说，郄穴多用于急性痛证，灸法偏温补，与郄穴泄热开郁的性子不太合。除非是极寒之证、气血凝滞，才可考虑温针，但一般临床以针为主，**灸法少用或不用**。


## ⚡ 倪师经穴气化与破局心法

- **经穴气化与开阖机理**：

  倪师讲小肠经的时候说，小肠者，**“受盛之官，化物出焉”** ，它的主要功能是接收胃中腐熟的水谷，进一步分清泌浊。清者上输，浊者下渗。小肠之气如果不能正常运化，就会出现**“液所生病”**——比如小便短赤、目黄、耳聋、咽痛、肩臂外后廉痛。

  养老穴作为小肠经的郄穴，它的气化机理，倪师推演为 **“通调小肠气化、开窍明目、利窍止痛”** 。这穴的性子是**通、开、利**三个字：

  - **通**：通小肠之气，通气机之闭。小肠气滞则肩背痛、腰腿痛，养老能通之。
  - **开**：开目窍。小肠经上行至目锐眦，养老能开目窍之郁，治目视不明。
  - **利**：利关节。小肠经经过肩胛、颈项，养老能利肩臂关节之活动，治肩臂疼痛、颈项强痛。

  倪师说，养老穴最特殊的地方，在于它**藏在骨缝里**，所以它能“**入骨通髓**”。你看老年人为什么会眼花、为什么骨头会痛？因为骨髓不足了。养老穴藏在骨缝之中，针下去能通到骨缝之间的气脉，引气血入骨，所以对老年人特别管用。这是一个**引气血入骨**的穴道，是“以骨治骨”的取穴法。

- **子母补泻与五行生克运用心法**：

  小肠经属火，其母穴为**后溪**（木穴，木生火），其子穴为**阳谷**（土穴，火生土）。养老穴是郄穴，不直接参与子母补泻的选取。但倪师说，如果你要从五行生克的角度来用养老穴，可以这样思考——

  老年人眼睛不行了，肩膀也痛了，这是**火气衰了，木气也弱了**。小肠经的火不足，不能生土（脾），土不能生金（肺），金不能生水（肾），肾水一弱，骨头就痛了。养老穴藏在骨缝里，你针它，它能把**心火之气引到骨缝里去**，把火气归到骨中去，这就叫 **“引火归元”**——不过这里归的是“骨元”，是引火入骨、引火生土、引土生金。所以养老穴虽然不是子母补泻里的直接补泻穴，但它能**调和小肠经火气，使之归入骨骼之中**，这在倪师的经验里是很重要的一个心法——

  **“小肠经的郄穴，能引火入骨，能引血入骨，能引气入骨。老年人骨节痛、眼花、腰痛，养老针下去，火气就到了骨头里。”**


## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：

  1. **目视不明**：老年人眼花、目眩、视力模糊，这是养老穴的第一特效主治。《针灸大成》云： “养老主目视不明。”倪师说，你碰到现在年轻人天天看手机，眼睛干涩、视力模糊，这也是小肠经气不能上荣于目，针养老有效。
  2. **肩臂疼痛**：肩背酸痛、臂痛不能上举、颈项强痛，尤以小肠经循行部位的酸痛为特效。倪师说，肩膀痛得手抬不起来，你在养老穴下一针，同时让病人活动肩膀，痛就去了一大半。
  3. **急性腰痛**：郄穴治急症，急性腰扭伤、闪腰岔气，针养老配委中，效果立竿见影。
  4. **小便不利**：小肠主液，养老能通调小肠气化，对小便短赤、尿频、尿急有辅助疗效。
  5. **耳聋耳鸣**：小肠经入耳中，养老能通耳窍，对耳聋耳鸣有开窍之功。

- **倪师经典对穴与排针组合**：

  1. **养老 + 后溪**：后溪是小肠经的俞穴（木穴），通督脉。养老配后溪，一郄一俞，一开一合，专治**颈项强痛、肩背酸痛、落枕**。后溪通督脉，养老通小肠，两针齐下，从颈到肩到腰，一气贯通。
  2. **养老 + 睛明 + 光明**：养老配睛明（膀胱经起点，治目疾）配光明（胆经络穴，治目疾），三针合用，专治**目视不明、老年眼花**。倪师说，光明是胆经的络穴，别走肝经，肝开窍于目；养老是小肠郄穴，小肠经至目锐眦；睛明是足太阳膀胱经起点，也是目内眦。三针一下，眼睛的气血就通了。
  3. **养老 + 委中**：养老是手太阳郄穴，委中是足太阳合穴（血郄）。两太阳经相配，郄穴配血郄，专治**急性腰背痛、急性腰痛**。倪师说，委中本来就治腰背痛，“腰背委中求”，再加养老，一上一下，太阳经气就通了。
  4. **养老 + 足三里 + 三阴交**：这是倪师常用的**老年人保养针方**。养老引气血入骨，足三里补脾胃之气，三阴交调三阴经之血。三针合用，气血双补、筋骨同调，专治**老年人气血两虚、筋骨酸痛、目视不明、小便无力**。


## 🗣️ 倪师讲义实录与针灸秘要

- **倪师讲养老穴的原汁原味金句**：

  > “养老穴，你注意看，它为什么叫养老？因为它藏在骨缝中间。你看那个尺骨小头，你手掌翻过来朝自己，骨头缝就开了。这穴道藏在骨头缝里，你摸到那个缝，针下去，这才是养老。你手不翻，那个缝是闭着的，你扎不到。”

  > “养老穴是手太阳小肠经的郄穴。郄穴是什么？郄穴是气血深聚的地方，是专门治急症的。所以你看，急性腰痛、闪到腰、脖子突然不能转、肩膀突然痛得抬不起来——郄穴都可以用。但养老这个郄穴不一样，它还能治眼睛，还能治老年人骨头酸痛。为什么？因为它在骨缝里，能引气血入骨。”

  > “你碰到一个老太太，眼睛看不清楚了，肩膀也抬不起来了，腰也酸，膝盖也痛——你怎么办？你针养老，再针足三里、三阴交，再针睛明、光明。针完以后你跟她说，你回去动一动肩膀。她一动手，哎，怎么松了？怎么眼睛也亮了一点？这就是小肠经的气血通了。”

  > “养老穴下针，五分就够了，不要深。针下去之后，你用手去摸那个骨缝，针是在骨缝里面的，那个气是往骨头里走的。你不要提插得太猛，轻轻地捻针，让气慢慢渗到骨缝里去。这叫‘引气入骨’。”

  > “为什么养老不灸？郄穴是泄热开郁的，灸了反而把火气堵住了。养老是通气的，不是补气的。你要补，找足三里、关元去补。养老是开路的，是通气的，是把火气引到骨头里去的。你灸它，就变成火上浇油了。”

- **实战手下针感体会**：

  倪师在视频中演示养老穴取穴时，反复强调 **“手掌要翻过来朝自己”** 。他说，你不翻手，骨缝是合着的，你摸不到那个凹陷。你一翻手，尺骨小头就转开了，那个缝就露出来了。针下去的时候，针尖要**顺着骨缝的方向**，不要横着扎。病人会有一种**酸胀感从手腕往肩膀方向走**，有时候会传到手指。如果病人说“酸到肩膀了”，那这个针就到位了。

- **医案故事**：

  倪师在讲义中提到，临床上很多老年人**眼花、肩痛、腰痛**三样一起来。他常用养老配光明、睛明、足三里、三阴交。有一个案例，一个六十多岁的太太，眼睛看东西模糊，肩膀痛得不能梳头，腰也酸得不能久站。倪师针养老（双侧）、睛明、光明、足三里、三阴交，留针二十分钟。起针后，老太太说眼睛亮了一些，肩膀也松了。倪师让她回去每天自己按养老穴，配合热敷肩膀。两周后复诊，眼睛明显好转，肩膀也能抬起来了。

  倪师总结说： **“养老穴是老年人的好朋友。你把养老穴用好了，很多老年人的毛病，不用吃药，针几次就好了。”**

---

**总结**：养老穴是手太阳小肠经的郄穴，藏在尺骨小头桡侧的骨缝中，取穴时必须掌心向胸、骨缝中求。它的核心机理是**通小肠之气、开目窍、利关节、引气血入骨**。临床上专治老年人目视不明、肩臂疼痛、急性腰痛、小便不利。配后溪治颈肩，配睛明治目疾，配委中治急性腰痛，配足三里三阴交作老年人保养针方。倪师心法在于 **“郄穴治急，骨缝入骨，引火归元，通调小肠”** 十六个字。
