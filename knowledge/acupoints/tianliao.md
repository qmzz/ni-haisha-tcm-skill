# 天髎

## 📍 经络归属与精准取穴法

- 天髎归属**手少阳三焦经**，为**手足少阳与阳维脉之会**。在倪师的人纪体系中，三焦经主“气化”与“水道”的枢转，天髎地处肩颈交界，是少阳枢机与阳维脉维系诸阳的交汇点，故其性善“转枢利节、通达上焦”。
- 天髎不是五输穴，也不是原络郄募俞，它的身份是**会穴**——手足少阳与阳维之会。阳维主“维络诸阳”，阳维为病苦寒热，所以天髎能通调上焦表卫之气，把阳经的气血像网一样兜住。
- 精准取穴：在肩胛骨上角处，**肩井与曲垣连线的中点**，也就是第七颈椎棘突下与肩峰连线中点再往后到肩胛骨上角之间的凹窝里。白话讲：先找到脖子后面最突的那块骨头（大椎），再往外摸到肩膀最高点（肩峰），这两者连线中点偏内侧、按下去有个明显的凹陷，就是天髎。
- 倪师特别强调：天髎与肩井、曲垣、秉风相邻，取穴时会摸到**肩胛骨上角内侧缘**，针尖要贴着骨缘向内下斜刺，而不是直刺。直刺容易扎到肺尖，造成气胸，倪师对此反复告诫。
- 下针深度：**0.5～0.8寸**，斜刺或平刺，针尖朝肩胛骨上角方向。禁深刺，禁向内下直刺过深。灸法可温和灸3～5壮，但倪师说此穴近肺尖，灸也宜少宜温，不宜大壮多灸。
- 骨度折量参考：从大椎到肩峰为**12寸**，天髎约在肩胛骨上角内侧，距脊柱约**6～7寸**水平。摸骨关键是先定肩胛冈与肩胛骨上角，再向上推到第一肋间水平的凹陷。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演天髎的气化，核心在**“少阳枢转、阳维固表”**。三焦为决渎之官，主气化水道，天髎居肩颈，是上焦气机往头面、肩背布散的关口。气到此处若堵住，就像水管拐弯处积了气，肩背就僵、转头就痛、手臂就麻。
- 天髎的气血流注特点是**“上通头角、外达肩臂、内应胸膈”**。它能引上焦郁热下行，也能把阳维脉兜住诸阳的气重新分布到肩颈。倪师说：肩背僵硬如板、转头卡住、落枕一周不好，针天髎配肩井，气一松，整个人像卸了枷。
- 子母补泻：天髎本经为手少阳三焦经，三焦五行属**火**。其母穴为**中渚**（木生火），其子穴为**天井**（火生土）。但天髎本身是会穴，不是五输，所以倪师用天髎时不以它做子母补泻，而是**借它通阳维、转少阳枢机**。若三焦火虚、气化无力，先补中渚，再取天髎导气上达；若三焦火郁、肩颈热痛，先泻天井，再用天髎开郁散结。
- 五行生克上，三焦火与心包火相表里，天髎可借阳维联系诸阳，间接助心火温煦肩背。所以倪师治**寒凝肩背、阳气不到**之证，常在天髎上加灸，取“火郁发之”之意。

## 🎯 临床主治与配穴组合手印

- 核心主治：
  1. **肩颈强痛、落枕、转头不利**——天髎是肩背气机枢转点，单针天髎配肩井、后溪，即效。
  2. **肩胛上角痛、上肢酸麻**——天髎配曲池、外关，通少阳与阳明，气到痛止。
  3. **热病汗不出、寒热往来**——阳维为病苦寒热，天髎配外关、风池，解表通阳。
  4. **胸膈满闷、上焦气郁**——天髎配膻中、内关，开上焦气结。
- 倪师经典对穴组合：
  - **天髎 + 肩井**：松肩颈如解绳结，治一切肩背板滞。
  - **天髎 + 外关**：外关通阳维，天髎会阳维，二穴合用，维脉气通，寒热自解。
  - **天髎 + 后溪**：后溪通督脉，天髎转少阳，治颈项强痛、落枕特效。
  - **天髎 + 天宗 + 秉风**：肩胛三针，治肩胛痛、上肢不能后伸。
  - **天髎 + 内关 + 公孙**：若胸膈气闷兼胃心胸不适，先开公孙内关，再取天髎导上焦之气。
- 急症救逆方面，天髎不主回阳，但治**热闭、气闭于上**之证，可配大椎、曲池、合谷点刺放血，再针天髎引气下行。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在针灸篇讲肩颈部穴位时原话大意：**“天髎这个穴，你们不要看它小，它是手足少阳和阳维的会穴。阳维是什么？阳维就是专门管你身上所有阳经的网。阳维脉有问题，人就忽冷忽热，肩膀像被绳子绑住。天髎一针下去，那个绑住的绳子就松开了。”**
- 手下针感体会：倪师说针天髎时，针尖要贴着肩胛骨上角的内侧缘进去，病人会有**酸胀感往肩胛骨里面透，或者往手臂外侧放散**。如果针下去病人说“像电到手指”，那是扎太深碰到神经了，要立刻退针。正常得气是**沉、紧、酸、胀**，不是刺痛。
- 医案故事：倪师曾治一妇人，**落枕半个月**，脖子歪一边，针肩井、后溪、风池皆不效。倪师改针**天髎透向肩井方向**，留针二十分钟，起针后妇人头即能转正。倪师说：**“这就是阳维脉被寒束住了，你光扎太阳经没用，要扎到阳维的会穴上，把那个网打开。”**
- 倪师又讲：天髎近肺尖，**“你们不要逞能，不要深针，不要直刺，不要向内下斜刺。针尖贴骨走，安全又有效。灸可以，但少灸，三五壮就好，肺在上面，灸多了热入肺，反而咳。”**
- 关于禁针禁灸：天髎**可针可灸，但禁深针、禁直刺向内下、禁大壮多灸**。倪师说：**“凡是靠近肺尖的穴，你都要当作老虎嘴巴，针可以，但要斜着、浅着、贴着骨头走。”**
