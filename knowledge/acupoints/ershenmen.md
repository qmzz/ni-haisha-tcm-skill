# 耳神门

## 📍 经络归属与精准取穴法

- **所属经络与特定穴属性**：耳神门属**耳针体系**，非十二正经腧穴，为耳廓三角窝内的特定刺激点。倪师在《人纪·针灸篇》中将其归入**耳针治疗系统**，与心经原穴“神门”同名异位，但气化功能相通——心主神明，耳神门即为**调神安神之耳部总开关**。在五行归属上，耳神门对应**心火**，因其安神定志之功，临床上视为心经在耳廓的**络应之点**，与心、肝、肾三脏关系最密。倪师强调：耳针的穴位不是按经络走向找，而是按**解剖对应区**找，耳神门位于三角窝内，是调节大脑皮层兴奋与抑制的核心点位。

- **倪师动态取穴与骨度折量法**：倪师取耳神门，大白话讲——**先把耳朵翻过来看背面，再翻回正面**。三角窝在耳轮脚上方、对耳轮下脚与对耳轮上脚之间形成的三角凹陷区。耳神门就在三角窝**靠近对耳轮上脚与对耳轮下脚交汇处**、三角窝尖端偏内侧。倪师取穴手法：用探针或火柴棒头在三角窝内**按压寻找最敏感的那个点**，病人喊“酸麻胀痛最明显”的地方就是耳神门。**下针法则**：一般用**短毫针（0.5寸）斜刺或直刺2-3分**，不穿透耳软骨为度；也可用**王不留行籽贴压**，此为倪师最常用的方式——贴上去让病人自己按，一天按三五回，每回按到酸胀为度。**禁针禁灸**：耳廓**禁灸**，因为耳软骨薄，灸了容易烫伤软骨导致耳廓变形；**耳廓有感染、冻疮、溃疡时禁针禁贴**。倪师特别交代：**孕妇慎用耳神门**，因其安神之力强，恐有坠胎之虞，非必要不针。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演耳神门的气血流注与开阖机理**：倪师讲，耳神门的机理就是四个字——**引神归舍**。人为什么会失眠、焦虑、烦躁？因为**心神外越，不能内守**。耳神门这个点，通过耳廓与脑、心之间的密切联络（倪师说“耳为宗脉之所聚”，十二经都通耳），一刺激它，就像给大脑皮层发了个信号——**该收工了，神该回来了**。它的气化机理是**潜阳入阴、引火归元**。阳气白天在外干活，晚上要回到阴里面休息；阳不入阴就是失眠。耳神门就是把浮越在外的阳气拽回来，让它归到肾水里面去，这就是**水火既济**。另外，耳神门还有**开窍醒神**的作用，这是双向调节——你昏沉嗜睡它也管，你亢奋失眠它也管，它调的是**神机的开阖**，不是单向的镇静。

- **子母补泻与五行生克运用心法**：耳神门对应心火，按五行生克，**虚则补其母**——肝木生心火，故心气不足、神明无主之虚证（如健忘、恍惚、心悸而脉弱），可配**耳穴肝**来补母生火；**实则泻其子**——心火生脾土，故心火亢盛、烦躁狂越之实证（如癫狂、口舌生疮、小便赤涩），可配**耳穴脾**来泻子夺火。倪师更常用的心法是：**耳神门配耳心**，此为心与神门同气相应，直接调整心的阴阳；若涉及肾水不足、心火独亢（心肾不交之失眠），则**耳神门配耳肾**，一潜一滋，水火既济。倪师总结一句口诀：**神门调其神，心肾治其本，肝脾调其路**。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **急症救逆**：晕针、晕车、突发心悸、惊恐发作——倪师常用耳神门**重按**急救，配合**耳心**稳定心神。
  - **失眠焦虑**：这是耳神门的**看家本领**，无论入睡困难、早醒、多梦、还是焦虑烦躁，耳神门贴压几乎是倪师耳针的**第一选择**。
  - **痛症特效**：各种疼痛——头痛、牙痛、胃痛、痛经、术后疼痛，耳神门有**镇痛安神**之功，尤其对**痛而兼烦**者效果最佳。
  - **妇科/儿科**：小儿夜啼、小儿多动、妇女更年期潮热汗出、经前紧张综合征——耳神门能**安神定志、平冲降逆**。
  - **戒断综合征**：戒烟、戒酒、戒毒之烦躁不安，倪师常取耳神门配耳肺、耳胃。

- **倪师经典对穴与排针组合**：
  - **耳神门 + 耳心 + 耳肾**：心肾不交之失眠、心悸、健忘。此为倪师**耳针三神穴**，一贴上去病人当晚就好睡。
  - **耳神门 + 耳肝 + 耳脾**：肝郁脾虚之焦虑抑郁、梅核气、消化不良伴失眠。此为**疏肝健脾安神方**。
  - **耳神门 + 耳胃 + 耳交感**：胃痛、胃痉挛、恶心呕吐。倪师说胃不和则卧不安，反之不安也加重胃病，此组合**和胃安神**双管齐下。
  - **耳神门 + 耳内分泌 + 耳卵巢（女）/耳睾丸（男）**：更年期综合征、月经不调、性功能紊乱。
  - **体针配合**：耳神门贴压 + **体针神门（心经原穴）+ 太溪（肾经原穴）**，此为倪师治失眠的**耳体合针法**，内服黄连阿胶汤，效果如鼓应桴。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：倪师在《人纪·针灸篇》中讲耳针时，原话大意是——**“耳朵啊，是一个倒过来的胎儿。你看那个耳垂就是头面，耳轮就是躯干，三角窝就是盆腔、就是心神所在。耳神门在三角窝里头，你拿个探针一压，病人叫一声‘哎哟’，你就找到了。这个点，你贴个王不留行籽，叫他一天按三回，晚上睡觉前一定要按一回，按到耳朵发红发烫，神就回来了。失眠？不存在的。”** 倪师还讲：**“神门这个名字，本身就告诉你它是神进出的门户。体针的神门在手腕上，耳针的神门在耳朵里，两个神门一起用，那叫前后夹击，神无处可逃，只好乖乖回来睡觉。”**

- **实战手下针感体会**：倪师说，耳神门**针感非常强**，比体针神门还猛。你斜刺进去2分，病人立刻感觉到**整个耳朵发热、半边头面发胀、眼睛发亮**，有的人当场就打哈欠想睡。如果用王不留行籽贴压，按对了那个点，病人会觉得**一股酸麻从耳朵窜到太阳穴，再窜到后脑勺**——这就是**气至病所**。倪师强调：**按耳神门要按到酸胀，但不能按破皮**，按到耳朵红热即可。

- **医案故事**：倪师讲过一个案例——一位**长期失眠十几年**的太太，安眠药吃到没效，整个人烦躁欲死。倪师给她**耳神门、耳心、耳肾**三颗王不留行籽贴上去，当场教她按，按了五分钟，她说“眼睛睁不开了”。倪师让她回家睡前按，**当晚睡了八小时**，十几年没睡这么好过。还有一个**小儿夜啼**的案例，孩子一到半夜就哭，怎么哄都不行。倪师用**耳神门配耳心**贴压，让妈妈在孩子睡前给按一按，**三天就好了**。倪师最后说：**“耳神门这个穴，你学针灸不学它，等于丢了半条命。因为它太方便了，不用针不用药，贴个籽就能救人，这才是中医的慈悲。”**
