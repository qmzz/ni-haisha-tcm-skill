# 梁门

## 📍 经络归属与精准取穴法

- **所属经络**：足阳明胃经。梁门是胃经在腹部的重要穴位，位于上腹部，内应胃之中部。
- **特定穴属性**：梁门非五输穴、原络郄募俞、八会穴等特定穴，但它是胃经气机在腹部转输的关键节点之一。倪师在《人纪·针灸篇》中强调：“梁门者，胃之梁木也，主中焦气机升降之枢纽。”它虽无特定穴之名，却有承上启下之实——上承不容、承满，下接关门、太乙，与中脘、天枢共同构架中焦气化。
- **倪师动态取穴与骨度折量法**：
  - 首先找准**中脘**——胸骨下端与神阙连线的中点。倪师常讲：“中脘找不准，梁门就歪了。”
  - 从中脘旁开**二寸**（以同身寸为准，即患者中指第二关节横纹至指尖为1寸，两寸即两个同身寸）。
  - 倪师心法：“肚脐到心蔽骨是八寸，折半是四寸为中脘。中脘旁开两寸，就是梁门。你不用死记，摸到中脘，手指一横，两寸就到了。”
  - **下针深度**：倪师在《针灸大成》讲义中明确：“梁门针五分到八分，不可深针。”因为下面就是胃体与腹膜，深针易伤内脏。
  - **禁针禁灸法则**：倪师强调：“梁门一般不灸，灸则助火，中焦有热者禁灸。孕妇禁针，腹部穴位皆然。”对于胃虚寒者，可温和灸，但需辨证精准。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：倪师推演梁门气化，认为它是**胃经浊气在此沉降、清气在此升发**的关口。他说：“梁门就像胃这条大梁上的门闩，门闩一开，中焦气机就活了。”其机理在于**健脾行水、消积化滞、升提中气**。胃主受纳，脾主运化，梁门恰在胃体中部，能助胃磨谷、助脾散精。
- **子母补泻与五行生克运用心法**：
  - 胃属土，梁门为土经土位附近之穴，但非五输。倪师以五行生克延伸运用：**虚则补其母（火生土），实则泻其子（土生金）**。
  - 临床若见胃虚纳呆，倪师常配**足三里（土经土穴，补）、解溪（火穴，母穴）**，再针梁门，引火生土以暖胃。
  - 若见胃实胀满，倪师配**厉兑（金穴，子穴）**，再针梁门，以泻土之子，使金气肃降，胃胀自消。
  - 倪师原话：“梁门不是子母穴，但它是中焦的开关。你补母泻子，最后都要经过梁门这个门闩，门闩不开，补泻都白搭。”

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **急症救逆**：食积胃胀、急性胃痛、呕吐不止。倪师曾用梁门配内关，治一患者食后胃胀如鼓，针下气通，胀消呕吐止。
  - **慢性病调理**：慢性胃炎、胃下垂、消化不良、食欲不振。倪师认为梁门能升提中气，对胃下垂有特效，常配百会、足三里。
  - **妇科/儿科**：小儿疳积、消化不良，倪师用梁门浅刺不留针，配四缝点刺。妇科妊娠恶阻，梁门配中脘、内关，但需注意孕妇禁针腹部，倪师多以灸法或指按替代。
  - **痛症特效**：胃脘痛、胁下痛。梁门配太冲，治肝气犯胃之胃痛，倪师称“开四关不如开梁门加太冲，直接解中焦之郁”。
- **倪师经典对穴与排针组合**：
  - **梁门 + 中脘 + 足三里**：倪师称“中焦三才针”，治一切胃病。
  - **梁门 + 天枢 + 关元**：调中焦、通下焦，治腹胀便秘。
  - **梁门 + 内关 + 公孙**：倪师常讲“公孙内关治胃心胸”，再加梁门，直达病所。
  - **梁门 + 太冲**：开四关之变通，治肝胃不和。
  - **排针组合**：倪师在《人纪》中演示，从中脘、梁门、天枢到关元，一排气针，治中焦气机壅滞，针下如风吹云散。

## 🗣️ 倪师讲义实录与针灸秘要

- **原汁原味逐字稿金句**：
  - “梁门，你们不要小看它。它在中脘旁边两寸，正好是胃的中间。胃像一个袋子，梁门就是袋子上的一个扣子。扣子解开，袋子里的东西才能动。”
  - “我针梁门，针下去五分，病人常常会觉得胃里咕噜一声，那是气通了。你要是针到八分，病人会感觉胃里发酸，那是针到胃壁了，不能再深。”
  - “梁门配足三里，一上一下，一升一降，胃就活了。你光针足三里，下面动了，上面不动，胀还是胀。加上梁门，上下都动，立竿见影。”
- **实战手下针感体会**：
  - 倪师描述：“针梁门，手法要轻。得气后，病人会觉得胃里一阵温暖，或者一阵蠕动。你要是捻针太猛，病人会恶心。所以我都用平补平泻，轻轻捻转，引气到胃。”
  - “有时候针梁门，病人会打嗝，那是胃气通了，好事。你不要怕，让他打，打完就舒服了。”
- **医案故事**：
  - 倪师曾治一中年妇人，胃胀三年，西医诊断为慢性胃炎，服药无效。倪师取梁门、中脘、足三里、内关，针下不到十分钟，妇人连打数个嗝，胃胀大减。倪师笑言：“你这胃啊，门闩锈住了，我帮你打开，气一通，就好了。”后续调理月余，诸症悉平。
  - 又一老者，胃下垂，食后坠胀。倪师针梁门、百会、足三里，用补法，针后嘱其卧片刻。三次后，老者自觉胃部有上提感。倪师说：“梁门能提中气，但你要配合百会，上下呼应，才提得起来。”
