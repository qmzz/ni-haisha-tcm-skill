# 次髎穴 (BL32)

**归经：** 足太阳膀胱经  
**定位：** 骶部，当髂后上棘内下方，适对第 2 骶后孔处

## 📍 穴位定位

### 标准定位
**《针灸大成》：** "在第二空，侠脊陷中。"

### 取穴方法
第 2 骶后孔中，约当髂后上棘下与督脉之间。

---

## 🩺 功能主治

### 功效
- **调经止带** - 妇科病要穴
- **通淋止痛** - 小便不利
- **强健腰膝** - 腰骶疼痛

### 主治病证

**倪海厦：**
> "次髎为治疗妇科病要穴，主调经止带，通淋止痛。
> 凡妇科病，皆可取次髎。"

| 系统 | 病证 |
|------|------|
| **妇科病** | 月经不调、痛经、带下、不孕、难产 |
| **泌尿病** | 小便不利、遗尿 |
| **男科病** | 遗精、阳痿 |
| **其他** | 腰骶痛、下肢痿痹 |

| 配伍穴位 | 功效 | 主治 |
