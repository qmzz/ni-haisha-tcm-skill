# 次髎穴 (BL32)

## 📍 经络归属与精准取穴法

次髎穴，膀胱经上面，八髎穴之一。膀胱经是阳经，它的气血流注是下午三点到五点（申时），从头走足，所以它在背上、在腰骶部。

八髎穴怎么分？倪师原话讲得很清楚：上髎、次髎、中髎、下髎，左右共八个，合称八髎。八个髎穴刚好对应八个骶孔，就扎在骶后孔里面。

怎么找？你先找到髂后上棘，就是手摸到骨盆后面两个凸起的骨头尖。髂后上棘跟督脉之间画一条线，这条线的中点就是上髎。上髎往下约一寸就是次髎。倪师讲得更直接——从骶骨最上缘往下推，推到第一个洞是上髎，第二个洞就是次髎。你用手按，按到那个孔，病人会有酸胀感，那就是穴道所在的地方。不要死记几寸几分，要用手去摸那个洞。

下针深度：次髎穴要扎进骶后孔，针下去的时候角度稍微朝内、朝下，刺入一到一寸半。倪师强调，这个穴道要扎到孔里才有效，扎到骨头上没用，扎到外面肌肉上效果也差。所以你的手感很重要——针穿过皮肤、穿过肌肉，突然有一个落空感，那就是进了孔了。

这个穴道，禁灸？不，次髎可以灸。但是你要看情况——妇人经痛、腰酸，灸次髎很好；但如果局部有红肿热痛、有炎症，那就不能灸。

## ⚡ 倪师经穴气化与破局心法

次髎穴在八髎之中，八髎统管盆腔、子宫、卵巢、膀胱、大肠，以及腰骶部的气血。倪师讲，八髎穴是治疗妇科、男科、泌尿系统问题的总开关。为什么？因为它是骶后孔，直接通到骨盆腔里面去。你针下去，气会直接到达盆腔深层，这就是它“破局”的地方——别的地方到不了，它能到。

从气血流注来看，膀胱经主一身之表阳，但八髎区域又紧邻督脉和任脉的起点。阳经的气血在这个地方汇聚、沉降，然后渗入盆腔。倪师说，次髎可以“引阳入阴”——把膀胱经的阳气引到盆腔里面去，温暖子宫、卵巢。所以妇人宫寒不孕、月经不调、白带多、痛经，次髎是主力穴。

五行上面，膀胱经属水。次髎在八髎之中偏下，有“通利水道”的作用。倪师常用次髎配中极、配三阴交来通利膀胱，治疗小便不利、癃闭。它跟肾经、脾经也在下焦交会，所以次髎可以健脾行水、利湿化浊。

子母补泻？膀胱经的母穴是至阴（金生水），子穴是束骨（水生木）。次髎本身不是五输穴，但你在次髎上做补泻，可以通过手法来调。虚证——比如肾虚腰痛、子宫脱垂——你用补法，针下去慢慢推、慢慢进，让气聚在那里；实证——比如痛经、急性腰痛、小便不通——你用泻法，针下去快速进、快速出，摇大针孔。

## 🎯 临床主治与配穴组合手印

次髎的主治范围非常广。

第一，妇科病。痛经、月经不调、白带过多、子宫内膜炎、不孕症、更年期综合征。倪师讲，妇人月经痛，你针次髎、中极、三阴交，痛立止。

第二，男科病。遗精、阳痿、早泄、前列腺炎。

第三，泌尿系统。小便不利、癃闭、膀胱炎、尿道炎。

第四，腰骶痛。次髎所在的位置就是腰骶部，所以腰骶神经痛、坐骨神经痛、腰椎间盘突出引起的腰腿痛，次髎都可以治。

第五，下肢痿痹。因为膀胱经从腰骶下行到腿，所以次髎可以治下肢麻木、无力。

配穴组合：

- **次髎 + 中极 + 三阴交**：治痛经、月经不调、不孕。中极是膀胱募穴，三阴交是脾经要穴，三穴合用，通调下焦。
- **次髎 + 肾俞 + 命门**：治肾虚腰痛、阳痿、遗精。肾俞、命门补肾阳，次髎通盆腔气血。
- **次髎 + 委中**：治腰骶痛连到腿。委中是膀胱经的合穴，“腰背委中求”，配上次髎，上下呼应。
- **次髎 + 关元 + 气海**：治小便不利、癃闭。关元、气海补下焦元气，次髎通利水道。
- **次髎 + 血海 + 膈俞**：治血瘀型痛经、子宫肌瘤。血海、膈俞活血化瘀，次髎引血下行。

倪师还讲过，次髎配大肠俞、天枢，可以治便秘、肠鸣、腹胀，因为八髎统管盆腔，盆腔里也有大肠。

## 🗣️ 倪师讲义实录与针灸秘要

倪师在视频里面讲八髎穴的时候，原话是这么说的：

“八髎穴，你手去摸，摸到骶骨上面有八个洞。上髎、次髎、中髎、下髎。妇人妇科的问题，你针八髎，效果非常好。尤其是次髎，你针下去，针要进到洞里面，病人会有一种酸胀感，一直传到子宫、传到会阴。这个时候，痛经的人当场就不痛了。”

“次髎这个穴道，你看它名字叫‘次’，就是第二个。上髎是第一个，次髎是第二个。你不要小看它，很多妇科的病，你针次髎，比针三阴交还快。为什么？因为它直接通到盆腔里面去。”

“我治过一个妇人，痛经十几年，每次月经来都要吃止痛药。我针次髎、中极、三阴交，针下去不到五分钟，她说痛没有了。后面每个月来之前针一次，针了三个月，好了。”

“还有小便不通的，膀胱胀得要死，尿不出来。你针次髎、中极、三阴交，针下去，小便就出来了。为什么？因为次髎通膀胱，中极是膀胱的募穴，三阴交通下焦。三个一起用，效果立竿见影。”

倪师还讲过一个细节：针次髎的时候，病人的感觉很重要。如果病人说“酸胀传到会阴去了”，那就是扎对了。如果病人只说“痛”，那就是没扎到孔里，扎到骨头或者肌肉上了，要调整角度。

倪师强调，次髎穴不要扎太深，扎太深会伤到骶神经。一寸到一寸半就够了。而且针下去之后，不要大幅度提插，要轻轻地捻转，让气慢慢地扩散。
