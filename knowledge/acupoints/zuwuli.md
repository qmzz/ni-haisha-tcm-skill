# 足五里

## 📍 经络归属与精准取穴法

- 足五里属足厥阴肝经，位于大腿内侧。在《针灸大成》中，足五里被列为足厥阴肝经的穴位，位于气冲穴下三寸，也就是从腹股沟动脉搏动处（气冲）往下量三寸。这个穴位不是五输穴，也不是原络郄募俞，它就是肝经循行路线上的一个普通经穴，但在倪师的人纪针灸体系里，它的定位是“阴挺、睾丸肿痛、小便不利”的关键处理点。

- 倪师在取穴上强调用骨度折量法配合体表标志来摸。他说：“气冲在哪里？你摸腹股沟，有一条大筋，大筋外侧、动脉跳动的地方就是气冲。从气冲直下三寸，就是足五里。”三寸怎么折？用同身寸，病人自己的四指并拢就是三寸。倪师特别讲，你不要拿尺去量，拿病人自己的手指去比，这叫同身寸，最准。摸到足五里后，再往下一寸就是阴廉，再往下就是阴包。所以足五里在气冲下三寸、阴廉上一寸的位置。

- 下针深度：倪师说，足五里这个地方肉比较厚，可以下针五分到八分，甚至一寸。但要注意，这个地方有大动脉——股动脉的分支经过，下针时要避开动脉。倪师的原话是：“你摸到动脉跳动，针就下在动脉旁边，不要直刺动脉。”禁灸：足五里一般不灸，因为靠近阴部，灸了容易上火，而且古书里也没有说这个穴位要灸。禁针的情况：如果病人大腿内侧有严重静脉曲张，或者局部有感染，不要下针。

## ⚡ 倪师经穴气化与破局心法

- 倪师推演足五里的气血流注，认为它是肝经从阴部往大腿内侧下行的一个中转站。肝经环绕阴器，足五里正好在气冲之下，是肝经气血从腹腔出来、经过腹股沟、下行到腿部的关键节点。倪师说：“足五里这个穴，顾名思义，就是足部的五脏之气在这里汇聚。它能够通调下焦，尤其是对前阴的问题——睾丸、阴囊、子宫、膀胱，都有直接的作用。”

- 它的开阖机理：倪师讲，足五里能“开下焦之闭，利水湿之停”。当肝经气血郁滞在下焦，出现小便不利、阴囊潮湿、睾丸肿痛、妇人阴挺（子宫脱垂）时，足五里就是一个破局点。它不像太冲那样走全身气机，也不像曲泉那样走关节，它专门走前阴和下腹。倪师说：“你想想，肝经绕阴器，足五里就在阴器旁边，它一扎下去，肝经的气就通了，下焦的水就动了。”

- 子母补泻与五行生克：足五里本身不是五输穴，所以不直接用它做子母补泻。但倪师在临床上，会把足五里和肝经的母穴曲泉（水穴，水生木）、子穴行间（火穴，木生火）配合使用。如果肝经虚证，比如阴挺、疝气下坠，先补曲泉，再针足五里，这是“虚则补其母，再加局部导引”。如果肝经实证，比如睾丸红肿热痛、小便赤涩，先泻行间，再针足五里，这是“实则泻其子，再加局部破滞”。倪师强调，足五里的作用不是补也不是泻，它是“通”，是让肝经的气血在局部重新流动起来。

## 🎯 临床主治与配穴组合手印

- 核心特效主治病症：足五里的主治，倪师归纳为三大类。第一，前阴病：睾丸肿痛、疝气、阴囊潮湿、阴茎痛。第二，妇科病：子宫脱垂（阴挺）、赤白带下、月经不调属于肝经下焦湿热或虚寒下陷的。第三，小便问题：小便不利、癃闭、尿频尿急属于肝经气滞的。倪师说：“足五里是肝经上专门处理‘下面’问题的穴，你记住，只要是前阴、少腹、小便的问题，都可以用它。”

- 倪师经典对穴与排针组合：
  - 睾丸肿痛：足五里 + 太冲 + 关元。先针太冲（平肝气），再针关元（温下焦），最后针足五里（局部导引）。
  - 子宫脱垂：足五里 + 百会 + 气海 + 三阴交。百会升提，气海补气，三阴交调肝脾肾，足五里直接作用在子宫周围。
  - 小便不利：足五里 + 中极 + 阴陵泉 + 三阴交。中极是膀胱募穴，阴陵泉利水，三阴交调下焦，足五里通肝经。
  - 疝气：足五里 + 大敦 + 关元 + 三角灸（以病人脐孔为顶点，向下作等边三角形，两底角为穴）。大敦是肝经井穴，专门治疝气，足五里加强局部。
  - 倪师特别提到，足五里配阴廉、阴包，是肝经在大腿内侧的三连针，对于大腿内侧痛、静脉曲张、阴部抽痛，一起下针，效果很好。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲足五里的时候，原话是：“足五里，这个穴在气冲下三寸。你摸，气冲在腹股沟动脉那里，下三寸就是。这个穴道呢，我们很少灸，因为靠近阴部，灸了会热。针呢，可以下五分到八分。你下针的时候，病人会有一种酸胀感，往阴部放散，这就是气到了。”

- 倪师讲过一个医案：“有一个病人，睾丸肿得像鸡蛋那么大，痛得不能走路。我一看，肝经的问题。先针太冲，再针足五里，针下去不到十分钟，病人说痛减了。第二天再来，肿消了一半。第三次来，基本好了。我告诉你，足五里是肝经上通睾丸的要穴，你只要看到睾丸肿痛，就想起它。”

- 倪师手下针感体会：“针足五里，你不要直直地扎，要稍微斜一点，针尖朝向阴部方向。病人会感觉到一股气从大腿内侧往阴囊那边走，这就是‘气至病所’。如果没有这种感觉，你就把针提出来一点，再往里送，或者稍微捻转一下，气就来了。”

- 倪师还讲：“妇人子宫脱垂，你针足五里，再针百会，效果很好。但你要记住，这是肝经虚证，要补，不要泻。补的手法：针下去得气后，慢慢推针，病人吸气时推，呼气时停，这叫补。泻的手法反过来。足五里本身不补不泻，但你要配合肝经的母穴曲泉一起用，才能标本兼治。”

- 倪师最后强调：“足五里，足五里，就是足部的五脏之气在这里汇聚。你不要小看这个穴，它虽然不是什么大穴，但在下焦病、前阴病上，它是先锋。你把它和太冲、关元、三阴交配在一起，就是一套组合拳，打下去，病就退了。”
