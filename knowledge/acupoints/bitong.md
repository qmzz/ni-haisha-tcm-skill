# 臂臑二

## 📍 经络归属与精准取穴法

- **所属经络**：手阳明大肠经。臂臑为手阳明络脉之别络，别走手少阳三焦经（《针灸大成》：手阳明络，别走少阳）。
- **穴名释义**：臂，上肢；臑，上臂肌肉隆起处。穴在上臂三角肌下端后缘，故名臂臑。
- **特定穴属性**：手阳明大肠经与阳维脉、手足太阳经之交会穴（《针灸大成》归为“手足太阳、阳维之会”）。倪师在讲阳维脉时点明：阳维主表、主一身之藩篱，臂臑能通阳维，故可治表证与目疾。
- **倪师动态取穴法**：
  - 先让病人手臂自然下垂，或屈肘叉腰，肩头会出现一个凹陷——肩髃穴。
  - 从肩髃往下，沿着三角肌下缘摸，摸到上臂外侧肌肉隆起最高点、按之有酸胀感处。
  - 倪师口诀：“肩髃下三寸，三角肌下缘，按到那个凹窝里就是臂臑。” 骨度折量：肩髃至曲池为九寸，臂臑在肩髃下三寸、曲池上六寸。
  - 简便取法：屈肘握拳，上臂外侧三角肌下端凹陷处，按压酸胀明显即是。
- **下针深度与角度**：直刺或斜刺0.5～1寸，针感可放射至肩臂。倪师强调：**“这穴不要深针，一寸左右，得气即止。”**
- **禁针禁灸**：古籍载“不宜灸”（《针灸大成》引《铜人》：不宜灸）。倪师解释：臂臑近肩关节，灸之易助火入络，导致肩臂红肿，故一般不灸，以针为主。

## ⚡ 倪师经穴气化与破局心法

- **气血流注机理**：臂臑为手阳明别络，阳明多气多血，别走少阳。倪师推演：阳明经气从肩髃下行至臂臑时，气血在三角肌处有一个“蓄势”的过程，如水库蓄水，再往下灌入曲池、手三里。故臂臑能**通调上肢气血、疏利关节**，尤其善于把肩部郁滞的气血往下引导。
- **开阖枢机**：阳维脉起于诸阳之会，臂臑为其交会。倪师讲：“阳维像伞骨，管全身在表的阳气。臂臑就是伞骨的一个节点，所以它能解表、能明目、能通肩臂。”
- **子母补泻与五行生克**：手阳明大肠经五行属金，臂臑为大肠经穴，不属五输。倪师在子母补泻中不将臂臑作补泻主穴，而是作为**通络开结**的配穴使用。实则泻其子——大肠经金之子为水（二间），虚则补其母——土（曲池）。臂臑在此体系中是“开路先锋”：先针臂臑通络，再按虚实补泻曲池或二间，气才能顺利传导。
- **倪师心法总结**：“臂臑是肩臂之间的关卡，关卡一开，气血就下去了。你针曲池没感觉，先针臂臑，再针曲池，气就来了。”

## 🎯 临床主治与配穴组合手印

- **核心特效主治**：
  - **肩臂痛、颈项拘挛**：臂臑是治肩臂酸痛、抬举困难的近端要穴。倪师常言：“肩膀痛，从肩髃到臂臑到曲池，一路针下去，像疏通下水道一样。”
  - **目疾**：目赤肿痛、目昏暗、迎风流泪。倪师从阳维脉交会推演：阳维入脑，臂臑通阳维，故能引气血上濡于目。
  - **瘰疬（淋巴结肿大）**：臂臑为手阳明络，阳明多气多血，针之能消痰散结。
  - **上肢麻木、偏瘫**：中风后上肢不遂，臂臑配肩髃、曲池、合谷，是倪师常用的“通臂四针”。
- **倪师经典对穴与排针组合**：
  - **肩三针**：肩髃 + 肩髎 + 臂臑 —— 治肩关节周围炎，倪师称“肩痛三针”。
  - **臂臑 + 曲池 + 合谷**：手阳明经气道贯通，治上肢痿痹。
  - **臂臑 + 光明（胆经络穴）**：阳维交会配少阳络穴，治目疾。倪师说：“臂臑通阳维，光明通胆络，两个一配，眼睛就亮了。”
  - **臂臑 + 天井（三焦经）**：治瘰疬、淋巴结肿，取阳明少阳同调。
  - **臂臑 + 外关（阳维所过）**：解表退热，治外感肩背僵痛。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲手阳明大肠经时，讲到臂臑这一段，原话大意是：

  > “肩髃完了以后，下一个穴道叫臂臑。臂臑怎么找？你把手臂弯起来，肩膀这里有个三角肌，三角肌下缘那个凹的地方，就是臂臑。你看《针灸大成》写‘臂臑，肩髃下三寸’。这个穴道是手足太阳、阳维之会。阳维是什么？阳维就是管你在表的阳气。所以臂臑这个穴，你针下去，肩膀的痛就去掉了，因为它能通阳维。”

- 倪师手下针感体会：

  > “针臂臑的时候，针下去要贴着骨头走。你直直进去，病人没什么感觉；你稍微斜一点，顺着三角肌下缘往肩髃方向透，病人会感觉酸胀从肩膀一路麻到手指。这就是气到了。得气以后，你再去针曲池，那个气就像接了电一样往下走。”

- 医案故事：

  > “有个病人肩膀痛了三年，手抬不起来，穿衣服都困难。我一看，肩髃、臂臑、曲池、合谷，一路针下去。针臂臑的时候，他跟我说：‘哎呦，这个酸一直冲到手指头。’第二天来，他说昨晚睡了个好觉，手能抬到耳朵了。为什么？因为阳明经气血通了，阳维的阳气也通了。肩臂痛，你只要把阳明的关卡打开，气血自己会去修复。”

- 倪师特别提醒：

  > “臂臑这个穴，古籍说不宜灸。为什么？因为它靠近肩关节，你灸下去，火气往关节里钻，肩膀会肿。所以臂臑我们只针不灸。针也不要太深，一寸左右，得气就停。你针太深，扎到骨头，病人会痛得跳起来。”

- 秘要总结：臂臑是手阳明别络、阳维交会，**主通不主补**，是肩臂气血的“开关穴”。倪师用此穴，重在“通”字——通阳明、通阳维、通肩臂、通目窍。凡肩臂气血郁滞、阳气不布之证，先针臂臑开络，再配曲池、合谷引气下行，则诸症自解。
