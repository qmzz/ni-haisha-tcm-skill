# 陶道

## 📍 经络归属与精准取穴法

- **所属经络**：督脉。督脉为“阳脉之海”，总督一身之阳。陶道穴是督脉上、下焦气化交接的一个重要关口。
- **特定穴属性**：陶道为**督脉与足太阳膀胱经之会穴**。太阳主表，督脉主阳，故本穴能通阳解表、清热截疟。它不是五输穴，也不是原络郄募，但它是阳经之气在背部转输的“陶铸之道”——像陶匠转盘一样，让阳气均匀分布到上下。
- **倪师动态取穴与骨度折量法**：
  - 先找大椎。大椎怎么找？倪师讲：“你叫病人低头，后颈最凸起的那个骨头下面就是大椎。大椎在第一胸椎上，那大椎下就是陶道。”大椎与陶道相差一个椎体——大椎在第一胸椎棘突下，陶道在**第一胸椎棘突下**。等等，这里要跟倪师原意对齐：大椎穴是在第七颈椎棘突下，陶道就在大椎下面一个椎体，即**第一胸椎棘突下**。倪师原话：“大椎下个椎体就是陶道。”
  - 骨度折量法：从大椎到陶道，正好是**一个椎体**的距离。倪师说：“你摸到大椎，再往下摸一个突起的骨头，那个下面的凹陷就是陶道。”不需要复杂的分寸折量，摸骨最实在。
  - **下针深度**：倪师说督脉背上这些穴“下针不要太深，五分到一寸。”陶道穴因为靠近脊柱，**针五分即可**，不要超过一寸，免得伤到脊髓。针下去是**斜刺**，针尖稍微朝上，顺着督脉的经气方向。
  - **禁针禁灸法则**：陶道穴**可灸**，但倪师强调：“督脉上的穴，除了长强，大部分都可以灸，但不要乱灸。”陶道穴如果是**热证、疟疾发热**的时候，古代说“陶道禁灸”，因为灸了更助热。但如果是**虚寒、阳气不足**，灸陶道能升阳。倪师的原则是：**热证不灸，寒证可灸**，针则寒热皆可。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演气血流注与开阖机理**：
  - 陶道穴的“陶”字，倪师解释：“陶就是陶铸，像窑里烧陶器，把土变成器。陶道就是阳气在这里被‘陶铸’成能用的阳气。”督脉的阳气从长强一路往上，到大椎已经聚集了手足三阳的气，到陶道这里，阳气进一步**分清泌浊**——清阳往上走，浊阳往表走。所以陶道是**通阳解表、清热散邪**的关键穴。
  - 倪师讲：“大椎是手足三阳与督脉之会，陶道是督脉与太阳之会。太阳主开，督脉主升。陶道一开一升，能把陷在里面的阳气提出来，把堵在表上的热邪散出去。”所以**疟疾**——那种忽冷忽热、邪在半表半里、阳气被堵住出不来——倪师就取陶道，配合大椎、间使，一针下去让阳气重新“陶铸”一遍。
  - 另外，陶道靠近肺的上部，倪师说：“肺主气，督脉主阳。陶道能宣肺气、通督阳。所以**咳嗽、气喘、项强、肩背痛**，你都可以在陶道上做文章。”
- **子母补泻与五行生克运用心法**：
  - 陶道不是五输穴，所以严格来说不直接套子母补泻。但倪师在临床上会**借用五行生克**来配穴：督脉属阳，阳气不足就是“虚则补其母”——母在中医里可以取**肾经的复溜**（金生水？不对，这里要按倪师的逻辑）。倪师实际用法是：**陶道配复溜**，复溜是肾经的经穴，属金，金能生水，水能涵阳，所以灸陶道再加复溜，能把阳气牢牢锁住，不让它散掉。
  - 如果**实热、疟疾、高热**，那就是“实则泻其子”——陶道配**外关**（三焦经络穴，属火），火能泄热，针用泻法，把热从表散出去。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **急症救逆**：疟疾寒热、高热神昏。倪师说：“陶道是截疟的专穴。”配上大椎、间使、后溪，针下去疟疾就退。
  - **慢性病调理**：督脉阳气不足导致的**背寒、脊椎痛、项强**。陶道配上身柱、至阳，能温通整条督脉。
  - **妇科/儿科特效**：小儿**疳积、消化不良**，倪师会在陶道、身柱上**点刺放血**，或者用**米粒灸**，三五壮，能健脾升阳。
  - **痛症特效**：**肩背痛、颈椎病**，陶道配**大椎、天宗、后溪**，针完病人当场觉得脖子松了。
- **倪师经典对穴与排针组合**：
  - **陶道 + 大椎 + 间使**：截疟三针。倪师说：“疟疾一发，先扎大椎、陶道，再扎间使，热就退了。”
  - **陶道 + 身柱 + 至阳**：督脉三阳针。治背寒、脊痛、阳气不升。
  - **陶道 + 合谷 + 复溜**：通阳解表、固本培元。治虚人感冒、自汗盗汗。
  - **陶道 + 风门 + 肺俞**：宣肺解表。治咳嗽、气喘、项背强。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原汁原味逐字稿金句**：
  - “大椎下个椎体就是陶道。你摸大椎，大椎下面那个突起的骨头，下面那个凹洞，就是陶道。”
  - “陶道者，陶铸之道也。阳气在这里像烧陶器一样，把它炼成能用的阳。”
  - “疟疾，忽冷忽热，就是阳气被堵住了。你针陶道、大椎、间使，一针下去，阳气一通，冷热就平了。”
  - “督脉的穴，下针不要深，五分到一寸。你扎太深，扎到脊髓，病人当场就瘫掉了。所以背上这些穴，我都是斜刺，针尖朝上，顺着督脉走。”
  - “陶道可灸，但热证不灸。你发高烧，再灸陶道，那不是火上浇油吗？寒证，背冷的，灸陶道，阳就起来了。”
- **实战手下针感体会**：
  - 倪师说：“你针陶道，针尖朝上斜刺五分，病人会有一种**酸胀感往上走**，走到大椎、走到后脑。这就是阳气被提起来了。”
  - 如果是疟疾，针下去病人会觉得**后背一热，然后汗出**，寒热就退了。
- **医案故事**：
  - 倪师讲过一个案例：“有个病人，疟疾，忽冷忽热，一天发一次。我扎大椎、陶道、间使，针下去不到十分钟，病人说后背热了，然后开始出汗，汗一出，烧就退了。第二天再扎一次，疟疾就没再发。”
  - 还有一个：“小孩疳积，面黄肌瘦，肚子大。我在陶道、身柱上米粒灸，灸了五次，小孩胃口开了，脸色也红了。”
