# 大钟二

## 📍 经络归属与精准取穴法

- **所属经络**：足少阴肾经。
- **特定穴属性**：**络穴**。肾经的络穴，别走足太阳膀胱经。同时它也是足少阴肾经的**原络配穴**中的“络”穴端。
- **五行定位**：肾经属水，大钟为络穴，络穴无独立五行属性，但因其沟通肾与膀胱（太阳寒水），在五行生克中充当“水水相通”的桥梁，常用于**虚实互调**。
- **倪师动态取穴心法**：
  - 大白话找穴：从**太溪穴**（内踝尖与跟腱之间凹陷）往下摸，摸到**跟骨**（脚后跟那块大骨头）的上缘。在跟骨上缘、跟腱内侧前缘的凹陷处，就是大钟。
  - 倪师原话意思：你摸到太溪后，顺着跟腱内侧的沟往下滑，滑到骨头（跟骨）挡住你的地方，那个缝隙就是大钟。它不像太溪那么“空”，它是贴着骨头边的。
  - **骨度折量法**：太溪下0.5寸，稍向后，跟骨上缘凹陷中。
- **下针深度**：直刺或略向后下方斜刺 **0.3～0.5寸**。
- **禁针禁灸法则**：**可灸**。倪师常用于虚寒证，如肾阳虚引起的足跟痛、气喘，灸大钟有温肾纳气之效。禁针方面，古籍未强调绝对禁针，但因其靠近跟腱与跟骨，**不宜深刺、猛刺**，避免伤及跟腱或骨膜，造成剧烈刺痛。

## ⚡ 倪师经穴气化与破局心法

- **倪师推演的气血流注与开阖机理**：
  - 大钟是肾经的络穴，**“络”就是别通、联络**。肾与膀胱相表里，大钟就是这条表里通道上的“开关”。
  - 倪师讲：**肾主骨，大钟正好贴在跟骨上**。所以它能像个“气泵”一样，把肾精肾气打到骨头里去。足跟痛、骨头里的问题，大钟是破局点。
  - 开阖机理：肾气不足，水液代谢失常，大钟能**打开膀胱经的排水通道**，同时**关住肾精不外漏**。它既有“开”的一面（利水、通淋），又有“阖”的一面（纳气、固精）。
- **子母补泻与五行生克运用心法**：
  - 肾经属水。虚则补其母，肺经属金，金生水，故肾虚可补肺经（如太渊）。实则泻其子，肝经属木，水生木，故肾实可泻肝经（如太冲）。
  - 但**大钟作为络穴，是“虚实通用”的调气穴**。倪师心法：不管肾虚肾实，只要出现“肾气不固”或“肾水泛滥”的中间态，大钟都能双向调节。它不直接补母泻子，而是**疏通肾与膀胱之间的气血卡点**。
  - 临床若见肾虚足跟痛，倪师常**大钟配太溪**，太溪补肾（母穴），大钟通络（子穴通路），这叫“母子通路同调”。

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **足跟痛**（特效）：肾主骨，大钟贴跟骨，针之立减。倪师原话：“足跟痛，你下大钟，针下去病人就感觉脚跟松了。”
  - **肾虚气喘、咳喘**（纳气归元）：大钟能引气下行，纳气归肾。对久喘、动则喘甚、吸气困难者，配太溪、气海。
  - **癃闭、小便不利**（通利膀胱）：络穴通膀胱，对前列腺肥大、产后尿潴留，针大钟配中极、三阴交。
  - **痴呆、健忘、脑鸣**（肾精上充于脑）：肾主骨生髓，脑为髓海。大钟通肾络，能引肾精上充。配百会、四神聪。
  - **月经不调、崩漏**（固摄下元）：肾主封藏，大钟能固冲任。配关元、三阴交。
- **倪师经典对穴与排针组合**：
  - **大钟 + 太溪**：肾虚足跟痛、肾虚腰痛。太溪补肾，大钟通络，一补一通。
  - **大钟 + 公孙 + 内关**：公孙内关治胃心胸，大钟纳肾气。用于肾不纳气引起的心悸、胸闷、喘。
  - **大钟 + 中极 + 三阴交**：癃闭、小便难。中极利膀胱，三阴交调下焦，大钟通肾络膀胱。
  - **大钟 + 然谷**：然谷是肾经荥穴，属火，能温肾阳。大钟配然谷，专治足跟冷痛、肾阳虚足跟如踩冰。

## 🗣️ 倪师讲义实录与针灸秘要

- **倪师原味金句（根据人纪针灸篇讲义精神转写）**：
  - “大钟穴，你摸到太溪，往下一点点，贴着跟骨的那个缝，就是大钟。它是肾经的络穴，络到膀胱经去的。”
  - “足跟痛的人，你下太溪、下大钟，针一下去，他当场就讲‘哎呀，松了’。为什么？肾主骨啊，大钟贴在骨头上，它就是把肾气灌到骨头里去的。”
  - “大钟是络穴，络穴就是可以通表里。肾有问题，膀胱有问题，你都可以在大钟上做文章。它像个开关，开一下，水就利出来；关一下，精就固住。”
- **实战手下针感体会**：
  - 倪师下大钟，针尖略向跟骨方向斜刺。得气时，病人常感觉**一股酸胀感从内踝后方往脚底或足跟放射**，有时会麻到脚趾。若针感只停在局部，效果差；针感向下传，足跟痛立减。
  - 若病人肾虚严重，针下常觉**空虚感**，此时宜留针久一些，或加灸。
- **医案故事（倪师风格示例）**：
  - 倪师讲过一个案例：一位老先生足跟痛三年，走路像踩钉子。西医说是骨刺，要开刀。倪师取太溪、大钟，下针后让老先生走走看。老先生一下床，走了几步，回头说：“不痛了，钉子没了。”倪师说：“骨刺还在，但肾气通了，气血过去了，痛就没了。大钟就是把肾气打到跟骨去的。”
