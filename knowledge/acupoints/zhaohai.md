# 照海穴 (KI6)

## 📍 经络归属与精准取穴法

- **所属经络**：足少阴肾经。照海为肾经腧穴，同时也是**阴跷脉**的起始穴（八脉交会穴之一，通阴跷脉）。阴跷脉从照海发出，沿内踝上行，最终与阳跷脉交会于目内眦，主司一身左右之阴气与下肢运动、眼睑开合。
- **五行属性**：肾经为阴水经，照海为肾经腧穴，其五行归属以“阴跷脉所生”与“肾水”为本，倪师在讲阴跷脉时特别强调：照海统领一身之阴，是**阴跷脉的开关**——阴跷脉有病，取照海。
- **倪师动态取穴与骨度折量法**：
  - 先找到**内踝尖**。将足内踝尖垂直向下推，推到内踝正下方凹陷处——这个凹陷就是照海。倪师原话：**“内踝尖下五分，骨头旁边那个凹洞就是照海。”**
  - 白话操作：让病人脚自然放松，手指从内踝尖往下摸，摸到一个骨头缝隙、按下去有点酸胀的凹陷，就是照海。
  - **下针深度**：直刺或斜刺，针入**三到五分**。倪师说：**“照海下针，贴着骨头下，不要扎太深，五分就够了，太深就扎到骨头上，病人会痛。”**
  - **禁针禁灸**：照海可以灸，但倪师强调——**“照海这个穴道，灸的机会不多，大部分是下针。虚证的时候可以灸，实证的时候针泻。”** 没有绝对禁灸之说，但一般不作为常规灸穴。

## ⚡ 倪师经穴气化与破局心法

- **气血流注与开阖机理**：照海是**阴跷脉的起点**，而阴跷脉主一身左右之阴。倪师在讲奇经八脉时说：**“阴跷脉是管阴气的，照海就是阴跷脉的开关。阴跷脉有病——比如脚往内翻、眼睛张不开、白天想睡又睡不着——统统在照海上下针。”** 照海的气化机理，倪师归结为八个字：**“引阴入阳，引火归元。”** 它能把浮越在上的虚火拉回下焦肾水之中，让水火既济。
- **子母补泻与五行生克运用心法**：
  - 肾经属水。肾经的井穴涌泉属木（水生木，涌泉为肾经母穴），肾经的合穴阴谷属水（本穴）。
  - 照海不是肾经五输穴，但倪师在讲子母补泻时，常配合复溜（肾经经穴，属金，金生水，复溜为肾经母穴）一起用。**“肾虚，补复溜；肾实，泻涌泉。照海是管阴跷的，跟补泻五输穴是两条路——一个是调肾脏本身，一个是调阴跷脉的气机。”**
  - 实战心法：**虚证**——照海配复溜，补法；**实证**——照海配涌泉，泻法。倪师说这是“水路不通的时候，照海开闸，复溜放水。”

## 🎯 临床主治与配穴组合手印

- **核心特效主治病症**：
  - **失眠**：照海配申脉。倪师原话：**“失眠，尤其是那种晚上精神特别好、白天想睡——阴跷阳跷不平衡——照海配申脉，一针下去，晚上就困了。”**
  - **咽喉干痛、慢性咽炎**：肾经循喉咙，照海是肾经穴，针照海能引肾水上行润喉。倪师说：**“喉咙干、说话没声音、慢性咽炎，照海针下去，口水就来了。”**
  - **妇科**：月经不调、痛经、带下。照海通阴跷，阴跷主阴血，配三阴交、关元。
  - **癫痫、抽搐**：阴跷脉病则下肢内翻、抽搐，照海配申脉、太冲。
  - **脚内翻、足跟痛**：局部取穴，照海配昆仑（对侧取穴法）。
- **倪师经典对穴与排针组合**：
  - **照海 + 申脉**：调阴跷阳跷，治失眠、癫痫、下肢运动障碍。
  - **照海 + 列缺**：列缺通任脉，照海通阴跷，合治**胸膈、喉咙、肺系**病症。倪师说：**“列缺照海，管喉咙到胸口这一段。”**
  - **照海 + 三阴交 + 关元**：妇科月经病、带下、不孕的经典组合。
  - **照海 + 太溪 + 复溜**：肾虚引起的腰痛、耳鸣、咽干。

## 🗣️ 倪师讲义实录与针灸秘要

- 倪师在讲阴跷脉时原话：**“照海穴，内踝尖下五分。这个穴道是阴跷脉的起点。阴跷脉从照海一路往上，到眼睛内眦。所以阴跷脉有病，眼睛张不开，或者脚往内翻，都在照海上下针。你记住，申脉是阳跷，照海是阴跷，两个合起来管失眠、管癫痫、管脚的内翻外翻。”**
- **针感体会**：倪师说：**“照海下针，病人会感觉酸酸胀胀的，有时候会麻到脚底。你捻针的时候，病人说‘哎，脚底麻了’——对了，气到了。”**
- **医案故事**：倪师在课堂上讲过一个案例：**“有个太太，失眠十年，晚上精神好得很，白天昏昏沉沉。我一看，阴跷阳跷不平衡。照海、申脉两边一起下，针完当天晚上就睡着了。第二天来，她说‘倪医师，我十年没睡这么好过了。’”**
- **针灸秘要**：倪师强调——**“照海这个穴，你不要小看它。喉咙干、咽炎，针照海比针列缺还快。为什么？肾经循喉咙啊，照海直接引肾水上来。你针下去，病人喉咙马上就不干了，口水就出来了。这叫引水润喉。”**
