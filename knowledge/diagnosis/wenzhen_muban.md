# 倪师问诊模板与动态辨证流程

## 👁️ 诊断要诀与原典法度

倪师问诊，非流水账式填表，而是一套**动态辨证引擎**。其法度根于《伤寒论》六经辨证与《黄帝内经》藏象学说，以**十问歌为框架**，以**六经为经纬**，以**方证为归宿**。问诊之要，在于通过患者的症状反应，反推体内阴阳气血的虚实寒热与病位深浅。倪师常言：“问诊如审案，每一问都是一条线索，线索汇聚，病机自现。”故问诊非求全，而求**精准锚定六经**，最终落实到“**但见一证便是**”的方证对应上。动态辨证流程的核心，是**随证治之**，方随证转，证随问显。

## ⚡ 倪师望闻问切破局心法

问诊启动前，倪师必先以**望闻切**三诊定下基调，此为问诊之“导航仪”：

- **望眼诊**：眼白（肺）、瞳孔（肾）、黑眼珠（肝）、眼睑（脾）、眼眦（心）。眼诊一过，五脏虚实已露端倪。若瞳孔收缩无力，肾阳已衰；眼白现血丝，肺有热或瘀。
- **摸手脚**：手冷至肘、脚冷至膝，为**四逆**，少阴寒化或厥阴厥逆之兆；手热脚冷，为**上热下寒**，厥阴提纲之证。
- **寸口人迎脉法**：寸口（肺脉）候五脏，人迎（胃脉）候六腑。人迎大于寸口，病在六腑，为阳证、热证；寸口大于人迎，病在五脏，为阴证、寒证。此脉法一锤定音，直接指向六经归属。
- **闻声**：语声低微为少阴，气粗为阳明，叹息为厥阴，谵语为阳明腑实。

**破局心法**：先以望闻切锁定嫌疑经络，再用问诊验证、补充、排除，形成“**锁定—验证—排除**”动态闭环。

## 🎯 六经辨证抓手与鉴别要点

倪师问诊十问，每一问皆对应六经抓手，现提炼如下：

| 问诊条目 | 六经抓手 | 鉴别要点 |
|---|---|---|
| **一问寒热** | 太阳恶寒发热并见；阳明但热不寒；少阳往来寒热；少阴但寒不热；厥阴寒热错杂 | 恶寒是否加衣被？太阳恶寒加衣不减，少阴恶寒加衣可减。往来寒热为少阳独有。 |
| **二问汗** | 太阳无汗（麻黄汤）、有汗（桂枝汤）；阳明大汗（白虎汤）；少阳头汗（小柴胡）；少阴无汗（麻黄附子细辛汤） | 汗出部位、时间、冷热。盗汗为阴虚或阳明热。 |
| **三问头身** | 太阳头痛项强；阳明前额痛；少阳偏头痛；太阴头重如裹；少阴咽痛；厥阴巅顶痛 | 头痛部位直接分经。身痛为太阳，身重为太阴，身痒为表虚。 |
| **四问便** | 阳明便秘（承气汤）；太阴下利（理中汤）；少阴下利清谷（四逆汤）；厥阴热利下重（白头翁汤） | 大便颜色、气味、形状。青黑色为寒，黄臭为热。 |
| **五问饮食** | 阳明能食；太阴食不下；少阳不欲食；少阴但欲寐；厥阴饥不欲食 | 口渴与否分寒热。渴喜冷饮为热，渴喜热饮为寒。 |
| **六问胸** | 太阳胸满（桂枝去芍药汤）；少阳胸胁苦满（小柴胡）；阳明胸中懊憹（栀子豉汤）；少阴胸痛（瓜蒌薤白） | 胸满位置与伴随症。 |
| **七问聋** | 少阳耳聋（小柴胡）；少阴耳聋（附子汤） | 少阳耳聋伴口苦咽干，少阴耳聋伴脉微细。 |
| **八问渴** | 阳明大渴（白虎加人参）；少阳渴（小柴胡去半夏加栝楼）；少阴渴（猪苓汤）；厥阴消渴（乌梅丸） | 渴的轻重与饮水多少。 |
| **九问旧病** | 久病必虚，久病必瘀，久病入络 | 旧病与新病关系，新病引动旧病。 |
| **十问因** | 病因分内外。外感六淫，内伤七情，不内外因 | 问起因、时间、诱因，定病位病性。 |

**鉴别要点**：每一问都要追问**伴随症状**，如问寒热必问汗，问汗必问二便，问二便必问饮食。症状群交叉锁定，六经自明。

## 🗣️ 倪师讲义实录与问诊秘要

倪师在《人纪》中反复强调问诊的**动态性**与**实战性**，其秘要如下：

1. **问诊即辨证**：不是问完再辨，而是边问边辨。一问寒热，便知在表在里；二问汗，便知营卫强弱；三问头身，便知经络归属。每一问后，心中已有一经候选。

2. **十问歌活用**：倪师不主张死记十问歌，而主张“**以十问为纲，以六经为目**”。例如问“寒热”，太阳恶寒、阳明恶热、少阳寒热往来、少阴但寒、厥阴寒热错杂，一问即分五经。

3. **抓主证，弃兼证**：倪师常言：“**主证一现，兼证皆从**。”如见“往来寒热，胸胁苦满，默默不欲饮食，心烦喜呕”，但见一证便是小柴胡汤，不必悉具。此为动态辨证之精髓。

4. **问诊中的“试探性治疗”**：倪师在问诊中有时会用**试探性方剂**，如予小柴胡汤一剂，若症状缓解，则少阳证确认。此为“**以方测证**”的动态验证。

5. **问诊秘要——问“睡眠”与“手足”**：倪师特别重视睡眠与手足温度。失眠多梦为心肾不交或厥阴热扰；嗜睡为少阴但欲寐；手足冷为四逆，手足热为热厥。此二问，直指阴阳枢纽。

6. **动态辨证流程**：倪师流程为：**望闻切定基调 → 十问锁六经 → 主证定方证 → 试探验证 → 随证治之**。若主证变化，则方证随之变化，如太阳转少阳，桂枝汤转小柴胡汤；少阳转阳明，小柴胡转承气汤。此即“**观其脉证，知犯何逆，随证治之**”。

7. **问诊语言的艺术**：倪师问诊多用**患者能懂的语言**，如“怕冷还是怕热？”“手脚是热的还是冷的？”“大便硬不硬？”，避免术语，直取症状。问诊时观察患者**表情、语气、动作**，皆为辨证线索。

**最后秘要**：倪师曰：“**问诊之要，在于知常达变。常者，六经提纲；变者，合病并病。问诊如布网，网眼为六经，收网为方证。**”动态辨证，即是在问诊中不断收网，直至方证相应，一击即中。
