# 倪海厦十问歌与问诊抓手（寒热汗头身便饮食渴睡等）

## 👁️ 诊断要诀与原典法度

倪师言：**「问诊不是聊天，是拿刀切穴。」** 十问歌者，非十句泛泛而谈，乃十把钥匙，每一把直开一脏一腑一腑之门户。张景岳《十问歌》为底本，倪师临床化为**「寒热、汗、头身、便、饮食、渴、睡、胸腹、耳目、精神」**十字纲纪，一问一答之间，阴阳表里虚实寒热已现七分。

倪师铁律：

- **一问寒热** → 定阴阳之根。恶寒者，太阳表证未解或阳虚；但热不寒者，阳明里实或温病；寒热往来者，少阳枢机不利，小柴胡汤证立判。
- **二问汗** → 察营卫之开阖。无汗而喘，麻黄汤；汗出恶风，桂枝汤；但头汗出，剂颈而还，湿热郁蒸或阳脱。
- **三问头身** → 辨表里深浅。头痛在太阳经（后脑）、少阳经（两侧）、阳明经（前额）；身痛如被杖，寒湿入骨。
- **四问便** → 验里实里虚。便秘腹满拒按，阳明腑实，承气汤；下利清谷，少阴寒化，四逆汤。
- **五问饮食** → 测脾胃之气。能食不知味，脾败；饥不欲食，胃阴伤；食后胀甚，虚痞。
- **六问渴** → 判津液之存亡。大渴引饮，白虎加人参汤；渴不欲饮，湿阻；但欲漱水不欲咽，瘀血。
- **七问睡** → 观心肾之交。失眠烦躁，黄连阿胶汤；但欲寐，少阴病提纲；夜卧不安，胃不和则卧不安。
- **八问胸腹** → 定结胸与痞。胸痛彻背，栝蒌薤白白酒汤；心下痞满，半夏泻心汤。
- **九问耳目** → 察少阳与肾。耳聋口苦，少阳；目眩，少阳或肝风；耳鸣如蝉，肾虚。
- **十问精神** → 决生死之机。烦躁欲死，吴茱萸汤；郑声，虚;谵语，实。

**倪师口诀：「寒热定阴阳，汗定营卫，头身定表里，便定虚实，饮食定胃气，渴定津液，睡定心肾，胸腹定结痞，耳目定少阳少阴，精神定生死。」**

## ⚡ 倪师望闻问切破局心法

倪师临证，**四诊合参，问诊为先锋，但绝不单凭问诊下药**。十问既毕，立刻以望闻切三诊验证，此为「一问三验」之法。

**望诊破局**：
- **眼诊看五脏**：瞳孔属肾，黑睛属肝，白睛属肺，内外眦属心，上眼睑属脾。瞳孔缩小，肾阳虚；瞳孔散大，肾阴竭。白睛黄，湿热；白睛青，肝风。
- **舌诊**：舌苔白厚，寒湿；黄厚，湿热；舌红少苔，阴虚；舌淡胖有齿痕，阳虚水泛。
- **面色**：青属肝，赤属心，黄属脾，白属肺，黑属肾。面色黧黑，肾虚；面赤如妆，虚阳上浮。

**闻诊破局**：
- **声音**：声高有力，实证；声低息微，虚证。谵语，阳明实；郑声，少阴虚。
- **气味**：口臭，胃热；体臭，湿热；尿臊，肾衰。

**切诊破局**：
- **寸口人迎脉法**：寸口主五脏，人迎主六腑。寸口大于人迎，病在脏；人迎大于寸口，病在腑。
- **手足冷热辨阴阳**：手足温，阳气在；手足冷，阳虚或阳郁。**「手足冷至肘膝，四逆汤；冷不过肘膝，当归四逆汤。」**
- **脉象**：浮沉定表里，迟数定寒热，虚实定盛衰。脉浮紧，麻黄汤；脉浮缓，桂枝汤；脉沉细，四逆汤；脉滑数，白虎汤。

**倪师心法**：「问诊如审案，望闻切如取证。十问所得，必以三诊验之。**一问寒热，切其脉之迟数；二问汗，望其皮肤之润燥；三问头身，按其所痛之处；四问便，闻其腹中之鸣；五问饮食，观其舌苔之厚薄；六问渴，视其唇口之干润；七问睡，察其目睛之动静；八问胸腹，扪其痞结之有无；九问耳目，看其目色之青黄；十问精神，听其语声之高卑。**」

## 🎯 六经辨证抓手与鉴别要点

十问所得，必归于六经。倪师言：「**六经是地图，十问是路标。**」

**太阳病**：
- 问寒热：恶寒发热，寒热并见。
- 问汗：无汗，麻黄汤；有汗，桂枝汤。
- 问头身：头痛项强，身痛腰痛。
- 抓手：脉浮，头项强痛而恶寒。

**阳明病**：
- 问寒热：但热不寒，潮热。
- 问汗：汗出濈濈然。
- 问便：便秘，腹满拒按。
- 问渴：大渴引饮。
- 抓手：胃家实，脉洪大或沉实。

**少阳病**：
- 问寒热：寒热往来。
- 问头身：头痛在两侧，胸胁苦满。
- 问耳目：口苦，咽干，目眩，耳聋。
- 抓手：脉弦，小柴胡汤证。

**太阴病**：
- 问饮食：食不下，自利益甚。
- 问便：腹满时痛，下利。
- 问渴：不渴。
- 抓手：脉沉迟，腹满而吐，自利。

**少阴病**：
- 问睡：但欲寐。
- 问寒热：恶寒蜷卧，手足冷。
- 问便：下利清谷。
- 抓手：脉微细，但欲寐。

**厥阴病**：
- 问寒热：寒热错杂，厥热胜复。
- 问胸腹：心下疼热，气上撞心。
- 问饮食：饥不欲食，食则吐蛔。
- 抓手：脉微欲绝，厥阴提纲。

**鉴别要点**：
- **太阳与少阴**：太阳脉浮，少阴脉沉；太阳恶寒发热，少阴但寒不热。
- **阳明与太阴**：阳明便秘腹满拒按，太阴下利腹满喜按。
- **少阳与厥阴**：少阳寒热往来，厥阴寒热错杂；少阳口苦咽干，厥阴气上撞心。

**倪师一击必中**：
- 见**但欲寐**，直取少阴，四逆汤。
- 见**寒热往来**，直取少阳，小柴胡汤。
- 见**大渴引饮**，直取阳明，白虎加人参汤。
- 见**手足冷至肘膝**，直取少阴，四逆汤。
- 见**心下痞满**，直取太阴或少阳，半夏泻心汤。

## 🗣️ 倪师讲义实录与问诊秘要

**倪师原声**：

「你们问诊，不要像西医那样，问东问西，问得病人烦。**十问歌是刀，一刀下去，要见血。**」

「问寒热，不是问『你怕冷吗？』，要问『你怕冷还是怕热？冷的时候想加衣服吗？热的时候想脱衣服吗？』——**恶寒加衣不减，恶风加衣可减，此为关键。**」

「问汗，不是问『你出汗吗？』，要问『你出汗是全身还是局部？是白天还是晚上？汗出后舒服还是不舒服？』——**汗出后舒服，桂枝汤；汗出后烦躁，阳明热。**」

「问头身，不是问『你头痛吗？』，要问『头痛在哪？后脑？两侧？前额？』——**后脑太阳，两侧少阳，前额阳明，巅顶厥阴。**」

「问便，不是问『你大便好吗？』，要问『大便几日一次？硬还是软？颜色？气味？』——**大便硬，阳明；大便溏，太阴；大便黑，瘀血；大便白，胆道阻塞。**」

「问饮食，不是问『你能吃吗？』，要问『你想吃吗？能吃多少？吃完舒服吗？』——**饥不欲食，胃阴伤；食后胀，脾虚；食后痛，胃溃疡。**」

「问渴，不是问『你渴吗？』，要问『你想喝水吗？喝热水还是冷水？喝多少？』——**渴喜冷饮，阳明热；渴喜热饮，少阴寒；渴不欲饮，湿阻。**」

「问睡，不是问『你睡得好吗？』，要问『你几点睡？几点醒？梦多吗？』——**但欲寐，少阴；失眠，心肾不交；早醒，肝郁。**」

「问胸腹，不是问『你胸痛吗？』，要问『胸痛在哪？痛多久？按之如何？』——**胸痛彻背，栝蒌薤白；心下痞，半夏泻心。**」

「问耳目，不是问『你耳鸣吗？』，要问『耳鸣如蝉还是如潮？耳聋是突然还是渐进？』——**耳鸣如蝉，肾虚；耳鸣如潮，肝火。**」

「问精神，不是问『你精神好吗？』，要问『你烦躁吗？谵语吗？郑声吗？』——**烦躁欲死，吴茱萸汤；谵语，承气汤；郑声，四逆汤。**」

**倪师问诊秘要**：

1. **问诊如审案，必问其详**：病人说「我头痛」，必问「痛在哪？痛多久？痛的性质？何时加重？」
2. **问诊如钓鱼，必引其言**：病人说「我睡不着」，必问「为什么睡不着？是难入睡还是易醒？醒后能再睡吗？」
3. **问诊如切脉，必验其真**：病人说「我冷」，必摸其手足，看其舌苔，切其脉象。
4. **问诊如用兵，必知其要**：十问所得，必归于六经，必辨其阴阳表里虚实寒热。
5. **问诊如讲道，必传其心**：病人不懂，必以白话解之，使其知病之所在，治之所在。

**倪师最后叮咛**：

「**十问歌不是死的，是活的。** 你们要灵活运用，不要死记硬背。问诊如打仗，要随机应变。病人说东，你要问西；病人说表，你要问里。**一问三验，四诊合参，方为良医。**」
