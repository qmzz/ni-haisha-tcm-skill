# 倪氏十问歌与临证鉴别决策体系

> *"问诊为知病情之枢纽，倪师临证首重阳气、水火与气化。问诊不是对号入座，而是探求阴阳虚实之根。"*

---

## 🧭 倪氏十问核心脉络

| 序号 | 问诊项目 | 核心探求机理 (倪师原理解析) | 关键鉴别眼目 |
|:---|:---|:---|:---|
| **一问** | **睡眠** | 探心阳与神气。心藏神，肝藏魂，阳入于阴则寐。 | • 彻夜不眠（心肾不交/血虚/虚烦）<br>• 凌晨1-3点醒（肝经病/肝实）<br>• 凌晨3-5点醒（肺经气血流注异常） |
| **二问** | **胃口与食欲** | 探脾胃运化与阳明燥土。 | • 知饥能食（胃气尚存）<br>• 腹满不欲食（太阴脾湿/水饮内停）<br>• 消谷善饥（胃热/中消） |
| **三问** | **口渴与饮水** | 探体内津液与水气寒热。 | • 渴喜冷饮（阳明热盛/实热）<br>• 渴喜热饮/饮不解渴（下焦虚寒/水饮不化）<br>• 口干不欲饮（内有瘀血或水饮伏聚） |
| **四问** | **大便** | 探大肠传导、小肠火候与下焦寒热。 | • 便秘硬结（阳明燥热/津亏）<br>• 晨起泄泻/完谷不化（脾肾阳虚/命门火衰）<br>• 腹泻如水/下利清谷（四逆汤证/真寒） |
| **五问** | **小便** | 探膀胱气化与肾阳温煦。 | • 色清量多（下焦虚寒/阳气不化）<br>• 色黄赤热痛（下焦湿热）<br>• 夜尿频多（肾阳不足/心火不降） |
| **六问** | **出汗** | 探营卫和与不和、表里开阖。 | • 动则大汗/自汗（卫阳不固/气虚）<br>• 睡时出汗/盗汗（阴虚/少阳郁热）<br>• 无汗恶寒（太阳伤寒表实/麻黄汤证） |
| **七问** | **下焦与手足温度** | **【倪师最核心抓手】** 探心阳与小肠之火是否下达。 | • 手足温热/脚热（心阳下达小肠，阳气充沛）<br>• 手足冰冷/下肢冷（心肾阳衰，水饮内停）<br>• 头热脚冷（上热下寒/厥阴证/真寒假热） |
| **八问** | **头身与胸腹** | 探六经部位与经络气血阻滞。 | • 头项强痛（太阳表证）<br>• 往来寒热/胸胁苦满（少阳枢机不利）<br>• 心下痞满/按之痛（结胸/心下痞） |
| **九问** | **体力与精神** | 探元气与少阴根本。 | • 但欲寐/神疲肢厥（少阴病死生之机）<br>• 精神烦躁/不得卧（阴阳离决前兆） |
| **十问** | **妇人经带胎产 / 男子精血** | 探冲任气血与厥阴肝经。 | • 月经色暗夹块（胞宫寒凝/瘀血）<br>• 白带清稀如涕（下焦虚寒/带脉不固） |

## 🌲 临证动态追问决策树 (Agent 交互引擎)

当患者/用户提出主诉时，按以下优先级发起针对性追问：

```
[ 用户主诉进入 ]
       │
       ▼
1. 查【寒热与脚温】：
   - "平时手脚是温热的还是冰凉的？晚上睡觉脚冷不冷？" (直断下焦真寒真热)
       │
       ▼
2. 查【口渴与饮水偏好】：
   - "口渴不渴？想喝温热水还是冰水？喝下去胃里舒服吗？" (鉴别水饮与津亏燥热)
       │
       ▼
3. 查【二便性状与规律】：
   - "大便每天几次，是干结还是溏稀？小便颜色是清亮还是深黄？" (鉴别阳明与太阴/少阴)
       │
       ▼
4. 查【出汗与睡眠节奏】：
   - "夜里几点容易醒？有没有盗汗或活动后大汗？" (定位病位脏腑)
       │
       ▼
[ 四诊证据链齐备 ➔ 出具倪氏理法方药标准案 ]
```
